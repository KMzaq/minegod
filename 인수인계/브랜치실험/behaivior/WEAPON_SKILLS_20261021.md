# 선택형 보상 무기 스킬·마나 — 2026-10-21

`behaivior`의 기존 미커밋 작업을 보존하며 게임 모듈에 추가했다. 운영 서버 배포·부팅·실제 클라이언트 조작은 수행하지 않았다. [작성·동작 계약](../../../mythictrpg-main/docs/WEAPON_SKILLS.md)을 기준으로 후속 작업한다.

## 사용자 결정과 구현

- 모든 무기가 아니라 지정 보상 무기만 주 손 우클릭 스킬을 가진다. 처음/최대 마나200, 사용 후 대기 없이 초당2 회복, 스킬마다 비용·쿨타임을 작성한다.
- `CombatPowerPolicy.ItemRule.rightClickSkill`은 선택 필드다. 기존 `skills` 점수만으로 실행하지 않는다. 기존 5/10인수 생성자를 유지했다. 등록된 귀속 보상 무기의 본인 획득 이력을 기존 게임 API로 인증한다.
- `weaponskill/`에 정의·입력 요청·실행·마나 SavedData·본인 상태 전송을 추가했다. `client/weaponskill/`은 양손 중복 요청 방지, 정확한 주 손 변형 일치, 마나 HUD를 담당한다. Shift+우클릭은 기존 상호작용을 유지한다.
- 서버가 현재 접속 플레이어 객체·선택 슬롯·실제 아이템·소유권·효과·자원을 재검사한다. 성공 시에만 소모하며 재접속/무기 교체로 마나·동일 스킬 쿨타임이 초기화되지 않는다. 손상된 NBT는 원본을 보존하며 사용을 거절한다.
- 초기 실행 행동은 조준 **마법 피해**, 자가 회복, 임시 유익 효과다. 피해는 기존 레이드/PvP/NPC 보호를 통과하며 미로딩 청크를 강제 로드하지 않는다. 임시 효과는 영구 가호 보유권과 인간 루트 조건을 바꾸지 않는다.
- 개별 무기 배정·수치·정식 스킬 파일은 작성하지 않았다. 성급함 쿨타임 감소, 최대 마나 성장, 광역·돌진·소환 등은 미확정/미구현이다. 전체 무기 자동 적용이나 AI 권한 확장은 없다.

## 검증

최종 게임 컴파일·JAR 생성 성공. 순수 검사 `weaponSkillDefinitionTest`19 + 기존 전투력 평가33/정책38 = 90 assertions 통과.

관련 GameTest 고유253개를 실행했다. 최종 결과는 다음 두 기록을 조합한다.

무기 스킬16개는 상태8·네트워크2·실행6이다. 실제 보상 지급과 소유권, 선택적 연결, 아이템 변조·내구도, 다른 비용/쿨타임, 저장/재접속, 즉시20틱당2 회복, 임시 효과·가호 보유권 분리, 벽과 레이드 보호에 의한 피해 거절을 포함한다.

첫 행렬의 실패2개는 삭제/합격 처리하지 않았다. 모의 접속에는 실제 연결 틱 펌프가 없으므로 회복 테스트에서 `ServerPlayer.doTick`으로 실제 NeoForge 이벤트를 발생시키도록 수정했다. 기존 시험장 테스트는 GameTestServer의 비실시간 틱150개를 비동기 엔티티 로딩 대기시간으로 사용해 약0.67초 안에 실패했다. `TrialRaidGameTests`에만 실제10초 제한·1ms 양보를 적용했으며 운영 준비 조건은 변경하지 않았다. 두 묶음을 새 격리 월드에서 다시 통과시켰다.

실제 마우스/키 입력과 HUD 그래픽은 미확인이다. 테스트는 프로토콜·매칭 및 서버 실행을 확인하며 실제 클라이언트 조작을 대체하지 않는다. 전체 프로젝트/실제 LLM 품질 게이트 통과나 운영 배포 승인을 뜻하지 않는다.
