# 장신구 아이템 분류·사용자 텍스처 — 2026-10-22

브랜치 `behaivior`, 게임 **1.0.39**. 사용자가 제공한 이미지4장으로 장신구 아이템 분류를 만들고 이름을 바꾸도록 요청했다. 직전 E 인벤토리 장착 작업(1.0.38)도 이번 JAR에 함께 포함한다. [아이템 ID·작성 안내](../../../mythictrpg-main/docs/ACCESSORY_ITEMS.md), [검증·최종 JAR](../../../검토결과/accessory-items-20261022/REVIEW.md).

## 구현

- 투명 PNG4장을 `amethyst_pendant`, `azure_ring`, `brass_cuff`, `crimson_talisman` 파일명으로 복사했다. 이름은 자수정 펜던트·청옥 반지·황동 가죽팔찌·주홍 부적이다. 원본1254×1254/ARGB/투명도와 바이트를 유지하며 원본 파일은 수정하지 않았다. 모델4개·한/영 번역을 연결했다.
- 공통 `AccessoryItem`과 실제 `mythictrpg:accessories` 크리에이티브 탭을 만들었다. 같은 ID의 item 태그에는 신규4종과 구형 `bound_accessory`를 등록했다. 크리에이티브 기본 외형에는 소유권/효과를 발급하지 않으며 툴팁으로 실제 보상 장신구와 구분한다.
- `RewardAccessoryItems`가 보상 정의 `itemId`에 따라 전용 외형을 생성한다. E 슬롯·Shift·커서·재지급·옛 토큰 정리는 공통 아이템 분류를 확인한다. 실제 보상 원장 UUID·소유자·정의·외형 일치 검증은 유지한다. 구형 TOKEN은 같은 권리로 장착하며 꺼낼 때 새 외형으로 표시하고, 다른 신규 아이템에 보상 데이터를 복사한 위조는 거부한다.
- 기존 `proto_cbt:clear_mana_stone`은 **청명의 펜던트**, `proto_cbt:blade_knot`은 **연계의 반지**로 이름과 외형을 갱신했다. 기존ID·UUID·최대 마나+40/연계10%·고정 전투력12는 유지한다. 팔찌/부적의 새 개별 효과는 기획 단계다.
- 기본 네 외형은 크리에이티브 장신구 탭에서 확인한다. 실제 효과와 E 장착은 기존 `/mythprototype grant kit`의 소유권 있는 시험 보상을 사용한다. 네트워크는 직전 `accessories-2`를 유지하고 서버·클라이언트 게임 JAR을 같은 버전으로 맞춘다. AI 기본 게임 API 경로는1.0.39로 갱신했다.

## 검증과 배포 범위

검증 수·해시·빌드 로그는 위 검증 보고서를 따른다. 신규 원본 그림 자체는 수정하지 않았다. 리소스 경로/모델/번역/태그와 원본 해시 일치를 확인했고 관련 GameTest를 실행했다. **실제 Minecraft 클라이언트 렌더/화면 조작은 확인하지 않았다.** 운영 서버·개인 런처에 설치하거나 운영 서버를 부팅/중지하지 않았다. 현재 사용자가 실행한 게임은 정상 종료 후 새 JAR 하나로 교체해야 한다.
