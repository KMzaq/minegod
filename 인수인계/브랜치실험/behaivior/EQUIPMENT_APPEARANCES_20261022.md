# 무기·장신구 외형 재사용 — 2026-10-22

브랜치 `behaivior`, 게임 **1.0.40**. 사용자 요청은 검2종과 기존 장신구 그림을 재사용하면서 같은 외형의 이름·능력·인챈트·스킬을 다르게 정의하는 기능이다. [작성·시험 안내](../../../mythictrpg-main/docs/EQUIPMENT_APPEARANCES.md), [검증·JAR](../../../검토결과/equipment-appearances-20261022/REVIEW.md).

## 구현

- `equipment/EquipmentItems`·크리에이티브 무기 외형 탭에 강철검/결투검 두 기본 아이템을 등록했다. 사용자 투명PNG를 편집 없이 복사했다. 기본 외형 자체에는 보상 권리를 만들지 않는다.
- `mythictrpg/equipment/<ID>.json`의 논리 정의가 외형 `itemId`와 이름·공격력 기여량·공격 속도·내구도·실제 인챈트·고유 전투력·선택형 우클릭 스킬을 가진다. 하나의 정의에서 기존 `NpcRewardEntry`와 `ItemRule`을 함께 생성한다. 기존11종은 유지하며 `reuse_demo` 검4개를 추가했다.
- `CombatPowerPolicyManager.forRegistries`는 해당 reload의 frozen registry lookup을 캡처한다. 등록 SwordItem·실제 스택 codec·인챈트와 전투력 규칙을 확인한 후 정의/정책 하나의 스냅샷으로 교체한다. 준비 중 다른 스킬 리스너의 미적용 상태를 읽지 않으며 실제 보상 참조 검증 시 연결 스킬 존재를 검사한다. 기본 `Loaded(policy,reason)` 생성자는 기존 격리 검사와 호환한다.
- 공통 `equipment` 보상 참조를 codec·신 등급 검증·자동/선택/오프라인 claim·실행 거부 경계에 연결했다. 온라인은 지급 전, 오프라인은 대기 영수증 생성 전에 구체적인 장비 구성요소를 저장한다. 장비 정의 표식은 기존 출처 영수증 정리 후의 재수령 방지에 사용하며 무기 실행 권한은 여전히 개인 획득 이력과 실제 전체 아이템 구성요소로 검사한다.
- 장신구의 표시용 `components`를 미리보기·지급·착용·재지급에서 같은 factory로 만든다. lore/반짝임/희귀도/custom_model_data만 허용하고 소유자·권리UUID·정의는 서버가 새로 설정한다. 실제 장착 능력은 기존 `effects`를 사용하며, 같은 펜던트 외형을 공유하는 마나/연계 예시2개를 추가했다. 기존 시제품 장신구와 사용자 그림4종은 보존했다.
- OP2 `/mythequipment list`, `/mythequipment grant <정의ID>`, `/mythequipment grant examples`는 기존 `PrototypeGrantService` 영수증·실제 지급·획득 이력·권리·복구 거래를 재사용한다. 신규 원장/퀘스트 실행기를 만들지 않는다. 시험 묶음은 검4+장신구2, 첫 지급 빈 칸6개 필요. 같은 정의 ID를 무기·장신구 양쪽에 중복 등록하면 해당 지급은 거절한다.
- 대량 수집에 맞춰 기존 획득 이력 상수만 개인4096/서버65536으로 늘렸다. 저장 형식·이미 불완전한 이력·기존 보유권은 유지하며 자동 복구/삭제하지 않는다. 구512/8192 한도를 넘은 저장을 이전 버전으로 되돌리는 것은 안전하지 않다.

## 조정·후속

실제 정의 JSON과 연결 스킬 파일을 수치 원본으로 사용한다. 기존 장비 구성요소를 바꾸면 전체 획득 정체성이 달라지므로 새 정의ID/명시적 이관이 필요하다. 기존 영수증과 현재 정의가 다르면 개발 재지급도 거절한다. 같은 스킬ID의 마나·쿨타임·행동 수치 변경은 장비 실물 정체성을 바꾸지 않는다. 새로운 효과·스킬 행동이 필요하면 기존 실행기를 확장한다. 정식 인물·보상 배정은 이번 기술 예시로 확정하지 않는다.

관련 GameTest149/149와 게임 컴파일/JAR·순수46+36+38검사·기존 밸런스3/2/11검사가 통과했다. AI main/test API 컴파일·소유권·패키지551클래스/게임 중복0도 통과했다. 산출물 해시는 위 검증 보고서를 따른다. **서버/런처 미배포, 실제 GUI·손 모델 렌더 미확인**이다.
