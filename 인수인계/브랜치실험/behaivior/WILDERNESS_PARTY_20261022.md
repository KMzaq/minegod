# 야생 전투·FTB 파티 확장 — 2026-10-22

브랜치 `behaivior`, 게임 **1.0.37**. 사용자가 시험장 밖 스킬 사용, PvP·주민 공격, 본인 소유 동물 보호, 일반 야생 파티와 파티원 피해 방지를 요청했다. 기존 1차 기획 ZIP의 시험 범위 제한은 이 후속 요청으로 변경한다. 실제 사용법은 [야생 전투와 파티](../../../mythictrpg-main/docs/WILDERNESS_COMBAT_AND_PARTY.md), 수치는 [조정 안내](../../../mythictrpg-main/docs/BALANCE_TUNING.md)를 따른다.

## 변경

- `PrototypeCombatAccess`에 플레이어·차원별 야생 scope를 연결했다. 검기·패링·짧은 회피를 야생에서 사용할 수 있다. 레이드 입장/전투/정리 중 권한과 시험장 등록 적·구역은 유지하고, 밖에서 쏜 스킬로 다른 전장에 개입하지 못한다. 레이드 정리가 끝난 뒤 보상 정산만 대기하는 상태는 야생 이용을 막지 않는다.
- 야생 패링은 실제 플레이어/몹의 직접 근접 공격, 회피는 명시된 vanilla 투사체와 검기를 분류한다. 레이드/시험장의 기존 개별 공격 허용 목록과 기믹 예외는 유지한다. 인물 특수지원의 레이드 전용 규칙은 유지한다.
- `CombatTargeting`을 일반 스킬·검기·지속 공격·실제 피해에 공통 적용했다. 비파티 플레이어·주민·중립 생물은 공격할 수 있다. 실제 소유 UUID가 본인 또는 같은 파티원인 동물과 현재 파티원을 보호한다. 온라인/오프라인 소유자, 화살·해로운 포션·잔류형 포션을 확인하며 이로운 효과는 유지한다. 환경 피해에 무적을 주지 않는다.
- 검 휩쓸기는 `CombatPartySweepMixin`에서 보호 대상을 제외하여 피해 취소 전 발생하는 넉백도 막는다. 서버 PvP 설정·vanilla 팀의 아군 공격 금지·다른 모드의 피해 취소는 우회하지 않는다.
- `PartyService`와 `/mythparty`는 **기존 FTB Teams 하나만** 원본으로 사용한다. 생성·조회·초대·동의 후 가입·탈퇴·권한 범위 내 추방·파티장 이전·해산을 연결했다. 별도 파티 저장소나 보상 원장은 만들지 않았다. 기존 FTB Quests/Story의 팀 공유도 동일한 팀을 사용한다. 이미 시작한 레이드 명단은 중간 파티 변경으로 바꾸지 않는다.
- 스킬 무기로 주민을 직접 우클릭하면 스킬이 발동하고 Shift+우클릭하면 거래한다. 상자·문의 기존 우선순위는 유지한다.
- 피해량·선후딜·마나·쿨타임·장신구 수치·획득 권리/재지급 규칙은 변경하지 않았다. 마나는 기존 기본200·최대 마나의 초당1% 회복이다. AI 빌드의 기본 게임 API 경로를 1.0.37로 갱신했다.

## 검증과 산출물

최종 결과는 [검증 보고서](../../../검토결과/wilderness-party-20261022/REVIEW.md)에 기록한다. 격리 GameTest 월드만 사용하며 운영 월드와 분리한다. 최초 실패의 테스트 환경 보정과 후속 재검증도 보고서에 남긴다.

**소스 구현·자동 검증·JAR 생성과 파일 설치·실제 플레이는 다른 단계다.** 이번 작업은 운영 `server/mods`·`server/client-required-mods`와 개인 Minecraft 런처를 교체하지 않았다. 운영 서버 부팅/중지, 실제 클라이언트 UI·사람 간 멀티플레이·밸런스 평가는 하지 않았다. 기존 AI 대사 품질 미통과/기획 미등록 상태도 변경하지 않는다.

개인 클라이언트는 정상 종료 후 `mythictrpg-1.0.36.jar`를 새 **1.0.37 하나로 교체**하고 재실행한다. 멀티플레이는 서버·참가자 클라이언트에 같은 새 게임 JAR이 필요하다. 기존 월드·플레이어 획득 이력을 초기화하지 않는다.
