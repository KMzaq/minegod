# 스킬·장신구·조합형 특수지원 — 2026-10-22

## 구현

- `skills/`와 기존 `weaponskill/`: 기존 보상 원장 기반 습득·선택·사용, K/J 및 일반 명령, 공통 Start/Hit/Finished 시전UUID, 범위/반복 공격, 정상 공격의 유료 빗나감, 동적 최대 마나·초당1% 회복, HUD·v1→v2 저장 이전.
- `accessory/`, `client/accessory/`: 자유2칸, 별도 획득한 같은 장신구 중첩, 전투 중 교체, 실제 보상 권리별 효과·현실 쿨타임, 연계/환급 중복 방지, 정화·응급 회복·점프·마나·행운·피해·속도·재생·골드. O/인벤토리 버튼/일반 명령과 재지급 버튼. 전용 귀속 아이템은 새 권리나 제작 재료 복제를 만들지 않는다.
- `specialskill/`, `control/`: 사용 제한 최소 하나 선택, 여러 제한은AND. 도전별 횟수·현실 만료·정확한 재료·마나를 검증하고 기록한다. ACTIVE 참가자만 사용하며 같은 인물 외형의 비영속 지원 실체가 한 행동 후 퇴장한다. 기존 NPC 실체·대화·퀘스트·관계 소유권을 건드리지 않는다. 일반 기절·기믹 분리·정화·별도 면역 정의를 제공한다.
- `quest/reward/`: `learn_skill/accessory/special_skill`을 기존 자동·선택 claim과 같은 저장소에서 확정한다. v7 이전·결정적 권리ID·소유권/영수증 상호 검사·정리 후 출처 재사용 방지. NPC 표도 개인 영수증으로 연결한다. 가호 보유권으로 취급하지 않으며 원래 지급 출처를 유지한다.
- 등급: 신규 습득/장신구/특수는 하급/상급/최상급 최소 등급, 제공 인물·실제 정의를 검사한다. 등급이 있는 제공자의 방어구/무기는 하급/중급 제한을 검사한다. 기존 미작성 일반 장비는 레거시 호환이며 새 콘텐츠의 실제god_rank 작성이 필요하다.
- 보상/전투력: 장신구+가호 행운을 공통 조회하고17상한 유지, 골드 추가분은 영수증에 고정하고 일반 credit/환불 제외. 스킬 점수는 ID별 최대값, 장신구 고정 점수는 보유 권리 중 상위2개이며 실제 효과는 착용2개만 적용한다.
- 기존 `RaidState`에 참가자/부활 대기 읽기API, 게임 부트스트랩에 지원 실체/귀속 아이템 등록을 추가했다. 네트워크는 동적 마나 `weapon-skills-2`와 새 스킬/장신구 채널이다.

## 기획 후속·운영 경계

인물별 스킬·장신구·특수스킬 파일과 정식 수치는 비워 두었다. 기획자가 전달서의 사용 제한 선택/조합과 신별 양식을 채우면 기존 지급 경로에 연결한다. 초월급의 별도 보상 종류를 임의로 만들지 않았다. 미구현 돌진/투사체 등 새 행동은 개별 기술 기획을 받은 뒤 확장한다.

이번 기본 중첩 처리(정화 순차 충전·응급 회복 동시 합산·추가 점프 합산·시전 시작 시 효과 고정), 행운17상한, 골드 보너스 대상과 피해 보정 단계는 기획 전달서에 명시했다. 장신구 고정 점수는 기존 획득 기반 평가와 일치하도록 보유 상위2개를 사용한다.

운영/클라이언트 JAR을 교체하지 않았다. 신규 아이템·엔티티·네트워크와 저장 형식 때문에 배포 시 같은 게임 JAR을 양쪽에 맞추고 백업·버전/해시를 확인해야 한다. 이전1.0.36이라는 파일명만으로 같은 산출물로 판단하거나 새 저장 자료를 구 JAR로 무조건 롤백하지 않는다.
