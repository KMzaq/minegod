# 말투 및 출처 메모

## 프로젝트 내부 기준
- `AI_CHARACTER_CONTENT_AUTHORING_GUIDE(1).md`의 5개 JSON 역할과 금지사항을 기준으로 작성했다.
- `그리스_신화_주요_신격_영웅_등장인물_태그_DB .md`의 이름, 태그, 핵심 설명을 캐릭터 사실의 주 자료로 사용했다.
- `세계관_배경스토리_확장판(1).md`의 업, 신격, 창구, 봉인, 세력 관계의 고정 설정을 공통 지식으로 사용했다.
- 타 신화 개별 신과의 관계는 이번 버전에서 보류했다.

## 외부 한국어 대화 스타일 참고
말투는 Smilegate AI의 공개 자료를 **스타일 원리 참고용**으로만 사용했다. 데이터셋 원문 대사는 이 패키지에 복사하지 않았다.

### Korean SmileStyle Dataset
- 동일 멀티턴 대화를 formal, informal, gentle, king, seonbi 등 다양한 한국어 문체로 변환한 자료.
- 여기서는 존댓말/반말, 격식 정도, 고전적 권위체, 부드러운 말투의 차이를 설계할 때 참고했다.
- 원본 데이터셋 문장은 포함하지 않았다.
- 데이터셋은 공개 저장소의 라이선스 조건을 별도로 확인해야 한다.

### OPELA
- 고정 페르소나를 유지하는 한국어 오픈도메인 대화, 맥락 유지, 능동성, 공감/흥미 요소를 연구한 자료.
- 여기서는 '캐릭터가 매번 자기 권능만 반복하지 않기', '사용자 발화의 의도에 직접 반응하기', '짧아도 대화를 이어갈 여지를 주기' 같은 작성 원칙에 참고했다.
- OPELA 원문 대사는 포함하지 않았다.

## 생성 대화 원칙
- 모든 예시는 새로 작성했다.
- 신격당 5개: 낯선 인사 / 정보 질문 / 부탁 / 퀘스트 제안 / 사과·갈등.
- 실제 퀘스트·아이템·가호 실행을 완료했다고 말하지 않는다.
- 답변은 대부분 1~2문장이다.
- 말투 태그는 작성 가이드가 허용한 P_* 목록만 사용한다.
