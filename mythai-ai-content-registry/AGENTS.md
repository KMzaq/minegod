# MythAI 콘텐츠 레지스트리 진입 지침

작업 전 [상위 AGENTS.md](../AGENTS.md)와 [작업 시작 안내](../인수인계/START_HERE.md)를 읽고 해당 작업의 프로젝트 스킬을 선택한다. 과거 기록은 [공용 인수인계](../인수인계/PROJECT_HANDOFF.md)에서 관련 절만 확인한다.

이 모드는 정적 콘텐츠와 조회 계약을 제공한다. 게임의 God ID와 파일 기반 콘텐츠 ID를 구분하고, 실제 진행도·관계·보상 상태의 새 원본 저장소를 만들지 않는다. 상위 작업공간이 없는 복사본이면 게임 정의와 배포 상태를 확인했다고 단정하지 않는다.
