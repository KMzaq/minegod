# E 인벤토리의 장신구 두 칸

2026-10-22 게임 **1.0.38** 후속. 장신구 효과·보상 권리·현실 쿨타임은 기존 [스킬·장신구 가이드](SKILLS_ACCESSORIES_SPECIAL.md)를 유지하며 장착 조작을 기본 인벤토리에 연결했다.

게임 **1.0.39**에서 사용자 제공 [장신구 외형4종·아이템 분류](ACCESSORY_ITEMS.md)를 추가했다. 아래 장착 방식은 그대로 사용한다.

## 사용

- **생존/모험:** `E` 인벤토리에서 캐릭터 오른쪽, 보조 손 칸 위에 장신구 두 칸이 있다. 본인 보상 장신구를 마우스로 집어 넣으면 장착하고, 칸의 아이템을 집어 꺼내면 해제한다.
- **빠른 장착:** 일반 인벤토리/핫바의 장신구를 Shift 클릭하면 빈 장신구 칸에 장착한다. 두 칸이 가득 차면 기존 인벤토리/핫바 이동을 따른다. 장착 칸을 Shift 클릭하면 일반 인벤토리로 돌려준다. 빈 칸이 없으면 장착 상태를 유지한다.
- 장착 칸 위에서 숫자키/보조 손 교환도 본인 장신구와 빈 칸에만 허용한다. 일반 재료·다른 플레이어 장신구·같은 획득 UUID의 복사본을 추가 장착하지 못한다. 따로 획득한 같은 종류의 두 장신구는 함께 착용할 수 있다.
- **크리에이티브:** `E`의 **생존 인벤토리 탭**에서 같은 두 칸을 사용한다. 서버가 아이템 이동과 커서를 확인한다. 다른 아이템 목록 탭으로 갈 때 커서의 물건을 먼저 빈 칸에 놓는다. 휴지통 대신 빈 칸으로 옮기거나 Q/화면 밖 드롭을 사용한다.
- `O`, `/mythaccessory`, E 화면의 **장신구 관리** 버튼은 재지급·연계 대상 지정·보유 목록 관리에 계속 사용한다. 이 화면의 장착·해제도 같은 두 칸에 반영한다.

전투 중 교체는 계속 가능하다. 장착 자체가 마나를 채우거나 장신구의 현실 쿨타임을 초기화하지 않는다. 장착한 장신구는 일반 인벤토리 한 칸을 추가로 차지하지 않는다. 재지급은 현재 장착 칸·커서·본인 인벤토리에 이미 있는 같은 장신구를 추가로 만들지 않는다. 상자에 보관한 물건까지 검색하지는 않는다.

## 저장과 기존 자료

기존 보상 원장의 획득권리 UUID와 `AccessoryState`의 두 착용 UUID가 유일한 원본이다. 별도 물리 장신구 저장소나 새 보상 권리를 만들지 않는다. 예전 관리 화면에서 착용한 상태도 그대로 표시하고, 해당 착용 권리의 옛 인벤토리 기념 토큰은 착용 칸으로 정리한다. 사망·리스폰·재접속으로 착용 권리와 현실 쿨타임을 초기화하지 않는다. 일반 인벤토리/커서 물건의 사망 처리는 기존 Minecraft 규칙을 따른다.

메뉴 끝에 두 슬롯을 추가하므로 기존 방어구·제작·핫바·보조 손 슬롯 번호는 유지한다. 서버 검증 전에는 추가 슬롯의 직접 변이를 허용하지 않고, 정상 메뉴 클릭이 소유권 확인과 아이템 교환을 한 번에 처리한다. 크리에이티브의 직접 슬롯 설정 패킷으로 새 칸에 아이템을 쓰는 방식은 사용하지 않는다.

메뉴가48칸으로 바뀌므로1.0.38부터 장신구 네트워크 버전은 `accessories-2`다. 서버·클라이언트 게임 JAR 버전을 맞춘다. 새 외형은 **1.0.39**부터 포함한다. Minecraft를 정상 종료하고 이전 게임 JAR을 새 파일 하나로 교체한 뒤 다시 실행한다. [장착 구현·검증 기록](../../인수인계/브랜치실험/behaivior/ACCESSORY_INVENTORY_20261022.md)과 [외형 후속 기록](../../인수인계/브랜치실험/behaivior/ACCESSORY_ITEMS_20261022.md)에서 자동 검증과 실제 클라이언트 확인 여부를 구분한다.
