2026-10-22 `behaivior`. [사용자 원본 명세](../../추가개발/전투1차/기획원본/1차_장비스킬_기획/01-first-combat-prototype.md)를 기존 보상·권리·전투력·장신구 시스템에 연결했다. `proto_cbt`는 시제품 콘텐츠 ID이며 실제 인물이나 God ID가 아니다. 보상 인물은 미배정이다.

**1.0.37 변경:** 사용자가 시험 범위를 확대했다. 이제 야생에서도 사용하며 PvP·주민 공격을 허용하고 자기/파티 소유 동물과 파티원을 보호한다. [야생 전투·파티 사용법](WILDERNESS_COMBAT_AND_PARTY.md)을 따른다. 시험장 등록은 선택 사항이다.

## 직접 시험 시작

서버·클라이언트 양쪽에 같은 새 게임 JAR이 필요하다. 기존 서버/런처의 파일은 자동 교체되지 않는다. 평평하고 전방 10칸이 비어 있는 곳에서 생존 모드, OP 권한 2 이상으로 실행한다. 평화로움 난이도에서는 몬스터 표적을 사용할 수 없다.

```text
/mythprototype grant kit
/mythprototype arena
/mythskills select proto_cbt:short_dodge
/mythaccessory
```

키트는 무기 3개·방어구 8개·회피 습득권·마나석 두 권리·매듭 두 권리를 지급한다. 빈 인벤토리 칸 15개가 필요하다. 기존 물건·가호·마나·쿨타임을 초기화하거나 장비를 강제 장착하지 않는다. 같은 명령은 권리를 늘리지 않고 본인 인벤토리에서 없어진 실물만 복구한다. 상자까지 검색하지 않으므로 보관품을 분실로 취급해 재발급하지 않도록 한다.

시험장은 현재 위치 중심 32×32칸, 아래 4~위 12칸이다. 전방 3·5·7·9칸에 체력 200, 방어력 0인 표적 4개를 만든다. 지형은 바꾸지 않는다. AI·전리품·경험치가 없고 종료·개설자 로그아웃·정상 서버 종료 시 제거된다. 시험장은 재시작 후 유지하지 않는다.

| 조작·명령 | 효과 |
|---|---|
| 지정 무기 주 손 우클릭 | 검기 또는 패링. 단련의 검은 스킬 없음 |
| `J`, `/mythskills use` | 선택한 짧은 회피 |
| `K`, `/mythskills` | 습득 스킬 선택 |
| `E` / `O`, `/mythaccessory` | 인벤토리의 장신구 두 칸 / 보유 목록·재지급·연계 관리 |
| `/mythaccessory link proto_cbt:short_dodge` | 매듭 감소 대상 지정 |
| `/mythprototype status` | 마나·범위·표적 체력 |
| `/mythprototype targets` | 살아 있는 표적 체력만 회복 |
| `/mythprototype attack melee` | 40틱 뒤 실제 근접 피해 4 예약 |
| `/mythprototype attack projectile 40` | 회피 가능한 투사체 피해 시험 |
| `/mythprototype attack area 40` | 회피 가능·패링 불가 범위 피해 시험 |
| `/mythprototype attack mechanic 40` | 패링·회피 모두 불가 피해 시험 |
| `/mythprototype attack unclassified 40` | 허용 목록에 없는 피해 시험 |
| `/mythprototype join 개설자이름` | 같은 영역의 시험장 참가, 총 5명까지 |
| `/mythprototype end` | 개설자는 전체 종료, 참가자는 본인만 이탈 |
| `/mythprototype grant proto_cbt:wave_blade` | 특정 시제품 지급·분실 복구 |

예약 공격은 가장 가까운 등록 표적의 위치에서 실제 `hurt`로 판정한다. 패링은 해당 표적을 바라보고 4칸 이내에서 시험한다. 예약 시각에 맞춰 패링·회피를 쓴다. 플레이어끼리 공격하는 명령이나 마나·쿨타임 초기화 명령은 추가하지 않았다.

검기는 승인 시 눈 위치·방향을 고정한다. 반경0.25·틱당1칸·최대10칸/발사 후10틱 이동하며 서로 다른 적 최대3개에 8/4/4 물리 피해를 준다. 벽·유리·문·울타리·반블록 형태로 차단하며 블록을 파괴하지 않는다. 1.0.37의 야생에서는 다른 플레이어·주민·중립 생물도 공격하며 자기/파티 소유 동물과 파티원은 통과한다. 레이드/시험장에서는 등록 대상 제한을 유지한다. 무적·흡수로 체력이 줄지 않은 적도 관통 수를 소비하지만 적중 이벤트는 없다. 힘·날카로움·치명타·충전을 복제하거나 넉백을 추가하지 않는다. 기존 방어력·강인함·보호·저항·피격 무적을 따른다.

패링은 승인 수평 방향 전방 ±60도·현재 중심4칸·막히지 않은 시야의 명시 허용 직접 근접 공격 한 번만 취소한다. 반격·스턴·적중 이벤트는 없다. 대쉬는 수평 방향으로4틱 동안 총3칸 이동하며 몸체 연속 충돌·생물·발밑·영역·월드 경계·청크 로드를 검사한다. 지상 보행만 가능하고 첫 안전 이동0.25칸 미만은 무소모 거절한다. 승인 후 막히면 이동·회피를 종료하고 비용·후딜을 유지한다. 자동 계단 오르기나 낭떠러지 건너기는 없다.

공통 잠금 중 다른 스킬·평타·음식·방패를 막는다. 이동·시선·인벤토리 교체는 가능하다. 무기 선딜 도중 변형 교체·파손, 패링 중 교체는 취소한다. 같은 tick 교체 후 복귀로 부활하지 않는다. 발사된 검기는 교체 후 유지하되 사망·로그아웃·범위/도전 권한 이탈 시 제거된다. 승인 뒤 빗나감·중단은 비용·쿨타임을 되돌리지 않는다. 상자·문 직접 지정 또는 Shift는 기본 상호작용이 우선한다. 주민은1.0.37부터 스킬 무기 우클릭으로 공격하고 Shift+우클릭으로 거래한다.

매듭은 승인 당시 장착 권리·지정 스킬을 고정하고 검기의 실제 체력 적중에 시전당 한 번만 발동한다. 회피가 쿨타임 중이면 한 개20틱, 두 개40틱 감소한다. 평타·패링·대쉬·장신구 쿨타임에는 적용하지 않는다.

## 실전 연결과 전투력

1.0.37부터 이번 세 행동도 일반 야생에서 사용할 수 있다. 레이드·등록 시험장에서는 기존 적/참가 권한 격리를 유지한다. 석상 시련의 휩쓸기는 패링·회피 허용, 환형 충격파는 회피 허용, 봉인 낙하·봉인 실패 폭발은 모두 불가다. 봉인·표식·페이즈·즉사·낙하·공허·익사·환경 피해를 우회하지 않는다. 다른 레이드의 대쉬는 안전 구역을 별도 작성하기 전까지 거절하며 새로운 공격의 방어 허용도 명시 작성이 필요하다.

기존 계산식과 획득 이력의 슬롯별 최고 장비 정책을 유지한다. H20/A1·가호/버프/기타 점수0·회피K15·장신구J24의 독립 계정에서 무기3종 모두 철 조합 **176.9089023**, 다이아 조합 **187**, 무기만 있으면 각각120이다. 두 세트 모두 받은 계정은 다이아 획득 이력이 남아 철을 입어도 역사 점수가 내려가지 않는다. 비교용 독립 계정별로 장비를 지급하거나 실제 피해·방어력을 별도 기록한다. 기존 가호·획득 이력은 초기화하지 않는다. 과거 이력이 불완전하면 기존처럼 전투력/무기 소유권을 확정하지 못할 수 있다.

## 수치 수정 위치

에이전트가 수치를 바꿀 때는 [밸런스 조정 안내](BALANCE_TUNING.md)부터 읽는다. `dev-tools/Get-CombatBalance.ps1`로 소스 현재값·편집 경로와 동기 수정 필드를 확인할 수 있다. 기본 마나·회복률은 `skills/ManaTuning.java`가 단일 원본이다.

`mythictrpg-main/src/main/resources` 기준이다.

| 내용 | 경로 |
|---|---|
| 검기 비용·쿨타임·피해·속도·거리·반경·관통·TTL·선후딜 | `data/proto_cbt/mythictrpg/weapon_skills/blade_wave.json` |
| 패링 비용·쿨타임·시간창·각도·거리 | 같은 폴더 `timed_parry.json` |
| 회피 비용·쿨타임·시간·거리·점수 | `data/proto_cbt/mythictrpg/learned_skills/short_dodge.json` |
| 마나석·매듭 | `data/proto_cbt/mythictrpg/accessories/clear_mana_stone.json`, `blade_knot.json` |
| 장비 정체성·실물 속성·고유 점수·연결 | `data/mythictrpg/mythictrpg/combat_power/default.json`의 `items` |

스킬·장신구·정책은 외부 데이터팩의 같은 ID를 `/reload`로 다시 읽는다. 소스 JSON/Java 편집은 재빌드·JAR 교체·재시작이 필요하다. OP 실물 카탈로그는 JAR의 컴포넌트를 한 번 읽으므로 외부 정책 컴포넌트만 덮어써도 지급 실물이 바뀌지는 않는다. 장비 속성·이름 등 컴포넌트 변경은 기존 실물/영수증과 정체성이 달라지므로 새 시제품 연결이나 별도 이관을 설계한다. 선딜 최소1틱이다.
