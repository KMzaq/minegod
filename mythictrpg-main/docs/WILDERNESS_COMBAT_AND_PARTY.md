# 야생 전투와 파티

2026-10-22 게임 **1.0.37** 후속. 사용자의 변경 요청에 따라 기존 시험 범위를 확대했다. 검기·패링·대쉬의 피해량·마나·쿨타임은 변경하지 않았다. [시제품 지급·사용 안내](FIRST_COMBAT_PROTOTYPE.md), [수치 조정 위치](BALANCE_TUNING.md).

## 야생 사용

습득·소유한 무기 스킬과 짧은 회피는 일반 야생에서도 사용한다. 시험장 등록은 필요 없다. 기존처럼 주 손 지정 무기 우클릭, 선택 습득 스킬은 기본 `J` 또는 `/mythskills use`다. 시험장은 수치 비교를 위한 선택 기능으로 유지한다.

다른 플레이어·주민·중립 생물·타인의 동물을 공격할 수 있다. 본인과 **현재 같은 FTB 파티의 플레이어 및 그 파티원이 소유한 길들인 동물**은 보호한다. 늑대·고양이·말 등 실제 게임의 소유 UUID를 확인하며 이름이나 목줄 표시로 판단하지 않는다. 오프라인 소유자도 같은 기준을 적용한다. 소유자 없는 동물은 일반 대상이다. 서버 `pvp=false`, vanilla 팀의 아군 공격 금지, 다른 모드의 피해 취소·NPC 무적 설정은 우회하지 않는다.

보호는 평타·검 휩쓸기·화살·일반 공격 스킬·지속 피해에 공통 적용한다. 보호 대상은 스킬 적중이나 매듭 발동 횟수로 세지 않는다. 검기/지속 공격 도중 파티가 바뀌면 다음 실제 피해 시점의 현재 파티로 재검사한다. 파티 조회 저장소가 아직 준비되지 않았거나 조회가 실패하면 해당 플레이어 사이 피해를 허용하지 않는다. 환경 피해·낙하·익사에 대한 무적은 주지 않고, 이로운 포션은 유지한다.

스킬 무기를 들고 **주민을 직접 조준해 우클릭하면 스킬**을 사용한다. 거래하려면 **Shift+우클릭**한다. 상자·문 직접 조준 시 기본 블록 상호작용 우선은 유지한다. 일부 신/NPC의 자체 상호작용·무적 규칙은 해당 정의를 따른다.

야생 패링은 전방·거리·시야·시간창을 충족하는 플레이어/몹의 직접 근접 공격에 적용한다. 회피는 명시된 vanilla 투사체와 검기에 적용한다. 모든 환경·지속 피해·미분류 공격을 통째로 지우지는 않는다. 원래 선후딜·무기 교체·충돌·낭떠러지·월드 경계·청크 로드 검사는 유지한다.

## 일반 파티 명령

기존 FTB Teams가 파티 원본이다. 별도 파티 저장소를 만들지 않았으며 기존 `/ftbteams` 명령/화면으로 만든 파티도 동일하게 보호한다. 야생에서 OP 없이 사용할 수 있다. 서버의 FTB 명령 권한 설정은 따른다.

파티장:

```text
/mythparty create 모험 파티
/mythparty invite 친구이름
```

초대받은 친구:

```text
/mythparty join 파티장이름
```

`join`에는 초대받은 파티의 기존 구성원 이름을 지정할 수도 있다. 초대만 받았거나 FTB의 ALLY 관계인 상태는 실제 파티 가입이 아니다. 같은 파티의 구성원이 된 뒤 보호된다.

| 명령 | 용도·권한 |
|---|---|
| `/mythparty`, `/mythparty list` | 현재 파티·역할·접속 여부 |
| `/mythparty invite <플레이어>` | 파티장/관리자가 초대 |
| `/mythparty join <파티원>` | 본인이 받은 초대를 수락 |
| `/mythparty leave` | 본인 탈퇴 |
| `/mythparty kick <플레이어>` | 파티장/관리자가 권한 범위 내 추방 |
| `/mythparty transfer <플레이어>` | 파티장만 다른 구성원에게 소유권 이전 |
| `/mythparty disband` | 파티장만 해산 |

다른 구성원이 남아 있는 파티장은 먼저 파티장을 넘기거나 해산한다. 파티 정원·저장·재접속은 기존 FTB Teams를 따른다. 같은 FTB 팀이므로 기존 FTB Quests/Story의 팀 공유 동작도 그대로 이어진다. 이번 변경이 별도의 보상 분배 원장을 만들거나 완료 보상을 다시 지급하지 않는다.

## 레이드와 시험장 경계

이미 레이드가 시작되었거나 입장/정리 중이면 야생 규칙으로 권한을 바꾸지 않는다. 레이드 참가 명단·초대 집합·적 목록은 기존 시도에 고정되며 파티 탈퇴/변경으로 팀킬이나 외부 개입을 허용하지 않는다. 외부에서 야생 검기를 쏴 전장·등록 적을 침범하는 경로도 막는다. 레이드의 봉인·표식·위치 기믹·허용 공격 목록, 인물 특수지원의 레이드 전용 규칙은 유지한다.

시험장은 등록 표적/참가 권한으로 분리된다. `/mythprototype end`는 시험 권한만 종료하며, 종료 뒤에는 일반 야생 스킬을 다시 사용할 수 있다. 시험장 참가 명령과 일반 파티 가입은 서로 다른 기능이다.

## 구현 위치와 검증

- `party/PartyService.java`, `PartyCommands.java`: 실제 FTB 조회·동의·역할 검증과 명령.
- `combat/CombatTargeting.java`: 대상 선택과 실제 피해/투사체/포션의 공통 보호.
- `mixin/CombatPartySweepMixin.java`: vanilla 검 휩쓸기의 피해 전 넉백에서 보호 대상을 제외.
- `prototype/PrototypeCombatAccess.java`: 야생·시험장·레이드 구역과 방어 가능한 공격의 분류.
- `skills/SkillExecutor.java`, `CombatCastRuntime.java`: 실제 피해 시 재검사와 기존 결제·시전 생명주기.

검증·JAR·배포 여부는 [이번 작업 기록](../../인수인계/브랜치실험/behaivior/WILDERNESS_PARTY_20261022.md)을 따른다. 실제 클라이언트에서 새 파일을 사용하려면 Minecraft를 정상 종료하고 기존 게임 JAR을 **1.0.37 하나로 교체**한 뒤 재실행한다. 멀티플레이 서버도 같은 새 게임 JAR이 필요하다.
