# 가호 전투력 — 보유 기준과 효과별 점수

2026-10-02 / HanesTest 개발본. 이 문서의 기본 점수는 사용자가 작성을 승인한 **조절 가능한 초안**이며 완성된 서버 밸런스나 실전 측정값이 아니다. 지급 JSON·우유·부활·재적용 명령은 [영구가호 가이드](PERMANENT_BLESSINGS.md)를 따른다.

## 무엇을 계산하는가

- 게임의 영구 가호 **보유 기록**을 읽는다. 우유로 지웠거나 사망 직후 효과가 없어도 해당 가호의 전투력은 낮아지지 않는다.
- 같은 효과의 가호를 여러 신에게 받으면 보유 기록의 출처는 유지하지만, 점수 입력은 효과별 최고 단계 하나다. 같은 효과를 여러 번 받아 단계가 더해지지 않는다.
- 전체 전투력에서는 보유 가호와 현재 효과를 합쳐 효과별 최고 단계만 계산한다. 강한 임시 포션은 그 단계로 한 번만 반영하고, 포션이 끝나면 보유 단계로 돌아간다. 소유하지 않은 일시 효과는 기존처럼 현재 활성 상태를 따른다.
- 효과가 내부적으로 만든 attribute modifier는 기존 전투력 공급자가 제외하므로 가호 점수와 영구 능력치 점수에 두 번 넣지 않는다.
- `/mythpower`의 **영구 가호 전투력**은 보유 가호 항만 보여준다. 장비 이력이나 세계 권장치가 없어서 전체 전투력이 `UNAVAILABLE`이어도 이 항은 독립적으로 조회할 수 있다. 이 숫자를 전체 전투력·신과 인간의 서열로 대신 사용하지 않는다.

## 점수 파일

기본 리소스는 `data/mythictrpg/mythictrpg/blessing_power/default.json`이다. 데이터팩에서 **동일 경로**를 덮어쓰고 `/reload`하면 JAR 재빌드 없이 변경할 수 있다. 다른 이름의 두 번째 정책 파일을 추가하면 모호한 적용을 방지하기 위해 계산을 거절한다.

```json
{
  "schemaVersion": 1,
  "effects": [
    {"effectId": "minecraft:strength", "scores": [12, 26, 42, 60, 80]},
    {"effectId": "minecraft:night_vision", "scores": [0, 0, 0, 0, 0]}
  ]
}
```

`scores[0]`은 I단계(amplifier 0), `scores[1]`은 II단계다. 비음수·유한·단계가 높아져도 감소하지 않는 수를 작성한다. 0점은 명시적으로 전투력에 넣지 않는다는 뜻이다. 미등록 점수/단계는 0으로 추측하지 않고 계산 불가를 반환한다. 예시 두 행만 복사하면 다른 효과의 점수가 사라지므로 실제 수정은 전체 기본 파일을 복사한 뒤 한다. 점수 정의는 가호 지급 권한이나 효과를 생성하지 않는다.

| 효과 | I / II / III / IV / V 초안 |
|---|---|
| 힘 | 12 / 26 / 42 / 60 / 80 |
| 저항 | 14 / 34 / 66 / 130 / 250 |
| 신속 | 5 / 11 / 18 / 26 / 35 |
| 재생 | 10 / 22 / 38 / 60 / 90 |
| 생명력 강화 | 8 / 16 / 24 / 32 / 40 |
| 흡수 | 6 / 12 / 18 / 24 / 30 |
| 화염 저항 | 모든 단계 8 |
| 투명화 | 모든 단계 4 |
| 점프 강화·성급함 | 1 / 2 / 3 / 4 / 5 |
| 느린 낙하 | 모든 단계 2 |
| 수중 호흡·돌고래의 우아함 | 모든 단계 1 |
| 전달체의 힘 | 모든 단계 3 |
| 야간 투시·행운·마을의 영웅 | 모든 단계 0 |

직접 전투 기여도가 높은 효과를 더 높게, 저항·재생 같은 강한 고단계 효과는 비선형으로 평가한 출발점이다. 특정 보스·수중전·맵에서는 효용이 달라질 수 있다. 점수에 V단계가 있다고 그 가호를 플레이어에게 실제 지급하도록 설정한 것은 아니다. 즉시 치유 같은 즉시형 효과는 영구 가호로 사용하지 않는다.

## 기존 전체 전투력 정책과의 관계

기존 `combat_power` 정책의 `effects`에 명시한 **동일 효과+단계 점수**가 우선한다. 이 표는 누락한 효과 점수의 기본값을 제공한다. 기존 `effectCoefficient`는 전체 계산 때만 곱하며 `/mythpower`의 가호 항은 곱하기 전 점수다.

장비 점수·세계 권장 전투력·진행 구간·획득 이력은 새로 추측하지 않았다. 따라서 이 작업만으로 모든 플레이어의 전체 전투력/캐치업이 활성화되는 것은 아니다. [기존 공급자 계약](../../인수인계/브랜치실험/HanesTest/COMBAT_POWER.md)의 이력·저장·권한 보호는 유지한다. 가호 보유 저장소 손상도 빈 목록/0점으로 숨기지 않는다.

일반 효과와 겹친 영구 가호, 우유 제거, 중복 지급, 사망·저장 복원과 점수 변경은 함께 검증해야 한다. 재적용 명령은 점수를 올리는 기능이 아니라 이미 보유한 효과를 되거는 기능이다.
