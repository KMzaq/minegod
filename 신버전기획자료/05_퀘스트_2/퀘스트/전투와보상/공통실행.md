## common contract
- 단위·사용범위: 체력 2=하트 1, 거리=블록, 20tick=20TPS에서 1초. 일반 무기/습득 스킬은 필드 및 허용 전투에서 사용 가능하며 레이드 전용 아님. 서버 보호 구역·PvP 정책 유지. 이번 공격은 PvP·아군·주민·중립/길들인 동물 제외, 적대 전투 대상만. 일반 사냥/좌클릭은 기존 정책. 시험 배포 범위를 정식 사용 제한으로 승격하지 않는다.
- 조작: 무기 주 손 우클릭 1회=연결 기술 1개. Shift+우클릭 및 직접 지정한 상자·문·NPC 상호작용 우선, 이 입력에서 기술 무소모. 무기 기술과 보조 손 사용 동시 소비 금지. 습득 기술은 K 목록에서 1개 선택 후 J 또는 /mythskills use. 시전 승인 순서가 빠른 하나만 동시 입력을 차지한다.
- 마나·쿨타임: 기본 최대 마나 200, 장착 장신구 증가분 합산 후 현재 최대치의 초당 1% 회복. 살아서 접속 중, 회복 대기 없음. 장신구는 자유 2칸, 교체로 현재 마나를 채우지 않고 상한 감소 시 clamp. 일반 쿨타임은 서버 가동 tick, 재접속·부활·교체·재지급으로 초기화하지 않음. 같은 스킬 ID의 무기 복사본도 쿨타임 공유.
- 선후딜·실패: t=0 서버 승인. 구간은 [시작,끝), 끝 tick부터 다음 입력 가능. 승인 시 마나 차감+쿨타임 시작. 권리 없음·죽음·관전·기절·공통 잠금·마나 부족·쿨타임·금지 구역은 승인 전 무소모. 승인 뒤 헛침·취소·벽·목표 무적은 비용 유지. 후딜까지 다른 스킬·좌클릭·음식·방패 사용 잠금, 이동/회전은 개별값. 사망/기절/로그아웃은 남은 효과 취소하되 비용·쿨타임 보존. 공통 잠금 자체는 추가 구현 요구다.
- 교체: 무기 기술 도중 주 손 등록 변형 변경·파괴는 미발사/미발동 효과 취소; 이미 발사된 투사체는 최초 스냅샷으로 계속. 취소해도 후딜 남음. 습득 기술은 별도 조건이 없는 한 무기 교체로 취소 안 함. 장신구와 연계 대상은 시전 시작 스냅샷. 뒤늦은 착용으로 이득을 추가하지 않음.
- 피해·적중: 피해 수치는 원시 입력값이다. 개별 콘텐츠와 아래 적용 범위별 계약이 피해 유형 및 처리 경로를 결정한다. wave1의 물리 스킬 규칙을 wave2 마법피해나 확장 평타에 덮어쓰지 않는다. 방어·무적·장벽·페이즈·기믹·아군 보호는 해당 경로의 원문대로 유지한다. 체력 피해>0인 적중만 해당 연계에 유효하며, 다부위 보스는 같은 전투 대상 ID당 시전1회다. 실제 damage type·처리순서는 구현 후 시험해야 하며 검증 완료를 주장하지 않는다.
- 장신구연계: 공격 시전 전체에서 성공한 연계 감소 1회; 다중 표적/다단으로 반복하지 않는다. 재정비 환급은 시전 종료까지 유효 적중 0일 때만 기존 합산율(최대 지불 마나100%) 적용, 쿨타임 환급 없음. 순수 방어·이동·버프에는 공격 적중/빗나감 이벤트를 발행하지 않는다.
- 보스·기믹: 강제 처형·공허·낙하·익사·질식·환경 용암/화염·낙인·위치/인원 검사·방 파괴는 방어/이동/CC로 해제하지 않음. 미분류 공격은 패링 불가. 일반 CC와 강제 이동은 명시 분류. 이동 중 기믹 접촉/발판 검사는 계속. 지형 파괴·통과·무적 우회·전투 밖 봉인 해제 없음.
- 지급·중복: 실제 개인 수행·제공 의사·등록·수용 조건을 확인하고 권리와 실지급을 분리한다. 같은 성과 중복 지급0. 지급 실패는 미수령을 보존하고 영수증/실물 대조 후 누락만 복구한다. 디오니소스 신규 획득1회 및 같은 영구 UUID의 기존 소유자 복구만 허용한다. 추가 권리·MAIN·주시·가호·동일 권리 두칸 장착·음악/점수 중복은 없다.
- 지원상태: 기존 참고 소스에는 item+components 지급, 전투력 items, rightClickSkill, learn_skill, 마나/쿨타임, 장신구 2칸 기반이 설명되어 있다. 실제 콘텐츠 등록·배포는 없음. 이동 투사체/방향 패링/충돌 대시/사용자 정의 버프/세부 입력잠금/정밀 적중 원자성은 자체 확장 요구. 외부 모드명·호환성 확인이나 지원 주장은 하지 않는다.
- 전투력: 장비 고유 E·무기 기여 W·무기스킬 K·습득스킬 고유점수는 아래 독립 제안값. 실제 공격 속성·실제 피해와 점수를 혼동하지 않음. 장비7등급은 문서 등급이며 기존 파서에 새 grade 필드 투입 금지. 고유점수로 운영 입장컷이나 균형 검증을 주장하지 않음.
- blacksmith direct craft rule: 기존 누적 자격표는 일반 원칙으로 유지한다. 다만 대장장이 태그 인물의 직접 제작 장비는 전투등급에 따른 장비 종류 제한의 예외이며, 제작 전문성·소재·과정과 개별 제공 조건을 검증한다. 가호·독립 습득 스킬·NPC 지원 자격은 예외 대상이 아니다.
- human eligibility: 기존 누적 자격은 일반 원칙이고 실지급 약속이 아니다. 무라마사는 하급을 유지하되 대장장이 태그 예외로 직접 제작한 무기를 보상으로 제공할 수 있다. 기존의 무기 직접 지급·완성 무기 제작 보상 전면 금지는 이 범위에서 철회한다. 대리 지급 우회·기존 서비스 자동 변경은 허용하지 않는다. 허준의 최하급 및 습득 회복 스킬·회복 버프·부활 지급 없음, 인간에게 가호 자동 생성 없음은 유지한다.
- tool classification: 헤파이스토스 최상급, 관우 상급, 토르 최상급 유지. 일반 제작 도구를 보상 등급표만으로 금지하지 않는다. 전용 전투 성능·전투 스킬을 붙인 도구는 무기로 분류한다. 무기 제공은 일반적으로 중급 이상 자격을 검사하되, 대장장이 태그 인물의 허용된 직접 제작 장비는 전투등급별 장비 종류 제한의 예외로 검사한다. 도구를 들고 일반 공격하는 바닐라 성격 자체는 전용 무기 기획이 아니다. 하급 무라마사도 별도 직접 제작 무기 제공은 가능하지만 기존 손질 서비스를 새 전투 무기 증여로 자동 바꾸지 않는다.
- rights count rule: 같은 콘텐츠 ID의 수치·내구·복구 정정은 신규 콘텐츠나 신규 최초권리가 아니다. 무기와 내장기술은 한 콘텐츠로 센다.

## execution scope priority
- 현행 전역기준의 확정 공통원칙과 명시된 기존 예외를 유지한다. 전역 신규보상 예산표로 기존 개별 수치를 소급 변경하지 않는다.
- 각 행위의 content_id와 행위 종류를 먼저 고른다. 개별 콘텐츠·획득 챕터의 명시값이 해당 항목에서 우선하며, 아래 범위별 계약이 생략된 공통 실행 의미를 보완한다.
- 확장 좌클릭은 EXPANDED_NORMAL_ATTACK, wave1 공격 기술은 WAVE1_PHYSICAL_SKILL, wave2 공격은 WAVE2_MAGIC_AND_STATE를 따른다. 한 무기의 좌클릭과 우클릭은 서로 다른 경로일 수 있다.
- 서로 다른 범위의 물리/마법 태그, 스턴 family, 환급, 상태정리를 자동 합치거나 다른 콘텐츠에 확장하지 않는다. 무보상·서비스·BGM에는 공격 경로를 적용하지 않는다.
- 아래 값은 채택된 저술 실행계약이다. 엔진 태그·본체 이동·지형보호 연동 및 교차조합의 실제 지원 여부는 구현시험 대상이며, 이를 수치/권리 미정으로 되돌리는 근거로 쓰지 않는다.

#### contract
- 단위와대상: 거리=블록, 20tick=1초, 체력2=하트1. 일반 기술은 허용 필드·레이드에서 사용. 이번 공격은 적대 전투 대상만, PvP·아군·주민·중립·길들인 개체 제외. 일반 좌클릭은 기존 보호정책. 피해값은 기존 마법피해 경로에 넘길 원시값이며 힘·날카로움·무기 공격력으로 재증폭하지 않는다. 기존 마법피해 경로를 재사용하되 실제 구현 코드·damage type 태그는 이번에 확보하지 않았다. 갑옷/강인함 우회 여부, 보호 인챈트·저항 적용, 무적·장신구 고정 피해 보정 순서는 태그별 승인 시험 전 미확정이다. 현재 적용 완료나 갑옷 관통을 약속하지 않으며, 같은 피해경로의 보스/일반 적 시험을 통과하기 전 활성화하지 않는다.
- 조작: 무기 주 손 우클릭. Shift+우클릭과 상자·문·NPC 직접 상호작용 우선, 기술 무소모. 보조 손 중복 사용 금지. 습득 스킬 K에서 선택하고 J로 사용. 특수스킬은 별도 특수스킬 선택/사용 UI 연결 필요, K/J 일반 습득형으로 오등록하지 않는다. 선후딜 중 일반 공격·다른 기술 시전 금지, 이동·시점은 개별 제한만 적용. 동시에 온 입력은 서버 승인 순서 첫 하나만.
- 마나: 기본200 + 착용 장신구 최대마나 합계. 살아서 접속 중 현재 최대치의 초당1% 회복, 사용 뒤 대기 없음. 상한 증가로 현재량 충전 금지, 감소 때 새 상한으로 clamp. 이번 변신은 최대마나·회복률을 바꾸지 않는다.
