# 포라스 — 같은 얼룩 다른 원인

관리키 RPG-S14-080 · 정의 EP036A-RPG-S14-080 · 중급 · SIDE / 신규 MAIN 없음

외운 정답을 잘하는 제자보다 자기 가설을 버리고 다시 만지는 제자를 좋아하는 논리의 교사다. 짧게 묻고 오래 기다린다. ‘왜냐하면 선생이 그랬다’는 답에는 못마땅한 웃음을 흘린다.

## 현재 요청
같은 증상에 다른 이유가 있을 수 있다는 점을 처방 비교에서 드러내고 싶다.

## 실제 수행
1. 본인 소유 손상 재료 2개와 각 재료에서 나온 시험 조각 1개씩을 기존 작업면에 놓고 첫 원인 가설을 말한다. 표본 A에는 젖음, B에는 마찰을 한 조건씩 실제 적용한다. 물병 1개의 물을 허락된 휴대 용기에 소량 쓰되 네더 바닥에 물을 설치하지 않는다.
2. 젖음 조각 A는 10초 노출, 마찰 조각 B는 돌 표면에 접촉 3회로 관측한다. 조각 2개는 시험에 소비/변형된 실물로 추적하고 같은 조각을 새 시료로 반복 차감하지 않는다. 반례가 실제 있으면 첫 가설을 고치고, 혼합 조건·반례 없음은 미확인으로 남긴다.
3. 확인된 손상 재료에만 건조 보관 또는 마찰면 분리 중 맞는 보존법을 적용해 전후를 비교한다. 다른 증상에 적용하지 않았음을 밝힌다. 부에르의 실제 응답이 없으면 의학적 원인·처방을 대신 말하지 않는다.

## 완료와 갈림길
실제 두 조건 시험·반례·가설 정정·확인 재료 보존 적용·범위 설명 AND 포라스 판정. 관측 데이터가 가설과 모순되지 않으면 억지 반례로 성공시키지 않는다.

- 시험 거절은 자기 재료 회수·추측 종료, 연구품/지도권 없음.
- 같은 답을 검증 밖 증상에 판매하면 실제 받은 청중과 피해·정정 미수신 보존, 성공권 없음.
- 기존 유효 시험이 있으면 새 조각 소비 없이 현재 적용/보고부터 이어감.

## 보상과 선택 수령
원인 분류 지도 1회와 허용 표본 교환 1회는 별도 선택. 지도 90초 비교·반례 설명/피드백. 교환은 포라스 보유 평범한 비교 조각 1개 ↔ 플레이어의 허락된 미소비 비교 조각 1개, 양측 품목·정수량 수락 및 인수 후 소유 변경. 마법 효과 0·추가 비용 0; 2조각 등 실제 허용 정수량 변경은 version으로 보존한다.

정상 사건별 실제 수행자 최초1회. 같은 사건 재개는 미수령/미지도 잔여만. 새 사건을 자동 발생시키지 않는다.

## 중단·재개·지식
공통실행계약의 체크포인트, 원물 장부, 영수증 대조, 실제 청중 규칙을 적용한다. 미수신을 수신으로 만들지 않고 완료한 행동을 재연하지 않는다.
포라스는 틀린 가설을 버린 상대에게 비교 연구품을 내놓을 수 있으나 모든 병의 원인을 안다고 말하지 않는다. 확인 범위를 넘어 같은 답을 팔면 비교 연구품 제공을 멈추고 잘못 처방한 대상의 피해를 별도로 남긴다.

## 구현과 예상
습윤/마찰/얼룩 관측은 해당 퀘스트 소품 상태의 구현 요구. vanilla 물리나 치료 효과로 지원된다고 주장하지 않는다. 물병 용기는 원물 회수, 사용한 물만 실제 소비. 실패 시험도 변형 조각·물 소비를 보존한다.
예상 7~12분. 실제 API·게임·LLM 시험은 하지 않은 기획값이다. 지도는 비전투 경험이며 전투 능력 보상이 아니다.
