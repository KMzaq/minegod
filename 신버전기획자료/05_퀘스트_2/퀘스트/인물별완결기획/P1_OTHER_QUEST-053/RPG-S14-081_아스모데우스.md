# 아스모데우스 — 값을 매기지 않은 마지막 수

관리키 RPG-S14-081 · 정의 EP035B-RPG-S14-081 · 최상급 · SIDE / 신규 MAIN 없음

나누어떨어지지 않는 몫과 그만둘 때의 값을 오래 들여다본다. 느긋한 조롱 사이 정확한 요구를 넣으며 계산 밖 선택에는 불쾌함과 호기심을 함께 드러낸다.

## 현재 요청
자기 구속의 재심에서 실제 발언 기회와 독립 통행의 요구를 따로 주장하고 싶다.

## 실제 수행
1. 현재 허용 제한 접견에서 각자가 실제 가진 평범한 돌 3개씩만 준비한다. 기존 평지 3×3칸에 서로 다른 표시를 두되 인물/통행/봉인/남의 자유를 판돈으로 받지 않는다. 돌 소유는 끝까지 원주인에게 남는다.
2. 합의된 작은 수 싸움은 교대로 빈칸에 자기 돌 1개씩 놓아 먼저 가로/세로/대각 3개를 이으면 승리. 각자 3개가 놓인 뒤에는 자기 돌 1개를 인접 빈칸으로 옮긴다. 반복 판면 3회는 무승부, 그 전에 언제든 그만둘 수 있다. 현재 가능한 합법 수만 실행한다.
3. 마지막 이득을 포기하고 종료 OR 합의한 승패/무승부까지 진행 후 자기 돌을 실제 회수한다. 가격으로 설명되지 않는 자기 선택을 짧게 직접 말하고 떠난다. 실제 아스모데우스 패배가 있었을 때만 패배 조롱 분기 전제가 생긴다.

## 완료와 갈림길
수 싸움의 실제 행동·합의한 종료·자기 돌 회수·자기 선택 설명을 아스모데우스가 수신. 이득 포기 OR 게임 종료이며 둘 다 강제하지 않는다. 시작 전 거절은 정상 교류 완료로 대체하지 않는다.

- 남의 자유 담보 제안은 거절·승부 중지, 담보 계약 생성0.
- 실제 패배를 굴복이라 조롱하면 재승부 거절, 호기심 종료로 처리하지 않음.
- C16/C17/C21은 이미 존재하고 열람 허락된 결과만 참조. C21 완료 새 선행0·옛 재심 재체결0.

## 말과 반응
- “아깝지 않나? 다음 한 수면 네가 이길 수도 있는데.”
- 설명을 실제 들은 뒤: “값이 없다는 말인가. 마음에 들지는 않아. 한 번 더 생각하게는 하는군.”

## 보상과 선택 수령
보상 0, 돌은 사용 후 원주인 회수이며 도박 재산 이전 없음. C16/C21 신규 개인 실물권 없음, C17 선택 보급 식량8·화살16의 별도 원문 권리·조건은 여기서 생성/소비하지 않는다.

정상 사건별 실제 수행자 최초1회. 같은 사건 재개는 미수령/미지도 잔여만. 새 사건을 자동 발생시키지 않는다.

## 중단·재개·지식
공통실행계약의 체크포인트, 원물 장부, 영수증 대조, 실제 청중 규칙을 적용한다. 미수신을 수신으로 만들지 않고 완료한 행동을 재연하지 않는다.
아스모데우스는 값으로 잡히지 않는 선택에 불쾌함과 호기심을 함께 남긴다. 이는 새로운 개인 교류이며 옛 재심 당사자·해방·사라나 라파엘의 동의를 만들지 않는다. 패배를 굴복이라 조롱하면 그는 돌을 거두고 다음 승부를 거절한다. 자기 선택을 설명한 경우에만 호기심을 남긴 접견으로 끝난다.
