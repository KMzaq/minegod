# 스톨라스 — 삐뚤어진 관측선

관리키 RPG-S14-084 · 정의 EP036A-RPG-S14-084 · 하급 · SIDE / 신규 MAIN 없음

장엄한 별 이야기보다 어제와 조금 어긋난 점 하나에 기뻐하는 관측자다. 평소에는 작게 중얼거리다 작은 차이를 발견하면 갑자기 말이 빨라진다.

## 현재 요청
반복 관측에서 생긴 작은 차이를 그림의 실수로 덮지 않고 남기고 싶다.

## 실제 수행
1. 같은 기존 안전점 A에서 6~12블록 떨어진 동일 균사/빛 표본 1곳을 3회 관찰한다. 기본 활동 간격 20초, 실제 가림/변화/안전 때문에 간격을 바꿨으면 실제 시각을 적는다. 오프라인 시간은 관측 회차로 세지 않는다.
2. 각 회차에 보인 선·빛과 가림 구간을 실제 기록한다. 소음으로 설명을 못 들은 것은 관측 불가와 따로 미수신 표시. 보이지 않은 지상 별·밤하늘을 끌어오지 않는다.
3. A에서 4~8블록 떨어진 기존 안전점 B로 이동해 같은 표본 1곳을 다시 2회 관찰하고 첫 그림과 나란히 비교한다. 가림이 남아도 실제 실패 기록을 보존하면 비교가 가능하며 전부 선명해야 한다는 조건은 없다.

## 완료와 갈림길
A 실제 반복 관찰·B 실제 이동/재관찰·실패 포함 비교 AND 스톨라스 확인. 안전점 B 접근 불가면 A 기록만 부분결말, 지도권 없음.

- 예쁜 도형에 맞춘 미관측 값은 위조, 성공권 없음.
- 가림/소음은 실패 데이터이지 자동 실패 종료가 아니다.
- 중단 뒤 유효 3+2회 중 남은 회차만 수행, 전부 다시 그릴 의무 없음.

## 말과 반응
- “여기! 선이 달라졌어. 아니, 지우지 마. 못 본 자리가 더 흥미롭잖아.”
- “별은 여기서 안 보이지. 그러니 이 빛을 보자는 거야.”

## 보상과 선택 수령
관측 도표 지도 1회와 허락 비교 사본 1장 별도 선택. 지도는 60초 동안 관측선/빈선을 직접 구분해 피드백 받음. 스톨라스 소유 실제 종이1장·복제 허락을 확인해 사본 인수, 지도 수강이 사본 수령을 대신하지 않는다. 미래/길흉 능력0.

정상 사건별 실제 수행자 최초1회. 같은 사건 재개는 미수령/미지도 잔여만. 새 사건을 자동 발생시키지 않는다.

## 중단·재개·지식
공통실행계약의 체크포인트, 원물 장부, 영수증 대조, 실제 청중 규칙을 적용한다. 미수신을 수신으로 만들지 않고 완료한 행동을 재연하지 않는다.
스톨라스는 실패 기록이 있는 상대에게 다음 비교 그림을 맡긴다. 미래 길흉이나 숨은 정답의 자동 습득은 없다.

## 구현과 예상
공통 권위 동작·소품·원물·응답 저장 연결. 새 전투 시스템 없음.
예상 4~8분. 실제 API·게임·LLM 시험은 하지 않은 기획값이다. 지도는 비전투 경험이며 전투 능력 보상이 아니다.
