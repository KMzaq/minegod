# 사브나크 — 나가는 틈을 지키다

관리키 RPG-S14-089 · 정의 EP036A-RPG-S14-089 · 상급 · SIDE / 신규 MAIN 없음

견고한 벽을 세우는 실력에 자부심이 커서 출구 이야기를 허점 찾기로 받아들이는 방어의 장인이다. 단호하고 방어적인 말투다. 출구를 설명할 때는 못마땅해도 손으로 실제 통로를 따라가 본다.

## 현재 요청
자신의 방어안이 채택될 가치를 인정받으면서 출구를 남긴 성벽도 견고할 수 있음을 자기 방식으로 증명하고 싶다.

## 실제 수행
1. 기존 임시 방어물의 출구 폭2·높이2와 바깥 12블록 피난 길을 직접 걸어 확인한다. 협력 동료1명·떠날 참가자1명의 현재 동의를 확인하고 출구 옆 3블록 측면에 엄호 위치를 잡는다. 같은 사람이 두 역할을 맡으면 실제 순간별 역할만 기록한다.
2. 현재 실제 적대 몬스터가 접근할 때 출구를 막지 않고 기존 공격/방어로 엄호한다. 떠나려는 참가자가 실제 출구를 지나 안전점에 도달해야 이탈을 확인한다. 몬스터가 없으면 방어 준비만 남기며 소환으로 성과를 채우지 않는다.
3. 실제 공격이 끝난 뒤 이번 허락된 임시 장애물 최대2개를 제거·회수하고 통로를 다시 왕복 확인한다. 머물지 않겠다는 참가자의 답을 듣고 자유 이탈을 실제 허용한다. 출구가 처음부터 열려 있고 장애물이 없으면 제거 목표0, 허위 파괴를 만들지 않는다.

## 완료와 갈림길
출구 유지한 실제 방어·실제 참가자 이탈 AND 공격 종료·허용 장애물 정리·자유 출입. 무위협 준비/단순 철수는 정상 지도권 아님.

- 준비 부족이면 열린 출구로 안전 철수, 미수행 방어 유지.
- 출구까지 막아 고립시키면 평가중지·현재 장애물 제거 복구, 가둔 채 생존은 성공 아님.
- 공격 뒤 붙잡으면 새 억류·정상 지도0. 지난 방어 공적 자체는 소급 삭제하지 않는다.

## 말과 반응

## 보상과 선택 수령
출구를 살리는 방어 배치 지도1회. 안전한 현장에서 출구/엄호/피난점 3곳을 잡고 90초 내외 피드백. 새 성채·상설군·자동 NPC 지원0.

정상 사건별 실제 수행자 최초1회. 같은 사건 재개는 미수령/미지도 잔여만. 새 사건을 자동 발생시키지 않는다.

사브나크는 출구를 남긴 방어가 버틴 근거를 얻거나 실패한 부분을 다시 설계한다. 새 성채와 상설 주둔군은 없다. 떠나려는 사람을 가두면 방어 평가를 중지하고 현재 막은 출구를 다시 여는 복구만 남긴다.
