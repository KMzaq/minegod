# 부네 — 묘비보다 먼저 필요한 것

관리키 RPG-S14-077 · 정의 EP035B-RPG-S14-077 · 중급 · SIDE / 신규 MAIN 없음

산 사람의 수고와 돌봄의 비용을 먼저 센다. 후원자의 존재감을 즐기며 값싼 한 끼의 든든함에도 관심을 두지만 애도라는 말로 일한 손을 공짜로 만들지 않는다.

## 현재 요청
장례와 묘역을 위한 비용이 실제 필요한 자리에 쓰이도록 자신의 후원 몫을 남기고 싶다.

## 실제 수행
1. 현재 접근 가능한 허락된 묘역의 경계 파손 2곳·운반 도구 부족을 확인한다. 네더 접촉만 가능하고 실제 묘역 접근/유족 허락이 없으면 기록 검토·준비 부분결말이며 묘역을 네더에 자동 생성하지 않는다.
2. 실제 제공된 공동 기금 에메랄드 최대 4개로 현재 합의 가능한 보유자에게 돌 4개·운반용 나무 삽 1개를 구입한다. 기본 거래 제안은 돌 4개에 2개, 삽 1개에 1개, 잔액 1개 보관. 현재 판매자의 실제 재고·수락 가격이 없으면 구매 미성립. 실제 거래 정수량/대체재는 기금 사용권자의 승인 안에서 다시 고정한다.
3. 허락된 경계 2곳에 돌 2개씩 총 4개를 배치하고 실제 공동 짐 1묶음을 8~16블록 운반한다. 삽은 소모품이 아니라 공동 도구로 반납하며 실제 내구만 기록한다. 남은 기금은 보관자에게 실제 반환/인수 OR 특정 다음 용도 승인을 받고 보관한다.

## 완료와 갈림길
실제 필요한 보호·운반 완료 AND 공동 기금·재고·잔액 정산. 장식만 산 경우 정직하게 보고해도 보호 미완료. 잔액 사용 승인≠소비.

- 장식이 실제 허용된 용도면 그 구입만 유효, 보호 완료/추가 후원권 없음.
- 상인/재고/유족 부재는 준비·구매·작업 해당 부분 보류.
- 이장·가족 동의 대행·잔액 은닉·완료 과장은 승인 범위 밖.

## 보상과 선택 수령
정상 쓰임을 본 부네가 별도 현재 승인할 때만 실제 보유 돌 최대 4개를 해당 돌봄의 다음 유지 작업 보관자에게 전달. 개인 보상/임금 아님, 자동 승인 0. 작업당 추가 후원 1회·합의량 한도. 제시됐으나 미승인인 것은 미수령권 아님.

정상 사건별 실제 수행자 최초1회. 같은 사건 재개는 미수령/미지도 잔여만. 새 사건을 자동 발생시키지 않는다.

## 중단·재개·지식
공통실행계약의 체크포인트, 원물 장부, 영수증 대조, 실제 청중 규칙을 적용한다. 미수신을 수신으로 만들지 않고 완료한 행동을 재연하지 않는다.
부네는 실제 쓰임을 보고 후원 여부를 판단한다. 유족 동의 없는 이장이나 전원 후원은 생기지 않는다.
