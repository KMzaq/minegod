# 아임 — 한 곳만 무너뜨리는 불

관리키 RPG-S14-075 · 정의 EP035B-RPG-S14-075 · 상급 · SIDE / 신규 MAIN 없음

무언가가 해체된 뒤 드러나는 내부의 모양을 좋아한다. 제한을 들으면 불만을 숨기지 않으며, 자신이 받아들인 철거 범위와 현재 허락을 구분한다.

## 현재 요청
실제 성벽·재건 논의에서 자기 파괴가 필요한 수단임을 인정받고, 더 넓은 철거의 주도권을 얻고 싶다.

## 실제 수행
1. 실제 기존 파손 벽의 돌출부 2블록을 대상으로 주민/현재 소유자의 제거 허락을 받는다. 지지부는 별도 금지 표지하고 주민을 작업면에서 8블록 이상 떨어진 기존 안전점으로 실제 대피시킨다. 허락이나 대피가 없으면 작업 중지.
2. 현재 도구와 해당 블록 채굴 가능 여부를 확인한 뒤 손 닿는 범위에서 돌출부 2블록만 하나씩 제거한다. 범위 밖 클릭은 승인된 철거로 접수하지 않는다. 실제 붕괴·화염·낙하 위험이면 즉시 중지/철수한다.
3. 실제 발생 잔재를 세고 소유자가 지정한 작업면에서 6블록 이내 보관점에 인도한다. 남은 지지부 2곳과 폭 2·높이 2 통로를 직접 확인한다. 아임의 추가 철거 제안을 실제 듣고 기존 허락 밖 확장은 거절한다.

## 완료와 갈림길
주민 허락·대피·허용 2블록 제거·잔재 정리·남은 벽 버팀/통행 확인. 위반 추가 철거가 있으면 좁은 성공 사실은 보존하되 정상 배분권 없음.

- 도구 좁은 해체가 정상 선택. 아임 화력 제안을 곧 실행 허가로 해석하지 않는다.
- 대피/지지 확인 불충족은 안전 중단·부분결말이며 보상 없음.
- 지원부 파괴·확장 강행은 실제 피해와 복구 의무를 남긴다. 원래 벽 전체/완공을 생성하지 않는다.

## 말과 반응
- “두 조각? 벽 속을 겨우 눈으로만 보라는군.”
- “길은 뚫렸어. 그렇다고 저 안까지 마음에 드는 건 아니고.”

## 보상과 선택 수령
원소유자가 실제 분배를 승인한 동일 잔재 최대 1개, 정상 수행 사건당 전체 배분 상한 1개. 여러 수행자가 있으면 배분 수신자 1명을 모두 명시 합의, 나머지는 기여만. 잔재 0 또는 미승인이면 물품권 0. 신규 장비/재료 능력 없음.

정상 사건별 실제 수행자 최초1회. 같은 사건 재개는 미수령/미지도 잔여만. 새 사건을 자동 발생시키지 않는다.

## 중단·재개·지식
공통실행계약의 체크포인트, 원물 장부, 영수증 대조, 실제 청중 규칙을 적용한다. 미수신을 수신으로 만들지 않고 완료한 행동을 재연하지 않는다.
아임은 좁은 성과에도 불만을 남길 수 있다. 위반한 파괴는 복구·적대 문제로 남으며 완공이나 새 성채를 만들지 않는다.

## 구현과 예상
영향 범위·지지 상태·잔재 원물ID를 연결하는 구현 요구. 물리 붕괴를 지원한다고 가정하지 않으며 기존 블록/보호/낙하 판정과 작업 상태 검사를 결속. 새로운 화염 기술 없음.
예상 7~12분. 실제 API·게임·LLM 시험은 하지 않은 기획값이다. 지도는 비전투 경험이며 전투 능력 보상이 아니다.
