# 베파르 — 화물 없는 선원의 자리

관리키 RPG-S14-088 · 정의 EP036A-RPG-S14-088 · 상급 · SIDE / 신규 MAIN 없음

운송의 체면보다 배에서 사라진 이름을 더 못 견디며 선주와 봉쇄자 모두에게 날을 세운다. 차갑게 또박또박 이름과 수를 확인한다. 안전을 장담하기보다 지금 확인한 것만 짧게 말한다.

## 현재 요청
운송 조건에서 화물만 남고 선원의 자리가 지워지지 않게 하고 싶다.

## 실제 수행
1. 가져온 허락된 운송 기록1건에서 화물 항목과 귀환 인원 항목을 실제 대조한다. 실제 기록에 없는 사람은 미확인. 참가자 2명(수행자와 동의한 동행 역할1명)의 역할 명부를 별도로 작성해 실제 선원 생존명부와 섞지 않는다.
2. 화물을 줄여 귀환 인원 자리와 회수 공간1칸을 실제 확보한다. 고체 지면 연습 경로는 연습 짐4개 중 2개를 보관점에 남겨 역할짐1개와 회수 여유를 확보하고 폭2·높이2·길이12블록을 왕복한다. OR 실제 열린 기존12~24블록 경로에서는 현재 자기 짐의 실제 수량과 동행을 확인해 필요한 몫을 보관하고 운반한다. 실제 경로에는 연습용 역할짐과 연습4개 구성을 새 필수로 요구하지 않는다.
3. 고체 지면 연습을 택했으면 다친 사람 역할짐1개를 되돌려 옮기고 실제 참가자2명의 안전점 도달과 역할짐 도착을 따로 확인한다. 실제 기존 경로를 택했으면 허락 동행과 자기 짐을 운반하고 뒤처진 동행이 있으면 자기 화물을 줄여 함께 안전 귀환한다. 두 경로 모두 맡긴 자기 짐은 안전하게 실제 회수하거나 못 가져온 몫의 현위치·보관·손실을 정확히 남기고 베파르에게 보고한다. 역할짐 도착은 연습 경로에서만 필수다.

## 완료와 갈림길
귀환 인원/회수 여유 실제 배치 AND [(고체 지면 연습에서 동행과 실제 귀환 AND 역할짐 도착) OR (열린 기존 경로에서 허락 동행과 자기 짐 실제 운반·안전 귀환 AND 미회수 몫의 현상 보존)] AND 정직한 범위 보고·베파르 확인. 동행 부재를 솔로 성공으로 대체하지 않으며 실제 경로에 역할짐을 역추가하지 않는다.

- 화물로 사람 자리 채우기는 배치 위반·운반 중지.
- 동행을 버리면 운반 실패·회수 작업 잔여, 지도0.
- 연습과 실제 운반을 모두 강제하지 않으며 역할 귀환을 해상 구조/치유로 기록하지 않는다.

## 보상과 선택 수령
운송 인원·회수 공간 설계 지도1회. 정상 수행자가 빈 공간1칸을 다시 표시하고 인원/짐을 따로 세어 베파르 피드백을 받는 60초 실습. 장비/선박/보호 보증0.

정상 사건별 실제 수행자 최초1회. 같은 사건 재개는 미수령/미지도 잔여만. 새 사건을 자동 발생시키지 않는다.

## 중단·재개·지식
공통실행계약의 체크포인트, 원물 장부, 영수증 대조, 실제 청중 규칙을 적용한다. 미수신을 수신으로 만들지 않고 완료한 행동을 재연하지 않는다.
베파르는 화물만 남은 완료 주장을 거부한다. 바다 이동·포칼로르 응답·모든 선원의 생존을 모형 성공으로 확정하지 않는다. 동행 역할까지 함께 귀환하면 줄인 화물과 돌아온 인원이 각각 확인된다. 뒤처진 이를 버리면 해당 운반은 실패하며 회수 작업이 남고 성공 지도는 없다.
