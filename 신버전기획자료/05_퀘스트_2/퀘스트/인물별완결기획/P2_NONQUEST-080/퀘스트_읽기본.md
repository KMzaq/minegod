OR 장식 유지=(실제 설명 수신 AND 왕의 유지 결정 AND 도구를 장식 배치 쪽으로 실제 돌림 AND 수선 실제 중단 AND 실제 미수선 상태·사용 재료·손실 보고 수신). 준비·운반·작동 확인만으로 실제 수선 완료0. 수선은 끝났으나 인수 전이면 수선 완료·반환 미완료로 나누며 같은 원물만 반환한다.

보상·권리: 원문에 지정된 실제 생활 결과·감사·현재 관계만. 추가 지급권·수강권·장비·가호·주시·레벨0. 원물은 소유자에게 실제 반환하며 반환을 플레이어 보상으로 바꾸지 않는다.

시간: 일상 3–6분, 실제 배분·수선 10–18분의 정적 예상. 당사자 답 대기 별도, 마감 없음.

정산·재개: 공통 거절·부분·재개·후발·동시 계약을 적용한다. 실제 미수령 몫만 같은 권리·원물로 이어 처리하고 본 역할에 없는 교습·물품은 생성하지 않는다.

연결: 루스탐의 원전 구출 인연은 자기 과거 범위만 유지한다. 현재 새 구출·포로·부활을 만들지 않는다. 루스탐 EP030A-RPG-S12-010의 선택 방어 지도는 본 수선 감사와 별도다.

## 공통 중단·청중
거절은 정상 선택이며 이미 끝난 일은 보존한다. 죽음·로그아웃·서버 재시작에는 현재 본체·원물·소비·수신을 대조하고 미완료만 잇는다. 후발자는 지금 실제 본 공개 결과만 알며 과거 공로·사적 대화·권리를 소급받지 않는다. 손 2블록은 실제 접촉 작업에만 적용한다. 원거리 관측은 실제 시야와 청중을 따른다.
