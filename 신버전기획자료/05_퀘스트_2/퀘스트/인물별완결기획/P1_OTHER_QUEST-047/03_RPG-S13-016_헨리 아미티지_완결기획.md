# 헨리 아미티지 · 완결 수행기획

관리키 RPG-S13-016 / God ID mythictrpg:lovecraft_unassigned_henry_armitage

실행 스키마가 아닌 채택 기획. 공통 회차·원물·수령·지식 계약은 00_공통수행계약을 따른다.

## 실제 수행

1. 실제 확보한 계산 기록의 열람 허락 부분1곳과 폐허의 현장 바닥을 대조한다. 표준 비교는 기록에 표시된 돌 두 칸 중 현재 아래까지 고체인 발판1곳과 무너진 빈칸1곳이다. 확인할 대상은 기존 실제 지형이며 기록을 맞추려고 바닥을 새로 파괴하지 않는다. 출발 안전점에서 발판·사본의 실제 위치를 관측하고 이동 경로를 고른다.

2. 필요한 지형 정보만 실제 듣고 발판을 밟아 사본1부에 접근한다. 표준 이동은 폭1블록 이상, 연속 단차1블록 이하의 마른 지상 통로에서 편도12–24블록. 막힌 곳은 이미 열린 우회로를 고르거나 보류하며 새 발판 공사를 필수로 붙이지 않는다. 비공개 주문 전체를 읽어야 움직일 수 있는 구조가 아니다.

3. 소유자가 맡긴 같은 사본을 실제 집어 안전점으로 가져와 합의 수령자에게 인계한다. 알하즈레드 사건이 이미 같은 COPY-PAIR 원물을 회수했으면 현재 원물과 본인 기여 기록을 사용한다. 후발자는 현재 대조를 돕더라도 과거 회수 공로를 상속하지 않는다. 제한된 설명 때문에 현장 확인이 늦어진 경우 실제 지연·손상·위치를 그대로 기록한다.

4. 아미티지는 알하즈레드에게 허락된 다른 구절1곳을 실제 제시한다. 이번 기획의 무해한 비교 표본은 “물자국 아래”/“물자국 옆”이며 앞서 알하즈레드의 대목과 구분한다. 실제 현물의 허락 구절이 따로 있으면 페이지·정확 문장·차이를 수락묶음으로 고정한다. 실제 응답받은 어휘 차이만 대조한 뒤 나머지 부분은 닫는다. 상대 부재이면 회수만 완료하고 대조는 보류한다.

5. 모든 내용을 무단으로 펼쳐 전달한 경우 실제 수신 범위만 기록하고 추가 열람 중단·제한 주석 보상 없음으로 끝낸다. 회수 성공 자체와 보안 피해를 별개로 보존한다. 아미티지는 필요한 설명이 부족했다는 실제 지적에는 안전 정보를 보충하지만 금서 전문 공개를 보상이나 정답으로 강요하지 않는다.

## 원물과 비용

계산 관찰 대목1곳·안전 발판 확인1곳·회수 사본1부·상대 대조 다른 구절1곳. 소모0 기본이며 기존 물건을 보관/인계할 뿐 책 지급0. COPY-PAIR 원물1개를 두 사건이 공유, 회수·인계 각1회만. 대조 대목A/B는 허락 범위와 실제 수신자를 각각 저장한다.
