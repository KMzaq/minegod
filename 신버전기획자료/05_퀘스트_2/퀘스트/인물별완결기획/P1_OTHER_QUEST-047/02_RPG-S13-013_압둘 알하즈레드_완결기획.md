# 압둘 알하즈레드 · 완결 수행기획

실행 스키마가 아닌 채택 기획. 공통 회차·원물·수령·지식 계약은 00_공통수행계약을 따른다.

## 실제 수행

1. 실제 확보한 판본과 회수 요청된 사본을 구별하고 소유자에게 회수·운반·열람 각각의 허락을 받는다. 표준은 회수 사본1부와 대조할 판본1부, 허락된 구절1곳이다. 현재 어휘 차이를 지목하되 사본 전체 소유권을 알하즈레드에게 넘기는 조건으로 바꾸지 않는다.

2. 기존 폐허의 안전 접근로를 따라 실제 사본까지 이동하여 집어 보호하고 마른 보관점으로 돌아온다. 표준 회수 지점은 안전 발판에서 12–24블록 이내의 접근 가능한 자리이며 새 방·제외 연구자·보스는 추가하지 않는다. 비·유입수·몹이 실제로 있을 때만 급박한 대사를 쓴다. 이미 젖었으면 현재 상태를 보고하고 수분 손상 판정 기능이 없는 서버에서는 젖음만으로 파괴를 발명하지 않는다.

3. 아미티지에게 대조 이유·구절 범위·현재 소유자의 허락을 실제 전한다. 그가 응답한 범위만 펼치고 서로 같은 대목의 다른 어휘를 실제 읽고 지목한다. 이번 기획의 무해한 대조 표본은 “둘째 돌의 안쪽”/“둘째 돌의 바깥쪽”이며 주문 전문이 아닌 허락된 지형 어휘 주석용 예시다. 이미 현물에 다른 허락 문장이 있으면 그 정확 문장·페이지·차이 한 곳을 수락 시 지정하며 표본으로 덮어쓰지 않는다.

4. 알하즈레드가 자기 실제 판본에서 수정할 낱말을 고르고 그 판본 소유자의 허락 범위에서 주석을 남긴다. 다른 판본의 전체 정답·주문 효능·피해 원인은 별개 미확인이다. 아미티지 부재·거절이면 회수는 보존하고 그 판본 대조는 보류한다. 자기 판본의 수정이 상대 응답을 대신하지 않는다.

5. 허락 없이 펼쳐 전하는 위반이 실제 발생하면 실제 읽거나 들은 청중과 전달한 대목만 남긴다. 듣지 않은 사람에게 누출 지식을 주거나 실제 들은 것을 삭제하지 않는다. 자료 소유자는 추가 열람을 중단할 수 있고 성공 주석 보상은 생기지 않는다. 전파된 주장과 실제 주문 피해를 동일시하지 않는다.

## 원물과 비용

회수 사본1부는 COPY-PAIR 회차의 동일 원물. 아미티지 사건에서 이미 회수한 경우 새 회수·물품 생성·공로0이며 본인 기존 기여를 참조한다. 대조 판본1부·허락 구절1곳·어휘 차이1곳을 수락묶음으로 고정. 소모 재료0이 기본, 원본 훼손·주문 재현·희귀품 납부 없음. 기록을 새 종이에 남기기로 별도 합의하면 소유자가 승인한 종이1장만 쓰고 주석 열람을 필수 복사본 제작으로 바꾸지 않는다.
