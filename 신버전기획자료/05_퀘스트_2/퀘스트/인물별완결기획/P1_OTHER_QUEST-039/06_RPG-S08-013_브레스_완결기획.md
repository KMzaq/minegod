관리키 RPG-S08-013 / 현재 God ID mythictrpg:celtic_unassigned_bres

## EP025A-RPG-S08-013 · 수행
예상 6–11분. 시간제한 없음.
1. 현재 브레스와 거래자가 같은 거래표에 실제 현물종류·수량 q·소유·인도법·제공할 경작설명 범위를 적어 확인한다. q는 이번 현물 합의값이며 고정 가격표/새 아이템을 만들지 않는다. 완성된 합의 전 인도0. 유료 거래 또는 공개 시범 청취만 OR.
2. 유료 거래자는 합의한 q를 실제 인도하고 브레스 수령 후 허락된 현재 밭 구역에서 공개 순서를 따라 경작한다. 예: 현존 허락한 경작 가능 흙1칸을 고르고 쟁기질→현재 제공된 씨앗1개 심기를 실제 해 본다. 해당 재료/심기 허락이 없으면 그 작업을 제공 범위로 합의하지 않고 현재 가능한 흙 상태 관찰·정리 순서를 명시한다. 관찰자는 실제 공개 시범만 보며 수확/성장 결과를 선취하지 않는다.
3. 인도·실습이 실제 충족한 거래자에게 합의한 제한 설명을 직접 전달하고 수신을 확인한다. 설명 미수신이면 같은 채무만 보류, 재결제0. 브리기드 구호는 별도 실제 수락·인계, 루 사면은 루의 현재 판단이며 본 거래의 관문/보상 아님.

### 원물·정산
거래_id별 q 현물=실제인도+미인도, 인도와 소유이전만 기록해 소비와 구분. 경작 씨앗은 실제 심은 최대1개(그 작업으로 합의된 경우), 자기 도구 비소비/원래 사용 규칙 유지. 구호재고와 보수재고 분리, 공용 시범에 유료채무0.
실제 지불·연습 완료자에게 합의한 경작 설명1건. 공개 청취자는 공개내용만, 전체기술·풍요가호·수확배율·사면 없음. 권리/발언/수신 원장 분리, 못 들은 설명만 같은 거래로 재전달.

### 완료와 원문 분기
합의한 대가의 실제 인도·수령과 공개된 경작 순서의 실제 연습을 마친 거래자에게 합의한 제한 설명만 실제 전달한다. 공개 시범 청취자는 그 공개 범위만 알고, 브리기드 구호 수락·실제 인계와 루 사면 판단은 서로 별개다.

B1: 플레이어는 실제 제시한 대가의 품목·현물량·소유·인도 방법과 받을 제한 설명을 듣는다. 그 구체 내용을 당사자가 같은 것으로 이해한 뒤 거래 의뢰 참여를 수락하거나 공개 시범 청취만 택한다. 숫자·품목이 아직 정해지지 않았으면 결제하지 않는다.
- 한정 거래의 대가와 범위를 합의한다: 유효 제안·수락과 지불 준비만. 설명 수신·경작 연습·사면은 아직 없다.
- 공개 시범만 보겠다고 한다: 공개 관찰 갈래. 지급·제한 지식 권리·퀘스트 거래 성공을 만들지 않는다.
- 현재 하던 일의 이유를 묻고 참여 여부는 따로 정한다: 실제 질문과 허락된 현재 답의 수신만. 질문하지 않은 행동·보고·침묵·먼저 하는 NPC 발언에 이 질문 수신을 공통 조건으로 붙이지 않는다. 이미 끝난 자기 결과는 보존한다.

B2: 거래자는 합의한 자기 대가를 실제 건네고 브레스의 수령을 확인한 뒤 공개한 경작 순서를 허락 범위에서 실제 해 본다. 관찰자는 그 공개 시범만 본다. 플레이어는 지금 관측할 수 있는 흙·배치·작업 결과만 전하며 성장·풍요를 기다렸다고 꾸미지 않는다. 브레스는 브리기드와 실제 접촉했을 때 그 구호 필요를 자기 보수와 분리해 묻는다.
- 대가를 실제 내고 공개 순서를 연습한다: 유효 교환과 연습이 확인되면 제한 설명 단계로 간다. 지불만 했거나 연습만 했으면 해당 부분만 보존한다.
- 공개 시범을 보고 돌아간다: 공개 지식만 수신. 제한 설명·유료 거래 완료·사면·구호 없음.
- 애도를 압박하거나 지불 약속만으로 설명을 요구한다: 관찰·실제 지불·실제 연습은 보존하나 새 제한 설명·사면·구호 성공은 없다.

B3: 실제 교환·연습을 마친 플레이어에게 브레스가 합의한 제한 기술 설명을 자기 이름으로 말한다. 실제 들은 사람만 그 범위를 안다. 별도 구호는 브리기드가 실제 수락한 몫의 인도·수령까지 있어야 이동하며 루 사면은 루의 실제 판단을 기다린다.
- 유효 거래의 제한 설명을 듣는다: 해당 한정 지식만 획득. 설명 사양은 이미 실제 지불·연습한 사실을 지우지 않는다.
- 미완 거래를 보류하거나 선택 구호를 하지 않는다: 유효 지불·작업·지식 보존. 구호·사면은 미실행으로 남는다.

## 성격과 반응
패배했다고 말의 값까지 낮아졌다고 여기지 않는 협상가다. 조건을 먼저 내놓고 웃음은 늦게 보인다. 도움에도 자기 몫과 말할 자리를 찾으며 동정을 대가로 삼으려는 요구에는 쉽게 입을 열지 않는다. 신 과일을 먹고 표정이 달라지지 않는 놀이에서는 흥정 때와 다른 장난기를 드러낸다.
초면: “얼마를 주고 무엇을 들을지부터 정하자. 동정은 품목이 아니다.” 실제실습: “자란 걸 본 건 아니지. 오늘 한 순서부터 말해 봐.” 구호: “그분의 필요와 내 보수는 다른 이야기다.”
초면/경계에는 현재 소유·의사를 먼저 확인하고, 실제 신뢰가 있으면 반대 의견과 독립 시도를 더 편히 묻는다. 친분은 수락·소유·보상·사적공개를 대신하지 않는다.
