# 엘라하 · 보급만 싣는 갑판

관리키 RPG-S08-014 / 현재 God ID mythictrpg:celtic_unassigned_elatha

실행 스키마가 아닌 채택 기획. 기존 정체·개인 MAIN·생사·표현 범위 보존. 공통 저장·복구·청중 규칙은 00_공통수행계약을 따른다.

## EP025A-RPG-S08-014 · 수행
예상 8–15분; 실제 답 부재시 적재 부분만 보존. 시간제한 없음.
1. 기존 항구 보급의 실제 품목별 수량·원소유·지정 수혜자·적재범위를 확인해 이번 몫을 수락한다. 브레스의 부담은 실제 본인 답 전까지 공란. 보급·전함을 생성하지 않는다.
2. 허락된 몫을 현재 배에 실제 싣고 묶음을 당겨 안정성을 시험한다. 바람이 없으면 현재 가벼운 흔들림만 시험, 폭풍/파손 연출0. 브레스와 실제 접촉해 자신의 빚·갚을 몫에 대한 공개 허락 답을 받았을 때만 엘라하에게 출처와 함께 전달한다.
3. 적재·시험과 실제 브레스 답의 엘라하 수신이 충족하면 해당 보급의 사절 준비 단계만 연다. 출발·항구도착·상대응답은 후속 실제 사건 각각의 증거 필요. 실제 맡은 운반도구는 별도 반환, 이미 수혜자가 받은 보급을 실패로 소환하지 않는다.

### 원물·정산
보급 항목별 q=육지잔량+배적재+실제수혜자 인수+실제손실. 소유는 원권리대로, 플레이어는 운반자. 묶는 도구 실제 대여수량만 반환, 존재하지 않은 대여0. 준비를 배달로 정산하지 않는다.
새 물품0. 기존 항구 약속 내 사절 준비/파견 가능성만, 자동 출발·도착·무력보증·전함·보급 소유권 없음.

### 완료와 원문 분기
허락된 기존 보급의 실제 적재·묶음 시험과 브레스의 자기 부담에 관한 실제 답이 엘라하에게 도달한 범위에서만 사절 준비를 시작한다. 준비·출발·도착·상대 응답은 별도이며 무력 보증·플레이어 보급 소유권은 생기지 않는다.

B1: 플레이어는 실제 펼친 보급의 소유·수량·수혜자와 옮길 범위를 엘라하에게 확인한다. 브레스가 무엇을 부담할지 실제 답하기 전에는 그 몫을 추측하지 않는다. 제한 지원 의뢰를 수락하거나 적재 보류를 선택한다.
- 보급만 보내는 한정 지원에 참여한다: 지원 준비만 성립. 적재·출항·브레스 답·사절 성공은 아직 없다.
- 브레스의 부담 답을 기다린다: 미적재·답 대기. 가족 대신 채무를 약속하지 않는다.
- 현재 하던 일의 이유를 묻고 참여 여부는 따로 정한다: 실제 질문과 허락된 현재 답의 수신만. 질문하지 않은 행동·보고·침묵·먼저 하는 NPC 발언에 이 질문 수신을 공통 조건으로 붙이지 않는다. 이미 끝난 자기 결과는 보존한다.

B2: 플레이어는 허락 몫을 실제 싣고 엘라하와 짐의 묶음을 당겨 흔들림을 시험한다. 바람이 없으면 현재 가벼운 흔들림 시험만 하며 폭풍을 만들지 않는다. 브레스가 실제 자기 빚과 갚을 몫을 말했을 때만 허락된 답을 엘라하에게 원출처와 함께 전한다.
- 실제 보급을 묶고 정확한 답을 전한다: 안정 적재와 해당 답 수신 범위만 사절 준비 근거. 출발·도착·무력 지원 없음.
- 적재만 끝내고 답 또는 안전을 기다린다: 부분 운반 보존, 사절 준비·통항 성공은 미성립. 이미 안정한 묶음을 위험하게 흔들어 재연하지 않는다.
- 가족이니 무력 지원까지 약속했다고 전한다: 해당 왜곡·보류 상태. 이미 다른 수혜자에게 실제 인도된 몫은 되감지 않는다.

B3: 플레이어는 현재 적재한 몫과 실제 전달한 답을 확인한다. 엘라하는 해당 범위에서만 기존 항구 약속의 사절 준비를 택한다. 실제 출발이 생기면 출발만, 실제 도착과 응답이 각각 확인되면 그 단계만 더한다. 맡은 도구는 원소유자에게 돌려준다.
- 확인된 범위에서 사절 준비를 마친다: 이번 준비의 완료만. 아직 출발 안 했으면 출발 없음. 실제 후속 단계가 관찰/전달될 때만 추가한다.
- 미답·미인수 상태로 지원을 보류한다: 이미 끝낸 운반은 보존, 사절 성공·무력 보증 없음. 다음에는 미완 부분부터 이어 간다.

## 성격과 반응
아들의 체면을 세워 주고 싶지만 대신 모든 손해를 짊어질 마음은 없는 아버지다. 부드럽게 말한 뒤에도 조건을 흐리지 않는다. 대답 전 옷깃을 고르고, 가족 이야기에서도 누가 무엇을 감당할지 묻는다. 먼 배의 돛이 바람에 따라 접히는 모양을 비교하는 시간을 좋아한다.
초면: “아들 체면은 세워 주고 싶네. 그 아이 몫까지 내가 말해 줄 수는 없지.” 적재뒤: “배에 실린 것은 확인했네. 이제 그 아이가 한 말을 들려주게.” 친밀해도 조건을 흐리지 않는다.
초면/경계에는 현재 소유·의사를 먼저 확인하고, 실제 신뢰가 있으면 반대 의견과 독립 시도를 더 편히 묻는다. 친분은 수락·소유·보상·사적공개를 대신하지 않는다.
