## EP025A-RPG-S08-010 · 수행

1. 자기 장비1점의 주인·용도·현재 걸림을 확인하고 기존 묵직한 손잡이 유지 또는 허락된 가벼운 교체부 사용 중 하나를 수락한다. 장비 통째 재제작/유일검 개조/공격력 증가는 이 의뢰 범위가 아니다.
2. 실제 위탁된 장비만 고이브니우가 손질하고 필요한 연결 작업은 현재 접근·동의한 크레드네와 진행한다. 유지 경로는 교체부 차감0. 교체 경로는 실제 부품 장착 때만 재고 이동, 뺀 원부품은 소유자 보관칸에 남긴다.
3. 안전한 무생물 시험면 앞에서 사용자가 평소 자세를 반복해 같은 걸림이 남는지 직접 확인한다. 임의 합격횟수/피해 판정 없음. 선택 맞춤과 무걸림이 확인된 장비만 수리완료, 미완이라도 원장비·원부품의 반환권은 유지한다.

### 원물·정산
원장비 UID1·선택 교체부 최대1건. 유지면 교체소비0, 교체면 실제 장착량만 소비/변환, 원부품은 반환량으로 별도 기록. 원장비를 새 보상장비로 복제0. 절삭량은 실제 공정기록, 재접속 재료 재생0.
기존 소유 장비 손잡이 맞춤 수리1회, 신규 무기/장비/스킬 보상0. 대장장이 직접제작 종류 예외는 인정하지만 이 원문의 수리를 새 제작권으로 확대하지 않는다. 신이 새로 준 장비의 기본 무한내구 규칙과 달리 기존 인간제 원장비 손질은 원내구 성질을 바꾸지 않는다. 시험작/수작/완성작/명작은 공정명, 장비7등급/인물등급과 별개이며 이번 수리로 등급승급0.

### 완료와 원문 분기
묵직한 기존 손잡이 유지 또는 허락된 가벼운 교체부 장착 후 실제 반복 자세에서 걸리지 않음을 확인한 선택 장비만 돌려준다. 반환과 손잡이 맞춤 수리 보답을 분리하며 미완·온전한 원장비는 소유자에게 원래 상태 범위로 반환한다.

B1: 플레이어는 장비의 실제 주인과 용도를 말하고 현재 느끼는 걸림을 설명한다. 고이브니우가 안전한 자리에서 손잡이를 쥐어 보도록 허락한다. 묵직함 유지와 가벼운 교체 중 자기 취향을 고르고 SIDE 의뢰를 수락한다.
- 묵직한 손잡이를 남기려 한다: 유지 수리 준비. 기존 손잡이를 버렸거나 교체부를 소비했다고 하지 않는다.
- 가벼운 교체부를 고른다: 교체 준비만. 실제 장착 전 소비·성능 확정 없음.
- 현재 하던 일의 이유를 묻고 참여 여부는 따로 정한다: 실제 질문과 허락된 현재 답의 수신만. 질문하지 않은 행동·보고·침묵·먼저 하는 NPC 발언에 이 질문 수신을 공통 조건으로 붙이지 않는다. 이미 끝난 자기 결과는 보존한다.

B2: 플레이어가 소유 장비를 실제 맡기고 고이브니우와 크레드네가 허락한 부분만 손질한다. 이후 사용자가 안전한 표적 앞에서 익숙한 자세를 여러 번 취해 손가락이 걸리는 지점을 직접 말한다. 유지와 교체는 택한 한 경로만 실행한다.
- 고른 손잡이로 실제 반복 시험한다: 걸림 없으면 선택 장비 확인으로 B3. 걸림이 남으면 그 부분만 미완 저장하고 출고하지 않는다.
- 용도를 숨겨 전투용 출고를 재촉한다: 완성 수리 성과 없음. 원장비와 실제 교체/미사용 부품 상태만 보존한다.

B3: 플레이어는 시험에서 실제 확인된 장비 상태를 듣고 원장비와 자기 원부품을 인수한다. 걸림 없이 선택 맞춤이 완료된 때만 수리 결과를 받으며 미완이면 손상 없는 범위의 원장비 반환과 남은 결함만 확인한다.
- 맞춤 완료 장비를 인수한다: 실제 맞춤 수리 완료와 실제 반환이 따로 기록된다. 새 장비·신격 무기·수치 상승 없음.
- 미완 원장비를 돌려받거나 재작업을 미룬다: 원소유 반환은 보상 아님. 미완성품을 성공 장비로 지급하지 않고 다음에는 실제 남은 부분만 재작업한다.

## 성격과 반응
잘 쓰이는 도구에 만족하는 대장장이다. 짧은 지시 사이에 퉁명스러운 농담을 끼우지만 손잡이와 쓰임을 묻기 시작하면 말이 길어진다. 단단한 빵 껍질을 깨무는 소리를 좋아한다.
초면: “무거운 게 좋나, 손이 편한 게 좋나? 둘이 늘 같은 건 아니지.” 시험: “내가 잘 만들었다는 말 말고, 네 손이 걸린 곳을 말해.” 미완: “네 물건은 돌려주마. 끝냈다고 쓰진 않겠다.”
초면/경계에는 현재 소유·의사를 먼저 확인하고, 실제 신뢰가 있으면 반대 의견과 독립 시도를 더 편히 묻는다. 친분은 수락·소유·보상·사적공개를 대신하지 않는다.
