## EP025A-RPG-S08-015 · 수행

1. 실제 해당 징수 요구와 현재 주민의 천막/짐을 확인한다. 주민이 잔류 또는 자발적 이동을 직접 고르게 하고 물건별 도움 허락 뒤 수락한다. 요구가 없으면 피해사건 생성0.
2. 잔류면 실제 접힌 천막을 다시 펴서 주민이 사용하도록 한다. 이동이면 주민이 직접 고른 현재 허락된 새 자리까지 실제 짐을 옮겨 천막을 펼친다. 두 경로 OR. 이미 펼쳐진 천막은 일부러 접지 않고 같은 사건의 과거 유효행동이 있을 때만 근거를 접수한다.
3. 에리우가 브레스에게 자기 이름 근거 철회를 실제 요구하고 해당 징수가 실제 철회된 범위만 기록한다. 주민 선택 이행·실제 사용·징수 철회를 확인한 수혜자에게만 지정 경로 통행증1개를 선택 인도한다. 단지 통행증 수령 때문에 완료를 늦추지 않는다.

### 완료와 원문 분기
주민이 실제 고른 잔류 또는 자발적 이동을 돕고 천막이 실제 사용되며, 에리우가 브레스에게 이름 근거 철회를 요구해 해당 징수가 실제 철회된 범위만 인정한다. 현재 온전한 천막 관찰만으로 미실행 재설치·이동을 완료하지 않는다. 유효 성취 확인 뒤 해당 경로의 통행증만 제공한다.

B1: 플레이어는 주민에게 남을지 자발적으로 옮길지 묻고 현재 답을 듣는다. 짐에 손대기 전에 물건별 소유·도움 허락을 확인하고 선택한 도움 범위의 SIDE를 수락한다. 실제 징수 요구가 없으면 피해 상황을 꾸미지 않는다.
- 주민이 남는 선택을 돕는다: 잔류 도움 준비만. 천막 사용·징수 철회·통행증 없음.
- 주민의 자발적 이동을 돕는다: 이동 준비만. 실제 인도·설치·징수 철회는 남는다.
- 이미 온전한 천막 상태만 확인한다: 안전 관찰만 새로 남긴다. 하지 않은 재설치·이동 공로·통행증은 없음.
- 현재 하던 일의 이유를 묻고 참여 여부는 따로 정한다: 실제 질문과 허락된 현재 답의 수신만. 질문하지 않은 행동·보고·침묵·먼저 하는 NPC 발언에 이 질문 수신을 공통 조건으로 붙이지 않는다. 이미 끝난 자기 결과는 보존한다.

B2: 잔류 도움자는 주민과 실제 접힌 천막을 다시 편다. 이동 도움자는 허락받은 짐을 실제 새 자리로 옮겨 주민이 사용할 수 있게 편다. 둘을 함께 요구하지 않는다. 에리우는 브레스에게 자기 이름을 빼라고 실제 말하고 브레스의 실제 답을 받는다.
- 주민 선택대로 실제 천막을 사용 가능하게 한다: 천막 사용 결과와 실제 철회 상태를 분리. 브레스 부재/미철회이면 천막 도움은 보존하되 통행증 권리는 아직 미성립이다.
- 혈연의 땅이라며 짐을 강제로 빼앗는다: 강제 반출은 도움 완료 아님. 천막을 세운 사실로 강요가 상쇄되지 않는다. 새 동의 전 미완 상태.
- 현재 상태와 미철회 요구를 남긴다: 현재 관찰·부분 작업만 남는다. 관찰을 재설치·징수 방지 성공으로 치환하지 않는다.

B3: 플레이어는 실제 수행한 펼침/자발적 이동 또는 이전 유효 작업 근거를 제시하고 주민의 선택이 지켜졌는지 확인한다. 브레스의 해당 징수 요구가 실제 철회된 경우 에리우가 이를 확인한 수혜자에게 한정 경로 통행증을 직접 내어준다.
- 유효 성취를 확인받고 한정 통행증을 받는다: 그 한정 경로 권리만. 수령 불가면 유효 미수령분을 보존하며 실물 복제 없음.
- 천막 도움과 미철회 요구를 분리해 남긴다: 부분 성과 보존. 통행증 권리 없음. 완료한 천막 도움을 다시 접고 펼칠 필요 없음.

## 성격과 반응
가족이라는 말이 남의 땅과 물건을 차지할 근거로 쓰이면 조용한 질문이 날카로워진다. 긴 설득보다 상대가 건너뛴 말을 정확히 되묻는다. 앉기 전 작은 돌을 옆으로 밀고, 서로 다른 흙에 손가락 자국이 남는 모양을 재미있어한다. 가까운 사람의 사정도 그곳에 사는 사람의 선택을 대신하지 못한다고 여긴다.
초면: “남고 싶은 분께 왜 먼저 짐을 접으라고 했죠?” 브레스에게 실제 요구: “내 이름을 빼세요. 그분의 대답도 대신하지 말고요.” 철회 뒤: “이번 요구가 물러난 겁니다. 모든 땅이 당신 것이 된 건 아니에요.”
초면/경계에는 현재 소유·의사를 먼저 확인하고, 실제 신뢰가 있으면 반대 의견과 독립 시도를 더 편히 묻는다. 친분은 수락·소유·보상·사적공개를 대신하지 않는다.
