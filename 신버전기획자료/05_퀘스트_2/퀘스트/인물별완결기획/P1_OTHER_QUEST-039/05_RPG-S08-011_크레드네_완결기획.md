## EP025A-RPG-S08-011 · 수행
예상 8–14분. 시간제한 없음.
1. 실제 접히는 부품1점과 해당 납품 요청을 확인해 걸리는 방향을 재현한다. 제한된 임시 사용 또는 전면 재작업의 범위·지연을 듣고 하나를 고른다. 납기를 새 현실 타이머로 바꾸지 않는다.
2. 플레이어는 실제 접었다 펴기 방향을 바꿔 걸림을 보이고 크레드네는 허락 부위만 깎는다. 그 뒤 같은 동작을 다시 해 제한 범위 또는 완전 무걸림 결과를 확인한다. 모형에서 실제 버티는 근거가 있을 때만 허락 장비에 임시 조립, 임시 갈래에 완전 무결 요구0.
3. 선택 결과와 사용 제한을 실제 수령자에게 고지하고 수락·인도를 기록한다. 미인수면 납품완료0. 그러나 허용된 갈래의 실제 재현+재시험 기여자에게 생긴 선택 지도권은 납품 미인수와 별도로 보존한다. 부품 이름/크레드네 출처는 실제 들은 수령자만 안다.

### 원물·정산
부품 UID1과 실제 절삭량/교체량만 정산. 임시 조립 소유이전0. 미사용 재고와 떼어낸 원부품은 원소유 반환. 지도재료는 납품 원물과 분리된 자기/허락 비전투 연습재료1점, 실제 깎은 양만 소모.
허용 갈래에서 실제 재현·재시험을 한 당사자에게 비전투 부품 다듬기 지도1회. 납품 인수/전체 EP종결은 별도, 미인수 때문에 기여권리 취소0. 새 장비/전투스킬/가호0. 대장장이 예외·신제장비 기본무한내구·공정명과 장비등급 분리를 보존하되 새 제작권 자동추가0.

### 완료와 원문 분기
한정된 임시 사용을 실제 고지·수락한 범위 또는 재작업 뒤 무걸림을 확인한 완전 납품 중 선택한 결과만 성립한다. 크레드네의 부품 이름은 실제 전달된 청중에게만 알려지며 실제 재현·재시험 기여자만 선택 다듬기 지도를 받는다.

B1: 플레이어는 크레드네가 허락한 부품을 받아 손동작을 따라 보며 어떤 접힘에서 걸리는지 직접 묻는다. 임시 제한 사용 또는 재작업의 비용과 납품 지연을 듣고 현재 의뢰 참여를 수락한다.
- 접힘 문제를 맡아 본다: 진단 준비·현재 관측만 남는다. 재작업·무걸림·납품은 아직 없다.
- 현재 하던 일의 이유를 묻고 참여 여부는 따로 정한다: 실제 질문과 허락된 현재 답의 수신만. 질문하지 않은 행동·보고·침묵·먼저 하는 NPC 발언에 이 질문 수신을 공통 조건으로 붙이지 않는다. 이미 끝난 자기 결과는 보존한다.

B2: 플레이어는 접었다 펴는 방향을 바꿔 실제 걸림을 재현하고 크레드네가 그 부분을 깎은 뒤 다시 움직인다. 모형에서 버티는 결과가 있으면 실제 허용된 장비에 임시 조립해 손에 닿는 느낌을 확인한다. 전면 재작업과 제한 임시 사용은 서로 다른 선택이다.
- 제한된 임시 사용을 고지한다: 한정 임시 사용만 유효. 완전 수리·전투 효능을 선언하지 않는다.
- 납품을 미루고 다시 만든다: 실제 무걸림이면 완전 납품 가능. 걸림이 남거나 재료 부족이면 미완 재작업만 저장한다.
- 결함을 감추고 넘기려 한다: 정상 납품과 지도 권리 없음. 부재한 고이브니우의 즉시 압수를 생성하지 않는다.

B3: 플레이어는 부품의 임시 제한 또는 완전 시험 결과를 해당 수령자에게 실제 전한다. 부품 이름과 크레드네 작업을 말하면 실제 들은 수령자에게만 그 출처가 남는다. 허용된 성공 갈래의 실제 재현·재시험 기여를 크레드네가 확인한 사람은 납품 인수 여부와 별도로 지도를 선택할 자격을 보존한다. 실제 지도는 현재 크레드네의 현존·동의와 허락된 실제 연습 재료가 있을 때만 진행한다. 미인수 상태를 납품·전체 이야기 완료로 올리지 않는다.
- 허용 결과를 인계하고 지도를 선택한다: 선택 경로의 납품과 별도 수강만 기록. 임시 납품에 완전 수리 배지를 덧붙이지 않는다.
- 미완 부품을 남기고 인계를 미룬다: 이미 실제 한 재현·재시험은 보존한다. 미인수 납품·전체 이야기 완료·사용자의 이름 청취는 생성하지 않는다. 자격 있는 기여자의 실제 선택 지도가 별도로 이뤄진 때만 그 수강을 기록하며, 미실행 지도는 완료하지 않는다.

## 성격과 반응
보이지 않는 작은 걸림을 찾았을 때 조용히 만족하는 장인이다. 설명은 낮게 시작하지만 잘못 짚은 곳에서는 목소리가 커진다. 칭찬을 들으면 부품을 다시 보고, 큰 물건의 위용보다 작은 접합부가 어떻게 움직이는지를 궁금해한다. 달걀 껍질의 가느다란 무늬를 오래 바라보며 자연스러운 선을 좋아한다.
초면: “작다고 덜 걸리는 건 아닙니다. 어느 쪽으로 접었죠?” 실제 재현: “거기! 그 작은 턱입니다.” 제한납품: “이 방향까지만 쓰는 겁니다. 이름보다 그 말을 먼저 전해 주세요.”
초면/경계에는 현재 소유·의사를 먼저 확인하고, 실제 신뢰가 있으면 반대 의견과 독립 시도를 더 편히 묻는다. 친분은 수락·소유·보상·사적공개를 대신하지 않는다.
