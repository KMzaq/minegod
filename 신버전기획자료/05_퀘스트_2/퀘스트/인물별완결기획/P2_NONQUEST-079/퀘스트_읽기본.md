세계 해금은 누구 한 명의 유효 달성으로 전역 영구 적용. 현재 조건을 갖춘 실제 조우주체와 개인 권리·지식은 별개다. 기존 초기접근과 이미 배치된 동일 본체는 새 조건·재추첨으로 잠그지 않는다. 최초 미배치는 기존 본체 현존을 요구하지 않으며 사망·봉인·미로드·부재는 최초 미배치가 아니다.

### 떠나는 사람의 한 끼 · EP028A-RPG-S11-003 (service, NONE)
- B1: 피난처의 남은 식재료로 두 가지 맛의 작은 식사를 함께 만들고, 플레이어가 오늘 먹고 떠날 자리와 함께 설거지할 자리를 고른다. 새 건축 없이 기존 화덕과 자리를 쓴다.

- B2: 먹기를 실제 선택한 사람의 빈 그릇만 거두고 떠나는 사람이 자기 짐을 챙길 때 문을 열어 둔다. 환웅의 허가를 대신 구하지 않는다.
다음은 선택 경로별 실제 행동이며 서로 모두 수행할 조건이 아니다:

## 해모수 · RPG-S11-006

다음은 선택 경로별 실제 행동이며 서로 모두 수행할 조건이 아니다:

전달 자료 없이 내 다음 대화를 정한다: 허락된 제삼자 자료가 없으면 다른 이의 불만을 지어내지 않고 플레이어 자신의 다음 대화 요청을 말한다. 해모수가 실제 동의한 주제와 끝낼 시각만 정한다.
칭송만 하고 관계 요구를 꺼내지 않는다: 해모수를 칭송하고 길의 전망만 이야기한다. 해모수는 현재 아는 길에 대해 말할 수 있지만 실제 묻지 않은 관계 요청에 답한 것으로 만들지 않는다.
  - B1-1 응답: 현재 화자가 이 시점의 사실을 실제 알고 대화 가능한 청중에게만. 해모수: 질문을 실제 들은 뒤: “그 요구에 답하겠네. 오늘 대화의 끝도 지금 정하지.”
