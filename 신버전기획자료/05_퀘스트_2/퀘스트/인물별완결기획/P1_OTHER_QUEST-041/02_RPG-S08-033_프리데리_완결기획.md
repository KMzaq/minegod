# 프리데리 · 열쇠를 놓고 가는 용기

실행 스키마가 아닌 채택 기획. 기존 정체·개인 MAIN·생사·표현 범위 보존. 공통 저장·복구·청중 규칙은 00_공통수행계약을 따른다.

## EP026-RPG-S08-033 · 수행
예상 10–18분. 시간제한 없음.
1. 기존 탐색길 입구에서 가까운 조사구간 기본20블록과 돌아설 표식을 정한다. 실재 흔적의 위치·방향을 관찰하고 보이지 않는 구간은 미확인으로 보고한다. 리안논 연락이 실제 왔다면 그 원하는 도움을 우선하며 과거 실종 기록만으로 현재 구조를 개시하지 않는다.
2. 동시에 프리데리와 현재 협업 동의한 마나위단이 실제 망가진 상점 물건1개를 수선한다. 기본안은 느슨한 진열대 판자1곳에 소유자 허락 판자1개를 장착하는 생활 수선. 이미 수선 완료면 재소비0, 대상/마나위단 없으면 가능한 준비만 보존한다.
3. 플레이어 실제 제한조사 보고 + 수선된 물건 + 실재 상품을 원재고에서 진열 + 상점 당사자의 실제 문 열기 모두 있어야 재개. 기본 진열은 현재 상품1종 1스택 이하를 원물 그대로 옮기며 판매가·재고는 기존 상점 규칙 유지. 이 장면이 새 재고를 만들지 않는다.
4. 실제 위험 발견 뒤 추가탐색 준비를 택하면 동행자 현재 동의·귀환수단을 다시 확인한다. 상점 미개방이면 그 결말은 미완료, 추가여정 시작을 구조/귀환으로 쓰지 않는다. 확인되지 않은 길 강요는 중단하고 정확한 정정 후 남은 작업부터.

### 원물·정산
기본 허락 판자1개 실제 장착소비1; 기존 수선 대상별 합의 정수량 우선. 상품은 상점 소유·판매 때만 이전, 진열 소비0. 리안논 보관 증거와 상점 원재고를 섞지 않는다.
상점 재개는 서비스 접근 결과, 무료 상품·개인 입장 독점권0. 실제 가격/재고에 따른 일반 거래는 별도 세션으로 원EP 반복보상0.

### 완료와 원문 분기
제한 조사 보고와 실제 수리·진열·문 열기가 끝난 갈래에서만 상점이 재개된다. 실종자의 구출이나 귀환, 무료 상품은 없다.
대안 결과: 준비된 추가 탐색은 별도 여정의 시작 또는 준비 상태다. 상점 문이 실제 열리지 않았다면 상점 재개 미완료이며 나중에 할 수리와 조사 결과를 보존한다.
해로운 경로는 실제 위반·손실과 미완료만. 준비/클릭/질문으로 완료되지 않는다.

B1: 탐색길 입구에서 프리데리가 앞으로 나가려다 뒤의 일터를 돌아본다. 마나위단이 실제 접촉하면 고칠 물건과 맡을 일을 함께 정한다. 플레이어는 허용된 가까운 흔적의 조사 범위와 돌아올 경계를 확인한다. 리안논에게서 실제 도착한 연락이 있으면 그 원하는 도움을 먼저 읽고 새 구조 계획을 대신 덧붙이지 않는다.
- 오늘의 실제 준비를 한다: 실제 준비·허락만. 실행 성공·상대 수신·보상권 없음.
- 이미 유효하게 한 자기 행동을 보여 준다: 유효한 자기 기여는 재연 없이 보존. 근거가 없는 완료·수신·수락은 생성하지 않는다.
- 이미 끝난 선택 경로의 근거를 접수한다: 이미 유효하게 마친 본인 수행을 재연 없이 접수한다. 새 친구의 기억·보상권을 만들지 않는다.
- 현재 하던 일의 이유를 묻고 참여 여부는 따로 정한다: 실제 질문과 허락된 현재 답의 수신만. 질문하지 않은 행동·보고·침묵·먼저 하는 NPC 발언에 이 질문 수신을 공통 조건으로 붙이지 않는다. 이미 끝난 자기 결과는 보존한다.

B2: 정상: 플레이어가 허용된 가까운 길에서 실제 흔적을 살피고 확인한 위치·보이지 않은 구간을 구분해 돌아온다. 그동안 프리데리는 현재 함께 일하기로 한 마나위단과 망가진 물건을 고친다. 마나위단이 없으면 협업을 발명하지 않고 프리데리의 가능한 준비까지만 한다. 실제 수리와 상품 진열을 마친 당사자가 상점 문을 연다.
대안: 조사에서 실제 위험이 확인되면 그 범위를 프리데리에게 보고하고 더 나갈 준비·동행자 동의·귀환 수단을 별도로 마련한다. 준비되지 않은 사람은 현재 안전한 일터에 남는다. 현재 출발 가능한 경우만 추가 탐색을 시작하고 실제 돌아오기 전에는 귀환을 말하지 않는다.
경계 위반: 확인되지 않은 흔적을 확신인 듯 말하며 동행자를 불명 길로 밀어 넣으려 한다. 프리데리가 제안을 실제 들으면 중단하고 당사자 동의를 다시 묻는다. 실제 강행 피해는 그 범위만 남기며 실패를 구조 성취로 바꾸지 않는다.
- 합의한 정상 경로를 실제 수행한다: 제한 조사 보고와 실제 수리·진열·문 열기가 끝난 갈래에서만 상점이 재개된다. 실종자의 구출이나 귀환, 무료 상품은 없다.
- 다른 허용 경로 또는 보류를 선택한다: 준비된 추가 탐색은 별도 여정의 시작 또는 준비 상태다. 상점 문이 실제 열리지 않았다면 상점 재개 미완료이며 나중에 할 수리와 조사 결과를 보존한다.
- 경계를 어기는 제안을 하거나 실제 강행한다: 실제 해로운 제안/행동과 NPC가 안 범위만 실패·중단으로 남는다. 앞서 끝난 유효 행동은 보존하되 없는 성공·허락·보상은 주지 않는다.

B3: 프리데리는 실제 문이 열린 경우 손에서 열쇠를 내려놓고 다음 출발 전에 맡을 일을 마나위단과 나눈다. 미완료면 열쇠를 쥔 채 남은 수리만 짚는다. 실제 선택 경로의 근거만 확인하고 관계 결과와 보상별 자격·실제 제공은 분리한다.
- 정상 경로의 실제 결과를 마친다: 제한 조사 보고와 실제 수리·진열·문 열기가 끝난 갈래에서만 상점이 재개된다. 실종자의 구출이나 귀환, 무료 상품은 없다.
- 선택한 대안의 결과만 남긴다: 준비된 추가 탐색은 별도 여정의 시작 또는 준비 상태다. 상점 문이 실제 열리지 않았다면 상점 재개 미완료이며 나중에 할 수리와 조사 결과를 보존한다.
- 실패 또는 부분 결과를 남기고 돌아간다: 실제 끝난 몫 보존, 미완료와 필요한 정정·반환만 남음. 선택 후기 사양은 완료 취소 아님.

## 성격과 반응
가고 싶은 곳이 생기면 몸부터 움직이지만 붙잡는 말에는 멈춰 답을 듣는다. 떠날 채비를 마치고도 끈을 다시 묶으며 작은 물건이 손바닥에서 균형 잡히는 자리를 찾는다. 성급한 마음을 감추지는 않되 자신이 바라는 구출과 상대가 실제로 원하는 도움을 같다고 우기지 않는다.
조사 전: “거기까지라면 돌아와서 문도 열 수 있겠지.” 문 열기 뒤: “오늘은 열쇠를 여기 놓을게. 다음에 나갈 때도 맡을 일부터 정하자.”
초면/경계에는 현재 소유·의사를 먼저 확인하고, 실제 신뢰가 있으면 반대 의견과 독립 시도를 더 편히 묻는다. 친분은 수락·소유·보상·사적공개를 대신하지 않는다.

추가 서비스 없음. 선택 후기·현재 질문은 원 사건 재개방이나 보상 사건이 아니다.

## 지식·복구·구현
당사자별 실제 행동과 직접 관측, 허락 전언의 발신·수신을 분리한다. 후발자는 현재 공개 결과만 새로 배운다. 관계 후속은 실제 요청·허락·접촉·답·원요청자 수신이 있어야 반영하며 부재한 인물을 이동시키지 않는다.
사망·이탈·로그아웃 뒤 같은 원물과 이미 실행된 소비를 대조해 남은 부분만 재개한다. 선택 후기/지도/선물 거절로 완료 취소0. 상세 원분기·원문 완료·권리 및 개별 관계반응은 동명의 기획 JSON에 수록했다.
기본 블록배치·이동·제작·인벤 관측을 활용하는 기획이다. 장면의 하중·싹 상태·반사·향·비언어 검출 및 원장/수신은 신규 구현 요구이며 현 엔진 API나 테스트 성공 주장이 아니다.
생활 수행·선택의 실제 결과와 관찰/협력 숙련이 가치다. 원문 허용 현물·사용권·지도 외 전투 보상0. 플레이 예상은 정적 추정이며 실전 검증 아님. 반복서비스는 보상·경험치·호감 수치 농사로 쓰지 않는다.
