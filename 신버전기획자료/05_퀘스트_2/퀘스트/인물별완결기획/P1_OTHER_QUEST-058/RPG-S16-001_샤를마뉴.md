## 현행 해금과 조우

누군가 기존 출발점에서 열린 길의 목표점(경로거리 32블록 이상)을 실제 방문하고 같은 출발점 3블록 안으로 귀환하면 세계 해금. 전쟁·원정 생성·승리 조건 없음.

원문 최초접촉 현장: 기존 길의 귀환 지점이 보이는 쉼터. 행군 검토를 한다면 이미 존재하는 길만 살피며 새 원정·전쟁은 개시하지 않는다. 현재 조건: 해당 현장의 현재 열린 통행범위 16블록 안에 실제 도달한 사람이 일반 최초 접촉 후보이다. 원문 배치 제안의 지리와 적합 기존 부지·현재 접근·봉인·단일 본체·의사를 확인한다. 아래 SIDE layout은 수락 후 실제 수행 장소이며 일반 첫접촉 장소나 선행으로 강제하지 않는다. SIDE 물품·R/C 수행·개인 실적을 일반 접촉의 새 조건으로 요구하지 않는다.

한 명의 유효 달성으로 세계공통, 이후 현재 적격자 중 실제 1명 선정. 해금자와 달라도 됨. 단일 본체·전역 확률/주기/CAS는 공통 계약 참조.



## 현장

쉼터를 기준점 O로 두고 기존 낮은 길의 병목 A를 경로거리 12~32블록, 귀환점 B를 O의 3블록 안에서 고른다. 통행 폭 2블록·높이 2블록, 짐 회전자리 3×3블록을 실제 검사한다. 적합 길이 없으면 출발을 보류하고 새 왕성이나 주민을 만들지 않는다.



## 실제 수행

- B1 실제 귀환 요청자 전원을 UUID/현장 배우ID로 목록 N에 적는다. N은 현재 동의자 수인 양의 정수이며 예시 인원으로 제한하지 않는다. 각자의 귀환점·짐 품목/정수량·잔류 확인 방식·분배 품목/정수량을 명시 수락한다.

- B2 수락자가 A까지 직접 걸어 병목 바닥과 회전자리 두 지점을 8블록 이내 가시선에서 확인한 뒤 출발점으로 돌아와 실제 대상에게 경로를 알린다.

- B3 N 각자 실제 B의 2블록 안 도착 OR 현재 위치에서 직접 밝힌 자발 잔류를 기록한다. 동행 중 8블록 넘게 벌어지면 앞사람은 안전 지점에서 기다린다. 맡은 짐은 손 2블록 안 실인도하며 수령 증거를 남긴다.

- B4 샤를마뉴의 6블록 안 실제 청취에서 귀환/자발잔류/미확인을 읽어 주고 수신 확인을 받는다. 전원 확인이어야 성공. 미확인 한 명이라도 있으면 부분종료로 남는다. 나임 조언 인용은 실제 전달된 경우만.

- B5 선택 식량은 수락 때 허락한 품목별 수량 q와 실제 귀환 사용 후 남은 허락분 r 중 min(q,r)만 인도한다. 0이면 식량 없는 완료이며 재고를 생성하지 않는다. 다른 합의 식량도 허용한다.



## 완료와 부분결말

B1 수락 AND B2 현장답사 AND N 전원 귀환/직접 잔류 확인 AND 맡은 짐 인수 확인 AND B4 실제 보고 수신. B5 식량 수령 및 나임/롤랑 선택 후속은 필수 아님.



## 보상과 비용

허락 잔여 식량 분배 1회/실제 귀환 사건/수행자. 품목별 원합의량 이내이며 귀환 예비분·다른 사람 몫 제외. 반복 방문은 새 재고·권리를 만들지 않는다.

원문 합의 품목·양의 정수량은 offer에 품목별 {원소유자,현보유자,item_instance,수량,목적,수신자}로 동결한다. 다른 합의품목을 예시 하나로 제한하지 않는다. 물품 OR 행동 대가를 AND로 바꾸지 않는다. 실행 중 변경은 당사자 재동의와 revision으로 남기고 완료량을 소급 늘리지 않는다. 손실은 실제 드롭/소실 상태이며 퀘스트 재시작으로 복제하지 않는다.

event_uuid+참가UUID+권리종류 유일키. 완료→권리→제공예약→실인수 receipt를 분리한다. 실패/부분종료는 완료권리 없음. 이미 끝난 본작업은 선택 지도/수령 사양으로 되돌리지 않는다. 미수령은 보존; 재접속/FTB/반복 클릭은 재지급 안 함. 불명확 인벤 전달은 원장/실물을 대조한 뒤 누락분만 복구. 새 실제 요청 없는 반복은 관계대화만.

## 원래 선택 경로

### B1

현재 귀환 요청자에게 자기 도착점·동행 의사·짐 허락을 묻고 맡을 구간을 정한다. 제공자가 허락한 식량의 실재고·귀환 예비분·완료 뒤 남으면 나눌 종류와 수량을 수락 전에 함께 적는다.

- 전진희망 / 더 먼 성과를 제안한다 → END
  기존 길의 더 먼 굽이를 가리키되 귀환 여유와 허락을 아직 확인하지 못했다고 말한다.
  결과: 이번 먼 구간 제안은 보류하고 현재 귀환 목록은 유지한다. 수행 수락은 아직 없다. 현재 한정 구간을 맡고 싶으면 별도로 B1의 한정수락을 선택한다.

- 한정수락 / 확인 가능한 귀환 구간만 맡는다 → B2
  한 구간 답사와 실제 동행을 명시 수락한다.
  결과: 이번 SIDE 역할만 배정되고 아직 도착 성과 없음.

- 미수락 / 동행을 맡지 않는다 → END
  메모를 돌려주고 길을 비운다.
  결과: 일반 인사와 자기 길 관찰은 가능하다.

### B2

수락한 플레이어가 낮은 길의 좁아지는 부분까지 걸어 바닥·짐을 돌릴 공간·귀환 방향을 직접 확인한다. 샤를마뉴도 실제 동행 가능하고 수락했다면 같은 길을 걸으며 자기 시야 안 결과만 본다.

- 되돌림 / 위험이 커서 오늘 동행을 중단한다 → END
  본 구간을 기록하고 확보된 길로 돌아가 위험과 미실행을 알린다.
  결과: 동의자들이 출발한 것으로 처리되지 않는다.

- 이동준비 / 확인한 낮은 길로 동행을 준비한다 → B3
  갈림길에서 실제 출발 위치로 돌아가 대상에게 경로와 부담을 알린다.
  결과: 실제 통행 구간이 확정되고 아직 귀환은 미실행이다.

### B3

실제 동의자를 따라 걸으며 좁은 곳에서는 먼저 멈춰 짐 돌릴 공간을 비운다. 당사자가 귀환점에 닿는 것을 확인하고 짐은 주인에게 인계한다. 잔류를 고르면 현재 본인의 답과 위치만 기록하고 강제로 끌지 않는다.

- 귀환 / 실제 동행을 마치고 결과를 보고한다 → B4
  확인된 사람과 인수 짐을 가리키며 쉼터의 샤를마뉴에게 돌아간다.
  결과: 대상별 결과가 전언/직접으로 나뉘며 B4 보고 가능.

- 누락보고 / 미확인자를 남긴 채 현재 결과만 알린다 → B4
  안전한 귀환점으로 돌아가 확인된 명단과 못 본 구간을 구분해 보고한다.
  결과: 이미 도착한 사람·인수 짐은 유지된다.

- 중단 / 안전 지점에서 인계하고 그만둔다 → END
  맡은 짐만 허락받은 인수자에게 넘기고 미배정 역할을 알린 뒤 물러난다.
  결과: 실제 인계한 짐만 이동하며 새 개인 완료 없음.

### B4

귀환·잔류·미확인 세 칸을 읽어 주고 왕의 약속 범위와 대조한다. 나임의 실제 조언이 있으면 정확히 인용한다. 없으면 직접 관측을 근거로 쓰며 다음에 나임의 신중한 관점을 듣겠다는 의향만 남긴다.

- 떠넘김 / 미귀환자를 비겁하다고 평가한다 → END
  평가를 덧붙여 말하지만 직접 들은 이유가 없음을 확인한다.
  결과: 사실 보고는 보존하고 없는 내면은 삭제한다. 미확인은 완료가 아니다.

- 책임보고 / 정확한 결과로 약속을 검토한다 → B5
  본인이 맡은 범위와 관측만 읽고 빠진 것은 미달로 남긴다.
  결과: 합의 범위의 SIDE가 성립한다. 실제 남은 허락 재고를 확인했으므로 B5에서 수령 여부와 실인계를 따로 처리한다.

- 여기까지 / 완료 보고 후 분배를 받지 않는다 → END
  식량 수령은 사양하고 자기 짐을 챙긴다.
  결과: SIDE 완료는 유지. 미수령 권리만 보존하거나 명시 포기하면 종료한다.

- 미달보존 / 미확인 항목을 남기고 오늘 보고를 마친다 → END
  확인한 사람·짐만 보고하고 미확인 사유를 지어 쓰지 않는다.
  결과: 부분 귀환은 보존하고 남은 항목만 재개 가능하다.

### B5

제공자가 B1에서 허락한 품목·수량과 실제 남은 재고를 대조해 귀환에 쓰지 않은 몫만 직접 건넨다. 플레이어는 받을 공간을 마련하고 받은 양을 확인한다.

- 수령 / 남은 허락 몫을 받는다 → END
  합의 몫 중 실제 남은 수량을 받아 지급 기록과 대조한다.
  결과: 받은 분량만 실지급. 먹는 것은 이후 실제 소비다.

- 나중 / 수령을 미룬다 → END
  미수령량과 보관자를 확인하고 떠난다.
  결과: 미수령만 저장, 중복 지급 없음.



## 중단·친구·지식

마감 없음. 사망·로그아웃·자발중단은 현재 위치, 원물, 실제 소비/인수/청중, 수행증거, 미완료 항목을 저장한다. 진행 중 실전은 시간정지 안 함. 복귀시 현재 안전·단일 본체·의사·대여품 상태를 재확인하고 남은 일만 잇는다. 실제 사망/드롭 규칙을 적용하고 NPC 과거 전승으로 현재 사망·부활을 선언하지 않는다.
