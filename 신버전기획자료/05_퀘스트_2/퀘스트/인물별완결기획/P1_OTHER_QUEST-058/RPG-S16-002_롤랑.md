# 롤랑 — 부르기 전에 정한 한계



완결 저술 기획. 실제 구현·게임 시험 완료를 뜻하지 않는다. 공통 계약을 함께 적용한다.



## 인물과 범위

롤랑. 힘있게 다짐하지만 함께 선 사람의 귀환도 짊어지는 영웅.

## 현행 해금과 조우

기존 조기접근은 유지한다. 역사 H1 OR H2를 이번 일반 보충 해금으로 채택: 실제 위험에서 지원 신호를 보내고 동의한 동료의 귀환을 직접 도운 이력 OR 아서가 실제 기록/현재 동의를 바탕으로 책임 면담을 소개하고 소개 대상이 수신한 이력. 한 명 달성으로 세계공통. 기존 접근에 새 H를 추가하지 않는다.

원문 최초접촉 현장: 기존 피난 기록이 가리키는 길과 현재 걸을 수 있는 길이 갈라지는 낮은 언덕. 현재 조건: 해당 현장의 현재 열린 통행범위 16블록 안에 실제 도달한 사람이 일반 최초 접촉 후보이다. 원문 배치 제안의 지리와 적합 기존 부지·현재 접근·봉인·단일 본체·의사를 확인한다. 아래 SIDE layout은 수락 후 실제 수행 장소이며 일반 첫접촉 장소나 선행으로 강제하지 않는다. SIDE 물품·R/C 수행·개인 실적을 일반 접촉의 새 조건으로 요구하지 않는다.

한 명의 유효 달성으로 세계공통, 이후 현재 적격자 중 실제 1명 선정. 해금자와 달라도 됨. 단일 본체·전역 확률/주기/CAS는 공통 계약 참조.



## 현장

기존 회랑의 안전 대기점 O, 지원선 A는 O에서 8블록, 시야가 끊기는 굽이 G는 A보다 4블록 이상 앞. 실전 C14 원전장은 변경하지 않고 해당 지형 안에서 안전선만 합의한다. 대련은 별도 9×9블록 평지에 중심선·후퇴선 간격 4블록을 둔다.



## 실제 수행

- B1 O와 A를 걸어 확인하고 실제 위협 대응 OR 현재 호위 OR 제한 대련 중 하나를 고른다. C14 실전은 C10 AND C11 및 현재 적 상태가 있을 때만 사용한다. 끝난 적은 생성하지 않는다.

- B2 실전은 실제 현존 적을 엄폐 방향으로 유도하며 A에서 롤랑이 추격을 끊는다. 호위는 동의한 현재 일행이 정한 끝점에 닿고 교대를 요청한다. 대련은 느린 접근 1회를 받아낸 뒤 선에서 정지한다. 모든 경로에서 롤랑이 실제 지원 신호를 발신하고 참가자는 수신 여부를 기록한다.

- B3 실제 O 2블록 안 귀환 후 6블록 안 대화로 멈춤·신호·응답/무응답을 대조한다. 지원자 부재는 거절/무응답으로 남겨도 철수 성공 가능. 롤랑 자신의 필수 신호 부재 또는 미귀환은 부분종료.

- B4 선택 지도는 4블록 엄호구간에서 느린 접근 1회, 방패 뒤 2블록 폭 탈출공간을 남기고 실제 멈춤·피드백을 받는다. 빌린 일반 방패만 원주인에게 실반환한다.



## 완료와 부분결말

합의 형태 하나에서 실제 멈춤 AND 롤랑 신호 발신 AND 귀환 AND B3 결과 대조. 지원자 답은 있으면 실제 인용, 없으면 무응답 허용. B4 선택 지도는 분리.



## 보상과 비용

엄호 자세 지도 1회/현재 수행 사건/실제 수행자. 일반 방패 대여는 소유권 이전·신규 장비보상이 아니다. 스탯·가호·독립 스킬 없음.

원문 합의 품목·양의 정수량은 offer에 품목별 {원소유자,현보유자,item_instance,수량,목적,수신자}로 동결한다. 다른 합의품목을 예시 하나로 제한하지 않는다. 물품 OR 행동 대가를 AND로 바꾸지 않는다. 실행 중 변경은 당사자 재동의와 revision으로 남기고 완료량을 소급 늘리지 않는다. 손실은 실제 드롭/소실 상태이며 퀘스트 재시작으로 복제하지 않는다.

event_uuid+참가UUID+권리종류 유일키. 완료→권리→제공예약→실인수 receipt를 분리한다. 실패/부분종료는 완료권리 없음. 이미 끝난 본작업은 선택 지도/수령 사양으로 되돌리지 않는다. 미수령은 보존; 재접속/FTB/반복 클릭은 재지급 안 함. 불명확 인벤 전달은 원장/실물을 대조한 뒤 누락분만 복구. 새 실제 요청 없는 반복은 관계대화만.



## 인물의 말과 실력 판단

- 초면: “내 뒤를 따라오기만 하지는 마. 네가 멈출 선을 말해.”

- 실제 신호에 응답한 동료: “이번에는 먼저 불렀다. 네가 들었는지 확인하고 싶다.”

- 힘을 보였더라도 동료의 체력·겁을 안다고 단정하지 않는다.



## 대련·전투 실행과 연출

### 적용
합의 대련/방패 실습만의 새 구현 요구. 실전 C/R 전투의 HP·방어·전리품·기믹·시도ID는 현재 본편 정의 그대로이며 이 훈련으로 무적·딜우회·승리 대체 없음.

### 준비
평지9×9·높이3, 출입/항복구역2×2, 비참가자와 거리를 3블록 이상 둔다. 무기 손질/방패 현내구·현재 체력/상태·퇴로를 확인한다. 참가자 양쪽 명시동의 후 60tick 준비. 실제 적/민간인이 들어오면 훈련 즉시 중단. 재준비는 위험 해소 후 새 동의.

### 타점
느린 접근 1회: 출발 3블록 앞, 0.1블록/tick로 20tick 이동하여 1블록 전방에 정지. 공격 준비20tick→활성2tick→회복20tick. 수평 전방 폭0.8·높이1.2·깊이1.5블록의 실제 스윕이며 몸 중심 y+0.9, 최대도달2블록. 앞 고체벽 raycast가 먼저 닿으면 판정 종료. 한 시도 한 대상 한 접촉; 뒤·옆·벽너머·친구·관전자·다부위 보스 접촉 점수 없음.

### 방패
활성시 방패방향 전방90도 안의 실제 접근 접촉 및 방패사용 상태를 동시에 만족해야 막음. 늦은 방패·등 돌림은 실패 기록. 훈련은 HP피해/넉백/내구소모0의 모의 접촉으로 실제 장비 공격을 가로채는 별도 구현; HP무적 버프를 주지 않는다. 외부 실전 공격은 정상처리하고 훈련을 중단한다. 실패해도 세계 전투력/등급을 깎지 않는다.

### 연출
시작은 목검/방패 실제 모형을 들고 상체를 낮춤→손·팔 궤적이 판정폭 안에서 이동→접촉에 작은 흰 선 0.3블록과 나무 탁 소리 8블록→회복시 팔을 내려 잔상 4tick 뒤 소멸. 경계는 바닥 표식이고 기믹을 가리는 파티클 없음. 실제 공격무기/SS 고유효과는 상속하지 않는다. 모형/들기·막기·멈춤 애니메이션·접촉음 자산 필요. 작은 큐브 투사체로 대체하지 않는다.

### 중단회복
그만/항복 버튼·합의 음성신호·경계이탈·접속끊김·실제 피해 즉시 활성 모의판정 취소. 합의 상대는 정지, 실제 적은 정지하지 않는다. 실제 회복은 원래 음식/회복 규칙만, HP복구0. 재시도 40tick 회복+현재 동의; 한 정상 동작으로 충분하며 승수파밍 없음.

### 회수귀속

## 원래 선택 경로

### B1

서로 보이는 지원점과 뒤의 대기점을 실제 걸어 확인한다. 롤랑은 “저 굽이를 넘으면 뒤를 못 본다. 그 전에 부르겠다”라고 한계를 밝힌다. 플레이어는 자신의 유인/엄호/호위 몫과 중단 신호에 명시 동의한다.

- 보류 / 싸움도 대련도 맡지 않는다 → END
  회랑 밖 안전 위치로 물러나거나 현재 길 정보만 남긴다.
  결과: 일반 대화와 관측은 잠기지 않는다.

- 실전 / 현재 위협에서 정한 선까지 대응한다 → B2
  현재 적과 민간 회랑을 구별하고 한계를 다시 짚어 실제 대응 위치로 이동한다.
  결과: 전투 준비만 성립, 적 제압·지원은 아직 없다.

- 안전확인 / 현재 호위 또는 합의 대련으로 멈춤을 확인한다 → B2
  현재 호위면 이동 끝점, 대련이면 비통행 평지·중단 신호·장비를 정하고 명시 수락한다.
  결과: 지난 약탈대 전투와 별개인 현재 수행이 정해진다.

### B2

실전이면 플레이어는 앞의 실제 적을 보이는 엄폐 쪽으로 유인하고 롤랑은 뒤를 보며 정한 선에서 추격을 끊고 직접 지원 신호를 낸다. 호위면 실제 일행과 정한 끝점에서 멈추어 교대를 요청한다. 대련이면 합의한 접근 한 번을 받아내다가 선에서 멈추고 신호를 낸다.

- 추격 / 더 따라가려다가 한계를 재판단한다 → END
  선 밖 추격을 고집하면 플레이어는 따라가지 않겠다고 말하고 확보한 대기점으로 후퇴한다. 롤랑의 실제 움직임과 위험은 별도 확인한다.
  결과: 멈춤·신호가 실제 없으면 목표는 미완료. 돌아온 것만 보존한다.

- 신호 / 정한 선에서 멈추고 지원을 청한다 → B3
  추격/접근을 끊고 몸을 대기점 쪽으로 돌린 뒤 롤랑의 실제 신호와 자기 응답 여부를 확인하며 철수한다.
  결과: 지원 요청은 발생. 응답자는 아직 실제 답이 있을 때만 센다.

- 중단 / 안전 신호로 현재 수행을 끊는다 → B3
  실제 중단 신호를 내고 안전 퇴로로 물러난다. 대련 상대는 즉시 공격을 멈추며 실제 적은 동의 없이 멈추지 않는다.
  결과: 실제 귀환과 재대면이 성립하여 B3에서 멈춤·신호의 충족 여부를 대조한다. 롤랑의 필수 신호가 없었다면 B3 미확인으로 끝나며 단순 취소는 완료가 아니다.

- 귀환미확인 / 중단 뒤 아직 대기점으로 돌아오지 못했다 → END
  현재 안전 위치·남은 위험·신호 발신·피해만 저장하고 가능한 퇴로를 쓴다.
  결과: 부분 행동만 보존하며 B3 결과 면담이나 SIDE 완료는 없다.

### B3

응답한 지원자가 있으면 그가 실제 한 역할과 직접 밝힌 사유를 듣는다. 응답자가 없으면 확보된 퇴로로 돌아온 사실과 무응답만 보고한다. 롤랑이 두려워한 실망과 실제 발언을 구별한다.

- 사실 / 응답과 불안을 구별해 끝낸다 → END
  지원자의 직접 말을 인용하거나 무응답을 미수신으로 남긴다.
  결과: SIDE 수행 성립. 지원 없었어도 실제 철수 성공은 유지하며 원 전투 승리는 별도다.

- 지도 / 완료 뒤 짧은 엄호 지도를 원한다 → B4
  지도는 새 선택임을 알고 안전 자리로 이동한다.
  결과: SIDE 완료 상태는 유지하고 지도만 아직 미수행이다.

- 미확인 / 돌아오지 못한 항목을 남긴다 → END
  모르는 동료 반응을 꾸미지 않고 현재 안전 위치와 미완료 항목을 남긴다.
  결과: 기존 기여 보존·필수 항목 미완료.

### B4

롤랑이 일반 방패를 실제 소유자 허락으로 빌려 줄 수 있으면 대여를 기록하고, 없으면 자기 장비로 무리 없는 자세를 본다. 서로 선을 정해 한 번의 느린 접근에 방패를 세우고 옆 동료가 빠질 공간을 남긴다.

- 실습 / 엄호 자세를 직접 해 본다 → END
  느린 접근을 한 번 받아내고 상대가 빠질 공간을 확인한 뒤 멈춘다. 실제 빌린 장비만 반환한다.
  결과: 지도 수신과 실습만 기록하며 능력치·기술 ID 자동 부여 없음.

- 그만 / 지도만 듣거나 여기서 마친다 → END
  동작을 멈추고 실제 대여품이 있으면 소유자에게 반환한다.
  결과: 이미 완료한 SIDE와 들은 설명은 유지.



## 중단·친구·지식

마감 없음. 사망·로그아웃·자발중단은 현재 위치, 원물, 실제 소비/인수/청중, 수행증거, 미완료 항목을 저장한다. 진행 중 실전은 시간정지 안 함. 복귀시 현재 안전·단일 본체·의사·대여품 상태를 재확인하고 남은 일만 잇는다. 실제 사망/드롭 규칙을 적용하고 NPC 과거 전승으로 현재 사망·부활을 선언하지 않는다.
