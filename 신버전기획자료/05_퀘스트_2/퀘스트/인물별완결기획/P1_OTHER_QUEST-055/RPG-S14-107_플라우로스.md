# 플라우로스 — 질문을 바꿔 도망치지 않기

관리키 RPG-S14-107 · 정의 EP037A-RPG-S14-107 · 상급 · SIDE / 신규 MAIN 없음

정확한 답을 요구한 자가 불편한 결론 앞에서 질문을 바꾸는 순간을 놓치지 않는 추궁자다. 직설적이고 인내심이 짧다. 같은 질문에 다른 말로 도망가면 원래 질문을 더 짧게 돌려준다.

## 현재 요청
자기에게 답을 청한 상대가 그 답의 불편함까지 떠안게 하고 싶다.

## 실제 수행
1. 실제 열람 허락을 받은 물증 1건과 처음 책임 질문 1개를 기존 안전 대조 자리에 둔다. 물증의 식별 흔적·위치를 손2블록 또는 8블록 관측 시야로 확인하고, 본인의 기억과 관측을 구별해 말한다. 단탈리온 기억 기록은 실제 열람·전달 허락이 있을 때만 자료가 된다.
2. 원래 질문과 불리한 근거를 유지해 실제 오류를 판별한다. 잘못 옮긴 물품이 확인되면 원소유자에게 해당 실물 전량을 반환·인수한다. 잘못 전달한 말이 확인되면 실제 원 수신자에게 정정하고 각 수신 여부를 확인한다. 두 오류가 모두 있으면 둘 다 처리하고 하나만 있으면 해당 행위만 처리한다.
3. 플라우로스에게 실제 반환 영수증과 정정 수신 범위를 보여 준다. 오류가 근거상 확인되지 않으면 미확인으로 남기고 없는 반환/사과를 만들지 않는다. 현재 합의한 실제 피해 수습이 있으면 수행 여부도 별도 기록하고 장기 피해가 모두 없어진 것으로 말하지 않는다.

## 완료와 갈림길
실제 질문/물증 비교와 확인된 오류별 반환·정정 수신을 마쳐야 그 책임 이행 완료. 오류 부재/미확인은 조사 결과로 남기고 허구의 책임을 만들지 않는다. 필수 정정 미수신·반환 미인수는 부분, 무보상 유지.

- 불리한 답에 질문을 바꾸면 원질문/새질문을 나누고 아직 다루지 않은 책임을 보존한다.
- 복구 거절은 이미 끝난 반환만 유지하고 피해·미수신 의무를 남긴다. 플라우로스가 실제 회피를 인지한 범위만 해당 관계 적대이며 공격 자동 실행 없음.

## 말과 반응
- 제안: “그건 새 질문이다. 처음 질문부터 끝내.”
- 기억이 불분명하다고 하면: “모른다는 자리는 놔둬. 아는 흔적까지 덮지 말고.”
- 대답만 적고 떠나려 하면: “종이는 돌려받았군. 물건 주인은 받았나?”

## 보상과 선택 수령
별도 보상0. 반환품은 원주인에게 돌려주는 원물이며 수행자 전리품이 아니다. 단탈리온 기록 열람권·범인 판결·평판 전체 복구 없음.

정상 사건별 실제 수행자 최초1회. 같은 사건 재개는 미수령/미지도 잔여만. 새 사건을 자동 발생시키지 않는다.

## 중단·재개·지식
공통실행계약의 체크포인트, 원물 장부, 영수증 대조, 실제 청중 규칙을 적용한다. 미수신을 수신으로 만들지 않고 완료한 행동을 재연하지 않는다.
플라우로스는 책임을 회피한 상대에 적대를 남길 수 있다. 정정해도 남은 피해·모르는 진실은 지워지지 않는다.

## 구현과 예상
공통 권위 동작·소품·원물·응답 저장 연결. 새 전투 시스템 없음.
예상 8~14분. 실제 API·게임·LLM 시험은 하지 않은 기획값이다. 지도는 비전투 경험이며 전투 능력 보상이 아니다.
