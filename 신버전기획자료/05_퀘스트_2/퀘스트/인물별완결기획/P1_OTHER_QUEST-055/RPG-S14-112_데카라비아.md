# 데카라비아 — 닮은 깃의 다른 자리

관리키 RPG-S14-112 · 정의 EP037A-RPG-S14-112 · 하급 · SIDE / 신규 MAIN 없음

닮은 것들을 같은 이름으로 덮는 순간을 놓치지 않고 자신의 세밀한 눈을 자랑하고 싶어 한다. 조용히 단서를 하나씩 내민다. 성급한 동일시에 날카롭고 작은 차이를 발견한 사람에게는 기뻐한다.

## 현재 요청
생물과 표본의 닮은 겉모습 뒤에서 서로 다른 피해와 쓰임을 밝혀내고 싶다.

## 실제 수행
1. 실제 허락된 떨어진 흔적 1개와 현재 표본 1개를 접촉 인수/열람해 모양을 비교한다. 살아 있는 생물·둥지는 손대지 않는다. 둥지/서식 흔적이 실제 있는 안전 가장자리 6~12블록 시야에서 훼손 방향·밟힌 지면·관측 시점을 30초 동안 살핀다. 특정 새/깃털이 없는 네더에 그것을 자동 생성하지 않는다.
2. 닮은 특징 1개와 다른 피해/형태 근거 1개 또는 구분 불가를 기록한다. 자기 장애물이 실제 해롭다는 근거가 있으면 원위치·영향·이동 위치를 합의하여 해당 장애물만 옮긴다. 남의 장애물은 소유자 허락 없이 손대지 않는다. 자기 해로운 장애물이 없으면 없다고 남기고 이동 목표를 생성하지 않는다.
3. 장애물을 옮겼다면 같은 시야에서 실제 30초 후속 관찰을 하고 전후 차이/무변화를 기록한다. 이동 대상이 없을 때도 실제 예외와 미분류를 제출한다. 데카라비아가 직접 본 것과 보고받은 것을 구별해 확인한다. 로그아웃 시간은 관찰초로 세지 않는다.

## 완료와 갈림길
실제 흔적 비교·예외 관찰 AND (자기 해로운 장애물 없음 OR 허락 이동·후속 관찰)이 정상. 정확한 이름 미확정도 가능. 장애물 부재와 관찰 자체 부재를 혼동하지 않는다. 표본 수령·지도는 선택.

- 생물 포획/상처는 즉시 중지·안전 해제·피해 기록, 정상 관찰 성취 아님.
- 예외를 지우면 원 관측을 복원해 안내를 중지한다. 실제 둥지 피해는 분류명 정정만으로 소멸하지 않는다.

## 말과 반응
- 제안: “닮은 윤곽 말고, 이쪽 자국부터 보겠나.”
- 구분 불가를 인정하면: “이름 하나를 덜 붙였군. 대신 차이 하나는 남았어.”
- 작은 차이를 직접 발견하면 조용히 기뻐하며 두 표본을 따로 돌려 보여 준다.

## 보상과 선택 수령
분류 지도 1회와 허용된 실제 떨어진 표본 몫. 기본 제공 제안 1개, 다른 실제 허락 정수량 q는 보존하며 q≤허용 현재고. 본인 이미 채집분은 새 지급0. 지도는 닮은 점/피해 근거를 직접 짚어 피드백 수신. 생물 소유/복원 효과0.

## 중단·재개·지식
공통실행계약의 체크포인트, 원물 장부, 영수증 대조, 실제 청중 규칙을 적용한다. 미수신을 수신으로 만들지 않고 완료한 행동을 재연하지 않는다.
데카라비아는 이름보다 구별의 근거를 기억한다. 생물 전부의 속내나 세계 전체 생태를 아는 결과는 없다. 예외를 지우면 그 분류를 다음 안내에서 쓰지 못하며 장애물을 그대로 둔 둥지의 피해도 남는다.
