# 자간 — 빛나는 금속으로 낸 품삯

관리키 RPG-S14-106 · 정의 EP037A-RPG-S14-106 · 상급 · SIDE / 신규 MAIN 없음

금속의 번쩍임보다 모두가 같은 값을 믿게 만드는 힘을 자기 영향력으로 여기려 한다. 여유롭게 값을 부르다가 노동의 몫이 나오면 계산을 세밀하게 한다. 탐욕을 숨기기보다 상호 의존을 들이민다.

## 현재 요청
변환 금속을 거래할 때 사람들이 믿고 주고받을 값의 기준을 자기 방식으로 세우고 싶다.

## 실제 수행
1. 현재 실제 노동 대가 채권자와 지급 의무자, 실험 금속 소유자를 확인한다. 기존 임금의 품목·정수량 W와 시작 시 이미 인수한 양 P0를 영수증으로 확정한다. W는 합의version에 고정하고, 현재 인수 누계 P는 P0에서 시작해 실제 신규 인수 영수증마다 한 번만 갱신한다. 신규 거래 기본 제안은 공개된 가공 구리 2개와 상대가 요구한 철 1개의 교환이지만 기존 임금·적법 대체재·정수량 합의를 덮지 않는다. 각 당사자가 질감·흠집·용도를 손2블록에서 실제 확인한다.
2. 받는 사람이 금속을 대가로 명시 수락한 경우만 실제 교환·인수한다. 거절하면 실험 금속을 원소유자에게 남기고 기존 합의 대가를 별도 인도한다. 각 실제 인수 뒤 해당 채무 항목의 P를 갱신하고, 부족분은 갱신된 W-P만 장부에 남긴다. 다른 금속으로 대체할 때는 당사자가 실제 합의한 대체 품목·정수량과 원채무 소멸량을 같은 version에 결속한다. 구리 개수와 철 개수를 임의로 같은 단위로 빼지 않는다. 금속을 보여 주거나 바닥에 내려놓기만 한 것은 지급이 아니다.
3. 부족분을 자기 소유·사용 허락 자원으로 실제 보충하고 채권자 인수를 확인한다. 처음부터 정상 지급이면 새 채무/추가납품을 만들지 않고 기존 영수증을 대조한다. 지급할 자원이 없으면 거래를 중지하고 미지급과 현재 당사자 응답을 자간에게 보고한다. 다음 거래는 배상된 범위와 새 동의를 따로 확인한다.

## 완료와 갈림길
합의된 교환과 실제 부족분 인수만큼만 이행. 전체 정상 마감은 해당 합의의 미인수0과 당사자 확인이 필요하다. 미지급 정직 마감은 미결이며 퀘스트 실패/중단이 기존 채권을 삭제하지 않는다. 지급과 지도/친분은 별개다.

- 동의 없는 반짝이는 금속을 완료 지급이라 주장하면 수신자에게 미합의·부족분 정정. 금속 소유 이전을 말로 만들지 않는다.
- 미합의 손실을 노동자 몫에서 공제하면 실제 공제를 되돌려 채권에 반영하고 손실의 책임은 별도. 사과 한마디로 실제 인수를 만들지 않는다.

## 말과 반응
- 제안: “빛은 내 금속에 있지. 받아 쓸 이유는 그쪽 손에 있고. 둘 다 계산해 보자.”
- 값을 깎으려는 말에는 여유롭게: “네 시간이 싸다면 내 계산도 쉬웠겠지. 일한 몫은 얼마였나?”
- 부족 인정 뒤: “그만큼은 아직 네 빚이다. 솔직하다고 공짜가 되는 건 아니지.”

## 보상과 선택 수령
실제 합의된 재료 거래 몫과 기존 노동 대가만. 정수량 W·P·미지급을 품목별 유지하고 P≤W, 인수 누계≤권리량. 보상으로 새 금속/화폐 생성0. 지급 의무는 SIDE 수락·정상 성공과 무관하며 다음 거래 자동 개방/하겐티 승인0.

정상 사건별 실제 수행자 최초1회. 같은 사건 재개는 미수령/미지도 잔여만. 새 사건을 자동 발생시키지 않는다.

## 중단·재개·지식
공통실행계약의 체크포인트, 원물 장부, 영수증 대조, 실제 청중 규칙을 적용한다. 미수신을 수신으로 만들지 않고 완료한 행동을 재연하지 않는다.
자간은 배상된 실제 범위에서만 거래를 다시 열 수 있다. 새 통화·무한 금 생산·시장 전체 안정은 없다.

## 구현과 예상
품목별 채무·교환의 양방향 인도/인수와 합의version을 분리한다. 물품 대가와 노동 대가를 하나의 퀘스트 토큰으로 치환하지 않는다.
예상 7~12분. 실제 API·게임·LLM 시험은 하지 않은 기획값이다. 지도는 비전투 경험이며 전투 능력 보상이 아니다.
