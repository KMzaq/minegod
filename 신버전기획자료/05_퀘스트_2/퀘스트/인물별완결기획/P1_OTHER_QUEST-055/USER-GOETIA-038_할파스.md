관리키 USER-GOETIA-038 · 정의 EP037B-USER-GOETIA-038 · 상급 · SIDE / 신규 MAIN 없음

화려한 돌격의 공보다 준비한 것이 끝까지 버티는 공을 자기 몫으로 가져오고 싶어 한다. 말수가 적고 숫자를 크게 자랑하지 않는다. 준비를 하찮게 말하면 투박한 질문을 연달아 던진다.

## 현재 요청
방어 준비를 청하는 상대가 비축과 배치의 중요성을 인정하고 자신의 판단을 먼저 구하게 만들고 싶다.

## 실제 수행
1. 실제 현재 적대 위협과 방어할 기존 길목을 확인한 뒤 SIDE를 수락한다. 기본 배치는 12블록 길목과 뒤쪽 8블록의 안전 퇴로다. 실제 위협이 없으면 일반 대화·준비 검토만 가능하고 방어 수행으로 세지 않는다. 현존 적을 퀘스트 때문에 증식/강제 적대시키지 않는다.
2. 자기 탄약·회복품과 사용 허락 예비품의 품목별 정수량 N을 실제 센다. 기본 제안은 화살8개와 식량2개를 정면/퇴로에 절반씩 두는 것이지만 보유 방식·대체품·합의된 다른 정수량을 보존한다. 부족하면 감당할 짧은 방어 범위를 실제로 줄인다. 기존 보관 위치는 플레이어가 걸어 닿을 수 있어야 하며 가상 보급 메뉴로 원거리 전송하지 않는다.
3. 합의 구간의 실제 소규모 방어에 참여한다. 각자 실제 공격·경고/시야 감시·탄약 인계·동료 퇴로 확보 중 맡은 역할로 적 접근에 대응한 증거를 남긴다. 실제 전투 중 안전 철수도 가능하며 승리는 적의 실제 이탈/제압 결과만이다. 전투 전 철수는 준비 부분, 전투 참여 후 패전·철수는 패전 그대로 정직한 작업 완료가 가능하다.
4. 안전 귀환 뒤 자기/빌린 몫의 소비·손실·잔여를 대조하고 빌린 잔여 전량을 원소유자에게 실제 반환·인수한다. 누가 준비·보급했는지 할파스가 실제 수신한다. 남은 위협에 다시 싸울지는 새 동의·준비로 결정하며 재전투는 완료 필수 아님.

## 완료와 갈림길
실제 준비·방어 참여·안전 귀환·소비 대조·남의 잔여 실반환·정직한 기여 확인이 모두 필수. 실제 패전 후 책임 철수는 정직한 완료 가능, 준비만/전투전 철수는 지도권0. 실제 방어를 말이나 30초 대기로 대체하지 않는다.

- 정면에만 몰아두어 실제 접근이 끊겼으면 못 쓴 물자/손실과 철수를 기록. 접근이 끊기지 않았다면 실패를 강제하지 않는다.
- 보급 공로 은폐는 다음 배치 조언 거절 사유. 남의 잔여 반환 의무는 조언 거절과 별개이며 지도 성공으로 넘기지 않는다.
