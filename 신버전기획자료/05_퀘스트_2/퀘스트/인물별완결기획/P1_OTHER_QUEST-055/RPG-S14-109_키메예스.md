# 키메예스 — 휴전문을 따라 걷기

관리키 RPG-S14-109 · 정의 EP037A-RPG-S14-109 · 중급 · SIDE / 신규 MAIN 없음

모호한 말로 우위를 얻으려는 자에게 그 모호함을 되돌려 주는 날카로운 문법가다. 짧은 조롱 뒤 정확한 대안을 준다. 의미 없는 장황함에는 마지막 문장부터 잘라 묻는다.

## 현재 요청
휴전의 문장에 숨어 있는 일방적 빠져나갈 길을 찾아 자기 기술의 효용을 보이고 싶다.

## 실제 수행
1. 실제 동의한 대련 참가자 2명을 확인한다. 친구가 없으면 현재 참여·동의 가능한 기존 NPC를 사용할 수 있으나 임의 대역 생성은 하지 않는다. 기존 안전 지면 8×8과 각자 물러날 3블록을 확보하고 사용하는 무기/동작·중지 구호·동의 철회권을 함께 읽는다. 기본은 비공격 휴지 동작부터이며 장비 피해는 현재 정의 그대로다.
2. 한쪽이 “멈춤”을 실제 말하면 양쪽이 무기를 비활성 슬롯으로 내리고 상대 반대 방향으로 3블록 물러난다. 역할을 바꿔 1회씩 실행한다. 서로 다른 해석 1곳 또는 모호할 수 있는 항목을 고쳐 행위자·신호·중지 순서를 양쪽이 같은 뜻으로 읽는다.
3. 양쪽 새 동의를 받고 짧은 재연습을 한다. 기본은 10초 이내 움직임과 각자 최대1회의 합의한 대련 공격 후 즉시 고친 휴지 동작 실행이며 실제 피해·내구는 남는다. 안전 여유가 부족하면 공격 전에 중단하고 재연습 미완으로 둔다. 먼저 재개를 제안할 사람과 상대의 응답 신호를 확인한다. 이후 실제 대련 재개는 선택이며 양쪽 새 신호가 있어야 한다.

## 완료와 갈림길
두 실제 참가자의 휴지 역할 교대·문장 수정·짧은 재연습·재개 방법 확인이 모두 있어야 지도권. 실제 재개나 지도 수강은 선행 아님. 재연습 전 재개 거절은 정당한 종료/부분 성과로 보존한다.

- 상대만 멈추게 하고 공격하거나 재개 동의 없이 공격하면 실제 피해를 남기고 종료. 사과로 피해/동의 복구0.
- 훈련 중 실제 몬스터 공격은 상호 동의 요구 대상이 아니며 안전 대처 뒤 미완 단계만 재개한다.

## 말과 반응
- 제안: “주어가 둘인데 멈추는 발은 하나군. 좋은 문장인가?”
- 장황한 변명에는: “마지막 말만 남겨 보자. 누가, 언제 멈추지?”
- 양쪽이 실제 멈춘 뒤: “이제 그 문장이 입 밖에서도 읽히는군.”

## 보상과 선택 수령
실제 완수 참가자 각자 행동 조건 문법 지도 1회. 본인이 행위자·중지·재개 조건을 다시 쓰고 상대가 같은 뜻으로 읽어 키메예스 피드백을 받는다. 친구의 성공을 다른 참가자에게 복사0. 무기/스킬/휴전 강제효과 없음.

정상 사건별 실제 수행자 최초1회. 같은 사건 재개는 미수령/미지도 잔여만. 새 사건을 자동 발생시키지 않는다.

## 중단·재개·지식
공통실행계약의 체크포인트, 원물 장부, 영수증 대조, 실제 청중 규칙을 적용한다. 미수신을 수신으로 만들지 않고 완료한 행동을 재연하지 않는다.
키메예스는 문법이 실제 행동을 바꾼 결과를 얻는다. 위반 뒤 피해는 남고 재연습 동의 전 대련을 자동 재개하지 않는다.

## 친구와 후발자
