# 발라크 — 보물 상자 밖의 흔적

관리키 USER-GOETIA-062 · 정의 EP037B-USER-GOETIA-062 · 중급 · SIDE / 신규 MAIN 없음

남이 지나친 자리에서 가치 있는 단서를 먼저 찾아 발견의 공을 갖고 싶어 하는 호기심 많은 탐색자다. 호기심이 앞서 질문이 빠르다. 무시당하면 토라지지만 실제 단서를 알아봐 주면 설명이 길어진다.

## 현재 요청
보물을 찾는 상대에게 마지막 물건보다 놓친 단서의 가치를 인정받고 싶다.

## 실제 수행
1. 소유자가 열람 허락한 실제 빈 상자 1개와 바깥 긁힌 돌/끈 흔적을 확인한다. 상자 인벤토리를 실제 열어 빈 상태를 본 때만 빈 안쪽 관측으로 기록한다. 바깥 흔적은 6블록 이내 시야에서 살피며 상자 파괴는 필요 없다.
2. 현재 허용된 16~24블록의 짧은 구간까지만 긁힘과 끈의 연결을 실제 따라가 발견물 또는 실제 끊김을 확인하고 돌아온다. 발견 확률로 없는 물건을 새로 생성하지 않는다. 발견물 소유 근거가 있으면 자기 몫과 타인 몫을 분리하고 타인 물건은 실제 원주인에게 인도·인수한다.
3. 발라크에게 실제 따라간 흔적과 끊김, 발견/미발견을 보여 준다. 소유가 불명확하면 실제 허락된 보관자에게 인수시키고 그 미결을 별도 남긴다. 정직한 미발견은 정상 탐색이지만 발견물 있음·소유미결 보관만은 소유 처리 미완으로 지도권을 보류한다.

## 완료와 갈림길
실제 허락 흔적 탐색·귀환·정직한 보고 AND (미발견 OR 발견물 소유 확인·자기 몫 분리 또는 반환 실인수)이 정상. 정직한 미발견과 발견물 소유 미결은 다르다. 발견물 권리는 소유 근거·분배 합의에서 생기며 SIDE 성공/수강을 소급 소유 조건으로 만들지 않는다.

- 상자만 파괴는 탐색 성공 아님. 무단 파괴면 피해/정리 기록, 허락 파괴라도 없던 보물 생성0.
- 위험해 탐색 거절은 미탐색을 남긴 철수. 타인 소유·끊김을 숨긴 자랑은 근거와 주장을 분리하고 실제 반환 필요.

## 말과 반응
- 선행 열람 전: “상자 안과 아래 돌을 살펴볼까?”
- 빈 상자를 실제 본 뒤: “안쪽은 비었지. 그럼 아래 선은 왜 이어질까?”
- 작은 흔적을 알아봐 주면 말이 길어지고, 미발견 보고에는: “끊긴 곳도 가져왔네. 거기서부터 모른다는 거지?”

## 보상과 선택 수령
허용된 실제 발견물 몫은 품목별 실제 분배 정수량 q≤현물량만, 미발견 지급0. 이미 인수한 자기 몫 재지급0. 정상 수행자에게 흔적 추적 지도 1회: 긁힘·끈 연결/끊김을 직접 짚고 발라크의 피드백을 수신한다. 용 권능·추가 보물·장비 없음.

정상 사건별 실제 수행자 최초1회. 같은 사건 재개는 미수령/미지도 잔여만. 새 사건을 자동 발생시키지 않는다.

## 중단·재개·지식
공통실행계약의 체크포인트, 원물 장부, 영수증 대조, 실제 청중 규칙을 적용한다. 미수신을 수신으로 만들지 않고 완료한 행동을 재연하지 않는다.
발라크는 알아본 흔적의 가치를 얻고 미발견이면 허풍의 비판도 받는다. 용 형상은 새 용종·혈연·화력으로 확대하지 않는다.

## 구현과 예상
상자 실제 내용·바깥 흔적·탐색 경로·발견물ID·소유미결과 미발견을 구별한다. 지도권과 이미 적법하게 가진 물건 소유권을 별도 저장한다.
예상 8~12분. 실제 API·게임·LLM 시험은 하지 않은 기획값이다. 지도는 비전투 경험이며 전투 능력 보상이 아니다.
