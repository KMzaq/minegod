# 안드로말리우스 — 찾아도 돌려주지 못한 물건

관리키 RPG-S14-115 · 정의 EP037A-RPG-S14-115 · 중급 · SIDE / 신규 MAIN 없음

물건을 되찾았다는 박수보다 잘못 지목한 주인의 얼굴을 끝까지 확인하려는 추적자다. 건조하고 집요하다. 원망을 들어도 같은 확인을 하지만 착오를 인정하면 모욕을 덧붙이지 않는다.

## 현재 요청
반환이 힘 있는 소유 주장만 돕는 일이 되지 않도록 실제 물건과 실제 주인을 맞추고 싶다.

## 실제 수행
1. 실제 도난 주장 대상 1건의 현물·표식·사용 흔적과 두 주장자의 허락 근거를 각각 비교한다. 접촉검사는 손2블록, 현물 열람은 안전 시야 6블록. 주장자가 없으면 새 증언을 만들지 않고 현재 얻은 근거만 보존한다. 확인 전 실제 동의한 중립 보관자·위치·수량을 정해 인수를 확인한다.
2. 소유가 확인되면 확인 소유자에게 실제 반환·인수한다. 근거가 불명확하면 반환을 보류하고 양측 허락 보관의 실제 인수 상태를 기록한다. 보관 합의도 없으면 임의 취득 없이 현 상태를 지키고 미해결로 남긴다. 힘센 주장자의 요구가 소유 근거는 아니다.
3. 실제 오고발이 있었는지 원 발화/청중을 확인한다. 있다면 허락된 원 수신자 전원에게 해당 오류의 정정을 실제 전하고 수신을 확인한다. 현재 합의한 복구 항목이 있으면 품목·정수량/행동·대상·완료증거를 고정해 실제 수행한다. 없다면 오고발/피해를 새로 만들어 사과하지 않는다. 안드로말리우스에게 수신·복구 범위와 장기 미결을 따로 제시한다.

## 완료와 갈림길
실제 근거 대조 AND (확인 반환·인수 OR 정직한 미해결 허락 보관·인수) AND 실제 오고발 있을 때 원 청중 정정 수신·현재 합의 복구 수행. 정직한 보관도 개인 판별 작업 완료 가능하나 소유/범인 판결은 미결. 보관 무동의·정정 미수신·필수 복구 미수행은 부분이다.

- 힘센 사람에게 넘기면 실제 인수자·위치를 추적해 회수/반환 협의, 반환 전 소유 회복 확정0.
- 물건만 돌려주고 정정 거절하면 반환은 유지되지만 오고발 책임과 정상 지도권 보류. 사과가 전체 평판 복구는 아니다.

## 말과 반응
- 제안: “찾은 물건은 여기 있군. 받을 손의 근거는 어디 있지?”

## 보상과 선택 수령
정상 판별 작업 수행자에게 흔적·소유 근거 판별 지도 1회. 본인이 흔적과 주장 근거를 따로 짚고 실제 피드백을 수신한다. 반환품은 보상0, 중립 보관자는 소유자/수혜자가 아니다. 장기 피해·미확인 범인 자동 해결0.

정상 사건별 실제 수행자 최초1회. 같은 사건 재개는 미수령/미지도 잔여만. 새 사건을 자동 발생시키지 않는다.
