# 세에레 — 빈 손으로 돌아온 급행

관리키 RPG-S14-113 · 정의 EP037A-RPG-S14-113 · 중급 · SIDE / 신규 MAIN 없음

빨리 끝내는 기쁨을 좋아하지만 도착했다는 한마디가 남의 약속을 망치면 자존심이 상한다. 빠르고 밝게 말하지만 핵심 질문은 빠뜨리지 않는다. 장황한 요구를 몇 개의 짧은 선택으로 바꾼다.

## 현재 요청
급행을 원하는 이에게 빠름과 실제 수령을 함께 만족시키는 운송을 인정받고 싶다.

## 실제 수행
1. 발송자와 수령자의 실제 응답으로 품목·정수량 N·수령 위치/가능 시점을 정한다. 기본 운반 제안은 물자 4개를 24~40블록 기존 열린 길로 옮기는 것이다. 이미 합의된 다른 품목/정수량·대체재는 유지한다. 운반 대가의 품목·정수량 또는 합의된 행동 대가와 실패 귀환 대가 유무를 출발 전에 별도 합의한다. 경로 지도를 그 사전 대가로 정할 수도 있으나 필수는 아니다. 책임 운반 정리·비용 공개 뒤 세에레가 범위상 선택 경로 지도를 실제 제시하는 원문 후속도 유지한다. 사전 합의가 없었다는 이유로 이 후속 제시 자체를 막지 않고, 자동 지도권은 만들지 않는다.
2. 발송자에게서 N개를 실제 인수하고 길을 직접 걸어 수령자에게 실인도·인수한다. 수령자 부재면 빈 자리에 놓고 완료하지 않는다. 실제 위임 보관자에게만 해당 허락량을 맡기거나 미수령 짐을 가지고 돌아온다. 현재 받지 않겠다는 응답을 수락으로 바꾸지 않는다.
3. 미수령분이 있으면 원발송자에게 실제 반환·인수 OR 새 수령 응답과 재배송 비용의 명시 합의 뒤 재운반·수령 인수를 택한다. 이미 정상 배송이면 새 실패/재배송을 만들지 않고 실제 소비만 세에레에게 보고한다. 모든 구간에서 짐 보유량·실소모·운임·받는 사람을 기록한다.

## 완료와 갈림길
실제 운반 뒤 수령 인수 OR 책임 반환과 발송자 인수, 비용/첫 실패의 정직한 공개가 정상. 맡겼다면 실제 적법 위임과 보관자 인수가 있어야 하며 맡김과 최종 수령은 구별한다. 반환은 배송 성공이 아니지만 책임 운반 정리로 정상 가능.

- 빈 자리에 놓고 도착했다고 하면 위치·분실 위험을 보존하고 실제 회수 전 반환 완료 아님.
- 재배송 비용 은폐는 실제 비용/미합의 청구를 구별해 정정. 미합의 실패귀환 운임은 생성하지 않는다.

## 말과 반응
- 제안: “빠르게? 좋아. 누구 손, 어느 자리, 지금 받을 수 있나?”
- 부재 확인 뒤: “도착은 했고 수령은 안 됐어. 둘을 섞으면 내 빠름도 엉터리지.”
- 책임 반환 후: “빈손으로 돌아온 게 아니라 짐과 답을 같이 돌려준 거야.”

## 보상과 선택 수령
실제 사전 합의한 운반 대가 OR 실제 제시되어 동의한 경로 지도. 경로 지도는 사전 합의 대가 또는 책임 운반 정리·비용 공개 후 범위상 별도로 제시된 선택 후속으로 구분한다. 후속 지도는 자동 보충 보상이 아니며 기존 운임권을 동의 없이 없애거나 같은 권리를 중복 정산하지 않는다. 새 제안의 물품 기본은 현재고 빵1개/동등한 합의 식량1개이며 기존 정수량·다른 대체재 합의를 좁히지 않는다. 실패 반환 대가는 별도 사전 조항이 있을 때만. 행동 대가 선택은 경로/부재 회수 기준 설명과 세에레 피드백 1회다. 재배송은 별도 합의, 기존 인수 운임 재지급0.

정상 사건별 실제 수행자 최초1회. 같은 사건 재개는 미수령/미지도 잔여만. 새 사건을 자동 발생시키지 않는다.

## 중단·재개·지식
공통실행계약의 체크포인트, 원물 장부, 영수증 대조, 실제 청중 규칙을 적용한다. 미수신을 수신으로 만들지 않고 완료한 행동을 재연하지 않는다.
세에레는 빈손 귀환도 책임 있는 운송으로 기억한다. 바틴 이동망이나 수령 동의를 자동 대신하지 않는다. 재배송 비용을 숨겨 청구하면 해당 비용은 미합의 분쟁으로 남고 세에레는 다음 급행 의뢰를 맡기지 않는다.
