# 바풀라 — 주인이 고치는 이음새

관리키 RPG-S14-105 · 정의 EP037A-RPG-S14-105 · 하급 · SIDE / 신규 MAIN 없음

장인이 자기 설명 없이도 도구의 원리를 알아보는 순간을 기다리는 까다로운 공예 교사다. 설명하다 자주 ‘왜 이쪽인가’를 묻는다. 서툰 질문에는 인내하지만 베낀 답에는 냉담하다.

## 현재 요청
의수와 도구를 다루는 이가 완성품 복제보다 고장을 찾아 고칠 능력을 갖추게 하고 싶다.

## 실제 수행
1. 실제 사용자·원소유자가 허락한 사용 중지 보조도구 1개를 기존 2×2 작업면에 놓는다. 축 1곳과 고정부 1곳을 손 2블록 내에서 짚고 흔들림 원인을 구별한 후 실제 분해한다. 새 의수/신체 치료를 발명하지 않는다.
2. 허락 부품 정수량 N을 확정한다. 기본 제안은 고정부 1개 교체이며 다른 허용 재료·정수량을 보존한다. 접촉 가공 3회(회당 2초)를 실행해 맞물림을 확인하고 실패 조각·손실도 분리 보관한다. 소유자가 동의한 낮은 부담 동작 3회를 실제 사용자가 시험한다. 기본은 무부하 잡기·풀기이며 타격/전투 사용이 아니다.
3. 사용자의 실제 편안함·안전 응답을 받고 바풀라가 동작과 맞물림을 확인한다. 불편 신호면 즉시 정지, 안전 분리 뒤 새 동의로 재가공하거나 사용금지 상태로 종료한다. 안전 판정 뒤 원소유자의 실제 인수는 반환으로 기록한다.

## 완료와 갈림길
원인 분해·실제 교체·사용자 낮은 부담 시험과 안전 장착감 판정이 모두 있어야 정상 지도권. 사용자 부재·불편·미완성은 부분. 도구의 안전 반환 권리는 성공과 별개이며 선택 지도 거절로 정상 본작업 취소0.

- 완성품만 요구하며 작업 거절하면 별도 판매/증정 생성0.
- 불편 무시 강행은 즉시 중지·분리·사용금지, 실제 손상/피해 유지. 정직한 중지는 안전 복귀이지 장착 성공은 아니다.

## 말과 반응
- 제안: “돌아간다는 답 말고, 이쪽을 잡은 까닭을 말해 봐.”
- 서툰 질문에는 부품을 다시 놓으며: “여기부터. 모르는 곳을 짚는 건 괜찮아.”
- 베낀 설명에는: “그 말을 한 손은 지금 이 도구를 잡고 있지 않군.”

## 보상과 선택 수령
수리한 원도구 반환은 새 지급0. 정상 수행자별 교체 부품 제작 지도 1회: 남은 허락 부품의 맞물림을 설명하고 안전한 소품 가공 1회와 실제 피드백. 새 무기·의수 능력·독립 제작 스킬 해금 없음.

정상 사건별 실제 수행자 최초1회. 같은 사건 재개는 미수령/미지도 잔여만. 새 사건을 자동 발생시키지 않는다.

## 중단·재개·지식
공통실행계약의 체크포인트, 원물 장부, 영수증 대조, 실제 청중 규칙을 적용한다. 미수신을 수신으로 만들지 않고 완료한 행동을 재연하지 않는다.
바풀라는 자기 기술을 이해한 수리자를 다음 교체 작업에 부른다. 의수 장착 성공은 실제 사용자의 판정이 있어야 하고 수치 강화는 없다. 불편하다는 사용자의 말에도 강행하면 시험을 중지하고 도구를 사용 금지로 남기며 교체 지도 지급권은 생기지 않는다.

## 구현과 예상
도구 축/고정부 분해 모델, 사용자 중지 신호, 저부하 3동작·안전 판정 구현. 시험 소품 수리 상태만 변하며 바닐라 장비 내구 무료복구 시스템을 열지 않는다.
예상 9~15분. 실제 API·게임·LLM 시험은 하지 않은 기획값이다. 지도는 비전투 경험이며 전투 능력 보상이 아니다.
