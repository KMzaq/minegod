# 카임 — 말보다 아래의 소리

관리키 RPG-S14-098 · 정의 EP036B-RPG-S14-098 · 하급 · SIDE / 신규 MAIN 없음

유창한 사람의 말을 작은 울음 하나로 뒤집을 때 즐거움을 느끼는 논박가다. 재빠르고 빈정댄다. 반박당해도 실제 소리가 다르면 눈을 빛내며 다시 듣는다.

## 현재 요청
숲과 하류의 피해를 말 많은 사람의 설명 뒤로 밀리지 않게 들려주고 싶다.

## 실제 수행
1. 주민의 실제 허락 진술 1건을 듣고 뒤틀린 숲 기존 안전 가장자리에서 소음이 큰 자리와 소리가 끊긴 자리 2곳을 직접 찾아간다. 각 점의 12블록 청취 범위에서 실제 발생한 소리/침묵을 30초씩 관찰하고 긁힘 1곳 또는 긁힘 없음도 8블록 시야로 기록한다. 네더에 없는 하류는 전언 자료일 뿐이다.
2. 실제로 이동 가능한 소음 물건 1개를 지정하고 소유자에게 새 위치와 영향을 설명해 허락받는다. 기본은 실제 작동 중인 소리 소품/작업도구이며 다른 허용 물건을 바꾸지 않는다. 같은 안전 지면에서 원위치보다 관측점에서 8블록 이상 먼 위치로 접촉 이동한다. 소음 물건 부재면 이 필수 단계 보류이지 가상의 물건 생성이 아니다.
3. 같은 두 관측점에서 실제 접속·청취 30초씩 다시 듣고 돌아온 소리와 돌아오지 않은 소리를 카임에게 보고한다. 관측 중 이탈/로그아웃은 그 관찰 구간만 중지하며 누적 관측초와 공백을 분리한다. 생태 회복 성공을 요구하지 않는다.

## 완료와 갈림길
주민 진술 수신·현장 비교·실제 소유자 허락 이동·후속 관찰·카임 확인이 모두 있어야 정상. 실제 생물 무응답도 관측 결과이며 생태 복원과 다르다.

- 설명만 듣고 비교 거절은 수신한 설명만 남는다.
- 즉시 회복 선전은 원 청중에게 실제 관측·미회복을 정정. 은폐한 피해가 자동 회복되지 않는다.

## 말과 반응
- 제안: “설명이 참 크군. 잠깐만 조용히 해도 그 설명이 버티나 보자.”
- 미회복 보고: “안 들렸다고? 그 말은 적어도 네가 들은 척한 건 아니네.”
- 카임도 틀린 해석을 지적받으면 빈정대다 귀를 기울이고 실제 소리로 다시 비교한다.

## 보상과 선택 수령
현장 소리 관찰 지도 1회. 들린 소리·안 들린 구간·원인 미확인 각각을 구별해 재관측 30초 뒤 실제 피드백을 받는다. 생물·둥지 소유권이나 청각 전투 버프 없음.

정상 사건별 실제 수행자 최초1회. 같은 사건 재개는 미수령/미지도 잔여만. 새 사건을 자동 발생시키지 않는다.

## 중단·재개·지식
공통실행계약의 체크포인트, 원물 장부, 영수증 대조, 실제 청중 규칙을 적용한다. 미수신을 수신으로 만들지 않고 완료한 행동을 재연하지 않는다.
카임은 반박으로 이긴 말보다 실제 남은 피해를 기억한다. 조용해졌어도 파괴된 생태는 자동 복원되지 않는다.

## 구현과 예상
소음원 이동 전후 실제 가청 범위·음량과 원위치/새위치 연결. 침묵을 가짜 생물 응답으로 치환하지 않는다.
예상 7~11분. 실제 API·게임·LLM 시험은 하지 않은 기획값이다. 지도는 비전투 경험이며 전투 능력 보상이 아니다.

## 세계 해금과 첫 조우
세계 공용: 한 실제 플레이어가 네더 뒤틀린 숲의 안전 가장자리에 도달하여 현재 소리/침묵을 20초 관측한다.

개인 조우: 뒤틀린 숲 공개 가장자리 방문. 생물 응답·특정 물품은 추첨 선행 아님.

안전 발판 8~12블록 이내 시야로 몸짓을 발견. 실제 대화는 들리는 6블록 내. 접촉 집기만 손2블록. 현재 개인 조우조건을 충족하는 실제 플레이어 한 명이 추첨 주체. 세계 해금자와 같을 필요 없음. 친구/팀의 조건을 복사하지 않는다.
퀘스트/공통설계/시간_조우_성장_운영정책.json#CAMPAIGN06_OPERATION_POLICY. 확률·검사주기·NONE·전역 단일본체 claim/CAS·재시도·인원 보정은 그 정책을 사용하고 재설계하지 않는다.
단일 실제 본체의 현재 생존·완전봉인 아님·현위치·기존 사건 미점유를 검사. 이미 존재하면 재소환하지 않고 실제 위치에서 접촉. 본체 부재를 분신/원격 응답으로 대체하지 않는다.

## 친구와 후발자
각 수락자가 자신의 필수 관측·판단·이동/접촉/인수·보고에 실제 참여한 증거를 가진다. 공동 단일물리 작업은 누가 어느 부분을 수행했는지 분담을 수락 시 고정하고, 개인별 관측·결과 설명은 직접 해야 한다. 단순 동석·파티 완료는 권리0. 유일물 재해체·재반환을 각자에게 요구하지 않고 이미 완료된 행동에 참가한 범위만 인정한다. 뒤늦은 참가자는 새 독립 현장이나 남은 현재 작업만 맡는다.
