# 알로케스 — 표식이 없는 돌아오는 길

관리키 RPG-S14-097 · 정의 EP036B-RPG-S14-097 · 중급 · SIDE / 신규 MAIN 없음

높은 학문도 길 한 번 제대로 찾는 데 쓰여야 한다고 고집하는 엄한 실용 교사다. 딱딱하고 명령처럼 들리지만 실패를 숨기지 않는 사람에게 같은 설명을 다시 해 준다.

## 현재 요청
관측으로 배운 방향이 현장에서 길을 찾는 판단으로 이어지게 하고 싶다.

## 실제 수행
1. 기존 네더 길의 출발점과 왕복 가능한 16~24블록 갈림길 1곳을 선정한다. 본인 표식 1개만 허락 위치에 놓고 실제 왕복해 지형 기준 2개를 관찰한다. 타인 길 표식은 손대지 않는다.
2. 본인 표식 1개를 가리고 갈림길에 다시 가서 지형과 실제 발자국/기록을 보고 출발점으로 귀환한다. 가상 내비 화살표로 자동 이동시키지 않는다. 위치를 잃으면 안전 위치에 멈춰 실제 도움을 요청하고 구조 응답·귀환을 독력 성공과 구별한다.
3. 알로케스가 실제 동행 가능한 때 같은 갈림길을 걸으며 잘못 본 기준 또는 처음부터 혼동 가능했던 기준 1곳을 다시 확인한다. 자기 가림물과 표식을 실제 회수하고 알로케스에게 두 시도·구조 여부를 사실대로 보여 준다.

## 완료와 갈림길
실제 귀환 AND 같은 갈림길 재확인 AND 자기 표식 회수 AND 정직한 경로 접수. 첫 실패 후 구조·재확인은 정상 가능. 최초 성공에 실패 이력을 만들지 않고, NPC 동행 부재는 그 부분 보류.

- 길 잃음 인정은 정당한 안전 중단이며 구조·재확인 전 완수 아님.
- 구조를 지운 독력 기록은 교육에서 제외하고 원 경로를 되살린다. 친구의 길 찾기 성공은 본인 귀환이 아니다.

## 보상과 선택 수령
현장 방향 판단 지도 1회. 안전한 자리에서 본인이 지형 기준 2개로 방향을 실제 가리키고 알로케스 피드백을 받는다. 자동 길찾기 능력·전투등급 상승 없음.

정상 사건별 실제 수행자 최초1회. 같은 사건 재개는 미수령/미지도 잔여만. 새 사건을 자동 발생시키지 않는다.
