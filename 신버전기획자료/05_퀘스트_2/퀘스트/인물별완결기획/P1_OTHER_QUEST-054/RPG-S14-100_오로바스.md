# 오로바스 — 보증할 수 없는 나머지

관리키 RPG-S14-100 · 정의 EP036B-RPG-S14-100 · 중급 · SIDE / 신규 MAIN 없음

충성을 자랑하는 입보다 지킬 수 있는 약속의 크기를 줄이는 입을 더 믿는 보호자다. 차분하고 또렷하다. 믿으라는 말보다 자신이 맡을 부분을 먼저 말하며 과장된 칭찬을 피한다.

## 현재 요청
자신이 보증하는 말이 실제 이행 가능한 범위 안에 머물게 하고 싶다.

## 실제 수행
1. 실제 도움 약속의 당사자·수령자·원물·전체 약속량 T와 지금 전달 가능한 정수량 n을 확인한다. 기본 제안은 합의 물자 2개를 짧은 길로 운반하는 것이나 기존 정수량·대체재 합의를 보존한다. 0<n≤min(T, 현재 허락 재고)이고 전달 목적·대가 여부를 분리한다. 실제 당사자 부재는 보증 성공이 아니다.
2. 현재 열린 16~32블록 기존 길에서 해당 n개를 직접 운반해 수령자의 실제 인수를 확인한다. 오로바스에게 인수 근거와 미인수량 T-n을 구별하여 제시한다. 친구가 운반한 몫은 친구 기여로 기록한다.
3. 약속 당사자에게 부족분을 실제 설명하여 현재 가능한 추가 이행량 m 또는 미결 유지의 응답을 받는다. m은 0≤m≤min(T-n, 추가 허락 재고)의 정수이고, m>0 합의면 실제 인도·인수하며, 불가능하면 미결의 범위와 상대의 실제 수신만 남긴다. 거절/부재에 새 기한·수락을 만들어 넣지 않는다.

## 완료와 갈림길
작은 실제 인수와 부족분의 당사자 수신·현재 응답을 오로바스가 확인한 범위만 개인 정리. 모든 채무 완료와 구별한다. 남은 짐/채무/미수신은 그대로이며 미수신으로 본작업 전체 성공을 만들지 않는다.

- 친분으로 전체 보증한 허위는 실제 수신자에게 확인 범위를 정정. 철회할 수 있는 것은 오로바스 자신의 해당 보호 약정뿐, 전역 가호 삭제 없음.
- 부족을 정직하게 남겨 제한 신뢰가 생길 수 있어도 미이행이 사라지지 않는다. 철회 이유 은폐는 별도 관계 손상이다.

## 말과 반응
- 제안: “이 짐이 그 손에 닿는 것. 지금 내가 보증할 수 있는 것은 거기까지다.”
- 친구에게도: “널 믿는 일과 네가 가진 물자를 세는 일은 다르지.”
- 부족 인정 뒤: “남은 말을 줄였군. 아직 남은 짐까지 줄어든 것은 아니다.”

## 보상과 선택 수령
별도 보상0. 운반된 원물은 본래 수령자의 것, 보증은 물품·소유권·예언 확약 아님. 제한 신뢰는 실제 당사자의 응답만 기록한다.

정상 사건별 실제 수행자 최초1회. 같은 사건 재개는 미수령/미지도 잔여만. 새 사건을 자동 발생시키지 않는다.
