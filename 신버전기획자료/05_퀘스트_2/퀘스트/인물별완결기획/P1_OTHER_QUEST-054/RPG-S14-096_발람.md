# 발람 — 조건이 바뀐 갈림길

관리키 RPG-S14-096 · 정의 EP036B-RPG-S14-096 · 상급 · SIDE / 신규 MAIN 없음

예언을 듣고 책임까지 맡기려는 상대를 경멸하며 조건을 정확히 말하는 데 자부심이 있다. 단정적인 음색으로도 범위를 좁혀 말한다. 책임을 떠넘기는 말에는 긴 설명 대신 차갑게 질문을 되돌린다.

## 현재 요청
수색의 현재 단서와 미래 예측이 뒤섞이지 않는 조언을 내놓고 싶다.

## 실제 수행
1. 실제 허락된 수색 요청 1건과 그 요청의 실제 흔적 구간을 정한다. 기존 열린 길 24블록 이내에 출발점과 관측점 2곳을 선택한다. 본인이 각 점에 도달해 12블록 이내 시야로 흔적/빈 곳·관측 시점을 기록한다. 실종자·흔적이 없으면 새 피해자를 생성하지 않는다.
2. 직접 관측한 위치와 앞으로 갈 것이라는 예상 문장을 분리한다. 정한 짧은 구간을 실제 걷고 돌아와 통로 폐쇄·동행 변화가 실제 있으면 그 변화를, 없으면 변화 미확인을 발람에게 보고한다. 수색 결과가 빈손이어도 현재 범위 탐색 증거는 남긴다.
3. 발람의 현재 근거 확인/한정 조언을 실제 수신한다. 새 예측은 다음 실제 확인 전 미지로 남긴다. 위험을 만나 중단했다면 실제 걸은 범위·미탐색 지점·철수를 별도로 제출하고 이미 정한 필수 관측을 충족했는지 판정한다.

## 완료와 갈림길
필수 실제 구간 탐색·흔적/빈곳/조건 구분·발람 수신과 확인이 정상. 발견/구출은 요구하지 않는다. 탐색을 못 마친 정직한 철수는 부분, 필수 탐색을 마친 빈손 보고는 정상이다.

- 미관측을 목격담으로 전했으면 원 수신자에게 정정 수신 전 정상 지도권 보류.
- 변화 은폐와 정직한 미확인은 다르다. 사생활·미래 위치·보증을 확정하지 않는다.

## 말과 반응
- 제안: “봤다는 말에는 네가 선 자리를 붙여라. 예상에는 조건을 붙이고.”
- 책임 전가에는: “네 발은 누가 움직였지?”
- 정직한 빈손 보고 뒤: “없는 곳을 지웠군. 찾았다는 말보다 지금은 그게 정확하다.”

## 보상과 선택 수령
조건과 관측을 분리하는 수색 지도 1회. 본인이 관측 1문장과 조건부 예상 1문장을 나누어 설명하고 발람의 실제 피드백을 수신한다. 발견 보상·예언 확약·오로바스 보증0.

정상 사건별 실제 수행자 최초1회. 같은 사건 재개는 미수령/미지도 잔여만. 새 사건을 자동 발생시키지 않는다.

## 중단·재개·지식
공통실행계약의 체크포인트, 원물 장부, 영수증 대조, 실제 청중 규칙을 적용한다. 미수신을 수신으로 만들지 않고 완료한 행동을 재연하지 않는다.
발람은 현재 증거를 가져온 상대에게만 수정 조언을 주며 실종자의 사생활·미래를 전지적으로 확정하지 않는다.

## 구현과 예상
공통 권위 동작·소품·원물·응답 저장 연결. 새 전투 시스템 없음.
예상 8~12분. 실제 API·게임·LLM 시험은 하지 않은 기획값이다. 지도는 비전투 경험이며 전투 능력 보상이 아니다.
