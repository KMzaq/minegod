# 크로셀 — 소리가 먼저 도착하는 곳

관리키 RPG-S14-095 · 정의 EP036B-RPG-S14-095 · 하급 · SIDE / 신규 MAIN 없음

보이지 않는 흐름을 소리만의 신비로 남기지 않고 손에 잡히는 설명으로 보여 주고 싶어 한다. 차분한 설명에 소리 흉내를 섞는다. 신비롭다는 말에는 웃지만 측정 질문에는 더 열심히 답한다.

## 현재 요청
수로에서 들리는 소리와 실제 흐름이 다른 지점을 찾아 납득할 만한 설명을 만들고 싶다.

## 실제 수행
1. 기존 안전 발판에서 빈 관 1개와 돌 틈 1곳의 울림을 4~8블록 거리에서 듣고 각각 열린 끝의 시야를 확인한다. 소리는 통로 안전 판정이 아니다. 소유자가 허락한 작은 시험구 1개를 통과 가능한 관에만 넣어 나온 위치를 실제 확인한다. 나오지 않으면 미회수로 기록하고 몸을 틈에 넣지 않는다.
2. 실제 존재하고 사용 허락을 받은 폐쇄 시험 장치 1대를 사용한다. 투명한 3블록 길이의 밀폐 관 안에서 시험구가 이동하는 폐회로를 채택한다. 관의 유효 연결/막힘 상태를 조작하고 출발·도착을 각 5초 동안 관측한다. 이는 자연 물/수원 아닌 폐쇄 장치 내부 시험 흐름이다. 장치가 현장에 없으면 새 건축을 즉석 생성하지 않고 첫 조사만 보류한다.
3. 첫 예상과 실제 흐름이 다른 지점 또는 예상과 일치한 근거를 표시한다. 틀렸으면 가설을 수정하고, 맞았으면 불확실 범위를 명시해 막힘 조건 1개를 바꿔 다시 시험한다. 두 실제 관측을 크로셀에게 설명하고 확인된 통로와 울림만 있는 쪽을 구별한다.

## 완료와 갈림길
울림/실제 틈 대조 AND 폐쇄 장치 첫 시험과 재시험 AND 근거에 따른 가설 검토/수정 AND 크로셀 확인. 잘못된 최초 답을 강제로 만들지 않는다. 장치 부재·재시험 없음은 부분이며 도면 열람/지도는 선택.

- 위험 틈 진입·고립이면 실제 구조·철수와 손실을 남기며 통로 성공 없음.
- 불일치를 지우고 장치 탓을 하면 해당 청중 정정·잘못된 안내 중지. 수원 개방이나 안드레알푸스 승인 자동 없음.

## 말과 반응
- 제안: “통, 통. 크게 울리는 쪽이지. 그쪽으로 나왔다는 뜻은 아직 아니야.”
- 관측을 고치면: “그 소리 뒤에 빈칸을 남긴 게 마음에 들어. 이제 실제 끝을 보자.”
- 신비하다는 감탄에는 미소, 측정 질문에는 관의 양 끝을 직접 가리켜 설명한다.

## 보상과 선택 수령
정상 수행자별 울림·통로 판별 지도 1회와 허락 도면 1건 열람 제시. 본인이 도면의 막힘과 확인 통로를 실제 시험과 대조하고 크로셀 피드백을 받아야 수강. 도면 복제/소유/수원 권리0, 열람 거절로 완료 취소0.

정상 사건별 실제 수행자 최초1회. 같은 사건 재개는 미수령/미지도 잔여만. 새 사건을 자동 발생시키지 않는다.

## 중단·재개·지식
공통실행계약의 체크포인트, 원물 장부, 영수증 대조, 실제 청중 규칙을 적용한다. 미수신을 수신으로 만들지 않고 완료한 행동을 재연하지 않는다.
크로셀은 울림과 흐름을 구별한 상대에게 허용된 도면을 열어 준다. 수원·수로 개방은 실제 존재와 접근 확인 전 미발생이다.

## 구현과 예상
밀폐 관/시험구의 가시적 이동과 막힘·회수 상태, 같은 모형의 소리 방향을 구현. 네더에 물 원천을 설치하거나 자연 물 흐름을 가정하지 않는다.
예상 8~13분. 실제 API·게임·LLM 시험은 하지 않은 기획값이다. 지도는 비전투 경험이며 전투 능력 보상이 아니다.
