# 비네 — 없앨 돌을 고른다

관리키 RPG-S14-091 · 정의 EP036A-RPG-S14-091 · 상급 · SIDE / 신규 MAIN 없음

오래 버텼다는 찬사만으로 불편한 구조를 지키는 일을 비웃으며 바꾸는 쪽에 성급히 기우는 자다. 성급하고 직설적이다. ‘원래 그렇다’는 말에는 비웃고 실제 쓰임의 설명에는 귀를 기울인다.

## 현재 요청
막힌 통행을 만드는 성벽의 어느 부분을 없애야 하는지 구체적으로 정하고 싶다.

## 실제 수행
1. 실제 권리자와 조사·해체·잔재 처분을 각각 합의한다. 기존 벽의 3×3블록 표면을 6블록 이내 시야에서 보고 통행 방해부와 지지부를 따로 표시한다. 기본 제안은 비지지 방해 블록 1개 제거이며 실제 허락된 정수량 N과 각 좌표를 확정한다. 다른 적법 범위 합의를 1개로 좁히지 않는다. 지지부·상부 낙하물·통행자 대피가 불명확하면 제거하지 않는다.
2. 허락된 N개만 손 2블록 이내에서 맞는 도구로 실제 채굴한다. 도구 내구와 실제 드롭만 기록한다. 원주민이 아닌 장식 이름표를 허락 주체로 쓰지 않는다. 실제 짐은 본인 소유 보관함/운반 물품 중 합의한 1묶음으로 지정하고, 길을 뚫었다고 자동 운반하지 않는다.
3. 자기 짐을 지닌 채 제거 지점 앞뒤 각 3블록의 통과선을 실제 넘는다. 플레이어 충돌상자와 합의한 짐의 운반 방식으로 통과를 판정하며 가상 중량·폭을 발명하지 않는다. 걸리면 걸림 위치를 남기고 추가 허락 전 채굴0. 성공하면 실제 발생 잔재 전량을 회수하거나 허락 보관함으로 옮겨 인수하고, 비네에게 남긴 지지부와 확인한 폭을 설명한다.

## 완료와 갈림길
정상은 허락 선별 해체 AND 실제 짐 통과 AND 발생 잔재 정리 AND 비네 확인. 미허락·걸림·위험 철수는 부분 종료다. 잔재 몫 수령은 완료 뒤 선택이며 사브나크 성채·새 수로는 변경하지 않는다.

- 안전을 모르면 무훼손 철수. 새로 안전과 허락이 확보되면 미완 부분만 재개한다.
- 전부 철거·과장해 추가 철거는 위반. 위험 봉쇄·대피·손상 대조를 먼저 하고 새 허락 없이 지지부를 복원/제거하지 않는다. 정정만으로 노동 몫을 소급하지 않는다.

## 말과 반응
- 제안: “다 남기자는 말도 다 부수자는 말도 쉽지. 어느 돌이 길을 막는지 짚어.”
- 정상 통과를 본 뒤: “그래. 저 돌은 남길 이유가 있었군. 네 짐이 지나간 폭까지만 말해.”
- 친밀해도 지지부 파괴 제안에는: “네 부탁이라서 돌이 덜 무너지나?”

## 보상과 선택 수령
허락된 실제 잔재의 노동 몫만. 정상 완료 뒤 권리자·수행자가 품목별 정수량 q를 합의하며 0≤q≤실재 회수 재고, 여러 수행자의 합≤승인 분배량. 기본 제안은 회수 자갈/벽돌류 중 1개이나 동의한 다른 품목·정수량을 보존한다. 거절/무승인 분배에는 지급권0. 원물 인수분을 새 드롭으로 생성하지 않는다.

정상 사건별 실제 수행자 최초1회. 같은 사건 재개는 미수령/미지도 잔여만. 새 사건을 자동 발생시키지 않는다.

## 중단·재개·지식
공통실행계약의 체크포인트, 원물 장부, 영수증 대조, 실제 청중 규칙을 적용한다. 미수신을 수신으로 만들지 않고 완료한 행동을 재연하지 않는다.
비네는 선별한 해체의 근거를 얻고 실패면 수정 계획을 남긴다. 사브나크의 기존 성채나 새 수로를 원격 개방하지 않는다.

## 구현과 예상
표면 지지/방해 표식, 허락 좌표 집합, 실제 채굴 드롭·통과선·잔재 인수 연결. 자동 구조물 붕괴 물리는 추가하지 않고 실제 낙하/손상만 판정.
예상 8~12분. 실제 API·게임·LLM 시험은 하지 않은 기획값이다. 지도는 비전투 경험이며 전투 능력 보상이 아니다.

안전 발판 8~12블록 이내 시야로 몸짓을 발견. 실제 대화는 들리는 6블록 내. 접촉 집기만 손2블록. 현재 개인 조우조건을 충족하는 실제 플레이어 한 명이 추첨 주체. 세계 해금자와 같을 필요 없음. 친구/팀의 조건을 복사하지 않는다.
