# 윌 스칼렛 — 농가에 남긴 바퀴 자국

## 인물과 범위

윌 스칼렛은 멋진 싸움을 좋아하는 이들 사이에서도 남의 마당에 남긴 피해를 외면하고 싶지 않다. 뒷정리를 한다고 멋이 없어진다는 말에는 웃으며 받아치되 자기 몫은 끝낸다.

## 현행 해금과 조우

원문 최초접촉 현장: 기존 농가 바깥길의 흙이 흐트러진 구간 현재 조건: 해당 현장의 현재 열린 통행범위 16블록 안에 실제 도달한 사람이 일반 최초 접촉 후보이다. 원문 배치 제안의 지리와 적합 기존 부지·현재 접근·봉인·단일 본체·의사를 확인한다. 아래 SIDE layout은 수락 후 실제 수행 장소이며 일반 첫접촉 장소나 선행으로 강제하지 않는다. SIDE 물품·R/C 수행·개인 실적을 일반 접촉의 새 조건으로 요구하지 않는다.

한 명의 유효 달성으로 세계공통, 이후 현재 적격자 중 실제 1명 선정. 해금자와 달라도 됨. 단일 본체·전역 확률/주기/CAS는 공통 계약 참조.



## 현장

기존 농가의 실제 젖은길 구간과 허락 바깥길을 사용한다. 바깥길은 동일 출발/수령점을 잇는 16~32블록 열린길, 젖은길은 현재 손상 비교 가능한 2~6블록 구간. 새 피해를 일부러 생성해야 하는 퀘스트가 아니다.



## 실제 수행

- B1 집주인의 실제 운반요청·길 허락·품목별 정수량·지정수령자를 확인한다. 우회경로는 짐 실인수 후 바깥길로 걸어 수령자 손2블록 안 실인도한다. 젖은길 경로는 실제로 통과해 생긴 자기 자국만 시각/블록상태 전후 증거로 구분한다.

- B2 우회는 실제 짐수령 및 새피해 없음을 집주인이 6블록 안 보고/관측으로 확인하면 성공. 복구경로는 실제 자기손상 셀 목록 D와 주인이 고른 복구법·허락재료 품목/정수량을 합의해 셀별 실행한다. 두 경로 AND 아님.

- 농지 복구는 허락한 호미로 해당 블록 경작, 실제 손실된 작물의 재파종은 별도 허락 종자 1개/셀 소비; 길 블록은 허락 도구로 원래 상태 복원. 바퀴흔적 전용 표시는 셀당20tick 손2블록 정리로 제거하는 새 구현 요구. 기존 옛자국은 D에 넣지 않는다. 집주인의 실제 복구확인 필요.

- B3 복구를 실제 마친 경우에만 집주인이 현재 허락한 휴식자리와 보급한몫(품목별 합의 양의 정수량)을 따로 제공한다. 우회만 성공한 사람에게 이 복구보상 없음. 로빈/존 분담은 선택 실제 요청/응답이며 없다고 본작업을 다시 미완료로 만들지 않는다.
