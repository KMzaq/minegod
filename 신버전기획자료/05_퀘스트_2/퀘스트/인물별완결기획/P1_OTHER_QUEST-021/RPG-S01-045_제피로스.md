## 현장과 수락
기존 정원 바깥 공용 마당. ZP-START-01에서 ZP-END-01까지 정원경계 밖 실제 우회로16~32블록. FL-EDGE-01 플로라가 실제 허락한 경계, ZP-CLOTH-01 소유허락 있는 가벼운 천1.
동일 본체의 실제 의사와 현장 조건이 성립한 때 해당 사건 참가를 명시 수락한다. 일반 인사는 별도이며 이 사건 완료를 조우의 선행으로 되돌리지 않는다.

## 실제 수행
1. 꽃을 밟는 지름길과 허락된 우회로의 경계를 실제 확인하고 ZP-START-01→ZP-END-01→ZP-START-01 왕복1회를 걷는다. 소요시간과 꽃밭침범0을 기록하고 돌아와 실제 불편했던 바람 방향을 짚거나 불편 관측없음을 구분한다. 정원 안을 들어가야만 조우하게 하지 않는다.
2. 플로라 RPG-S01-064에게 경계와 시험방향을 실제 요청. 동의하면 경계 바깥 시작점에서 끝점 방향의 작은 바람 시험1회를 제피로스가 수행, 주변 실제 사람은 시험 동의를 받거나 영향범위 밖에 둔다.
3. 천의 움직임1과 꽃 상태 전후1쌍을 직접 비교. 원래 경계 바깥으로만 도움이 갔는지 확인하고 원위치·소품 반환 후 끝낸다.

## 선택과 결말
플로라 부재/거절이면 바람시험 미실행으로 닫고 우회로 확인 결과만 남긴다. 통행인이 불편하다고 하면 즉시 시험중단·방향 재동의. 다음 항해 도움은 이 결과와 별도 요청이다. 바람시험 미실행/미확인은 우회 관측의 부분종료이며 전체 SIDE 완료가 아니다. 허락된 시험·실제 반응 비교·중단/반환까지 확인한 경우에만 전체 완료한다.
바람이 돌아가는 길에서 실제 선택한 행동과 결과: 그가 실제 허용된 방향으로만 도움을 조정하고 다음 항해 바람의 요청도 별도 검토한다. 영구 바람·자동 항해 능력은 없다.
이전에는 계획 또는 상대에 대한 기대였다. 실제 관측 뒤에는 그가 실제 허용된 방향으로만 도움을 조정하고 다음 항해 바람의 요청도 별도 검토한다. 영구 바람·자동 항해 능력은 없다.

## 전언과 기억
제피로스와 플레이어 각각이 직접 관측하거나 허락된 보고를 실제 받은 범위만. 참가명부만으로 지식이 생기지 않으며 실제 청취/목격/열람 UUID별로 기록한다. 외부 상대는 counterpart_delivery의 실제 수신완료 내용만.
개인 수락·손실 사연·사적 발언은 별도 동의 없는 공유 금지. 과거관계와 현재응답은 별개.
- RPG-S01-064: 제피로스와 정원 바깥에서 꽃을 밟지 않는 우회로를 실제 걸어 보고 지름길과 소요 부담을 비교한다. 플로라가 허용한 경계는 직접 확인한 범위만 따른다. 플로라가 실제 응답할 때 허용한 경계 바깥의 작은 바람 도움만 시험하고 꽃과 지나가는 사람의 반응을 직접 살핀다. 상대는 본문에서 요청한 범위에만 실제 답한다. 전달 전 발화자의 내용·수신자 허가를 확인하고 실제 상대가 받은 질문에 동의·거절·조건을 직접 답한 때만 응답으로 남긴다.
