## 현장과 수락
기존 숲폐허/저택의 안전 공용자리, 갈림 O와 실제 목적지 OD-END-01(24블록 이내), 두 경로 OD-A/OD-B는 기존 지형만 사용.
동일 본체의 실제 의사와 현장 조건이 성립한 때 해당 사건 참가를 명시 수락한다. 일반 인사는 별도이며 이 사건 완료를 조우의 선행으로 되돌리지 않는다.

## 실제 수행
1. 오이디푸스와 현재 질문1의 주장/발신자를 먼저 분리해 해석2개를 세운다. 경로질문이면 목표2~3의 실제길 비교를 반례로 사용. 자료/길상황이 없으면 자기 짐1을 허락된 문앞에 놓은 본인은 남고 동의한 상대가 옮겨 먼저 떠나는 순서를 실제 보여, 놓은사람/옮긴사람/떠난사람을 각각 관측한다. 이 반례 경로는 길비교 목표2~3만 해당없음으로 건너뛰며 짐을 원소유자에게 실제 돌려준 뒤 공통 결론 목표4를 수행한다.
2. 눈에 보이는 짧은 길과 실제 걸은 길을 나누어 첫 주장1을 적는다. 실제 안전한 경로1을 걷고 거리/소요시간을 기록한다. 다른 길이 위험하면 들어가지 않고 미확인으로 표시.
3. 안전한 다른 경로가 있으면 걸어 비교하고 첫 주장에 불리한 결과도 남긴다. 하나만 확인했으면 비교불가가 결론. 오이디푸스는 보이는 길을 빠른 길이라고 확정하지 않는다.
4. 선택 경로의 실제 관측사실·해석·아직 모르는 부분을 분리하여 오이디푸스와 결론을 확인한다. 본인이 실제 소유·열람허가한 기록이 있을 때만 관련 주장1과 대조. 없으면 현장 결론까지만 종료, 기록열람 청원은 현재 소유자의 동의가 있을 때만 별도 제출한다. 청원/승낙/실제열람은 별개이고 복사·반출은 별도 허락 없이 하지 않는다.
