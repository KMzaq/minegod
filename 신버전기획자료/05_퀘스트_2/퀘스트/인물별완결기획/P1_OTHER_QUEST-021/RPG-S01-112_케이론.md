## 현장과 수락

## 실제 수행
1. 첫 실습은 실제 돌출 장애물을 돌아 출발선까지 왕복6~12블록을 두 방식으로 비교. 동료가 있으면 빠른 동선과 기다린 동료의 실제 구간을 비교하며 불필요한 재주행0. 혼자면 빠르게1회·엄폐에서3초 멈춰1회 직접 왕복한다. 말로 기다리겠다는 정답만은 완료0.
2. 대련 선택 시에만 서로 동의한 비살상 대련/판단연습1회를 시작. 공격/동료퇴로 보호 중 어떤 선택이 가능한지 설명하되 정답을 미리 강요하지 않는다. 실제 적대 상황이 끼면 연습을 중단하고 대응/철수한다.
3. 대련 선택 시 총60초 이내의 실습에서 준비구령1초 뒤 공격기회와 동료귀환을 같은5초 선택창에 제시한다. 한 시도의 첫 유효 공격/보호 행동을 선택으로 기록한다. 공격선택은 표적에 기본공격1회 실제 적중, 보호선택은 엄폐칸으로 이동해 동료가6블록 귀환하는 동안 공격을 멈추고 길을3초 유지한다. 창 종료 뒤 뒤늦은 반대 행동을 같은 기회의 동시 성공으로 합산하지 않는다. 동료를 실제 공격하는 연출/피해는 없다.
4. 어느 선택으로 무엇을 놓쳤는지 실제 위치/공격 로그와 비교하고 다음 훈련 동선을 플레이어가 직접 정한다. 스승의 정답을 되풀이하는 것만으로 완료하지 않는다.

## 선택과 결말
