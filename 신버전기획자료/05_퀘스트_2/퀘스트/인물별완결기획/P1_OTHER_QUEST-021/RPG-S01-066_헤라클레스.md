## 현장과 수락
현재 실제 공동 구조/회수 현장의 안전 퇴로. HE-LOAD-01은 기존 통로를 막은 소유확인 물건1, HE-DROP-01은6~12블록 떨어진 허락된 놓을 자리. 명부에 새 인질/보스 추가0. HE-VESSEL-01은 짐 아래 실제 소유자 그릇1. 대상 부재면 새 인질이나 파손을 생성하지 않고 해당장면 대기.
동일 본체의 실제 의사와 현장 조건이 성립한 때 해당 사건 참가를 명시 수락한다. 일반 인사는 별도이며 이 사건 완료를 조우의 선행으로 되돌리지 않는다.

## 실제 수행
1. 위험과 퇴로를 현장에서 확인하고 힘쓰는역할·인원통과확인·놓을자리확인 중 실제 맡을 역할을 선택한다. 헤라클레스가 한 물건을 들어 옮길 의사가 있을 때만 작업 시작. 짐 아래 현재 그릇과 곁에서 받치는 실제 손의 위치를 보고 그릇 소유자에게 빼낼 방향을 묻는다. 들어 올리기 전 안전 받침/놓을 자리와 동료의 손빼기 신호를 모두 확인한다.
2. 모두가 동의한 손빼기 신호를 맞춘 뒤 헤라클레스가 짐1덩이를 실제 들어 올리면 플레이어는 밑의 기존 그릇1을 안전하게 빼거나 신호역할을 수행한다. 짐을 허락된 놓을자리에 내려놓아 물체UUID·소유권을 유지. 그릇이 없는 다른 구조로 원문 사건을 대체하지 않는다.
3. 작업 뒤 소유자와 손상 유무1항목 이상·남은 위험을 확인하되 기존 손상/이번 작업 손상/원인 미확인을 나눈다. 근거 없이 책임을 단정하거나 시험용 파손을 만들지 않는다. 허락된 수습1행동: 흩어진 자기 물품 반환 또는 기존 통로의 허락된 블록1 재설치. 남은 수습이 없으면 이상없음 현장 확인으로 끝낸다.

## 선택과 결말
구조 상황이 없으면 새 위기를 만들지 않고 생활대화. 물건 소유자 거절은 이동중지, 이미 옮긴 것은 안전한 허락자리로만 내려놓는다. 구조성공과 수습완료는 별도, 위험이 남으면 부분완료·지도보류. 기존 개인 MAIN 소유자 문구를 여기의 MAIN 생성권으로 쓰지 않는다.
들어 올린 뒤 남은 손에서 플레이어가 실제 선택한 행동과 그에게 나타난 반응
헤라클레스는 다음 작업의 들어 올리는 시점을 동료에게 맡기고 공동 구조를 선택한다. 이올라오스·데이아네이라의 현재 응답은 발명하지 않는다.
