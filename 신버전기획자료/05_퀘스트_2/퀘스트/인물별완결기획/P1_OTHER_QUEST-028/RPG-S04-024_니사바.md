## 장면과 참여

잘 쓴 글과 빠른 셈을 좋아하며 설명을 시작하면 기세가 붙는다. 그러나 상대가 못 알아들으면 자신이 아끼는 표현도 짧게 고친다. 가르친 글이 속임수의 장식으로 쓰이면 가르친 즐거움마저 더러워진다고 느낀다. 같은 무게인데 모양이 다른 씨앗을 나란히 놓는 일을 즐기며 틀린 글씨 옆에 더 쉬운 글씨를 남겨 비교한다.

부족분0이면 만들지 않는다. 있되 미수신/허락 없음이면 인계 대기이며 최종 완료0. 표시 모양을 지키자는 고집은 실제 개선 실패. 연습 표시값과 세계 실제 단위 혼동 금지.

장터 허락 비교면 O의 저울A/B를3블록 간격으로 놓고 구매자 선택면은 O에서4블록. 판매재고와 연습재고는 별도 통.

개별 명시 수락으로 자기 몫에 참여한다. 공통 계약의 접근·실패·정산·후발자 정책을 적용한다.

## 실제 수행

### 실물 계량

같은 빈 그릇1개를 먼저 저울 A/B에 각각 올려 빈값을 기록한 다음, 같은 그릇에 같은 밀8개 묶음을 넣어 A/B에 각각 실제 올린다(빈 그릇2회+채운 그릇2회=4측정). 연습 기준은 밀1개=표시1, 빈 그릇=2(세계 화폐·실제 질량 정의 아님). A 빈값2·합계10이면 순량8, B에 검증된 일정 영점 오프셋+2가 있으면 빈값4·합계12이고 각각 자기 빈값을 빼 순량8이다. 차감 후에도 차이가 남으면 실제 관측값 그대로 미검증 표시하며 조작을 단정하지 않는다. 하야가 실제 검증해 전달한 자료가 있으면 해당 저울 기준과 대조하고 없으면 현재 관측과 미검증 원인을 구분한다.

판정: 같은 그릇uuid·같은 밀 묶음uuid, A/B 빈값2회와 합계2회, 각 저울 순량=합계-해당 빈값, 자료 실제 수신 여부. 시간 제한 없음.

### 이용자 선택

확인된 기준으로 밀4개짜리 작은 묶음2개를 만들고 이용자가 고른 단순 표시1개를 붙인다. 구매자1명이 자기4개 몫을 실제 골라 저울에 올리고 뜻을 설명하도록 한다. 틀리면 그 표시만 고쳐 같은 미완료 시도를 재개한다. 공식 답만으로 통과0.

판정: 실제 선택된4개/현재 기준, 이용자 설명 수신, 이해 실패면 통과0. 시간 제한 없음.

### 부족분 인계

확인된 실제 거래 손실이 없으면 니사바에게 없음으로 확인해 닫는다. 손실이 있으면 거래당사자 허락 범위의 실제 부족량·출처를 난셰에게 직접 전달하여 수신 확인한다. 연습 저울 차이를 실제 피해로 발명하지 않는다.

판정: shortfall 실제값, permission, 난셰 수신 또는 no_shortfall 확인. 시간 제한 없음.

## 원래 대안·완료 경계

원문 B1: 사용 허락을 받은 같은 곡물 묶음을 양쪽 저울에 번갈아 올리고 빈 그릇의 무게를 먼저 뺀다. 하야가 실제 검증해 전달한 자료가 있으면 해당 저울의 기준과 대조하고 없으면 현재 관측과 미검증 원인을 나눈다.

- 손으로 같은 비교를 재현한다: 비교 가능한 차이와 원인 확인/미확인 구분이 남는다. 수치 정답만 말한 것과 다르다.

- 공식만 외워 설명한다: 설명은 들었으나 실제 계량 개선은 미확인. 실물 비교로 돌아갈 수 있다.

원문 B2: 확인된 기준에 맞춘 작은 실물 묶음을 만들고 이용자가 고른 단순 표기와 대조한다. 실제 다음 거래 당사자의 허락을 받아 그 사람이 자기 몫을 골라 저울에 올리게 한다. 잘못 고르면 어느 표시가 헷갈렸는지 물어 그 부분만 바꾸어 다시 확인한다.

- 이용자 표기로 실제 거래를 확인한다: 실제로 이해·사용한 거래만 남는다. 확인된 부족분이 있으면 인계 후보가 된다.

- 멋진 글씨를 그대로 두자고 주장한다: 이해 실패가 남고 실제 개선 완료는 없다. 수정 후 재시도 가능.

원문 B3: 부족분이 있으면 출처·확인 범위·아직 돌려받지 못한 양을 해당 당사자 허락 아래 난셰에게 실제 전한다. 난셰가 듣거나 읽은 범위만 기록한다. 부족분이 없으면 확인된 이 거래에는 없다고 니사바에게 말하고 마친다.

- 있는 부족분만 실제 전달한다: 수업과 인계 완료. 반환·청원 판정은 별도이며 아직 없음.

- 부족분 없음으로 수업을 닫거나 인계만 기다린다: 없는 부족분을 생성하지 않는다. 미수신 인계는 최종 인계 완료가 아니다.

같은 물건의 실제 비교로 오류 근거를 확인하고 이용자가 고른 표기와 실물 묶음으로 현재 다음 거래를 실제 해 보아 이해 여부를 확인한다. 확인된 부족분이 있으면 당사자가 허락한 내용만 난셰에게 실제 전달·수신 확인. 부족분 없음은 없다고 마치며 환급은 이 SIDE가 자동 실행하지 않는다.
