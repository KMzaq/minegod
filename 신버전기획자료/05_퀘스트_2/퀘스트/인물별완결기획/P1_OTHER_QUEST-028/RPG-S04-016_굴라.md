## 장면과 참여

## 실제 수행

### 구호와 접근

굴라가 지정한 환자1명과 구호품6개(깨끗한 천용 흰 양털2, 물병2, 빈 그릇2)를 용도별 통에 직접 분류한다. 환자 이동 동의를 받고 진료면까지 실제 동행하여 굴라 인수 확인. 물병은 음용/치료 효과를 자동 부여하지 않는 보통 소품이다.

판정: 분류6/6, 환자 동의·연속 위치·굴라 인수. 시간 제한 없음.

### 회복 인계 대안

판정: 다무 실제 인수 OR R 실제 도착+현재 담당 수행+굴라 확인. 시간 제한 없음.

## 원래 대안·완료 경계

원문 B1: 지시받은 보통 구호품을 용도별로 놓고 환자가 동의하면 진료 통로까지 동행한다. 명성 높은 이를 먼저 돕자는 제안도 굴라의 실제 임상 판단을 바꾸지 못한다.

- 굴라가 정한 급한 순서를 돕는다: 실제 접근·인수만 완료. 치료 결과는 굴라의 실제 판단을 기다린다.

- 유명한 방문객을 먼저 돕자고 한다: 대기 도움은 그 실제 기여만 남는다. 지정 구호·환자 접근 미수행이므로 다음 인계 장면으로 넘어가지 않는다.

원문 B2: 환자의 동의를 확인하고 다무가 있을 때 실제 인계에 동행한다. 부재하면 환자가 동의한 휴식 자리를 마련하거나 기다리는 동안 필요한 보통 돌봄을 돕는다.

- 다무에게 실제 인계한다: 인계 경로 완료. 다무는 실제 받은 정보만 안다.

- 임시 휴식으로 돌봄을 이어 간다: 환자가 동의한 휴식 자리에 실제 도달하고 현재 담당의 돌봄·굴라 확인까지 성립한 경우만 임시 돌봄 경로 완료. 다무 인수·치료 성공은 추가하지 않는다. 이동 거절·미도달이면 자리 준비만 보존하고 STOP으로 간다.

실제 구호품 정리·굴라 지시한 환자 접근을 돕고, 환자 동의 아래 다무의 실제 인수 또는 합의된 임시 휴식·대기 돌봄을 확인하면 해당 경로 완료한다. 치료 성공을 대신 선언하거나 다무 미수신을 인수로 쓰지 않는다.
