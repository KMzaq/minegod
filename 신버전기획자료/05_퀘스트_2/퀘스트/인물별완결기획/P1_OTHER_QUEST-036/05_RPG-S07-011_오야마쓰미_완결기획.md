### 완료와 원문 분기
실제 운반할 허락 짐이 있을 때 B2의 선택한 두 번 나르기 또는 일부 남긴 한 번 운반을 직접 마치고 B3에서 기존 폭 계속 이용 또는 이번 남은 운반 포기를 실제 선택·확인하면 이번 운반 SIDE를 닫는다. 짐이 전혀 없으면 현재 길 관찰만, 운반 완료 없음. 이와나가히메의 답·장기 계약은 별도다.

B1: 실제 옮길 자기 또는 소유자 허락 짐과 출발·도착·퇴로를 확인하고 SIDE 제안을 듣는다.
- 내 실제 짐으로 운반을 맡는다: 운반 선택과 수락만, 아직 도착 없음.
- 짐 없이 길만 본다: 오늘 길 관찰만. 없는 짐 분할·반환·운반 완료 없음.

B2: 짐을 나누어 두 번 직접 나르거나 일부를 허락된 보관 자리에 남기고 한 번만 옮긴다.
- 나누어 두 번 나른다: 실제 두 운반이 끝난 때만 전체 선택 몫 도착. 도중 중단은 부분 운반.
- 일부를 남겨 한 번만 간다: 실제 도착 몫과 남은 짐. 남긴 것을 소비·포기한 소유권으로 자동 변환하지 않는다.

B3: 기존 폭으로 현재 이용을 계속할지, 이번 남은 운반을 포기하고 안전하게 돌아갈지 자신의 선택만 말하고 실행한다.
- 기존 폭으로 계속 이용한다: 현재 운반·이번 이용 응답만. 딸의 뜻·장기 산길 계약 아님.
- 이번 남은 운반을 포기한다: 이미 한 운반 보존, 미실행 몫 중단. 이용 포기 자체를 모욕·벌금으로 바꾸지 않는다.

B4: 본인이 직접 말하고 싶고 오야마쓰미에게 전해도 되는 현재 조건에 대해 현재 전달 요청과 공개 허락을 확인한다. 상대 본체에 실제 접근해 허락된 요청만 전하고, 실제 답 중 돌아가도 되는 부분만 원요청자에게 가져온다.
- 이미 받은 허락 답을 원요청자에게 실제 전한다: 양쪽 실제 수신 범위만 각자의 지식. 오야마쓰미가 이와나가히메의 실제 조건을 들은 뒤 산의 값과 별개 답으로 남긴다. 장기 계약은 현재 모든 당사자 실제 응답 전 성립하지 않는다.
- 상대가 명시 거절한 답만 전한다: 실제 거절 수신만. 긍정 응답에 따른 관계 변화는 없음. 기존 개인 결과는 보존.
- 요청은 닿았지만 아직 답이 없다: 요청 수신·답 대기. 무응답을 거절·찬성·배신으로 만들지 않는다.

- 현재 상대를 만나지 못했거나 연락을 사양한다: 상대 수신·답·소개 성립 없음. 요청하지 않은 문의를 보냈다고 하지 않는다.
