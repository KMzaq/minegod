## 인물의 선택

팔라메데스는 경쟁에서 이기고 싶지만 누구의 마음까지 승리의 물건으로 삼고 싶지는 않다. 인정받으려 바꾸어야 한다는 요구에 지쳐 자기 방식의 쓸모를 행동으로 보여 주려 한다.

트리스탄의 경쟁자라는 이름을 넘어 자기 방식의 추적 능력을 인정받고, 신앙이나 연애를 양보하지 않아도 성립하는 협력을 만들고 싶다.

## 실제 플레이와 판정

### 공통참조

### 장소와실물

기존 숲길 두 흔적의 마른 분기점. 실제 발자국/trail receipt가 있는 현장만; 미구현 흔적은 발자국 판정·시각 자산 구현 요구이며 임의 문장으로 발견 생성 0. 각각 길을 따라24~48블록 범위의 두 갈림과 귀환점.

### 행동

- B1 두 갈림의 서로 다른 실제 흔적 1곳씩을 8블록 내 시야에서 확인하고 각 방향 굽이까지 실제 왕복. 새로운 끈 표식은 선택이며 기존 알아볼 지형 표지로도 가능, 타인 흔적 훼손 0.
- B2 준비와 철수 기준을 실제 정한다: 길이 끊김/낙차 3블록 이상/활성 적이 귀환로를 막음/동행자 5블록 이탈 중 1 발생 시 안전점 복귀. 감당할 끝점과 관측 가능흔적 범위를 계약 판본으로 확정. 실제 끝점 도달 OR 기준 도달 후 실철수·관측 범위 공유.
- 트리스탄이 실제 다른 구간 근거를 전달할 때만 출처를 붙여 합침. 경쟁/공동 추적 거절 시 단독 결과도 정상. 공격·포획은 요구하지 않는다.
- B3 팔라메데스에게 실제 지점/끊긴 곳/미확인을 수신시킨다. 자기 표식은 실제 회수, 부재면 위치와 미회수 의무 보존. 미확인 정답 강요·이졸데 거절 번복 거래는 실제 발언을 알게 된 뒤 공동 추적 중단.

### completion_guard

두 방향 실확인 AND 선택 끝점 왕복/철수 기준에따른 실복귀 AND 정직한 관측 수신. 안전 철수는 확인 범위 성취/지도만, 미확인 목표 발견·포획 성취 0.

### 보상실인도

확인된 흔적 현장 지도 1회. 현재 실제 신선/오래된 흔적이 각각 있을 때 표면 겹침/끊김을 8블록 내 비교; 없으면 이번 확인 흔적의 한계만 설명. 초능력 추적·목표 자동 표시 0.

### 시간

전체 시간제한 없음. 8~14분 예상(정적기획 추정, 실측 아님).

## 선택 결말과 보존 경계

해당 quest 성공 완료는 정상 선택 경로의 필수 실행·접수·NPC 판정이 실제 충족된 때만이다. 실패·미수신·위반·부분 결과는 해당 경로의 종료 또는 보류이며 성공 완료가 아니다. 실제 선택·실행한 경로의 결과만 확인한다. 아래 서로 다른 결과를 동시에 부여하지 않는다.
준비와 철수 기준을 정해 답사한다: 자기 발견과 상대 관측이 구분된 협력 근거가 남는다. 같은 신앙·연애 양보·목표 공격을 요구하지 않는다.
위험 때문에 철수하고 확인 범위만 공유한다: 안전 답사 범위와 한계는 성취로 남는다. 끝까지 발견·포획 성과 없음. 확인 범위 지도만 가능.
미확인 정답이나 사적 거래를 강요한 결과: 시간과 위험이 남고 발견 보상·사적 거절 번복 없음. 이졸데 현재 참여를 만들지 않는다.
