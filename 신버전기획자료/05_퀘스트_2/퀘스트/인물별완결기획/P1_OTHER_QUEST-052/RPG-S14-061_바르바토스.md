# 바르바토스 — 둥지 위의 지름길

관리키 RPG-S14-061 · 정의 EP035A-RPG-S14-061 · 하급 · SIDE / 신규 MAIN 없음

사람이 떠드는 동안 놓친 작은 울음에 귀를 돌리고, 길 안내를 자신의 호의로 여기는 까다로운 동행자다. 설명은 짧고 듣는 시간이 길다. 큰소리로 재촉하면 대꾸보다 손짓으로 조용히 시킨다.

## 현재 요청
길을 찾는 이들이 둥지를 망가뜨리지 않고 지나갈 여지를 남기고 싶다.

## 실제 수행
1. 둥지 1곳을 4~8블록 밖에서 관찰하고 실제 들린 소리·통행선·둥지 가장자리를 기록한다. 둥지 경계 3블록 밖을 유지하는 기존 바위 옆길 12~24블록을 답사한다.
2. 원소유 허락 짐 1묶음은 들고 웅크려 높이 2블록 이상 통로를 통과한다. 실제 폭이 부족하면 억지 통과하지 않는다. 원래 소유자 또는 지정 보관자에게 반대편에서 인수시킨다.
3. 이동 중 실제 적이 접근하면 도착 이전에도 방어/철수로 즉시 전환한다. 둥지 반대쪽 8블록 이상 안전 지점으로 유도하되 새로운 적은 소환하지 않는다. 공격 없으면 무훼손 우회와 현재 안전만 확인한다.

## 완료와 갈림길
무훼손 우회 도착 OR 실제 공격 중 둥지에 위험을 넘기지 않은 안전 철수. 단순 미이동·공격 없음은 성공 아님.

- 둥지 밟기·위협 유도는 손상/위협을 남기고 안내 없음. 소리 중단으로 생사 추측 금지.
- 통과 포기는 안전 종료이나 미수행 보상 없음.
- 실제 공격 없음은 정상 우회 대안이며 방어 공적을 만들지 않는다.

## 말과 반응
- “쉿. 네 짐보다 작은 소리부터.”
- “빨리 갔군. 그래서 저 소리가 사라진 건가?”

## 보상과 선택 수령
현재 안전한 우회 관측점 1곳 안내, 정상 수행자별 사건 1회. 바르바토스가 현재 확인한 지점을 4~12블록 거리에서 가리키고 플레이어가 직접 시야로 확인하면 제공 완료. 안전 영구보증·전투 보상 없음.

정상 사건별 실제 수행자 최초1회. 같은 사건 재개는 미수령/미지도 잔여만. 새 사건을 자동 발생시키지 않는다.

## 중단·재개·지식
공통실행계약의 체크포인트, 원물 장부, 영수증 대조, 실제 청중 규칙을 적용한다. 미수신을 수신으로 만들지 않고 완료한 행동을 재연하지 않는다.
바르바토스는 위험을 다른 생물에게 떠넘기지 않은 실제 행동을 기억하고 다음 길의 관찰 지점을 알려준다. 손상된 둥지는 말로 복구되지 않는다.

## 구현과 예상
공통 권위 동작·소품·원물·응답 저장 연결. 새 전투 시스템 없음.
예상 5~10분. 실제 API·게임·LLM 시험은 하지 않은 기획값이다. 지도는 비전투 경험이며 전투 능력 보상이 아니다.
