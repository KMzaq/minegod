# 구시온 — 서명 뒤의 무게

관리키 RPG-S14-064 · 정의 EP035A-RPG-S14-064 · 중급 · SIDE / 신규 MAIN 없음

화해했다는 선언보다 그 다음날의 빈손을 오래 바라보는 끈질긴 중재자다. 차분하게 같은 질문으로 돌아온다. 대답을 회피하는 농담에는 웃지 않고 기다린다.

## 현재 요청
서명만 남은 화해가 실제 배상 한 번으로 이어지는지를 끝까지 보고 싶다.

## 실제 수행
1. 실제 배상 당사자 2명과 합의서를 함께 확인한다. 이번 소규모 운반 채택량은 온전한 판자 8개; 기존 합의가 다른 품목/정수량이면 양쪽이 실제 수락한 변경량을 시작 전에 고정하고 원합의는 보존한다. 변경 미합의면 원량 수행 또는 이행불능 부분종료.
2. 받는 지점을 8~16블록 기존 평지에 정한다. 기본 판자8개 합의일 때는 4개씩 2회 운반·인수한다. 다른 품목/정수량 N이 이미 유효하게 합의됐으면 그 실물을 현재 안전한 회차별 분량으로 나누어 누계 N만 운반·인수하고 기본 판자/8개를 추가 요구하지 않는다. 물품 창고 등록 원량이 적으면 부족량만 남기며 지급/배상 물자를 생성하지 않는다.
3. 실제 파손을 수령자와 확인한다. 책임자가 자기 허용 재료로 실제 수선하고 수령자가 수선품을 확인·인수한 몫을 온전한 이행으로 센다. 기본 판자 예시에서 수선 대신 동일품 교환을 양측이 실제 수락한 때만 책임자 소유 온전한 판자1개와 불량1개를 교환하고 불량은 책임자에게 반환한다. 대체재 합의는 해당 품목의 실제 수선 또는 별도 합의 교환을 적용한다. 파손 없으면 수선·교환 목표0. 원물·수선 소비재·교환품·환수 불량은 별도 장부로 남기고 온전한 인수 누계를 다시 확인한다.

## 완료와 갈림길
온전한 실제 인수 누계가 해당 합의량에 도달하고 양측 이행 확인을 구시온이 받은 범위만 완료. 수정 협의 승인≠인수.

- 서명만 제시하면 미배상.
- 8개 중 6개 인수/2개 파손이면 이행 6·잔여 2, 전체 완료 아님.
- 정직한 부족은 부분결말, 파손 은폐는 별도 위반.
