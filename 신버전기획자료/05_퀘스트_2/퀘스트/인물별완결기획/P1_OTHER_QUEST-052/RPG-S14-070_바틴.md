# 바틴 — 돌아올 짐의 자리

관리키 RPG-S14-070 · 정의 EP035B-RPG-S14-070 · 상급 · SIDE / 신규 MAIN 없음

빌린 물건을 놓을 빈자리와 돌아올 길을 먼저 살핀다. 속도에 들뜨지 않고 귀환을 물으며, 돌아와 달라 보이는 평범한 풍경 이야기에 오래 귀를 기울인다.

## 현재 요청
급행을 원하는 사람도 돌아갈 방법을 잃지 않는 이동 약정을 만들고 싶다.

## 실제 수행
1. 입구 A·귀환점 B를 기존 열린 길 16~32블록에서 발로 확인한다. 표지 2개를 허락된 A/B에 놓는다. 기존 우회 C를 추가 답사 OR 빠른 길만 확인한다. 우회 미답사를 실패로 강제하지 않는다.
2. 자기 조약돌 4개 또는 이미 가진 평범한 짐 중 협의한 정수량 1~8개를 보관자에게 실제 맡기고 품목·수량·인수 기록을 남긴다. 보관 허락 없으면 위탁 완료 없음.
3. 열린 길로 실제 왕복 OR 현재 바틴이 수락한 제한 이동으로 B 도착 뒤 A 귀환한다. 새 이동 능력을 부여하지 않는다. 귀환 시 보관자가 맡은 정확한 물품을 인도하고 플레이어가 인수한다.

## 완료와 갈림길
허용 왕복·실제 귀환 AND 실제 맡긴 짐 회수. 추가 짐이 타인 자리를 침범하면 자기 짐을 줄여야 한다.

- B 막힘이면 대기 OR 실제 열린 C 우회. 귀환 전 성공 없음.
- 다른 귀환자 밀어냄은 피해·미완료, 빠른 도착으로 상쇄 안 됨.
- 보관자 부재는 실물 회수 대기이며 재접속으로 새 짐 지급 안 됨.

## 말과 반응
- “돌아왔을 때 놓을 자리부터 비워 두자.”
- “빨랐다는 건 알겠어. 맡긴 네 짐은 받았나?”

## 보상과 선택 수령
검증한 왕복 경로 1건 안내. 60초 내외로 실제 본 갈림길·귀환점·막힘 대안을 짚고 현재 설명 수신을 기록. 포털/상시 순간이동 없음.

정상 사건별 실제 수행자 최초1회. 같은 사건 재개는 미수령/미지도 잔여만. 새 사건을 자동 발생시키지 않는다.

## 중단·재개·지식
공통실행계약의 체크포인트, 원물 장부, 영수증 대조, 실제 청중 규칙을 적용한다. 미수신을 수신으로 만들지 않고 완료한 행동을 재연하지 않는다.
바틴은 실제 귀환을 마친 요청만 재이용 근거로 삼는다. 공간 개방·포털 발명·다른 사람 강제 이동은 없다.

## 구현과 예상
공통 권위 동작·소품·원물·응답 저장 연결. 새 전투 시스템 없음.
