# 아가레스 — 돌아가는 사람의 발

관리키 RPG-S14-056 · 정의 EP035A-RPG-S14-056 · 상급 · SIDE / 신규 MAIN 없음

말을 가르치는 즐거움과 돌아온 자를 다시 떠나보내야 하는 불만을 함께 가진 통역자다. 느린 복창 뒤 짧은 정정을 붙인다. 가르칠 때는 즐겁게 까다롭지만 거짓 통역 요청에는 말수가 줄어든다.

## 현재 요청
이동 요청에서 ‘돌아가겠다’와 ‘돌려보내겠다’가 뒤섞이지 않는 귀환 문답을 만들고 싶다.

## 실제 수행
1. 여행자 1명·동행인 1명의 말을 따로 실제 듣는다. 의뢰인 말과 여행자 답을 각각 기록하고 운반 허락을 받은 짐 1묶음의 원소유·내용 수량을 확인한다. 직접 선택한 잔류점 또는 열린 귀환 구간 끝을 8~24블록 안의 기존 안전 지면으로 정한다.
2. 이동 직전 여행자의 현재 답을 재확인한다. 잔류면 의뢰인에게 삯을 받지 않고 귀환을 수행하지 않겠다고 실제 알린 뒤 짐과 여행자를 잔류점에 둔다. 귀환이면 여행자와 함께 열린 구간을 걷고 짐을 인수시킨다. 번복하면 즉시 멈추고 새 방향만 따른다.
3. 아가레스가 실제 잘못 옮긴 주어가 있을 때만 여행자 앞에서 정정한다. 오역이 없으면 의도적으로 만들지 않는다. 실제 이동·인수와 아가레스가 받은 정상 결과를 대조한다.

## 완료와 갈림길
잔류 OR 자발 귀환. 여행자 현재 의사·실제 몸과 짐 도착·인수 AND 필요한 오역 정정. 잔류의 실제 삯 포기 통지가 빠지면 보류. 바틴 인계는 선택 후기이지 정상 완료·지도권 선행이 아니다.

- 잔류/귀환 모두 정상. 번복 없는 여행자에게 답을 바꾸라 요구하지 않는다.
- 강제 견인·짐 탈취·번복 무시는 위반 종료, 다음 강제 통역 거절.
- 여행자 부재는 의사 미확인 부분결말. 바틴만 부재면 자기 정상 결과 보존, 선택 인계만 미수신.

## 말과 반응
- “돌아가겠다… 돌아가겠다. 좋아. 이번에는 누가 말했지?”
- “그 사람이 남겠다고 했다. 네 삯은 내가 번역할 말이 아니야.”
- 바틴에게 실제 전달 시: “돌려보내겠다는 청이 아니라, 본인이 고른 답이다.”

## 보상과 선택 수령
귀환 언어 지도 1회, 정상 수행자별 최초 1권. 시범 문장 2개를 듣고 주어를 바꿔 뜻을 설명하는 60초 내외 실습과 아가레스 피드백. 자동 번역·독립 스킬·물품 없음. 별도 비용 0.

정상 사건별 실제 수행자 최초1회. 같은 사건 재개는 미수령/미지도 잔여만. 새 사건을 자동 발생시키지 않는다.

## 중단·재개·지식
공통실행계약의 체크포인트, 원물 장부, 영수증 대조, 실제 청중 규칙을 적용한다. 미수신을 수신으로 만들지 않고 완료한 행동을 재연하지 않는다.
아가레스는 수정된 요청만 새로 받아들이며 플레이어가 강제 귀환을 꾸몄다면 다음 통역도 거부한다.
