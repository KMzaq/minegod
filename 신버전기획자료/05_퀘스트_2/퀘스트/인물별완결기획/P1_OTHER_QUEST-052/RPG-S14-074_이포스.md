# 이포스 — 물러날 용기의 자리

관리키 RPG-S14-074 · 정의 EP035B-RPG-S14-074 · 하급 · SIDE / 신규 MAIN 없음

엉뚱한 답과 허세의 빈틈을 즐기는 도발자다. 겁을 숨기는 큰소리에는 끼어들지만 물러설 이유를 자기 말로 하는 상대에게는 질문을 남긴다.

## 현재 요청
용감해 보이려는 사람에게 손실까지 자기 말로 고르게 하고 싶다.

## 실제 수행
1. 현재 HP/상태이상/착용 방어구와 들고 있는 자기 짐을 실제 확인한다. 기존 안전 갈림길에서 제한 구간 12블록과 철수점 6블록을 확인한다. 수치 컷/피해를 새로 만들지 않는다.
2. 자기 짐 1~8개를 허락 보관점에 두고 제한 구간을 건너 왕복 OR 출발을 중지하고 철수점으로 이동한다. 짐이 처음 없으면 위탁·회수 목표 0. 실제 위험이 커지면 즉시 철수 가능.
3. 돌아와 건넌 거리/철수 이유·놓친 몫을 이포스에게 설명한다. 맡긴 짐이 안전하게 회수 가능하면 실제 인수하고 불가능하면 현위치와 잃은 몫을 남긴다.

## 완료와 갈림길
제한 왕복 OR 실제 안전 철수 후 자기 손실까지 정직하게 설명. 위험 돌입이나 명예 주장만으로 인정 없음.

- 무리한 돌입은 실제 부상/패배/철수 그대로, 소급 성공 없음.
- 손실 숨기기·미수행 거리 과장은 허풍 결과.
- 미회수 짐을 솔직히 남겨도 원문 정상 자기판단 결과 가능, 가상 회수 금지.

## 말과 반응
- “빈손으로 돌아왔다고? 그럼 네 발은 데려왔군. 무엇을 놓았지?”
- “누가 웃을까 걱정했나, 아니면 네가 잃을 것을 봤나?”

## 보상과 선택 수령
보상 0. 용기 인정 자동 지급/영구 동행/회수품 복제 없음.

정상 사건별 실제 수행자 최초1회. 같은 사건 재개는 미수령/미지도 잔여만. 새 사건을 자동 발생시키지 않는다.

## 중단·재개·지식
공통실행계약의 체크포인트, 원물 장부, 영수증 대조, 실제 청중 규칙을 적용한다. 미수신을 수신으로 만들지 않고 완료한 행동을 재연하지 않는다.
이포스는 자기 도발에 휘둘리지 않은 상대에게 다시 위험을 물어볼 수 있지만 영구 동행을 약속하지 않는다.

## 구현과 예상
공통 권위 동작·소품·원물·응답 저장 연결. 새 전투 시스템 없음.
예상 4~8분. 실제 API·게임·LLM 시험은 하지 않은 기획값이다. 지도는 비전투 경험이며 전투 능력 보상이 아니다.
