# 모락스 — 틀린 이름의 표본

관리키 RPG-S14-073 · 정의 EP035B-RPG-S14-073 · 하급 · SIDE / 신규 MAIN 없음

이름표를 외운 사람보다 대상 앞에서 모른다고 하는 사람에게 시간을 준다. 손의 감각과 눈의 크기가 어긋나는 순간을 즐기며 표본에 맞추어 이름을 고친다.

## 현재 요청
관측과 약초 표본에서 이름표가 실제 대상을 가리지 않게 정리하고 싶다.

## 실제 수행
1. 실제 채집 기록이 붙은 비슷한 표본 2개를 작업면에서 비교한다. 본인 작은 시험 조각 각 1개만 접촉해 깨고 두 단면·촉감·채집 지점을 비교한다. 모재 2개는 보관하고 시험 조각 2개만 소비/파편 기록한다.
2. 원래 표지와 실제 차이가 확인되면 잘못된 이름표 1개를 정정한다. 근거가 불충분하면 미확인 부분종료. 처음부터 유효한 비교/파괴 이력이 있으면 다시 소비하지 않는다.
3. 오기 표본을 이미 받은 실제 연구자가 있으면 허락 정정을 보내 수신을 확인한다. 대상 없음이면 새 연구자 생성 0. 실재 대상 부재/미수신이면 정정 전달만 보류한다.

## 완료와 갈림길
근거 있는 비교·자기 표지 정정·실재 필요한 정정 수신 AND 모락스 판정. 실제 반출 대상 없음과 대상 부재를 분리한다.

- 이름표만 믿는 선택은 미검증 종료, 지도권 없음.
- 남의 표본 파괴는 손상 위반.
- 실재 반출 연구자 미수신은 부분결말이며 성공 지도/사본권 없음.

## 말과 반응
- “이름을 아주 잘 외웠네. 이제 이름표는 뒤집고 만져 보자.”
- “모르겠다는 말은 좋아. 이 조각이 말해 주지 않은 것까지 붙이지 않았으니까.”

## 보상과 선택 수령
표본 비교 지도 1회와 허용 비교 사본 1부 각각 별도 선택. 지도 60초 비파괴 비교·피드백; 사본은 복제 허락된 실제 기록 1장, 거래가치·스탯 0. 원기록 보유자가 준비한 실제 종이 1장만 소비, 수령 확인 전 지급 완료 없음.

정상 사건별 실제 수행자 최초1회. 같은 사건 재개는 미수령/미지도 잔여만. 새 사건을 자동 발생시키지 않는다.

## 중단·재개·지식
공통실행계약의 체크포인트, 원물 장부, 영수증 대조, 실제 청중 규칙을 적용한다. 미수신을 수신으로 만들지 않고 완료한 행동을 재연하지 않는다.
모락스는 정정에 참여한 실제 상대에게 다음 관찰을 함께 맡긴다. 미수신자는 아직 이전 이름으로 알고 있다.

## 구현과 예상
공통 권위 동작·소품·원물·응답 저장 연결. 새 전투 시스템 없음.
예상 7~12분. 실제 API·게임·LLM 시험은 하지 않은 기획값이다. 지도는 비전투 경험이며 전투 능력 보상이 아니다.
