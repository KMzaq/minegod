# 레라예 — 거둔 화살의 값

관리키 RPG-S14-067 · 정의 EP035A-RPG-S14-067 · 상급 · SIDE / 신규 MAIN 없음

끝난 싸움 뒤에도 상처를 기억하게 하는 일을 자기 솜씨로 여기며 쉽게 손을 놓지 않는다. 날카롭게 짧게 말하고 상대가 먼저 눈을 돌리는지 본다. 감탄을 들으면 잠깐 말이 길어진다.

## 현재 요청
사냥 중지를 청하는 상대에게 자신이 위협을 거두는 값과 경계를 직접 인정받고, 물러남이 굴복으로 기억되지 않게 하고 싶다.

## 실제 수행
1. 치료선과 레라예 사격선을 가르는 실제 불투명 바위 1곳을 확인한다. 치료 대상 1명의 비공개 소재를 말하지 않고 8×8블록 치료 구역과 연결된 폭 2·길이 12블록 후퇴선의 제한 휴지를 요청한다.
2. 회수 가능한 원화살을 1~3개 범위에서 실제 세고 이번 정수량 N을 레라예와 확정한다. N=0이면 회수 거래 미성립, 다른 값의 새로운 휴지는 별도 동의 없이는 만들지 않는다. 실제 휴지 응답 전 사격이 멎었다고 하지 않는다.
3. 실제 휴지 응답 뒤 차폐된 12블록 내 회수선의 N개를 접촉 회수해 레라예가 인수한다. 치료 완료/철수 확인 또는 합의 시작 후 활동시간 180초 중 먼저 도달한 때까지 위 구역의 해당 대상 사냥만 중지한다.

## 완료와 갈림길
실제 레라예 휴지 수락·준수 AND 합의 N개 반환/인수. 치료받은 이 소재 공개는 성공 조건 아님.

- 거절/공격이면 차폐·후퇴, 성공 휴지/평화 없음.
- 화살 빼돌림·실제 합의 침해는 현재 중지 파기 응답 확인, 과거 휴지 소급 삭제 없음.
- 화살 부족은 반환 잔여를 보류하며 임의 대체품으로 거래 성립 안 함.

## 말과 반응
- “세 개다. 하나를 숨기고 내 시선까지 거뒀다 우길 생각은 말고.”
- “내가 물린 활이다. 네가 꺾은 활이 아니야.”

## 보상과 선택 수령
사냥 중지 자체가 서비스 결과 1건. 물품·스킬·영구 평화 0. 전투 발생 시 기존 NPC 공격/방어 체계 사용, 새 보스/무기 수치 없음.

정상 사건별 실제 수행자 최초1회. 같은 사건 재개는 미수령/미지도 잔여만. 새 사건을 자동 발생시키지 않는다.

## 중단·재개·지식
공통실행계약의 체크포인트, 원물 장부, 영수증 대조, 실제 청중 규칙을 적용한다. 미수신을 수신으로 만들지 않고 완료한 행동을 재연하지 않는다.
레라예는 자신이 실제 거둔 위협의 범위를 기억한다. 위반하면 사냥 금지 합의는 깨지고 피해·소비가 남는다.

## 구현과 예상
활동시간은 해당 현장 권위 시뮬레이션이 진행하는 시간. 전체 현장 언로드 시 잔여시간 저장; 한 참가자 로그아웃으로 다른 현장의 휴지를 무한 연장하지 않는다. 범위·기간·N은 실행 전 실제 수락해야 하며 불수락은 원문 거절 분기로 간다.
예상 5~9분. 실제 API·게임·LLM 시험은 하지 않은 기획값이다. 지도는 비전투 경험이며 전투 능력 보상이 아니다.
