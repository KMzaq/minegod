## 실제 진행

1. 필요한 원목4를 실제 채집/운반하여 작업대 재료통에 놓는다. 소유권 없는 나무를 파괴하지 않는다. 플레이어와 치트랑가다가 자기 확보분과 남은 제작 일을 나눈다. 남음 경로에서는 판자16→상자2 제작으로 이어가고, 떠남/제안 부재 경로에서는 현재 원목·판자·완성품을 구별해 미완 작업을 남길 수 있다. 플레이어는 원목2 이상 실제 운반 등 사전에 맡은 재료 확보 역할을 수행하며 제작만 했다고 미수행 채집/운반을 소급 기록하지 않는다.

2. 아르주나의 방문 제안이 실제 수신된 경우에만 남을지/떠날지/날짜 변경을 치트랑가다가 결정한다. A(남음)는 함께 실제 제작창에서 판자16→상자2를 완성하고 자기 상자1을 작업터에 놓아 실제 물건1을 넣어 쓴 뒤 다음 가능한 시간을 제안한다. B(떠남)는 현재 남은 원목/판자와 미완 제작·설치·정리 범위를 실제 동의 인수자에게 넘기고, 인수자가 원물ID·수량·남은 책임을 확인한다. 치트랑가다가 귀환제안 기간을 Minecraft1일(활성20분)로 말하되 실제 상대 응답이 있으면 그 기간을 우선 저장한다. 짐을 꾸려 안전한 출발선 O에서8블록 밖으로 실제 나가는 것을 확인한다. 제안 기간은 자동 귀환·상대 동의나 새 플레이어 실패 마감이 아니다.

3. 떠남 경로에 인수자가 없거나 거절하면 책임을 떠넘기지 않고 출발을 보류하거나 치트랑가다가 실제로 남는 선택을 새로 한다. 아르주나의 현재 제안 자체가 없으면 가상 재회를 만들지 않고 실제 여행 짐1을 꾸려 현재 남은 재료를 허락 보관처에 놓아 자기 원정 준비를 마친다. 치트랑가다는 실제 채집·제작·인계/준비를 확인하고 해당 경로를 종료한다. 상자2가 실제 완성되고 소유자와 분배가 합의된 경우에만 약정 수령자 상자1의 권리가 생기며 실제 인벤토리에 전달한다. 위탁 제작 미완이나 자기 준비 완료만이면 SIDE는 끝날 수 있으나 상자 보상권은 아직 미발생이다. 가족의 현재 위치나 새 동행을 자동 생성하지 않는다.
