# 힌두 지역 퀘스트 공통 계약

## status

채택된 완결 저술 기획. 실행 스키마 아님; 실제 구현·API·게임시험 미실행.

## access

인물 본체는 세계에 하나. 기존 세계 해금은 누군가 성립시 공용이며 개인 퀘스트로 다시 잠그지 않는다. 개별 최초 출현의 기존 미확정 상태를 임의로 초기/후기 고정하지 않는다. 현재 본체·봉인·출입·의사 확인 뒤 4블록 안 실제 접촉에서 범위·비용 제시와 개인 명시 수락을 저장한다. 대화·관찰·퇴장은 수락 없이 가능. 순차 현장 작업은 1회차만 활성; 다른 요청은 기존 동의 참가자로 합류하거나 대기하며 본체 복제 없음.

## ledger

canonical episode ID가 있으면 그것이 저장키다. 새 설계 alias는 같은 canonical→world_site→attempt→player 원장에 해석한다. canonical 완료 후 alias 조회·재수락·재접속은 새 권리를 만들지 않는다. 새 사건은 Q-{관리키}-01 저장키. 시도는 현장 수락 때 단조 증가하며 중단/로그아웃/사망은 같은 시도. 실제 다음 별도 의뢰만 새 회차, 최초보상 한도는 회차와 무관하게 개인 canonical키로 유지.

## save

수락명부·선택·행동 좌표/시간·소유자·실물ID·재고 전후·NPC 응답·실제 청중·미지급권을 저장. 보상 예약→소유권 이전→수령 완료는 동일 거래ID로 원자 처리한다. 가방 부족은 지급대기, 자동 땅 드롭 없음. 응답 유실은 인벤토리/거래 결과를 조회하고 미지급분만 재시도. 실제 소실한 지급물은 자동 재지급하지 않는다.

## interruption

거절은 미수락 또는 중단이지 실패 위장 완료가 아니다. 사망은 실제 일반 손실을 유지하며 미수행 행동을 진행하지 않는다. 로그아웃은 새 시간벌금이나 현실48시간 마감 없이 저장한다. 위험 작업만 안전 중지. 돌아오면 현장·배우·동의·실물 잔량을 재확인하고 남은 작업부터 잇는다. 부분 이행은 잃지 않으며 원물 손실을 임의 추가 필수 채집 관문으로 만들지 않는다.

## late_join

후발자는 현재 남은 일에 새 동의 후 실제 자기 기여를 기록한다. 남은 일이 없으면 공개 기록 열람만 가능하고 과거 운반·식사·수락·공로·보상권은 받지 않는다. 원래 완료자는 재방문·연습 가능하나 현물을 재생성하지 않는다.

## knowledge

Story Fact는 실물 상태 변화/선택 결과/실제 인수 뒤 확정. 개인 지식은 직접 관측 또는 허락된 보고의 실제 수신 때만 별도 추가. 목격자는 목격, 보고 수신자는 출처 있는 전언으로 남긴다. NPC는 같은 현장 8블록 안 시야가 열린 수행만 관측하며 대화는 실제 수신한 청중만. 사적 고백·배상 사유는 당사자 허락 청중에게만; 경로·물건 현재 상태는 실제 관찰 가능. 모르는 전투력·사건·미래 결과를 신격으로 추론 확정하지 않는다.

## relationship

처음 만난 사람은 현재 작업을 설명하고 과거 신뢰를 가정하지 않는다. 같은 개인의 정직한 수행은 그 장면의 신뢰, 거절은 선택 존중, 속임수·무단훼손은 해당 작업만 보류하고 변경 근거를 요구한다. 개인 감정은 전쟁 진영·MAIN·가호·주시가 아니다. 관계 상대의 실제 응답이 없으면 서로 좋아졌다고 쓰지 않는다.

## implementation

기존 세계해금/단일 본체/물품·일반 이동·블록 상호작용 개념을 사용한다. 새 구현 요구는 수락·개인 수행 원장, 동일물 추적, 재고 예약·원자 인수, 상대동의·청중 수신, 아래 상대배치의 실제 부지 결속. 새 조리/훈련 판정은 기획 요구이며 설치된 API라고 주장하지 않는다. 새 능동기술·무기스킬·보스0. 일반 동작 애니메이션·연기 표시를 전투권능으로 부여하지 않는다.

## acceptance

- 물리행동 없이 정답만 말함→진행0
- 각 원래 A/B 대안 한 가지씩 성공시키고 선택하지 않은 대안을 요구하지 않음
- STOP·사망·로그아웃 후 실제 잔량과 미수행 부분만 재개
- 같은 canonical과 alias 동시 수령→거래1개·권리1개
- 후발 미참가자→현재 공개 사실만, 과거 기여/보상0
- 보상 가방부족→예약유지; 수령응답 유실→실지급 조회 후 미지급분만
- 원물 반환→같은ID, 보상/복제0
- 지도 거절→본 사건 완료 유지; 실습 정산은 독립
