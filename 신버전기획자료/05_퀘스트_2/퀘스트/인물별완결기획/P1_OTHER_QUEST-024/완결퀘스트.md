# 북방의 작은 약속과 손일

11인 비독점 에피소드 상세 저술. 실제 구현·서버 시험 완료를 뜻하지 않습니다.

## 공통 운영 계약

### status
채택된 상세 저술 설계. 로더 실행 스키마가 아니며 게임 등록·플레이 검증은 미실행.

### scope
11인 각1개 비독점 생활 퀘스트/이벤트/서비스 복합 에피소드. 개인 MAIN 신규0, 습득/무기스킬0. 원문 profile·정체·진영·생사·접근 계약은 관리키 참조로 보존하고 전승 사망을 현재 죽음으로 옮기지 않는다.

### unlock_and_acceptance
원문 세계해금/조우 후보 계약은 그대로 참조한다. 한 사람의 달성으로 세계 공통해금, 현재 조건을 만족한 사람이 조우 주체. 이미 등장한 동일 본체에 수주할 때 다시 개인해금/추첨하지 않는다. 아래 활동은 실제 본체·현재 접근/봉인/표현·의사·소유권·안전 확보 후 명시적 수락해야 시작. 질문·관찰은 수락 아님. 미해석 접근정보를 자유통과로 취급하지 않고 실제 세계 가용상태 확인 전 배치하지 않는다.

### ownership
episode_definition_id + player_uuid로 개인 수행·보상권을 저장, attempt_uuid로 각 시도 구분. 한 장소의 공유물은 object_uuid와 세대번호로 잠금, 실제 참가자1명과 선택적 보조 최대4명. 활동중인 NPC 복제 없음. 보조는 자기 기여/지식만 얻고 수주자 완료/보상을 복사하지 않는다. 후발자는 남은 작업에 실제 등록하거나 별도 새 시도에 참가, 끝난 최초회수·소유변화는 재생성하지 않는다.

### completion_and_ledger
준비→진행→중단/완료대기→정산 상태. 물리 수행은 서버 이동/접촉/인수/수량/시간/응답 로그로 검사한다. 각 개인 목표 직접 수행과 실제 최종 상태를 둘 다 검사하며 대사·정답만으로 완료하지 않는다. 보상권 생성과 아이템 소유이전은 원자적 거래키를 공유. 공간부족/접속끊김은 미수령권 저장, 실제 대면 재정산 때 미지급분만 지급. 재접속·재장착·재시도로 지급권·시간제한 초기화 금지. 서비스는 시작 아닌 실제 완료시 소비, 중단된 회복은 이미 회복한 HP를 원장에 남겨 남은 상한만 처리.

### death_logout_pause
사망·로그아웃·NPC 부재·현장 위험 시 새 행동 예약을 취소하고 중단 저장. 시간제한 없는 작업은 확인된 기여/소비를 유지. 경주·대련·수위·밀물의 진행중 짧은 시도는 중단 결과로 종료하고 새 시도로 시간창을 다시 열되 기존 물품/최초권리는 유지한다. 이미 발생한 세계손실/반환은 되돌리지 않는다. 위탁 작업물은 드롭 복제 없이 소유자 인수함으로 잠금회수, 실제 회수불가 상태이면 반환대기이며 전달완료 아님. 자기 일반장비의 사망처리는 기존 서버 규칙. 단순 퇴장·거절에 평판 전파/적대 생성없음.

### knowledge
실제 사건 완료후 fact_definition_id와 event_uuid를 만든다. 수행자와 직접 목격 NPC/청중에게만 관측 구간을 개인기억으로 전달. 기본 목격은8블록 내 시야, 청취는8블록 내 실제 전달·청중허락 모두 필요. 부재 NPC에게 자동 알림없음. 선택 이유는 사적 대화 수신자만, 물건 현재상태는 실제 재관찰로 배움. 전언은 출처·전달시각·원사건ID를 가진 claim이며 직접 경험으로 승격하지 않는다. 허락없는 내용·존재는 거절문/제목에도 노출하지 않는다.

### repetition_balance
기본 최초 개인권리1회, 별도 명시한 티아치 거래만 제한 반복. 지도는 설명/시범이며 K/J 습득 스킬·가호·장비로 등록하지 않는다. 호칭은 수치0. 원래 무보상 란 결말 유지. 평범한 생활재료는 일반등급이고 신성 장비 무한내구 규정을 적용할 장비가 아니다. 수선·운반·위치판단의 선택가치가 중심으로 전투성장 강제사슬 없음.

### support_boundary
기존 문서의 Story GRANT_REWARDS·RECOVER_REPUTATION 및 조건/보상 정의 기반을 참조하되 이 에피소드가 이미 연결되었다고 주장하지 않는다. 신규 요구는 개별 인수원장·공유물잠금·경로접촉/타이밍 판정·위탁회수·청중별 fact 전달·시범 애니메이션. 함수/action 이름은 엔진 지원으로 가정하지 않는다.

### site_selection
장소는 기존 발견 구조물 또는 원문이 허용한 자연부지에서 선정. 상대좌표 O와 통행/안전범위를 현장 배치값으로 바인딩한다. 개인 전용 건물·새 필수 NPC·새 차원·자동 부활 없음. 보호블록/타인소유 토지 수정은 허락없이 하지 않는다.

### 기존 SIDE와 서비스
기존 SIDE 연결: 각 인물 prior_episode_binding의 기존 에피소드와 이번 정의는 같은 사건이다. 완료·부분진행·실지급·미수령·소비·개인 기억을 한 원장으로 이관하고 양쪽 ID로 최초권리를 두 번 만들지 않는다. 기존 별도 서비스는 원문 모드 계약을 유지한다. 선택 지도·보상을 사양해도 이미 성립한 수행 완료는 유지한다.

목표: 상대가 자신의 한계를 어떻게 해석하는지 보고 성급한 힘자랑을 꺾으려 한다

### 장소와 수주
북방 감시탑 또는 폐허의 기존 평탄한 9×9 안전 공간. 중심 O에서 북쪽 그림판 A=(0,0,-3), 동쪽 관찰점 B=(3,0,0). 바닥 아홉 돌은 3×3, 간격 2블록. 서쪽 2블록 폭 출구는 항상 개방한다. 그림은 휴대 그림판이며 새 건물·환영 차원 없음.
해당 인물과 유효 접촉 후 이 활동 명시 수락. 다른 개인 MAIN/별개 SIDE 완료는 필수 아님.

### 실제 수행
1. 준비: 참가자가 정면 A를 3블록 안 시야에서 2초 관측한 뒤 시작돌을 밟는다. 첫 코스의 정면 순서 북→중앙→남→중앙은 실제 발걸음이 시작 근처로 돌아오는 고리다. 첫 실패를 말로 강제하지 않으며 다른 경로를 먼저 찾으면 선행 간파로 기록한다.
2. 두 번째 코스는 조건 공개 후 시작. 동쪽 B에서 2초 관찰하면 그림의 홈과 실제 돌 높이가 겹쳐 보인다. 공개 목표는 서로 다른 표시돌 4개를 최단 6걸음으로 연결하기. 시작 (−2,−2)→(0,−2)→(0,0)→(2,0), 각 인접 이동은 2블록이고 다른 돌을 밟지 않아야 한다. 좌표는 O 기준 x,z. 실제 네 돌의 접촉 순서와 누적 경로 길이 6~7블록(서버 이동 오차1)을 검사한다. 점프·비행·순간이동으로 건너뛴 구간은 재시도, 보행·질주 모두 허용.
3. 정답을 들은 참가자는 설명을 들었다고 표시한 별도 회전 코스(동서 반전)를 실제 걸어 마친다. 최초 간파자 사실은 주지 않되 공개 조건의 완수는 인정한다.

### 선택과 복귀
- 힘으로_반복: 정면 고리를 계속 걸어도 시도 수만 남고 성공은 아니다. 2회 뒤 출구와 옆 관찰점을 다시 알려 주며 강제 전환하지 않는다.
- 재도전: B 관찰과 두 번째 코스 완수 시 성공.
- 거절: 첫 속임수의 구조 설명을 들을지 고르고 종료. 설명 미수신자는 구조 지식도 받지 않는다.
재대결 거절 시 첫 속임수의 구조만 설명하고 끝낸다. 정답을 아는 후발자는 최초 간파자로 기록하지 않고 변형 코스에 참여할 수 있다.
사망·로그아웃·후발자는 공통 계약을 적용한다. 이 항목의 부분반환/실패는 이미 발생한 결과를 되돌리지 않는다.

### 보상과 비용
두 번째 코스 완수자에게 관점 풀이 지도 1회(60초 실제 그림 설명 서비스, 물품 아님), 공개 승부 호칭 「옆면을 읽은 자」 1개. 수치·가호·장비·토르 승패 변경 없음. 반복 코스는 연습 기록만 갱신한다.
비용0, 그림·돌은 거인 소유 전시물이고 가져갈 수 없다.
예상 5~9분. 수치 성장보다 해당 수행의 판단·관계와 작은 생활 자원에 맞춘 보상이다. 정적 기획 추산이며 플레이 검증값은 아니다.

### 관계와 지식
두 번째 코스를 풀면 거인은 속인 첫 승리보다 자신의 장치를 읽힌 즐거움을 드러낸다. 다음에는 이 플레이어에게 첫 단서를 조금 일찍 보여 준다.
- FACT-RPG-S02-041-SIDE01-01: 우트가르드로키, 실제 행동한 플레이어, 현장에서 해당 결과를 직접 본 청중만. 보지 못한 동료는 제외한다. 공유 물체 변화는 현장에 남지만 개인 선택 이유·친분은 실제 대화 수신자에게만 남는다. 사적인 대목은 본인이 허락한 청중에게만 말하고 비공개 수단이 없으면 보류한다. 후발자는 현재 물체를 보거나 당사자에게 공개 허락된 설명을 실제 들은 뒤 새로 배우며 당시 목격·완료를 소급 받지 않는다.

### 구현 인수 장면

## 티알피 · 빈손으로 돌아가지 않는 달리기
관리키 RPG-S02-042 / 정의 SIDE-RPG-S02-042-01 / 모드 quest, event
범위: 개인 MAIN 없음. 하급; 독립 개체; 이명·재출현은 한 명으로 집계
연결: 02_연결집필/P05_stage2.md#RPG-S02-042, 기존페르소나_인물별/RPG-S02-042/authoring_contract.json#/exact_scope_contract.

목표: 작은 실수를 숨기다 동료까지 묶이는 일을 되풀이하지 않으려 한다

### 장소와 수주
감시탑 밖 안전한 기존 길. 출발 O와 결승 F는 36블록 거리, 굽은 길 총48블록과 직선36블록을 현장에 맞춰 정한다. 양 경로 폭2 이상, 낙하1 이하, 위협 없음. 중간24블록 지점에 실제 짐 풀림 판정점.
해당 인물과 유효 접촉 후 이 활동 명시 수락. 다른 개인 MAIN/별개 SIDE 완료는 필수 아님.

### 실제 수행
1. 티알피와 참가자 각자 동일한 임시 짐 1묶음(빵4개)을 인수한다. 빵은 티알피가 소유한 운반물로 식용·판매 불가, 추가 무게 디버프 없음. 3초 출발 신호 후 O→중간점→F를 실제 이동한다. 경주 중 이동 스킬·비행·텔레포트 사용 시 그 시도는 기록 제외하며 보행 귀환은 계속 가능하다.
2. 티알피가 중간점에 도착하면 실제 끈 풀림 연출 뒤 자기 짐 4개가 경로 옆 6블록 안의 확인 가능한 네 지점에 놓인다. 참가자는 결승 먼저 통과하거나 돌아서 4개를 회수한다. 혼자 경주 중 티알피는 회수를 위해 멈추며 자동 완주하지 않는다.
3. 결승 선택은 실제 도착 시각으로 순위를 확정. 회수 선택은 각 조각의 소유ID·인수자와 F의 인계함에 4/4 반환한 사실을 확인한다. 참가자의 자기 짐4개도 반환해야 운반 종료다. 기록 승리와 회수 완료는 별도 사실이며 결승 후 회수해도 이미 얻은 기록을 소급 삭제하지 않는다.

### 선택과 복귀
- 기록: 먼저 F 통과한 기록 인정, 티알피 짐의 미회수 잔량은 계속 남는다.
- 함께_귀환: 결승 전 돌아서면 경주 도전을 중단한 기록과 함께 회수·느린 귀환 기록. 경주 패배를 승리로 고치지 않는다.
- 중단: 부족한 짐만 다음 방문에서 회수. 새 경주에는 기존 짐 원장 정산 후 새 동의 필요.
경주 거절은 토르에게 벌받을 이유가 아니다. 짐 손실은 현재 잃은 물건만 다루고 동료 탓으로 바꾸지 않는다. 다음에는 남은 회수 또는 새 경주를 고른다.
