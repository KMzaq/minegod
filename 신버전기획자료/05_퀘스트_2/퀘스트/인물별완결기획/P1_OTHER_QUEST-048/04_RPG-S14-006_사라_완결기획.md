## 실제 수행

1. 라구엘의 딸 사라 본인이 보존할 구석을 표시한다. 그 구석은 작업 대상에서 제외한다. 공동 잠자리1곳(바닥2×3블록, 높이2블록, 출입 폭1블록)을 기존 지붕 아래 정한다. 젖은 공동 침구를 허락받아6–16블록 옮기고 마른 침구의 실제 상태를 확인해 펼친다.

2. 현재 추가 손님이 있으면 각자의 이용 의사를 듣고 공동 침구/자리의 잔여수 C만큼만 받는다. 기본 추가자리1곳을 제안하되 실제 부족하면 부분 수용으로 남긴다. 남은 공동 침구의 건조는 지붕 아래 펼침120초와60초 때 뒤집기1회, 재젖음이면 마른 판정을 보류한다. 사라의 침구를 대체재로 강탈하지 않는다.

3. 사라가 정한 개방 시간에 실제 문을 열고 허락된 손님이 들어오는 것을 확인한다. 손님이 없다면 첫 마른 자리 마련까지만 남기고 추가 손님 입실을 생성하지 않는다. 토비아의 짐 나르기/라파엘 도움은 각각 사라가 청한 범위에 실제 답이 있을 때만 실행한다. 둘 부재는 자기 공동 작업을 막지 않는다.

4. 침구를 강제로 치운 경우 실제 원위치 복구와 사라의 새 의사를 따로 묻는다. 손님을 탓하거나 과거 죽음을 죄의 증거로 쓰지 않는다. 사과만으로 문이 다시 열리거나 기존 한시 이용이 영구권이 되지 않는다.
