## 실제 수행

2. 명시 수락한 플레이어가 맡은 한 구간을 걷는다. 짐이 있으면 소유 허락받은 묶음만 통로 옆 2×2블록 공간으로 실제 옮긴다. 처음부터 길이 비었다면 짐 치우기는 불필요하다. 굽이 너머는 실제 시야가 확보되는 위치에서 관찰한다. 통행자의 현재 속도에 맞춰 멈추며 6블록 이상 멀어지면 뒤를 확인한다. 거리 초과 자체는 실패나 순간 이동을 발생시키지 않는다.

3. 출발 동의자의 C 도달 또는 도중 자발적 잔류를 개별 확인한다. 도착은 C의 2×2블록 영역 실제 진입과 본인의 도착 확인, 잔류는 당사자의 실제 답을 증거로 한다. 길이 막히면 마지막 안전점까지 실제 돌아가 미완료 사람만 남긴다. 적 처치·출발 강요는 목표가 아니다.

4. 미카엘에게 누가 어디까지 갔는지 실제 보고한다. 민간 통과 사실과 남길 무장 경계 의견을 구별한다. 가브리엘의 전갈 대조·솔로몬의 경계 논의는 선택 후속이며 실제 수신/회신만 남긴다. 기존 C08/C16/C17 완료·해방·보급을 재지급하지 않는다.
