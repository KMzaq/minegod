# 이집트: 생활과 관계의 선택

11인의 선택적 퀘스트 읽기본. 신규 기획은 채택된 작업 기준이며 실제 등록·구현·게임 검증 완료를 뜻하지 않는다.

## 공통 진행과 보존

- 채택된 저술 설계. 실행 스키마/등록/구현/실플레이 검증 완료 아님.

- 11인 모두 해당 범위 개인 MAIN NOT_APPLICABLE. 별도 기존 MAIN과 공용 본편 권리·정산·세계 해금은 변경하지 않는다. 이 패킷에 새 보스·습득 스킬·무기스킬·가호를 추가하지 않는다.

- 현행 원문의 세계 해금·현 조우 조건·확률·단일 본체·봉인/부재 규칙을 그대로 참조한다. 누구 한 명의 세계 해금은 공유하되 개인 과거 수행을 후발자에게 재요구하지 않는다. 본 활동의 수락/작업 준비는 이미 나타난 본체와의 별도 단계이며 등장 확률을 새로 지정하지 않는다.

- 제시한 생활권과 실제 지형·소유자 허락에 맞는 기존 장소를 사용한다. 상대좌표는 안전 부지 중심 A 기준이며 장애물이 있으면 동일 거리/폭을 유지한 회전 배치. 검증된 공간이 없으면 활동 준비상태로 남기고 건물/NPC/유품/신규 사망을 생성하여 충족하지 않는다.

- 명시 수락 시 attempt_id와 수행자 UUID·참여시점·대상 물체ID·분기·실제 청중을 저장한다. 파티 가입만으로 수락/수령권이 생기지 않는다. 최초 수락자 독점은 없음. 공동 물체 작업은 action_id로 1회 반영하고 각자의 실제 역할을 연결한다. 최초 현장 수락 이후 합류는 남은 작업만 할 수 있으며 이미 끝난 단계 수행자로 소급하지 않는다.

- 각 필수 단계의 실제 서버 행동과 대상 상태가 증거다. 단계별 담당 참여자는 시작 전에 확정하고 실제 맡은 작업을 해야 개인 완료; 관전자·발언만 한 사람은 지식 수신만 가능. 선택 관계 방문은 양자 결과가 필요할 때만 별도 조건이며 독립 결말을 막지 않는다. 거절/손실/보호보관/미확인 결말과 협력 성공은 구분한다.

- 표시된 Minecraft tick은 월드 게임시각, 체류초·훈련초는 서버 활성 실행 시간이다. 전체 제한시간 없음. 개별 제한 대련60초 외 시간이 지나도 자동 실패하지 않는다. 게임밤/낮을 기다리는 동안 다른 활동 가능. 재접속으로 쿨/시간제한/소비/지급기록 초기화 금지.

- 거절은 수락 전 상태로 종료하고 불이익 없음. 중단은 마지막 검증 단계 저장. 사망은 원래 사망/드롭 규칙을 따르며 단계 진행을 보존하되 몸이 운반해야 하는 목표는 마지막 실제 위치부터 회수해야 한다. 로그아웃 중 현장 작업·대련은 중지, 세계 물체와 손실은 되감지 않는다. 재접속 시 본체·허락·물체·경로·위험·청중을 재검사하고 미완료 단계부터 재개한다. 대련 중 사망/로그아웃은 안전 무효 종료 후 같은 보상권 상태로 새 시도 가능. 손상·소모 재료를 공짜 복구하지 않는다.

- 위탁 유품/모형은 고유ID·소유자·보관자·현재 위치·허용 수신자를 관리한다. 판매/제작재료로 소비 금지. 사망시 일반 드롭 위치에서 같은 물건을 회수하며 소실이면 소실사건 및 반환 미완료를 남긴다. 복사본 생성으로 반환 완료하지 않는다. 로그아웃은 인계가 아니다.

- 제안→조건 충족 권리→재고예약/수업예약→실지급→수령확인의 원자 원장. 키는 플레이어UUID+보상ID+최초권리번호1. 인벤토리 부족/수신 실패/재고 부족이면 권리를 보류하고 미전달 몫만 복구. 아이템 실지급 뒤 응답 유실이면 해당 물품ID를 찾아 재확인하고 복제하지 않는다. 권리 거절은 이야기 성과 유지, 재제안은 같은 권리만. 지급된 물건을 잃은 것은 수령 실패가 아니며 영구 복구권 없음. 수업은 해당 지도 시간 및 시범을 마친 때 지급 완료, 배우지 않고 UI 수락만으로 성장 없음.

- Story Fact는 일어난 행동·현장·물체·시각의 사실, 개인 기억은 자신이 목격/청취한 범위, 평가는 NPC 발언으로 분리한다. 공개 현장 결과도 후발자가 직접 관찰/공개 기록 열람한 때 배운다. 친구·파티·세계 해금은 사적 지식의 경로가 아니다. 전달은 허용 내용·송신자·수신자·실제 읽음·응답을 각각 보존한다. 수신 확인 전 관계 상대의 협력/동의/새 지식 없음. 미래 완료 대사는 미리 기억에 넣지 않는다.

### support_boundary
- existing_game_basis: 실제 이동·블록 설치/제거·인벤토리·물·경작지·게임시각·원래 피해/사망 규칙을 사용하는 설계
- new_integration_requirements: 명시수락/역할/단계 증거와 세계/개인 상태 원장 / 물품 위탁·재고예약·수령 실패 원자복구 / 실제 청중 및 허용 전달 기반 지식 수신 / 생활 차양 이동과 국소 광열/흙탕/강풍 장면 상태 및 모델 / 테프누트 생활 식물 상태와 바닐라 작물 상태 분리 / 세트 제한 대련 안전정지·경계·목표선·외부 공격 중단 / 크눔 전용 용기 모델·물 상태·운반 사용 로그
- not_claimed: Java parser, 등록 ID, reload, 게임 테스트를 실행하지 않았다. authoring_id는 저술 식별자이며 엔진이 지원하는 action 필드라는 주장이 아니다.

- 비전투 생활 사건은 탐사·돌봄·관계·관측 방법의 가치가 중심이다. 8~25분의 실동작과 필요한 게임시각 재방문을 제안하며 반복 물자 농장은 차단한다. 수업은 숫자 능력치/독립 스킬이 아닌 실제 지도다. 라의 소량 건축 물자, 묘목1개, 생활용기1개가 전투 보상 등급 제한을 우회하지 않는다. 추정 시간·효용은 정적 설계이며 실전 검증 아님.

- 기존 SIDE와 이번 활동 ID는 prior_episode_binding대로 한 사건 원장을 쓴다. 기존 완료·부분결말·미수령·실지급·선택수업 이력을 보존하며 이중 최초권리를 만들지 않는다. 선택 지도·보상·후속 연락을 사양해도 이미 실제로 마친 핵심 행동의 완료는 유지한다.
