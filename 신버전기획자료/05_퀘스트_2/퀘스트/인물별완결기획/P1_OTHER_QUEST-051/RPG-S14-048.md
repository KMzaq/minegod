# 보현 · 두 번의 짐, 한 번의 약속
RPG-S14-048 | EP033B-RPG-S14-048 | 최상급 | SIDE | 예상 8~15분

보현은 좋은 결심을 들으면 곧 누구 손으로 할지를 묻는다. 실행을 좋아해 서두르기도 하지만 사람에게 끝없는 봉사를 떠맡기는 결심에는 동의하지 않는다.

## 현재 범위
문수의 질문을 실제 구호 약속으로 바꿈; 이행 상황에 따라 다음 여정 제안
현행 자료에서 개별 최초 일반 조우 시점을 확정할 근거가 부족하다. 옛 단계 템플릿만으로 전/후를 강제하지 않는다.
개인 MAIN을 만들거나 기존 본편 완료를 소급하지 않는다. 공통 수행·정산 규칙을 함께 적용한다.

## 장소
기존 구호 준비 자리와 쉼자리 사이 안전 경로24블록을 기준으로 두 왕복. 동선 중12블록 지점에 기존 쉬는 자리 사용. 새로운 길 건설 의무 없음.

## 실제 수행
1. 문수와의 실제 문답에서 나온 자발적 도움 의향을 확인한다. 오늘 감당할 총량 Q를 실제 물품2~8개의 정수로 협상하고 2개 운반 묶음으로 나눈다. 기본 빵4개+마른천2개는 예시 물량이며 기존 합의가 있으면 그대로 쓴다. 나눌 수 없는 물건은 보현의 몫으로 실제 배정한다.
2. 첫 묶음을 플레이어가 들고 목적지에 가서 인수시킨다. 보현은 약속한 가장 무거운 몫을 실제로 운반한다. 두 번에 나누기 경로는 첫 인수 후 빈손으로 준비 자리에 돌아가 두 번째 묶음을 받아 같은 안전길로 이동한다. 쉼자리는 비워 두며 중간 휴식은 선택이다.
3. 한 번에 끝내려 무리한 선택은 들 수 있는 실제 묶음만 옮기고 떨어뜨린/남긴 수량을 회수한다. 모드에 무게 시스템이 있다고 가정하지 않는다. 장면 운반 결속은 묶음1개만 동시 운반하게 하며 추가 묶음을 들려는 입력은 현재 위치에 남긴다. 실제 인수 합과 감당량을 대조하고 미운반분은 새 약속으로 따로 제안한다.

## 선택별 결과
실제 택한 한 경로의 결과만 남긴다. 서로 다른 경로를 AND로 합치지 않는다.
두 번 오가며 약속량을 줄인다: 합의한 감당 범위와 실제 인수량만 완료. 미운반분을 완료로 세지 않는다.
한 번에 다 끝내려 무리한다: 부분 운반·실제 회수. 완료량 부풀림과 추가 여정 성취 없음.

## 완료 보강
두 차례 운반의 실제 도착과 합의한 감당 범위만 완료. 원래 합의량을 줄이기로 당사자들이 실제 합의했다면 줄인 정수량을 기준으로 삼고 옛 수량을 다시 요구하지 않는다. 문수의 과거 유효 문답은 현부재와 무관하게 인정한다.

## 실제 대가와 소유
실제 운반 참여자에게 기존 로프 매듭·짐 분할 지도1회. 보현의 시범1회 뒤 허락된 끈1개로5초 매듭 작업과 실제 묶음 들어 보기1회, 피드백 수신으로 수강. 재사용 끈은 소비0, 끊어진 끈 교체만 실제 사용1개. 습득 스킬/장비 생성0.

## 말투와 관계
- 초면: “두 번 가자. 지금 들 수 있는 것부터.”
- 신뢰: “지난번 그만큼이면 충분했지. 오늘 몫은 네가 다시 정해.”
- 강함 목격: “무거운 것을 든 건 보았어. 그러니 끝없이 맡기겠다는 말은 아니야.”
- 무리 뒤: “도착한 것부터 세자. 남은 것은 약속이 아니라 아직 남은 짐이야.”

## 당사자 연결
- 이번 행동 결과 중 필요한 부분만 전하거나 현장에서 보여 준다. 실제 응답 성립 조건: 문수가 실제 문답에서 상대의 의향과 할 수 있는 범위를 분명하게 드러낼 때 실제 응답 뒤 행동: 보현은 문수의 질문을 명령으로 번역하지 않고 자신이 먼저 맡을 준비를 제안해 상대의 답을 기다린다.

- 합의 감소Q는 유효
