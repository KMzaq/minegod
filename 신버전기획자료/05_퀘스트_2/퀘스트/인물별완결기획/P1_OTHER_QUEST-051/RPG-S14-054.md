# 약사불 · 마른 천이 닿은 자리
RPG-S14-054 | EP034-RPG-S14-054 | 최상급 | SIDE | 예상 8~15분

약사불은 간절한 요청에도 큰 기적을 먼저 약속하지 않는다. 대신 덮개가 젖었는지, 손이 닿는 곳에 물그릇이 있는지 같은 돌봄의 빈틈에 오래 머문다.

## 현재 범위
아난다의 구호 기록과 우팔리의 공정한 배분을 검토; 치료 독점을 거절
현행 자료에서 개별 최초 일반 조우 시점을 확정할 근거가 부족하다. 옛 단계 템플릿만으로 전/후를 강제하지 않는다.
개인 MAIN을 만들거나 기존 본편 완료를 소급하지 않는다. 공통 수행·정산 규칙을 함께 적용한다.

## 장소
기존 구호 쉼자리 최대3곳, 각 자리2블록 작업공간·4~8블록 관측 시야 확보. 건조대는 기존 안전 햇볕/실내 건조 자리를 사용.

## 실제 수행
1. 실제 수혜자의 요청·동의와 젖은 천을 확인한다. 한 회차 대상 N은1~3명 정수, 각 마른 천1개와 식수 물병1개. 기본 흰 카펫 기반 천 소품과 minecraft:potion의 water 내용물 또는 허락된 기존 식수 그릇을 사용한다. 실제 재고가 모자라면 N을 몰래 줄이지 않고 부족수를 별도 표시한다.
2. 수혜자마다 젖은 천1개를 걷어 소유자 건조 자리에 옮기고 마른 천1개와 식수1회분을 실제 인도한다. 손 닿는 높이는 기존 받침 반블록로 낮춰 당사자가 물그릇을 실제 잡는지 확인한다. 사용 동의가 없으면 배치/인도만 남기고 마셨다고 하지 않는다.
3. 후원자의 독점 조건을 거절하고 필요에 따라 배분 OR 조건을 받아 부분 수혜만 남기는 경로를 고른다. 젖은 천은 현장 활성120초 동안 건조 자리에 유지되어야 마른 상태로 전환; 추가 천이 생성되지 않는다. 관찰된 도움은 아난다에게, 부족수는 우팔리에게 허락된 범위로 실제 전달한다.

## 선택별 결과
서로 다른 선택 결과를 합치지 않는다.
현재 필요한 자리로 나누고 부족을 정확히 전한다: 실제 닿은 자리만 돌봄 이행. 기록·배분 보고는 실제 수신된 범위만, 효과는 치료 증명 아님.
독점 조건을 받아 다른 자리를 남긴다: 독점 배분 실패·실제 부분 수혜·추가 지원 거절. 늦은 수혜를 제때 전원 회복으로 바꾸지 않는다.
배분은 했으나 보고 수신을 기다린다: 돌봄 사실 유지·기록 및 배분 보고 미수신. 완치나 상대 검토 완료 없음.

## 완료 보강
기준은 닿은 천/물과 실제 인수·사용, 치료효과는 판정하지 않는다. 아난다 기록 수신과 우팔리 배분 보고 수신은 각각 필요하며 한쪽 미수신이면 돌봄 성과는 유지하고 보고만 보류한다. 이미 받은 유효 배분안·보고를 현재 부재로 다시 요구하지 않는다. 수혜자의 실제 그릇 잡기 가능 확인과 허락된 인수는 필요하지만 강제 음용·치료효과를 요구하지 않는다. 사용하지 않았다면 미사용 상태로 남긴다. 아난다·우팔리에게 보낸 보고의 수신과 그들에게 별도로 물은 후속 질문의 답변 수신은 각각 별도이며 새 후속 답 부재가 이미 완료된 돌봄이나 유효 보고를 취소하지 않는다.

## 실제 대가와 소유
물품은 실제 쉬는 수혜자에게만. 천은 상태 전환·재사용, 물은 실제 마신 분량만 소비하며 빈 병/그릇은 원소유에 따른다. 플레이어 치료·가호·장비 보상0.
