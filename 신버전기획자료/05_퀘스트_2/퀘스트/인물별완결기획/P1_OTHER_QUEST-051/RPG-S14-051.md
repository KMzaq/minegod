# 금강수 · 쫓지 않는 통로
RPG-S14-051 | EP034-RPG-S14-051 | 최상급 | SIDE | 예상 6~12분

금강수는 설명을 길게 하느니 직접 비켜 설 자리를 만든다. 위협에는 빠르고 거칠게 반응하지만 조용한 질문자 앞에서는 큰 몸짓을 줄인다.

## 현재 범위
문수의 공개 문답과 관세음의 피난 통로를 보호; 무장 해제 약속 지속
현행 자료에서 개별 최초 일반 조우 시점을 확정할 근거가 부족하다. 옛 단계 템플릿만으로 전/후를 강제하지 않는다.
개인 MAIN을 만들거나 기존 본편 완료를 소급하지 않는다. 공통 수행·정산 규칙을 함께 적용한다.

## 장소
문수가 실제 공개 문답을 하는 기존 출입구. 최소폭2블록 통로 길8블록, 문밖12블록 이내 안전 쉼자리와 별도 방어 경계. 통로 부적합이면 사건 활성화하지 않는다.

## 실제 수행
1. 실제 공개 문답과 쉬러 나갈 의사가 있는 질문자가 있을 때 익명 무장 소란자1명 사건을 활성화한다. 첫 질문자1명을 안전 쉼자리로 동행한다. 총 대피자 N은 현장 자발적 대상1~3명을 명부로 확정하며 없는 청중을 채우지 않는다.
2. 안전한 대피 OR 준비된 방어 중 선택한다. 대피는 각 대상이 쉼자리 반경2블록에 실제 도착하고5초 머무는 동안 플레이어가4블록 이내 동행한 증거. 방어는 표시된 통로 방어 구역 안에서 실제 공격1회 이상을 막거나 소란자의 접근을 저지해 남은 대상의 안전 이동을 보장한 증거. 두 경로를 AND로 요구하지 않는다.
3. 금강수는 공격이 실제 시작되면 방어·무장 해제를 맡는다. 소란자가 무기를 내리면 추격하지 않는다. 마지막 대피자 이동 뒤 현재 안전한 범위를 문수에게 실제 전달해 수신을 확인한다. 관세음에게 피난 경로를 잇는 일은 실제 현장 정보 수신·응답이 있을 때만 별도 성립한다.

## 선택별 결과
서로 다른 선택 결과를 합치지 않는다.
안전한 대피로 끝까지 통로를 지킨다: 실제 대피·문수 수신과 보호 기여만 완료. 관세음 경로 연결은 실제 정보 수신·응답이 있을 때만 별도 성립. 방어 직접 참여를 필수로 더하지 않는다.
준비된 방어로 통로를 지킨다: 선택한 방어 역할의 실제 보호·안전 범위 전달만 완료. 비전투 대피 경로를 중복 수행할 의무 없음.
대피자를 두고 추격한다: 추격 실패 경로·현장 피해 보존. 통로 회복과 실제 남은 대피부터 다시 해야 한다.
마지막 대피는 끝났으나 전달이 남았다: 보호 사실은 유지, 필요한 전달·확인 미완료. 상대 답·경로를 생성하지 않는다.

## 완료 보강
대피 경로는 직접 전투 없이도 보호 기여로 완료. 방어 경로는 별도 대피 동행을 반복하지 않되 실제 보호된 이동은 있어야 한다. 문수 수신은 필수이고 미수신이면 보호 성과만 남긴다. 관세음의 새 응답은 선택 후속이다. 소란자를 쫓아 보호 구간을 이탈하면 해당 회차 보호 실패, 남은 대피·통로 회복만 실제 재개한다.

## 실제 대가와 소유
실제 보호 기여자에게 방어 자세·안전거리 지도1회. 금강수 시범 후 무해한 연습 공격2회 중 방패 방향 유지1회와3블록 옆 비켜서기1회, 실제 피드백으로 수강. 전투력/가호/장비 지급0. 소란자 무기 해제는 전리품 지급과 무관.

### 연출판정

### 금강수행동

### 종료
체력6 이하 OR 실제 금강수 무장 해제 후 항복 상태. 공격 중지·무기 내림, 안전한 기존 퇴로로 이탈하며 새 사망 선언 없음. 바깥 시스템의 실제 피해가 따로 생기면 그 사실만 보존하고 자동 부활/소거하지 않는다. 항복·무장 해제 이후 장면 공격과 추격 AI를 즉시 중지한다. 처치는 완료 조건이 아니며 항복 대상 추가 공격에 보호 공로/새 보상을 주지 않는다. 외부 실제 피해·사망이 발생해도 살아서 이탈했다고 꾸미지 않는다.

### 중단과친구
수락한 참가자별로 대피 또는 방어 구간과 실제 기여를 기록한다. 친구는 현재 안전한 합류점에서 자기 역할을 명시 수락한 뒤 남은 보호에만 참여하며 이전 대피·수신·지도권을 상속하지 않는다. 방어 준비가 없는 친구는 대피만 택할 수 있다. 사망·로그아웃·중단 시 해당 참가자의 미완 동작만 중지하고 이미 대피한 대상/무장해제/문수 수신과 원물 위치를 보존한다. 남은 참가자와 금강수의 실제 가능한 보호만 계속하며 대피자를 다시 위험 구간에 복귀시키거나 소란자를 재생하지 않는다. 안전한 인계가 불가능하면 남은 대피를 보류하고 현재 안전 쉼자리에서 재개한다.
