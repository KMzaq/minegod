# 말리카 · 편지보다 먼저 갈 짐
RPG-S14-045 | EP033B-RPG-S14-045 | 최하급 | SIDE | 예상 8~15분

말리카는 좋은 말도 닿을 때가 중요하다고 생각한다. 기다리는 데 능숙하지만 기다림을 핑계로 필요한 도움까지 늦추는 것은 달가워하지 않는다.

## 현재 범위
프라세나짓과 발송 시기를 논의; 실제로 받은 현장 보고에 따라 구호 우선순위 변경
기존 명부가 C01 공통 시작 뒤 공개 생활권의 초기 조우 후보로 제안한 인물. 현행 원칙과 충돌하는 개별 후행 조건을 확인하지 못해 후보안으로 유지한다. 전원 확정 출현이나 새 초기 배정을 뜻하지 않는다.
개인 MAIN을 만들거나 기존 본편 완료를 소급하지 않는다. 공통 수행·정산 규칙을 함께 적용한다.

## 장소
말리카의 실제 연락 준비 자리에서 승만부인이 지정한 현장까지 기존 안전길24~64블록. 다른 실제 거리는 출발 전 공개하며 시간 약속도 함께 정한다.

## 실제 수행
1. 승만부인의 실제 요청1건에서 물품·정수량·필요 시점을 읽는다. 기본 요청은 마른 천2개와 빵4개, 현장 실제 요청이 다르면 요청값을 보존하고 대체품/부분량을 승만부인과 합의한다. 요청이 없는 경우 새 요청을 창작해 시작하지 않는다.
2. 주인이 허락한 실제 물품을 포장해 운반한다. 짐 먼저 OR 편지 완성 후 함께 출발을 선택한다. 기본 생활 회차의 필요시점은 요청 확정 뒤 서버활성10분으로 제안하지만 이미 요청에 다른 시점이 있으면 그것을 쓴다. 정해진 기준이 없으면 먼저 필요시점을 확인하고 기한 전 성공을 판정하지 않는다.
3. 현장 수혜자/승인된 수령자가 물품을 실제 인수한 시간과 수량을 기록한다. 인수 답을 말리카가 실제 수신해야 이행 확인을 끝낸다. 도착했으나 답이 없으면 발송/인수 증거는 보존하고 응답만 기다린다. 사적 조언 편지는 별도 허용 수신자에게만 전한다.

## 선택별 결과
실제 택한 한 경로의 결과만 남긴다. 서로 다른 경로를 AND로 합치지 않는다.
짐을 먼저 보내고 실제 제때 인수를 확인한다: 실제 제때 인수·응답을 확인한 물량만 지원 이행. 조언 지연은 별도.
짐은 보냈지만 인수 답이 아직 없다: 출발 완료·구호 이행 확인 보류. 물자를 다시 만들어 보내지 않는다.
편지를 다듬다 늦게 보낸다: 실제 늦은 지원 또는 미도착. 제시간 지원 성취 없음, 실제 수혜 인수는 취소하지 않는다.

## 완료 보강
포장·출발·도착·인수·말리카의 응답 수신을 다섯 상태로 구분한다. 발송만으로 구호 완료 아님. 실제 제때 인수되었지만 회신만 늦으면 기한 준수 사실은 유지하고 확인만 나중에 끝난다. 기한 이후 인수는 늦은 지원으로 남는다. 프라세나짓이 실제 반대하지 않았다면 가짜 반대·설득 단계를 만들지 않는다.

## 실제 대가와 소유
구호 물자는 실제 현장 수혜자 몫, 플레이어 지급0. 사적 편지·왕가의 호의·자동 다음 재원 없음. 허락된 필요 품목 요약만 다음 준비에 쓰며 새 요청 없이 반복 출발하지 않는다.

## 말투와 관계
- 초면: “좋은 문장은 조금 늦어도 괜찮아요. 이 짐은 언제 필요하다고 했나요?”
- 신뢰: “지난 인수 답은 받았어요. 이번 요청은 따로 읽어 보지요.”
- 강함 목격: “지난 길을 지켜 준 일은 보았어요. 빠르게 갈 수 있어도 받는 분의 때가 먼저예요.”
- 회신 없음: “보냈다는 것까지는 압니다. 받았다는 답은 아직이에요.”

## 당사자 연결
- 이번 행동 결과 중 필요한 부분만 전하거나 현장에서 보여 준다. 실제 응답 성립 조건: 프라세나짓이 실제 편지 검토에서 자기 조급함과 필요한 답의 기한을 분리해 말할 때 실제 응답 뒤 행동: 말리카는 프라세나짓에게 무조건 기다리라고 하지 않고 먼저 보낼 질문과 늦춰도 되는 조언을 함께 고른다.
- 이번 행동 결과 중 필요한 부분만 전하거나 현장에서 보여 준다. 실제 응답 성립 조건: 승만부인의 실제 보고에서 지금 필요한 도움과 준비되지 않은 일을 읽거나 직접 들을 때 실제 응답 뒤 행동: 말리카는 승만부인에게 받은 범위의 도움을 먼저 의논하고 답장 뒤의 사적 사정은 다른 청중에게 넘기지 않는다.
