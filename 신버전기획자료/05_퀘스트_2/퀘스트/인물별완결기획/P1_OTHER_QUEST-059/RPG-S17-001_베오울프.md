# 베오울프 — 따라하지 않아도 되는 용맹



완결 저술 기획. 실제 구현·게임 시험 완료를 뜻하지 않는다. 공통 계약을 함께 적용한다.



## 인물과 범위

베오울프. 승부에는 크게 웃고 동료의 준비 앞에서는 속도를 늦추는 인간 영웅.

개인 MAIN: NOT_APPLICABLE; 원 에피소드: EP004B-RPG-S17-001-01



## 현행 해금과 조우

일반 인사·C09 공개조사에 과거 추적동행 심화 이력을 요구하지 않는다. 기존 일반접근을 현행 기본가용으로 채택한다. 역사 전투참여 OR 주민/짐 후송이력은 해당 심화요청에만 두고 세계 첫만남 잠금으로 확대하지 않는다.

원문 최초접촉 현장: 기존 숲길과 약탈 흔적이 실제 발견된 구간의 가장자리. 흔적이 없다면 출정 준비에 관한 대화만 한다. 현재 조건: 해당 현장의 현재 열린 통행범위 16블록 안에 실제 도달한 사람이 일반 최초 접촉 후보이다. 원문 배치 제안의 지리와 적합 기존 부지·현재 접근·봉인·단일 본체·의사를 확인한다. 아래 SIDE layout은 수락 후 실제 수행 장소이며 일반 첫접촉 장소나 선행으로 강제하지 않는다. SIDE 물품·R/C 수행·개인 실적을 일반 접촉의 새 조건으로 요구하지 않는다.

한 명의 유효 달성으로 세계공통, 이후 현재 적격자 중 실제 1명 선정. 해금자와 달라도 됨. 단일 본체·전역 확률/주기/CAS는 공통 계약 참조.



## 현장

현재 C09 또는 C14 사건의 원전장과 안전선을 사용한다. 열린 숲길에서 짐/주민 위치를 안전한 엄폐 뒤 16블록 이내로 관측하고, 기존 안전선까지 길 폭2·머리높이2 이상의 퇴로를 실제 확인한다. 새로운 약탈대를 생성하지 않는다.



## 실제 수행

- B1 현재 C09 OR C14 하나의 유효 시도ID·원선행·남은 적·소유자/압수짐 목록을 확인한다. 반출 OR 주민보호 역할 하나를 명시 수락한다. 반출은 베오울프의 실제 전면담당 동의가 필수; 보호는 주민의 이동동의가 필수며 베오울프 불참이면 혼자 가능한 순차몫만 한다.

- B2 반출은 합의 품목별 정수량의 허락짐을 실제 들고 안전선 안 2블록까지 옮겨 허락 보관자에게 인도한다. 보호는 동의 주민이 실제 안전선에 도착하는 것을 8블록 내 시야에서 확인한다. 둘 다 한 경로로 인정하며 상대 경로를 강요하지 않는다.

- B3 원전투의 실제 남은 경비를 제압한다. 엄폐는 고체 블록 raycast로 사선을 끊는 원래 공격판정이며 벽너머 타격/자동제압0. 베오울프 현동행·현재 전면행동이 없으면 보호막 효과0. 보호경로도 전투 뒤 실제 접근 가능한 허락 압수짐을 수습해 안전선으로 옮겨야 B4로 간다.

- B4 원주인과 품목/수량/실손실을 대조하고 손2블록 안 실반환·인수 및 6블록 안 보고수신을 마친다. 주인 부재/거절/소유 미확인은 수습·전투만 보존한 부분결말. 위글라프 실제 참여시만 그의 후방역할과 피로를 듣는다.

- B5 선택 지도는 고체엄폐 뒤에서 1블록 나오고 후방표식(뒤 3블록)을 직접 시야에 넣어 다시 엄폐하는 동작 1회와 베오울프 피드백. 원전투 전리품은 같은 개인+시도ID 지급원장에서 미정산분만 정산하고 신규전리품0.



## 완료와 부분결말

현존위협 및 유효수락 AND (보호 OR 반출)의 실제수행 AND 남은적 실제제압 AND 허락짐 실제확보/안전선도착 AND 원주인 인수/보고수신. 위협없는 정상 대화는 가능하지만 이 전투SIDE 완료 아님. 지도/위글라프 후속은 선택.



## 보상과 비용

원 C09/C14 정의의 미지급 일반 전리품만 동일 권리로 지급. 새 품목/수량 보상0. 실제 완료자에게 현재 합의한 짧은 엄폐·후방 확인 지도1회, 등록스킬 없음.

원문 합의 품목·양의 정수량은 offer에 품목별 {원소유자,현보유자,item_instance,수량,목적,수신자}로 동결한다. 다른 합의품목을 예시 하나로 제한하지 않는다. 물품 OR 행동 대가를 AND로 바꾸지 않는다. 실행 중 변경은 당사자 재동의와 revision으로 남기고 완료량을 소급 늘리지 않는다. 손실은 실제 드롭/소실 상태이며 퀘스트 재시작으로 복제하지 않는다.

event_uuid+참가UUID+권리종류 유일키. 완료→권리→제공예약→실인수 receipt를 분리한다. 실패/부분종료는 완료권리 없음. 이미 끝난 본작업은 선택 지도/수령 사양으로 되돌리지 않는다. 미수령은 보존; 재접속/FTB/반복 클릭은 재지급 안 함. 불명확 인벤 전달은 원장/실물을 대조한 뒤 누락분만 복구. 새 실제 요청 없는 반복은 관계대화만.

## 전투와 선택 지도 실행

### 적용
B1~B4 실전은 현재 C09 또는 C14 원사건의 유효 시도와 기존 적만 사용한다. C09는 C07 AND C08, C14는 C10 AND C11을 보존한다. 원전투와 공통 계약이 연결하는 현행 전투모드 전환의 HP·공격·피해·기믹·전리품·귀속을 그대로 사용하며 여기서 새 수치나 전투보상을 정의하지 않는다.

### 실전수행
실제 고체 엄폐의 사선 차단과 남은 경비 제압, 맡은 보호 OR 반출을 판정한다. 베오울프의 현재 동행과 실제 전면행동 없이 자동 방어/보호막을 부여하지 않는다. 안전철수·수습대기는 부분 상태이며 보호 경로에서도 허락 압수짐 실제회수와 원주인 인수가 필요하다.

### 선택지도
B5는 전투 종료 뒤 현재 안전하고 베오울프가 동의한 고체엄폐 옆에서 한다. 60tick 준비 후 엄폐 밖1블록을 실제 걷고, 뒤3블록 표식을 실제 시야에 넣은 다음 같은 엄폐로 돌아온다. 이동속도는 플레이어 현재 정상 걷기 그대로이며 순간이동·자동회전·속도버프0. 베오울프가 실제 본 움직임만 피드백한다. 느린공격·방패접촉·가상적 생성은 이 지도에 필요하지 않다.

### 연출
실제 엄폐·후방 바닥표식과 베오울프의 가리키는 동작만 사용한다. 표식은0.5×0.5블록 바닥 고리로 실제 관찰지점을 표시하며 벽너머 표시/시야 확보를 대신하지 않는다. 발걸음은 정상 이동 소리, 관측 성공은 해당 플레이어에게만 짧은 확인1회. 별도 공격 타점·피해·넉백·내구소모0.

### 중단회복
지도 그만/피로/로그아웃/실제 적 진입이면 지도만 즉시 중단하고 실제 위험은 정상 진행한다. 이미 끝난 B1~B4는 유지하며 재개시 현재 안전·본체·지도 의사와 미수행 동작만 확인한다. 지급은 원 C09/C14 개인+시도ID의 원장과 실물을 대조해 누락만 복구한다.

## 원래 선택 경로

### B1

현재 남은 경비의 사선과 주민·압수 짐 위치를 직접 살핀다. C09 또는 C14 중 실제 사건의 원 선행과 남은 적만 확인하고 역할·퇴로·소유 확인 가능한 짐 목록을 정해 명시 수락한다.

- 무위협 / 지금 위협이 없어 대화만 한다 → END
  현재 흔적과 자기 준비만 이야기하고 안전선에서 마친다.
  결과: 기존 제압 결과를 유지하고 적을 재생하지 않는다.

- 반출 / 전면 대응과 옆길 반출로 나눈다 → B2
  베오울프가 전면을 맡고 플레이어가 현재 허락된 짐을 옆길로 반출할 역할을 수락한다.
  결과: 역할만 정해지고 짐은 아직 그 자리에 있다.

- 보호 / 주민을 먼저 안전선으로 옮긴다 → B2
  주민 보호를 먼저 맡고 이후 남은 경비를 상대하는 순서를 명시 수락한다. 배우 동행 거절이면 플레이어가 가능한 몫을 순차 수행한다.
  결과: 주민 동의와 순서만 확보, 아직 이동 완료 아님.

- 거절 / 동행하지 않는다 → END
  현재 본 위험만 알려 주고 안전 퇴로로 물러난다.
  결과: 관측 기여만 남는다.

### B2

반출이면 엄폐를 옮겨 다니며 실제 허락된 짐만 들어 안전선 안에 놓는다. 보호이면 주민이 동의한 이동을 실제 끝까지 확인하고 잔류·거절은 따로 남긴다. 베오울프가 동행하지 않으면 그의 방어가 있다고 가정하지 않고 가능한 순차 행동만 한다.

- 안전확보 / 현재 보호/반출을 끝내고 남은 위협을 상대한다 → B3
  실제 도착자를 확인한 뒤 짐을 허락 보관자에게 두고 무게를 내려 남은 경비 사선으로 돌아간다.
  결과: 보호/반출은 성립하지만 경비 제압·주인 반환은 아직 별도다.

- 부분철수 / 지금 확보한 만큼만 지킨다 → END
  도착한 짐과 사람을 안전선 안에 두고 실제 인계/미배정을 알린 뒤 물러난다.
  결과: 부분 성취 보존, 전체 SIDE·전투 전리품 없음.

### B3

플레이어가 남은 경비의 실제 공격 사이에 엄폐로 사선을 끊고 가능한 간격에서 반격한다. 베오울프는 실제 동행 중이면 자기 전면 몫을 수행한다. 현재 위협이 실제 제압되었는지 확인한 후에만 짐으로 돌아간다.

- 제압 / 현재 남은 위협을 실제 끝낸다 → B4
  현장 결과와 남은 적 유무를 살핀다. 반출 경로는 안전선에 보관한 반환품을 확인하고, 주민 보호 경로는 전투 뒤 접근 가능한 허락된 압수 짐을 실제 수습해 안전선으로 옮긴다. 소유·수량·손실을 확인하여 실제 확보한 물건만 B4로 가져간다.
  결과: 전투 결과는 성립. 주민 짐 반환·보고는 B4에서 별도 확인한다.

- 후퇴 / 엄폐와 퇴로로 철수한다 → END
  추격을 끊고 안전선으로 돌아와 남은 적과 피해를 알린다.
  결과: B2 성취는 보존하고 제압 성취/전리품은 미발생.

- 수습대기 / 제압 뒤 짐을 아직 확보하지 못했다 → END
  제압 결과와 짐의 실제 위치·손실을 남기고 미수습 부분만 대기로 둔다.
  결과: 전투 성취는 유지하되 B4 인수·전체 SIDE 완료는 발생하지 않는다.

### B4

실제 주인에게 허락 목록과 짐을 대조하여 반환하고 인수를 확인한다. 위글라프가 실제 참여했다면 그가 맡은 후방 일과 피로를 직접 듣는다. 부재면 그 경험을 꾸미지 않고 플레이어와 베오울프의 실제 몫만 말한다.

- 분리보고 / 보호와 전투의 기여를 각각 밝힌다 → END
  자기 위험과 동료의 실제 행동을 나누어 보고한다.
  결과: SIDE 성립. 위글라프가 없으면 그 개인 판단은 아직 미수신이다.

- 후속 / 완료 뒤 허용 전리품/지도를 확인한다 → B5
  기존 C09/C14 같은 전투 정산 기록을 먼저 확인하고 별도 중복 권리 없이 남은 제공분만 묻는다.
  결과: 완료는 유지하며 수령·지도는 미실행이다.

- 미인수 / 주인이 없어 보관한다 → END
  짐을 현재 허락 보관자에게 두고 미인수와 확인한 소유 근거를 기록한다.
  결과: 전투·반출은 보존하나 반환 완료·전체 보상권 없음.

### B5

허용된 일반 전리품 정의와 원 전투 지급 기록을 확인해 아직 미정산인 개인 몫만 받는다. 지도는 별도 동의 뒤 엄폐에서 나왔다 다시 뒤를 보는 짧은 동작을 베오울프와 해 본다.

- 지도실습 / 후방 보호를 남기는 돌파를 연습한다 → END
  엄폐 밖 한 걸음 뒤 뒤의 표시를 실제 확인하고 돌아온다. 피로하면 즉시 멈춘다.
  결과: 실제 지도·실습만 기록. 새 기술 수치 없음. 미정산 실물이 있을 때만 원 정산 주체가 지급한다.

- 수령만 / 추가 지도 없이 미정산 일반 몫만 받는다 → END
  원 정산 주체에게 해당 개인의 아직 받지 않은 실물만 실제 인계받고 지급 기록과 대조한다.
