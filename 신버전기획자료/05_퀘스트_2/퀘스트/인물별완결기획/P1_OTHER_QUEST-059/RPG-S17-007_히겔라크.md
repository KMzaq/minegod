# 히겔라크 — 바다로 가지 않는 몫



완결 저술 기획. 실제 구현·게임 시험 완료를 뜻하지 않는다. 공통 계약을 함께 적용한다.



## 인물과 범위

히겔라크는 베오울프의 명성이 반갑고도 부담스럽다. 모든 이가 먼 원정만 바라보는 동안 항구가 비는 일을 보면 군주로서 자기 몫을 다시 세운다.

## 현행 해금과 조우

누군가 기존 해안 출항점과 24블록 이상 떨어진 기존 귀환점을 실제 왕복하면 세계해금. 항해·새배·원정 개시 불필요.

원문 최초접촉 현장: 기존 물가 선착장 가까운 짐을 내려놓는 쉼자리 현재 조건: 해당 현장의 현재 열린 통행범위 16블록 안에 실제 도달한 사람이 일반 최초 접촉 후보이다. 원문 배치 제안의 지리와 적합 기존 부지·현재 접근·봉인·단일 본체·의사를 확인한다. 아래 SIDE layout은 수락 후 실제 수행 장소이며 일반 첫접촉 장소나 선행으로 강제하지 않는다. SIDE 물품·R/C 수행·개인 실적을 일반 접촉의 새 조건으로 요구하지 않는다.

한 명의 유효 달성으로 세계공통, 이후 현재 적격자 중 실제 1명 선정. 해금자와 달라도 됨. 단일 본체·전역 확률/주기/CAS는 공통 계약 참조.



## 현장

기존 해안 항구의 안전한 평지6×6과 출항짐 보관점에서 실제 수신점까지 열린 길8~20블록. 새 배·원정·부재 수비자를 생성하지 않는다.



## 실제 수행

- B1 남는 방어연습 OR 현재 요청된 출항준비 중 하나를 정한다. 방어는 본인과 현참석자의 실제 남을 동의; 보급은 실제 요청자/제공자 권한 및 품목별 정수량·수신자 수락을 동결한다. 베오울프 몫은 베오울프 실제 요청/수락이 없으면 미배정.

- B2 방어경로: 방패를 들고 3블록 사이의 두 자리에서 신호에 따라 한 번씩 교대한다. 선행자가 방패를 유지하는 동안 후행자가 2블록 폭 통로를 지나고 끝나면 역할교환. 히겔라크가 마지막 교대/남을 의사를 실제 확인하고 출항지원 배정에서 해당 몫을 실제 제외한다.

- 보급경로: 허락한 정수량만 실제 옮겨 지정 수신자 손2블록 안 실인도·인수한다. 부재/거절이면 현보유/미인수, 방어지도권0. 준비와 출항승인을 혼동하지 않는다.

- B3 방어지도는 본작업 뒤 선택으로 방패각도 1회 시범/참가자 실습/직접 교정. 보급경로는 인수대조만. 실제 빌린 도구는 실반환한다.
