# 생활권 퀘스트 공통 계약

## 문서상태
채택된 완결 저술 설계. 실행 JSON/API가 아니며 게임·LLM·모드 호환 시험은 하지 않았다.

## 원문과보강
source_contract는 실제 authoring_contract.exact_existing_cards의 동일 필드값이다. 현행 수량·거리·복구·완료 보강은 adopted_detail에만 둔다. 원래 EP와 SIDE 범위 유지, MAIN 추가0.

## 접근
원래 세계 해금·후보 자격·확률·동일 본체 위치·접근/봉인 조건 유지. 세계 해금은 공통이고 개인 조우·첫 접촉·SIDE 수락·친구 합류·개인지식·보상은 독립이다. 별도 전투력 컷이나 전원 확정출현 없음.

## 현장선정
원문이 허용한 실제 기존 생활권 구조물 OR 안전한 기존 자연 부지에서 각 인물 장소 조건에 맞는 평탄한 경로를 정한다. 새 건물 의무0. 상대배치는 채택 설계값이며 실제 월드 좌표는 적합 지형에 결속한다. NPC 순간이동·분신으로 부재를 메우지 않는다.

## 거리
집기·배치·수선·물품 인수는 손2블록, 가시선 필요. 대화는 기본4블록 안에서 실제 청취·허용 청중 검사. 관측과 이동은 각 장면 범위에 따르며 손2블록을 원거리 관측에 적용하지 않는다.

## 수락과협상
활동ID+플레이어UUID+회차ID로 개인 수락을 기록. 참가자·수혜자·항목·정수수량·대체재·원소유자 허락·목적지를 같은 제안판으로 확정한다. 제시 기본값은 제안값이며 실제 합의한 수량·원문 허용 대안을 덮지 않는다. 변경된 부분만 재합의. 일반 질문·인사는 수락 불필요.

## 증거
의향이나 선택 클릭만으로 작업 성공 없음. 서버 권위 증거에 대상UUID/소품ID·발화자·수신자·원소유·회차·물량·위치·시간·실제 행동을 결속한다. 기존에 유효하게 수신/수행한 증거는 당사자의 현재 부재로 지우거나 다시 요구하지 않는다. 철회/내용 변경은 적용 이후 미수행 부분에만 반영한다.

## 물품
작업용 소품은 원소유·대여·인계·수혜자 소유를 분리한다. 기본 바닐라 항목은 표시/기반 리소스이고 젖음·매듭·바구니·놓인 그릇 등 상태 및 동작은 신규 구현 요구다. 소품 생성으로 물품 복제하지 않는다. 파괴·사망 드롭은 서버 기존 규칙과 원소유 추적을 적용한다.

## 시간과중단
별도 명시 없으면 기한 없음. 물리 작업 누적초는 해당 청크 활성·행위자가 살아 있고 작업 범위 안에 있을 때만 진행. 사망·로그아웃·서버중단은 미완 현재 동작만 멈추고 이미 인수·소비·전달·완료한 증거를 보존한다. 재접속은 마지막 유효 단계에서 재개하며 당사자 부재면 새 응답만 기다린다. 경과시간으로 미응답을 답변으로 바꾸지 않는다.

## 실패와재개
거절은 미수락, 중단은 잔여목표 보류. 피해·허위보고·소실은 실제 범위만 남기고 정정/반환/재수신으로 필요한 부분만 복구한다. 이미 완료된 대안 경로를 다른 경로와 AND 결합하지 않는다. 부분결말은 정식 종료 가능하며 나중에 남은 절차를 실제 이행해 이어 간다.

## 정산
실제 완료→권리 확정→실제 인도/수신은 별도. 보상 수령 거절은 본작업 완료를 취소하지 않는다. 개인 최초1회, 같은 회차 재접속·재수락·후발 합류로 권리를 복제하지 않는다. 반복 도움은 가능하나 자동 새 지급권0. 미수령분만 같은 권리로 재시도한다.

## 수령
빈 인벤토리는 정상 수령 가능. 물품 인수는 공간을 실제 확보하고 원소유 감소·수신자 증가·인수영수증을 원자적으로 확정한다. 가득 찼으면 원소유 보관에 미수령 예약하고 바닥에 던지지 않는다. 받은 물품 분실은 무료 복제하지 않는다. 현장 열람/대화/지도는 실제 표시·청취·연습 완료만 수신으로 기록한다.

## 지식
공유 현장 변화는 세계에 남아도 개인기억·MAIN·기여·보상권은 실제 당사자만. 후발자는 현재 남은 장면이나 허락된 요약만 알며 과거 목격자로 소급되지 않는다. 전언/직접 목격/미확인을 분리. 사적 편지·건강·가족사·문의는 허용 수신자에게만. 실제 들은 강함과 소문을 구분하며 숨은 스탯으로 태도를 바꾸지 않는다.

## 기존지원과신규요구
기존 Story 보상/대화 기반을 참조하되 이 사건 연결은 미구현. 회차 원장·발화 수신 영수증·동의판·상태 소품·원자 인도·관측 시야·단계 복구·청중별 공개·개별 상호작용 애니메이션을 구현해야 한다. 신규 스킬/장비/마나/가호/레이드 지원 정의0, SS/BC 전환 장비 추가0.
