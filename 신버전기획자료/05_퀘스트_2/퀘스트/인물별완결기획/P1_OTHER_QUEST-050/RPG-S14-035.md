# 마하가전연 · 빠진 한 절
RPG-S14-035 | EP033A-RPG-S14-035 | 하급 | SIDE | 예상 8~15분

마하가전연은 긴 말을 짧게 만드는 데 재미를 느낀다. 잘 줄인 문장을 아끼지만 쉬워 보이는 말 때문에 뜻이 바뀌었다면 미련을 내려놓으려 한다.

## 현재 범위
사리불과 요약문의 모순을 검토; 수정한 번역이 다음 수업에 남음
현행 자료에서 개별 최초 일반 조우 시점을 확정할 근거가 부족하다. 옛 단계 템플릿만으로 전/후를 강제하지 않는다.
개인 MAIN을 만들거나 기존 본편 완료를 소급하지 않는다. 공통 수행·정산 규칙을 함께 적용한다.

## 장소
허락된 기존 문과 문옆 바닥 3×3. 문을 연 상태의 점유칸을 실제 표시하고 통행을 막지 않는 시험 시간만 사용.

## 실제 수행
1. 사리불의 실제 참여 허락을 얻고 그릇2개를 빌린다. 짧은 지시로 플레이어가 문 회전 영역에 그릇A를 놓고, 긴 지시로 사리불이 영역 밖 그릇B를 놓는다. 플레이어는2~5블록에서 문 열림과 두 그릇 위치를 관측한다.
2. 문 열림 시 바닐라 그릇이 자동 밀린다고 가정하지 않는다. 장면 소품 기능으로 A를 열림칸 옆 빈칸까지1블록만 밀고 B는 유지한다. 충돌 위치와 이동을 같은 서버 사건으로 기록한다. 기능이 없으면 구현 전 활성화 금지.
3. 조건 한 절을 복원한 안내를 읽고 두 번째 놓기에서 문 회전칸을 비운다. 실제로 문을 다시 열어 그릇이 밀리지 않는 것을 확인한다. 앞서 잘못 들은 청자가 있으면 수정문을 실제 수신시키며, 부재 때는 정정 전달만 보류한다.

## 선택별 결과
아래는 서로 배타적인 선택별 결과이다. 실제 택한 경로에 해당하는 결과만 남긴다.
필요한 조건 한 절을 살려 다시 실행한다: 두 번째 실제 실행이 원뜻과 맞은 요약만 채택. 사리불과 실제 비교한 경험만 관계 변화.
외우기 쉬운 짧은 문장을 유지한다: 잘못된 요약 제외, 필사 성공 권리 없음. 이전 오청자의 실제 수정 수신은 미완료.

## 완료 보강
첫 비교에는 사리불의 실제 행동·지적이 필요하나 이미 성립한 그 증거를 현부재로 무효화하지 않는다. 두 번째 물리 시험 없이 정답 문장만으로 성공하지 않는다. 잘못된 안내를 유지하면 필사권0, 원상복구는 소품만 회수한다. 수정 재실행에는 원문대로 플레이어와 실제 청자의 수정문 수신·재배치·문 열림 관측이 필요하다. 첫 비교의 기존 유효 사리불 증거와 새 재실행 청자의 실제 참여는 구분한다.

## 실제 대가와 소유
검증된 요약1편을 개인 필사할 허락1회. 실제 종이1장 또는 플레이어 허락된 기존 책1면에 복사하고 원문/수정 이유를 남긴다. 개인 지도이며 K/J 습득 스킬이나 능력치 아님.

## 말투와 관계
- 초면: “짧기는 하지. 문을 열어도 맞는지 보자.”
- 신뢰: “네가 지적한 한 절을 이번에는 남겨 두었다.”
- 강함 목격: “문 앞을 지켜 낸 건 보았네. 이번엔 문장이 길을 막는지 보세.”
- 오류 발견: “하하, 줄인 게 아니라 뜻을 잘랐군. 긴 말을 되살리자.”

## 당사자 연결
- 이번 행동 결과 중 필요한 부분만 전하거나 현장에서 보여 준다. 실제 응답 성립 조건: 사리불이 실제 비교에서 짧은 말이 놓친 전제를 구체적으로 짚을 때 실제 응답 뒤 행동: 마하가전연은 사리불에게 간결함만 내세우지 않고 필요한 한 문장을 되살려 다음 설명에 남긴다.
