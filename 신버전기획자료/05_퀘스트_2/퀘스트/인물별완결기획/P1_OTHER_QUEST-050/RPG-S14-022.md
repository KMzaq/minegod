# 아난다 · 닫지 않은 물음
RPG-S14-022 | EP033A-RPG-S14-022 | 하급 | SIDE | 예상 8~15분

아난다는 곁을 지키는 일에 익숙해 먼저 대신 답하고 싶어질 때가 있다. 누군가 질문을 품고 기다리는 모습을 보면 보호와 차단 사이에서 마음이 흔들린다.

## 현재 범위
수밧다의 면담과 춘다의 부담을 조정; 질문을 정직하게 전달하면 신뢰
기존 명부가 C01 공통 시작 뒤 공개 생활권의 초기 조우 후보로 제안한 인물. 현행 원칙과 충돌하는 개별 후행 조건을 확인하지 못해 후보안으로 유지한다. 전원 확정 출현이나 새 초기 배정을 뜻하지 않는다.
개인 MAIN을 만들거나 기존 본편 완료를 소급하지 않는다. 공통 수행·정산 규칙을 함께 적용한다.

## 장소
공용 면담 자리 바깥 기존 그늘. 질문 대조는 아난다와 4블록 안, 면담 요청은 석가모니의 허용된 실제 접점에서 4블록 안. 수밧다에게 돌아가는 안전한 공개 경로만 사용.

## 실제 수행
1. 수밧다가 실제 제공한 질문 1건과 전달 허락을 받는다. 종이 1장에 원문 핵심과 발화자를 기록한다. 이미 받은 동일 질문은 재요구하지 않는다. 플레이어가 아난다 앞에서 해당 기록을 열어 읽고 축약본과 다른 대목 1곳을 표시한다. 손 인수만 2블록 이내다.
2. 석가모니에게 현재 면담 의사를 묻고 실제 응답 1건을 받는 경로 OR 접촉 불가·명시 거절·미응답 상태를 확인해 보관하는 경로를 선택한다. 대기에는 강제 타이머가 없고 질문을 폐기하는 선택도 실패 결말로 가능하다.
3. 응답 경로는 허용된 실제 응답을 수밧다에게 전달하여 수신을 확인한다. 보관 경로는 아난다가 질문 1장을 맡고 현재 미응답/불가임을 수밧다에게 전달한다. 수밧다 부재면 그 수신만 보류한다. 응답 경로에서는 같은 허락된 실제 답을 아난다도 수신해야 한다. 아난다·수밧다의 수신을 따로 기록하고 한쪽 미수신이면 해당 전달만 보류한다.

## 선택별 결과
아래는 서로 배타적인 선택별 결과이다. 실제 택한 경로에 해당하는 결과만 남긴다.
현재 면담 의사를 묻고 실제 답을 전한다: 실제 전달·수신된 면담 응답만 남는다. 아난다는 질문자를 대신 지우지 않는다.
면담 불가나 미응답이면 질문을 맡아 둔다: 미응답 또는 현재 면담 불가를 정직하게 전달한 보관 결과. 면담·답 내용 획득 없음.
질문을 폐기하거나 답을 꾸며 돌려보낸다: 질문 전달 실패. 잃은 종이·허위 전언이 자동 복구되지 않으며 면담·답 비교 보상 없음.

## 완료 보강
질문 수신·대조와 선택한 경로의 전달을 구분한다. 미응답 보관은 면담 완료가 아니다. 석가모니의 이전 유효 응답이 같은 질문·상황에 결속되어 있으면 현재 부재만으로 다시 묻지 않는다. 춘다에게 하는 별도 허락된 전언은 선택 후속이며 이 사건을 잠그지 않는다.

## 실제 대가와 소유
실제 답이 있는 성공 참여자에게 질문/답 비교 대화 1회. 보관자는 보관 상태 설명만 가능하고 답 비교 권리는 실제 답 수신 후에만 열린다. 종이는 수밧다의 전달 자료로 아난다가 보관하며 플레이어 전리품 아님.

## 말투와 관계
- 초면: “네가 들은 그대로 읽어 줘. 내가 덜어 낸 말부터 찾아보자.”
- 신뢰: “지난번처럼 출처를 남겨 주겠어? 이번에도 내가 대신 답하지 않도록.”

- 이번 행동 결과 중 필요한 부분만 전하거나 현장에서 보여 준다. 실제 응답 성립 조건: 춘다가 실제 대화에서 어떤 말 때문에 부담을 느끼는지 밝히고 아난다에게 전달 근거를 물을 때 실제 응답 뒤 행동: 아난다는 춘다에게 자신이 실제 들은 말만 전하며 아직 수신하지 않은 위로를 스승의 말로 꾸미지 않는다.
