# 춘다 · 다시 놓는 한 끼
RPG-S14-026 | EP033A-RPG-S14-026 | 최하급 | SIDE | 예상 8~15분

춘다는 손을 움직이며 마음을 가라앉히는 사람이다. 남의 불행을 자기 탓이라 몰아가는 말 앞에서는 위축되지만 다시 음식을 내놓을 용기를 잃고 싶지는 않다.

## 현재 범위
아난다가 전한 석가모니의 말을 듣고 구호를 재개; 책임 전가 소문을 검증하면 협력
기존 명부가 C01 공통 시작 뒤 공개 생활권의 초기 조우 후보로 제안한 인물. 현행 원칙과 충돌하는 개별 후행 조건을 확인하지 못해 후보안으로 유지한다. 전원 확정 출현이나 새 초기 배정을 뜻하지 않는다.
개인 MAIN을 만들거나 기존 본편 완료를 소급하지 않는다. 공통 수행·정산 규칙을 함께 적용한다.

## 장소
기존 허락된 세척 물통·건조 자리·화로를 각 2~6블록 안에 배치. 신규 시설 건설 불필요.

## 실제 수행
1. 춘다가 오늘 감당할 그릇 수 N을 1~4의 정수로 제안하고 당사자들이 같은 수량을 수락한다. 기본2그릇은 제안값일 뿐 고정 의무 아님. 그릇 N개를 물통에서 각 3초 씻고 건조 자리에 각 5초 놓아 실제 마른 상태를 만든다. N은 이번 합의의 전체 식사량이며 NPC/다른 수혜자 몫 C와 선택적으로 배정한 플레이어 몫 P의 합 N=C+P이다. 사람별 배정표에 중복 없이 기록하며 플레이어 몫을 N 밖에서 자동 추가하지 않는다. 이미 유효한 다른 정수량 합의는 유지한다.
2. 춘다가 허락한 식재료로 N끼를 조리한다. 기본 한 끼는 minecraft:baked_potato 1개이며 허락된 minecraft:bread 1개 OR minecraft:mushroom_stew 1개 대체가 가능하다. 완성 음식이면 재조리 불필요. NPC 수혜자와 참여자 몫을 사전 구분한다.
3. 춘다가 정한 수혜자에게 실제 음식 1개씩 인도한다. 플레이어 몫은 선택 수령으로 따로 보관한다. 아난다의 유효 전언이 있으면 출처를 밝히고 춘다의 실제 청취를 남기되 전언이 없어도 한 끼 준비는 진행한다.

## 선택별 결과
아래는 서로 배타적인 선택별 결과이다. 실제 택한 경로에 해당하는 결과만 남긴다.
전언의 유무를 구분하고 감당할 한 끼를 끝낸다: 한 끼 실제 제공과 식사 재개. 전언을 실제 들은 경우에만 그 전언 수신을 추가한다.
소문을 이기려 분량을 과도하게 늘린다: 지연·빈 그릇의 부분 실패. 이미 제공한 음식은 유지되며 미제공 성공 보상·과거 책임 판정 없음.

## 완료 보강
소문을 이기려 합의량을 넘긴 준비는 기존 N을 소급 증가시키지 않는다. 추가 약속은 별도 합의 전까지 미수락. 무리한 경로의 지연·빈 그릇은 그대로 남고 실제 인도분만 보존한다. 플레이어의 보상 수령 거절이 이미 끝난 공동 식사 제공을 취소하지 않는다. 한 끼 실제 제공은 춘다가 완성 음식을 지정 수혜자의 허락된 식사 자리에 실제 내놓은 증거로 판정하고 준비만 한 상태와 구별한다. 인도·수혜자 인수·섭취는 별도이며 공동 수혜자 몫은 실제 인수분만 배분 완료로 센다. N=1, C=0, P=1에서 유일 수령자인 플레이어가 사양해도 이미 성립한 준비·실제 내어놓은 제공은 유지하되 공동 배분 인수량은0, 개인 음식은 미수령이다. 내놓기 전 사양이면 준비만 남기고 실제 제공 성공을 생성하지 않는다.

## 실제 대가와 소유
춘다가 실제 내어 준 플레이어 몫 한 끼 1개, 이 사건 개인 최초1회. 배고픔 회복은 선택 식품의 기본 게임 효과만. 치료·면죄·가호0. 그릇은 재사용 소유물, 음식은 인도 후 실제 먹을 때 소비. 다른 수혜자 음식을 플레이어에게 옮기지 않는다. 배정표에 플레이어 몫이 실제 합의되고 춘다가 내어 준 경우에만 그 몫의 수령권이 생긴다. P=0이면 다른 사람 몫을 전용하거나 추가 한 끼를 자동 생성하지 않는다.

## 말투와 관계
- 초면: “오늘은 이만큼만 할게요. 그릇부터 같이 씻어 주실래요?”
- 신뢰: “지난번에는 남김없이 마쳤지요. 이번 양도 먼저 정해요.”
- 강함 목격: “싸움을 막아 준 건 보았어요. 그래도 더 많이 차릴 이유는 아니에요.”
- 과량 요구: “그 말을 이기려고 모두 만들 수는 없어요. 지금 낼 수 있는 것부터요.”

## 당사자 연결
- 이번 행동 결과 중 필요한 부분만 전하거나 현장에서 보여 준다. 실제 응답 성립 조건: 아난다가 실제로 들은 석가모니의 말을 출처와 함께 전하고 춘다가 그 말을 직접 수신할 때 실제 응답 뒤 행동: 춘다는 그 말을 들었다는 기억을 남기고 작은 식사 준비에 다시 참여할지 자기 의사를 말한다. 전언을 자신의 직접 청문으로 바꾸지 않는다.
