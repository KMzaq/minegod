## 운영참조
퀘스트/공통설계/시간_조우_성장_운영정책.json: state_separation, clocks, general_encounter, atomic_contract. 개인 확정값 우선. 기존 무작위 허용 경로만 공통 추첨 적용하며 배치/기록/제한접촉을 무작위로 바꾸지 않는다.

## 접근
세계해금은 누군가 한 번 달성한 공용 사실. 후발자 반복 해금0. 조우 적격 현재 주체·확률과 등장 뒤 일반 접촉·개인 수락을 분리한다. 동일 본체1·실제 생사/봉인/태어남/표현모드·현 위치·의사 확인. 현장에 이미 있어야 등장한다는 순환선행0. 기록전용 배우의 실체화0. SIDE는 개인 MAIN 소유·완료를 만들지 않는다.

## 회차와권리
원 EP만 canonical. 같은 사건에 새 Q를 발행하지 않는다. world_uuid+EP+원사건_uuid가 사건키, 개인참여는 사건키+player_uuid. 선착순 클릭으로 타인 몫/MAIN을 가져가지 않는다. 공동원물은 하나이고 소유·예약재고는 직렬화한다. 필수 목표가 만족된 순간 완료를 기록하고 선택후기/수강/수령/대여하지 않은 물품반환을 완료 AND 조건으로 붙이지 않는다.

## 정산
원재고=실제소비+현재보관+실제이전+실제소실. 가공 전후 형태가 달라도 같은 원물 lineage를 보존. 복구는 해당 delivery_id의 실제 인벤·현장·보관 receipt를 대조하고 미인도량만; 불확실하면 인도 보류. 완료/권리생성/예약/실인도/사용/반환은 분리. 팀/FTB 표시·재접속·반복클릭으로 신규 지급0. 선물 거절과 미수령 보류를 구별한다.

## 시간과재개
별도 개인 명시기한이 없는 사건은 시간제한 없음. 예상분은 이동/조작 정적 추정이며 마감이 아니다. 사망·로그아웃·서버중단은 마지막 확정 행동/소비/원물 위치 저장 후 현재 접근과 동의를 재검사해 미실행만 재개. 죽은 싹·파손·소실은 실제 발생만 기록. 정상 상태를 망가뜨려 절정 재현0. 이미 끝난 원사건 재개방0.

## 후발
현재 미완 목표에 본인 수락·기여로 참여하거나 현재 공개 결과를 관찰한다. 과거 참가·칭찬·관계·사적발언·보상권은 복사0. 완료한 물건을 되돌려 재수행하지 않는다. 선택 서비스는 독립 요청/회차/재료/정산을 사용한다.

## 지식
SET_FACT는 발생 사실이며 GRANT_KNOWLEDGE는 직접관측 또는 공개허락된 실제전언 수신 뒤만. fact_event+receiver+delivery 유일키. 같은 팀·같은 방·저자사실을 자동앎으로 바꾸지 않는다. 현장 관측자는 현재 결과만, 사적 발언은 당시 실제 청취자·허락범위만. 전달자 보고와 NPC 직접 시연 목격을 구분한다. 미전달/미수신/미응답/비공개/명시거절을 각각 저장.

## 서비스
아래 개인 서비스는 선택 후속이며 원 사건/MAIN 완료를 열거나 갱신하지 않는다. service_id+player_uuid+독립session_uuid가 키. 회차마다 본체·물품·의사 재확인; 안내/실습/실제 지식수신 분리. 원 사건의 1회 무료 지도권은 최초 실제수강 때만 사용, 재접속은 동일session 재개. 후발자가 과거 지도권을 상속하지 않으며 새로운 현재 요청은 무보상 서비스로 별도 동의 가능. 반복 경제/전투성장0.
