1. 현재 허락 배1척과 실제짐 Q를 확인한다. 물가 두 기존지점에서 전용 비전투 손짓 입력으로 신호를 왕복 송수신한다. 이 입력은 신규 장면 조작이며 웅크리기·하선 입력과 분리한다. 시오쓰치와 현재 보이는 가까운 굽이·원착지점·비상착지점을 직접 정한다. 거리/성능컷 발명0. 짐중 d를 동의육지보관해 덜기 OR 필요한짐을 유지하고 더짧은 실재구간으로 합의. Q=0이면 빈배 그대로.
2. 플레이어가 실제 배에 탑승해 고른 굽이까지 조종하고 신호를 보내 실제회신을 받은 뒤 원착지점에 돌아와 정박·하선한다. 방향지점과 회신·귀환좌표를 기록하며 수락/지도만으로 항해0. 신호상실·실제위험이면 준비한 가까운착지점으로 물러나 기본왕복 미완료; 폭풍·침몰을 연출상 생성하지 않는다.
3. 기본왕복 뒤 현재 허락·신호범위 내 추가 작은구간을 실제 탐색하고 귀환 OR 추가출항 없이 먼길보류 의사를 실제 확인받는다. 둘 다 필수 아님. 와타쓰미 제한수역은 실제허락·제한·거절을 시오쓰치가 들은 범위만; 답을 항해실적으로 바꾸지 않는다. 육지에 맡긴 짐은 실제원주인이 회수한다.

### 완료와 원문 분기

B1: SIDE를 수락하고 실제 배·짐 소유자 허락을 확인한다. 덜 짐은 육지에 두거나 필요한 짐은 남기되 왕복 범위를 더 짧게 정한다. 물가에서 서로 손짓을 실제 보내고 되돌려 알아본다.
- 짐을 덜고 신호를 맞춘다: 육지에 남긴 짐과 실제 신호 시험. 출항·귀환은 아직 없음.
- 필요한 짐은 남기고 더 짧게 맞춘다: 필요한 짐은 배에 남음. 가짜 하역0.

B2: 약속한 가까운 굽이까지 실제 조종하고 신호를 되돌려 보낸 뒤 같은 착지점으로 돌아온다. 신호가 안 보이거나 위험하면 준비한 가장 가까운 귀환으로 전환한다.
- 선택한 짧은 왕복을 실제 마친다: 실제 왕복을 마친 경우만 귀환. 확인한 구간만 정보로 남는다.
- 현재 위험으로 가까운 착지점에 물러난다: 실제 이동·철수·사용 자원만. 원래 왕복 성공·먼 항로 정보0.

B3: 현재 허락·준비·신호 범위 안에서 작은 추가 구간을 보고 돌아오거나 먼 길 전체를 다음 준비로 미룬다. 와타쓰미가 실제 응답하면 허락의 범위와 현재 변경점을 시오쓰치가 직접 듣고 그 범위만 안내한다.
- 신호 안의 일부만 더 확인하고 돌아온다: 추가 확인 구간과 실제 귀환만. 먼 길 전체 성공0.
- 먼 길을 미루고 가까운 정보로 마친다: 기본 SIDE 수행은 보존, 먼 항로 성공·추가 소비0.
- 와타쓰미의 현재 허락 범위를 따로 듣는다: 실제 허락 정보만. 자동 항해·시련·가호0.
