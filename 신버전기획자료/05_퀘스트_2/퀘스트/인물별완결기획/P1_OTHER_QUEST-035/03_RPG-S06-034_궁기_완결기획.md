# 궁기 — 궁기의 몰이

관리키 RPG-S06-034 / 정본 EP021-RPG-S06-034 / 기획별칭 Q035-03. 저술채택본이며 구현·게임시험 미실행. 공통계약 P035_COMMON 적용.

## 이야기와 경계
칭찬 같은 반문에도 가시가 있다. 불편한 답에는 긴 정적을 두며 인정 뒤에도 탐욕과 적대 가능성이 사라지지 않는다.
궁기가 직접 가한 압박 속에서 이 개인이 고른 실제 동선·대응, 자기 맡은 한정 몫 또는 거절 후 실제 탈출, 남을 먹잇감으로 내놓지 않고 자기 한계를 직접 지킨 결과를 본다. 승리·영웅 대사만으로는 인정하지 않는다. 거절한 사람에게 미수락 미끼 몫의 이행을 요구하지 않는다. 이 근거를 검토한 궁기의 실제 인정 결정·선언이 있어야 이 개인 인정 경로의 성취다. 활동 성공·SIDE 완료 표시만으로 인정은 생기지 않는다. 미전달 선언은 같은 사실의 전달만 남긴다.
궁기는 이번 추격을 거둘지 스스로 정하고, 거둔 경우 실제 몸을 통행선 밖으로 옮긴다. 불쾌함과 호기심은 남고 다음 이 개인에게는 더 노골적인 거래 조건을 먼저 말한다.

## 해금·조우·개인 수행
세계해금은 공통, 등장주체·현재접촉·개인인정·보상은 별개. 세부는 00_공통계약 및 01_세계해금과인정에 따른다. 원문 연결 C 장면은 해당 본편 원장만 참조하며 재정산하지 않는다. 동행은 친구의 조우 주체 자격·개인 인정·권리를 대신 만들지 않지만, 이미 등장한 같은 본체의 일반 목격·대화를 개인 네 인정 부족만으로 막지 않는다.

## 실제 현장과 목표
기존 바위길 굽이 A와 눈으로 확인 가능한 열린 터 B(16~32블록), 탈출점 E와 엄폐2곳. 다른 통행자 거처로 유도하지 않는다.

1. 궁기가 실제 압박하는 방향과 현재 비신격 포식자·열린 퇴로를 확인한다. OR 미끼의 한정 몫을 흥정해 SIDE수락 / 제안거절 후 자기 탈출 EVENT. 거절자에게 미끼 의무0.

2. 수락 경로는 실제 포식자를 B로 유도해 싸우거나 따돌린다. 성공은 그 개체가 궁기의 합의 통행선에 현재 돌아와 위협할 수 없게 된 실제 결과. 벽 뒤 잠깐 숨음·언로드·순간이동은 포식자 처리증거0.

3. 거절 경로는 실제 압박에서 자력 동선·엄폐를 이용해 E까지 빠져나간다. 현재 실제 공격이 있으면 피하거나 방어; 궁기와 결투승리·포식자처리 강제0. 남을 미끼로 내놓지 않는다.

4. 안전 대면 또는 실제 허용 보고 뒤 궁기가 당사자의 한계·탈출/한정이행·남에게 전가하지 않은 행동을 검토한다. 궁기의 자발적 추격철회와 인정 결정은 각기 별도.

## 분기·실패·후발
적을 단순 놓쳐 통행 위협이 남으면 수락몫 미완료. 거절 후 실제 안전탈출은 정상 EVENT 결과이며 인정 검토가 가능하되 자동확정0. 압박 지속 중 대사만으로 안전종료하지 않는다. NPC부재면 인정수신 대기, 안전탈출은 보존.
P035_COMMON#/recovery 적용. 제안 거절은 적대 공격의 자동 정지가 아니다. 실제 엄폐·퇴로로 벗어나고 전투 상태가 끝난 뒤에만 재접촉한다. 실패한 내기는 남은 위협·약속만 재검토하며 죽은 적·이미 탈출한 장면을 복제하지 않는다. 후발자도 현재 궁기의 위험한 다른 요구를 흥정하거나 실제 대치에서 자기 선택을 보여 재심받을 수 있다. 인정 없는 전투 승리는 별도 경험이다.
후발자는 현재 남은역할만 수행하며 개인인정·지난공로를 복사하지 않는다.

## 결과와 보상
사흉수 궁기 인정1항목 외 실물0. 인정해도 궁기 탐욕·불쾌함·다음 적대 가능성 유지. 이번 몸을 통행선 밖으로 옮겼다는 사실만 남기며 주변 모두 안전보장0.
궁기가 직접 가한 압박 속에서 이 개인이 고른 실제 동선·대응, 자기 맡은 한정 몫 또는 거절 후 실제 탈출, 남을 먹잇감으로 내놓지 않고 자기 한계를 직접 지킨 결과를 본다. 승리·영웅 대사만으로는 인정하지 않는다. 거절한 사람에게 미수락 미끼 몫의 이행을 요구하지 않는다. 실제 NPC가 그 개인을 인정하기로 결정·선언한 사실만 해당 개인 인정이다. 실물 지급권은 없다.

## 실제 반응과 지식수신
“남을 먼저 내밀 줄 알았는데. 네가 끝이라고 한 자리까지는 살아 나왔군.” 칭찬 뒤 긴 정적을 남기며 선량한 개심·복종을 선언하지 않는다.
직접목격과 실제보고수신을 분리한다. 선언·전달·수신이 다르며 타인의 사적과거를 세계해금으로 알게 하지 않는다.
