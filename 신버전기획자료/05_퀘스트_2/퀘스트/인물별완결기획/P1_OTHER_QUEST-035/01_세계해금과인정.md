# 세계 해금과 개인 인정의 분리

이번에 채택한 기획이며 실제 서버 구현·시험 완료가 아니다. 기존의 유효한 접촉과 세계가용성을 소급 잠그지 않는다.

## 네 가지 상태
1. 세계 해금: 누군가 유효 해금 행동을 하면 세계 공통으로 열린다.
2. 등장 주체: 현재 조건을 갖춘 개인과 기존 확률을 검사한다.
3. 일반 접촉: 실제 나타난 같은 본체를 동행자도 보고 대화할 수 있다. 안전·의사·허용 모드는 유지한다.
4. 개인 결과: 인정·관계·수주·수행·보상·지식수신은 각자 실제 근거만 남긴다.

## 용신의 세계가용성: 이번 최소 채택값
황룡은 청룡·백호·주작·현무의 저장된 세계개방 기록이 모두 성립하면 세계가용성을 연다. 흑룡은 혼돈·궁기·도올·도철의 세계개방 기록이 모두 성립하면 연다. 현재 네 존재의 출석·생존·응답, 공동 인정수집, 새 아이템이나 시험을 요구하지 않는다. 이 결합은 새 플레이 과업이 아니다.

원문의 동일 개인 네 인정은 세계개방으로 재분류하지 않는다. 황룡의 실제 새 조우 주체는 동일 개인의 네 사신수 인정, 흑룡은 동일 개인의 네 사흉수 인정을 갖춰야 한다. 파티가 둘씩 나눈 인정으로 대신할 수 없다. 그러나 그 주체와 함께 이미 나온 본체를 만난 친구에게 같은 네 인정을 다시 요구하지 않는다. 두 갈래 여덟 인정을 모두 모을 필요도 없다.

## 기존 자연 접촉
백호·주작의 조기접촉은 유지한다. 궁기·현무·도올은 원문의 추가 이력 없는 자연접촉안을 이번 채택한다. 순찰·대기시간·운반업적을 새 입장권으로 만들지 않는다. 현재 위치와 봉인·발화의사는 접촉 단계에서만 검사한다.

## 새 일상 세계해금 세 가지

### 도철 / WORLD035-TAOTIE-COOK
한 명에게 (직접 수확한 재료로 실제 음식 제작 완료) OR (자기가 마련한 식재료를 직접 실제 조리 완료) 중 하나가 최초 유효하게 성립.

- 제작 대안: 플레이어가 소유자 허락을 받은 밀을 직접 수확하고 그 provenance의 밀3개로 빵1개를 작업대에서 제작한다. 다른 정상 음식 조합도 제작 결과가 음식이고 입력이 자기 수확재료일 때 같은 판정.
- 조리 대안: 자기 마련 감자1개를 허락 화로/훈연기 또는 현행 허용 조리 블록에 직접 넣고 실제 구운감자1개 완성 이벤트를 확인한다. 자기 마련은 직접 채집·허락 구입/증여로 식재료 소유·준비를 한 기록이며 친구가 준 완성음식은 아님. 다른 현행 음식 조리 레시피도 허용.

증거: 행동자 UUID, 재료 원물/소유/출처, 직접 투입 또는 제작 이벤트, 변환결과 UUID, 실제 완성 시각. 공용 화로에서는 투입 provenance와 완성 결과를 묶어 다른 사람이 꺼냈다는 이유로 제작자를 바꾸지 않는다. 자동장치의 소유자 이름만으로 직접조리 인정0.

원물: 기존 레시피 재료·연료만 정상 소비. 완성음식은 원소유자 것, 도철에게 헌납/인도 필요0. 이미 먹거나 잃어도 세계해금 보존.

중단: 불이 꺼지거나 중단이면 정상 화로 상태에서 이어진 실제 완성만 확인. 미완성 음식 성공0. 다른 플레이어는 같은 조리를 반복할 의무0.

개인 경계: 도철 개인 인정·관계·수주·보상0. 이후 거래는 새 실제 음식·동의로만.

### 청룡 / WORLD035-QINGLONG-RETURN
한 명이 실제 연결된 한 물길/물가 구간의 출발쪽에서 반대편까지 이동하고 출발쪽으로 직접 돌아와 확인.

- 지형검사로 현재 연결된 물길/물가의 자연 굽이 또는 맞은편을 A/B로 고정한다. 초기 선정 권장 경로16~48블록, 거리 점수나 모든 플레이어에게 강제하는 최소 업적 컷이 아니라 실제 구간을 선정하는 제작 규칙이다. A/B는 겹치지 않는 도착영역 각 반경2블록으로 잡고 경로의 연결성을 함께 저장한다.
- 걷기 OR 직접 보트조종 OR 해당 구간 전체를 실제 동승한 보트탑승으로 A→B→A를 실제 통과한다. 물에 빠지거나 헤엄치기를 강요하지 않는다. 플레이어가 A에서 되돌아온 물길을 실제 향해 확인 행동을 하면 해당 구간 탐험으로 닫는다.

증거: route_uuid, 물길/물가 연결 샘플, A/B 좌표와 실제 이동 경로, 탑승 구간과 각 참가자UUID, 귀환 확인. 순간이동·제자리회전·친구 기록열람은 실제 왕복을 대신하지 않음. 동승자는 전 구간에 실제 있어야 개인기여 기록.

원물: 자기 또는 대여허락 보트는 정상 원물, 제출·소모0. 도구·식량의 실제 사용만 정상 소비.

중단: 로그아웃 시 현재 위치·왕복 미완료를 보존. 다른이가 보트를 옮겼다고 부재 플레이어 이동 인정0. 길이 변하면 현재 연결/안전 재검사 후 남은 실제구간을 이어가거나 새구간 합의, 과거 이미 완료 이력은 유지.

개인 경계: 세계 해금만. 청룡의 귀환점검 SIDE·인정은 실제 만남 이후 별도이며 후발 개인왕복 재요구0.

### 혼돈 / WORLD035-HUNDUN-TIMBRE
같은 한 명의 자기 제작 음표블록 완성 AND 그 동일 원물의 첫 받침 실제 직접 연주 AND 다른 받침에서 실제 다른 악기음의 직접 연주.

- 기존 레시피(판자8개+레드스톤1개)의 자기/사용허락 재료로 음표블록1개를 직접 제작한다. 원물에 creator UUID를 보존한다.
- 허락된 받침A 위, 상부가 실제 발음을 허용하는 자리에서 제작자가 직접 음표블록을1회 연주한다. 음높이는 제한하지 않고 실제 악기/음원 분류를 기록한다.
- 같은 음표블록을 정상 회수하여 다른 종류 받침B 위에 재배치한 뒤 같은 제작자가 직접1회 연주한다. A/B는 실제 instrument 분류가 달라야 하며 예시는 흙계열 하프와 목재계열 베이스. 서버 버전/모드의 실제 발음결과로 판정, 이름만 다른 같은음 받침은 불충족.

증거: craft event, creator UUID, note_block origin UUID, 각 배치/회수 이력, 받침 종류 및 instrument, 실제 sound event와 직접 누른 actor. 다른 사람이 대신 만든블록·레드스톤 자동연주·음이 차단된 눌림으로 대체0. 곡·박자·희귀재료·반복횟수 컷0.

원물: 기존 제작 재료만 소비. 받침과 음표블록 소유권 유지, 혼돈 앞 제출0. 원물 분실 뒤 이미 완료 이력은 유지. 미완료에서 다른 새 원물로 바꾸면 제작부터 그 새원물의 유효 이력을 묶는다.

중단: 첫연주 저장 뒤 재시작 시 동일 원물로 둘째만 이어갈 수 있음. 접속/재배치만으로 연주생성0. 세계1회해금 뒤 다른이의 악기만들기 강제0.

개인 경계: 세계 해금만, 개인 혼돈 인정·놀이 성공·스킬0.

## 인정과 선언
원문의 각8존재 EP021은 자신의 실제 증거와 자발적 인정결정/선언을 따로 둔다. 최초 작은 도움이나 활동완료를 인정으로 치환하지 않는다. EVENT 증거도 해당 원문경로에 따라 검토하되 SIDE를 소급 수락하지 않는다. 시스템은 decision receipt를 확인할 뿐 NPC의 숨은 마음을 완료bool로 대체하지 않는다.

정해진 대답, 퀘스트 완료 표시, 전투승리, 호감·주시·가호는 인정의 대체가 아니다. 이미 성립한 선언을 못 들었다면 같은 사실을 전달할 일만 남고 재시험은 없다. 새 부탁을 거절했다고 기존 인정을 취소하지 않는다.
