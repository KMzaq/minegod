# 혼돈 — 틀린 순서의 다른 해법

관리키 USER-BEAST-DRAGON-003 / 정본 EP021-USER-BEAST-DRAGON-003 / 기획별칭 Q035-07. 저술채택본이며 구현·게임시험 미실행. 공통계약 P035_COMMON 적용.

## 이야기와 경계
순서를 비틀고 낱말을 되짚으며 상대의 당황을 즐긴다. 그렇다고 실제 유효했던 답을 없던 것으로 돌리거나 허락 범위를 뒤집지는 않는다.
혼돈이 실제 자기 물건의 처음 말한 쓰임에 맞는 탐색 결과와 이 개인의 대안 기준을 직접 확인한다. 이미 유효한 답을 갑자기 취소하지 않고, 허락된 새 배치를 플레이어가 실제 만들고 혼돈 자신도 그 기준으로 찾아보는 역할 교환까지 확인한다. 고정 답 암기·새 해법 주장만은 부족하다. 이 근거를 검토한 혼돈의 실제 인정 결정·선언이 있어야 이 개인 인정 경로의 성취다. 활동 성공·SIDE 완료 표시만으로 인정은 생기지 않는다. 미전달 선언은 같은 사실의 전달만 남긴다.
혼돈은 뜻을 비트는 재미를 유지하면서 자기 차례에 낯선 배치를 실제 찾는다. 다음 이 개인과 놀 때 그 사람의 기준을 하나 끌어들이고 스스로도 예측 못 할 배치를 맡는다.

## 해금·조우·개인 수행
세계해금은 공통, 등장주체·현재접촉·개인인정·보상은 별개. 세부는 00_공통계약 및 01_세계해금과인정에 따른다. 원문 연결 C 장면은 해당 본편 원장만 참조하며 재정산하지 않는다. 동행은 친구의 조우 주체 자격·개인 인정·권리를 대신 만들지 않지만, 이미 등장한 같은 본체의 일반 목격·대화를 개인 네 인정 부족만으로 막지 않는다.

## 실제 현장과 목표
혼돈의 실제 짐을 놓을 허락 평지5×5, 소유물3개가 있으면 세 위치로 배치하되 수량이 적으면 실제 현물만.

1. 혼돈이 현재 실제 물건의 검증가능한 쓰임 하나를 말한다. 예: 자기소유 빈양동이·막대기·돌 중 “물을 담아 옮길 것”. 요청뜻·안전시연·사용허락을 고정한다. SIDE수락 OR 수주없는 놀이 EVENT로 시작한다.

2. 선택 물건을 실제 사용해 처음 쓰임을 증명한다. 예는 허락 수원에서 양동이에 물을 담고 자기 허락 가마솥에 옮겨 원수원 변경을 소유자와 확인한다. 기존 현물에 다른 유효해법이 있으면 같은 기능 판정으로 허용한다.

3. 새 규칙은 선택적 새놀이이며 처음 유효답 취소0. 역할교환을 선택하면 허락물건을 실제 다른 자리로 재배치하고 이번에 검증할 감각·사용흔적 기준1개를 설명한다. 혼돈 본인이 실제 찾아 집거나 가리켜 현재 결과를 확인한다.

4. 처음의 기능검증+실제 새배치+혼돈의 실제 탐색을 검토한 뒤 별도 인정 판단. 혼돈 정답/오답은 컷 아님, 역할교환을 거절하면 처음 성공만 보존하고 인정의 해당 근거는 미완료.

## 분기·실패·후발
물건·수원·가마솥이 없으면 예시를 스폰하지 않고 현물의 다른 검증가능 쓰임을 사전 고정한다. 물품 사용권이 없으면 사용행동만 보류. 정답대사 암기나 새해법 주장만 성공0. 첫 성공은 새규칙 거절로 지우지 않는다.
P035_COMMON#/recovery 적용. 거절하면 짐을 가져가지 않고 놀이를 끝낸다. 망가뜨리거나 무단으로 뒤집었으면 실제 복구 가능 범위부터 협의한다. 후발자·재도전자는 현재 자기 짐과 허락된 다른 탐색 기준을 사용할 수 있으며 동일 수수께끼 복원이나 정답 대사 재현을 요구하지 않는다.
후발자는 현재 남은역할만 수행하며 개인인정·지난공로를 복사하지 않는다.

## 실제 반응과 지식수신
“네가 바꾼 자리에서 내가 찾는 쪽이라니. 처음 답은 맞았어. 이건 다른 놀이지.” 장난과 순서비틀기는 유지한다.
