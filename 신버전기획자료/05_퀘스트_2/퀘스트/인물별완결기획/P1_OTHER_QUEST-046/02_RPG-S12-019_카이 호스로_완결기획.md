## 실제 수행

1. 실제 운반을 요청한 주민과 짐·수령자·목적지를 확인한다. 고장 난 수레 1대의 원소유자와 손상 부위, 허용 재료를 보고 수락한다. 첫 쉼점은 출발점에서 걸어서 12–24블록, 인도점은 그 뒤 16–32블록의 기존 통행로에서 고른다. 짐은 실제 맡긴 품목·정수량의 수락묶음이다.

2. 수레 바퀴가 구현된 현장에서는 들뜬 바퀴 1곳을 정렬하고 쐐기 2개를 끼워 실제 바퀴가 돌아가는지 확인한다. 표준 소모는 판자 2개·막대 2개이며 실제 손상에 필요한 다른 재료·정수량은 소유자와 합의하여 묶음을 고정한다. 말로 수선을 끝내지 않는다. 수레 연결이 미구현이면 수선 성과를 부여하지 않고, 소유자가 원할 때 기존 가용 마인카트나 보트 운반으로 별도 합의한다. 선택 가능한 실제 수단이 없는 경우 짐은 그대로 두고 수선 경로를 보류한다.

3. 본인 또는 카이 호스로와 실제 수레를 첫 쉼점까지 밀어 옮긴다. 대체 수단이면 실제 같은 짐을 적재해 해당 이동 동작을 수행한다. 첫 쉼점 도착만으로 주민 최종 수령을 만들지 않는다. 수레·보트·카트 소유권도 이동하지 않는다.

4. 직접 남은 길을 운반하거나, 도움을 원하는 참가자에게 남은 구간을 맡기는 OR 선택을 한다. 인계자는 상대의 명시 수락과 동일 짐 UID의 실제 인수를 확인한다. 최종 수령자가 합의 인도점에서 실제 받은 잔량이 0이 된 때 배송 완료, 일부 인수는 해당 수량만 완료다. 도움 요청만 해놓고 완료하지 않는다.

5. 혈통을 내세워 수레를 양도하라 하면 운반 협력은 중단된다. 이미 실제 고친 부분은 보존하고 주민 소유를 유지한다. 파랑기스의 경로 판단은 그녀가 허락한 전언을 카이 호스로가 실제 들었을 때만 소개하며 새 왕위 승인·귀환 완료는 없다.
