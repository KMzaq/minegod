## 실제 수행

1. 실제 기존 다리의 허용 구간과 현재 흔들리는 발판1곳·빈 손수레1대를 확인한다. 두 끝의 마른 안전점과 이미 있는 우회로를 걸어 확인한 뒤 무거운 화물은 내려둔다. 정상 다리에 일부러 결함을 만들지 않는다. 결함이 없으면 관찰만 하고 수리 사건은 미발생이다.

2. 김수로가 실제 관측하는 동안 플레이어는 안전한 쪽에서 빈 수레를 밀어 문제발판 앞까지 움직인다. 흔들림이 관찰되면 그 구간을 막고 작은 짐을 기존 우회로로 나눈다. 무거운 짐을 밀어 넣은 경우에만 실제 멈춤·손상을 기록하며 자동 추락/파손은 없다.

3. 허락된 자재로 발판1블록의 해당 결함을 수선한다. 기본 제안은 원래 동일수종 판자1개 교체이며 실제 이음 수선이면 해당 자재1개분을 적용한다. 기존 도구/받침을 사용하고 공구는 대여 반환한다. 수선 후 빈 수레 A→B→A, 이어 합의된 작은 짐1묶음을 실은 수레 A→B→A를 각각 실제 시험한다.

4. 빈 수레와 작은 짐 왕복이 모두 끝나고 김수로가 실제 확인한 구간만 개방한다. 자재 부족·작은짐 미시험은 완료한 수리/빈수레 부분만 남기고 구간은 닫아둔다. 결함 은폐가 실제 발견되면 해당구간 재폐쇄·실제 손해 정정만, 발생하지 않은 배상액은0이다.
