## EP025B-RPG-S08-021 · 수행
예상 7–12분. 시간제한 없음.
1. 메브 소유 현물을 상자 또는 허락된 바닥 전시에서 실제 세고, 전시/나눔/혼합을 수락한다. 기본 예산안은 실재 빵8개 중 주민 몫6·운반 보수2이며, 빵이 없으면 실제 물품 품목과 정수량을 새 합의한다. 기존 합의가 있으면 그 합의 우선, 없는 재고 생성0.
2. 전시는 허락된 3×2블록 자리에 실제 옮기고 통행 폭2블록을 유지하면 종료. 분배는 지정 수혜자 UID별 정확한 몫을 실제 들고 전달·수령 확인. 운반 보수는 같은 총량에서 예약하며 주민 물량과 중복 계산하지 않는다.
3. 수혜자는 식사/수선/보관을 자유 선택한다. 식사·후기·감사·아일릴 응답은 완료 AND 아님. 혼합은 실제 전시/인도한 몫 각각 종결하고 미수령만 남긴다.
4. 타인 물건 제안은 인도 전 차단, 이미 옮겼다면 원물 반환·실수령을 확인한다. 메브가 자기 물량으로 수정하면 수혜자별 새 동의 후 미실행분만 이어간다.

### 원물·정산
예시 8=주민6+보수2, 전시와 분배는 같은 UID를 중복 할당하지 않음. 식사 소비는 수혜자 수령 이후 별도 기록. 대체 합의의 품목/정수량/소유자/수령자/수정번호를 인도·복구까지 동결한다.
기본 합의안 운반 빵2개는 신규 생성 보상이 아니라 메브 실재8개 안의 몫. 무보수 동의 또는 다른 품목/정수량 합의도 보존한다. 전시 결말 현물보상0. 유효 운반 보수는 후기 없이 인도, 가득 참이면 예약 미인도2만 복구.

### 완료와 원문 분기
메브가 자기 소유분으로 실제 전시를 마치면 전시 결말, 실제 분배를 인도하고 수혜자가 수령하면 그 물량의 나눔 결말이다. 수혜자의 사용·의견은 본인의 현재 실제 선택만 기록한다. 운반 보수는 사전 합의한 몫만 같은 물량에서 차감한다. 아일릴 비용 답이 없으면 상대와의 흥정은 별도 미완료다.

B1: SIDE를 수락한 플레이어가 현재 현물과 소유를 확인한다. 메브가 전시할 자기 몫과 실제 내놓을 자기 몫을 직접 정한다. 플레이어 운반 보수가 있다면 받는 사람 몫을 줄이기 전에 같은 분배에서 합의한다.
- 자기 전시로 남길 물건을 정한다: 실제 전시 준비. 주민 수령·지원0.
- 실제로 건넬 몫을 나눈다: 분배 준비만. 물건은 아직 인도 전이고 지지·기부 공로는 미발생이다.
- 현재 하던 일의 이유를 묻고 참여 여부는 따로 정한다: 실제 질문과 허락된 현재 답의 수신만. 질문하지 않은 행동·보고·침묵·먼저 하는 NPC 발언에 이 질문 수신을 공통 조건으로 붙이지 않는다. 이미 끝난 자기 결과는 보존한다.

B2: 분배 갈래는 플레이어가 실제 수혜자에게 합의 물량을 운반하고 각 수령자가 받는 것을 확인한다. 주민은 실제 받은 식재료를 먹을지, 재료를 자기 도구 수선에 쓸지, 보관할지 고른다. 전시 갈래는 통행을 막지 않는 자리에서 실제 전시를 마친다.
- 합의한 자기 몫을 실제 수혜자에게 보낸다: 실제 받은 물량만 지원. 주민 지지·사용은 별도 실제 응답과 행동이 있어야 한다.
- 전시만 마친다: 전시 결말만. 변경 주민 지원·수령·감사0.
- 남의 물건을 허락 없이 보태려 한다: 실제 부당 이동·반환·잔치 중단 범위만. 훔치지 않은 제안에 도난 피해를 만들지 않는다.

B3: 실제 수혜자는 원하면 무엇을 받았고 어떻게 썼는지 말한다. 메브는 자기 몫에서 빠진 물량과 남은 전시를 직접 보고 다음 분배안에서 어느 쪽을 택할지 생각한다. 아일릴의 실제 반대·비용 답이 있으면 두 사람이 포기할 몫을 따로 흥정한다.
- 실제 받은 사람의 말을 듣고 정산한다: 실제 도움과 들은 의견만. 메브 호감·마을 전체 지지 자동 상승0.
- 전시 결과 또는 침묵한 수혜자 상태로 마친다: 전시 결말 또는 실제 인도 결말 보존. 감사·찬성·사용 증거는 미확인이다.
- 타인 물건을 돌려주고 자기 몫으로 줄인다: 반환·새 제안만. 이전 중단·실제 손실을 지우거나 새 분배를 자동 완료하지 않는다.

## 성격과 반응
사교 자리에서 먼저 대화를 열고 자기 매력을 자신 있게 드러낸다. 흥정에서도 자기 몫을 남의 허락 뒤에 숨기려 하지 않는다. 상대의 말을 다 듣고도 무엇이 자기 결정인지 다시 짚는다. 보이는 크기와 실제 남에게 건너간 몫을 다르게 헤아리며 칭찬만으로 선택의 값을 덮지 않는다. 말의 주도권을 빼앗기면 자기 쪽으로 시선을 돌리는 질문을 던진다. 물건을 바로 집지 않고 남의 반응을 살피며, 잘 익은 열매를 색만 보고 맞히는 승부를 좋아한다.
제안: “내가 내놓은 몫이라고 분명히 말해. 그리고 네 몫도 먼저 정하자.” 전시 뒤: “보기는 좋군. 그렇다고 누가 먹었다고 쓰지는 마.” 분배 뒤: “빠진 수만큼 누구 손에 갔는지 알겠어.”
초면/경계에는 현재 소유·의사를 먼저 확인하고, 실제 신뢰가 있으면 반대 의견과 독립 시도를 더 편히 묻는다. 친분은 수락·소유·보상·사적공개를 대신하지 않는다.
