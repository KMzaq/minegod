## EP026-RPG-S08-031 · 수행
예상 6–11분. 시간제한 없음.
1. 기존 숲 폐허 갈림길에서 현재 합의 왕복 경로를 정한다. 기본 제안은 같은 차원 확인된20블록 길 왕복이며 실제 지형·허락 경계에 맞춰 출발/회차점을 동결. 프윌 참석을 요구하지 않는다.
2. 자기 장비로 걷기. 실제 대여 원물이 있을 때만 UID/수량/상태를 인수 기록. 현존 비신격 위협은 피하기 OR 기존 전투로 통과, 위협 없으면 걷기만. 실제 회차점→귀환점 도달과 필요한 반환을 확인한다.
3. 실제 위험 우회는 안전경로로 돌아와 경로/이유를 아라운이 실제 듣고 수락해야 대체귀환 인정. 미수신이면 실제 귀환만 보존. 경계침범은 실제 위반과 미반환만, 안전철수는 막지 않는다.
4. 다음 재입장 논의 자격→아라운의 현재 구체 허락→본인의 실제 통과는 세 상태다. 다음 허락은 이번 왕복 완료의 필수후기 아님. 허락은 대상·구간·방향·한 번 왕복 단위로만, 현재 봉인/위치 검사 유지.

### 원물·정산
원물 대여0이면 반환0. 대여N은 실제 인수 정수N만 원주인에게 반환; 소실분은 실제 손해/미반환 기록, 새 대여로 과거 반환 완료0. 자기 장비 소유 유지.
물품 보상0. 유효 귀환자의 해당 제한 재입장 논의만 가능. 실제 허락 전 입장효과0, 미응답은 미수령 현물이 아니다.

### 완료와 원문 분기
합의한 왕복과 필요한 반환이 실제 끝난 본인에 한해 귀환 조건 이행을 확인한다. 아라운은 다음 제한된 재입장의 범위를 논의할 수 있다.
대안 결과: 수락된 우회 귀환은 정상 귀환과 같은 한정 논의로 이어진다. 설명 미수신·미수락이면 실제 귀환만 보존하고 허락 판정은 보류한다.
해로운 경로는 실제 위반·손실과 미완료만. 준비/클릭/질문으로 완료되지 않는다.

B1: 아라운이 갈림길의 나가는 쪽과 돌아오는 쪽을 번갈아 가리킨다. 플레이어는 오늘 실제로 걸을 짧은 왕복 구간과 귀환 지점을 함께 확인한다. 빌릴 물건이 실제 있다면 품목·현상태·주인을 확인하고 인수한다. 대여품이 없으면 빈손 출발이며 반환 과제를 만들지 않는다. 프윌의 참석이나 새 대답을 보편 선행으로 요구하지 않는다.
- 오늘의 실제 준비를 한다: 실제 준비·허락만. 실행 성공·상대 수신·보상권 없음.
- 이미 유효하게 한 자기 행동을 보여 준다: 유효한 자기 기여는 재연 없이 보존. 근거가 없는 완료·수신·수락은 생성하지 않는다.
- 이미 끝난 선택 경로의 근거를 접수한다: 이미 유효하게 마친 본인 수행을 재연 없이 접수한다. 새 친구의 기억·보상권을 만들지 않는다.
- 현재 하던 일의 이유를 묻고 참여 여부는 따로 정한다: 실제 질문과 허락된 현재 답의 수신만. 질문하지 않은 행동·보고·침묵·먼저 하는 NPC 발언에 이 질문 수신을 공통 조건으로 붙이지 않는다. 이미 끝난 자기 결과는 보존한다.

B2: 정상: 합의한 왕복 구간을 실제 걷는다. 비신격 위협이 있으면 물러설 공간을 확보해 피해 가거나 자기 준비에 맞춰 싸워 통과한다. 두 대응을 모두 요구하지 않는다. 위협이 없으면 전투를 만들지 않는다. 귀환 지점에 돌아와 아라운에게 자신이 실제 지난 길을 말하고, 빌린 물건이 있는 경우만 실제 돌려준다.
대안: 길의 실제 위험 때문에 합의한 구간을 계속 가지 않는다. 가능한 안전 경로로 돌아와 우회한 이유와 실제 지난 구간을 아라운에게 전한다. 안전한 연락 수단이 이미 있으면 출발 전 변경을 알리되 없는 원격 통신은 만들지 않는다. 아라운이 설명을 실제 듣고 수락하고 필요한 대여품 반환도 끝난 때만 대체 귀환으로 인정한다.
경계 위반: 돌아오겠다는 약속을 버리고 허락 범위 밖으로 더 들어간다. 실제 침입·위험·미반환만 남긴다. 아라운은 직접 발견하거나 유효 보고를 받은 범위에서 재입장 허락을 보류한다. 안전 철수는 막지 않는다.
- 합의한 정상 경로를 실제 수행한다: 합의한 왕복과 필요한 반환이 실제 끝난 본인에 한해 귀환 조건 이행을 확인한다. 아라운은 다음 제한된 재입장의 범위를 논의할 수 있다.
- 다른 허용 경로 또는 보류를 선택한다: 수락된 우회 귀환은 정상 귀환과 같은 한정 논의로 이어진다. 설명 미수신·미수락이면 실제 귀환만 보존하고 허락 판정은 보류한다.
- 경계를 어기는 제안을 하거나 실제 강행한다: 실제 해로운 제안/행동과 NPC가 안 범위만 실패·중단으로 남는다. 앞서 끝난 유효 행동은 보존하되 없는 성공·허락·보상은 주지 않는다.

B3: 아라운은 귀환자가 선 쪽으로 몸을 돌리고 다음 통행에서 물을 범위를 좁혀 말한다. 프윌에게 이 논의를 전하는 별도 허락·실제 수신이 없으면 프윌의 기억은 갱신하지 않는다. 실제 선택 경로의 근거만 확인하고 관계 결과와 보상별 자격·실제 제공은 분리한다.
- 정상 경로의 실제 결과를 마친다: 합의한 왕복과 필요한 반환이 실제 끝난 본인에 한해 귀환 조건 이행을 확인한다. 아라운은 다음 제한된 재입장의 범위를 논의할 수 있다.
- 선택한 대안의 결과만 남긴다: 수락된 우회 귀환은 정상 귀환과 같은 한정 논의로 이어진다. 설명 미수신·미수락이면 실제 귀환만 보존하고 허락 판정은 보류한다.
- 실패 또는 부분 결과를 남기고 돌아간다: 실제 끝난 몫 보존, 미완료와 필요한 정정·반환만 남음. 선택 후기 사양은 완료 취소 아님.

## 성격과 반응
앉기 전에 열린 문을 돌아보는 왕이다. 호의를 기억하되 그 빚을 남이 멋대로 불리는 것은 받아들이지 않는다. 짧은 질문 뒤 상대의 답을 끝까지 듣고, 문고리의 모양보다 젖은 손에도 잡히는지를 궁금해한다. 정중함이 곧 허락은 아니며 돌아올 약속까지 듣고 경계를 정한다.
출발: “나가는 길은 보았지. 돌아올 때 네가 설 자리는 어디인가?” 귀환 뒤: “돌아온 건 보았다. 다음 문턱은 지금 다시 이야기하지.”
초면/경계에는 현재 소유·의사를 먼저 확인하고, 실제 신뢰가 있으면 반대 의견과 독립 시도를 더 편히 묻는다. 친분은 수락·소유·보상·사적공개를 대신하지 않는다.
