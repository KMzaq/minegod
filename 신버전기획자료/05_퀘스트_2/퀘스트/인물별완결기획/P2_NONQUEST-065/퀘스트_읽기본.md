## RPG-S02-006 시귄

### 그릇을 내려놓을 자리
마른 동굴 입구 기존 받침 A, 시귄의 쉼자리 B는 A에서 3블록 이내, 두 자리와 퇴로 시야 확보. 로키의 위치는 별도로 확인하며 없으면 소환하지 않는다.

### 실제 수행
1. 시귄이 공개한 현재 그릇 1개의 내용·무게와 맡길 범위를 확인한다. 플레이어는 빈 받침을 손 2블록 안에서 눌러 흔들림을 시험한다. 시험만으로 인수하지 않는다. 위험을 감당하지 못하거나 시귄이 거절하면 교대 없이 주변 방해만 줄이고 끝낸다.
2. 인수하겠다는 현재 동의 후 두 사람이 같은 그릇의 무게를 실제 나눈다. 시귄의 손이 떨어지고 플레이어가 안정적으로 받친 시점에만 위탁 보유를 기록한다. 소유자는 시귄이며 내용물 폐기·복제·새 독 생성은 금지한다.
3. 자동 만료 없는 짧은 교대다. 시귄이 옆자리에서 손을 펴고 쉬는 실제 구간을 기록한다. 그만해야 하면 알리고 그녀가 다시 받을 때까지 받침과 현보유 상태를 유지한다. 그녀가 실제 받았거나 허용된 안전 받침에 놓였을 때만 떠난다.

### 분기와 마침
실제 휴식·중도 반환·교대 거절을 별도 결과로 닫는다. 감사는 로키 면책이나 봉인 접근권이 아니다.

### 중단·실패·재개
거절/미응답은 정상 종료 또는 해당 선택 보류. 이미 수행한 물리 행동·실제 수신은 남긴다. 사망/로그아웃/본체 부재는 완료가 아니며 현재 위험·위탁·반환 상태를 대조하고 같은 회차의 미완료 부분부터 재개한다. 실물이 이미 소비·전달되었으면 두 번째 실물 생성 0.

### 반복과 후발자
새 현재 요청과 남은 실제 현장 필요가 있을 때만 새 회차. 후발자는 기존 세계 해금 이력을 재수행하지 않으며 과거 참여·친분·지식·보상은 받지 않는다.

### 실제 청중
