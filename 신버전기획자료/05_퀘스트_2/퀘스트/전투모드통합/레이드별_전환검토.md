# 본편 8전투와 키메라 전환 검토

보스 HP를 일괄 올리지 않는다. 고정 저체력 전투는 강장비 5인의 빠른 제압을 허용하며 짐·인양·계약·귀환 수행을 대신하지 않는다. 모든 적 패턴의 공격범위/예고/활성/회복/패링·CC표는 유지한다. 아래 표의 목표는 5인 체류를 위한 저술 범위이지 강제 TTK나 실측값이 아니다.

| 전투 | 5인 HP 전→후 | 방어/강인 전→후 | 검토 목표 초 |
|---|---|---|---|
| C05 | 7000 → 7000 | 0/0 → 동일 | [180, 360] |
| C07 | 2360 → 2360 | 0/0 → 동일 | [60, 140] |
| C10 | 70 → 70 | 0/0 → 동일 | [1, 15] |
| C11 | 70 → 70 | 0/0 → 동일 | [1, 15] |
| C17 | 60 → 60 | 0/0 → 동일 | [1, 15] |
| T03 | 46 → 46 | 0/0 → 동일 | [1, 20] |
| T04 | 3420 → 3420 | 8/0 → 동일 | [80, 180] |
| C26 | 12000 → 12000 | 0/0 → 동일 | [240, 480] |
| CHIMERA | 10800 → 10800 | 8/4 → 동일 | [240, 600] |

C07 HP는 주적2280+방해적40×2=2360 합계다. T03 합46은 셜커30+마이트8×2이며 닫힘방어20/열림0을 단일평균으로 합치지 않는다. T04 실제 제압은HP1에서 종료하므로 총3420 사용 산술은1HP 보수차이다. C05/C26 자유합류·시작N 등 원래 각자의 명부규칙은 같지 않다.

## 목표와 실제가 어긋날 때

먼저 실제접근시간/명중률/콤보차수별 피해/10tick차액/다부위 중복/보스 GATE 손실을 분리한다. native 범위가 커져 여러 잡몹을 빨리 잡는 것은 역할 이득이며 자동으로 보스HP를 올릴 이유가 아니다. 반대로 단일머리에 다부위피해가 합쳐져 빨리 잡히면 HP조정이 아니라 중복처리 버그다.

C05는 정상 지상비율0.5와 마지막국면0.5909 때문에 근접 전투체류가 길어진다. 표의가동률은 비행시간을 이미 포함해 해석하거나 지상전용가동률에 stance 비율을 별도로 곱해야 한다. 두 번 차감하지 않는다. C26은 최소3×24초=72초 게이트를 별도로 더하고, 적제압 지연·조작 지연·최종안정보관은 별도다. 키메라는 스킬·방어·위치회피를 갖춘 선택적 장기전이고 단일본체 영구사망을 시험리셋으로 무효화하지 않는다.

스킬/가호/장신구는 각 실제 획득 범위만 사용한다. 합일검5개로5인 화력을 계산하지 않고 합일1+장도비교4로 계산했다. 이 조합 자체를 모든 파티가 적법하게 동시에 획득했다는 보장도 아니다. 실제 파티별 장비·가호 명세로 다시 검산한다.
