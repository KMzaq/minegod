# Simply Swords 기반 별도 무기 매핑 계약

정확 배포물 추가 확인: 같은 폴더의 배포실물_정적확인.json 및 .md가 선정한 5종 모델·텍스처·프로필과 관련 평타 클립의 실제 JAR 정적 대조 근거다. 이 범위에 한해 이전의 JAR 미확인 표기를 보완한다. 기본값·후킹 동작·정확 로더 조합·렌더·실효DPS·멀티플레이는 여전히 미시험이며 수치 전환안은 변경하지 않는다.


## 결정

무기13종을 분류했다. 기존 SS 아이템을 개명하는 것이 아니라, 기존 고유ID·콘셉트·획득권을 가진 우리 별도 아이템을 추가한다. 근접형11종 중 부채1종은 별도 연출 예외이며, 활2종은 근접 모드에 억지 매핑하지 않는다. 곡괭이3종·방어구·장신구·습득기술·스토리 원본6종은 별도 대상이다.

추천은 BC_NATIVE_BASELINE이다. Better Combat 정상 평타·콤보·양손을 활용하고 달라지는 범위·대상수·실효DPS를 전후 비교하여 재밸런스한다. 기존70도/3명/보조4.5 같은 숫자를 맞추려고 BC를 다시 구현하는 것을 기본안으로 삼지 않는다. 기존 판정 완전복제는 LEGACY_GEOMETRY 대안이다.

기존 원고와 수치는 original 스냅샷으로 그대로 보존한다. 새 전환안은 문서상 분리했고, 최종원고 직접변경0·설치0·실행0·5인시험0이다. 기존 총공격·속도·등급·내구는 초기 비교속성이다. 무스킬 여부·신제 무한내구·획득/단일권리·고유ID·입력·마나/가호 중복방지는 바꾸지 않는다.

## 버전 및 원본 효과

- Simply Swords 1.70.2-1.21.1 NeoForge와 Better Combat 2.4.0+1.21.1 NeoForge 배포 표시는 공식 CurseForge에서 확인했다. 실제 JAR·대응commit·NeoForge21.1.248 및5인 시험은 미확인이다.
- 확인한 ID와 모델은 Architectury-1.21 개발브랜치 자료다. 배포1.70.2와 동일하다고 주장하지 않는다.
- plain base에도 implicit 경로가 있어 무효과 상속이라고 가정하지 않는다. 우리 독립 아이템에 검증된 외형/BC 연결만 도입하는 방식이 기본안이다.
- unique appearance와 unique item 클래스/능력은 별개다. 이번에 확인되지 않은 unique 완성품은 단정 매칭하지 않았다. 추후 외형을 택하더라도 passive/on-hit/active/channel/회복/쿨초기화는 자동 이식하지 않는다.
- 원본능력 일괄삭제 설정을 가정하지 않는다. SS 원본 정의를 신규품으로 덮어쓰지 않되, 캠페인 원본 획득/사용은 통합계약에 따라 차단한다. 기존 원본은 자동 파괴하지 않고 격리·원장 확인한다.
- 정확 애니메이션ID·native 범위·양손·타수는 미확정이다. 아래 무기형과 동작은 후보/디자인 요구이며 확인된 클립 이름이 아니다.

## 전환 검증 순서

1. 정확 배포파일과 대응소스를 고정해 후보 registry·모델·부모텍스처·weapon_attributes·실제 클립을 확인한다.
2. 기존 공격력/속도/등급/내구를 초기값으로 별도 우리 아이템을 만들고 native 무기형을 연결한다. 이 작업은 후속 구현계획이며 이번에 실행하지 않았다.
3. 같은 조건에서 기존 대비 native 단일/다중 실효DPS·범위·콤보·양손·공격창을 측정해 차이표를 쓴다. 부족한 동작을 이유로 곧바로 BC 판정을 전면복제하지 않는다.
4. 관우 장병기/짧은망치/철퇴 콘셉트가 native로 살아나는지 비교하고, 필요한 것만 명시 재밸런스/전용동작 예외를 제안한다.
5. 스왑/재접속/원장복구/5인 동시 사용에서 중복피해·마나환급·CC 영구봉쇄·권리복제가 없도록 확인한다.
6. 새 전환안 채택 전에는 기존 원고를 덮지 않고, 미등록 보상의 권리만 보존한다.

## 전환 참조 우선순위 보충

original·획득계약원문·presentation은 현재 원문 출처/비교 스냅샷이다. presentation.relative_file은 매핑 JSON의 위치가 아니라 해당 document의 위치를 기준으로 해석한다. 원문의 평타 기하/타이밍 우선권은 LEGACY_GEOMETRY에서만 적용한다. BC_NATIVE_BASELINE 평타는 새평타전환안과 통합계약이 우선하며 기존 고유 우클릭 연출·피해·마나·쿨·획득권은 계속 원문을 적용한다.

개발프로필 관측은 배포 확정이나 실측이 아니다. SS diamond_longsword는 자체3단1/1/1.4·range_bonus0.1, diamond_greathammer는 heavy_axe 부모 위 자체3단1/1/1.5·range_bonus1·양손이다. 이름만으로 bettercombat:hammer와 동일시하지 않는다. cutlass는 sickle 부모의 단독2단과 쌍수 조건부 추가2단을 구분하고, katana는 양손4단0.8/1.2/1.2/0.8·range_bonus0.1, glaive는 통합계약의 양손3단 후보를 따른다. 각 공식 경로와 개발브랜치 한계는 JSON의 development_profile_observation에서 확인한다. 실제 애니메이션 클립 길이·실효DPS·절대범위는 미측정이다.
