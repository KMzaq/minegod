# 아나히타 — 현행 세계해금·첫 조우
관리키: RPG-S12-003

이번 기획으로 채택 완료. 실제 서버 활성화·구현·플레이 시험은 미실행이다.

## 세계 접근
기존 C01 공통 시작 뒤 초기접근 후보를 유지. 새 세계해금·개인 재해금0. 기존 접근/현재 적격성과 본체 상태만 확인.

## 현재 첫 조우
기존 허용 물가의 안전 마른점 도달+현재 수면 관찰1회. R07-01의 C02/후속 장면은 일반 첫 인사의 선행 아님.

부지는 정확 원문의 차원·선호/대체/바닐라 fallback·구조물 OR 자연부지를 보존한다. 상세 판정·초기화·단일본체 상태는 공통계약을 따른다.

## 보존 경계
현재 마스터의 명부·정체·전투등급·미정 소속·접근 분류를 그대로 보존한다. / 이야기상 옛 죽음·귀환·기적을 현재의 새 사망·부활·능력 효과로 자동 확정하지 않는다. / 자료의 종교·문학 배경을 사용한 게임 창작이다. 현실의 신앙 전체를 대신 설명하거나 평가하는 발화로 쓰지 않는다. / 사소한 행동은 기존 공간·도구로 표현한다. 새 차원·필수 건축·퀘스트·보상·실행 JSON을 요구하지 않는다. / 축복과 가호를 구별하며 소개나 도움을 자동 가호·정치 가입·MAIN 수락으로 바꾸지 않는다. / 실제 Story 서버 시험은 하지 않았다. 조건 지원과 런타임 연결·실행 성공은 다른 상태다. / 현재 접근 원본: 기존 명부가 C01 공통 시작 뒤 공개 생활권의 초기 조우 후보로 제안한 인물. 현행 원칙과 충돌하는 개별 후행 조건을 확인하지 못해 후보안으로 유지한다. 전원 확정 출현이나 새 초기 배정을 뜻하지 않는다. / R07에서 물길 준비·도움 범위·토비아의 현재 귀환 선택을 구별한다. 라파엘을 만나지 못해도 공개 도움 기록과 토비아 본인의 선택으로 지역 결말을 낼 수 있다. 라파엘의 일반 첫 만남을 C06에 고정하지 않고 실제 접근을 따른다. 숭배·수원 양도·상시 동행·모든 병의 치유를 도움의 자동 대가로 만들지 않는다. 제외된 마야·잉카 인물을 현재 배우로 되살리지 않는다. 현재 정체·등급·신격·미정 소속과 봉인·실제 세계/네더/엔드 접근은 결속 원문 그대로다.

해금자·조우주체·MAIN 소유자·보상 수혜자는 서로 다르다. 현재 같은 본체에 친구가 합류할 때 개인 세계해금을 반복하지 않으며 개인 지식은 실제 습득 출처로만 남긴다.
