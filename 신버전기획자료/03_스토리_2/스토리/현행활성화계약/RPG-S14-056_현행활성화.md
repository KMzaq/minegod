# 아가레스 — 현행 세계해금·첫 조우
관리키: RPG-S14-056

이번 기획으로 채택 완료. 실제 서버 활성화·구현·플레이 시험은 미실행이다.

## 세계 접근
기존 C01 뒤 초기접근 보존, 추가 세계해금 이력0.

## 현재 첫 조우
기존 네더 황무지의 안전 경계 공개 방문. 최초 인사에 희귀실물·통역성공·바틴소개0. 실제 통역은 후속 당사자 말/청중이 있는 경우만.

부지는 정확 원문의 차원·선호/대체/바닐라 fallback·구조물 OR 자연부지를 보존한다. 상세 판정·초기화·단일본체 상태는 공통계약을 따른다.

## 보존 경계
역사 access override null은 실행 허가가 아님. 실제 원문 세계해금/현재접근 및 패킷 선후행·배치를 대조. 052/053의 기존 네더 차원·바이옴·대체부지·소유·봉인을 그대로 유지.

해금자·조우주체·MAIN 소유자·보상 수혜자는 서로 다르다. 현재 같은 본체에 친구가 합류할 때 개인 세계해금을 반복하지 않으며 개인 지식은 실제 습득 출처로만 남긴다.
