# 비잔 — 현행 세계해금·첫 조우

## 세계 접근
기존 지하 폐허의 접근 가능한 안전 외곽 A→B→안전 복귀 A 실제 이동1회. 구금·탈출 사건 신규 발생0.

## 현재 첫 조우
현재 승인 부지에 도달 AND 현재 지하 외곽 접근/전달 경로를 대조할 자기 또는 열람허가 받은 실제 기록1개 소지. 허용 실물=minecraft:filled_map 또는 내용 있는 writable_book/written_book 또는 기존 개인팩의 출처확인 기록. 현재 부지·경로/물품을 가리키는 정보1개를 현재 관찰/자기 실제 receipt와 대조해 확인. NPC의 선행 서명/응답·미전달 비밀·다른 사람 해금이력 복사는 불가. 초기 대조는 플레이어의 실물/현장 확인이며 NPC와 하는 후속 대조·수락은 별도. 기록 소비/납부0.

부지는 정확 원문의 차원·선호/대체/바닐라 fallback·구조물 OR 자연부지를 보존한다. 상세 판정·초기화·단일본체 상태는 공통계약을 따른다.

## 보존 경계
현재 마스터의 명부·정체·전투등급·미정 소속·접근 분류를 그대로 보존한다. / 이야기상 옛 죽음·귀환·기적을 현재의 새 사망·부활·능력 효과로 자동 확정하지 않는다. / 자료의 종교·문학 배경을 사용한 게임 창작이다. 현실의 신앙 전체를 대신 설명하거나 평가하는 발화로 쓰지 않는다. / 사소한 행동은 기존 공간·도구로 표현한다. 새 차원·필수 건축·퀘스트·보상·실행 JSON을 요구하지 않는다. / 축복과 가호를 구별하며 소개나 도움을 자동 가호·정치 가입·MAIN 수락으로 바꾸지 않는다. / 실제 Story 서버 시험은 하지 않았다. 조건 지원과 런타임 연결·실행 성공은 다른 상태다. / 현재 접근 원본: 현행 자료에서 개별 최초 일반 조우 시점을 확정할 근거가 부족하다. 옛 단계 템플릿만으로 전/후를 강제하지 않는다. / 자기 과거 회상 경계: 마니제와 사랑하고 구덩이에 갇힌 원전의 자기 경험을 기억한다. 그것을 현재 위치 고정이나 현재 탈출 완료로 바꾸지 않는다. 제외된 마야·잉카 인물을 현재 배우로 되살리지 않는다. 현재 정체·등급·신격·미정 소속과 봉인·실제 세계/네더/엔드 접근은 결속 원문 그대로다.

해금자·조우주체·MAIN 소유자·보상 수혜자는 서로 다르다. 현재 같은 본체에 친구가 합류할 때 개인 세계해금을 반복하지 않으며 개인 지식은 실제 습득 출처로만 남긴다.
