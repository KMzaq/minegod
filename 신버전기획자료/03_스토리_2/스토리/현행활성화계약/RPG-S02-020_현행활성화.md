# 스키르니르 · RPG-S02-020

현재 채택 기획. 구현·서버 시험은 미실행이다.

## 세계 가용성
(기존 전달의 실제 출발→목적지 접근→귀환1회와 실제 인계/미인계 결과 기록) OR (기존 원정의 회수 목표 중 허용 실물1개 이상을 휴대해 출발 생활권으로 귀환1회). 실제 거절·미인계 귀환도 첫 갈래로 인정하며 전달 완료를 허위 기록하지 않는다.

신규 세계 false → 실제 한 사람의 위 완결 묶음1회 → 세계 영구 true. 기존 유효 접근은 소급 잠금하지 않는다.

## 최초 조우
minecraft:overworld의 기존 북방 감시탑의 쉬는 자리에서 전달할 긴 말을 줄이는 자리. 기존 배치 범위: 실제 생성 북방 폐허·감시탑의 안전한 공간. 희귀 shrine_tower는 발견 시에만 추가 선택지에 현재 직접 도달하고, 원문 지리·현재 통행권·안전한 접근/귀환로가 유효한 실제 온라인 생존 플레이어. 첫 후보에 새 소지품·제작/납품·개인 과거 수행·SIDE 수락·NPC 선행 응답은 요구하지 않는다.

exact 최초접촉의 현재 도달·접근 조건을 채택한다. 장면의 작업 소품과 선택 작업을 일반 인사의 필수로 올리지 않는다.

## 운영과 권리
기존 최초 장소와 선택 작업의 수행 장소를 분리한다. 본체 미배치/미로드/봉인/사망은 서로 다르며 해금으로 부활·분신을 만들지 않는다. 현재 조건을 맞춘 실제 한 사람이 주체이며 해금자·MAIN 소유자·보상 수령자와 같을 필요가 없다. 이미 나온 같은 본체에 친구가 인사할 때 다시 추첨하거나 개인 재해금하지 않는다. NPC 지식은 실제 관측·허용된 전달과 수신에만 의존한다.
