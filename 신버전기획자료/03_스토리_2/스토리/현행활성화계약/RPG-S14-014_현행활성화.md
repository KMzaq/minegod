# 기드온 · 현행 세계해금과 최초조우

관리키: RPG-S14-014

## 이번 채택
원문 미채택 후보를 현재 일반설계로 선택·수량화했다. 원문 status/null/후보 문자열은 수정하지 않으며 과거부터 채택됐다고 소급하지 않는다.

## 세계해금
기존 공동 탐험/개방 레이드에서 실제 공동참가자2명 이상이 있는 같은 attempt 중, 본인이 적법 회수물1개를 직접 인수해 기존 안전점으로 운반·귀환1회 OR 본인이 실제 후위 지점에서 적대 공격 방패차단1회 후 동료1명의 실제 앞쪽 안전점 통과를 확인하고 본인도 그 안전점 귀환1회. 역할선택 OR이며 가상동료·추격자 생성0.

새 세계 WORLD_RELEASE=false. 아래 실제 유효 달성 전에는 계약 작성·후보 등록만으로 true가 되지 않는다. 이미 유효하게 배치/접촉된 기존 본체와 그 세계 원장은 재잠금하지 않는다.
FALSE → 같은 플레이어의 실제 완료 증거 검증 → world_uuid+record_key 최초 CAS → TRUE 영구. 해금 달성자의 개인 소유/관계/보상/수신을 자동 생성하지 않는다.

증거: 실제 source event ID, world/player UUID, 행동별 object/item/route UUID, 순서있는 실제 위치 및 인수/소비 전후를 같은 시도로 결속. 각 행동의 정수량은 rule을 따른다. 이미 있는 동일 receipt는 증거로 참조할 수 있으나 횟수 누적·물품/권리/보상 재생성0. 다른 인물의 조건에도 사실상 맞는 사건이면 인물별 세계 판정에 참조 가능하며 같은 사건을 새 행동으로 복제하지 않는다.

## 최초조우
차원: minecraft:overworld

플레이어가 실제 생활권의 안전한 공용 마당이나 기존 훈련 빈터에 현재 접근 가능함. 훈련·회수에 쓸 횃불·물품은 해당 행동을 선택할 때 확인하며 모집 수락·삼손 면담을 일반 등장 전제로 삼지 않는다.

실제 부지 범위: 실제 생성 주점의 공용 방·마당, 발견된 저택의 안전한 공용 공간; 인물 전용 건축 없음

현재 공개 부지의 안전점에 생존·온라인 상태로 실제 도달. 별도 아이템·기록·행동·수락·과거 개인 이력 조건0.

별도 시간제한 없음. 실제 현재 부지의 출입·위험·세계/봉인 가용성은 항상 검사. 세계해금 행동의 시간조건은 그 행동에만 적용하고 첫조우에 이식하지 않는다.

기존 무작위 공용 풀. 확률/주기/NONE/actor가중/적격주체선정/쿨다운/CAS는 공통계약 pool 및 전역 참조를 그대로 사용. 이 파일은 전용 수치·새 풀·추가 추첨을 만들지 않는다.
현재 세계 가용성과 위 개인 조건을 갖춘 실제 온라인 생존 플레이어1명. 해금자일 필요 없고 0명이면 발생0. 여러 명은 기존 전역 선택계약.

## 이미 만난 뒤
이미 등장한 동일 본체의 일반 인사·재대화·친구 합류에는 위 최초 후보 준비물·관찰/이동 과제·새 추첨을 다시 요구하지 않는다. 현재 접근·청중·허용 접촉모드만 확인하며 실제 서비스/거래/수락은 기존 활동의 별도 조건을 따른다.

정체·현재 접근·발화/비언어·MAIN/보상 범위는 source_refs의 현재 페르소나와 기존 개별기획 그대로. 후속 활동 소품·소개자·장면 수행/응답은 최초 배치 전제로 끌어올리지 않는다. 원문 옛 사망·기적은 지금의 부활·새 본체를 허가하지 않는다.

세계 해금 receipt는 세계 가용성을 위한 기술 원장일 뿐 NPC의 자동 지식·개인 관계·공적 인정이 아니다. 누가 했는지는 실제 목격 또는 허락된 전달과 해당 청중의 실제 수신이 있을 때만 안다. 해금자=조우주체라고 대사에서 추정하지 않는다.

공통 상태·증거·단일본체·개인권리: 00_현행활성화_공통계약.json의 initialization, site_and_observation, body_state_machine, personal_separation을 그대로 참조한다. 본문에서 운영값을 새로 정하지 않는다.
