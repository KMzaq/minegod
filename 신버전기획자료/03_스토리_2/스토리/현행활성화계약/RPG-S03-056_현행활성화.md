# 우바오네르 · RPG-S03-056

현재 채택 기획. 구현·서버 시험은 미실행이다.

## 세계 가용성
(기존 구리 블록1개 직접 제작·배치→벌집 조각으로 동일 블록 밀랍칠→도끼로 동일 블록 밀랍 제거1회) OR (이미 지원되는 기존 조리법의 비활성 모형1개 직접 제작→다른 작업점 운반→원래 보관점 반환1회). 후자 조리법이 없으면 그 갈래는 사용하지 않고 전자 바닐라 경로로 완료 가능.

신규 세계 false → 실제 한 사람의 위 완결 묶음1회 → 세계 영구 true. 기존 유효 접근은 소급 잠금하지 않는다.

## 최초 조우
minecraft:overworld의 주점 공용 자리에서 손의 온도로 변하는 밀랍 모형을 살피는 자리. 기존 배치 범위: 실제 생성 주점의 공용 방·마당, 발견된 저택의 안전한 공용 공간에 현재 직접 도달하고, 원문 지리·현재 통행권·안전한 접근/귀환로가 유효한 실제 온라인 생존 플레이어. 첫 후보에 새 소지품·제작/납품·개인 과거 수행·SIDE 수락·NPC 선행 응답은 요구하지 않는다.

exact 최초접촉의 현재 도달·접근 조건을 채택한다. 장면의 작업 소품과 선택 작업을 일반 인사의 필수로 올리지 않는다.

## 운영과 권리
기존 최초 장소와 선택 작업의 수행 장소를 분리한다. 본체 미배치/미로드/봉인/사망은 서로 다르며 해금으로 부활·분신을 만들지 않는다. 현재 조건을 맞춘 실제 한 사람이 주체이며 해금자·MAIN 소유자·보상 수령자와 같을 필요가 없다. 이미 나온 같은 본체에 친구가 인사할 때 다시 추첨하거나 개인 재해금하지 않는다. NPC 지식은 실제 관측·허용된 전달과 수신에만 의존한다.
