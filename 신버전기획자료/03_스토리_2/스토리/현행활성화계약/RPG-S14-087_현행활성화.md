# 포칼로르 — 현행 세계해금·첫 조우
관리키: RPG-S14-087

이번 기획으로 채택 완료. 실제 서버 활성화·구현·플레이 시험은 미실행이다.

## 세계 접근
물이 실제 있는 기존 세계(Overworld)의 출발 해안 A→서로 다른 수상 B→A 보트 이동 왕복1회. 플레이어 실제 탑승·보트 entity·이동/귀환 receipt. 네더 물/바다 생성0; 최초 조우는 네더 원문 현무암 경계 유지.

## 현재 첫 조우
현재 승인 네더 안전 부지 AND 그 부지의 실제 공개 통행·위험 규칙 내용을 현재 visit에서 열람 확인1회. 기존 공개 경계·귀환로/안전규칙 정보만, 신규 게시판 건설/서약/계약0. 공개 규칙 내용이 없는 부지는 등록시 실제 안전검사로 마련한 해당 부지 공용 안내를 제시하는 새 구현요구, NPC의 비공개 지식 자동공개0.

부지는 정확 원문의 차원·선호/대체/바닐라 fallback·구조물 OR 자연부지를 보존한다. 상세 판정·초기화·단일본체 상태는 공통계약을 따른다.

## 보존 경계
역사 access override null은 실행 허가가 아님. 실제 원문 세계해금/현재접근 및 패킷 선후행·배치를 대조. 052/053의 기존 네더 차원·바이옴·대체부지·소유·봉인을 그대로 유지.

해금자·조우주체·MAIN 소유자·보상 수혜자는 서로 다르다. 현재 같은 본체에 친구가 합류할 때 개인 세계해금을 반복하지 않으며 개인 지식은 실제 습득 출처로만 남긴다.
