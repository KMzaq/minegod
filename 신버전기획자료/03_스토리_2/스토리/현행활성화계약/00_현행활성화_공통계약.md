# 세계해금·첫 조우 현행 활성화 계약

48명 관련범위의 현재 기획을 채택한다. 원문 보존 사본의 미채택 표시는 역사이며 이 별도 계약의 효력과 구분한다. 실제 구현·서버 적용·게임 시험은 아직 하지 않았다.

## 채택 범위
- {'direct_contact_A_adopted': 1, 'existing_restricted_contact': 1, 'initial_access_preserved': 9, 'world_unlock_adopted': 37}
- 감사24명 중20명 및 바바 야가1명, 052/053 추가16명은 세계해금 조건 채택.
- 기존 초기접근9명과 아스모데우스의 기존 무해금 제한접견은 소급 잠금 없이 유지.
- 나네페르카프타는 무덤의 동일 존재와 기존 묘실 직접접촉 A안. 생사·영혼·유령·부활·현신 설정을 새로 결정하지 않는다.

## 적용 순서
1. 현행 사용자 확정 정체·생사·봉인·관계·권리 및 기존 명시 전후시점
2. 이 문서의 record_key별 adopted_activation: 역사 후보의 채택 효력과 명시 레이블 보강만
3. 기존 개인팩의 수주·목표·완료·보상과 전용 조우운영값
4. 현행 전역 조우/원장 정책
5. 원문 역사·미채택 사본: 보존 증거이며 현재 활성화값으로 실행하지 않음

## 초기화와 세계영구해금
- new_world: 신규 해금 채택 대상 WORLD_RELEASE는 false로 시작. 계약 작성은 실제 달성·출현이 아니다. 초기접근 대상은 기존 C01/개별 접근 참조로 가용하며 새 이력 플래그를 요구하지 않는다.
- existing_world: 이미 유효한 세계해금/접촉·본체·권리 원장은 보존. 이관 전에 실제 원장과 본체를 대조. 검증된 과거 실제 달성 receipt가 조건과 일치하면 동일 최초해금으로 이관; 단순 소지·대사·원문 예시로 과거 수행을 만들지 않는다. 기존 유효 만남은 이 신규 조건으로 소급 재잠금하지 않는다.
- history_scope: 같은 world_uuid, 실제 player_uuid 한 명의 증거. 여러 사람 부분이력 합산0. 무기한 유효, 하루/주간 초기화0. 시간 조건은 지정 행동의 event 시각만. 로그아웃/서버 재시작으로 유효 완료이력 소멸0; 미완 이동은 저장된 마지막 실제 위치에서 계속하며 오프라인 이동 가산0. 사망/순간이동으로 끊긴 미완 왕복 구간은 마지막 안전 출발점에서 새 실제 왕복으로 시도, 이미 완료한 세계해금은 유지.
- release_commit: 조건 전부 충족한 실제 event를 world_uuid+record_key CAS로 최초1회 영구 저장. event_id 중복은 동일 결과만. 해금자는 기여자일 뿐 조우/MAIN/보상 소유자 아님.

## 현장과 관찰
- registration: 원문 허용 차원·기존 실제 지형/공간만 조사하여 site_uuid와 출발 A/목적 B/귀환점 및 필요한 우회 앵커를 등록. 서로 다른 현장 역할은 겹치지 않는 반경2블록 앵커로 선택, 이를 만들기 위한 건축·희귀지형·새 차원0. 거리 노가다 임계치0. 실제 연결통로·소유허가·세계/봉인 가용·몸체 충돌과 퇴로 확인; 안전 실패이면 그 부지 보류 후 원문 대체부지 조사.
- route_receipt: 연속한 서버 위치 이동과 world/dimension/player/route/visit UUID, 순서있는 anchor-enter receipt. A→B→A 한 완결1회. 도보 또는 해당 항목에서 허용한 보트/기존 포탈. 포탈 경계만 오가기·명령 이동·리스폰은 실제 경로 통과 대체0. 과도한 최소거리·완주 제한시간0.
- current_visit: 현재 생존·온라인·실제 해당 부지에 있는 적격자. 청크/출입권/통로·위험을 현재 검사. 과거 답사 세계해금은 현재 안전·접견을 대신하지 않음. current visit 이탈시 관찰 자격 종료; 돌아오면 현재 장면만 재확인, 세계이력 반복0.
- observation: 관찰 필요 항목은 해당 안전점 도달과 현재 visit에서 지형/수면/귀환로 표적1회 실제 바라보기 또는 관찰 상호작용. 표적까지 시야 가림 없음·16블록 이내, 멀면 안전한 가까운 원래 관측점 이용. 화면 확인 event만이며 NPC 응답/암기 정답/손2블록 검사 없음. 일반 공개 방문 항목에 관찰 과제 자동 추가0.
- fallback: 원문 구조물 OR 자연부지·대체바이옴을 그대로 유지; 선호바이옴 AND 희귀구조물로 축소0. 한국영웅3명만 이번 명시 Overworld 기존 자연부지 채택. 실제 좌표·registry·자산 연결은 구현 요구이며 존재를 검증했다고 주장하지 않음.

## 동일 본체 상태
- NEVER_PLACED: canonical actor가 아직 엔티티로 최초 배치되지 않았다는 명시 원장 상태. 허용 존재/접근모드·부지·현재 적격주체와 예약을 검사한 뒤 같은 actor 최초 배치 가능. 현장 선재·이전 NPC 응답을 요구하지 않는다.
- PRESENT: 동일 body_instance 방문. 새 추첨·본체복제0. 선정주체 아닌 친구도 현재 접근/청중/의사 범위에서 자유합류.
- UNLOADED_OR_MISSING: 이미 body_instance가 있거나 출현결과 불확실하면 journal/entity 대조 및 동일 인스턴스 복원만. 미로드를 NEVER_PLACED로 바꾸지 않는다. 확인 전 새 발화/인계0.
- DEAD_SEALED_ABSENT_BUSY: 실제 기존 사망·봉인·현장 부재·다른 활동은 그대로. 새 본체/부활/분신/원격응답0. 허용된 현재 접촉 모드만. 해금 영구이력은 취소하지 않음.
- contact: 실제 같은 본체와 감각/거리/청중 확인. 발화 의사는 답변·허가에 적용; 유효한 비언어 반응까지 발화 의사로 차단0. 사적 수락/허가/거래는 실제 본인 응답 필요.

## 공통 조우/개인 분리
확정 전용 확률/주기가 있으면 전용 경로만. 나머지 기존 무작위 경로는 general_encounter의 활동300초/서버창25%/출현후1800초, actor별 가중 후 현재 적격 실제 player 1명, NONE·단한번추첨·CAS·재시작 원장을 재사용. 배치형/기록/꿈을 일반풀로 바꾸지 않음.
MAIN 첫 유효 명시수락·소유, 보상권/실수령, 개인 관계·비공개 지식은 모두 별도 원장. 친구 합류로 복사0. 해금 기록은 NPC 지식이 아니며 실제 목격/허용전언/실물열람 출처를 보존.
