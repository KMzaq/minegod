# 푸르손 — 현행 세계해금·첫 조우
관리키: RPG-S14-072

이번 기획으로 채택 완료. 실제 서버 활성화·구현·플레이 시험은 미실행이다.

## 세계 접근
기존 탐험장소에서 적법 획득한 실제 물품1개를 안전 보관점에 운반·보관1회. 아이템 종류 제한0, original item UUID/발견 site UUID/획득·인계·보관 이력 결속. 출처가 필요한 물품은 종류만 같은 대체품 불가.

## 현재 첫 조우
현재 승인 부지에 도달 AND 현재 탐험 물품의 확인 가능한 출처를 대조할 자기 또는 열람허가 받은 실제 기록1개 소지. 허용 실물=minecraft:filled_map 또는 내용 있는 writable_book/written_book 또는 기존 개인팩의 출처확인 기록. 현재 부지·경로/물품을 가리키는 정보1개를 현재 관찰/자기 실제 receipt와 대조해 확인. NPC의 선행 서명/응답·미전달 비밀·다른 사람 해금이력 복사는 불가. 초기 대조는 플레이어의 실물/현장 확인이며 NPC와 하는 후속 대조·수락은 별도. 기록 소비/납부0.

부지는 정확 원문의 차원·선호/대체/바닐라 fallback·구조물 OR 자연부지를 보존한다. 상세 판정·초기화·단일본체 상태는 공통계약을 따른다.

## 보존 경계
역사 access override null은 실행 허가가 아님. 실제 원문 세계해금/현재접근 및 패킷 선후행·배치를 대조. 052/053의 기존 네더 차원·바이옴·대체부지·소유·봉인을 그대로 유지.

해금자·조우주체·MAIN 소유자·보상 수혜자는 서로 다르다. 현재 같은 본체에 친구가 합류할 때 개인 세계해금을 반복하지 않으며 개인 지식은 실제 습득 출처로만 남긴다.
