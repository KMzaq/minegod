# 타흐미네 — 현행 세계해금·첫 조우
관리키: RPG-S12-014

이번 기획으로 채택 완료. 실제 서버 활성화·구현·플레이 시험은 미실행이다.

## 세계 접근
기존 공개 생활권 운반 경로 출발 A→인도점/경로확인 B→A 실제 왕복1회. 새 물품납부·혈통표식·NPC 선행응답 없음.

## 현재 첫 조우
현재 방문 경로의 공개 출입점에서 접촉 예정 안전점까지 실제 이동해 도달. 세계해금 왕복의 반복 요구0, NPC의 선행 확인0.

부지는 정확 원문의 차원·선호/대체/바닐라 fallback·구조물 OR 자연부지를 보존한다. 상세 판정·초기화·단일본체 상태는 공통계약을 따른다.

## 보존 경계
현재 마스터의 명부·정체·전투등급·미정 소속·접근 분류를 그대로 보존한다. / 이야기상 옛 죽음·귀환·기적을 현재의 새 사망·부활·능력 효과로 자동 확정하지 않는다. / 자료의 종교·문학 배경을 사용한 게임 창작이다. 현실의 신앙 전체를 대신 설명하거나 평가하는 발화로 쓰지 않는다. / 사소한 행동은 기존 공간·도구로 표현한다. 새 차원·필수 건축·퀘스트·보상·실행 JSON을 요구하지 않는다. / 축복과 가호를 구별하며 소개나 도움을 자동 가호·정치 가입·MAIN 수락으로 바꾸지 않는다. / 실제 Story 서버 시험은 하지 않았다. 조건 지원과 런타임 연결·실행 성공은 다른 상태다. / 현재 접근 원본: 현행 자료에서 개별 최초 일반 조우 시점을 확정할 근거가 부족하다. 옛 단계 템플릿만으로 전/후를 강제하지 않는다. / 자기 과거 회상 경계: 소흐랍의 어머니라는 자기 관계를 기억한다. 루스탐에게 보낸 현재 증거의 도착 여부는 아직 모른다. 제외된 마야·잉카 인물을 현재 배우로 되살리지 않는다. 현재 정체·등급·신격·미정 소속과 봉인·실제 세계/네더/엔드 접근은 결속 원문 그대로다.

해금자·조우주체·MAIN 소유자·보상 수혜자는 서로 다르다. 현재 같은 본체에 친구가 합류할 때 개인 세계해금을 반복하지 않으며 개인 지식은 실제 습득 출처로만 남긴다.
