# 스톨라스 — 현행 세계해금·첫 조우
관리키: RPG-S14-084

이번 기획으로 채택 완료. 실제 서버 활성화·구현·플레이 시험은 미실행이다.

## 세계 접근
같은 플레이어가 Overworld 기존 전망점에서 서로 다른 서버 관찰 event 시점2회 실제 관찰하고 그 내용을 기록한 자기 writable_book 1개 또는 동등한 기존 관측기록1개를 네더로 실제 반입. 최소 대기시간0, 동일 event 재전송은 두번째 관찰 아님. 시각·위치·관찰 방향/실제 본 하늘 또는 지형 차이 기록; 별자리 정답0. 기록UUID/두 관찰 event/네더 인벤토리 인입 receipt 결속.

## 현재 첫 조우
현재 승인 네더 전망점 도달+주변 실제 네더 지형 관찰1회. 네더에서 별보기/Overworld 관찰기록 재반입0.

부지는 정확 원문의 차원·선호/대체/바닐라 fallback·구조물 OR 자연부지를 보존한다. 상세 판정·초기화·단일본체 상태는 공통계약을 따른다.

## 보존 경계
역사 access override null은 실행 허가가 아님. 실제 원문 세계해금/현재접근 및 패킷 선후행·배치를 대조. 052/053의 기존 네더 차원·바이옴·대체부지·소유·봉인을 그대로 유지.

해금자·조우주체·MAIN 소유자·보상 수혜자는 서로 다르다. 현재 같은 본체에 친구가 합류할 때 개인 세계해금을 반복하지 않으며 개인 지식은 실제 습득 출처로만 남긴다.
