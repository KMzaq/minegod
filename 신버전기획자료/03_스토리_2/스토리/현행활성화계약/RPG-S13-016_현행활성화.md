# 헨리 아미티지 — 현행 세계해금·첫 조우
관리키: RPG-S13-016

이번 기획으로 채택 완료. 실제 서버 활성화·구현·플레이 시험은 미실행이다.

## 세계 접근
허가된 기존 폐허의 회수 가능한 기록물1개(minecraft:written_book, writable_book, filled_map 중 실제 기록내용/출처가 있는 것)를 적법 인수하여 안전 생활권 기존 보관점에 실제 보관1회. 같은 물품 UUID/획득 출처/운반/보관 receipt 필요. 빈 책·임의 명칭변경·훔친책 불가; 새 금서/저자 대면0.

## 현재 첫 조우
정확 원문 encounter의 허용 지형·공간에 현재 실제 도달. 현재 통행권·안전·배치공간·귀환로를 확인한 공개 방문. 별도 소지품·과거 개인행동·선행 NPC응답·수주 조건 없음.

부지는 정확 원문의 차원·선호/대체/바닐라 fallback·구조물 OR 자연부지를 보존한다. 상세 판정·초기화·단일본체 상태는 공통계약을 따른다.

## 보존 경계
현행 자료에서 개별 최초 일반 조우 시점을 확정할 근거가 부족하다. 옛 단계 템플릿만으로 전/후를 강제하지 않는다. / 현재 행동은 성격 저술의 진행 방향이다. 여기 적었다고 새 공격·계약·피해·승전·탈출을 이미 실행한 세계 사실이 되지 않는다. / 실제 접근·본인 의사·현재 봉인을 먼저 적용한다. 자유대화 제작과 현재 본체 출현·최초 조우의 허용을 구별한다. / 코어는 Story 등록 JSON이나 퀘스트 수주 gate 구현물이 아니다. 조건부 공개·canonical 전달도 실제 청중·입수 경위가 있어야 하며 미연결 gate·개인 상태 일괄 동기화를 지원한다고 가정하지 않는다. / 기존 세계·네더·엔드 안에서 쓴다. 새 건축·새 차원·전투 수치·필수 개인 퀘스트를 생성하지 않는다. / 윌버·기타 현재 명부 밖 원전 인물의 새 현장 참여·생존·계산을 전제하지 않는다. 과거 작품의 사건을 새 게임 사건으로 완료 처리하지 않는다. 신규 문장은 현행 effective_rule 범위에서만 사용하며 제한 접촉을 유창한 새 아바타·전지적 해설로 확대하지 않는다. 예수·하나님 및 명부 밖 인물의 현재 출연 없음.

해금자·조우주체·MAIN 소유자·보상 수혜자는 서로 다르다. 현재 같은 본체에 친구가 합류할 때 개인 세계해금을 반복하지 않으며 개인 지식은 실제 습득 출처로만 남긴다.
