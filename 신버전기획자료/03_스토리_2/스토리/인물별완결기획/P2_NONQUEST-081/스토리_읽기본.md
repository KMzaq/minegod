# P2_NONQUEST-081 · 스토리

현재 채택 저술 기획. 실제 게임·API·LLM·영상·5인 서버 시험은 하지 않았다. 새 SIDE·개인 MAIN·성장 보상은 만들지 않는다.

공통 조우는 300 활동초 창의 서버 25% 추첨, 인물별 실제 출현 후 1800 가동초 쿨을 재사용한다. 전역 해금·현재 주체·단일 본체·개인 기억은 별개다. 이미 배치된 본체 인사에는 재추첨하지 않는다.

## 시야바쉬 · RPG-S12-018

사막길 바람이 통하는 쉼자리에서 자기 천이 마르는 것을 살핀다. 그늘을 묻는 방문자에게 쉬어도 될 현재 범위만 알려 주고 결백을 설명할 의무를 부과하지 않는다.

장소: 최초 조우는 사막 생활권의 바람이 통하는 기존 쉼자리다. 한정 휴전은 당사자가 실제 고른 통행 구간에서만 관측하며 이 쉼자리 인사로 이동 완료하지 않는다.
세계 해금: 누구 한 명이 사막 생활권에서 위험을 피할 기존 왕복 통행로를 실제 발견하고 돌아오면 전역 해금한다. 자기 몸을 해치는 시험은 조건0.
현재 조우 주체: 현재 사막길의 안전한 바람 통하는 쉼자리에 도달해 공개 복귀길을 확인하는 사람. 결백·가문·파랑기스의 사적 동의는 일반 인사 선행이 아니다.

### 기존 장면의 실제 진행

**EP030B-RPG-S12-018 · 상처 없는 휴전**

- B1: 현재 범위에 대응하는 실제 경로를 고른다.
다음은 선택 경로별 실제 행동이며 서로 모두 수행할 조건이 아니다:
통행 중 멈출 공격을 정한다: 현재 파랑기스와 실제 접촉하고 쉬어 갈 구간을 함께 고른다. 플레이어는 이번 통행에서 무기를 들이대거나 추격하지 않을 범위를 자기 말로 제안한다. 시야바쉬는 결백 시험을 논점에서 빼고 안전자리에서 상대의 응답을 기다린다.
  실제 변화: 통행 중 멈출 공격을 정한다: 실제 구간·제안 범위만 정해진다. 상대 동의·휴전·통행 완료는 아직 없다.

- B2: 현재 범위에 대응하는 실제 경로를 고른다.
다음은 선택 경로별 실제 행동이며 서로 모두 수행할 조건이 아니다:
합의한 구간을 함께 지난다: 상대가 실제 응답한 공격 중지 범위와 파랑기스·시야바쉬·이동 참가자의 현재 동의를 확인한다. 해당 구간만 함께 걸으며 서로 공격하지 않고 쉼점에 도착한다. 미응답·위험 재발에는 이동 성과를 만들지 않고 안전하게 중단한다.
조건이 맞지 않아 안전자리로 돌아간다: 상대의 미응답 또는 맞지 않는 조건을 확인하고 안전한 귀환길로 실제 돌아온다. 처음부터 안전자리에 있었다면 거기 머물며 이동을 시작하지 않는다.
결백을 위한 고통 시험을 요구한다: 플레이어가 현재 실제로 고통 시험을 교섭 조건으로 요구하면 시야바쉬가 그 조건을 거절하고 교섭을 중단한다. 몸을 다치는 사건을 연출하거나 요구만으로 부상을 생성하지 않는다.
  실제 변화: 합의한 구간을 함께 지난다: 실제로 공격을 멈추고 통과한 한 구간만 성과. 세계 전쟁 종식·모든 의심 해소 없음.
조건이 맞지 않아 안전자리로 돌아간다: 실제 복귀 또는 안전자리 체류만. 휴전 성립·통행 완료 없음.
결백을 위한 고통 시험을 요구한다: 교섭 중단만. 결백 증명·휴전 보상 없음.

- B3: 선택 경로의 실제 결과와 미완료를 구분하고 실제 허락된 현재 청중에게만 확인한다. 휴전은 해당 당사자·구간·현재 이동에만 적용한다. 물품·권능·결백 인증 보상 없음. 파랑기스와 상대의 동의를 대신하지 않는다.
  실제 변화: 실제 선택·실행한 경로의 결과만 확인한다. 아래 서로 다른 결과를 동시에 부여하지 않는다.
합의한 구간을 함께 지난다: 실제로 공격을 멈추고 통과한 한 구간만 성과. 세계 전쟁 종식·모든 의심 해소 없음.
조건이 맞지 않아 안전자리로 돌아간다: 실제 복귀 또는 안전자리 체류만. 휴전 성립·통행 완료 없음.
결백을 위한 고통 시험을 요구한다: 교섭 중단만. 결백 증명·휴전 보상 없음. 실제 수령·수강 또는 그 거절은 별도로 남는다.

현행 완료 보강: 통행=(파랑기스 현재 참여 AND 시야바쉬·실제 참가자 동의 AND 상대의 해당 공격중지 응답 AND 한 구간 실제 이동 AND 그 구간 공격중지 준수 AND 쉼점 도착). OR 불성립 종료=(미응답/조건불일치 확인 AND (이미 안전자리 체류 OR 실제 안전 복귀)). 고통 시험 요구는 실제 들은 요구 거절·교섭 중단만이며 부상 생성0.

선택 일상:
- 마르는 천: 사막 쉼터의 바람길에서 시야바쉬가 자기 천을 말린다. 플레이어는 그늘을 같이 쓸 수 있는지 묻는다. 잠깐 쉬거나 대화 없이 떠난다. 무고함을 설명하지 않아도 일상 만남이 끝난다.
- 쉴 수 있는 통행: 파랑기스가 실제 고른 길의 쉼 구간을 확인하고 플레이어는 자기 장비로 마른 발판을 왕복한다. 위험하면 다른 구간을 택하거나 돌아온다. 안전 복귀만 확인된 경우 휴전 성공으로 부풀리지 않는다.
- 멈출 행동 하나: 현재 갈등 당사자가 실제 응답할 때 이번 통행 중 멈출 공격·추격 범위만 말한다. 결백을 증명하라는 요구 대신 한정 행동을 합의하거나 거절한다. 실제 이동과 중단이 함께 확인된 구간만 휴전 결과로 남는다.
- 상처 없는 재회: 이전 통행에서 중단 약속을 지킨 상대에게 시야바쉬는 긴 방어 설명 대신 먼저 쉼자리를 권한다. 다음 길은 별도 의사를 묻고 오늘 쉬는 것으로 끝낼 수 있다. 신뢰와 평온이 늘어도 전쟁 종식·의심 전부 해소는 아니다.

## 아프라시야브 · RPG-S12-020

아프라시야브는 자기 끈의 매듭을 당겨 본다. 방문자가 다른 매듭을 보이면 잠깐 살피지만 그 작은 관심이 가족 화해나 사적 속마음 공개는 아니다.

장소: 최초 조우는 공용 면담 공간의 출입이 보이는 가장자리다. 왕래는 왕이 현재 권한을 가진 문턱과 합의 복귀점 사이에서만 이루어지며 저택 전체를 영역으로 부여하지 않는다.
세계 해금: 누구 한 명이 공개 생활권의 실제 허용 출입로를 탐험하면 전역 해금한다. 충성 선언·굴복은 조건이 아니다.
현재 조우 주체: 현재 공개 면담 가장자리에 안전하게 도달해 출입로를 관찰하는 사람. 두 요구를 미리 얻거나 왕의 호의를 살 필요는 없다.

### 기존 장면의 실제 진행

**EP030B-RPG-S12-020 · 열어 둔 문턱**

- B1: 현재 범위에 대응하는 실제 경로를 고른다.
다음은 선택 경로별 실제 행동이며 서로 모두 수행할 조건이 아니다:
두 이동 요구를 각각 전달한다: 각 당사자가 이번 중개를 허락한 문장과 수신자를 확인하고 마니제의 요구와 파랑기스의 요구를 각각 전달한다. 한 요구만 실제 왔다면 그 요구만 접수하고 다른 사람의 항목은 미수신으로 남긴다. 아프라시야브는 출입이 보이는 가장자리에서 지금 통제 가능한 문턱을 지목한다.
  실제 변화: 두 이동 요구를 각각 전달한다: 실제 전달된 각 요구와 현재 통제 범위만. 둘의 충성 서약·동의·이동 없음.

- B2: 현재 범위에 대응하는 실제 경로를 고른다.
다음은 선택 경로별 실제 행동이며 서로 모두 수행할 조건이 아니다:
한정 허용과 당사자 동의 뒤 왕래한다: 아프라시야브가 실제 자기 권한 안의 가까운 한 번 왕래를 허용한 당사자에게만 조건을 전달한다. 그 당사자가 실제 동의하고 해당 길을 움직여 돌아온 범위를 확인한다. 다른 사람의 미수신 요구나 거절을 같은 허용으로 덮지 않는다.
문턱을 닫는 답을 각각 전달한다: 아프라시야브가 실제 권한 안에서 해당 왕래를 거절하면 그 답만 당사자의 허락된 수신 경로로 전달한다. 실제 수신 전에는 당사자가 거절을 알거나 다음 결정을 내린 것으로 쓰지 않는다.
요구를 하나의 충성 서약으로 바꾼다: 실제 별개 요구를 충성 서약으로 바꾸어 중개한 경우 당사자가 그 변조를 실제 알고 중개를 철회한 범위를 기록한다. 부재하거나 모르는 당사자의 즉시 철회 발언은 생성하지 않는다.
  실제 변화: 한정 허용과 당사자 동의 뒤 왕래한다: 동의하여 실제 움직인 당사자의 한 번 왕래만. 온순해짐·가족 화해·영구 통행권 없음.
문턱을 닫는 답을 각각 전달한다: 해당 왕래 미실행. 실제 거절을 들은 당사자는 다음 요구를 스스로 정할 수 있다. 물리적 감금 사건 없음.
요구를 하나의 충성 서약으로 바꾼다: 실제 철회·줄어든 대화만. 가족 화해·호감·인질 획득 없음.

- B3: 선택 경로의 실제 결과와 미완료를 구분하고 실제 허락된 현재 청중에게만 확인한다. 문턱의 현재 통제권 범위만 다룬다. 타인의 신체·가족 관계·충성·지휘권은 보상이 아니다. 허용은 영구 통행권이 아니며 현재 감금·구출을 새로 만들지 않는다.
  실제 변화: 실제 선택·실행한 경로의 결과만 확인한다. 아래 서로 다른 결과를 동시에 부여하지 않는다.
한정 허용과 당사자 동의 뒤 왕래한다: 동의하여 실제 움직인 당사자의 한 번 왕래만. 온순해짐·가족 화해·영구 통행권 없음.
문턱을 닫는 답을 각각 전달한다: 해당 왕래 미실행. 실제 거절을 들은 당사자는 다음 요구를 스스로 정할 수 있다. 물리적 감금 사건 없음.
요구를 하나의 충성 서약으로 바꾼다: 실제 철회·줄어든 대화만. 가족 화해·호감·인질 획득 없음. 실제 수령·수강 또는 그 거절은 별도로 남는다.

현행 완료 보강: 당사자별 허용 왕래=(해당 실제 요구 수신 AND 왕의 현재 권한·한정 허용 AND 해당 당사자 조건 실제 수신·동의 AND 실제 왕복). OR 거절 종료=(왕의 해당 거절 AND 당사자의 실제 수신), 이동0. 마니제 완료 AND 파랑기스 완료를 공통 종료조건으로 쓰지 않는다. 변조는 실제 행위와 해당 당사자의 실제 인지 뒤 철회만 기록한다.

선택 일상:
- 버티는 매듭: 아프라시야브는 자기 끈의 매듭을 시험하다 플레이어의 매듭 방식에 짧게 관심을 보인다. 견해만 말하거나 물러난다. 작은 취향 대화가 가족 문제의 화해로 번지지 않는다.
- 요구 두 개: 마니제와 파랑기스가 실제 보낸 왕래 요구를 각각 듣는다. 플레이어가 전달한다면 원문의 화자를 유지한다. 둘의 요구를 한 충성 서약으로 합치지 않는다. 누구의 답도 들리지 않았으면 빈 요구로 꾸미지 않는다.
- 한 번 열리는 문턱: 왕이 한정 허용을 직접 답하고 당사자도 동의했을 때 플레이어는 실제 문턱 밖 복귀로를 확인한다. 문을 닫는 안도 가능하며 현재 이동은 일어나지 않는다. 허용된 한 번의 왕래만 남고 영구 출입권·포로 해방은 별도다.
- 돌아온 요구: 실제로 제한을 지키며 자기 뜻을 말한 상대에게 아프라시야브는 대신 조작된 답보다 직접 조건을 제시한다. 대립을 이어 가거나 이번 협상을 끝낸다. 플레이어가 강해져도 가족 화해·신뢰가 자동 증가하지 않는다.

## 자하크 · RPG-S12-025

자하크는 돌자리 안쪽에 자기 물건을 일정한 간격으로 놓고 누가 움직이는지 본다. 다가온 사람에게 아직 없던 탄원을 꺼내거나 모르는 과거 굴복을 강요해 기록하지 않는다.

장소: 최초 조우와 대독은 황무지 폐허의 안팎이 갈리는 돌자리 바깥이다. 편의는 실제 현재 통제 가능한 안쪽의 바람 피할 자리 한 곳에 한정한다. 완전 봉인이라면 어느 장소도 일반 대면을 열지 않는다.
세계 해금: 누구 한 명이 황무지의 공개 통행로와 안전 복귀점을 실제 탐험하면 전역 해금한다. 봉인·생사 상태를 바꾸지 않으며 고문·굴복·탄원 변조는 조건0.
현재 조우 주체: 현재 황무지 폐허 바깥의 허용 접점에 도달해 안전 복귀길을 확인하는 사람. 탄원·충성·카베 배신을 준비물로 요구하지 않는다.

- B2: 현재 범위에 대응하는 실제 경로를 고른다.

자기 이름으로만 굴복한다: 자하크가 현재 자기 통제 범위의 안쪽 돌자리에서 잠깐 바람을 피할 자리를 실제 제안한 때 자기 이름으로만 굴복 발언을 한다. 카베의 요구·이름을 팔거나 그 동의를 대신하지 않는다. 자하크가 위세를 과시한 행동을 현재 청중만 본다. 카베가 실제 이 사실을 알고 대변 자격을 거둔 때만 그 철회를 기록한다. 자하크가 실제 자리를 내주고 플레이어가 실제 들어가 쉰 때만 그 쉼이 성립하며, 그 전에는 약속에 머문다. 새 영구 출입권이나 물품은 없다.
  실제 변화: 작은 편의를 거절하고 물러난다: 실제 거절·철수만. 카베 실제 수신 뒤에만 다음 요구의 접점. 봉기 성공·왕 몰락 없음.

  실제 변화: 실제 선택·실행한 경로의 결과만 확인한다. 아래 서로 다른 결과를 동시에 부여하지 않는다.

## 라흐쉬 · RPG-S12-028

라흐쉬는 풀 냄새가 나는 바람 쪽으로 코를 낮추고 무게를 다른 발로 옮긴다. 아래 반응은 전부 비언어 관찰 묘사이며 인간 대사·속마음 자막이 아니다.

장소: 최초 조우는 기존 공개 생활권 바깥 길의 그늘과 넓은 마당을 채택한다. 작은 실내 방에 말을 억지로 배치하지 않는다. 운반은 실제 그늘 보관처, 동행은 별도 안전길이며 기본 8–16블록 구간을 제안하되 더 짧은 실제 자발 이동만 있으면 그 거리만 기록한다.
세계 해금: 기존 초기 후보를 유지하여 C01 공통 시작 뒤 추가 해금 없이 일반 풀에 등록한다. 목초지 왕복은 선택 탐험 기록이며 조련·승차·루스탐 동의를 최초 조우 잠금으로 추가하지 않는다.
현재 조우 주체: 현재 공개 길 가장자리의 안전한 거리에서 실제 본체 통행을 막지 않는 적격자. 일반 관찰에 인간 질문이나 루스탐의 동행 수락을 요구하지 않는다.

### 기존 장면의 실제 진행

**EP030B-RPG-S12-028 · 귀가 돌아선 곳**

- B1: 현재 범위에 대응하는 실제 경로를 고른다.
다음은 선택 경로별 실제 행동이며 서로 모두 수행할 조건이 아니다:
내려서 짐을 나누어 그늘로 옮긴다: 루스탐과 실제 탑승한 사람이 라흐쉬의 정지를 보고 안전하게 내린다. 짐 소유자의 허락 아래 실제 실린 짐을 나누어 사람이 그늘로 운반한다. 라흐쉬를 끌지 않으며 실제 그늘로 몸을 돌렸을 때만 그 반응을 기록한다.
재촉만 멈추고 현재 자리에서 쉰다: 짐을 내리지 않는 경로에서는 고삐 재촉과 출발 요구를 실제 멈춘다. 안전한 현재 자리에서 라흐쉬의 반응을 기다린다. 라흐쉬가 스스로 그늘 쪽으로 돌면 그 이동만 따라 관찰한다.
  실제 변화: 내려서 짐을 나누어 그늘로 옮긴다: 실제 하차·짐 분담만큼 등의 무게가 줄어든다. 그늘 이동은 라흐쉬가 실제 했을 때만.
재촉만 멈추고 현재 자리에서 쉰다: 정지와 쉼만. 짐 하차·하중 감소 기록 없음.

- B2: 현재 범위에 대응하는 실제 경로를 고른다.
다음은 선택 경로별 실제 행동이며 서로 모두 수행할 조건이 아니다:
스스로 보폭을 맞추면 짧게 출발한다: 라흐쉬가 실제 다시 걷고 보폭을 맞추는 반응을 보일 때만 동행자가 그 속도에 맞춰 기존 길의 짧은 안전 구간을 함께 이동한다. 새 재촉·강제 기승을 하지 않고 다시 멈추면 이동을 중단한다.
여전히 멈추면 더 쉰다: 라흐쉬가 계속 멈추면 동행자도 출발을 미루고 안전한 현재 그늘에서 휴식을 이어 간다. 짐을 내린 경로인지 그대로 둔 경로인지 현물 상태를 유지한다.
고삐를 계속 잡아끈다: 실제 재촉하여 잡아끄는 행동이 있으면 라흐쉬가 발을 박고 이동을 거부하는 현재 반응을 남긴다. 동행자는 재촉을 중단하고 필요한 짐을 사람이 실제 옮겨야 하며 자동 운반 완료는 없다.
  실제 변화: 스스로 보폭을 맞추면 짧게 출발한다: 실제 자발적으로 맞춘 보폭과 이동 거리만. 영구 조련·기승권 없음.
여전히 멈추면 더 쉰다: 그늘의 휴식 지속만. 동행 거리 증가·출발 성공 없음.
고삐를 계속 잡아끈다: 실제 이동 거부와 남은 짐만. 동행 신뢰·기승 보상 없음.

- B3: 선택 경로의 실제 결과와 미완료를 구분하고 실제 허락된 현재 청중에게만 확인한다. 라흐쉬는 루스탐의 말이며 플레이어 소유·상시 탈것으로 양도되지 않는다. 짐은 원소유자에게 속하고 실제 내려 나눈 짐만 사람이 운반한다. 물품·능력·기승 보상 없음.
  실제 변화: 실제 선택·실행한 경로의 결과만 확인한다. 아래 서로 다른 결과를 동시에 부여하지 않는다.
스스로 보폭을 맞추면 짧게 출발한다: 실제 자발적으로 맞춘 보폭과 이동 거리만. 영구 조련·기승권 없음.
여전히 멈추면 더 쉰다: 그늘의 휴식 지속만. 동행 거리 증가·출발 성공 없음.
고삐를 계속 잡아끈다: 실제 이동 거부와 남은 짐만. 동행 신뢰·기승 보상 없음. 실제 수령·수강 또는 그 거절은 별도로 남는다.

현행 완료 보강: 하차·운반=(실제 탑승자 하차 AND 원소유자 허락 AND 실제 짐 하역·사람의 운반). OR 휴식=(실제 재촉 중단 AND 안전자리 체류), 이 경로 하중감소0. 이후 자발 이동 OR 휴식 지속을 판정한다. 귀 움직임·고개 낮춤만으로 출발/동의/기승/인간 감사0. 존재하지 않는 탑승자·짐을 만들지 않는다.

선택 일상:
- 바람 쪽의 코: 라흐쉬가 현재 풀 냄새가 나는 쪽으로 코를 낮춘다. 플레이어는 길을 막지 않는 거리에서 멈춘다. 지나가거나 조용히 머무를 수 있다. 울음·호흡은 관측한 소리로만 남고 대사나 퀘스트 질문으로 번역하지 않는다.
- 움직이지 않는 발: 실제로 귀를 돌리고 발을 멈추면 루스탐이 내리고 플레이어는 좁은 길과 발판을 살핀다. 짐을 나누어 그늘로 옮기거나 더 쉬도록 둔다. 돌봄 행동과 현재 반응만 기록한다. 위험의 정확한 이유를 라흐쉬가 설명한 것으로 쓰지 않는다.
- 가까워진 보폭: 휴식 뒤 라흐쉬가 실제 움직이는 경우에만 짧은 구간에서 보폭을 맞추는지 본다. 더 쉬면 동행 거리를 늘리지 않고 강제로 끌지 않는다. 이동이 성립해도 플레이어의 탈것 소유·영구 조련·승차 허락은 없다.

## 시무르그·잘의 보호자 · RPG-S12-029

잘을 길러 준 이 시무르그 개체는 능선의 넓은 쉼자리에서 바람을 등지고 가벼운 것이 내려앉는 방향을 본다. 실제 말을 하는 원문을 유지하며 관찰만 하러 온 이를 도움 청구자로 만들지 않는다.

장소: 최초 조우는 안전한 능선과 이어지는 기존 북방 폐허·감시탑의 넓은 외부 쉼자리다. 실제 몸·날개 크기와 이착륙/통행 충돌을 수용할 자연 평면을 우선하며 작은 탑 실내를 강제하지 않는다. 희귀 shrine_tower는 발견한 경우만 선택 부지이며 필수 해금 건축이 아니다.

### 기존 장면의 실제 진행

**EP030B-RPG-S12-029 · 날개 아래 남기지 않을 일**

- B1: 현재 범위에 대응하는 실제 경로를 고른다.
다음은 선택 경로별 실제 행동이며 서로 모두 수행할 조건이 아니다:

  실제 변화: 잘의 돌봄 물건을 펼쳐 맡을 일을 고른다: 실제 펼친 물건과 잘이 직접 선택한 자기 몫만. 돌봄 수행·시무르그 도움 완료는 별도.

- B2: 현재 범위에 대응하는 실제 경로를 고른다.
다음은 선택 경로별 실제 행동이며 서로 모두 수행할 조건이 아니다:
잘이 자기 몫을 한 뒤 남은 한 부분을 돕는다: 잘이 선택한 실제 돌봄을 수행한다. 예를 들어 준비한 물그릇을 안정된 곳에 놓고 덮개를 정리하는 자기 일을 끝낸 경우 시무르그는 직접 그 수행을 본 범위에서 아직 바람에 흔들리는 한쪽만 몸을 돌려 가려 준다. 실제 물건·요청·접촉이 다르면 그 허락된 한 부분만 돕고 원격 치유나 날개 운송을 만들지 않는다.
잘이 자기 몫을 한 뒤 추가 도움은 기다린다: 잘이 실제 선택한 자기 돌봄을 끝낸 뒤 시무르그가 지금은 추가 도움을 기다리겠다고 직접 답한다. 플레이어는 남은 물건과 미해결 부분을 현재 상태로 보존한다. 자기 돌봄 수행을 지우지 않고 도움은 미실행으로 둔다.
모든 일을 날개에 맡기려 한다: 실제로 잘이 맡을 돌봄까지 시무르그에게 전부 떠넘기려 하면 시무르그가 추가 도움을 보류한다. 옛 은혜나 깃털 소지 주장을 무제한 호출권으로 인정하지 않는다.
  실제 변화: 잘이 자기 몫을 한 뒤 남은 한 부분을 돕는다: 잘의 실제 자기 돌봄과 시무르그의 한정 실제 도움만. 시무르그는 본 수행을 다음 요청의 근거로 기억한다.
잘이 자기 몫을 한 뒤 추가 도움은 기다린다: 잘의 실제 자기 수행·시무르그의 기다리겠다는 응답만. 추가 도움·치유 완료 없음.
모든 일을 날개에 맡기려 한다: 추가 도움 보류와 자기 미수행 돌봄만. 새 깃털·치유·전투 승리 없음.

- B3: 선택 경로의 실제 결과와 미완료를 구분하고 실제 허락된 현재 청중에게만 확인한다. 잘이 허락한 돌봄 물건만 펼치고 사용한다. 깃털은 실제 별도 승인된 사용 맥락·소모만 기존 근거로 보존한다. 이 대화에 새 깃털·가호·권능·무조건 치유·승리 지급 없음.
  실제 변화: 실제 선택·실행한 경로의 결과만 확인한다. 아래 서로 다른 결과를 동시에 부여하지 않는다.
잘이 자기 몫을 한 뒤 남은 한 부분을 돕는다: 잘의 실제 자기 돌봄과 시무르그의 한정 실제 도움만. 시무르그는 본 수행을 다음 요청의 근거로 기억한다.
잘이 자기 몫을 한 뒤 추가 도움은 기다린다: 잘의 실제 자기 수행·시무르그의 기다리겠다는 응답만. 추가 도움·치유 완료 없음.
모든 일을 날개에 맡기려 한다: 추가 도움 보류와 자기 미수행 돌봄만. 새 깃털·치유·전투 승리 없음. 실제 수령·수강 또는 그 거절은 별도로 남는다.

## 디브에 세피드 · RPG-S12-030

디브에 세피드는 동굴 바깥 소리의 울림을 듣고 발을 한 번 굴린다. 실제 발화 가능한 백색 디브이며 동굴을 달래면 열리는 보상 상자로 바꾸지 않는다.

장소: 최초 조우는 오버월드 지하 폐허와 이어진 실제 동굴 입구의 돌턱 바깥을 채택한다. 묘지·폐예배당 후보만 있고 동굴 접점이 없으면 이 첫 장면 부지로 대체하지 않는다. 귀환은 현재 합의한 외부 인수점으로 실제 이동하며 면담 자리에서 말을 했다는 이유로 완료하지 않는다.
세계 해금: 누구 한 명이 오버월드 지하 폐허의 안전 외곽을 실제 탐험하고 복귀하면 전역 해금한다. 카이 카부스 구금·디브 패배를 새로 만들지 않는다.
현재 조우 주체: 현재 실제 동굴 입구 돌턱 바깥 안전점에 도달하고 열린 복귀로를 확인하는 사람. 무기 소지·루스탐 동행·확인된 포로는 일반 최초 조우의 필수가 아니다.

### 기존 장면의 실제 진행

**EP031-RPG-S12-030 · 동굴 밖에서 끝낼 말**

- B1: 현재 범위에 대응하는 실제 경로를 고른다.
다음은 선택 경로별 실제 행동이며 서로 모두 수행할 조건이 아니다:
무기를 낮추고 바깥에서 듣는다: 플레이어가 실제 가진 무기가 있으면 사람을 겨누지 않게 낮춘다. 무기가 없다면 낮춘 척하지 않고 빈손으로 돌턱 밖에 선다. 디브는 안쪽을 등으로 가린 채 바깥의 평평한 곳을 발끝으로 짚는다. 플레이어가 그 자리까지 실제 움직이고 양측이 서로의 말을 들을 거리를 확인한다.
경계 밖으로 물러나 말을 듣는다: 플레이어가 실제 뒤로 물러나 돌턱 바깥에 멈춘다. 디브는 플레이어가 선 자리까지만 몸을 돌리고 양측이 들을 수 있을 때 면담 의사를 다시 묻는다. 루스탐이 실제 함께 있고 스스로 물러났다면 그 직접 관측에 대해서만 디브가 조건 하나를 말한다. 루스탐 부재·무응답은 이 면담의 필수 참여 조건이 아니다.
  실제 변화: 무기를 낮추고 바깥에서 듣는다: 면담할 바깥 거리가 생긴다. 동굴 안 출입 허락·포로 존재·해방은 아직 없다.
경계 밖으로 물러나 말을 듣는다: 실제로 물러난 사람과만 면담이 열리고 루스탐의 선택·승패·사망을 대신 만들지 않는다.

- B2: 현재 범위에 대응하는 실제 경로를 고른다.
다음은 선택 경로별 실제 행동이며 서로 모두 수행할 조건이 아니다:
확인된 포로의 한 차례 귀환을 교섭한다: 이 경로는 카이 카부스의 실제 현재 포로 상태, 현재 해방 가능한 당사자와 접근, 귀환 의사 및 양측의 유효 응답이 확인된 때만 열린다. 플레이어는 돌아갈 한 차례 통로와 동굴 출입을 분리하여 묻는다. 디브는 바깥으로 나올 자리만 가리킨다. 카이 카부스의 실제 응답을 직접 듣거나, 본인이 그 문장·수신자를 허락한 전달을 실제 수신한다. 군대 후퇴의 합의 범위도 당사자의 실제 응답 이상으로 넓히지 않는다. 양측이 현재 한정 조건에 응답한 뒤 실제 인도와 카이 카부스의 바깥 이동·귀환 인수를 확인한다. 부재·거절·조건만 합의하고 아직 이동하지 않은 경우 인도 완료 없이 현재 단계에 남는다.
포로가 확인되지 않아 앞으로 말할 범위만 정한다: 현재 포로 상태가 확인되지 않았음을 그대로 둔다. 플레이어는 사람의 귀환 요청이 실제 생겼을 때 어디서 무엇을 논의할 수 있는지 묻고 디브의 현재 답을 듣는다. 디브는 돌턱 바깥을 다시 짚고 안쪽을 등으로 가린다. 두 사람은 지금의 면담 범위만 합의하거나 합의하지 못한 부분을 남긴다. 없는 포로·왕의 응답·해방 장면을 만들지 않는다.
동굴 전체를 전리품이라 주장하며 들어간다: 실제로 점령을 주장하고 경계를 넘으려는 행동이 있는 때 디브가 입구를 막는다. 가정 질문이나 농담만으로 침입 사실을 만들지 않는다. 교섭을 중단하고 플레이어는 현재 위험을 보며 안전한 바깥으로 철수한다. 대결을 별도로 택하면 현행 전투 준비·접근부터 확인하며 이 카드가 전투·승패·포로 상태를 자동 실행하지 않는다.
  실제 변화: 확인된 포로의 한 차례 귀환을 교섭한다: 현재 한정 조건을 실제 받아들여 인도·이동·인수를 마친 경우에만 카이 카부스의 이번 귀환이 남는다. 동굴 개방·디브 항복·전투 승리 없음.
포로가 확인되지 않아 앞으로 말할 범위만 정한다: 실제 답하고 수신한 경우 동굴 밖 면담 범위만 남는다. 카이 카부스의 구금·소재·해방·승패는 계속 미확인이다.
동굴 전체를 전리품이라 주장하며 들어간다: 교섭이 깨지고 디브가 막은 현재 입구만 남는다. 성공한 해방·보상·전투 승리 없음. 이전 유효 면담 수신은 지워지지 않는다.

- B3: 선택 경로의 실제 결과와 미완료를 구분하고 실제 허락된 현재 청중에게만 확인한다. 돌턱·동굴의 사용 허락은 디브에 세피드가 정한 현재 범위만. 카이 카부스는 소유·전리품·플레이어 보상이 아닌 자기 응답권을 가진 당사자다. 면담에 물품 소비·지급 없음. 실제 인도·이동은 한 번만 기록하고 새 전투 보상은 이 사건에서 정산하지 않는다.
  실제 변화: 실제 선택·실행한 경로의 결과만 확인한다. 아래 서로 다른 결과를 동시에 부여하지 않는다.
확인된 포로의 한 차례 귀환을 교섭한다: 현재 한정 조건을 실제 받아들여 인도·이동·인수를 마친 경우에만 카이 카부스의 이번 귀환이 남는다. 동굴 개방·디브 항복·전투 승리 없음.
포로가 확인되지 않아 앞으로 말할 범위만 정한다: 실제 답하고 수신한 경우 동굴 밖 면담 범위만 남는다. 카이 카부스의 구금·소재·해방·승패는 계속 미확인이다.
동굴 전체를 전리품이라 주장하며 들어간다: 교섭이 깨지고 디브가 막은 현재 입구만 남는다. 성공한 해방·보상·전투 승리 없음. 이전 유효 면담 수신은 지워지지 않는다. 실제 수령·수강 또는 그 거절은 별도로 남는다.

현행 완료 보강: 귀환=(카이 카부스 현재 포로 상태 확인 AND 실제 해방 가능한 당사자·접근 AND 본인 귀환 의사 AND 양측 현재 유효 응답 AND 실제 인도 AND 바깥 이동 AND 귀환 인수). OR 포로 미확인 대화=(현재 미확인 유지 AND 디브의 실제 면담 범위 응답·수신), 구금·귀환0. 전언 수신은 직접 목격 대사가 아니라 “귀환했다는 답을 받았다”로 말한다. 침입은 실제 점령 주장+경계 침범 시도에만 반응한다.

선택 일상:
- 벽의 온도: 지하 외곽의 안전 접점에서 디브에 세피드는 동굴의 실제 울림을 듣는다. 플레이어는 돌턱 밖에서 말하거나 떠난다. 많이 묻는다고 대답 수가 늘지 않는다. 침묵으로 끝날 수 있다.
- 무기를 낮춘 자리: 플레이어는 무기를 휘두르지 않고 교섭 가능한 바깥 공간과 돌아갈 길을 확인한다. 낮추지 않으면 거리를 둔 채 면담을 끝낼 수 있다. 안전 접점만 생기며 포로 인도·영역 양도는 발생하지 않는다.
- 인도할 사람이 있을 때: 현재 실제 해방 대상과 카이 카부스 측 응답이 확인된 경우에만 한 차례 인도 경로를 논의한다. 대상이 없으면 가상의 구금 사건을 만들지 않고 조건 대화로 끝낸다. 실제 이동·양측 수신이 확인된 인도만 성립한다. 포로를 플레이어 보상으로 취급하지 않는다.
- 끝나지 않은 대결 가능성: 루스탐과의 기존 대결 가능성은 남기되 실제 승인된 전투가 아닐 때는 레이드 패턴이나 사망 결말을 확정하지 않는다. 플레이어는 회담을 끝내고 물러나거나 후속 대결안을 별도 제안한다. 경계를 지킨 상대에게 먼저 조건 하나를 말할 수 있어도 우호·복종은 자동 증가하지 않는다.

## 공통 중단·청중
