  - 안쪽에서 매복 움직임을 뒤늦게 본다: 플레이어가 현존 엄폐와 퇴로를 확인해 몸을 피한다. 타격·손실은 실제 판정된 부분만 남긴다. → 실제 공격·엄폐·현재 위험만. 자동 패배나 분실 없음.

- B3: 실제 위협만 막고 이탈할지, 백골부인을 좇아 좁은 길로 다시 들어갈지 고른다. 후자는 별도 실제 전투 위험이며 결과를 미리 쓰지 않는다.

  - 현재 위협만 막고 안전한 길로 이탈한다: 실제 공격이 있으면 필요한 자기 방어를 수행하고 열린 퇴로로 안전 경계까지 실제 이동한다. 공격이 없으면 거리와 퇴로를 확인해 이탈만 하며 방어·전투 성과를 만들지 않는다. 실제 안전 도달과 현재 위협 범위를 확인한 경우만 B4로 간다. → 실제 생환과 확인한 위험 범위. 그녀가 살아 퇴각하여 실패한 유인을 직접 겪었을 때만 그녀의 조건부 다음 접근 변화가 가능하다.

  - 정체를 안다며 추격한다: 플레이어가 실제 이동·전투를 계속하며 생환·부상·제압·사망을 실제 결과로 판정한다. → 진행 중이면 진행 중. 실제 안전 생환할 때만 B4로 별도 재진입 가능, 미관측 살해·자동 처형 성공 없음.

  - 현재 공격이 없는 안전한 거리를 유지한다: 플레이어가 안전한 기존 길로 실제 나가며 관찰한 불일치만 남긴다. → 공격 방어·전투 승리 없이 실제 안전 이탈.

- B4: 이미 전부 가지고 있으면 위험 정보만 남기고 마친다. 자기 물건이 현장에 남았다면 현재 접근 안전과 실물을 확인해 회수하거나 그대로 두고 떠난다.

  - 물건 회수 없이 확인한 위험만 남긴다: 현재 보유와 미회수 실물을 구분해 남기고 기존 안전 길로 이동한다. → 확인한 위험 정보만. 미수령 보상권·가짜 반환 물품 없음.
