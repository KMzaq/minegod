### 비싼 향보다 편한 자리
- 현재 세계 해금: C01 이후 기존 before 초기 후보 보존. 새 향 구매·제작·치료 이력 없음.
- 현재 조우 주체: 원문 주점·저택 공용 공간의 안전한 공개 방문자. 향을 싫어하거나 비교를 사양해도 인사 가능.
- 활동 장소: 기존 주점 볕드는 의자. 통로 바깥에 비교용 천 두 장을 놓고 향 사용 여부부터 묻는다.

1. 소유자 허락을 받은 천 2장과 실제 있는 비교용 향 2종의 이름·값표를 가리고 두 조합을 비교한다. 향 없는 비교는 천 2장만 사용한다. 향의 감각은 선택 설명과 당사자 진술이지 현실 냄새 감지·포션 효과가 아니다.
2. 참가자가 고른 한 조합을 허락된 의자에 실제 놓고 앉아 사용한다. B1-1은 자기가 편한 조합을 고른 이유를 본인이 실제 말하고 바스테트가 들은 범위만 기록한다. B1-2는 값표를 실제 확인해 비싼 조합을 놓고 다른 취향을 받아들이는 분기이며 B1-1의 편안함 이유 발언을 필수로 붙이지 않는다. 앉는 자세·위치·충돌 표현은 신규 구현 요구이며 미구현 상태에서 앉은 결과를 생성하지 않는다. 기본 시연 향은 소유자가 허락한 기존 1회분만 사용하고 남은 병·천은 반환한다. 값으로 고른 가지는 실제 가격 선호만 기억하며 편안함을 추정하지 않는다.
3. 네페르템에게 실제 받은 향의 불편 1건만 허락해 전달할 수 있다. 실제 회신 수락·거절·수정과 실제 인수를 분리한다. 출처 없거나 요청 사양이면 향을 치우고 천만 남겨 놀이를 마친다.

“값표는 잠깐 뒤집자. 네가 앉을 자리잖아.”
“내가 고른 것과 다르네. 그래서 어느 쪽이 더 편했어?”
“향이 싫다면 치우면 돼. 참아 낼 시험이 아니니까.”

실제 동의·허락된 비교 AND (B1-1의 편한 조합 선택·이유 실제 발언 OR B1-2의 실제 값표 확인·비싼 조합 선택·다른 취향 수용) AND 선택한 조합을 놓고 실제 앉아 사용하기로 놀이를 종료한다. 향 사양이면 천 비교만 하며 향 사용을 강제하지 않는다. 교환은 선택 별도이며 실제 제공 출처·수락·인수까지 없으면 교환0.
바스테트는 전원 치료 담당이 아니다. 향·천의 감각 묘사는 재생·회복·내성 효과가 아니며 네페르템의 재료·기존 거래 권리를 여기서 무료 복제하지 않는다.

## 베스 · RPG-S03-026

### 위엄 없는 가면극
- 현재 세계 해금: C01 이후 기존 before 초기 후보 보존. 보호 봉사·웃음 반응을 해금 시험으로 사용하지 않는다.
- 현재 조우 주체: 원문 주점·저택의 안전 공용 공간에 실제 방문한 사람. 공연 없는 날도 접촉 가능.
- 활동 장소: 기존 주점 공용 방 놀이공간 4×4와 열린 출구. 쉬는 사람의 자리와 8블록 이상 분리하되 소음 전달 여부는 현장에서 확인한다.

1. 베스와 동의한 소품 1개를 쓰고 플레이어가 2블록 거드름 걸음→정지→과장된 인사 동작을 한다. 실제 넘어짐·낙하 피해 없이 동작으로만 표현하며 베스가 한 차례 과장해서 받는다. 관객을 지목하지 않는다.
2. 평시에는 먼저 연습임을 실제 청중에게 알리고 짧은 경보 소리 1회에 소품을 내리고 출구 폭 2블록을 비운다. 타웨레트가 실제 있으면 쉬는 자리에서 들은 음량을 받아 한 번 낮춰 재연습한다. 부재면 둘의 연습만 완료.
3. 실제 경보가 있으면 연습과 별도 기록으로 전환해 공연을 끄고 실제 열린 안전 경로로 참가자 철수를 돕는다. 출구에서 실제 이동한 UUID만 집계하며 남은 사람·위험은 미해결로 남긴다.

“내 위엄은 네가 망쳐 줘. 저 사람은 관객으로 두고.”
“연습이야. 이 소리가 나면 농담은 접고 길부터 비우자.”
“안 웃어도 돼. 내가 지금 너무 점잖았나 보지!”

비조롱 공연의 실제 결과와 (평시: 연습 고지 AND 실제 신호·출구 비움 OR 실제 경보: 즉시 공연 중지 AND 실제 안전 이동·남은 위험 확인)을 각각 기록한다. 경보 발생 시 연습 완료를 기다리지 않고 즉시 철수하며, 철수만으로 앞 공연의 비조롱 성과를 만들지 않는다. 관객 웃음·완치·전원 안전 자동완료0.
타웨레트와 음량 합의는 실제 수신·응답이 필요. 환자의 공포를 실패 점수로 취급하지 않고 보호소를 공격 불가 지대로 만들지 않는다.

## 타웨레트 · RPG-S03-027

### 한 일을 맡기는 쉼
- 현재 세계 해금: C01 이후 before 초기 후보 유지. 제작 준비 원문은 실제 운반 준비와 별개로 적용하며 최초 접견에 새 물품 제출을 추가하지 않는다.
- 현재 조우 주체: 원문 강변 주점·초원 폐허·야영지 공용 공간에서 강과 연결된 안전 통행을 현재 확인한 방문자.
- 활동 장소: 강변 기존 야영지의 공용 물통 보관점 A와 가족이 허락한 쉼자리 B. 길은 4~12블록, 사적 구역 밖에서 먼저 요청을 듣는다.

1. 오늘 요청자가 고른 물 또는 침구 중 한 일을 받는다. 기본은 허락된 물통 1개 운반 또는 침구 1세트 정리이며 실제 요청에서 합의한 품목·정수량·대체재가 다르면 그 회차 원장에 정하고 전체 합의분을 처리한다. 둘을 모두 필수로 만들지 않는다.
2. 실제 맡은 물품만 A에서 인수해 B에 놓고 당사자 인수 응답을 확인한다. 2블록은 물품 접촉 때만 적용. 타웨레트 의자 물건은 그 소유자의 허락을 별도로 얻어 옆으로 옮기고 실제 앉음이 있을 때만 그녀의 쉼을 기록한다.
3. 오늘 남은 요청은 맡지 않았다고 알린다. 다음 방문 B2는 새 회차. 현재 베스 공연이 있고 쉬는 당사자가 원할 때만 사유를 밝히지 않은 소음·장소 요청 1건을 전하고 실제 이동 전에는 조용해졌다고 쓰지 않는다.

“지금 맡을 수 있는 일 하나만 골라 줘. 모두 해 준다는 말보다 그게 좋아.”
“그쪽은 도움을 원하지 않았어. 자리를 비워 두자.”
“이제 내가 잠깐 앉을게. 다음 부탁까지 네 몫이 되지는 않아.”

선택한 한 요청의 실제 인수·처리·수령 확인으로 오늘 회차 종료. 쉼은 실제 앉은 경우만. 다음 방문·베스 응답은 이전 완료를 잠그지 않는다.
돌봄은 원소유 물품의 도움이다. 출산 성공·회복·보호 버프를 보장하지 않고 소베크의 강길 합의를 덮어쓰지 않는다.

## 콘수 · RPG-S03-032

### 돌아가도 되는 거리
- 현재 세계 해금: C01 공통 시작 확인으로 공개 생활권 일반 후보를 현재 채택한다. pending을 후반 잠금이나 봉인 해제로 해석하지 않는다. 환자 자격·병력·이시스 만남·반복 방문 없음.
- 현재 조우 주체: 원문 주점·저택의 공개 안전 공간에 현재 방문한 사람. 밤 보행은 선택 장면이며 낮 일반 대화도 허용.
- 활동 장소: 기존 주점의 조용한 쉼자리 A와 평탄한 길 위 B. B는 A에서 4블록, 돌아오는 총 8블록 이내를 기본 제안으로 하며 당사자는 더 짧게 또는 이동0을 고를 수 있다.

1. 실제 도움 요청자에게 오늘 이동할지 쉴지만 물어 합의한다. 이동은 A→B의 실제 걸음이며 당사자 보조자인지 본인인지 분리한다. 걷지 않는 선택은 A 주변 통로를 비우고 실제 쉴 자리를 확인하는 도움으로 마친다.
2. 불편·중지 의사가 오면 즉시 추가 이동을 멈추고 당사자가 원하는 안전 자리로 돌아가거나 그 자리의 안전 확보만 돕는다. 목표 거리를 채우지 않아도 중지·휴식 처리로 종료하며 호전을 기록하지 않는다.
3. 다음 실제 방문에서는 오늘 말한 변화와 실제 동의한 동작만 비교한다. 이시스의 낮 기록은 당사자·원소유자 허락과 실제 수신 항목만 연결하고, 허락없는 청중 앞에서는 내용·제목·존재도 암시하지 않는다.

“오늘은 저기까지 가도 되고, 여기 있어도 돼.”
“그러자. 오늘 갈 길은 여기까지로 하자.”
“네가 걸은 거리와 그 사람 몸이 나아졌는지는 다른 이야기야.”

(오늘 요청한 움직임의 실제 도움 OR 당사자 의사에 따른 실제 중지·휴식 도움) AND 당사자의 현재 응답으로 회차를 종료한다. 실제 요청자가 부재하면 새 회차0. 다음 방문은 선택이며 완치0.
콘수의 회복 관찰을 HP 회복·의학적 진단·상태이상 제거·퇴원 보장으로 바꾸지 않는다. 이시스 개인 MAIN과 재료·치료 권리를 여기서 대신 완료하지 않는다.
