# P2_NONQUEST-063 · 스토리

현재 기획과 원문 보존을 구분한 읽기본. 실행 스키마가 아니며 실제 시험은 하지 않았다.

## 공통 운영
- 문서성격: 현재 채택된 저술·구현 요구. 실행 스키마, 구현완료, 실제 API/게임/LLM 시험 결과가 아니다.
- 원문과보강: source_contract와 retained_profile은 선택한 원문값 그대로다. 과거 미채택 표기·미정은 역사 원문에만 보존하며 현재 정책은 adopted_detail만 적용한다. 기존 정체·등급·관계·본편 권리·봉인을 바꾸지 않는다.
- 조우운영:
  - 정책참조: 퀘스트/공통설계/시간_조우_성장_운영정책.json#general_encounter 및 #atomic_contract
  - 적용: 현재 채택한 일반 무작위 경로만 공통 정책에 등록한다. 기존 실제 배치 본체는 재추첨 없이 직접 접촉. 제한 봉인석 접촉은 일반풀 제외.
  - 확률과주기: 일반풀의 300 활동초 창·서버25%·실제 등장 뒤 인물1800 가동초 쿨 및 현재 전투등급 가중치는 참조 정책을 재사용한다. 인물마다 별도25% 추첨하지 않는다.
  - 공통상태: world_uuid+canonical_actor 세계 해금. 누구 한 명의 유효 사건으로 전역 개방. 조우조건 맞춘 실제 한 사람만 주체, 해금자와 다를 수 있다.
  - 단일본체: 전역 canonical_actor CAS와 journal/실제 entity 대조, 재시작 후 동일 결과 복구. 이미 활동중이면 새 본체0.
  - 권리분리: 동행자는 세계 해금을 반복하지 않고 같은 본체를 목격할 수 있다. 일반 인사·응답은 해당 인물에게 허용된 발화·접촉 모드 안에서만 가능하다. 비언어 생물에게 사람말·인간식 승낙을 만들지 않는다. 개인 관계·사적 허가·수신·MAIN·보상은 별도이며 현재 안전과 의사를 확인한다.
  - 소급: 기존 유효한 조우·초기접근을 새 해금으로 잠그지 않는다. 기존 해금 확인 receipt가 있으면 유지. 과거 이력 증거가 없으면 허위 과거를 생성하지 않고 현재 새 유효 사건을 기다린다.
- 현재대화:
  - 판정순서:
    - 실제 동일본체·현재 접촉모드
    - 현재 안전·의사·실제 청중
    - 본인이 관측/허용전언으로 아는 플레이어 행위
    - 그 상대와의 실제 관계 기억
    - 이번 발언의 내용과 말투
  - 독립축: 친밀·존중·불쾌함·두려움·관측한 전투력은 서로 다르다. 강함을 보아도 자동 경외·존댓말·가호 지급 없음. 관계별 기존 profile의 9단계 지침을 유지하되 숨은 호감점수로 모든 반응을 대신하지 않는다.
  - 강함예문사용: 각 예문에 명시한 행위를 이 인물이 실제 직접 보았을 때만 사용한다. 숨은 CP·친구 기억·장비 외형으로 대체하지 않는다. 비언어 생물은 감각 반응만.
  - 대화거리: 사담 기본 8블록 및 실제 시야·음성 수신. 인수·집기만 2블록. 원거리 생물 관측은 현장 안전거리와 시야를 사용하며 접근·접촉을 강요하지 않는다.
  - 중단: 대화 거절·반박·침묵·퇴장은 정상 선택. 실제 위험중이면 안전철수 필요. 사망/로그아웃은 수행중단, 실제완료·소비·대여·수신 기록만 보존. 재회는 현재 접근을 다시 확인하고 끝난 사건을 재연하지 않는다.
- 기록과지식:
  - 저자진실: 정체·관계 정사와 인물의 실제 앎을 분리한다. 개인 미공개 사건·미래 분기·원전 전체를 loreKnowledge에 자동 주입하지 않는다.
  - 지식영수증: event_id·speaker/source·receiver_uuid·실제청중·공개허락 범위·received_at를 별도 저장. NPC도 실제 목격/수신 이전에는 모른다.
  - 정정: 거짓 주장을 수신한 사실과 그 주장 내용의 진위를 분리. 정정은 원청중의 실제 재수신이 있어야 하고 원래 수신을 삭제하지 않는다.
  - 사적정보: 새 청중이 끼면 비공개 내용 발화 중단 또는 현재 허락된 일반 정보로 전환. 제목으로도 비공개 비밀을 암시하지 않는다.
- 서비스와물건:
  - 수주: 이 패킷의 신규 퀘스트/개인MAIN 0. 기존 event/service/dialogue_only 방식 유지. 현재 행동 동의는 퀘스트 수락이 아니다.
  - 성장: 신규 장비·가호·주시·습득스킬·레벨·성장량0. 기존 허용된 생활지도/현물채집은 별도 보존.
  - 정산: 실제 물품과 원장 unique receipt를 대조. 인도불확실이면 새 생성0. 미인도 실제 물건만 현재 소유·보관 합의에 따라 복구. 미차용 반환의무0.
  - 반복: 현재 새 요청과 실재 현물을 분리한다. 기존 지도권은 실제 제공·수강·거절·미수령을 따로 기록한다. 같은 회차의 실물/지도는 중복 정산하지 않고 연습 반복은 성장 보상0.
- 본체상태: FIRST_UNPLACED는 유효 경로에서 최초 배치 가능, UNLOADED는 기존 UUID 재로드만, ACTIVE는 현 위치 직접 접촉, BUSY는 대기/거절, DEAD는 새 생성·부활0, SEALED는 원문 허용 접촉만. 불명 상태를 최초 미배치로 취급하지 않는다.
- 원문효력: 원문 보존 필드와 현행 상세가 충돌할 때 명시된 최신 정사·현재 보강을 적용한다. 원문 source_contract를 몰래 고치지 않는다. 특수 전투/지원/최종 MAIN은 해당 기존 문서가 단일 소유하며 일반풀 기본값으로 대체하지 않는다.
