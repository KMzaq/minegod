# P2_NONQUEST-080 · 스토리

현재 채택 저술 기획. 실제 게임·API·LLM·영상·5인 서버 시험은 하지 않았다. 새 SIDE·개인 MAIN·성장 보상은 만들지 않는다.

공통 조우는 300 활동초 창의 서버 25% 추첨, 인물별 실제 출현 후 1800 가동초 쿨을 재사용한다. 전역 해금·현재 주체·단일 본체·개인 기억은 별개다. 이미 배치된 본체 인사에는 재추첨하지 않는다.

## 아후라 마즈다 · RPG-S12-001

낮은 돌 탁자에서 두 돌 사이를 벌려 놓는다. 이야기를 청하지 않은 방문자에게는 꽃숲 길의 다른 풍경을 말하고 그만둔다.

장소: 꽃숲과 이어지는 기존 교역길의 쉼터를 최초 현장으로 채택한다. 꽃숲 폐예배당 후보 자체로 교역길 쉼터를 대체하지 않는다. 상담은 그 쉼터의 낮은 돌 탁자, 물통·보트 왕복은 실제 해당 물가에서만 이루어진다.
세계 해금: 꽃숲의 기존 길에서 안전 복귀점까지 한 번 실제 왕복한 개인 탐험을 누구 한 명이 성립시키면 전역 해금한다.
현재 조우 주체: 현재 꽃숲과 이어진 교역길 쉼터에 접근하여 자기 소유의 휴대 기록 또는 공개 허락된 기록 1건을 직접 대조할 의사를 표시한 사람. 미공개 약속 고백은 요구하지 않는다.

### 기존 장면의 실제 진행

**EP004A-01 · 내 이름을 빼고 남는 몫**

- B1: 실제로 미이행한 약속이 있을 때만 그 한 건의 말과 현재 결과를 나누어 말한다. 구체 예시는 오늘 자기가 맡은 물건 반환을 늦춘 경우에만 쓰고, 그런 이력이 없으면 지금의 가상 비유임을 밝힌다. 상대가 떠맡은 기다림과 본인이 아직 가진 물건을 각각 돌 옆에 표시한다.
  실제 변화: 두 돌 사이에 빈 간격이 생긴다. 신 이름이 없어도 남는 플레이어의 말 한 줄이 드러난다.

- B2: 당사자의 실제 답 중 아후라 마즈다에게 전해도 되는 부분만 읽는다. 반환·보완 행동을 했다면 실물 인수나 직접 관측과 자신의 주장을 구별한다. 예컨대 실제 반환은 끝났으나 기다린 손해에 대한 대화는 거절됐을 경우, 반환한 물건의 자리를 비우되 상대의 거절 돌은 그대로 둔다.
  실제 변화: 아후라 마즈다가 자신의 이름을 적은 면을 뒤집고 완료 몫의 돌만 옮긴다. 미완료 돌은 남는다.

현행 완료 보강: B2 변화=(실제 이행 증거 또는 자기 주장으로 한정된 진술) AND 공개 가능한 당사자 답의 실제 수신. 실제 반환 인정은 실물 인수 증거가 있을 때만이다. 가상 비유는 대화로 끝나며 실제 이행 기록으로 승격하지 않는다.

선택 일상:
- 나뉘는 이야기: 꽃숲의 이미 열린 산책길에서 플레이어는 강 쪽과 언덕 쪽 중 보이는 구간을 설명한다. 아후라 마즈다는 어느 결말이 더 재미있는지 자기 취향만 말한다. 잡담만 하거나 실제 짧은 왕복을 제안한다. 대화는 시험 통과 없이 끝날 수 있다. 걸었을 때만 그 구간을 서로 본 기억이 생긴다.
- 통이 지나갈 폭: 실제 운반 중인 물통이 있다면 플레이어는 마른 둑의 폭과 보트가 닿을 물가를 직접 살핀다. 이미 안전한 길은 다시 수리하지 않는다. 도보 길을 고르거나 자기 보트로 왕복하고, 준비가 부족하면 돌아온다. 확인한 이동 가능성만 남는다. 신의 말 한마디로 좁은 길이 넓어지지는 않는다.
- 판정 뒤의 손: 미트라의 설명과 라슈누의 판정이 실제 전달되었을 때만, 아후라 마즈다는 그 결론 뒤에 남은 운반·수선 담당을 묻는다. 플레이어는 자기 몫만 맡거나 참여를 거절한다. 타인의 동의를 대신하지 않는다. 실제 수행한 물자 이동은 남고 판정 공로는 라슈누에게 둔다. 이행하지 않은 약속은 완료가 아니다.
- 다른 결말로 돌아옴: 재방문에서 당사자가 실제로 겪은 결과를 말하면 아후라 마즈다는 처음의 비유와 달라진 지점을 듣는다. 잘 안 된 부분까지 말하거나 오늘은 풍경만 보고 간다. 스스로 정정한 말을 실제 들으면 조언부터 하지 않고 다음 해법을 먼저 듣는다. 세계 해금과 무관한 개인 신뢰 변화다.

## 라슈누 · RPG-S12-005

강변의 평평한 돌에서 크기가 다른 돌 두 개의 균형을 살핀다. 돌놀이를 망쳤다는 이유로 유죄 판정을 하지 않는다.

장소: 최초 조우는 강변 생활권의 안전 공용 공간, 재심은 동일 생활권 평평한 돌 위다. 실제 강을 건너는 관측은 그 통행 구간의 시야에서 별도로 하며 탁자 위 제출과 같지 않다.
세계 해금: 누구 한 명이 강을 건너기 전 마른 복귀 발판을 확인하고 안전 구간을 한 번 실제 왕복하면 전역 해금한다.
현재 조우 주체: 현재 강변 공용 공간에 도달하고 자기 기록 또는 허락받은 기록의 약속·이행을 구분해 제시하거나 직접 대조하는 사람. 실제 분쟁이나 유력자 보증은 필수가 아니다.

### 기존 장면의 실제 진행

**EP030A-RPG-S12-005 · 길을 돌려주는 재심**

- B1: 신규 저술안의 제안은 다음과 같다. 라슈누는 미트라에게 실제 받은 계약과 청원자의 이행 흔적을 나란히 놓고 플레이어에게 자신이 직접 본 사실만 말하게 한다.
다음은 선택 경로별 실제 행동이며 서로 모두 수행할 조건이 아니다:
직접 본 이행과 약속을 나눈다: 실제 받은 계약과 허락된 이행 흔적을 나란히 놓는다. 플레이어는 직접 본 행위의 대상과 시점을 말하고 전언은 출처를 따로 밝힌다. 라슈누는 미트라에게 실제 연락 가능한 경우만 반대 근거를 묻고 미수신 항목을 빈 채 둔다.
  실제 변화: 직접 본 이행과 약속을 나눈다: 비교한 조항과 직접 관측·전언·미확인 항목이 분리된다. 판정 철회는 아직 없다.

- B2: 증거가 충족되면 여행을 막은 자기 판정을 그 범위만 철회하고, 모자라면 제한을 넓히지 않은 채 보완할 사항을 당사자에게 직접 말한다.
다음은 선택 경로별 실제 행동이며 서로 모두 수행할 조건이 아니다:
충족한 범위만 판정을 철회한다: 이번 이동을 막은 자기 판정의 근거와 실제 충족 증거를 라슈누가 대조한다. 해당 재심에서 미트라에게 물은 반대 근거의 실제 응답이 필요한 허가 변경은 현재 쟁점에 유효한 그 응답을 실제 수신했을 때만 진행한다. 이미 유효하게 받은 응답은 상대의 현재 부재 때문에 다시 요구하지 않는다. 필요한 응답이 없으면 이 철회는 보류하고 부족한 근거를 남기는 보완 경로로 간다. 일반 대화·증거 분리·이미 입증된 이행 기록은 계속 가능하며 별도의 선택적 후속 인계 전체를 필수로 만들지 않는다. 그 제한을 수정할 권한과 증거가 실제 있는 범위만 철회를 직접 고하고 해당 당사자가 그 통지를 받는다.
부족한 근거를 남기고 재심을 연다: 실제 부족한 이행 흔적이나 미트라의 미수신 답을 항목별로 당사자에게 말한다. 라슈누는 제한을 새로 넓히지 않고 보완 후 다시 볼 항목을 남긴다.
보지 않은 이행을 봤다고 말한다: 직접 보지 않은 일을 목격한 것으로 실제 진술하고 모순이 확인되면 라슈누가 그 진술을 근거에서 제외한다. 가정 질문이나 단순 추측은 허위 진술로 단정하지 않는다.
  실제 변화: 충족한 범위만 판정을 철회한다: 해당 판정 철회와 실제 통지 수신만 성립. 모든 여행의 자동 허가 아님.
부족한 근거를 남기고 재심을 연다: 판정 유지와 보완 요청만. 무죄·철회 성공 없음.
보지 않은 이행을 봤다고 말한다: 해당 진술 제외. 판정은 그 허위 말로 바뀌지 않는다.

- B3: 선택 경로의 실제 결과와 미완료를 구분하고 실제 허락된 현재 청중에게만 확인한다. 계약 열람·진술 공개 허락 범위만 사용한다. 판정 수정은 해당 당사자의 권리 회복이며 플레이어 통행 독점권·보상·MAIN이 아니다. 미트라 부재의 반대 답을 생성하지 않는다.
  실제 변화: 실제 선택·실행한 경로의 결과만 확인한다. 아래 서로 다른 결과를 동시에 부여하지 않는다.
충족한 범위만 판정을 철회한다: 해당 판정 철회와 실제 통지 수신만 성립. 모든 여행의 자동 허가 아님.
부족한 근거를 남기고 재심을 연다: 판정 유지와 보완 요청만. 무죄·철회 성공 없음.
보지 않은 이행을 봤다고 말한다: 해당 진술 제외. 판정은 그 허위 말로 바뀌지 않는다. 실제 수령·수강 또는 그 거절은 별도로 남는다.

현행 완료 보강: 철회=(해당 제한 수정 권한 AND 현재 쟁점의 충족 증거 AND (반대 응답 불필요 OR 현재 쟁점에 유효한 반대 응답 실제 수신) AND 라슈누의 해당 제한 철회 실제 결정·고지 AND 해당 당사자의 실제 통지 수신). 증거 정리·통지 준비만으로 철회0. 보완=(부족한 근거 또는 필요한 답의 미수신 확인 AND 라슈누의 부족 항목 실제 설명 AND 해당 당사자 수신); 기존 제한을 유지하며 새로 넓히지 않는다. 철회 OR 보완은 별도 결말이고 부분·미수신은 완료가 아니다.

선택 일상:
- 짝이 아닌 돌: 플레이어는 강변 돌의 모양을 보며 라슈누가 맞춘 균형을 구경한다. 손대도 되는 돌만 옮겨 보거나 구경으로 끝낸다. 균형을 무너뜨려도 도덕시험 실패가 아니다. 라슈누는 다음 배치를 혼자 다시 고른다.
- 다녀온 발판: 현재 통행 판정에 다툼이 있을 때 플레이어는 실제 건널 수 있는 마른 둑을 보고 자기 왕복 결과만 말한다. 조사를 맡지 않아도 일반 대화는 가능하다. 새 이동 증거와 계약 이행 증거는 구별한다. 이 탐험만으로 기존 제한이 자동 철회되지는 않는다.
- 보증인의 이름을 가림: 미트라가 실제 전달한 계약과 당사자의 이행 설명을 나란히 놓고 라슈누는 쟁점 한 문장만 비교한다. 근거가 충족되면 해당 자기 판정을 고치고, 부족하면 남은 질문만 밝힌다. 한 범위의 여행 제한만 실제 철회될 수 있다. 무죄 전역 선언·새 MAIN·물품 지급은 없다.
- 덜 묻는 재심: 이전 사실을 정확히 설명한 플레이어가 돌아오면 라슈누는 그가 이미 말한 부분을 반복 심문하지 않는다. 새 사실이 없으면 재심을 보류하고 강돌 이야기로 돌아간다. 신뢰는 말할 기회의 여유로 표현된다. 우정이 증거의 무게를 올리지 않는다.

## 앙그라 마이뉴 · RPG-S12-008

교역길 돌턱에서 문서의 앞줄만 읽다 악역의 변명을 다른 어조로 되풀이한다. 자기 놀이에 참여하지 않는 방문자를 반드시 유혹 과제에 묶지 않는다.

장소: 황무지와 연결되는 기존 교역길 돌턱을 최초 현장으로 선택한다. 발견된 폐허가 있어도 길 쪽으로 두 걸음 물러날 통행 여유를 보존한다. 후속 비용 설명도 같은 본체의 현재 접촉이 있는 곳에서만 한다.
세계 해금: 누구 한 명이 황무지 폐허와 이어진 실제 통행 경로 두 갈래를 발견하면 전역 해금한다. 배신·유혹 수락은 불필요하다.
현재 조우 주체: 현재 황무지와 이어진 교역길 돌턱의 안전 통행부에 도달해 자기/허락 기록의 생략 여부를 대조하는 사람. 타인 비밀·미트라 계약 원본 강제 제출0.

### 기존 장면의 실제 진행

**EP004A-03 · 손해 뒤에도 남은 약속**

- B1: 가린 줄을 보여 달라 요구하거나 자기에게 허락된 같은 약속 원문을 펴서 문장 끝을 손가락으로 따라간다. 실물 없이 기억으로 반박하면 기억이라고 밝힌다. 앙그라 마이뉴가 유리한 앞줄만 읽었다는 사실과 약속 자체가 거짓이라는 주장을 구별한다.

바깥에서 대치한다: 바깥 접촉만 성립. 안쪽 조건 수락과 AND 아님.

## 잘 · RPG-S12-011

### 기존 장면의 실제 진행

**EP030A-RPG-S12-011 · 가려진 자리의 등불**

방문을 막고 저녁 돌봄을 실행한다: 실제 식사 수령·쉼 범위만. 잘의 돌봄과 플레이어 도움은 각자 기록.

**EP030A-RPG-S12-012 · 손님이 떠날 수 있는 초대**

- B1: 신규 저술안의 제안은 다음과 같다. 루다베가 초대할 상대에게 머물 시간과 돌아갈 시각을 직접 묻고 플레이어가 중개를 맡으면 상대의 답을 실제 가져온다.

## 카이 카부스 · RPG-S12-017
