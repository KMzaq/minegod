누구 한 명이 기존 접근 가능한 해당 장소에 실제 도달해 원문 공개 단서를 관측하면 전역 영구 개방. 이미 유효한 초기접근·배치·해금 기록은 그대로 인정하고 새 행동을 소급 요구하지 않는다.

현재 원문 차원의 접근 가능한 장소에 실제 도달한 한 사람. 안전·현행 봉인·본체 일정·원문 접근조건 확인 후 공통 확률풀 대상. 기존 본체가 이미 배치됐으면 새 추첨 없이 접촉.

개별 일반 조우 장 번호는 확정하지 않는다. 현재 현장까지 실제 도달하고 배우가 활동 중이면 접촉 후보다. 과거의 미작성 분류를 새 전역 금지로 읽지 않는다.

마당의 공개길에서 목소리가 새지 않는 실제 사적 청중을 확인한다. 사적 전달 기능이 없으면 가족 내용 발화0. 봉투가 실제 위탁됐을 때만 물건 인수 거리를 검사한다.

수신자 한 사람별 허락된 문구·공개 범위·전달/비전달·실수령을 나눈다. 카르나·비마·아르주나 동의를 합산하지 않는다. 거절은 편지를 놓고 가는 허락이 아니다. 답 없이 청취만 성립한 결말도 정상이다.

3~8분; 이동·응답 대기 별도. 가족 고백 보상0.

### 열지 않은 편지 · EP017B-RPG-S05-033

공개길에서 떨어진 거처의 조용한 마당. 문 안쪽의 대화 자리가 실제 사적 청중을 보장할 때만 내용을 읽으며, 없으면 접힌 편지는 탁자 위에 둔다. 기존 거처의 공개길에서 떨어진 조용한 마당의 현장 유형. 실제 기존 부지 등록 연결 대기이며 새 차원·대규모 건축·가상 좌표가 아니다.

- B1: 내용을 듣기 전 현재 들을 사람과 범위를 확인한다. 허락된 부분만 실제 듣거나, 내용을 읽지 않고 봉투 전달 의향만 말한다. 공개 공간이면 편지는 열지 않는다.

  - 실제 범위: 한 번에 해당 수신자와 실제 합의한 주제만. 가족 이름을 나열해 모두의 동의를 묶지 않는다.

  - 현재 허락한 부분만 듣는다: 합의한 부분을 실제 듣고 어느 문장까지 전달해도 되는지 다시 구분한다. 들은 것을 정리하더라도 당사자의 뜻을 덧붙이지 않는다. → 실제 받은 내용만 지식. 다른 가족의 청취·답·편 선택은 미확인이다.

  - 편지를 열지 않고 전달만 논의한다: 봉투를 닫은 채 수신자에게 연락 의사를 물어볼지 정하고 내용 없는 요청 문구만 쿤티와 확인한다. → 편지 내용 지식 없음. 맡겠다는 의향만으로 실제 인도·수신 없음.

- B2: 해당 자녀 한 사람에게 지금 들을 의사와 범위를 묻는다. 거절하면 편지를 넣어 두지 않고 돌아오며, 동의하면 합의한 범위만 사적으로 실제 전달한다.

  - 실제 범위: 현재 한 수신자가 허락한 범위만. 부분 동의에는 그 부분만 전하며 다른 사람의 고백 내용을 보태지 않는다.

  - 거절을 지키고 편지를 돌려준다: 거절 또는 미접촉 상태를 구분해 쿤티에게 알려 주고 실제 맡은 봉투만 돌려준다. 맡지 않았다면 미전달 상태만 말한다. → 거절이면 거절, 부재면 미접촉. 고백 전달·청취·화해 없음.

  - 동의한 범위만 실제 전한다: 해당 부분을 실제 읽거나 본인이 청취하도록 전달한다. 답은 청할 수 있으나 강요하지 않고 전달 허락을 받은 답만 가져온다. → 실제 들은 부분만 수신자 지식. 답하지 않음·편 선택 보류도 그대로 유효하다.

- B3: 직접 본 전달·수신과 상대의 허락된 답만 쿤티에게 전한다. 쿤티가 책임질 말만 남기고 다음 접근을 재촉하지 않는지 현재 대화에서 확인하며 마친다.

  - 실제 범위: 현재 수신자의 이번 범위만. 다른 자녀에게 결과를 자동 공유하지 않는다.

  - 거절·미전달 결과를 그대로 마친다: 상태를 정확히 전하고 실제 반환된 편지는 쿤티 곁에 둔다. 새 접근은 상대가 허락한 범위를 넘지 않게 보류한다. → 거절·미전달의 결말 유지. 가족 화해·고백 완료·보상 없음.

  - 실제 청취 사실만 남기고 답을 재촉하지 않는다: 실제 전달한 범위와 답 유무만 보고한다. 쿤티가 다음에 말할 주제도 수신자가 허락한 것만 남긴다. → 청취·답/무응답이 구별된다. 더 듣지 않겠다는 경계도 유지하며 편들기 의무 없음.

결말: 실제 수신자가 듣겠다고 정한 범위만 전달된 경우 그 전달 결과를, 거절·부재면 되돌려 보관한 결과를 각각 남긴다. 듣고도 답하지 않는 것은 유효하며 자녀의 편 선택·화해·모든 가족의 청취를 요구하지 않는다.

재회: 쿤티는 잔을 다시 감싸고 “나는 말했다”보다 “그가 어디까지 듣기로 했는가”를 먼저 묻는다. 거절한 사람의 다음 답을 재촉할 편지를 덧쓰지 않는다. 선택 질문·답변(현재 대면 중, 질문하지 않아도 진행 가능): “그러면 누구 편인가?”라면 현재 고백을 편 선택의 조건으로 거래하지 않겠다고 자기 결정을 말한다. 이 반응은 실제 그 사람과 해당 일을 겪거나 유효 보고받은 경우만. 첫 방문자는 현재 상황부터 설명한다.

현재 분기 해석: 수신자의 거절 OR 현재 접촉·사적 전달 불가는 미전달로 닫을 수 있는 정상 대안이다. 실제 위탁·현 보관자·실반환을 확인하며 편지를 맡지 않았거나 수신자가 보관 중이면 복제 반환하지 않는다. 한 자녀의 동의와 기억을 다른 자녀에게 복사하지 않는다.

### 서약 앞의 빈 자리 · EP017B-RPG-S05-038

기존 길목 그늘의 대면 자리. 비슈마의 자리 맞은편을 비워 시칸디가 앉거나 서거나 그대로 떠날 수 있고 청원 내용을 들을 자격 없는 통행인은 바깥길로 지난다. 기존 길목의 그늘진 대면 자리의 현장 유형. 실제 기존 부지 등록 연결 대기이며 새 차원·대규모 건축·가상 좌표가 아니다.

- B1: 시칸디가 허락한 청원만 읽고 이미 답이 있는 대목과 아직 직접 답하지 않은 대목을 짚는다. 시칸디가 현재 만나려는지 실제 확인한다.

  - 실제 범위: 현재 청원 한 건의 허락된 범위. 옛 운명·죽음·전투를 현재로 재연하지 않는다.

  - 현재 청원에서 빈 답을 짚는다: 허락한 문장을 읽고 그 요구에 직접 대응한 답이 무엇인지 묻는다. 실제 면담이 성립하면 당사자에게 발언을 돌려준다. → 답이 있는 부분과 없는 부분이 드러난다. 아직 화해·서약 변경은 없다.

  - 면담이 없으면 요청만 보관한다: 현재 이름을 존중한 내용 없는 면담 요청이나 허락 청원만 실제 보관한다. 허락 없는 내용을 공개하지 않는다. → 요청 보관만. 시칸디의 출석·응답·청원 해결 없음.

- B2: 현재 청원의 허락된 한 대목에 직접 답해 달라고 요청한다. 비슈마가 서약을 그대로 유지하며 가능한 행동·거절 이유를 구체적으로 말하도록 기다린다.

  - 실제 범위: 이번 청원의 해당 요구만. 서약 변경이나 역사 수정은 새로 확정하지 않는다.

  - 구체적 답을 요청하고 실제 답을 듣는다: 허락 요구를 짚어 묻고 비슈마가 할 수 있는 일·할 수 없는 일·이유를 실제 말하게 한다. 자신의 결정을 대신 쓰지 않는다. → 직접 답한 범위만 확인된다. 상대 수긍·화해는 아직 없다.

  - 서약만 되풀이한 거절을 기록한다: 그 말을 실제 듣고 청원의 어느 요구가 답을 받지 못했는지 허락 범위에서 명확히 남긴다. → 거절·미해결 청원. 긴 발언을 해결·화해로 표시하지 않는다.

- B3: 시칸디의 현재 말을 끊지 않고 듣고 떠나려면 길을 비운다. 비슈마에게 다음 청원도 직접 받을지 물을 수 있으나 이를 화해 조건으로 삼지 않는다.

  - 실제 범위: 이번 실제 답과 실제 반응 범위. 용서·정체 폭로·재대결을 강제하지 않는다.

  - 수긍이나 반박을 그대로 듣는다: 실제 반응을 듣고 서로 다른 의견은 다른 채로 남긴다. 비슈마가 받은 응답 범위만 이후 기억에 반영한다. → 수긍·반박 각각의 결과. 어느 쪽도 자동 화해·서약 변경이 아니다.

  - 퇴장·무응답을 허용하고 마친다: 길을 비키고 요청 기록의 현재 보관을 허락대로 정리한다. 뒤따라가 답을 강요하지 않는다. → 실제 직접 답 또는 거절 결과와 청원인의 퇴장·무응답이 함께 남는다.

결말: 시칸디의 실제 허락 청원을 비슈마가 듣고 구체적 답 또는 거절을 직접 한 결과를 남긴다. 시칸디의 수긍·반박·퇴장은 별도 실제 선택이다. 부재·면담 거절에는 요청 보관만이며 면담·해결 완료를 부여하지 않는다.

재회: 비슈마는 시칸디가 나가는 동안 대리인을 부르려던 손을 내린다. 직접 답한 가지라면 다음에는 아직 답하지 못한 부분부터 들으려 한다. 선택 질문·답변(현재 대면 중, 질문하지 않아도 진행 가능): “이제 화해했나?”라면 자신이 한 답과 상대가 실제 한 말을 나누어 말한다. 이 반응은 실제 그 사람과 해당 일을 겪거나 유효 보고받은 경우만. 첫 방문자는 현재 상황부터 설명한다.

현재 분기 해석: 같은 시칸디 청원 면담은 동일 면담 ID와 실제 발언 영수증을 재사용한다. 직접 답 OR 실제 회피 OR 면담 부재를 구별하고 시칸디의 수긍·반박·무응답·퇴장은 각각 본인의 실제 선택이다.
