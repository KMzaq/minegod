# 여우신 지식 전달

정적 profile에 사적 미래 사실 자동 적재0. 알려진 자기 경험과 NPC가 아는 것·공개 허락은 각각 별도.

SET_FACT와 GRANT_KNOWLEDGE 별도. 실제 canonical 발언 수신과 직접 관측 기록에 화자/대상/청중/시점/출처를 붙인다. 파티/후발자/문서 존재만으로 획득0. 일반 전언은 전언으로 저장. 미공개 이름은 알고도 말하지 않는 범위이며 새 이름·생사·혈연을 채우지 않는다.

흡수 대상 보호 검사는 서버가 모든 플레이어(오프라인 포함)의 실제 대화 이력 AND 현재 비적대 관계 중 하나라도 있는지 검사한다. 친구가 아닌 모든 관련 플레이어 대상. 단순 거절·미접속은 적대가 아니다. 보호검사를 여우신의 NPC 지식으로 공급하지 않는다.

FOX-FACT-MAIN-OWNER: 첫 유효 MAIN 수락자 UUID 1명
획득: C15/실제 자료/신호/준비/본체 제안/명시수락 원자 성공
청중: 당사자와 여우신; 서버 소유원장은 지식 방송 아님

FOX-FACT-EMBER: 단일 불씨의 발견/안정/보존/풀기/유예
획득: 각 M 단계의 실제 관측/실행 커밋
청중: 여우신과 직접 관측한 적격 소유자; 공용 길 상태만 관측자에게 공개. 발신자 생사 미확정

FOX-FACT-GROWTH: 실제 여우신 본인의 현재 성장
획득: 기존 독립 성장 시스템의 유효 결과만
청중: 본인의 직접 경험; 훈련은 이 필드를 읽거나 쓰지 않음

FOX-FACT-ADDRESS: 동일 소유자 M05 보존/풀기 완료 AND 여우신 실제 초월급
획득: 두 조건 뒤 다음 실제 재회
청중: 해당 소유자에게만 관계 표현; 다른 사람에게 호칭 자격 복사0

FOX-FACT-TRAIN-W: 본인의 사선 연습과 같은 부채 인수 여부
획득: W1–W4 증거와 실수령
청중: 수련자/현장 여우신; 참관자는 본 범위만

FOX-FACT-TRAIN-L: 본인의 제한 형태 연습과 기술 습득 여부
획득: L1–L3 증거와 learn receipt
청중: 수련자/현장 여우신; 참관이 습득은 아님
