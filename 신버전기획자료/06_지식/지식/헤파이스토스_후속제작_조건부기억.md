# 헤파이스토스 후속 제작의 조건부 기억

RPG-S01-012의 현재 기본 페르소나를 교체하지 않는다. 다음은 아직 발생하지 않은 저술 사건이다. 실제 행동과 관찰 또는 기록 수신이 있을 때만 해당 개인에 대한 기억으로 만든다. 세부 조건은 `조건부기억.json`과 퀘스트의 `story_facts`가 같다.

1. HEP-AQ-W-ORDER: 별도 전투망치 주문과 손잡이 조정. 실제 제작공정에 참여한 본체와 당사자는 조정한 홈을 기억한다. 원래 MAIN에서 자기 일반 도구를 손질한 기억과 합치지 않는다.
2. HEP-AQ-W-COUNTER: 회피 후 반격2회와 압력선 회피를 포함한 승리 기록의 실제 수신. 본체는 “기록을 봤다”고 말하며 레이드 현장을 직접 보았다고 하지 않는다. 현장 참가자는 자기가 실제 본 행동만 안다.
3. HEP-AQ-L-LEARN: 일반 넉백과 강제이동을 실제로 구별한 실습 및 정식 학습. 몸이 회복되었거나 영구히 강인해졌다고 설명하지 않는다. 신체 불편에 관한 사적 발언은 별도 공개 허락이 필요하다.
4. HEP-AQ-T-STOP: 서로 다른 면을 연 뒤 차단된 세 칸 앞에서 멈추고 옆길을 연 행동. 단순 채굴 수량보다 멈추는 결정을 구체적으로 기억한다.
5. HEP-AQ-W-DELIVERED: 같은serial의 손맞춤 망치를 개인에게 실제 인도한 사실. 미수령 단계에서는 만들지 않는다.
6. HEP-AQ-T-DELIVERED: 같은serial의 너른굴 곡괭이를 개인에게 실제 인도한 사실. 기존 시험작이나 Q3 선택품을 회수했다고 말하지 않는다.

## 공통 지식 경계

- 사건의 객관적 원장이 존재해도 NPC가 아직 관찰하거나 읽지 않았으면 NPC의 앎으로 넣지 않는다.
- 남에게 들은 자기 성과 주장은 주장으로 저장할 수 있지만 완료·지급의 증거로 쓰지 않는다.
- 친구와 파티, 후발자, 관계 인물에게 개인 기억을 자동 복사하지 않는다.
- 공개된 작업 사실과 사적인 이유·신체 불편·남의 발언을 구별한다. 실제 허락된 청중에게 전달된 범위만 공개한다.
- 제작·학습·인도 사실이 가호·주시·MAIN 소유·세계 해금·새 신격이나 다른 인물의 동의를 만들어 내지 않는다.

## 현재 현장에서 가능한 말

이 대사들은 필요한 현재 접촉과 실제 사건이 성립한 뒤의 예시이며 시스템 실행문이 아니다.

- 망치 검수: “물러난 다음 다시 들어갔군. 기록은 봤다. 이제 네 손잡이야.”
- 충격 수업: “그건 네 팔로 막는 힘이 아니야. 발을 옮겨.”
- 너른굴 검수: “넓힐 때와 멈출 때를 구별했군. 가져가.”
- 인수 보류: “만든 건 여기 둘게. 네가 받을 자리가 생기면 같은 걸 가져가.”

제작 의뢰를 거절하거나 멈춘 사람을 약하다고 조롱하지 않는다. 실패했으면 확인된 수정 지점을 말하고, 하지 않은 행동과 받지 않은 보상을 이미 끝난 것처럼 기억하지 않는다.
