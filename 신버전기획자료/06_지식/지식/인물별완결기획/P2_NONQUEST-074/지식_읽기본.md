- 문서성격: 현재 채택된 저술·구현 요구. 실행 스키마·지원 API 선언이 아니며 실제 게임/API/LLM/영상/5인 서버 시험은 미실행이다.
- 우선순위: 현재 정체·원문 exact encounter/first contact·발화·생사·봉인 > 보존 에피소드의 원래 정상/부분/거절 경로 > adopted_detail의 실행 구체화 > 일반 기본값. source_contract와 retained_profile은 원문 동등 보존이며 과거 미채택 상태를 소급 고치지 않는다.
- 조우운영:
  - reference: 퀘스트/공통설계/시간_조우_성장_운영정책.json#/general_encounter 및 /atomic_contract
  - rule: 일반 무작위 허용 경로만 300 활동초 창·서버25%·현재 전투등급 가중치·실제 등장 뒤 1800 가동초 공용 쿨을 재사용. 개인별 확정/전용/고정/기록/봉인 접촉은 일반풀로 바꾸지 않는다.
  - world: 누구 한 명의 실제 유효 해금으로 world_uuid+canonical_actor 세계 영구 해금. 기존 초기 접근은 새 잠금0. 조우 주체는 현재 조건을 맞춘 실제 사람이며 해금자와 달라도 된다.
  - body: 최초 미배치, 미로드, 현존, 봉인, 사망을 구별한다. 미배치는 본체 선존재를 요구하지 않고 현재 배치가능 부지만 검사. 미로드는 저장된 같은 개체를 복구하며 새 본체 생성0. 사망·봉인은 일반 재등장으로 우회0. CAS·추첨 journal·재시작 대조는 참조 정책 그대로.
  - contact: 이미 배치된 같은 본체에는 새 추첨·개인 재해금 없이 접근한다. 다른 사람의 인사도 현재 모드·안전·청중·의사 범위만 가능. 비언어/제한 접촉/기록 예외가 일반 인사보다 우선한다.

  - rule: 정상 OR 분기는 각각 완결. 선택 후기·사본·관계 인계는 완료에 추가 AND로 붙이지 않는다. 미인수는 실패가 아니며 명시 수령 거절과 보류를 구분한다. 동일 request_id+owner+original_instance에 원물·소비·인수 receipt를 결속한다.
  - interrupt: 거절·침묵·중단·사망·로그아웃은 이미 수행·수신·소비한 부분을 보존한다. 재접속은 현재 접근과 미이행 부분만 재검사. 해금·개인 관계·권리 초기화0. 불확실 인수에는 원장/실물 대조 전 복제0.
  - time: 별도 원문 마감이 없으면 시간 제한 없음. 예측 분량은 정적 설계 예상일 뿐 실측 아님.
  - distance: 집기·수선·인계는 기본 2블록 실제 접촉, 일반 말은 시야와 실제 음성 수신 내 기본 8블록. 멀리 보기·이동·노래·전용 비언어 감각은 각 장면 범위이며 2블록을 일률 강제하지 않는다.
  - multiplayer: 한 본체의 현재 사건을 순서대로 공유한다. 동시 반대 조작은 revision으로 직렬화. 후발자는 현재 상태를 보고 자기 참여만 기록하며 이전 기여·MAIN·보상·사적 기억을 상속하지 않는다.
- 지식: 저자 진실, 전승 자기 기억, 현재 직접 관측, 출처 있는 보고, 추론, 미발생 미래를 분리. fact_event+speaker/source+receiver+actual_audience+permission+received_at를 기록한다. 실제 수신 전 NPC가 알지 않으며 무허가 청중이 들어오면 비공개 발화를 보류한다. 파티·공개방 이름·세계 해금은 수신권이 아니다.
- 관계와힘: 같은 거친 말도 실제 친분·맥락·신뢰 침해에 따라 반응한다. 관측한 힘·존중·친밀함·두려움·정치 소속을 합치지 않는다. 숨은 CP 읽기0, 강자에게 자동 복종·보상0.
- 보상범위: 개인 MAIN과 새 SIDE를 강요하지 않는다. 원문 NONE은 무보상, APPLICABLE 생활서비스·허락 현물은 실제 범위로 채택한다. 새 성장·가호·무기·독립 스킬0. 도구 수리는 원물 반환이며 신이 손댔다고 인간제 원도구를 무한내구화하지 않는다.
