## 황제 · RPG-S06-005

저자 진실과 미래 분기 내용을 NPC 기본지식으로 자동 변환하지 않는다. 현재 대사는 profile과 실제 자기 경험, 허락된 전달 수신만 사용한다. 개인 가족·청원·모욕의 내용은 허락 청중만.

실제 존재하는 공개 기록은 본체 부재에도 열람권/자료 접근이 있으면 읽을 수 있다. 읽은 사람만 그 기록의 주장과 출처를 배우며 사건 체험 기억은 얻지 않는다.

원청중에게 정정이 실제 전달된 범위만 지식 수정; 원래 수신한 주장과 진실 여부는 별도 저장.

- 사건: 이번 실제 개인 선택과 결과: 공개 인정은 상징적 손실과 발언 기록을, 조용한 문구는 한정 권리의 실제 협의 가능성을 남긴다. 황제가 거부하면 미합의가 남고 플레이어의 웅변으로 전후 체제가 바뀌지 않는다.

  - 수신: 황제와 해당 행동을 실제 보고 듣거나 허락된 기록을 읽은 플레이어·당사자만.

  - 공개: 공개 물건 상태는 현장에서 확인 가능하다. 사적 발언은 실제 청취자에게만, 외부 전달은 당사자가 허락한 범위·출처만 제공한다. 후발자는 현재 결과와 공개 가능한 기록을 새로 읽어 배우며 친구의 기억은 받지 않는다.

- RPG-S06-006: 삭제하지 않은 이름과 거주 쟁점의 한정 수정안를 실제로 요청한다. 수신 후 상대가 수락·범위 수정·거절한 말만 응답으로 남긴다.

  - 부재·거절: 부재·거절이면 이 상대의 동의·효과는 미성립이다. 공개 조사와 자기 권한의 작업은 계속하고, 필요한 이행·정산만 보류하여 같은 요청의 변경 부분부터 재방문한다.

현재 결과 기록: 아래 새사건은 원문에 보존된 조건부 결과 요약이지 선택 클릭으로 지급하는 사실 목록이 아니다. 실제 해당 episode의 available_when AND actual_execution AND observed_result가 확인된 범위만 개인 지식으로 기록한다. 정상 대안은 OR로 유지하고 STOP·거절·미수신·부분 수행을 성공으로 바꾸지 않는다. 전언 수신자는 전언으로만 기억한다. 공개 허락된 이름의 실제 낭독·황제의 인정 또는 거절과 생활 수정안의 실제 수신·응답은 대안 경로다. 추가 게시·반환은 위탁물과 허락이 있을 때만 한다. 한정 협의 가능성을 발효된 거주권·상대의 복종·화해로 바꾸지 않는다.
