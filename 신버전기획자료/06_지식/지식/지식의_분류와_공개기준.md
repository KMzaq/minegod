# 지식의 분류와 공개 기준

1. 고정 로어: 확정된 세계 사실이라도 모든 NPC가 아는 것으로 간주하지 않는다. 인물별 출처와 알게 된 범위가 필요하다.
2. 조건 공개: 출처·접촉·현재 청중·동의·진행 조건이 충족된 내용만 공개한다.
3. 개인 기억: 해당 NPC 또는 플레이어가 실제 겪거나 수신한 사건만 기록한다. 동료의 기억이나 공용 완료를 복사하지 않는다.
4. 미확정 사건: 미래 계획·제안·소문·분기는 완료 사실과 구분하며 사전 기억으로 넣지 않는다.

각 지식 항목에는 fact_id, record_key, category, truth_status, source, learned_when, disclosure_condition, audience, revision이 필요하다. 분류와 출처 검토를 통과한 항목만 NPC 입력으로 사용한다. 이 기준 문서는 완성된 NPC 지식 데이터가 아니다.
