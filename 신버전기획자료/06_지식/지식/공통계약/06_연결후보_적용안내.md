# 현재 연결 후보와 원문 참조 보존

## 사건 연결
현재 사건 후보는 기존 406참조를 그대로 연결하고 41개 편집 위치를 추가한 총447참조다. 대상은37패킷이며, 작성 중 다른 패킷의 통합 상태가 늘어나도 이 숫자를 전체 사건 검수 수로 확대하지 않는다.

- 032·033: 23인물의 story_fact. event 문자열은 설명이며 Fact ID가 아니다. 원문에 없는 게임 ID를 발급하지 않았다.
- 034: 11인물의 knowledge. 원문 fact_id는 그대로 적되 등록된 런타임 ID라고 주장하지 않는다.
- 096: 여우신 기존7장면의 contract/information. 지식·공개 제약을 찾는 편집 참조이며 7개의 신규 Fact를 발급한 것이 아니다.

현재 통합수는 03의 scope.integrated_packets_at_snapshot에서, 이 후보가 실제 다루는 패킷은 scope.candidate_covered_packets에서 별도로 확인한다. 향후 추가 통합분과 미작성 잔여 패킷을 연결·검수해야 한다. 기존 인물별 지식772·원래 사건색인·인물색인은 수정하지 않았다.

## 원문 제약의 최종 묶음 내 연결
04는 현재 참조 수요가 확인된20인물의 접근·표현 제약40개를 원문 값 그대로 선택 보존한 자료다. 전체 authoring_contract나 내부 검수 기록을 복사하지 않았다. 05의 exact_additions는 이40개와 기존 지식 자료 안에 이미 보존된 knowledge_routes20개를 정확한 위치로 연결한다. 기존 프로필751+제작범위739의1490개 연결을 변경하거나 대신하지 않는다.

다그다 원문은 first_contact_original_contract/presentation_boundary 및 /eligibility라는 구조다. 다른19인물은 실제 원문에 expression_contract 및 exact_access_baseline이 존재한다. 이름이 비슷하다고 전 인물을 한 구조로 바꾸지 않는다. 없는 포인터는 있는 것처럼 성공 처리하지 않는다.

현재 정체·생사 확인에는 페르소나/인물의 current_identity와 현재 접근·제작 분류를 우선 확인한다. 05의 frozen_identity 관련20개 제안은 현재 정체로 읽는 목적의 의미상 참조 변경 제안이지, 과거 frozen_identity 전체가 동일값으로 보존됐다는 별칭은 아니다. 역사 정체 컨테이너 전체가 필요한 작업은 원문 필드별 추가 보존 검토를 거친다. 현재 정체를 과거 필드로 되돌리지 않는다.

이 묶음 내부 대상 파일은 target_base가 ‘이 후보 묶음’이다. 통합자가 파일을 최종 폴더에 배치할 때 document만 실제 최종 논리 위치로 바꾸고, 원문값과 JSON Pointer가 같은지 다시 검증한다. 기존 지식 파일을 가리키는 항목은 target_base가 ‘최상위 저술 폴더’다. 파일명만 보고 두 기준을 섞지 않는다.

## 보존자료의 사용 제한
원문은 과거 제안·접근 제약을 확인하는 근거다. 최신 세계공유 해금, 현재 조우·본체 단일성, 개인 MAIN·보상·지식 공개, 채택 수치가 우선이다. 과거 개인별 조건·확률 제안으로 현재 열린 세계를 소급 잠그지 않는다. 원문에 등장하는 후속 장면은 이미 발생한 사건이 아니다. 공개용 제작 문서라는 이유로 NPC 초기 프롬프트·플레이어 공개 지식으로 통째 주입하지 않는다.

게임 등록·권위 수행·청중별 자격·정식 수신 증거는 별도 구현 작업이다. 이 연결 후보의 포인터가 해석된다는 사실만으로 실행 가능·발생·목격·동의·권리가 생기지 않는다.
