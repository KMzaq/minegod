# 저술 자료

- 페르소나: 인물별 현행 정체성과 원문 성격·대화 사례.
- 스토리: 본편 원문과 인물별 연결 서사.
- 퀘스트: 원문 제작범위와 개별 퀘스트·장비·스킬·보스·밸런스.
- 지식: NPC가 언제 무엇을 누구에게 말할 수 있는지 구분하는 기준. 스토리 전체를 사전지식으로 사용하지 않는다.

인물 연결은 색인의 record_key를 사용한다. 이는 관리 식별자이며 게임 등록 ID가 아니다. 서사의 계획·조건·제안은 실제 발생 사실이나 구현 완료를 뜻하지 않는다.

## 전투·스킬을 구현할 때

인물별 이야기만으로 기술을 추정하지 말고 퀘스트 폴더의 전투와보상, 스킬연출, 본편전투, 본편성장을 함께 읽습니다. 스킬연출에는 준비·이동·명중·종료의 형태와 시간, 실제 판정 범위, 벽 충돌, 필요한 자산과 영상 인수 조건이 있습니다. 임시 큐브 투사체나 판정과 다른 장식만으로 완성 처리하지 않습니다.

전투와보상/색인.json의 수량은 기존 콘텐츠와 공방 장비 묶음의 집계입니다. 별도로 작성한 본편·인물 보상은 추가정의_참조색인.json에서 찾습니다. 참조 색인은 물품을 새로 지급하거나 같은 정의를 복제하는 목록이 아닙니다. 장비 효과와 함께 원래 획득 조건·선택권·재고·고유성·실패 복구 계약을 적용합니다.

모든 수치 검산은 가정을 명시한 초기 설계이며 실제 Minecraft 서버·API·멀티플레이·완성 자산·영상 시험 결과가 아닙니다. 실제 구현 뒤에는 각 문서의 인수 장면과 판정 로그로 확인해야 합니다.

## 원문과 현재 기획의 구분

인물별범위와 original_profile은 원문 보존 자료입니다. 현재 채택된 실행값은 공통설계와 해당 인물별완결기획·전투 정의를 함께 적용합니다. 오래된 획득 후보·테스트 ID·개인별 세계 해금 문구로 최신 결정을 되돌리지 않습니다. 원문 파일명이 남은 참조는 공통설계/원문참조_연결색인.json에서 이 묶음 안의 동일 보존값을 찾을 수 있습니다. 이 연결표는 실제 객체가 같은 1,490곳만 연결하며, 나머지 원문 필드까지 존재한다고 가정하지 않습니다.
## Simply Swords · Better Combat 전환

전투모드통합 폴더는 별도 신규 무기에 Simply Swords의 허용 리소스와 Better Combat의 기본 공격을 연결하는 현재 전환 기획입니다. 원본 아이템의 이름만 바꾸거나 고유 효과를 전부 함께 가져오는 방식이 아닙니다. 기존 무기 정의와 획득권은 보존하며, 기본 공격의 모양·콤보·양손·타격 시점은 전환 계약의 BC_NATIVE_BASELINE이 이전 수기 기본 공격 기하보다 우선합니다. 무기별 original과 presentation은 변경 전 비교자료이며 그 값을 모두 다시 강제하는 명령이 아닙니다. 커스텀 검기와 대시 등 스킬의 별도 연출·판정은 계속 적용합니다.

13개 실제 무기의 기반 후보와 부채·활 예외를 구분했습니다. 개발 브랜치 정보는 배포 JAR의 검증 결과가 아닙니다. 전환 후 초기 수치·레이드·연출의 교차 저술과 정적 검산은 전환_구현전달_기획.json 및 동봉 표에 정리했습니다. 실제 배포 프로필과 의존성이 동봉 정적 대조 전제와 일치하는지 확인한 뒤 해당 무기의 after_initial_design을 초기값으로 사용하며, 변경 전 비교 스냅샷으로 되돌리지 않습니다. 실제 설정이 다르면 전제를 다시 대조하고 재산정합니다. 1~5인 민감도와 마나 표는 명시한 가정의 산술이며 실제 서버에서 측정한 DPS나 최종 밸런스 인증이 아닙니다. 선정 5종의 실제 배포 프로필·모델 참조·텍스처와 평타 클립은 배포실물_정적확인에 정적 대조 근거를 추가했습니다. 이는 설치·실행 시험이 아니며, 정확 로더 조합·훅 동작·렌더·영상·멀티플레이는 인수 조건에 따라 검증해야 합니다.


## 현재 인물 보강과 활성화

각 범주의 현행추가저술_연결색인.json에서 기본 원문과 현재 상세 원고를 함께 찾습니다. 범주별 묶음은 같은 record_key를 선택하고, 범주연결.json의 경로는 이 묶음의 최상위 폴더를 기준으로 읽습니다. 원문 보존값과 현재 채택을 혼동하지 않습니다.

색인의 current_activation이 있는 인물은 스토리/현행활성화계약의 명시 채택 범위를 우선합니다. 과거 미채택 후보를 지우거나 초기접근·봉인·단일본체를 무효화하는 뜻이 아닙니다. 근거파일_연결.json은 이 묶음 안에 있는 원값을 찾는 연결표이며, 원문 근거를 NPC 자동 지식이나 실제 발생 사실로 만들지 않습니다. 이 기존 연결표 외에 추가된 활성화의 근거는 루트 색인의 current_activation_source_link_extensions에 연결한 세 표에서 찾습니다.

## 전투 경고와 실제 판정의 연결

퀘스트/스킬연출/판정연결은 주요 전투, 키메라, 보조 전투, 기존 플레이어 효과와 현장 조작의 경고·유해 코어·비판정 잔상을 연결합니다. 공격 전에 전체 위험을 읽을 수 있어야 하며, 이동 투사체의 밝은 핵은 실제 유해 수명 동안 유지합니다. 정적 기획 검수와 구현 후 영상·5인 시험은 별개입니다.

## 전체 지식 연결

지식/최종연결은 105패킷·772명 및 242개 현행 활성화의 기본앎·현재 사건·원문 근거를 연결한 기획입니다. 기존 447참조와 원문별칭 표는 역사 범위 그대로 보존하며 전체 연결은 이 최종연결 폴더를 함께 읽습니다. 파일에 미래 분기나 사적 내용이 있다는 이유로 NPC 초기 앎에 넣지 않습니다. 실제 관측·허락·개별 수신·청중·정정 계약을 먼저 적용합니다.
