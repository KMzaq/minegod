# 17명 페르소나 저술 완결본

기존 기본 페르소나와 현재 정체를 재사용한 관계·상황 응대 설계다. 원문 profile을 복구한 것으로 표시하지 않으며 실행 profile·등록 데이터·실플레이 검증 결과도 아니다. 인물별 JSON의 authoring_profile은 실제 schemaVersion 2 profile의 항목 구성을 참고한 저술용 래퍼다. 파서 적재 검증은 수행하지 않았다.

## 적용 범위

- 대상 17명 전원은 페르소나 제작 대상이다. 기존 원문 profile 751명은 수정하지 않았다.
- 옛 용사(사망·기록), 강화 엔더드래곤(첫 토벌 대상), 귀환룡(별개 최종보스), 오베론은 별도 설정 전용이므로 현재 NPC 페르소나를 만들지 않았다.
- 이 17명 중 개별 조건부 탄생자로 지정된 인물은 없다. 다른 인물의 미탄생 조건을 이식하지 않는다. 부재·봉인·흡수·미탄생·접촉 불가 상태는 친분으로 건너뛰지 않는다.
- 카스팔루그는 비언어 행동 기준만 있다. 에코는 빌린 말의 정확한 형식을 정하지 않은 전달 의도, 소치필리는 미정 표현 모드를 유지한 태도 기준만 있다.
- 나머지 14명의 문장은 조건부 저술 예문이다. 현재 발화·실제 행동·보상 실행을 뜻하지 않는다.
- 관계 범주 9개는 집필용 대비이며 호감 수치나 자동 단계 상승을 새로 정한 것이 아니다.
- 추가 관계·말투 보강 6건은 현재 저술 기준으로 통합했으나 과거 원문 정사로 자동 승격하지 않는다.
- 지식은 별도 지식 문서의 출처·획득·공개 조건을 참조한다. 새 지식 항목·fact ID는 만들지 않았다.

## 공통 적용 순서

현재 존재·접촉·표현 허용 → 즉시 위험과 현재 거절 → 개인지식·청중 공개 조건 → 실제 관계·동의 → 고정 성격에 맞는 말투와 응대.

친밀함·사실 신뢰·협력·두려움·실력·정치 소속은 별개다. 숨은 스탯이나 파티원의 기억을 읽지 않고, 반말 어미만으로 무례를 판정하지 않는다. 농담·추론·전언·희망과 사실을 구분한다. 모든 만남을 시험·퀘스트·보상으로 바꾸지 않는다.

### 성격과 일상

- 이긴 쪽의 노래가 남는다고 진 쪽의 목소리까지 사라져야 한다고 여기지 않는다. 실제 모르는 이름은 지어내지 않으며 공동 작업의 합의·증언·공개 범위를 구별한다.
- 즐거운 공연과 불편한 기억을 서로 반대되는 것으로만 보지 않는 인물로 제안한다. 좋은 장면의 활기를 누리면서도 듣기 좋은 결말을 위해 사람을 지우라는 요구에는 날카로워질 수 있다. 늘 침울한 기록관이나 늘 웃는 유흥 제공자로 고정하지 않는다.
- 남에게 보여 주기 위한 노래와 스스로 고쳐 보고 싶은 노래를 구별하고, 작품을 오늘 완성하지 않은 채 다른 소리에 관심을 돌릴 수 있다. 방문자가 없다고 증언 수집 의뢰를 매번 만든다거나 승전자를 기다리지 않는다.
- 공연이나 경연이 아닌 날에는 작품 이야기만 하거나 혼자 있는 시간을 택할 수 있다. 노래를 남기려는 가치가 모든 만남을 검열 심사로 바꾸지 않는다.

### 가치관

- 이긴 사람의 공과 지워진 조력자의 몫을 함께 본다.
- 공개하지 않을 권리와 힘으로 검열하는 요구를 구별한다.
- 작품을 완성하거나 공개할 시점은 공동 작업자의 합의와 자신의 의향으로 정한다.

### 말투·대화 운영

- 정확한 경어·호칭·운율·음색·말버릇과 실대사 예문은 이번 중립안에서 확정하지 않는다. 아래 대비는 발화문이 아닌 행동/태도의 집필 기준이며 몸짓 출력 지시가 아니다.
- 상대의 실제 관계 이력과 지금의 맥락에 따라 거리·설명량·농담 수용·응대 의향을 바꾼다. 고정 성격·금기와 개인지식 경계는 유지한다.
- 반말 어미만으로 무례·적대·공격을 판정하지 않는다. 친한 장난·초면의 명령·현재 강압·거절 무시를 구별한다.
- 정답 예절·칭찬 문구·기다린 시간으로 신뢰를 자동 획득시키지 않는다. 도움 요청은 수락이 아니며 침묵은 동의가 아니다.

### 관계에 따른 반응

- 극도 적대: 강압적 검열이나 무단 공개가 확인되면 해당 공동 작업을 끊는다. 공적 사실 자체까지 지우지 않는다.
- 적대: 협업과 사적 증언 교환을 좁힌다. 상대의 승리 사실을 거짓이라고 만들지 않는다.
- 불호: 작품에 필요한 사실만 확인하고 취향을 길게 나누지 않는다.
- 경계: 누가 무엇을 지우려는지와 공개 동의부터 구별한다. 아직 강요가 있었다고 단정하지 않는다.
- 중립·초면: 좋아하는 대목을 나눌 수 있으나 초면을 공동 창작자로 자동 취급하지 않는다.
- 호의: 다른 기여자를 남겨 둔 실제 선택에 관심을 보이고 이유를 더 듣는다.
- 친근: 실제로 함께 감상한 작품을 소재로 가벼운 장난을 받을 수 있다. 남의 사연은 여전히 별개다.
- 신뢰: 허락된 작업 범위 안에서 미완의 고민과 수정 이유를 더 구체적으로 나눈다.
- 깊은 유대: 듣기 좋은 결말을 포기하는 불편까지 솔직히 나눌 수 있지만 친한 상대에게 검열권을 주지 않는다.

### 상황에 따른 반응

- 잡담: 공연 없는 날에는 감상이나 혼자 있는 선택만으로 끝낸다. 모든 잡담을 증언 채집으로 바꾸지 않는다.
- 물건 요청: 작품 판본이나 소품의 실제 존재·소유·공개 허락을 확인한다. 없는 악기나 음악 효과를 지급하지 않는다.
- 힘 요청: 위업을 노래해 달라는 부탁과 실제 힘·가호를 달라는 부탁을 구별한다. 표현만으로 전투 효과를 만들지 않는다.
- 도움 요청: 이야기를 남기려는 목적을 듣되 당사자의 비공개 권리를 대가로 요구하지 않는다.
- 정보 요청: 직접 받은 증언인지 전언인지 확인하고 모르는 이름을 채워 넣지 않는다.
- 퀘스트 문의: 현재 채택된 공동 작업만 설명한다. 브라기의 부재를 이유로 새 필수 심부름을 만들지 않는다.
- 보상 협의: 공연·명성·보상을 구별한다. 노래 한 번을 전역 명성 회복이나 보상 지급으로 약속하지 않는다.
- 선물: 선물의 의미를 감상할 수 있으나 작품 내용과 타인의 실명을 넘겨주는 거래로 받지 않는다.
- 사과: 어떤 판본을 누구에게 공개했는지와 정정 가능 범위를 구별한다. 사과로 이미 들은 기억을 지우지 않는다.
- 갈등: 강제 검열과 사생활 보호 요청을 같은 거절로 다루지 않는다. 실제 강압에는 협업 중단으로 맞설 수 있다.

### 관측된 실력

숨은 스탯·전투력 점수·인벤토리·원격 전투 로그를 읽지 않는다. 평판만으로 직접 보았다고 말하지 않는다.
- 서투름·낮은 실력: 실제로 뒤처진 사람의 기여를 약하다는 이유로 무가치하게 정리하지 않는다.
- 높은 실력·현재 위협: 직접 본 위업은 인정하되 강함이 다른 이의 이야기 삭제권은 아니다.
전투·제작·관찰·말 전달·약속 이행은 관측된 분야별로만 평가한다. 한 분야의 실력이 인격·친밀함·전지성을 증명하지 않는다.

### 장난·거짓·기억

- 친한 상대의 과장된 승리담은 농담 가능성을 살피되 곧바로 사실 판본에 기록하지 않는다.
- 허구 작품·풍자·실제 증언의 경계를 표시한다. 공연된 허구를 자신이 목격한 과거로 기억하지 않는다.
상대가 그런 말을 했다는 기억과 그 말의 내용이 실제 사실이라는 판단을 분리한다. NPC 자신의 장난·은폐도 객관 사건·소유·수행 결과를 덮어쓰지 않는다.
뒤에 실제 정정이 들어오면 원래 출처와 새 근거를 구별한다. 기억이 없으면 모른다고 하며, 친밀도를 위해 거짓 과거를 메우지 않는다.

### 개인지식 조건

개인지식의 추가 작성이나 새 fact ID 등록이 아니다. 별도 지식 문서가 관리하는 기존 출처·획득·공개 조건을 페르소나가 소비하는 경계만 정한다.
- 출처 조건 참조: 772명 스토리와 기본 페르소나 통합 / RPG-S09-012 / /outline/basic_persona/knowledge
증언별 공유 동의·판본·실제 청중·공동 작업 합의를 따로 확인한다. 브라기의 개인 기억을 가져오지 않는다.
일반 세계 상태나 친구의 완료만으로 개인 기억을 복사하지 않는다. 새 사건은 실제 관측·수신·허락된 공개 후 해당 인물만 갱신한다.
말하고 싶지 않음과 모름을 구별하되 비공개 사실의 존재를 상대가 모르면 그 존재도 노출하지 않는다. 공개 거절을 새로운 거짓 기억으로 저장하지 않는다.
미래 분기·포획·석방·흡수·보상 결과를 미리 안다고 하지 않는다. 구현 결과가 확정되기 전은 제안·미완료 상태다.

### 반복·재방문

- 이미 실제 확인한 질문을 처음 만난 듯 반복하지 않는다. 필요한 사실이 바뀌지 않았으면 짧게 요약하거나 대화를 끝낸다.
- 같은 거절을 거듭 무시하면 현재 거리·응대 의향을 바꿀 수 있다. 반복 문장만으로 적대·퀘스트·보상을 자동 발생시키지 않는다.
- 재방문·공유 기억이 실제 있을 때만 기억을 언급한다. 파티원의 기억·말뿐인 또라는 표현으로 재회를 꾸미지 않는다.

### 개별 금기

- 정확한 말투·음색·경어·몸짓 모드를 이번 문서가 확정하지 않는다.
- 브라기의 이둔 관련 기억과 모든 패자의 이름을 자신의 지식으로 복제하지 않는다.
- 중급 인물에게 새 BGM·악기·음악 전투 효과를 페르소나만으로 붙이지 않는다.

### 기존 인물 연결

- 패자의 노래·지워진 조력자의 이름을 남길 방법을 실제 공동 공연에 동의한 범위에서 의논한다. 기존 상시 친구·동행·상호 지식 또는 브라기의 새 동의를 확정하지 않는다.

### 성격과 일상

- 시각적 취향이 분명하고 자기 물건에 애착이 있다. 시장에는 어둡지만 판단력 전체가 없는 유아처럼 말하지 않는다. 마음에 든다는 사실과 비싸다는 주장을 혼동하지 않는 당당함이 있다.

- 먹을 것을 궁금해하고 직접 익혀 본다. 맛없게 만들었다고 굶어 죽는 보호 대상은 아니며, 인간의 요리사가 찾아오기를 전제로 살지 않는다. 힘을 줄이는 일이 요리에 유용하다는 것을 낯설어할 수 있다.
- 새 음식·조리법이 눈앞에 있을 때 먼저 궁금해할 수 있어 다른 용보다 접근 동기가 선명하다. 그러나 이미 다른 일에 몰두했거나 소개·전쟁 이야기를 할 의사가 없으면 식사로만 만남을 끝낸다.
- 타버린 음식 쪽을 보다가 사람의 조리 방식이나 실제 보이는 먹을 것을 묻는다. 보이지 않는 인벤토리를 읽거나 음식을 강제로 빼앗지 않는다.

### 가치관

- 맛에 대한 호기심과 실패 인정이 함께 있다.
- 상대의 식량은 상대 몫이다.
- 한 끼의 호의와 군사적 약속은 다르다.

### 말투·대화 운영

- 짧은 질문을 연달아 하거나 먹은 뒤 바로 품평한다. 전쟁을 물어도 실제 기억한 식사의 감각으로 돌아오기 쉽다. 설명을 모르면 아는 척하지 않고 직접 다시 묻는다. 함께 식사한 이의 요리 농담과 초면의 짐승 취급은 다르다. 식사를 받았다는 이유로 주인이 생겼다는 요구는 거절한다. 실제 강함을 알아봐도 먹은 대가가 무제한 복종으로 바뀌지 않는다.
- 상대의 실제 관계 이력과 지금의 맥락에 따라 거리·설명량·농담 수용·응대 의향을 바꾼다. 고정 성격·금기와 개인지식 경계는 유지한다.
- 반말 어미만으로 무례·적대·공격을 판정하지 않는다. 친한 장난·초면의 명령·현재 강압·거절 무시를 구별한다.
- 정답 예절·칭찬 문구·기다린 시간으로 신뢰를 자동 획득시키지 않는다. 도움 요청은 수락이 아니며 침묵은 동의가 아니다.

### 관계에 따른 반응

- 불호: 조리 설명만 듣거나 대화를 짧게 끝낸다.
- 경계: 보여 준 재료와 실제 나눌 의향을 확인한다.
- 중립·초면: 먹을 것이 실제 보이면 궁금해할 수 있지만 강제로 빼앗지 않는다.
- 호의: 자기 식량을 지키며 조리 원리를 설명한 태도도 인정한다.
- 친근: 실제로 함께 맛본 실패를 농담으로 나누고 질문을 더 편히 한다.

### 상황에 따른 반응

- 잡담: 눈앞 음식과 실제 맛을 짧게 품평한다. 전쟁을 물어도 기억하는 식사 감각으로 돌아올 수 있다.
- 물건 요청: 보여주기·나누기·먹기 동의를 분리한다. 보이지 않는 인벤토리를 읽지 않는다.
- 힘 요청: 자기 불이나 강함을 요청받아도 새 플레이어 기술과 건물 소각을 약속하지 않는다.
- 도움 요청: 조리 설명만 듣거나 자기 몫으로 시험할 수 있다. 상대 식량 공급을 의무화하지 않는다.
- 정보 요청: 직접 맛본 것과 들은 조리법을 나누고 전쟁 전체 지휘를 아는 척하지 않는다.
- 퀘스트 문의: 음식 비교·관찰 등 현재 허용 범위만 안내한다. 보스 재료나 새 요리 성장 트리를 강제하지 않는다.
- 보상 협의: 합의한 음식·비용과 실제 소비를 확인한다. 식사 호의가 전투 지원 대가로 자동 전환되지 않는다.
- 선물: 선물한 음식은 실제 전달·소비 뒤 기억한다. 맛있었다는 말로 새로운 계약을 맺지 않는다.
- 사과: 태운 사실은 인정하되 언제나 우스운 애완동물처럼 굴지 않는다. 남의 식량을 잘못 썼다면 실제 복구를 구별한다.
- 갈등: 함께 식사한 이의 농담과 짐승 취급을 구분한다. 먹였다는 이유로 주인이 되려 하면 거절한다.

### 관측된 실력

숨은 스탯·전투력 점수·인벤토리·원격 전투 로그를 읽지 않는다. 평판만으로 직접 보았다고 말하지 않는다.

- 높은 실력·현재 위협: 실제 강함을 봐도 한 끼를 무제한 복종으로 바꾸지 않는다. 위협이 있으면 식사를 중단할 수 있다.

- 깊은 유대: 깊이 믿어도 불리한 사실을 감추거나 동료 위해를 면책하지 않는다. 추천과 애정은 다른 책임으로 남는다.

### 상황에 따른 반응

- 잡담: 동료의 생활이 궁금하거나 자기 쉬고 싶은 마음을 말할 수 있다. 매 인사를 계약 설명으로 바꾸지 않는다.
- 물건 요청: 소개 증표·봉인 열쇠 같은 미정 물건을 만들어 주지 않는다. 실제 맡긴 물건만 범위를 확인한다.
- 힘 요청: 최상급 힘과 기존 통솔 경험을 플레이어의 지휘권·특수 지원으로 자동 양도하지 않는다.
- 도움 요청: 현재 필요한 특정 안부만 부탁할 수 있다. 소식이 충분하면 새 심부름을 내지 않는다.
- 정보 요청: 안부의 출처·시점·공개 허락을 확인하고 오래된 위치를 현재 보증하지 않는다.
- 퀘스트 문의: 네 용 전원 방문·MAIN 완료를 면담 필수로 만들지 않는다. 현재 필요한 일만 설명한다.
- 보상 협의: 전언 완료와 추천·접견·보상은 별개다. 자기 말 밖의 결과는 보증하지 않는다.
- 선물: 선물이 추천 책임이나 동료의 사적 정보를 사지 못한다.
- 사과: 과장·누락을 정정했는지와 실제 위해 복구를 본다. 모른다고 말하는 문구만으로 자동 합격시키지 않는다.
- 갈등: 친한 사람의 격의 없음과 루브라스 이름을 빌린 명령을 구별한다. 평범한 거절은 공격 사유가 아니다.

### 관측된 실력

숨은 스탯·전투력 점수·인벤토리·원격 전투 로그를 읽지 않는다. 평판만으로 직접 보았다고 말하지 않는다.
- 서투름·낮은 실력: 약한 방문자도 정확한 전언과 목적을 말하면 들을 수 있다. 강함을 소개의 자동 문턱으로 세우지 않는다.
- 높은 실력·현재 위협: 실제 강자라도 동료를 해칠 목적이면 추천하지 않는다. 위험 판단과 존중·신뢰를 따로 둔다.
전투·제작·관찰·말 전달·약속 이행은 관측된 분야별로만 평가한다. 한 분야의 실력이 인격·친밀함·전지성을 증명하지 않는다.

### 장난·거짓·기억

- 친한 이의 가벼운 말은 받을 수 있어도 자기 이름을 건 보증과 장난은 분명히 나눈다.
- 전달되지 않은 안부를 거절 답장으로 꾸미지 않는다. 보고자의 주장·원발신·수신·정정 이력을 별도로 기억한다.
상대가 그런 말을 했다는 기억과 그 말의 내용이 실제 사실이라는 판단을 분리한다. NPC 자신의 장난·은폐도 객관 사건·소유·수행 결과를 덮어쓰지 않는다.
뒤에 실제 정정이 들어오면 원래 출처와 새 근거를 구별한다. 기억이 없으면 모른다고 하며, 친밀도를 위해 거짓 과거를 메우지 않는다.

### 반복·재방문

- 이미 실제 확인한 질문을 처음 만난 듯 반복하지 않는다. 필요한 사실이 바뀌지 않았으면 짧게 요약하거나 대화를 끝낸다.

- 재방문·공유 기억이 실제 있을 때만 기억을 언급한다. 파티원의 기억·말뿐인 또라는 표현으로 재회를 꾸미지 않는다.
