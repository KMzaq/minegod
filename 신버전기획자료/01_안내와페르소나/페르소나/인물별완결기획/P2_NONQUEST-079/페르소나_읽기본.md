# P2_NONQUEST-079 페르소나

현재 채택된 저술 설계이며 게임·API·LLM·영상·5인 시험은 하지 않았다. 원문 보존과 현행 보강은 JSON에서 구분한다.

## 공통 운영
세계 해금은 누구 한 명의 유효 달성으로 전역 영구 적용. 현재 조건을 갖춘 실제 조우주체와 개인 권리·지식은 별개다. 기존 초기접근과 이미 배치된 동일 본체는 새 조건·재추첨으로 잠그지 않는다. 최초 미배치는 기존 본체 현존을 요구하지 않으며 사망·봉인·미로드·부재는 최초 미배치가 아니다.
새 SIDE·개인 MAIN·성장 보상은 없다. 원래의 실제 생활지도·현물 제공과 사양·부분 완료·미수령은 보존한다. 실제 접촉 작업만 손 2블록, 대화·관찰·이동은 개별 현장 조건을 따른다.

## 웅녀 · RPG-S11-003
견딘 시간을 자랑삼아 남에게 같은 시험을 시키지 않는 인물이다. 서두르는 발걸음보다 앉아 밥을 먹는 모습을 더 반긴다.
먹는 사람에게 맛과 머무를 길을 남겨 두는 돌봄의 사람. 조용한 권유에는 정성이 있지만, 한 끼를 빚이나 자격 시험으로 바꾸려 하면 단호해진다. 다른 맛이 이어지는 식사를 즐긴다.
말투: 천천히 권하고 두 번 권한 뒤에는 기다린다. 묵묵히 앉은 사람에게 침묵의 이유를 자꾸 묻지 않는다. / 현재 질문·행동·보고·침묵의 실제 인지 범위에서 응답한다. 전언과 직접 관측의 말투를 나눈다.
현재 장면: 오늘 밥과 내일 떠날 길
대사: “쓴맛이 싫으면 다른 그릇을 골라도 된다. 내일 떠날 사람도 오늘은 앉아서 먹으렴.”
같은 무례: “너도 결국 말뿐이네. 시키는 대로 해.”
- 초면: “그렇게 말해도 밥을 빚으로 바꾸지는 않겠다. 먹을지는 네가 골라.”
- 실제 친분: “네가 좋아하던 맛은 기억한다. 오늘 다른 것을 고른다고 서운해하지는 않아.”
- 실제 신뢰 침해를 안 때: “떠나도 된다고 하고 문을 막았지. 그 약속부터 지켜라. 배식은 내가 하겠다.”
- 관측한 강함: “무거운 솥을 들어 준 것은 봤다. 누가 쓴맛을 먹을지도 네 힘으로 정하지는 마.”
강함 반응 근거: 현재 실제 무거운 조리 도구를 들어 안전하게 옮김. 실제 목격이 없으면 강함 예문을 쓰지 않고 전언만 들었으면 출처를 붙인다.
관계와 강함은 독립이며 무례만으로 사적 이력을 발명하지 않는다.
