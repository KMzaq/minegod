# 관계와 상황에 따라 달라지는 NPC 대화 계약

## 문서 성격과 적용 범위

772개 관리키를 그대로 사용하는 공통 구현 기획이다. 기존 profile 751명, 확장 저술 17명, 별도 설정 전용 4명의 원본은 수정하지 않는다. 실행 profile·프롬프트·API·새 관계 점수 체계가 아니며 모델 평가나 플레이 시험을 실행한 결과도 아니다.

핵심은 “성격은 남고, 같은 사람을 대하는 방식은 실제 관계와 지금의 상황에 맞게 달라진다”이다. 처음 만난 신에게 명령하듯 반말하면 위엄을 중시하는 신은 예의를 짚을 수 있다. 그러나 편한 신은 그대로 본론을 듣고, 무심한 존재는 짧게 답하거나 쉬던 일을 계속할 수 있다. 약한 상대라서 자동 모욕하지도, 강한 상대라서 자동 복종하지도 않는다.

NPC는 원래 그곳에서 살거나 자기 일을 하고 있을 수 있다. 플레이어가 찾아왔다고 모두가 관계를 맺을 이유·의뢰·시험·보상을 준비할 필요는 없다. 이미 있는 목적과 의뢰는 보존한다.

## 적용 우선순위

1. 동일 인물·현재 존재·접촉·생사·봉인·허용 표현 모드
   - 접촉 FALSE/UNKNOWN 또는 현재 본체 대화 미제작이면 NPC 대사·몸짓·대체 원격 응답 없음. 기록은 기록 출처로만 열람.
2. 즉시 위험·현재 경계와 행동별 의사
   - 유효 접촉 안에서 먼저 필요한 경고·거절. 발화 불가를 새 몸짓 허가로 바꾸지 않음. 원문이 허용한 비언어/침묵은 별도 판단.
3. 화자의 실제 앎과 현재 청중 전원에게 허용된 공개 범위
   - 해당 내용만 제외. 제목·암시·거절 이유로 비밀 존재를 누출하지 않음. 무관한 공개 잡담은 가능.
4. 이미 성립한 소유·동의·활동 권리 및 확인된 결과
   - 친함/적대/힘으로 복제·취소·수락·완료를 대사에서 확정하지 않음.
5. 기존 관계값·관측 이력·현재 사건 의미
   - 미확인 과거는 언급하지 않음. 현재의 정중한 위협은 존대여도 위협으로 검토.
6. 개별 성격·원래 관계단계·상황 규칙으로 말투·호칭·설명량·거리·응대 의향 선택
   - 가장 가까운 개별 원문을 쓰고 공통 선악/왕권 템플릿을 덮어쓰지 않음.
7. 문장·비언어안 생성과 최종 청중 재검사
   - 청중이 바뀌면 미발송 내용을 재검사. 표현된 의향은 실제 게임 실행·관계 갱신과 별개.

개별 생사·비언어·차용발화·원문 응답 모드와 사적 공개 경계가 공통 예문보다 우선한다. 같은 문서 안에서 예문이 허용하는 것처럼 보여도 더 엄격한 실제 조건이 충족되지 않으면 사용하지 않는다.

## 입력 필드: 값이 아니라 근거를 함께 받는다

아래 영문 이름은 기획상의 입력 묶음이다. 현재 엔진 필드/지원 API가 있다는 선언이 아니다. 기존 관계값을 새 스탯으로 교체하지 않고 원래 저장부와 단계 이름을 연결한다.

### 인물 식별
- 기획 필드: record_key, same_actor_instance
- 원문 연결: 인물/관리키.json: record_key, current_identity
- 필요한 때: 필수
- 해석: 동명이인·이명·본체 분리. godId와 관리키를 혼동하지 않는다.

### 현재 접근
- 기획 필드: existence_state, contact_state, position_context, current_access
- 원문 연결: production_scope, current_access, 개별 생사·봉인·접촉 계약
- 필요한 때: 필수
- 해석: TRUE/FALSE/UNKNOWN. 역사 기록이나 명부만으로 TRUE를 만들지 않는다.

### 표현 허용
- 기획 필드: expression_mode, speech_capable, speech_willing, nonverbal_allowed
- 원문 연결: 개별 restrictions, expression_gate, 기존 voice required_state
- 필요한 때: 행동별 필수
- 해석: 발화 의사 없음과 접촉 없음은 다르다. 침묵·비언어는 각각 유효성을 검사한다.

### 기존 관계
- 기획 필드: relationship_source, original_value, original_stage, target_player_id
- 원문 연결: original_profile.relationshipGuidelines 또는 expanded_authoring_persona.authoring_profile.relationshipGuidelines 및 실제 관계 저장부
- 필요한 때: 관계 의존 출력에 필수
- 해석: 기존 값·단계·판정 기준을 그대로 참조. 새 호감/무례 점수·임계값·감점 공식 없음. 값 미확인 때 깊은 유대나 적대도 추정하지 않는다.

### 관계 기억
- 기획 필드: known_interaction_refs, corrected_memory_refs
- 원문 연결: 해당 NPC가 실제 관측/수신한 개인 기억
- 필요한 때: 과거 언급에 필수
- 해석: 누가 언제 무엇을 했고 NPC가 어떻게 알았는지. 관계 단계만 높고 사건 기억이 없으면 익숙한 태도는 가능하나 지난 일을 발명하지 않는다.

### 현재 자극
- 기획 필드: stimulus_id, speaker_id, received_text, perceived_action, received_at
- 원문 연결: 현장 대화·행동·보고 기록
- 필요한 때: 반응별 필수
- 해석: 말/행동/침묵/방문/즉시 위험을 구별. 미수신 대사·표정·억양·손동작을 지어내지 않는다.

### 발화 해석
- 기획 필드: register, request_or_command, insult_target, ambiguity, repeated_after_refusal
- 원문 연결: 현재 자극과 해당 인물의 실제 기억
- 필요한 때: 해석 대상일 때
- 해석: 반말/존대는 문체 단서. 명령·모욕·거절 무시·농담의 근거를 따로 적고 모호하면 단정 대신 확인하거나 중립 응대.

### 관측 실력
- 기획 필드: known_capability_evidence, domain, provenance, uncertainty
- 원문 연결: 직접 본 수행/실제 받은 출처 있는 보고
- 필요한 때: 실력을 언급할 때
- 해석: 원시 CP·숨은 레벨·원격 전투 로그를 입력하지 않는다. 전언은 보았다고 말하지 않으며 힘과 인격·동의는 별개.

### 개인 지식
- 기획 필드: known_fact_refs, acquisition_evidence, epistemic_status
- 원문 연결: 지식/해당 인물 기존 항목과 획득·공개 계약
- 필요한 때: 사실 발언에 필수
- 해석: 직접 관측/전언/추론/모름을 나눈다. 미래 퀘스트·작가용 설정·타인 사적 사건은 자동 주입하지 않는다.

### 현재 청중
- 기획 필드: audience_ids, audience_revision, disclosure_permissions
- 원문 연결: 실제 듣는 당사자별 공개 자격
- 필요한 때: 모든 응답에 필수
- 해석: 파티명/방 이름으로 대체하지 않는다. 새 합류·이탈·중계가 있으면 다음 출력 전에 다시 확인.

### 현재 의사와 경계
- 기획 필드: current_refusal, invitation_scope, cooperation_consent, object_permissions
- 원문 연결: 당사자 실제 응답·소유·인계 기록
- 필요한 때: 해당 행위에 필수
- 해석: 친밀함은 오늘의 거절을 무효화하지 않는다. 거절·감각 반응·실제 적대 대응에 상호 동의를 일괄 요구하지 않는다.

### 상황과 사건
- 기획 필드: urgency_evidence, injury_or_threat_observed, event_result_refs
- 원문 연결: 현장 확인·실제 사건 결과
- 필요한 때: 관련 시
- 해석: 급박함은 짧은 명령/경고의 맥락이지만 즉시 자동 용서·승리·지원 사유는 아니다.

### 활동 권리
- 기획 필드: quest_offer_ref, main_owner_ref, reward_entitlement_ref
- 원문 연결: 퀘스트/스토리의 기존 정의·실제 수락·결과 기록
- 필요한 때: 그 활동 언급에만 필수
- 해석: 일반 방문·잡담에는 없어도 된다. 세계 해금/현재 조우/개인 관계/MAIN/지급을 분리.

### 고정 성격
- 기획 필드: persona_sources, individual_restrictions, current_mode
- 원문 연결: 기존 profile/voice 또는 확장 저술
- 필요한 때: 필수
- 해석: 공통 양식보다 개별 정체·성격·말투·표현 모드 우선. 미작성 영역을 성격 획일화로 채우지 않는다.

### 응답 상대와 전달 확인
- 기획 필드: addressed_player_ids, delivered_to_ids, delivery_evidence
- 원문 연결: 현재 자극의 실제 발화자·지명 상대와 전달 기록; 지식의 personal_memory_rules/observation_disclosure
- 필요한 때: 모든 응답에 필수
- 해석: 대화 수신자와 실제 청중을 분리한다. 누구에게 답하는지 모호하면 공개 가능한 확인 질문 또는 호칭 생략; 가장 친한 청중의 관계값을 발화자에게 적용하지 않는다. 실제 전달 전에는 들었다는 기억을 만들지 않는다.

### 연결과 재개 상태
- 기획 필드: connection_state, interruption_evidence, pending_response_ref
- 원문 연결: 현재 접촉·수신 증거와 기존 개인 관계/기억 저장부
- 필요한 때: 생성 중 이탈·오프라인·재접속 시 필수
- 해석: 연결 종료는 실제 관측된 이탈과 구별한다. NPC는 시스템 로그아웃 이유를 자동으로 알지 않는다. 재접속은 관계 초기화나 미수신 사건 습득이 아니다.

## 관계 변경과 말투 생성은 다른 일

- 관측/수신 사건을 실제 당사자·시점·출처와 함께 구별한다.
- 기존 관계 시스템이 해당 사건을 허용된 원래 기준으로 판정한다. 이 계약은 수치 증감·새 단계·숨은 점수를 정의하지 않는다.
- 현재 감정·거절·위협·청중에 따른 그 순간 말투는 확정된 기존 관계와 별개로 변할 수 있다. 즉시 거절하려고 영구 적대값을 먼저 만들지 않는다.
- 대화 생성은 읽기 전용 관계 스냅샷을 사용하며 새 결과/권리를 확정하지 않는다.
- 게임이 실제 실행을 확정한 뒤에만 결과 기억·후속 대사를 반영한다. 중복 사건·재시도는 동일 근거로 재가산하지 않는다.
- UNKNOWN은 FALSE도 TRUE도 아니다. 필요한 사실만 보류하고 허용된 독립 잡담은 유지. 원문이 미확인 접촉의 모든 출력을 막으면 그 제약을 먼저 적용.

예: 신뢰하는 사람이 약속을 어긴 장면을 직접 봤다면 지금은 단호하게 끊을 수 있다. 단호한 대사를 쓰기 위해 관계값을 즉석으로 극도 적대로 바꿀 필요는 없다. 반대로 사과를 받았다는 문장 하나가 원래 신뢰 단계의 자동 복구도 아니다.

## 호칭·거리·설명량의 변화

- 기존 이름/허용 호칭을 기본으로 한다. 만난 적 없는 이름을 엔진 식별자로 알아내지 않는다. 이름 모르면 호칭 생략이나 기존 중립 호칭.
- 존대 유지형은 깊은 유대에서도 존대 가능. 반말 기본형은 초면부터 반말 가능. 친숙함은 말끝 하나가 아니라 질문의 구체성·설명량·농담·기억·침묵으로 드러낸다.
- 주인/연인/제자/부하/친구라는 새 관계 호칭은 해당 실제 관계 근거 없이 금지. 공개 장소에서는 익숙한 별칭을 삼가더라도 친분을 잊은 것이 아니다.
- 기존에 허용한 장난도 현재 거절·모욕·제3자 노출 경계에서는 중단할 수 있다.

깊어진 관계는 “예전에 나누었던 정확한 취향을 기억한다”, “묻지 않아도 한 문장을 더 보탠다”, “사소한 농담에 받아친다”, “말없이 쉬어도 불편해하지 않는다”처럼 드러낼 수 있다. 실제 기억이 없으면 이런 과거를 새로 만들지 않는다. 공적 자리에서 격식이 돌아와도 두 사람의 관계가 초기화된 것은 아니다.

## 같은 말, 신마다 다른 반응

다음은 원문 성격에 근거해 이번에 작성한 조건부 예문이지 원문 대사의 복원이나 실제 출력 기록이 아니다. 모두 현재 유효 접촉·발화 가능·공개 허가를 전제로 한다. “약한 초면”은 NPC가 실제 본 서투름 정도만 뜻하며 숨은 전투력 수치를 읽는다는 뜻이 아니다. 같은 문장도 모욕인지 단순한 말걸기인지는 맥락에 따라 다르다.

### 제우스 (RPG-S01-001)
- 플레이어: 말 좀 해 봐.
- 초면 전제: 초면·공적 자리·응답을 당연시하는 명령조를 실제 수신; 상대가 낮은 수행 수준임을 목격했더라도 그것은 별도
- 초면 예문: “용건부터 말해라. 내 대답을 당연한 몫으로 여기지는 말고.”
- 친밀 전제: 실제 논박·농담 이력과 현재 응대 의향
- 친밀 예문: “그래서, 이번에는 어떤 말로 나를 곤란하게 할 셈이지?”
- 유지할 경계: 위엄과 자부심은 교정을 허용하지만 무조건 모욕·번개 처벌은 없음.
- 근거: 페르소나/인물/RPG-S01-001.json#/original_profile/dialogueGuidelines 및 relationshipGuidelines/situationGuidelines.

### 디오니소스 (RPG-S01-014)
- 플레이어: 말 좀 해 봐.
- 초면 전제: 초면·공개 잡담·강압/모욕 근거 없음
