# 후위 방어 기술과 기존 공방 보스의 연결

이번 두 번째 챕터에서 얻는 H02 「후위를 지키는 자세」를 첫 챕터에도 사용할 수 있도록, 기획자가 다음 연결을 명시한다. 이미 서버에 적용했다는 뜻은 아니다.

- 기술: mythictrpg:guan_yu_rearguard.
- 대상 레이드: mythictrpg:workshop_trial_warden.
- 허용 패턴: hammer(망치 들기)만. 명시된 일반 직접 근접 공격의 피해에 H02의 방향·4블록 거리·활성 시간 조건을 모두 검사한다.
- 불허 패턴: pressure_line(압력선), two_plates의 실패 충격. 후위 자세가 이 두 피해를 줄이거나 기믹 성공을 대신하지 않는다.
- 성공 시 기존 갑옷·보호 계산 뒤 H02 단계에서 ×0.70을 적용하고, 고정 장신구 최종 보정은 기존 순서를 따른다.
- 이미 패링·무적 등으로 취소된 피해에는 중복 성공이나 보상을 만들지 않는다. 넉백 차단·반격·정화·보스 경직도 추가하지 않는다.

철 방어15·강인함0·등록 보호합8, 저항 없음의 기존 모델에서 망치 원시8은 약3.733HP이며, H02 조건 충족 시 약2.613HP다. 이 예시는 정적 산술이며 실제 서버 피해 처리 순서 검증은 필요하다.

첫 챕터 원본에는 H02 허용 여부를 따로 명시하지 않았으므로 이 문서가 해당 연결을 추가한다. 다른 기술이나 모든 보스의 직접 공격을 자동 허용하는 전역 규칙이 아니다. 구현 시 정확한 피해 사건과 기술 조건을 매핑하고 정면·후방·거리·시간 경계 및 다른 방어 효과 중복을 시험한다.
