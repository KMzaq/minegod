# 연출 제작 묶음

1. 00_공통연출기준: 판정과 시각을 분리하는 공통 제작·멀티·시인성 기준.
2. 01_대표검기_제작시편: 네모 탄환으로 대체할 수 없는 검기 형태와 상세 인수 기준. 기존 21개 보상에 새 스킬을 붙이지 않는 독립 시편.
3. 효과별: 기존 관리 콘텐츠21개의 서로 다른 동작·실루엣·시간·자산·검수.
4. 02_동영상인수와제작자산: 촬영·판정·5인·네트워크 검수와 자산 제작 순서.

모든 값은 제작 기획이며 구현/엔진지원/실플레이 완료를 뜻하지 않는다. 기존 피해·권리·내구·조작·쿨·면역 규칙은 보존한다.

5. 판정연결/00_읽는순서와_연결원칙: 주요 전투·키메라·보조전투의 경고부터 실제 타격·종료까지, 기존 플레이어 효과와 원본/합일검의 실제 판정 연결을 함께 적용한다. 이 폴더는 기존 수치나 보상권을 교체하지 않는다.
