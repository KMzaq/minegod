# 전투 시각 경고와 판정 연결

이 문서는 기존 전투와 효과의 연결 설계다. 구현·게임 실행·렌더·성능 시험은 하지 않았다. 새 보스·보상·권리는 없다.

## 읽는 순서
1. `00_시각판정_공통계약.json`: 표시 문법, 동시 가독성, 벽·층·LOD·통신·관전.
2. `01_패턴별_연결.json` 및 읽기본: 주요8전투와 키메라, C07 방해적의 정확 시간/공간.
3. `02_플레이어와지원_연결.json`: 기존21효과, BC 무기, 실제 NPC 1행동, 대표검기 시편.
4. `03_현장조작과원본_연결.json`, `03A_보조전투_연결.json`: 원본6·합일검, 현장 순차조작, 기존 보조원정.
5. `04_구현전_인수.json`: 구현 후 실제 수행할 25개 교차사례와 패턴별 경계시험.

## 예고와 판정은 다르지만 모순되면 안 된다
예고는 가능한 위험의 전체 외피, 밝은 코어는 지금 위험한 부피, 잔상은 피해 없는 장식이다. 예고부터 전체 범위와 방향을 읽게 하고 타격 때 처음 알려주지 않는다. 전체 부채 단발의 회전 리본은 판정 진행률이 아니다. C26 앞발은 t12부터 반경5·120도 전체 예고, t36 이후에도 전체 위험을 유지하고 t38에 한 번 실제 판정한다. 반대로 T04 손날은 실제 회전 스윕이므로 매tick 전체 부채로 다시 때리지 않는다.

C05의 넓은 예고외피는 의도된 안전여유다. 실제경계와 따로 표기한다. C26 지면공격의 발 중심과 다른 공격의 AABB 교차도 서로 바꾸지 않는다. 경고 밖이라는 말은 공허·낙하·다른 탄·익사까지 안전하다는 약속이 아니다.

## 동시에 싸울 때
적의 필수 예고와 실제 탈출선, 적 코어, 자기 생존/조작, 자기 실제 동작, NPC와 아군 동작, 장식/잔상 순이다. 뒤 순위의 장식을 줄일 뿐 실제 NPC 본체나 적 경고를 숨기지 않는다. 같은 위험끼리는 첫 타격이 가까운 순으로 읽되 각 윤곽을 남긴다. 무음·색 구분 불가에서도 형상과 기능명, 지형명으로 대응한다.

장식 입자는 반경8의 5인 기준120 초기목표이며 원본/탄의 더 작은 개별 예산을 우선한다. 추가로 장식 제출32개·장식 삼각형16384개를 초기 상한으로 채택한다. 필수 윤곽/실제 본체는 별도 계측한다. 이것은 실제 프레임/TPS 성능 통과값이 아니다. 16/32/64블록 LOD는 미세장식만 줄이며 본인에게 실제 위험한 예고는 거리 때문에 지우지 않는다. 벽 뒤 투시, 아래층 링 복제, 강제카메라, 파티클 안개는 금지한다.

## 전환과 원본을 지키는 경계
BC 평타는 `전투모드통합/전환_구현전달_기획.json`의 BC_NATIVE_BASELINE과 after_initial_design이 우선한다. 과거 H01 t6·70도·3대상·보조4.5를 덧씌우지 않는다. 커스텀 기술·NPC지원·기믹은 별도 사건이다. 배포 JAR 선정5종의 프로필·클립 존재는 실제 동작·정확 로더·기본값·성능 증거가 아니다.

C26은 기존 엔더섬의 바깥 자리/옆 자리/귀환 자리와 엄폐3곳을 사용한다. 분산은 70% 귀환4→2, 40% 옆3→1, 15% 바깥5→6을 순차40tick 처리한다. 합일은40tick 지목→실물검접촉→40tick 확인이다. 최소480tick은 자동 성공시간이 아니며 보조적 전멸과 실제 조작이 모두 필요하다. 조작이라는 이름으로 레이드 금지 채굴·건축·인벤 거래를 허용하지 않는다.

## 제출해야 할 실제 증거
모델/텍스처/애니/음원, V01–V13의 개발본과 미감본, 서버tick·castId·실제부피·피해/효력 로그, 5인/지연/저TPS/벽/높이/LOD 시험은 구현 단계다. SVG나 이 설계 파일을 게임 렌더 증거로 쓰지 않는다. 작은 네모 하나를 날리고 검기라고 부르거나, 넓은 장식과 좁은 판정이 다른 결과를 성공 처리하지 않는다.
