# C03 폐광 전투와 장비 선택권 연결

보조전투의 C03-C 실제 전투승리와 검증된 기여를 공용성장의 C03_FIRST_ROLE_CHOICE 한 권리에 연결합니다.

- 장비는 세 가지 중 한 가지, 수량 1, 개인 최초 1회입니다.
- 짐만 회수했으면 전투승리나 장비권이 생기지 않습니다. 회수 보급은 별도 기존 활동입니다.
- 후발자의 과거 참여를 소급하지 않으며, 정당한 미수령권은 재고·인벤토리 문제 뒤에도 보존합니다.
- 이 연결은 새 지급 경로가 아닙니다. 실제 등록과 서버 인수시험은 수행하지 않았습니다.

정확한 파일과 JSON 포인터는 같은 이름의 JSON에 있습니다.
