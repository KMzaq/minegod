# T03 어제 없던 복도

채택된 구현용 저술 설계다. 시스템 기반 외 실제 제작·등록·플레이 시험은 아직 하지 않았다. JSON은 실행 API가 아니다.

## 무엇을 마치는가
세계 T02와 C15 뒤, 기존 탑 상층의 세 불일치를 조사한다. 조사와 임시 봉쇄로도 전투와 동등하게 T03를 끝낸다. 누구의 개인 MAIN도 아니며 T04와 코어 장비에 필요한 전투 열쇠를 만들지 않는다. T02 경비체가 파괴됐다면 플레이어 관찰/점검판이 안내하고 없는 경비가 말하지 않는다.

첫 계단참에서 위로 올랐는데 이전 높이로 향하는 빛을 본다. 두 번째 모서리는 발소리가 나지만 실제 벽이다. 세 번째는 아래로 이어진 안전선과 윗부분이 빠진 유도선의 차이를 확인한다. 모양 차이뿐 아니라 유도선이 허용 문턱 밖 하층 안전선 쪽까지 뻗었다는 사실을 별도 적는다. 정답을 말하는 대신 실제 계단참2·벽/통로2·문양/문턱3개의 위치 증거가 필요하다. 각2블록 이내 관찰 입력, 시간 제한 없음. 모든 필수 자료는 안전선 쪽에서 보인다.

## 실제 두 해법
- 조사 봉쇄: 조사표에 세 근거를 연결한다. 안전선의 잠금장치 두 곳을 각40tick 유지 조작한다. 도중 이탈은 현재 장치만 초기화, 완료 장치 보존. 작업자는 마지막 사람까지 외측으로 나온 것을 확인하고 상층문 왕복 차단과 하층 계단 왕복을 검사한다. 말이나 메뉴선택만으로 완료하지 않는다. 이 결과는 임시 봉쇄이며 T04 외측 작업대에는 도달할 수 있다.
- 선택 전투: 위험과 참가를 명시 수락한 뒤 셜커1·엔더마이트2만 투입한다. 세 근거를 모은 뒤 실제 세 개체와 잔탄을 정리하고 안쪽 관찰점에서 T04 엄폐 후보를 하나 기록한다. 기존 계단 귀환으로 마친다. 안쪽 기록은 엄폐를 미리 아는 이점이지 필수 능력/새 열쇠가 아니다.
- 자료 없이 철수하면 조사 미완료다. 전투 도중 조사 봉쇄로 전환할 수 있지만 외측 귀환과 적의 실제 격리, 아직 없는 근거를 모두 검증한다. 단순 전투도주를 승리로 기록하지 않는다.

## 안전 공간과 짧은 높이 싸움
실내 15×15, 바닥0 천장 밑면4블록, 전 구간 낙하구멍0. 출입구3×3과 외측 귀환 통로까지 같은 천장/착지면을 연결한다. 플레이어 최대 발높이2.2로 부양 종료 낙하가3보다 작다. 단차는1 이하, 돌출 천장에 머리가 끼는 지점0. 엄폐2×2×3 두 개, 이동폭3 이상, 5인이 서로의 귀환선을 막지 않도록 세 갈래 이동선을 확보한다. 이 형상은 새 제작 요구이지 이미 놓인 맵이 아니다. 기존 탑에 맞는 층을 확보하지 못하면 전투 없이 본래 조사 경로만 연다.

셜커는 HP30, 닫혔을 때 방어20·열렸을 때0, 엔더마이트는 각HP8이다. 사람 수로 늘리지 않는다. 셜커 탄은 구형0.6와 나선꼬리1.2로 읽히고 작은 네모 대체물은 완성으로 인정하지 않는다. 30tick 개방 예고 후 발사, 속도0.18/tick, 최초20tick만 완만하게 유도한 뒤 직진한다. 실제 판정은 반경0.3의 연속스윕이며 벽에 닿으면 사라진다. 최대100tick/18블록, 동시1발. 원시4와 부양I 60tick, 기존 바닐라 효과와 중복 금지. 엄폐 뒤 회피와 탄 직접제거가 기본 해법이며 패링 기술 보유는 선택이다. 엔더마이트는16tick 웅크림 뒤0.6블록 짧은 도약, 폭0.6·높이0.6·전방1.1, 원시2 한 번. 두 마리는20tick 이상 시차를 둔다. 상세 시각/판정/패링/종료 계약은 JSON attacks가 단일 기준이다.

셜커 순간이동은 예약 앵커 세 곳만 사용하고 같은 UUID를 유지한다. 증식은 생성 전 차단한다. 기존 AI와 새 제어가 동시에 탄을 쏘면 안 된다. 실패·재시작·언로드 뒤 원장과 실제 개체가 어긋나면 해당 상층만 잠그고 조사 봉쇄 경로를 남긴다. 잔존 개체를 모른 채 새 셜커를 생성하지 않는다. 자연 처치 전리품은 원래 한 번이며 실패 정리/복제/재도전 보급 생산은 없다.

## 마감, 보급, 후발자
완료 기여자는 GROWTH의 T03 단일 조사보급 권리로 구운감자4 또는 화살8을 한 번 선택한다. 여기서 새 보상권을 만들지 않는다. 초기 감자40/화살80은 실제 조달해야 하는 공유 계획재고이며 시간 리필이 아니다. 슬롯 부족은 미수령으로 보존하고 재시도는 누락 지급줄만 복구한다. 전투자만 실제 승리 이력, 조사자는 조사·차단 기여만 남긴다. 새 측면장비는 미채택이다.

후발자는 현재 조사표를 실제 읽고 현재 경계를 확인한다. 이미 완료한 사건을 원상복구하거나 과거 기여·보급·개인 지식을 소급 지급하지 않는다. 도중 실제 참가한 사람의 공격·엄호·회복·조사 기여는 막타나 DPS컷 없이 기록한다. 사망/로그아웃은 정상 규칙이며 관찰증거를 없애거나 침입 시계를 돌리지 않는다. 보상과 사망물품을 복제하지 않는다.

## 지식과 제작 인수
발소리·빛·가면은 대화/피해/전리품 없는 흔적이다. T03에서 니알라토텝 대면을 생성하지 않는다. 크툴루는 기록에 이름 한 줄만 있으며 출현 증거가 아니다. 관찰자는 자기 관측만, 점검판 작성자는 공개한 구역만 안다. “소리는 길을 보여 주지만 계단을 대신 놓아 주지는 않는다.”를 현장 관찰문으로 사용한다.

신규 구현은 시도별 UUID/청크 고정·증식 차단·안전앵커·맞춤 탄/CC·물리 봉쇄·증거 원장·한 번 지급이다. 기존 이동/엄폐/공격/아이템 기반과 구별한다. 전투 안전이 미검증이면 조사만 공개한다. JSON acceptance의 영상과 장애주입은 출시 전 해야 할 시험이며 실행 완료를 뜻하지 않는다. 약/보통/강·1~5인·방어·마나 산술은 별도 읽기용 검산에 둔다. 권장 전체6~12분, 시간 제한 없음.

## 판정과 안전 보완
엔더마이트 물기는 발높이0~0.6에서 현재몸 앞1.1×폭0.6 박스를 실제 도약0.6 경로로 스윕하되 활성시작 기준 최대전방1.1 외곽으로 잘라 사거리를 덧붙이지 않는다. 총 전진외곽1.1의 쐐기 예고를 표시하고 벽에서 정지한다. 탄과 물기는 겹친5인 중 최초접촉1명만 한 번 맞는다.
활성구간은 시작포함·끝제외, 이전tick~현재tick의 실제 이동/회전부피와 대상 AABB를 연속 대조한다. 벽 동시접촉 우선, 비참가자/NPC 피해·CC0. 경계0.1블록 시험은 대상 중심이 아닌 AABB 가장 가까운 면 기준이다. 전장·작업점·퇴로에는 물/용암·익사구간·끼임·질식·강제낙사 경로가 없어야 하며 안전미검증 전투를 공개하지 않는다. 비전투 경로도 실제 봉쇄/차단이 검증돼야 완료한다.
관찰·열람·전달의 실제 수신자/증거/시점을 따로 남기고 실패·미수신으로 지식을 생성하지 않는다. NPC의 의사·허용모드·현재 청중전원 공개자격을 새발화마다 확인한다. 부재·흔적은 대체응답도 없고, 새청중에게 과거 개인지식이나 비공개 내용의 존재를 자동 알려주지 않는다.
