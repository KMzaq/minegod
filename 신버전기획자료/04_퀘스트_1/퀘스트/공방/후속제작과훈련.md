# 헤파이스토스의 후속 제작과 훈련

## 문서의 지위와 범위

채택된 획득 기획이다. 실제 서버 등록·구현·배포·플레이 검증은 아직 하지 않았다. 실행 파서에 그대로 넣는 설정 파일이 아니며, 수량·비용·조건·실패 정책은 함께 제공하는 `후속제작과훈련.json`을 기준으로 구현한다.

대상은 RPG-S01-012 헤파이스토스와 이미 정의된 다음 세 콘텐츠다. 새 보상 정의나 같은 장비의 두 번째 복사본을 추가하지 않는다.

- OLY-HEP-W01: 손맞춤 망치 · 짧은 울림. 기존 무기와 내장 우클릭을 합친 한 콘텐츠.
- OLY-HEP-L01: 충격 흘리기. 기존 독립 습득 기술.
- OLY-HEP-T01: 너른굴 곡괭이. 기존 전설 생활 도구.

원래 개인 MAIN 「빛나지 않는 손잡이」의 첫 유효 수락자 독점, 기존 자기 일반 도구의 무강화 손질·반환은 바꾸지 않는다. 공방 Q1 시험작, Q2, Q3 선택 장비와 첫 선택권, 반복 철2의 rolling24시간 최대2회도 그대로다. 구품 반납·교환·승급을 요구하지 않는다. C24 여섯 원본과 합일 공정, 새 캐릭터, 새 주신화 사건은 사용하지 않는다.

## 성장 흐름

기존 공방 Q3 개인 완료 → 망치 의뢰와 충격 흘리기 수업을 원하는 순서로 진행 → 두 수행을 마치면 너른굴 의뢰.

MAIN 소유자가 아니어도 되고, Q3에서 검·망치·곡괭이 중 무엇을 골랐는지도 무관하다. Q3 보상권은 있지만 인벤토리가 가득 차 아직 실물을 못 받은 사람도 후속 의뢰를 시작할 수 있다. W의 제작품 실수령을 T 선행으로 요구하지 않는다. 개인 수행 완료와 실제 보상 인도는 별도 상태다.

현재 유효한 같은 본체와의 접촉·응답 의사·안전한 작업은 필요하다. 세계 해금은 공유하지만 개인 수행과 보상은 공유하지 않는다. 친구 완료, 기부, 팀 가입, 좋은 대답만으로 단계가 완료되지 않는다. NPC의 기존 세계 해금·등장 확률을 새로 설정하지 않는다.

후속 세 의뢰의 예상 시간은 합계48~72분이다. 기존 공방45~75분까지 포함하면93~147분이며, 첫 NPC 조우·파트너 모집·전멸·재고 부족·장기 접속 중단은 제외한다. 후속 콘텐츠가 요구하는 추가 레이드 승리는 W의1회뿐이다.

기존 오버월드 해안 작업장을 사용한다. 동일 본체가 제작대에서 일하며 원격으로 제작하거나 레이드에 참가하지 않는다.

# 권리·실물·쿨타임의 영구 기록

세 보상의 실제 지급 출처는 QUEST 한 경로다. 보스 직드롭·FTB 보상·NPC 직접 보상에 같은 콘텐츠를 중복 배치하지 않는다.

- 첫권리: 개인UUID + canonical 보상 정의 + 기존 콘텐츠 최초획득 범위.
- 이전 범위의 동일 정의 권리가 있으면 그 식별자를 연결한다. 새로운 범위 문자열을 써서 두 번째 FIRST를 만들지 않는다.
- 제작: 개인 제작번호, 자재 로트, 예약·소비 영수증, 실물serial, 현재 소유자와 보관 위치.
- 수행: 개인UUID, SIDE ID, 목표ID, 행동 사건ID, 훈련세션 또는 레이드시도ID.
- 실제 수령: AVAILABLE → DELIVERY_PENDING → 실제 실물/학습 적용 확인 → DELIVERED. 결과가 불명확하면 대조 대기.

인벤 부족은 바닥드롭하지 않고 같은 미수령권과 검수대 실물을 보존한다. 재접속·수령 재클릭·정의 개정은 누락된 단계만 복구한다. 이미 지급된 장비의 정상 분실·용암 소실·디스폰은 미지급이 아니다. 새 무상 재발급을 만들지 않는다.

최종 W/T는 개인 UUID 귀속이다. 타인의 보관함에 있어도 권리는 이동하지 않고 타인의 사용·점수·특수 기능은 생기지 않는다. L은 학습 집합의 같은 정의1개다.

W/L의 일반 쿨은 개인UUID+canonical 기술ID로 저장한다. 같은 무기의 복사본, 임시 지도와 정식 습득도 같은 쿨키를 사용한다. 서버 가동 누적tick의 종료시각을 영구 보존하며 서버 정지 시간은 진행하지 않는다. 교체·반납·재대여·죽음·부활·재로그인·재학습·재지급으로 쿨이나 후딜을 초기화하지 않는다. 준비와 감속 같은 일시 효과만 해당 출처 기준으로 정리한다.

# 조건부 이야기와 NPC의 앎

실물 인도 사실은 DELIVERED 뒤에만 생긴다. 성과를 제출했지만 아직 받지 않은 사람에게 “이미 가져갔다”고 말하지 않는다. 사건을 알았다는 이유로 가호·주시·MAIN·세계 해금·새 관계 사건을 자동 부여하지 않는다.

# 밸런스와 구현 인수

W의 명목 평타는8×1.25=10 HP/초로 기존 공방 검·큰 망치의 명목12보다 낮다. 대신 짧은 우클릭의 작은 다수 대응과 일반 스턴이 있다. 우클릭은 보스 피해만 주며 기믹을 끊지 않는다. 명목 수치를 실제 방어·피격 억제·접근 시간·입력 잠금까지 검증한 DPS라고 부르지 않는다.

W30/10초=3마나/초는 기본 회복2를 넘는다. L18/9초=2는 그 기술만 쓸 때 평형이고 둘을 쿨마다 쓰는 명목 비용은5다. 이론상 장기 비용이 기본 회복을 초과하므로 무한 연타 보상이 아니다. L은 HP 피해나 보스 강제이동을 줄이지 않는다.

T의 높은 효율·행운·무한내구는 장기 생활 편의의 성장이다. 철 채굴 티어·암석5종·허용 구역·광물 확장0·전투력0을 유지하므로 보스 딜 장비를 대체하지 않는다. 기존 낮은 단계 곡괭이를 소비하지 않는다는 점을 수락 전에 고지한다.

구현에 필요한 것과 이미 설명된 기반을 구별한다. item+components, 기본 claim, 마나, K/J, Story 개인 범위가 설명되어 있다는 사실은 이 세 효과가 구현됐다는 증거가 아니다. 다음을 실제로 연결·시험해야 한다.

1. 새 SIDE3개와 개인 조건, 단일 QUEST claim, 기존 권리 연결.
2. 실제 자재·제작시간·본체 가용성·같은serial 대여와 인도.
3. W 평타/부채꼴/공통 입력 잠금과 기존 수호체의 읽기 전용 패턴 관측.
4. L 임시 지도와 정식 학습의 분리, 일반 넉백/기믹 원인 분류, 같은 쿨 원장.
5. T의 보호·유체·지지 블록·청크·드롭1회·입력면·샘플 재개 원장.
6. 실제 관찰·전언·기록 수신·청중에 따른 조건부 지식.

JSON에 서버 인수 사례40개를 제공한다. 기존32개에 오입력·부분확장 재개·지지대 자재 소실8개를 추가했으며 전부 미실행이다. MAIN 비소유자, 세 종류의 Q3 선택자, 10명 뒤 재고 부족, 동시 수령, 불명 결과, 사망·오프라인 승리, 쿨 초기화 시도, 세로·수평 면, 세 차단 블록, 광물·레이드 기믹, NPC의 미관찰 상태를 포함한다. 이 사례를 작성한 것과 게임에서 실행해 통과한 것은 다르다.
