# 북유럽 개인 이야기와 산해 공동 사건 완결 기획

기획 결정 완료본이다. 실제 엔진 등록, 리로드, 플레이 테스트를 했다는 뜻은 아니다. 정의 ID는 이번 작업 기준이며 실행 스키마에 그대로 넣는 파일이 아니다. 원문 이름·정체·전투등급·소속·현재 본체 방식과 무보상 결말을 보존한다.

총 7명이다. 프리그·헤임달·호드르·이둔·프레이는 기존 개인 MAIN 5개를 완결한다. 뇨르드·스카디는 공동 R02 3편을 한 벌로 재사용하고, 기존 MAIN 소유자용 덧대화만 연결한다. 두 사람에게 새 독점 MAIN이나 전체 완료를 추가하지 않는다. 스카디 추적은 수주·완료 배지가 없는 선택 동행이다.

보상 정의는 기존 범위의 정밀화 2개뿐이다. 헤임달은 실제 청음 수강 제공권 1회로 전투 효과가 없다. 프레이는 조약돌 32개·참나무 판자 16개·횃불 8개를 최초 완료자에게 한 번 제공한다. 나머지는 아이템·가호·수치 보상 없음이다.

## 공통 실행 원칙

조우 60초 확인, 후보 가중치1 대 NONE4, 동일 플레이어·장소 300초 대기는 이번 패킷의 미지정 부지만을 위한 기본값이다. 기존 명시값이나 다른 인물·전역 조우를 덮어쓰지 않는다. 재접속으로 대기·순환·본체 점유를 초기화하지 않고 실제 접근 가능한 적격자만 선정한다.

세계 해금은 한 명의 실제 달성으로 모두에게 열린다. 현재 조우 주체, 단일 본체, 개인 관계·MAIN·보상·수신 기억은 별개다. 이미 존재하는 본체와 대화할 때 다시 추첨하지 않는다. 원문 봉인·사망·부재를 해제하거나 새 차원·분신·부활로 대체하지 않는다.

첫 MAIN 수락은 목적·위험·비용·보상·독점을 설명한 뒤 빈 소유칸에 최초 유효 명시 수락자 한 명만 기록한다. 인사나 질문은 수락이 아니다. 사망·로그아웃으로 소유를 넘기지 않는다. 비소유자는 실제 도움을 줄 수 있으나 개인 결말과 보상은 복제하지 않는다.

총 현실 기한은 없다. 명시한 초 단위 관찰은 물리 증거를 얻는 길이이지 접속을 강제하는 마감이 아니다. 이미 끝낸 이동·소비·수신과 물리 월드의 변화를 보존한다. 대사만으로 이동·귀환·제압·물건 인계를 완료하지 않는다.

저자 진실과 NPC 지식, 직접 목격과 전언, 세계 사실과 개인 Knowledge를 분리한다. 현재 실제 청중 모두의 공개 자격을 검사한다. 사적 결과는 제목이나 거절문으로도 부적격자에게 노출하지 않는다.

#### H1. 들린 방향과 보인 것

수량·범위: 현재 경보 1건, 청취지점 2곳, 시야 확인 1회.

판정: 실제 음원 이벤트·수신범위·시야확인 대상 UUID. 후보를 고른 응답 자체는 증거가 아니다.

대사:
- 헤임달: 울림은 들렸다. 적이라는 말은 아직 붙이지 마.

#### H2. 경보의 원인을 없애거나 사람을 돌려보내기

수량·범위: 접수 1건. 선택 수강은 이 단계의 완료와 별개.

판정: 원인확인+소유자 실제기여+선택 H2 성공+유효 수신.

대사:

실패·재개: 부재면 접수만 대기. 전투 미확인을 접수 대사로 건너뛰지 않는다.

분기:

- 실제 궁수 제압: 현재 대상 제거와 경계확인. 새 전리품 지급 없음.

- 미확인 후퇴: 현재 위험·행동만 보존. 완료·훈련권 없음.
