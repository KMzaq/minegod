# P0_MAIN-007 공통 판정과 구현 계약

아래 값은 채택한 저술 기준이다. 실제 코드/월드 등록·서버 인수시험 완료는 별개다.

## 정의 ID

mythictrpg:p0m007_all_contract

## document_status

저술 완료·채택된 구현 기획 기준. 실행용 엔진 스키마가 아니며 코드 구현·등록·서버 실행·플레이 테스트 완료가 아니다.

## 우선순위

현재 정체·등급·신격·소속·실제 본체·현재 생사/봉인·원문 MAIN와 보상 자격을 유지한다. 원문에서 미작성인 일상 수량·동선·물품·판정·시간은 이번 위임 범위에서 결정했다. 주요 사망·새 화신·차원·본편 결말은 만들지 않는다.

## world_encounter

- unlock: 이 패킷은 새 세계 해금 이력을 만들지 않는다. 기존 초기 조우 후보 파르바티·락슈미 등을 재잠그지 않고, 현재 pending인 인물의 일반 조우를 C06/C15 또는 첫 용 처치까지 금지하지 않는다. 기존 허용 접근·세계 공통 가용성을 그대로 읽는다. 새 해금이 이미 있는 세계는 누구 한 명 달성으로 공용이며 후발자의 개인 재달성은 없다.
- scheduling: 아직 현장에 배치되지 않은 확률형 후보에 한해 적합 공용 사이트에서 활성 서버 시간 300초마다 1회. 본 패킷 적격 인물 가중치 각1, NONE4; 다른 패킷의 기존 가중치는 보존해 풀에 합산. 사이트 16블록 이내 현재 통행 가능한 온라인 적격자 중 균등 선택. worldSeed/siteId/checkSequence를 저장해 접속 재굴림을 막는다. 이는 이번 초기 설계값이지 설치된 스폰 코드가 아니다.
- current_body: worldId + productionGodId로 같은 실제 본체를 예약한다. 기존 위치에 본체가 있으면 재추첨·개인별 복제·순간이동 없이 그 위치에서 접촉한다. 봉인·행동/발화 불가·현재 다른 사건 점유는 존중한다. 가용성 미확인은 이번 등장/응답만 보류하고 기존 정사를 무봉인으로 고치지 않는다.
- site: 기존 Overworld 자연 부지/공용 구조물만 선정한다. 모드 바이옴/구조물 후보가 실제 없다면 기록된 vanilla 대체 부지 사용. 새 필수 신전·새 차원·미존재 지형을 만들지 않는다. 상대 앵커와 블록 조건을 실제 월드에 검증해 등록하며 절대좌표를 조사한 것처럼 쓰지 않는다.
- dialogue: 등장 뒤 일반 접촉은 현재 본체·접근·발화 의사·실제 청중을 확인한다. MAIN 미소유·약함·보상 거절·친구의 해금 미달로 인사/공개 관찰을 막지 않는다.

## main_ownership

- key: worldId + mainDefinitionId
- 앎의 습득: 범위·실제 비용·위험·독점 소유·분기별 보상 차이를 제시한 뒤 첫 유효 명시 수락을 원자 compare-and-set으로 단 한 ownerUuid에 기록한다. 제시·인사·후기 청취·참가 등록은 MAIN 수락이 아니다.
- retention: 수락 전 거절은 소유0. 수락 뒤 취소/사망/로그아웃/장기 부재에도 소유·기존 증거 보존, 양도·복제·자동 재수주0. 남이 자기 도움을 마쳐도 소유자의 선택·접수·완료를 대체하지 않는다.
- participants: 현장 최대 플레이어4명(소유자+보조3). 각 작업 시작 전 역할·물품 소유·노동 약정에 본인이 동의한 실제 참가자만 명부에 적는다. 특정 장면의 동의한 NPC는 별도 배우 UUID를 기록한다. 후발자는 남은 실제 작업에 자기 몫을 동의하고 합류할 수 있으나 완료된 과거 역할·피해·노동·지급권을 복사하지 않는다.
- separation: 원문이 실제 조리/교대/호위/대련+수선 기여자에게 따로 정한 권리는 그 개인의 수행으로 성립한다. MAIN 독점 보상과 서로 섞지 않는다. 일반 대화·일상·선택 서비스에 ownerUuid 조건을 템플릿처럼 붙이지 않는다.
- existing_episode_alias: 이 문서의 새 namespaced MAIN ID는 같은 원문 EP 개인 사건의 구현 이름이다. 운영 세계에 해당 원문 episodeId/동일 사건의 owner·진행·권리가 이미 있으면 그 canonicalEpisodeKey를 그대로 재사용하고 새 ID는 alias로 결속한다. 기존 소유자가 있으면 첫 수락 UI를 다시 열지 않는다. 같은 사건에 충돌하는 두 소유 기록이 발견되면 수주/지급만 검증 보류하고 임의 통합·양도·복제하지 않는다.

## execution

- states:
  - OFFERABLE
  - OWNED
  - ACTIVE
  - PAUSED
  - PARTIAL
  - COMPLETED
  - CLOSED_LOSS
- evidence: episodeUuid/attemptUuid/actorUuid/targetUuid 또는 blockPos/itemUuid/actionTick/result를 권위 로그에 적는다. 완료 의향·답안·칭찬·호감은 물리 수행 증거가 아니다. 접수는 이미 발생한 증거를 현재 NPC가 확인하는 단계다.
- 시간: 수락·재개·보상청구 자체에는 현실 마감·오프라인 벌금·새 일일/주간 제한이 없다. 훈련/시범의 tick은 동작 길이이며 접속 대기를 보상 예산에 합하지 않는다. 개별 위험은 실제 월드 상태로 변하며 채팅으로 멈추지 않는다.
- death: 원래 사망·드롭 규칙을 유지. 소유자 사망은 성공이 아니며 정상 부활 후 안전선에 실제 돌아와 남은 수행을 잇는다. 사망 연결 관찰은 공로·귀환을 대체하지 않는다. 같은 실물/생존 NPC를 되감거나 실제 사망한 고유 배우를 부활·복제하지 않는다. 실제 불가능해진 목표는 CLOSED_LOSS로 손실 기록, 성공 보상0.
- logout: 진행·대상·물자·수령·실제 청중·동작 checkpoint를 저장한다. 합의 대련은 다음 공격 중지 후 현재 안전선으로 중단하고, 환경 위험은 남는다. 청크 비활성화 동안 물리 이동/시범은 정지, 온라인 배우가 실제 계속한 세계 변화는 유지. 접속 자체를 귀환·돌봄·비행 도착으로 판정하지 않는다.
- abort: 철회는 아직 실행하지 않은 명령만 중단. 실제 이동·부착·소비·수령·손실은 남는다. 빌린 도구/짐은 실제 가진 경우에만 반환 책임. 미수령품 반환 관문은 없다.
- sparring: 참가자가 동의한 제한 동작만. 시작 HP12/20 이상·허기12/20 이상·지상 안전선·현재 원시 피해 상한을 제시한다. 한 명 HP6 이하, 중단 신호, 비참가자 진입, 장비 문제, 접속 끊김이면 신규 공격 예약을 취소하고 끝난 충돌은 보존한다. 안전 차단은 훈련용 의도 공격에만 적용, 일반 전투 무적/부활이 아니다. 실제 최상/초월 본체의 전력을 훈련 수치로 바꾸지 않는다.
- protected_world: 플레이어 건축·타인 소유·보호영역·비대상 블록은 작업/활/가공 대상에서 제외. 소품 파괴는 원본 UUID와 보호권 대조. 이미 수선된 시설을 다시 부수어 진행량을 만들지 않는다.

## inventory

- contract: 모든 물자에 제공자·소유근거·정확한 vanilla item 또는 등록 변형·계획량·예약량·실제 인수량·소비량·반환량을 둔다. 계획재고는 신규 장면 배치의 채택값이고 이미 서버에서 확인한 실재 재고라는 주장이 아니다. 시작 전 해당 소유자의 실제 인벤토리/보관함에 그 양이 없으면 부족분만 보류한다.
- ledger: AVAILABLE→DELIVERY_PENDING→DELIVERED와 reservation/journal/itemUuid를 대조. DB 저장과 인벤토리 저장을 각각 호출했다는 이유로 원자 거래라고 부르지 않는다. 같은 원장의 부분 지급만 복구한다.
- late: 독점 MAIN 물건은 서버1개/지정 소유자1권리가 우선이다. 작업이 끝난 뒤 온 사람을 위해 같은 파손/구조/판매를 재발생시키지 않는다. 이번의 비독점 기여몫은 참가자4인 상한 내 실제 남은 작업량에 한정하고 무한 재보급0. 별도 신규 제작 의뢰를 추가하지 않았으므로 불필요한 10개 유일물 복제도 없다.
- divine_equipment: 신이 제공한 장비는 특별한 유한내구 콘셉트가 없는 한 무한내구. 소실불가·무료 무제한 재발급은 아니다. 인간 아르주나/드로나가 준 일반 물건은 그 이유로 신제화하지 않는다. 대장장이 직접 제작 예외는 독립 스킬·가호·레이드 지원 자격 확장이 아니다.
- existing_claim_alias: 원문 동일 지급권의 claim/delivery/lesson 기록이 이미 있으면 이번 reward ID에 같은 canonicalClaimKey를 연결한다. 문서 개정·새 정의 ID라는 이유로 두 번째 권리를 주지 않는다. 미수령만 기존 원장 증거로 복구한다.

## knowledge

- separation: author_truth·Story Fact·기존 자기 기억·신규 실제 관측/전언을 분리. 이 문서의 미발생 사건은 initial_knowledge=false. 공개 완료가 모든 NPC/후발자의 지식이 되지 않는다.
- 앎의 습득: 시야24블록 이내의 실제 눈 위치 raycast, 보통 발화12블록 실제 수신, 공개 기록은 실제 열람을 기본값으로 한다. 청취는 직접 관측을 대신하지 않음. 보고는 전달자·내용·검증 범위·수신자를 저장한다.
- privacy: 청중 전원 공개 자격 검사. 비공개는 수신 UUID allowlist 채널만 사용하고 공개 fallback0. 제목·거절 이유·퀘스트 알림에도 비밀의 존재를 흘리지 않는다. 관계자에게는 별도 실제 수신/응답 때만 지식 추가.
- relations: 현재 관계·과거 친족 기억은 상대의 현재 위치·동의·새 고백·용서·복종이 아니다. 입력 간선의 화자/주어를 바꾸어 다른 인물의 출생·가족·사망으로 복사하지 않는다.
