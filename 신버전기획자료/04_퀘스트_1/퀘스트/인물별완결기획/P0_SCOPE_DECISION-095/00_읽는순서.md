# 북유럽 네 인물의 기존 범위와 획득 연결

1. 공통계약의 세계/개인/실물/지식 구분을 먼저 읽는다.
2. 오딘 SIDE, 토르 개인 MAIN, 로키 개인 MAIN, 헬라 지역사건 순으로 인물별 MD와 JSON을 읽는다.
3. 토르·헬라의 네 획득 사건은 기존 결말과 별개다. 기존 콘텐츠 정의를 복제하거나 원래 보상을 바꾸지 않는다.
4. 스킬연출은 각 획득 JSON에 결속된 최신 시트를 사용한다.

수량·시간·권리·부지·분기·복구는 이번 기획 기준으로 채택했다. 새 주요 정사·새 성장보상 정의는 없다. 실제 서버 구현과 플레이 시험은 하지 않았다.
