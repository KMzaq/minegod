## 실제 수행
1. 현재 운반자가 공개 허락한 상자1을 열어 실제 무장 운송품과 민간 생활품을 나란히 놓고 원래 보호약속과 대조한다. 실제 품목이3개 미만이면 있는 수량만, 밀봉이면 의심만 기록. 테미스에게 왕의 예외까지 심사할지 또는 생활품만 내밀지 선택, 은폐 시 미검사 화물 승인0.
2. 왕 표식 제외화물과 자기 보호범위 밖 짐을 지정 보관칸에 실제 내려놓고 민간 짐만 허락된 수레/운반체로 굽이12블록을 함께 이동해 도착 확인. 자기 예외를 유지하면 해당 짐은 싣지 않고 별도운송 대기, C14에서 이미 완료한 같은짐은 재운반하지 않는다.
3. 제우스와 비살상 이동 규칙에 각각 동의. 60초 겨루기에서 제우스는 중앙 또는 좌우 통로를 10초마다 하나 선택, 선택2초 전 손짓·해당 발밑 테두리 표시 후 초당2블록 보행. 플레이어를 관통하거나 순간이동하지 않는다.
4. 짐 지키기: 자기 짐1을 실제 보관선에 둔 채 2블록 안에서 옆으로 이동하여 15초 보호선을 유지, 왕의 먼 통과는 허용. 길 끊기: 자기 짐을 허락된 받침에 내려놓고 왕이 선택한 통로 앞 2×2 차단칸을 3초 선점하면 정지 판정. 공격·밀치기·블록 추가는 불가. 둘 중 선택한 목표1의 실제 이동 로그로 승부 종료.
