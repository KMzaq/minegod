# P1_OTHER_QUEST-020 공통 계약

## 상태
이번 기획권한으로 채택한 완결 저술 기준. 실행 스키마가 아니며 등록·리로드·실플레이 미검증.

## 범위
각 관리키의 개인 MAIN은 NOT_APPLICABLE. 명시 수락은 해당 SIDE/국소 사건 참가만이며 독점 MAIN·주시·가호·세계해금을 대신하지 않는다. 일반 인사에 이 SIDE 완료를 선행으로 붙이지 않는다. 원문 현행 세계해금·조우·접근·봉인·발화 제한은 유지하며 그 후보를 이 문서로 자동 활성화하지 않는다. 안전한 조사·자료대조·생활실습의 원문 초반 예외에는 전투력 최소컷을 추가하지 않는다. 활동 시작은 동일 본체의 실제 접촉·의사, 현장 접근·작업허락, 항목별 실물 조건을 확인한다.

## 상태저장
definition_id + world_case_uuid로 현장 사건을 식별하고 attempt_uuid별 참가 UUID·수락시각·단계증거·원래 소유자·물체 UUID·관측시각·청중·동의 버전을 저장한다. AVAILABLE→ACCEPTED→ACTIVE→RESOLVED 또는 WITHDRAWN/FAILED. 검증된 단계는 저장하고 파괴·소실된 세계를 롤백하지 않는다.

## 시간과중단
개별 제한 외 총 제한 없음. 일시 중단·로그아웃은 개인 미완 단계만 정지하고 물·적·다른 참가자 행동은 계속한다. 120초 부재 후 점유 작업대/차례를 해제하되 권리와 기여를 지우지 않는다. 재접속은 현재 물체와 증거를 대조해 다음 가능한 단계부터, 이미 끝난 구조·반환은 재연하지 않는다. 숫자 초는 서버가 가동 중인 권위 시계의 경과초다. 개인 미완 단계 정지는 목표 입력만 멈춘다는 뜻이며 이미 시작한 제우스60초·포세이돈120초·암피트리테90초·니케90초·관측60/120초는 로그아웃으로 멈추거나 초기화하지 않는다. 전원 부재·청크 비활성으로 물리 증거가 없으면 경과시간만으로 성공하지 않고 현장 재검증한다. 서버 중단 동안 시계는 보존·정지하고 복구 후 잔여시간을 잇는다.

## 사망
플레이어 사망은 해당 진행 중 기동·전투 시도를 실패 처리하고 실제 드롭·내구·소모를 서버 원칙대로 남긴다. 생존 동료의 구조/작업은 계속된다. 수락 NPC나 실제 대상이 사망/봉인/부재하면 필요한 단계만 중지하고 대역·부활·원격 응답을 만들지 않는다. 이미 확정한 완료/미수령권은 유지한다.

## 동시와후발
한 물체·본체 작업은 서버 승인순 한 사건만 쓰기 점유. 최대5명 동시 참가, 역할마다 실제 증거를 기록한다. 다음5명은 현재 남은 새 작업이나 허락된 별도 실습으로만 참여하며 이미 해결된 위기를 복제하지 않는다. 같은 현장의 후발자는 공개 결과를 배우되 이전 공로/보상/사적 기억은 받지 않는다.

## 비용과수령
기본 참가비0·금화0. 자기 음식/내구/설치재료는 실제 쓴 만큼만 소비. 보상은 각 항목에서 정의한 개인 최초1회, 반복지급0. claim=player_uuid+reward_definition+first_scope. 완료와 제안·수락·지급은 분리한다. 인벤 부족은 바닥드롭 없이 AVAILABLE, 부분 전달 영수증과 예약 재고를 대조해 누락분만 복구한다. 결과 불명 상태는 물체UUID·인벤·원장을 먼저 조회, 재지급으로 복제하지 않는다. first_scope는 해당 reward_definition의 캐릭터 생애 최초 권리로 고정하며 case/attempt/world 교체로 새로 만들지 않는다. 묶음의 map/repair/parts/practice 등 라인별 동일 claim 하위 영수증을 유지한다. 보수는 대상UUID·수리직전 damage·수리후 damage=max(0,직전damage-32)·재료1·receipt를 원자 확정하고 재요청은 같은 결과를 조회한다. 완료 후 물건 분실은 지급실패가 아니며 별도 분실복구 권한을 만들지 않는다.

## 재고
유한 보상 재고는 각 항목 stock의 구체 수량이 기준이며 참가자별 수락 때 필요한 보상분만 예약한다. 일반 묶음은 초기10인분, 선택형 보수는 아래 별도 규칙을 따른다. 실제 기부·제작·인계로 확인된 수량만 보충하고 시간 자동보충0. 재고 없음은 보상 약속을 새로 수락하지 않고 무보상 참여 또는 대기를 선택한다. 명시 거절·철회·확정 실패로 미발생한 권리의 예약은 해제하고, 확정 완료의 미수령분은 반환하지 않는다. 후발 실습은 원래 보상의 수행조건을 만족하지 않으면 새 권리를 주지 않는다.

## 지식
현장 사실 SF.<definition_id>.<case_uuid>에 실제 완료/실패/손실/선택과 증거를 보존한다. 각 NPC는 직접 관측 또는 허락된 전달 영수증을 받았을 때만 개인 기억을 갱신한다. 공개 발화는 같은 차원 12블록 이내 실제 청취 가능자, 시각 사건은 24블록 이내 가시선 확인자만. 비공개는 명시 수신UUID만, 비공개 채널 미지원이면 보류. 후발 열람은 별도 received_at를 남긴다. 저자 진실·미래 결과·파티 전원 지식을 자동 주입하지 않는다.

## 지원경계
이동·보트·블록 설치/철거·인벤·바닐라 물/적 등은 기본 Minecraft 기능 기반이다. UUID별 작업증거·수락/재고/청중 원장·NPC 이동동의·서비스 수리·관측 UI·조건판정은 새 연결 구현 요구이며 지원되었다고 주장하지 않는다. 사건 소품ID는 기획 논리ID, 엔진 등록명은 원문 profile godId만 생산 참조한다. 특수 물밀침 억제, 수동 범위 표시, 사건용 NPC 탑승/도보 호위와 사망 연동, 지도 주석과 관측 UI 역시 신규 연결 요구다. 바닐라가 자동 제공한다고 가정하지 않는다.

## 공통인수

## 추가 판정·복구 계약

### 정의와부지
각 문서 definition_id가 사건 정의이며 reward.definition은 같은 문서 reward 객체의 완전한 논리 정의를 가리킨다. 공통계약은 이 패킷11건에 적용한다. site의 O·상대좌표·물체ID는 실제 기존 적합 현장에 world_case_uuid와 함께 dimension/anchor/회전/절대좌표/물체UUID/소유자/허락범위를 결속해 수락 전에 고정한다. 지형의 수평 회전·이동만 허용하고 거리·폭·안전조건을 맞출 수 없으면 대기한다. 보호부지 우회·새 본체·새 위기·새 필수 건축0. 소품·원소유자 반환함은 기존 실물을 선택하며 없는 물품은 생성하지 않는다.

### 기억과권리
RESULT는 사건 정의의 결과 종류이고 SF.<definition_id>.<world_case_uuid>.<attempt_uuid>는 개별 발생 식별자다. facts에는 정의·시도·시각·증거·실제 목격/전언·허용청중을 연결한다. 참가 명부 자체는 개인 지식 수신 근거가 아니며 참가자도 실제 본/들은 필드만 received_at로 습득한다. NPC의 감정·다음 의향은 실제 응답 때만 기록한다.
