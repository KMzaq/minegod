# 가이아·아라크네·에코: 현재 범위 완결안

현재 정체와 허용된 역할을 구현 가능한 행동으로 정리한 기획 원고다. 실행 스키마가 아니며 게임·API·LLM 시험은 하지 않았다.

- 가이아: 기존 PE-MG-S01-023-01을 유지한 비독점 SIDE 1편. 일반 인사와 별도이며 MAIN은 없다. 기존 선택 지도·현지 재료를 구체화하고 무보상 종료를 보존한다.
- 아라크네: 일반접촉 1편과 그 안의 선택 직조 실습. 새 MAIN·보상 의뢰·장비 제작 서비스는 만들지 않는다.
- 에코: 승인된 문구 조합 발화로 일반접촉 1편과 선택 포획 SIDE 1편. 대상별 보호 당사자 전원의 명시동의와 최종 재확인을 적용한다. 승인된 기획이며 런타임 등록 완료는 아니다.

## 세계와 개인의 다섯 층

세계 해금은 공통이다. 현재 유효 조건을 누군가 이행했다면 후발자가 같은 행동을 반복할 필요가 없다. 기존 배치/접근을 새 무작위 풀로 바꾸지 않고, 미채택 신규 해금 제안은 이번 원고가 자동 활성화하지 않는다.

아직 등장 전에는 현재 후보의 장소·안전·기존 조건 및 단일 본체 가용성에 기존 조우 판정을 적용한다. 성공한 플레이어가 조우 주체다. 해금 달성자와 같을 필요도, 아직 등장하지 않은 본체가 이미 현장에 있을 필요도 없다.

이미 등장한 같은 본체에는 새 추첨 없이 접촉한다. 동행자의 목격·일반 접촉은 개인 해금 부족만으로 차단하지 않는다. 현재 안전, 당사자 의사, 사적 응답 허락과 에코의 발화 제약은 유지한다.

개인 수락·기여·관계·권리·수령은 복사하지 않는다. 공용 물길과 물건의 상태, 특정인이 한 행동, 특정 NPC가 실제 안 사실은 별도다. 누군가 한 일을 알아도 자신이 한 일이 되지 않는다.

## 저장과 복구

한 활동의 고유 시도와 실물 식별, 행위자, 변경 전후 상태, 소유자 허락, 실제 청중, 제안·수락·결과·수령을 분리 저장한다. 서버 판정 성공 후 응답이 끊기면 원장을 읽어 아직 반영하지 않은 부분만 복구한다. 대화 선택만으로 물건 이동·관측·실습이 완료되지 않는다.

로그아웃이나 사망은 NPC를 다시 만들지 않는다. 실제 손실은 정상 서버 규칙에 따르며 오프라인이라는 이유만으로 새 피해를 만들지 않는다. 살아 돌아오면 현재 안전과 물건을 재확인한다. 후발자는 남은 작업이나 현재 공개 결과부터 참여하며 과거 참가자로 소급하지 않는다.

가방 부족이면 확정된 미수령분만 원래 제공자에게 보존한다. 이미 받은 물건의 사망 드롭·분실은 새 권리가 아니다. 지급과 소비의 부분 실패는 한 거래 원장으로 되짚고 두 번 주지 않는다.

## 지식과 구현

직접 관측·전언·추측·저자 진실을 구분한다. 사실 상태 기록과 지식 부여는 별개이며, NPC는 실제 목격/수신한 범위만 기억한다. 정식 지식 전달은 기존 등록 사실·공개 단계·실제 청중 계약을 따른다. 이 원고의 설명을 대사로 읽었다고 정식 지식 등록이 완료되지는 않는다.

블록·베틀·현수막·일반 재고는 Minecraft의 실제 대상이다. 단일 본체 연결, 작업 원물 추적, 허락 검증, 가이아 현장의 제한 지반 위험, 실제 청중·원자 정산은 별도 구현 요구다. 현재 지원됐다고 단정하지 않는다. 새로운 전투 기술·장비 등급·가호·부활·세계 전체 지형 변경은 없다.
