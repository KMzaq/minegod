- 문서상태: 기획권한으로 채택한 완결 저술. 런타임 스키마·등록·구현·서버/플레이 시험 아님.
- 범위: 기존 16역의 현재 역할을 완결한다. 본편8레이드·키메라·성장·결말의 전투와 지급권은 단일 현행 정의를 참조하며 재발행하지 않는다. 모든 인물에 개인 MAIN을 만들지 않는다.
- 세계와개인: 해금은 세계 공통. 본체는 인물별 세계에 하나. 현재 만난 같은 본체에 후발자는 개인 재해금 없이 접촉하되 응답 의사·안전·허용 발화모드를 따른다. 실제 수행·청취·관계·수령권은 개인별이다.
- 정체: 원문 관리키·등급·성별 미지정·소속을 유지한다. 원문 profile의 godId가 있는 세 인물은 해당 생산 양식을 연결하되 등록 성공을 주장하지 않는다. 나머지 관리키를 새 God ID로 변환하지 않는다.
- 수락과저장: 질문/설명/접근은 수락이 아니다. 선택 SIDE는 목표·소모·보상·중단을 읽은 각 수행자의 명시 수락을 기록한다. 사건은 현장 의사만 사용하며 MAIN 소유 없음. 세계·NPC본체·사건정의·시도·수행자UUID·대상블록/물품·증거·수신단위·수령거래를 따로 저장한다.
- 공동수행: 최대5명 예시를 수용하되 입장인원 컷은 아니다. 개인 수행은 자기 목표만 완료한다. 공용 블록 작업은 처음 합의한 작업자별 실기여를 저장하고 같은 변화에 서로 보상을 중복 부여하지 않는다. 수락 후 완료 전에 합류자는 남은 목표에만 참여하며 끝난 공로를 소급받지 않는다.
- 일반복구: 시간 제한 없음. 사망·로그아웃·이탈은 실제 완료단계/물품위치를 보존하고 미수행만 재개한다. 물품은 바닐라 드롭/실제 보관상태를 확인해 회수하며 소실품 복제0. 플레이어가 중단·철회하면 미완 약속을 닫고 아직 맡은 NPC물건만 실제 반환한다. 동의 철회가 작업과 동시이면 미시작 작업을 막고 이미 일어난 물리는 대조한다.

- 영구부재후미수령: 요정 생전 완료검증과 수령권 확정이 끝났다면 기존 권리는 유지한다. 실제 당시 확정된 동일권리의 기술적 수령복구만 원장의 증거대로 수행한다. 죽은 요정의 새 축복 대사·시전·지원행동을 만들지 않으며 새 권리도 없다. 아직 완료검증 전이면 미완/이행불가이지 사후 성공이 아니다.
