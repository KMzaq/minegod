# 루브라스: 한 겹을 풀어도 남는 것

채택된 제작용 기획. 실행 스키마·서버 구현·영상 검증 완료본이 아니다. 수치와 상세 판정의 단일 정의는 함께 제공하는 「루브라스_첫외곽층_공정기획.json」이다.

## 이번에 완결하는 범위

LUB02의 비전투 로컬 사건 1개: 세 조사면 확인 → 선택 → 양측 한정 동의 → 전용 물품 제작·사용 → 실제 첫 외곽 이동 제한층 1개 분리 → 잔여층 확인 → 조건부 일반 인사.

새 개인 MAIN 0, 서비스 0, 실물 보상 0, 작업용 특수물품 정의 1개다. 별도 개인 MAIN 계약이 없는 현재 범위에 따라 로컬 공정으로 선택했다. 위험 지역의 전쟁 기록 회수 MAIN이라는 기존 채택 방향을 삭제하지 않지만, 이 작업은 그 의뢰의 제안·수락·소유·완료가 아니다. 기록 회수 원정을 해제 도구 조립으로 대체하지 않는다.

루브라스는 초월급 진짜 용 최강의 드래곤 로드, 천군 군단장, 천마의 신뢰받는 오른팔이다. 천마가 더 강하며 신격은 미지정이다. 사탄과 별개다. 거짓말할 수 없지만 침묵하거나 답변·협력을 거절할 수 있다. 첫 엔더드래곤 이전의 만남은 가능하되 실제 한 겹 해제와 남은 접촉 조건이 필요하다. 일반 조우 전에는 봉인석 바로 곁 작업 설명·안전·동의를 위한 짧은 응답만 가능하다.

## 현장과 실제 조사

현재 생활권의 기존 동굴 안전 옆길에 있는 단 하나 봉인 현장을 재사용한다. 신규 현장 배치가 필요한 경우 주택·보호구역·본편 조각실과 겹치지 않는 건조 동굴을 택한다. 새 신화 차원·거대 거점·필수 NPC·전투를 추가하지 않는다.

봉인석 작업면 하단 중앙을 O로, 바깥쪽을 +Z, 오른쪽을 +X로 정한다. 조사면은 A=(-3,1,3), B=(0,1,3), C=(3,1,3), 귀환점은 (0,0,8), 제한 접촉점은 (0,0,2)다. A는 외곽 연결, B는 안쪽 문양과 별도로 놓인 외곽 전용 소켓, C는 귀환 안전선이다. 각 표적은 1×1블록 면이며 폭3·높이3블록 이상의 안전 동선으로 잇는다. 보호 구역과 본체 모델 전체의 공간은 JSON의 site 규칙을 따른다. 안전영역은 O 기준 X -4.5..4.5, Z 1.5..9.5의 연결 바닥 위3블록 높이다. 조사면은 +Z를 향하고 지정 좌표가 면 중심이다. 점검대는 (1,0,3), 조립 거리는 직접 시야4블록이다. 적대 개체·피해 투사체·불·용암 유입이나 귀환 동선 단절은 확정 전 작업을 중단하며 자동 적 제거·무적은 없다. 시간은 서버 게임tick으로만 세고 정상20TPS에서40/60/100tick은2/3/5초이며 지연·오프라인 시간은 보충하지 않는다. 치수가 부족하면 현장을 수정하고 검수하며 본체를 축소·복제하지 않는다.

각 면에서 4블록 이내, 벽 없는 시선으로 우클릭을 40tick 유지한다. 세 면과 C의 로컬 점검 기록을 실제로 읽어야 한다. 설명 답안이나 다른 사람 완료 배지는 관찰을 대신하지 못한다. 조사 순서는 자유이며 중단해도 끝낸 관찰은 보존한다. 상태 버전이 달라졌으면 현재 문양을 다시 확인한다.

조사만 또는 봉인 유지 선택은 세 면 확인 후 출구에 도착하면 끝난다. 루브라스 응답·특수물품·재료 소비는 필요 없다. 유지는 향후 모든 해제 논의를 금지하는 영구 투표가 아니다. C02·LUB01·C12·C17·첫 용 토벌 완료 도장을 새 선행으로 삼지 않는다.

## 작업 물품: 외곽층 분리쇄

외곽층 분리쇄는 구리 고리 세 개를 철 손잡이로 이은 0.55블록 길이의 현장 전용 도구다. 종이 대조띠에는 현재 조사한 연결이 표시된다. 무기·장신구·가호·소환권이나 보상은 아니다.

- 정의 ID: LUB02-ITEM-OUTER-SPLITTER.
- 제작: B 옆 점검대에서 철 주괴 2, 구리 주괴 4, 종이 1을 선택 슬롯에 넣고 100tick 조립해 1개를 만든다. 일반 작업대·상인·자동 제작은 불가하다.
- 획득 조건: 제작자가 현재 세 면을 실제 조사하고 지정 외곽층이 아직 닫혀 있어야 한다. 동의 전에 도구를 준비할 수는 있지만 사용할 수는 없다.
- 현장 점검 기록의 조립도를 이용한다. 점검 담당자를 새 필수 NPC로 만들거나 전쟁 비밀을 조립도에 넣지 않는다.
- 조립이 완료되는 순간 재료 차감과 고유 serial 생성이 함께 확정된다. 중단·피격·이탈·로그아웃·가방 부족이면 재료 차감 0이다.
- 현장 ID와 지정층 버전에 결속하며 세계의 해당 현장당 활성 도구는 1개다. 이름만 바꾼 철괴, 다른 층, 다른 봉인, C17 장치와 제5원본에는 호환하지 않는다.
- A 준비에서는 소비하지 않는다. B에서 실제 외곽 연결 분리를 확정할 때만 1개 소모한다. 마나 0, 피해 0, 전투 쿨다운 해당 없음, 부산물·환급·경험치 0이다.

이 도구는 다른 플레이어의 일반 재산이나 MAIN 권리를 넘기는 열쇠가 아니다. 양측이 명시적으로 양도·수락하면 같은 serial의 보유자만 바뀐다. 등록 보유자가 오프라인이고 현장 제작·해제·양도 세션이 모두 종료된 경우에만, 새 작업자가 현재 세 면 조사와 자기 재료 철2·구리4·종이1로 대체 제작할 수 있다. 100tick 완료 직전에 부재·세션 없음·층 닫힘·옛 serial을 재검사하고 재료 차감·옛 serial 무효화·새 serial1개 발행을 함께 확정한다. 취소·가방 부족·경합·보유자 복귀는 변화와 차감 0이다. 옛 물품은 무효 껍질만 되며 타인 인벤토리에서 강제로 회수하지 않는다. 최초 제작·대체·양도·무료복구·분리는 같은 원장을 원자적으로 대조하므로 유효 도구는 항상 최대1개다. 주운 물품도 등록 사용권이 없으면 사용할 수 없고 원주인에게 반환할 수 있다. 부재자의 다른 물건·개인 계약에는 영향이 없다.

사망에는 도구가 통상 드롭될 수 있고 같은 serial을 회수한다. 실제 파괴·디스폰을 확인했으며 아직 소비 전인 경우에만 옛 serial을 폐기하고 같은 작업권 도구 1개를 무료 복구한다. 위치 불명이나 단순 부재를 소실로 단정하지 않는다. 이미 해제에 소모했다면 재발급 0이다. 일반 재료와 다른 사망 장비는 복구하지 않는다. 제작은 완료됐으나 인수 실패한 물품은 동일 serial로 대기하며 재료를 다시 차감하지 않는다.

## 한 겹 작업과 루브라스의 태도

1. 조사 결과를 봉인석 바로 곁에서 전한다. 플레이어는 외곽 이동 제한층만 조작하고 루브라스는 작업 중 조사 안전선 밖으로 힘을 뻗지 않기로 한정한다. 위험 유입, 안쪽 반응 이상, 철회, 중단 시 분리 확정 전에 멈춘다. 실제 승인·작업자 명시 선택이 있어야 진행한다. 침묵은 승인이 아니다.
   - “한 겹이다. 안쪽에는 손대지 마라.”
   - 지배권을 요구하면 “너는 한 겹을 제안했다. 내 생 전체를 사겠다고 말하지 않았다.”
2. 분리쇄를 손에 들고 A에서 60tick 사용한다. 현재 외곽층과 잔여층 상태를 분리해 저장하고 외곽 고리만 잡는다. 아직 봉인 변화와 도구 소비는 없다.
   - “그 바깥 고리까지다. 내가 말한 선은 바뀌지 않았다.”
3. B의 전용 소켓에서 같은 도구로 100tick 연속 사용한다. 거리 4블록, 직접 시야, 물품 serial, 동의, 안전, 현재 버전을 매tick 확인한다. 마지막 tick에 OUTER-MOBILITY-01을 닫힘에서 열림으로 바꾸면서 물품 1개를 같은 거래로 소모한다.
   - 확정 전: “멈춰야 하면 지금 말해라.”
   - 실제 변경 후: “바깥의 당김 하나가 풀렸다. 전부는 아니다.”
4. C에서 40tick 잔여층 반응을 관찰하고 출구 반경 1블록에 실제 도착한다. 지정층 연결만 끊겼고 나머지 봉인 상태는 작업 전과 같아야 한다. 기술 상태와 실제 연결을 읽어 판정하며 문양 애니메이션이나 대사만으로 성공시키지 않는다.
   - “남은 것은 남았다고 적어라.”
5. 같은 본체의 현재 발현·위치·잔여 제한·세계 수용·접촉자 수용·응답 의사를 별도로 확인한다. 실제 대화 접촉면 4블록 안에서 안전한 시야가 확보되어야 일반 인사로 넘어간다.
   - 처음 이름을 듣는 경우: “이제 이름을 들어도 되겠군.”
   - 실제 기여를 인지한 경우: “도운 것은 안다. 다음 약속은 따로 정한다.”

본체의 형상·크기는 기존 설정을 유지한다. 해제 후 이동은 첫 작업 전에 저장한 기존 봉인 위치의 본체 기준점 H0에서 수평 반경 8블록 이내의 충돌 검수된 연결 바닥을 상한으로 한다. 중심 H0는 이동·재접속으로 갱신하지 않는다. 모든 단계와 언로드 후 재로딩에서도 동일 영속 actor UUID를 유지하며, UUID를 대조하지 못하면 이동·일반 접촉을 보류한다. 필요하면 실제 이동 가능한 한 구간에서 4블록 이내 이동을 검증하되 이동 거절을 처벌하거나 강제하지 않는다. 발현·접촉이 검증되면 인사를 할 수 있으며 이동 자체가 새로운 과제는 아니다. 비행·차원 이동·원격 공격·원정 지원을 이 단계가 열지 않는다.

한 겹을 열었지만 본체 표현이나 수용 검증이 안 된 경우 ‘외곽층 해제, 일반 조우 미완료’다. 해제를 되돌리지도, 없는 일반 만남을 완료했다고 쓰지도 않는다.

## 실제 한 겹 판정과 복구

변경 전에는 지정층 닫힘, 나머지 봉인 스냅샷 R, 단일 본체 A, 세계 버전 V를 확보한다. 변경 후에는 지정층 열림, 동일한 R, 동일한 A, V+1, 소모된 serial 1개만 남아야 한다. 전체 층 수를 새로 확정하지 않으며 안쪽 힘의 구속은 그대로다.

공정은 준비기록 → 상태·소모의 원자 커밋 → 물리 표현 동기화 → 검증으로 연결해야 한다. 커밋 전 실패는 닫힘·미소모, 커밋 후 연출 장애는 열림·소모 유지 후 동일 표현 재동기화다. 커밋만 완료되고 실제 연결 비활성·잔여층 불변·동일 actor UUID 검증이 남으면 released_unverified로 보존하며 성공 대사·실제 해제 목격 지식·일반 조우를 먼저 지급하지 않는다. 저장 원자성을 보장하지 못하면 해제 경로를 배포하지 않는다.

- 작업 전 또는 B 진행 중 사망·로그아웃·거리 이탈·시야 차단: 현재 사용 타이머만 초기화, 조사 증거·미소모 도구 유지, 정상 사망 손실 적용.
- 분리 뒤 C 확인 전에 끊김: 열린 세계를 유지하고 C 확인만 재개, 소모 재청구 0.
- 동시 작업: 현장 실행 잠금 1개와 버전 비교로 첫 유효 커밋만 적용한다. 다른 사람의 조사·유지는 진행 중인 작업을 덮어쓰지 않는다.
- 동의 철회: 커밋 전에는 정지한다. 커밋 후 철회가 이미 열린 층을 다시 닫는 버튼이 되지는 않으며 이후 작업·접촉만 중단한다.
- 상태 불명: 새 시도를 겹치지 않고 저장 커밋·실제 연결·물품을 대조한다. 성공 여부를 추정해 환급하거나 층을 한 번 더 열지 않는다.
- 후발자: 현재 열린 현장으로 접근한다. 개인 재해금이나 분리쇄 재제작을 요구하지 않는다. 과거 첫 해제·동의·기여를 소급하지 않는다.

## 지식, 관계와 기존 사건의 경계

공용 사건은 ‘지정 외곽층 하나가 실제 해제됨’이다. 개인 기억은 누가 조사·재료 제공·제작·분리·잔여층 확인을 했는지, 누가 제안과 응답을 실제 들었는지로 나눈다. 루브라스는 몸의 변화는 직접 경험하지만 현장 밖 채광 공로는 보았다고 말하지 않는다. 실제 전달받은 기록은 보고로 기억한다.

공개 작업 기록에는 층 명칭·시각·현장 버전·잔여층 검증 여부만 남긴다. 사적 약속과 대화는 당시 청중·허용된 전달 범위로 제한한다. 후발자가 기록을 읽기 전에는 공용 상태가 개인 지식이 되지 않는다. 이름·우정·주시·가호·MAIN 권리를 함께 배포하지 않는다. 알려진 사실, 전언, 추론, 비공개, 모름을 구분한다.

- LUB01의 두 암반·문양·기록 조사와 귀환은 그대로다. LUB01 배지 없이 현재 현장에서 조사할 수 있다.
- LUB03은 실제 자료를 받고 판단하는 단독 면담과 승인된 의견의 실제 전달로 완결한다. 미승인 별도 용 배역은 활성화하지 않는다.

## 연출과 제작 인수

A에서 가는 고리 3개를 20tick씩 보여 준다. B에서는 고리가 외곽 문양만 잡고 100tick 동안 연결 선을 바깥으로 0.25블록 당긴다. 실제 커밋에 외곽 선 하나만 밝아졌다 끊어지고 낮은 금속 풀림음이 0.5초 들린다. 고리 흔적은 20tick에 사라지며 안쪽 문양은 그대로다. 실패하면 원위치로 돌아갈 뿐 전체 봉인 균열이나 폭발은 없다.

연출은 공격이 아니다. 판정은 1×1블록 표적면에 대한 최대 4블록 직접 ray hit뿐이다. 벽을 통과하지 않고 아군·적·다부위보스 피해와 넉백은 모두 0이다. 작은 큐브 임시물이나 문양을 가리는 파티클 구름은 완료 자산으로 인정하지 않는다. 도구 모델, 고리·손잡이·대조띠 텍스처, 구별 가능한 조사면, 외곽만 분리하는 애니메이션, 단일 본체와 실제 접촉 바인딩이 필요하다.

예상 플레이 시간은 조사/유지 약 5분, 재료를 갖춘 해제 약 8~12분이다. 초기 자원 수집은 환경에 따라 10~25분가량 추가될 수 있다. 정적 기획 예상이며 실제 플레이 테스트 결과가 아니다. 비용은 관계 접점의 선택 비용일 뿐 전투 보상 구매가 아니다. 기존 무보상 선택을 유지하므로 첫 용 난도를 전력 지원으로 건너뛰지 않는다.

동봉 JSON에 인수 시나리오 26개를 지정했다. 조기 해제, 거절, 위조 도구, C17 혼동, B의 99tick 중단, 커밋 후 장애, 잔여층 변조, 동시 입력, 소실·가방 부족, 후발자, 일반 조우 불가, 벽 차단, 최종 결말 불변, 시각 검수를 확인해야 한다. 모두 배포 전 실행할 시험이며 현재 실행 결과를 주장하지 않는다.
