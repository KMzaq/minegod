# 공통 판정과 구현 계약

## definition_id

mythictrpg:p0m016_contract

## document_status

채택된 구현 기획 기준. 실행용 엔진 스키마가 아니며 등록·코드 구현·실서버 시험은 수행하지 않았다.

## authority_and_precedence

기존 정체·등급·MAIN 범위·기존 결말을 보존하고, 사용자에게 위임받은 퀘스트 저술 권한으로 수량·시간·물품·판정·초기 밸런스를 이번에 확정했다. 옛 원문의 수치 미정·등록자료 대기는 이 기획에서 정한 정의를 보류시키지 않는다. 원문에 없는 새 주요 신화 사건은 추가하지 않는다.

## world_and_encounter

### unlock

아래 인물별 관측 사건을 이번 기획의 세계 해금 기준으로 채택한다. 해당 세계의 누구 한 명이 달성하면 공용 해금은 영구 true. 이미 해금 또는 기존 초기 접근 허가된 인물은 새 기준으로 소급 잠그지 않는다. 기존 봉인·생사·발화 제한은 해금과 별도다.

### legacy_evidence

기존 권위 이벤트의 행위자·대상·결과가 모두 있으면 1회 이관한다. 현물만 있거나 로그가 없으면 과거 공로를 추정하지 않는다. 이미 열린 세계 플래그는 그대로 보존한다.

### new_encounter_schedule

아직 본체가 배치되지 않은 경우에만 적합 사이트의 공용 조우 풀에서 300초마다 1회 판정한다. 인물 후보 가중치 1, NONE 가중치 4를 이 패킷의 초기 작업값으로 채택한다. 다른 인물이 함께 있는 공용 풀은 등록된 다른 후보 가중치를 더한다. 이 패킷에서 다른 인물의 가중치를 변경하지 않는다.

### initiator

사이트 경계 16블록 이내이고 현재 통행 가능한 온라인 플레이어 중 조건 충족자를 균등 추첨한다. 시드 worldSeed/siteId/checkSequence를 저장해 재접속 재굴림을 막는다. 등장 후 실제 동선으로 접근하며 세계 본체 잠금을 얻지 못하면 이번 후보를 취소한다.

### single_body

worldId + profile.godId 단일 본체 예약을 원자 처리한다. 이미 실제 본체가 존재하면 새 등장·재추첨 없이 그 위치에서 접촉한다. NPC를 플레이어에게 순간이동시키거나 파티별 본체를 만들지 않는다.

### site_rule

등록된 기존 Overworld 부지 중 인물별 지형·통행·충돌·보호 조건을 만족하는 곳을 선택한다. 좌표는 상대 앵커 A/B 등과 경로 길이로 바인딩한다. 미충족 시 같은 생활권의 기존 적합 부지로 이동하며 새 필수 신전·차원·전용 건물을 만들지 않는다. 적합 부지 없음은 배치 실패이지 퀘스트 성공이 아니다.

### after_spawn

수주 직전에 실제 본체·잔여 봉인·대화/행동 가능·현재 의사·도구·물자·허락을 재검사한다. 인사에 MAIN 소유나 개인 해금 반복 이력을 요구하지 않는다.

## ownership

### key

worldId + mainDefinitionId

### acceptance

제안 화면에서 범위·물자 소유·위험·독점 MAIN·취소 결과를 설명하고 최초 유효 명시 수락을 compare-and-set으로 ownerUuid에 기록한다. 첫 수락에는 기존 소유가 필요 없다. 인사·질문·파티 가입은 수락이 아니다.

### retention

부재·사망·로그아웃·보류로 소유를 양도하지 않는다. 원문에 없는 소유권 양도·재수주·전체 퀘스트 초기화는 없음. 거절은 소유 확정 전이면 소유권 없음, 수락 후면 미완료 상태 보존.

### shared_vs_private

실제 지형·NPC 위치·물품·위협은 세계 공용. 개인 선택·MAIN 완료·보상권·관계·허락·사적 지식은 각 UUID. 보조자의 참여를 주인의 실행으로 대리하지 않는다.

### participants

위험 구간 시작 전 실제 합류 의사를 표시한 최대 4명 플레이어와 명시된 NPC만 책임 명부에 넣는다. 솔로는 소유자와 해당 NPC로 가능하다. 뒤늦은 관찰자는 과거 책임 명부·귀환 성취·보상권을 자동 취득하지 않는다. 위험 중 새 구조 대상이 실제 생기면 별도 안전 기록에 추가하되 MAIN 공적은 소급하지 않는다.

### existing_main_binding

인물별 record_key와 원문 exact_scope_contract.main_ownership로 식별되는 기존 개인 MAIN과 이번 mainDefinitionId는 동일 권리의 별칭이다. 신규 제시 전 기존 소유자·진행·완료·미수령권·수령 영수증을 같은 원장에 원자적으로 조회·이관하며 옛 ID와 새 ID의 중복 수락/완료/보상은 금지한다. 기존 소유자가 있으면 그 사람만 남은 단계를 잇고, 완료이면 새 과제를 강제하거나 권리를 다시 만들지 않는다. 기존 권리 충돌 또는 검증 불가이면 해당 수락·지급만 보류하고 일반 대화는 유지한다.

## execution_and_recovery

### state_machine

- OFFERABLE

- OWNED

- ACTIVE

- PAUSED

- RESCUE_REQUIRED

- COMPLETED

- CLOSED_LOSS

### attempts

각 수행은 worldId/mainId/ownerUuid/attemptSequence로 식별한다. 완료된 단계 증거·실물 인수·비용 영수증은 재시도해도 유지한다. 새 시도는 새로운 실제 이동/실습만 기록하고 완료 보상은 늘지 않는다.

### death

소유자 사망은 성공 아님. 원래 사망·드롭 규칙을 적용하고 살아 있는 NPC·물품·위협 상태는 되감지 않는다. 소유자는 정상 부활 후 실제 현장/안전선에 돌아와 남은 수행을 재개한다. 참가자 귀환 목표에서는 죽은 플레이어를 사망 연결 관찰자로 기록하되 귀환 공로로 세지 않고, 정상 부활 후 안전선 복귀를 확인해야 정산한다. 실제 사망한 고유 NPC를 복제·부활시키지 않으며 그 때문에 불가능해진 결말은 CLOSED_LOSS, 성공·보상 0으로 닫는다.

### logout

접속 종료는 철수나 관측 완료가 아니다. 마지막 위치·역할·대상 UUID·진행·물품·청중·지급 영수증을 저장한다. 청크가 비활성화되면 해당 물리 수행의 시간·이동은 정지하고 실시간 보상쿨만 계속한다. 접속 복귀 때 현재 월드 상태와 대조한다.

### abort

취소 버튼은 새 명령만 중지한다. 위험이 생겼으면 실제 후퇴·방어가 필요하고 공격은 동의로 중지되지 않는다. 인벤토리 가득 참·NPC 부재·재고 부족은 권리 보존이며 성공 취소가 아니다.

### items

이동/제작/대여/반환에는 원본 itemUuid와 ledgerTxnId를 사용한다. 원래 물건을 보상으로 복제하지 않는다. 모든 지급은 AVAILABLE→RESERVED→DELIVERED 기록과 실제 인벤토리 결과를 원자 또는 복구 가능한 outbox로 연결한다.

### enemy_policy

새 보스와 사건 전용 적을 생성하지 않는다. 개별 사건이 요구하는 이미 존재하는 vanilla 적의 현재 UUID만 바인딩한다. 없으면 새 위험을 지어내지 않고 해당 시험을 기다리거나 명시한 적법 증거 재사용 경로를 쓴다. 죽은 적 재생성0. 자연 드롭은 기본 규칙을 따르며 퀘스트 추가 지급0.

## knowledge

### initial

정체와 원문 baseline_knowledge의 좁은 자기 기억만 초기 지식. 본문 사건의 성공·실패·보상·향후 응답·해금자의 사적 의도는 초기 지식 0이다.

### fact_vs_knowledge

권위 Story Fact 기록과 NPC/플레이어 지식 공급은 별도 단계다. 사실 저장 자체로 모든 NPC가 배우지 않는다. 각 fact는 observerUuid, speaker/source, actualReceivedAt, audiencePolicy, eventEvidence를 기록한다.

### observation

직접 시야 판정은 유효 눈 위치에서 대상까지 블록 차폐 raycast, 기본 24블록 이내. 발화는 기본 12블록 이내 실제 청취자. 큰 소리/기믹 소리는 개별 정의 거리. 벽 너머의 발화를 무조건 시야 지식으로 바꾸지 않는다.

### private

비공개 대사는 수신자 UUID allowlist를 적용한 개인 채널로만 전달한다. 공개 채팅 fallback 금지. 권한 없는 방문자의 UI 제목·거절문에도 비밀의 존재를 싣지 않는다. 개인 채널 미지원이면 그 전달만 보류한다.

### reports

NPC가 보지 않은 행동은 소유자의 실제 보고와 서버 증거를 대조해 업무 확인은 할 수 있지만, 자기 기억에는 출처 있는 보고로 남긴다. 감각형 인물에게 인간식 행정 기록·계약 개념을 주입하지 않는다.

### latecomers

현재 현장과 공개 허용된 기록을 실제 보고 배운 부분만. 친구·파티·세계 해금·FTB 완료 표시로 과거 경험·개인 허락·보상을 복제하지 않는다.

### not_claimed_present

- 이 패킷 ID들의 실제 등록

- 정밀 이동·교대·비행·퍼즐·청중/권리 저장 어댑터

- 실서버 AI 응답·다인 동시성·reload 시험

### delivery_rule

아래 새로운 기능은 구체 요구사항으로 구현한다. 현존하지 않는 action 필드를 엔진 지원값처럼 작성하지 않는다. 퀘스트 기능 연결 실패를 대사만의 완료로 대체하지 않는다.

### power_reward_guard

이 묶음의 지도는 생활·장비 운용의 실제 실습 서비스다. 신규 장비·가호·K/J 기술·레이드 호출·수치 강화는 0개다. 대여 소품과 소유품 반환을 보상으로 세지 않는다.

## participants

각 사건의 명부 상한을 따른다. 명시되지 않은 보조자는 최대 4명, 실제 동의와 현장 수행이 있어야 등록한다. 관찰자는 과거 기여를 얻지 않는다.
