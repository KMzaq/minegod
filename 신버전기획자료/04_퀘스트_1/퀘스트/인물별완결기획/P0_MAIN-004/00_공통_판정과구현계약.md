# 북유럽 7명 공통 판정·구현 계약

- 상태: 채택된 저술 기획. 실행 스키마·구현 완료·배포·실플레이 검증 아님.
- 범위: 7명의 기존 APPLICABLE 개인 MAIN을 각각 한 편으로 완결. 추가 MAIN·새 필수 보스·전쟁 소속 변경 없음. 무강화 수선/지도/이야기 결말을 전투 보상으로 바꾸지 않는다.
- 수락: 세계ID+인물관리키+원문MAIN범위로 단일 ownerUuid를 compare-and-set 한다. 기존 소유자가 있으면 신규 키로 두 번째 MAIN을 만들지 않고 같은 권리로 연결한다. 내용·비용·거절·고유결말·보상 고지 후 명시 수락만 인정. 인사·질문·조우 발생 주체는 소유권 아님. 최초 소유는 종료·사망·로그아웃·서버재시작으로 양도되지 않는다.
- 명부: 소유자 1명과 명시 참가자 최대3명을 책임명부에 저장한다. NPC는 같은 실제 본체만 참가. 출발 전 역할·접근·재산 허락 확인. 늦은 사람은 안전점에서 참가 동의 후 남은 행동만 수행하며 과거 선택·완료·보상은 복제하지 않는다. 소유자 선택 버튼은 소유자만 승인한다.
- 해금과조우: 개별 세계 해금은 어느 한 사람의 실제 증거로 영속 WORLD_SHARED가 된다. 만남 후보는 현재 현장에 도달한 다른 사람도 가능하다. 원문 해금 후보를 이번 기획으로 채택하되 이미 열린 세계를 닫지 않는다. 기존 개별 봉인·사망·부재·접근 기록 우선. 기록 미연결을 자유출현으로 취급하지 않으며 신규 봉인이나 부활을 만들어 해결하지 않는다.
- 조우확률: 서버의 기존 공용 풀 확정값이 있으면 그 값을 보존한다. 확정값이 없는 풀의 채택값: 적격 사이트마다 현실120초 창에 1회, NONE 가중치9·적격 각 인물 가중치1로 한 후보 추첨. NPC별이 아니라 사이트 풀 한 번이다. 주체는 현재 16블록 안 적격 UUID 정렬 목록에서 동일 창 서버 난수로 1명. 창ID·후보목록·난수를 영속해 재접속/청크언로드 재추첨0. 본체의 전역 예약을 획득한 뒤 기존 위치와 충돌검사. 다른 장소에 현존하는 본체는 후보에서 제외하고 복제0. 이미 현존하면 추첨 없이 일반 접촉 가능. 추첨은 일상 발생이며 MAIN을 자동 수락하지 않는다.
- 위험준비: 공용 인사에는 CP 하드컷0. 물리 위험 진입 직전 실제 보행 폭2·높이3·낙차2블록 이하 퇴로, 조명, 체력10HP 이상·허기12 이상을 확인한다. 조건이 부족하면 안전 관찰/질문만 가능하며 준비 후 재개한다. 동일 본체와 6블록 이내 시야·해당 행동 동의를 별도로 확인한다.
- 시도와시간: 세계 사건UUID와 개인 시도UUID를 분리한다. 시도 실패는 미완료 동작만 초기화하며 회수·소비·파손·동의철회는 보존한다. 전체 수락/청구 만료와 현실 일일 제한 없음. 단계의 짧은 동작 타이머만 서버tick으로 잰다. 시작하지 않은 미래 장면을 이미 발생한 기억으로 등록하지 않는다.
- 사망: 사망한 플레이어의 수행은 즉시 멈추고 해당 시도 성공0. 생존자는 안전 철수를 계속한다. 죽은 사람은 실제 귀환자로 판정하지 않는다. 부활 후 안전점에 직접 돌아와 남은 목표를 재수행한다. 사망 연결 관전은 서버 원래 정책만 사용하고 관전 이동/클릭은 목표 증거0. NPC를 복제 부활시키지 않는다. 실제 소실 도구/물품은 자동 재발급하지 않으며 대여 책임은 남는다.
- 로그아웃: 소유자 이탈 즉시 새 위험동작 정지, 들어 올린 부재는 안전 낮춤 상태로 전환 후 위치와 손상 저장. 이미 떨어진 블록·소모품은 되돌리지 않는다. 동행 이탈은 미귀환으로 기록하고 생존자 철수를 허용한다. 재접속 시 동일 소유/시도·현장 revision 확인 후 안전점에서 남은 목표만 재개. 완료·수령권·쿨·사용기록 초기화0.
- 중단: 준비 수락 전 거절은 상태·비용0. 수락 후 보류는 소유 유지·진행 보존. 확정 종료는 COMPLETED_CANCELLED/COMPLETED_PARTIAL/COMPLETED_SUCCESS 중 실제 결과로 기록하며 취소를 성공 보상으로 바꾸지 않는다. 원문에서 안전 취소가 개인 결말인 경우 그 사실만 완료, 실전 성과와 구분한다.
- 지급: 보상 source=QUEST, gold0. ownerUuid+정규보상ID+세계MAIN범위의 단일 claim. 선택형은 첫 선택을 고정하며 다른 선택권을 추가하지 않는다. AVAILABLE→DELIVERY_PENDING→DELIVERED. 인벤 부족은 바닥드롭0·미수령 유지. journal/실물claim표식/재고예약을 대조해 확인된 누락라인만 복구한다. 결과 불명 상태에서 재발행0. 실제 받은 물건의 소모·파손·용암소실은 지급 실패 아님. 원장과 인벤이 자동 원자적이라고 가정하지 않는다.
- 재고: 개인 MAIN 최초 소유자1명용 별도 재고만 예약한다. 후발5명에게 동일 희소보상 복제0. 비독점 신규 제작 서비스는 이번에 만들지 않으므로 10인분 보급선을 억지로 추가하지 않는다. 재고의 초기량은 구현 시 제공자 소유로 실제 편성·검증할 계획량이지 현재 보유 확인 주장이 아니다. 부족 시 보상권만 보류, 실제 재료 입고 로그 없이는 자동 보충0.
- 권리와연출: UI 글자·효과음·장면 애니메이션은 판정 원장에 대한 표시일 뿐이다. 표식이 안 보이거나 음소거여도 대체 자막·상호작용으로 같은 증거를 얻는다. 연출 재생/스킵/다른 청중 시청으로 물품·MAIN·가호권리 생성0. 서버 위치/조작/인수 이벤트가 물리 완료의 증거다.
- 지식: Story Fact 저장과 개인 지식 전달을 분리한다. 모든 미래 사건 initial_known=false, state=NOT_OCCURRED. 직접 목격은 거리16블록·시야, 발화는8블록·실제 청중과 공개동의, 선택보고는 수신자 응답ID로 기록한다. 원격 파티·친구·공유해금은 자동 수신0. 발화 시 청중 중 미허락자가 있으면 그 부분을 생략/비공개 자리로 이동하며 비밀 존재조차 암시하지 않는다. NPC가 보지 못한 시스템로그는 검증 판정 자료일 뿐 NPC 직접기억이 아니다.
- 엔진경계: 바닐라 이동·활·표적·도구내구·인벤토리·레버·블록은 활용 가능한 기본 동작이다. 퀘스트 등록, MAIN 원장, 권한검사, 소품 상호작용, 하중/가공/음향 관찰 어댑터, NPC 동의·실제 이동, 청중별 기억 전달은 개별 구현 요구. 지원된 action enum이라고 선언하지 않는다.
