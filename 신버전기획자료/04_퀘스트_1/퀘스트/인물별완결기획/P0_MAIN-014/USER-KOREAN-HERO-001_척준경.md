### steps

#### id

C1

#### action

각자 훈련 동의 후 척준경이 A→B를 이동하고 소유자는 A 귀환선을 지킨다. 척준경이 돌아서 중지 신호를 보내면 소유자가B에 접근했다가 뒤를 확인하며A까지 돌아온다. 다음에는 소유자가C 앞까지 전진한 뒤B의 척준경을 확인하고 함께A로 귀환한다.

#### sparring

막대 접촉은 근접2.5블록 안에서 시야와 실제 충돌을 확인해 서로1회씩 기록한다. 동의한 참가자 간 대련 피해만0으로 바꾸고 접촉 표식을 남기는 비치명 어댑터가 필요하다. 전역 아군 공격 허가나 적 피해 차단은 아니다. 미지원이면 대련을 보류하고 대사로 완료하지 않는다.

#### evidence

역할을 바꾼2구간의 이동·돌아섬·실제A귀환, 서로 접촉1회씩, 전원 동의. 앞으로 지나가기만 하면 성공이 아니다.

#### id

C2

#### action

기존 탐사길 S→T에서는 소유자가 후미, T→U에서는 선봉을 맡는다. T에서 명부 전원이 실제 모여야 교대한다. U에서 더 전진하지 않고 후미를 확인해 중지 신호를 보낸 뒤T→S로 돌아온다. 마지막 명부 구성원이S에 들어올 때까지 소유자는 먼저 정산하지 않는다.

#### threat

기존 적대 몬스터가 있으면 기존 전투·엄폐·우회로 대응하며 처치는 목표가 아니다. 실제 공격은 동의 없이 발생하고 초월급 자동 토벌은 없다. 척준경은 실제 후퇴 동선과 본체의 방어 행동만 쓴다. 새 궁극기나 전체 무적을 주지 않는다. 적이 없어도 실제 지형 탐사·교대·후미 귀환은 유효하며 가짜 적을 생성하지 않는다.

#### evidence

고정 명부, UUID별 S/T/U 도달, 소유자의 선봉·후미 거리 순서, 중지 신호의 실제 수신, 동행자 전원의S복귀. 부재한 동료를 돌아온 것으로 기록하지 않는다.

#### id

C3

#### action

#### outcome

다음 선봉의 책임에 대한 구체적 신뢰만 남긴다. 미래 임무 수락·신격·가호·지휘권은 자동으로 생기지 않는다.

### branches

#### return

#### abandon

혼자 끝점이나 귀환점을 통과하면 실패다. 남은 동행자를 실제 찾아 안전하게 복귀시키고 재시도 동의를 받아야 남은 구간을 수습한다. 버리지 않았던 기억으로 덮지 않는다.

### recovery

외부 적이 훈련장에 침입하면 훈련을 중단하고 안전하게 철수한다. 비치명 판정을 외부 전투에 확대하지 않는다. 플레이어 사망은 기본 드롭과 사망 연결 관찰로 기록하며 전원 귀환 성공이 아니다. 정상 부활 후 실제S복귀와 남은 동행 구조를 확인한다. 고유NPC가 죽으면 복제·부활하지 않으며 성공으로 닫을 수 없다. 로그아웃은 귀환 완료가 아니다. 현존NPC는 안전 철수할 수 있지만 소유자의 완료는 보류한다. 죽음·부재를 이유로 명부를 지워 성공시키지 않는다.

### cost
