# 중국5인 공통 판정·구현 계약



이 문서는 채택된 저술 기획이다. 현재 런타임 등록·실서버 수행 완료를 뜻하지 않는다. 각 인물 문서와 통합 JSON을 함께 적용한다.



## 범위

치우·공공·축융·서왕모·옥황상제의 기존 PERSONAL_MAIN 5개와 선택 서비스/공개 사건을 완결한다. 일반 대화와 서비스에 개인 MAIN 소유 조건을 일괄 복사하지 않는다.



- 정의 ID: mythictrpg:p0m009_contract

- document_status: 채택된 구현 기획. 현행 실행 스키마가 아니며 실제 등록·구현·reload·실서버 검증은 하지 않았다.

- authority: 현행 명부와 기존 MAIN/보상/분기 범위를 보존하고 위임된 저술 권한으로 수량·초수·소품·재고·정산을 확정한다. 원문의 수치 미정 문장은 이 정의의 기획 채택을 막지 않는다. 대정사·전쟁 소속·신격 변경은 없음.

## world_and_encounter

- unlock: 세계 공통 해금. 공공·축융의 기존 후보를 아래 인물별 관측 사건으로 채택하되 이미 열린 상태·유효한 조기 접근을 소급 잠그지 않는다. 나머지는 새 과거행동 게이트 없음. 해금은 봉인 해제·생사·개인 소유·지식이 아니다.

- schedule: 본체가 아직 배치되지 않았을 때만 적합한 기존 공용 풀에서 300초마다 1회. 이 패킷 인물 후보 가중치 각 1, NONE 가중치 4. 다른 후보 가중치는 기존값 유지. 첫 도착/재접속 즉시 추가 굴림 없음.

- subject: 사이트 접근 경계 16블록 이내 온라인 적격 방문자 중 균등 선정. worldId/siteId/checkSequence 난수 결과 저장. 해금 달성자와 같을 필요 없음.

- body: worldId+생산 God ID로 동일 본체 예약. 이미 존재하는 본체와는 새 확률 없이 실제 위치에서 접촉. 안전한 지형에 배치하며 파티별 분신·원격 대사·다른 장면 본체 순간이동 없음. 완전 봉인/사망/현행 제한이 있으면 그 행동만 막는다.

- 부지: 실제 발견된 적합 기존 구조물 OR 기존 안전 자연부지. 희귀 구조물을 필수로 삼지 않는다. 각 상대 앵커와 보호 범위를 사이트 등록 시 고정. 타인 부지 사용·변경은 해당 소유자 허락을 받고 범위 밖 파괴/침수 금지. 새로운 신전·차원·접수원 없음.

- contact: 현재 본체·접근·표현 모드·청중과 실제 응답 의사. 일반 인사/질문/침묵에 MAIN 소유·수락·전투력 컷 없음. 행동 위험·도구·동의는 해당 수행 직전 별도 검사.

## main_only_ownership

- 범위: 다섯 PERSONAL_MAIN 정의에만 적용. 일반 대화·공개 event·선택 서비스·기여자 정산에 MAIN 소유자 검사 템플릿을 복사하지 않는다.

- accept: worldId+원문 episodeId에 대한 첫 유효 명시 수락 1인을 compare-and-set으로 결속. 범위·위험·비용·독점·분기·보상을 먼저 고지. 첫 수락에 기존 소유가 필요하지 않다. 실제 현재 입력으로 수락하며 첫 클릭·질문·파트 가입은 수락 아님.

- retention: 사망·로그아웃·실패·명시 보류로 소유 이전 없음. 취소는 현재 수행 중단이며 후발자에게 MAIN 재발행하지 않는다. 처음 거절했으면 소유 없음.

- separation: 공용 지형·현물·위협·NPC 상태와 개인 선택·공로·진행·완료·사적 기억·보상권은 별도. 소유자 본인의 필수 행동을 도우미 행동으로 채우지 않는다.

- participants: 각 위험 작업 시작 전에 실제 역할 수락한 플레이어 최대4명(소유자 포함). 관찰자 수는 제한하지 않되 통로 방해를 중지시킨다. NPC는 인물별 기존 배우만. 후발 도움은 현재 잔여 역할만.

- death: 기본 사망·드롭 규칙 유지. 사망은 귀환/운반/수신 성공이 아니다. 안전 담당자가 현재 물건을 확보할 수 있으면 실제 확보하고 사망자 공로로 세지 않는다. 정상 부활 후 현재 안전선 복귀·남은 자기 수행만 재개. 이미 사망한 고유 NPC를 복제·부활하지 않는다. 그 때문에 결말이 불가능하면 CLOSED_LOSS로 종료하며 새 성공권리0.

- logout: 위치·역할·아이템UUID·상태·실제 수신·지급 영수증 저장. 접속 종료는 안전 귀환 아님. 청크 비활성 물리 동작/관측 초수는 정지한다. 살아 있는 참가자가 실제 끝낸 구간만 유지하며 소유자에게 자동 복사하지 않는다. 재접속은 현재 상태 대조 뒤 미실행 부분부터.

- abort: 새 행위만 중단. 진행 중 전투·뜨거운 화로는 실제 후퇴/소화 필요. UI 취소로 위협을 지우지 않는다. 완료 후 수령·지도·후일담 거절은 완료를 되돌리지 않는다.

- items: itemUuid, ownerUuid, custodianUuid, sourceLotId, txnId를 구분. 대여·반환은 원물 이동이며 새 지급 아님. AVAILABLE→DELIVERY_PENDING→DELIVERED와 실제 인벤/보관을 journal/outbox로 대조. 가방 부족이면 바닥드롭0. 부분 지급이면 누락 라인만 복구. 결과 불명은 대조 전 재시도0.

- world_damage: 기존 지형/작물/현물 손실은 저장한다. 정상 물건을 고장내거나 열린 길에 장애물을 넣어 과업을 만들지 않는다. 운영 오류로 유실된 소품의 복구는 기존 UUID와 증거로 동일 권리만 복원한다.

## 지식

- initial: 원문 baseline_knowledge의 자기 경험·취향·관계만. 앞으로 일어날 사건은 초기 프롬프트/정적 lore에 주입하지 않는다.

- fact: 서버 사실 원장과 배우별 실제 앎을 분리. observerUuid, sourceActor, evidenceId, receivedAt, audiencePolicy를 저장한다. 공개된 월드 결과도 실제 관측/전달 전에는 NPC 앎이 아니다.

- observation: 직접 관측은 24블록 내 눈 위치 raycast와 실제 대상 상태, 보통 발화는 12블록 내 실제 수신. 신호는 별도 개별 거리/전달 계약. 청취·시야·플레이어의 직접 신호 응답은 서로 대체하지 않는다.

- privacy: 개인 기록·포로 이름·사적 진술은 허용 UUID 전용 전달. 공개 채팅 fallback 금지. 권한 없는 사람에게 제목·농담·거절 이유로 존재도 유출하지 않는다. 공개 전달 범위는 당사자가 선택한 문장에만.

- reports: NPC가 못 본 수행은 실제 보고+권위 증거로 업무 접수 가능하나 기억에는 보고자·시점을 남긴다. 메타 완료표로 타인의 속마음/현재 위치를 생성하지 않는다.

- latecomer: 현재 지형·허락된 공개 결과를 실제 읽고 배운 지식만. 파티·친구·세계 해금으로 과거 경험/보상 복사0.
