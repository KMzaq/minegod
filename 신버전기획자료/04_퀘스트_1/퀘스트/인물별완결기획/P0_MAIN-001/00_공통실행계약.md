# 그리스 8명 개인 MAIN 공통 계약

- schema: authoring.complete_packet_common.v1
- packet_id: P0_MAIN-001
- title: 그리스 8명 개인 MAIN의 공통 실행 계약
- design_status: 현재 위임으로 채택한 구현 작업기준
- runtime_ready: false
- implementation_performed: false
- scope: 기존 개인 MAIN 8개를 완결한다. 공용 본편 C 카드와 공방 SIDE 3개를 재작성하거나 개인 MAIN의 대체 완료로 쓰지 않는다. 명부 정체·소속·전투등급을 유지한다. 원문 보존 값은 역사 근거이고 새 채택 결정과 구분한다.
- authority: 퀘스트 내용·보상·수량·밸런스를 기획자가 결정한다는 현재 지시를 적용했다. 실제 서버 등록·배포·실플레이 검증은 수행하지 않았다. 기존의 세부 수치 미정은 아래 값으로 닫았으며, 원문 무보상·명시적 금지·개인 독점·지식 비공개는 해제하지 않았다.
- unit: 거리=블록, 시간=초/분, 20tick=20TPS에서 1초. UTC 절대시각은 디오니소스 술 의뢰 48h에만 사용한다. 예상 플레이시간은 정적 기획 추정이지 실측이 아니다.
- identity_and_id: - 관리키 RPG-S01-xxx는 명부 join키다. provider_definition_id는 각 기존 profile.godId를 생산 설계 ID로 그대로 채택한다. 폐기된 139개 테스트 CSV를 보지 않고 ID를 되돌리지 않는다.
  - 본 패킷의 definition_id는 생산용 설계 식별자이며 로더 등록 성공을 뜻하지 않는다. source_episode_id는 원문 카드 연결 별칭으로 남긴다. 기존 전투 콘텐츠 ID는 새 정의를 만들지 않고 참조한다.
  - 새 핵심 인물·현대 부활·신의 분신을 만들지 않는다. 기존 일반 주민/동물/적은 현재 존재하는 개체 UUID에 결속한다. 다른 인물의 이름·현재 의사를 시스템이 대신 생성하지 않는다.
- world_and_contact: - 채택된 세계 해금은 누구 한 명의 유효 달성으로 공통. 이 패킷은 별도 세계 해금 후보를 새 필수 조건으로 승격하지 않는다. 기존 조기 접근을 유지하고 아폴론/아르테미스의 미채택 추가 해금 후보는 이번 MAIN에 사용하지 않는다.
  - 등장 전에는 현행 장소·시간·물건·봉인·현재 후보 조건과 기존 확률만 검사한다. 이미 없는 본체의 응답을 등장 전 조건으로 요구하지 않는다. 본체가 등장하면 일반 접촉마다 재추첨하거나 후발자에게 재해금을 요구하지 않는다.
  - 직접 대면은 같은 차원 거리 6블록 이내, 시야 통과, 같은 단일 본체, 본인의 현재 발화 의사와 허용 모드가 필요하다. 공개 연출의 시각 증거는 24블록 이내 실제 시야, 말의 청중은 12블록 이내 실제 수신과 접근권을 각각 기록한다. 공연은 별도 범위를 쓴다.
  - 공용 세계가 변해도 관계·MAIN 소유·개인 수행·지식·보상은 자동 공유하지 않는다. C08, C24, 다른 NPC의 동의를 새 말 한마디로 우회하지 않는다.
- offer_acceptance: - offer: 이름·책임·재료·위험·분기·보상·독점 여부를 보여 준 현재 offer_revision을 둔다. 인사·질문·팀 가입은 수락이 아니다.
  - commit: 수락 직전 현재 동일 본체와 접근·목표 현물·제공권을 재검사한다. 서버 순번으로 첫 유효 명시 수락 하나만 world_id+provider_definition_id+PERSONAL_MAIN 키를 획득한다. 미소유인 최초 수락에 기존 소유를 요구하지 않는다.
  - ownership: 각 8명별 세계에 단 한 개인 MAIN 소유자. 소유자의 명시 포기도 진행 보류이지 다른 사람으로 자동 이전 아님. 로그아웃·닉네임·팀 변경·일시 부재·사망으로 바뀌지 않는다. 동일 UUID의 미완료 진행을 이어 간다.
  - helpers: 참가 도움은 실제 사람 UUID와 동의 역할을 따로 기록한다. 목격·운반·엄호는 자기 기여일 뿐 소유자 최종 선택을 대신하지 않는다. 아테나의 명시된 기여자 지도만 개인 MAIN 소유권과 별도로 적용한다.
  - late_join: 실제 남은 일에 합류하고 이미 바뀐 현장/허락 기록을 오늘 관측한다. 처음부터 참여했다고 소급하지 않는다. 참가가 필요한 짧은 시도는 시작 명부를 고정하고 후발자는 다음 시도에 참가한다.
- state_storage: - world: 단일 본체 UUID/위치, 현물·블록 상태, C 공용 사실, 실제 NPC 응답, 해금·현장 접근, 사용 마을 이력. 월드 상태와 NPC 지식은 다른 저장소다.
  - personal: world_id+player_uuid+main_definition_id 아래 OFFERED/OWNED/IN_PROGRESS/RESULT_READY/COMPLETED, objective 증거 event_uuid, branch 선택 revision, 실제 읽기·청취·보고 수신, 비용·위탁·미수령 원장.
  - attempt: 각 전투·공연·훈련 시도 attempt_uuid와 명부·시작/끝 tick·현재 위치·출석·유효입력을 저장한다. 동일 입력 event_uuid는 한 번만 접수한다. 전체 MAIN에 공통 3단계 카운터를 만들지 않는다.
  - proof: 서버의 위치·블록 변경·인벤토리 인수·아이템 serial·탄약 발사·유효 청취 기록이 증거다. 자연어 설명·정답·약속만으로 실제 수행을 대신하지 않는다. 보고는 실제 근거를 가진 출처 있는 보고로만 남긴다.
  - failure: 확인된 관측/선택/소비/부분 수행은 유지. 이미 완료된 공용 변화를 되감지 않는다. 사망은 서버 기존 부활/드롭 규칙, 로그아웃은 보류이며 본 패킷만의 사망 벌금·오프라인 재앙 없음. 짧은 시도 중단은 해당 시도의 미완료 구간만 다시 한다.
  - blocked_actor: NPC 부재/봉인/동의 철회에는 새 대사·완료 확인을 생성하지 않는다. 독립적으로 가능한 조사·물품 보관은 계속하고 해당 확인만 대기한다. 접촉 재개 시 현재 안전/시야/권한을 다시 본다.
- claim_ledger: - keys: 최초: world_id+recipient_uuid+reward_definition_id. 반복 디오 서비스: world_id+recipient_uuid+service_attempt_uuid+choice_right. 권리 UUID와 물리 stack instance UUID는 다르다.
  - states: - ELIGIBLE
    - AVAILABLE
    - DELIVERY_PENDING
    - DELIVERED
  - transaction: 원자성을 DB와 인벤토리 동시 write라고 가정하지 않는다. 영속 delivery_journal에 transaction_uuid, entitlement_uuid, source_event_uuid, 각 line 수량, 예약 재고, 고유 stack/skill receipt를 먼저 기록하고 실전달 뒤 확인한다. 장애 뒤 journal과 실제 serial/학습이력을 대조하여 누락만 복구한다.
  - limits: QUEST claim 단일 경로. RAID_DIRECT/FTB/팀 보상에는 같은 지급을 두지 않는다. 권리 생성과 수령은 따로 세며 수령 지연으로 최초권/반복권을 바꾸지 않는다. 인벤토리 부족은 바닥 드롭 금지, 예약과 권리 유지.
  - skills: learn_skill은 실제 수강 끝에 같은 기존 skill_id 보유권 1개. 이미 learned면 동일 권리 연결만 하고 새 점수·두 번째 학습·마나/쿨 초기화 없음. 독립 K 목록 선택 후 J 사용이며 무기 우클릭 기술과 구별한다.
  - materials: 목록에 없는 물품·도구·상자·친구 재고를 자동 차감하지 않는다. 순수 열람·대화는 비용0. 증거품/대여품/보상/제출 소비를 구별한다. 제공권과 예약 재고가 모자라면 그 보상 약속이 포함된 수락만 보류한다.
  - recovery: 일반 소모품 지급 뒤 사용·분실은 추가 지급 없음. 기존 장신구의 명시 승인된 동일권리 복구만 별도 적용. 서버 지급 결과 불명확이면 대조 전 재지급 금지.
- knowledge_protocol: - fact: 행동 완료 event_uuid에 근거해 Story Fact를 설정하고, 누가 아는지는 별도 Knowledge 전달로 처리한다. 모든 future 사건은 실행 전 locked다.
  - actor: NPC가 직접 본 경우 direct_observation, 실제 보고만 받은 경우 reported_by+sender_uuid+message_event로 기록. 추측은 inference이고 미확인인 채 남긴다.
  - audience: 현장에 실제 있었고 감각/접근 범위를 만족한 사람만 목격. 사적 대화와 기록은 소유자/당사자 허락 범위에 한정. 함께 있는 사람 중 비허가자가 있으면 비밀의 존재를 암시하는 거절 대신 공개된 내용만 말한다.
  - memory: 다음 만남 대사는 실제 동일 player_uuid와의 기억이 있을 때만. 친구·세계 완료·profile lore로 과거 공적을 복사하지 않는다. 기존 신화 자기 기억과 현재 다른 인물 소재·의사를 구분한다.
  - late: 늦게 읽은 사람은 현재 공개 상태 또는 허락된 요약을 읽은 새 전달 사건으로 배운다. 과거 목격자나 사적 청중으로 추가하지 않는다.
