# 여우신 기존 장면: 돌아오지 않은 신호와 오늘의 길

기존 7개 장면의 의미를 유지한 상세 저술이다. 개인 MAIN은 5단계 한 연쇄이고 모든 사람에게 복제하지 않는다. 소유자 부재·거절·사망·미접속으로 소유권이 이전되지 않는다. 아래 실행 규모는 채택된 초기 기획값이며 게임 테스트 결과가 아니다.

## FOX-FIRST

선행: 현재 실제 접촉; C15/T03/밤 제한 없음

1. 쉼터에서 실제 여우신에게 인사한다. 일반 첫 만남에서는 현재 숲 풍경만 볼 수 있다. C15 뒤 신호 자료 조건이 맞을 때에는 조금 떨어진 자리에서 실제 불씨가 깜빡이는 숲 방향도 관찰한다. 인사 없이 지나간 것을 만남 완료로 세지 않는다.
2. 이름과 소속을 물을 수 있다. “달기, 타마모노마에, 구미호. 곳마다 다르게 불렀지. 어느 이름이든 내가 돌아볼 거야.”라고 답하고 천군 소속임을 숨기지 않는다. 호칭 선택은 유일한 진짜 이름 맞히기가 아니다.
3. 그녀가 숲으로 몇 걸음 먼저 움직이다 멈추는 모습을 본다. 플레이어는 지금 다닐 수 있는 숲 입구까지 걷거나 쉼터에서 대화를 마친다. 일반 산책은 SIDE로 이어질 수 있다. C15 뒤 신호 장면에서만 불씨가 향하는 실제 옛길과 공개 전쟁 자료의 귀환 흔적을 대조하며, 자료가 없는 초반 인사에 그 추적 성과를 주지 않는다.
4. C15 뒤 전쟁 조사 결과와 실제 신호 접점을 확인했고, 현재 숲길 조사·왕복·방어 또는 탈출을 수행할 준비를 확인한 경우에만 그녀가 “나와 저 불빛을 함께 찾아볼래?”라고 명확히 제안한다. MAIN이 미소유이면 이때 첫 수락 여부를 묻는다. 일반 인사·먼저 만남·SIDE 참여는 선점권이 아니다. 준비가 모자라면 이미 다닐 수 있는 길에서 연습하거나 보류하고, 다른 소유자가 이미 있으면 오늘 산책 SIDE나 현재 대화를 한다. 고정 전투력 수치·가호·장비를 제안과 동시에 지급하지 않는다.

현장 구현: 본체 3블록 이내 대화와 실제 응답 수신. 공개 이름·소속은 질문시 전달, 모든 질문을 의무화하지 않음. MAIN 선행 준비는 기존 안전 경로 8블록 왕복 가능 여부와 엄폐/탈출 안내 실제 확인으로 검사하고 고정 전투력 컷 없음. 기존 동등 실제 준비 증거를 재사용한다.

보상과 인수: 실물0. C15 자료 실제 열람과 현재 불씨 실제 관측이 없는 초반에는 추적 제안을 노출하지 않음.

실패·재개: 인사만/현재 산책/제안 거절 가능. C15 뒤 실제 자료·신호·왕복 및 방어·탈출 준비와 명시 수락이 모두 유효한 때 미소유 MAIN의 첫 한 명만 소유한다. 이미 소유자면 SIDE로 간다. 재접속은 새 최초 만남 아님. 대화 끊김은 미수신 말만 남기고 MAIN 자동 수락 없음. 본체가 타인과 있으면 같은 현재 장소에서 기다린다.

후발자: 먼저 만난 친구의 인사·사연은 소급하지 않는다. 현재 본체에게 자기 인사를 하며 기존 MAIN이 있으면 오늘의 SIDE·일반 대화가 대체 경로다. 제안 거절은 호감 벌점·자동 적대가 아니다. 필요한 후속 확인은 실제 접촉이 가능할 때 남은 부분만 수행한다.

예상: 2–4분; 전체 마감 없음.

## FOX-M01

선행: C15 세계 진행 + 본인 공개 전쟁 자료 열람 + 현재 신호 발견 + 수행 준비 + 본체 제안 + 미소유 원자 첫 명시 수락

1. 소유자는 입구의 굽은 나무를 기준점으로 살피고 본인이 돌아올 방향을 표시한다. 개인 소유 나무를 베거나 집 앞에 표식을 강제 설치하지 않는다.
2. 앞의 불빛을 따라 첫 나무 뒤로 걸어간다. 다시 같은 굽은 나무가 보이는 실제 짧은 고리 동선으로 돌아옴을 확인한다. 이동을 순간이동시키거나 실제 무한 미로를 생성하지 않는다.
3. 반복된 나무 아래 낙엽 두 곳을 내려다보고 그을음이 물가 쪽으로 이어진다는 관찰문을 얻는다. 불씨의 화재 연출이 플레이어 건축물을 태우지 않는다.
4. 물가의 발자국 시작점과 마지막 점을 차례로 밟아 실제 방향을 잡는다. 맨손 조사로도 가능하며 추적 스탯·직업 판정은 없다.
5. 여우신이 반대편으로 움직인 뒤 불빛만 그녀를 따라가고 발자국은 움직이지 않는 것을 기준점에서 비교한다. 플레이어가 먼저 말하면 이미 확인한 근거를 인정한다.
6. 움직이지 않은 발자국을 따라 물가 끝 지점에 도달하고 빛의 리듬을 관찰한다. 짧게 둘·길게 하나라는 패턴은 이번 실행안이다. 소리 없이 관찰문에도 표기한다.
7. 소유자가 불빛의 이동과 발자국의 방향을 구분한 기록을 확인한다. 실제 도착·두 흔적 확인·리듬 관찰이 완료 증거이며 정답 문장만 외워 말해서 완료되지 않는다.

현장 구현: T1/T2/T3 고리는 물리 도보. L1,L2와 F0,F1 관측, F1에서 짧은 2펄스와 긴1펄스(각4tick, 간격4tick, 마지막12tick; 40tick 주기)를 한번 실제 관찰. 두 흔적과 리듬을 이미 관찰했으면 고리 강제 재연 없음.

보상과 인수: 실물0, M02 접근만.

실패·재개: 그을음 먼저/둔덕 고리 먼저는 같은 발견으로 가는 조사 순서다. 관측 근거로 빛이 그녀를 따른다고 조기 추리하면 인정하고 쓸모없는 반복을 생략한다. 지금 귀환하면 남은 현장 확인만 보류. 사망·이탈 뒤 확인한 발자국과 단계 유지. 신호는 오프라인으로 꺼지지 않으며 재개 때 실제 여우신 위치를 찾는다. 현장에서 M02로 바로 이어 갈 수 있으며 보고만 하러 주점에 돌아가지 않는다.

후발자: 친구는 공개 길·적 정리를 돕고 현재 지도만 실제 읽는다. 소유자의 사적 첫 추적·대사·M02 소유 자격을 얻지 않는다. 필요한 후속 확인은 실제 접촉이 가능할 때 남은 부분만 수행한다.

예상: 6–10분; 전체 마감 없음.

## FOX-M02

선행: FOX-M01

1. 갈림길 입구에서 현재 건널목과 귀환 표식의 위치를 확인한다. 위험한 깊은 물에 먼저 빠져야 정보를 얻는 구조는 쓰지 않는다.
2. 낮은 강둑 경로를 택하면 물가의 반사점 두 곳을 순서대로 조사한다. 높은 둔덕 경로를 택하면 위에서 건널목 양끝과 음성이 향하는 막힌 수풀을 내려다본다. 두 경로는 같은 안전 건널목을 가리키며 한쪽만 조사해도 충분하다.
3. 발소리 쪽으로 움직이던 여우신에게 확인한 동선의 근거를 알린다. 아직 관찰하지 않은 소유자의 주장에는 먼저 살펴보자고 답한다. 실제 근거를 이미 찾았다면 그녀의 실수를 반복 연출하지 않는다.
4. 얕은 여울·기존 다리 중 실제 안전한 한 곳을 직접 건넌다. 필요한 경우 허가된 구간에 임시 발판 최대 3개를 놓는 시험안을 쓴다. 수영·특정 장비·공중 이동을 강제하지 않는다.
5. 맞은편 표식에서 뒤를 돌아 출발한 둔덕 또는 강둑이 보이는지 확인하고, 같은 안전 길로 귀환한다. 실제 왕복과 선택한 관측점 확인이 완료 증거다.
6. 돌아온 그녀의 “기다리던 소리 같아서 길을 잊었어”를 실제 청중만 듣는다. 기다리는 이를 묻거나 지금 묻지 않는 선택으로 대화를 마친다.

현장 구현: R1→R2 또는 H 관측 후 C0→C1→C0 도보 통과. 각 판정 반경1.5블록, 관측은3블록. 기존 다리면 발판0. 안전한 횡단을 대신한 순간이동은 왕복 증거 아님.

보상과 인수: 실물0, 확인된 안전길 공개는 소유자 공개 허락 범위만.

실패·재개: 낮은 강둑/높은 둔덕 중 하나면 충분. 기다리는 이를 묻기/말할 때 듣기 모두 유효. 실제 근거로 먼저 오류를 짚으면 그녀의 잘못된 걸음을 다시 연출하지 않는다. 관찰·남은 발판 유지. 이미 왕복 완료 뒤 대화가 끊기면 대화만 잇는다. 물에 빠짐은 일반 생존·사망 규칙이며 자동 구조 없음.

후발자: 후발 친구는 현재 건널목을 이용해 자신의 길 경험을 남긴다. 옛 왕복·사적 고백·M03 개인 자격 복제 없음. 필요한 후속 확인은 실제 접촉이 가능할 때 남은 부분만 수행한다.

예상: 5–8분; 전체 마감 없음.

## FOX-M03

선행: FOX-M02

1. 공터 가장자리에서 엄폐 두 곳과 M02 귀환길 입구를 실제로 확인한다. 전투를 시작하기 전에 전투·탈출 중 선택 비용과 방법을 보여 준다.
2. 전투안은 소유자가 여우신의 안정 작업 시작을 확인하고 엄폐 한 곳으로 이동해 적을 맞는다. 탈출안은 신호를 붙잡은 그녀와 함께 미리 확인한 귀환길로 움직이기 시작한다.
3. 전투안은 스켈레톤 사선을 나무·바위로 끊고 거미가 가까워질 때 실제로 처리한다. 도와주러 온 친구도 해당 일반 전투에 참전할 수 있다. 소유자가 모든 막타를 칠 필요는 없다.
4. 탈출안은 공터 출구·강 건널목·안전 둔덕의 세 실제 지점을 차례로 통과한다. 추격자를 피하거나 필요한 만큼만 맞서며 세 지점 사이 이동을 직접 수행한다. 탈출 판정은 마지막 구간에서 적의 실제 추적이 끝났는지 확인하거나 안전한 차단 상태를 적용한 뒤 한다.
5. 전투안은 해당 시도 적이 정리된 뒤 공터의 불씨 지점으로 돌아온다. 탈출안은 안전 둔덕에서 여우신과 현재 불씨 상태를 확인한다. 둘 다 흩어진 신호가 작은 불씨 하나로 안정되었다는 실제 이야기 적용을 확인한다.
6. 소유자가 현재 불씨를 살피고 여우신의 반응을 듣는다. “아직 따뜻해”라는 말은 신호 상태에 대한 말이며 발신자의 생존 증명은 아니다. 작은 불씨 안정과 해당 경로의 실행 증거가 완료 조건이다.

현장 구현: 스켈레톤2+거미2를 단일 시도ID로 공터 외곽 A+(±5,0,±4)에 생성, 바닐라 생존 전투 수치/난이도 사용, 장비 강화0·퀘스트 드롭/XP0. 방어는 소유자 엄폐 이동과 적의 유효 공격을 엄폐로 차단1회 또는 적에게 유효 공격1회 후 시도 적4마리 정리. 모든 막타 불필요. 탈출은 Exit→C0→Safe 순서 통과 및 소유자/본체 양쪽 안전 지점 진입, 적 추적대상 해제와 접근경로 차단 확인. 벽만 설치하고 추적 중이면 완료 아님. 분기 변경시 기존 적 사용, 추가4마리 생성 금지.

보상과 인수: 기존 음식4개 시험안을 minecraft:baked_potato 4개로 구체 채택. 수혜자는 이 성공 시도에서 위 방어 기여 또는 실제 3지점 탈출 동행을 수행한 개인. 소유자 무참가면 MAIN 미완; 친구 도움만으로 대리 완료 없음. 현장 공용 보급함은 실제 재고로 4×신청 인원 예약. NPC가 자기 식량을 실입고한 기록 필요. 재고 부족은 음식 지급만 대기, 이미 유효한 현장 성취를 막지 않음. 개인 최초1회, 새 반복경제 없음. 부분수령은4-실제수령량만 복구. 이미 받은 뒤 먹음/분실은 재지급 없음.

실패·재개: 전투/탈출/시작 전 보류. 소유자가 전투 중 탈출로 바꾸면 남은 실제 세 지점과 추적 종료를 확인한다. 친구 철수는 본인 참가만 끝낸다. 소유자 종료 때 신호 안전 보존·시도 적 정리. 정리 미지원이면 안전 귀환 후 중지, 새 적 중첩 금지. 안정 검증 뒤 사망했으면 되돌리지 않고 생존 복귀 후 확인만 잇는다.

후발자: 친구 막타와 일반 전투 기여는 인정하되 소유권·고백 권리는 없다. 소유자 부재 중 몹을 다 잡아도 개인 MAIN 완료를 대신하지 않는다. 필요한 후속 확인은 실제 접촉이 가능할 때 남은 부분만 수행한다.

예상: 5–10분; 전체 마감 없음.

## FOX-M04

선행: FOX-M03

1. 소유자는 공터에서 쉼터까지 확인된 길을 걸어 여우신의 현재 위치에서 재회한다. 바로 인접한 경우 불필요한 장거리 왕복을 추가하지 않는다.
2. 불씨 관찰점 옆에서 현재 빛이 일정하게 남아 있는지 확인한다. 안정된 작은 불씨를 인벤토리로 가져가려면 별도 허용과 실제 운반 자산이 필요하며 기본안에서는 현장 상태로 둔다.
3. 여우신과 안전 우회로가 보이는 쪽, 잔향이 남은 숲 쪽을 각각 바라본다. 한쪽은 신호 보존 뒤에도 쓸 길, 다른 쪽은 불씨를 풀었을 때 조용해질 범위라는 현재 두 용도를 설명한다.
4. 기다리는 사람을 묻기, 함께 신호 듣기, 오늘의 평범한 이야기를 하기 중 원하는 대화를 한다. 무응답 시간을 수치로 채워야 완료하는 묵념 퀘스트로 만들지 않는다.
5. 두 쓰임의 차이를 실제 현장 관찰문에서 확인한다. 소유자가 “신호는 남지만 숲 잔향도 남는다”, “숲은 조용해지지만 이 불씨의 귀환 단서는 사라진다”는 내용을 이해하고 질문을 마치면 M05 선택이 열린다. 지금 결정할 필요는 없다.

현장 구현: 안정 불씨와 보존 우회로/풀기 대상구간을 실제 관측. 두 용도 설명을 수신한 뒤 질문 종료/이해 응답으로 완료하되 특정 대사 정답·고백 열람은 요구 안 함. 인접한 본체에 주점 왕복 요구0.

보상과 인수: 실물0. 사적 이름은 계속 비공개 가능.

실패·재개: 사연 질문·신호 듣기·일상 중 선택. 답변을 거절해도 두 용도만 확인하면 완료. 급하면 사연을 생략한다. 둘 다 하자는 추리는 이번 불씨 1개의 양립 불가 범위만 설명한다. 끊김 뒤 이미 확인한 두 용도와 실제 들은 말 유지. 고백 재청취를 강요하지 않고 불씨 만료 없음. 청중 통제 미지원이면 사적 회상만 보류하고 공개 가능한 효과 설명은 진행.

후발자: 친구가 근처에 있다는 이유로 청중에 넣지 않는다. 소유자와 여우신이 함께 허용한 사람에게 실제 말한 부분만 남기며 늦은 사람은 현재 공개 길만 확인한다. 필요한 후속 확인은 실제 접촉이 가능할 때 남은 부분만 수행한다.

예상: 3–6분; 전체 마감 없음.

## FOX-M05

선행: FOX-M04

1. 불씨가 현재 안정되어 있고 이미 어떤 용도로 쓰이지 않았는지 확인한다. 후발 친구가 가져온 유사한 불빛을 원본 신호로 판정하지 않는다.
2. 소유자는 보존·숲에 풀기·유예 중 고른다. 앞선 설명을 알고 대상과 결과를 분명히 요청했다면 같은 확인을 반복하지 않는다. 농담·침묵·소유자 부재에는 아무 결말도 실행하지 않는다.
3. 보존을 확정하면 여우신이 동의한 현재 쉼터의 신호 자리로 함께 걸어가 불씨를 고정하는 작업을 진행한다. 플레이어는 그 자리에서 M01 리듬이 계속 읽히는지 확인하고 M02 우회로 입구까지 걸어 잔향이 남은 구간을 표시한다.
4. 숲에 풀기를 확정하면 여우신과 숲 입구·물가의 두 분산 지점으로 이동한다. 첫 지점에서 불씨를 풀고 다음 지점에서 잔향 감소를 확인한다. 효과 적용을 확인하기 전에는 단서가 사라졌다고 완료하지 않는다. 이어 기존 건널목을 걸어 더 이상 잘못된 방향 유도가 발생하지 않는지 관찰한다.
5. 보존안은 남은 신호와 안전 우회로, 풀기안은 사라진 이 불씨의 신호와 조용해진 지정 구간을 함께 확인해 마친다. 유예안은 현재 상태가 안정됨을 확인하고 떠난다. 유예에는 매일 접속·재료 공급·재서명 의무가 없다.

현장 구현: 보존: Keep에 본체와 소유자 도착→불씨 상태 retained 1회 커밋→리듬 관측→C0 우회 표식 확인. 풀기: Release1 도착→released 1회 커밋→Release2 잔향 감소 관측→C0/C1 건널목 관측. 유예: deferred/안정 보관만, complete false. 저장상태 불명은 원장과 현장 대조, 반대 분기 실행 금지.

보상과 인수: 실물0. M05 완료와 본인 실제 초월급은 별도 사건, 순서무관 AND. 다음 실제 재회에 소유자에게만 서방님·매우 우호. 훈련·선물·MAIN 추가시험0.

실패·재개: 보존/풀기/유예. 소유자의 명시 선택과 여우신의 현재 동의가 필요하다. 이미 대상·효과를 분명히 승인했다면 반복 확인하지 않는다. 침묵·농담·부재에는 실행 없음. 이미 풀기 적용 뒤 끊김이면 반대 결말로 바꾸지 않고 복귀 후 관찰을 마친다. 중간 상태 불명이면 현장을 검증하고 불씨를 추가 생성하지 않는다. 유예에는 납부·접속·재서명·반복 독촉 없음.

후발자: 친구는 길 정비 기여만 얻고 결말 권한·불씨·호칭을 받지 않는다. 소유자 부재에도 현재 우회로·SIDE·공용 코어는 진행한다. 후발자는 C28 현재 보존/소모/유예만 확인한다. 필요한 후속 확인은 실제 접촉이 가능할 때 남은 부분만 수행한다.

예상: 4–8분; 전체 마감 없음.

## FOX-SIDE

선행: 현재 실제 접촉; C15/T03/밤 제한 없음

1. 여우신에게 오늘 실제로 걸을 수 있는 강둑과 숲길 가운데 한 곳을 제안한다. 그녀가 지금 동행할 수 없으면 현재 길 조사만 해 두고 나중에 만나며 허구 동행을 기록하지 않는다.
2. 선택한 길의 입구에서 지금 실제로 보이는 지형·표식을 살핀다. 불씨 미발견 상태에서는 일반 산책으로 이미 확인한 안전한 길만 쓰고 M01·M02의 신호·반사점·귀환 증거를 생성하지 않는다. 불씨 발견 뒤 M05 보존 또는 진행 중이면 실제 공개된 안전 우회로를, 숲에 풀기 완료면 실제 조용해진 길을 쓴다. MAIN 자료가 공개되지 않았으면 별도의 현재 산책길을 택한다. 어느 상태라도 MAIN 단계 재연은 없다.
3. 길을 따라 실제 관찰점 두 곳을 걷는다. 평범한 여우가 실제로 있으면 멀리서 관찰할 수 있고, 없으면 강의 흐름·낙엽·사람의 발자국을 보는 대체를 쓴다. 여우 스폰·포획·사냥을 완료 조건으로 삼지 않는다.
4. 돌아오는 갈림길에서 오늘 선택한 길을 표시하고 동행을 마친다. 실제 왕복·두 관찰점·만난 배우가 완료 증거다.

현장 구현: MAIN 비소유자의 현재 산책. S→Walk1→Walk2→S 실제 왕복, 두 관측점에서 직접 관측. 숲/강둑 둘 중 안전한 현재 경로 사용; 여우 없어도 물결과 잎으로 완료. 실제 동행 구간만 기록하고 본체 이탈시 남은 부분을 재회 뒤 잇는다.

보상과 인수: 실물0, 개인 오늘 기억. 반복 가능하지만 MAIN·신호·호칭 권리0.

실패·재개: 강둑/숲길 취향 선택, 짧게 한 바퀴 또는 거절. C15 전에는 이미 안전한 일반 길만, 이후에는 실제 공개된 현재 우회로/조용해진 길만 쓴다. 자료 미공개면 별도 현재 길. 끊김 후 실제 걸은 부분을 유지하고 남은 왕복만 한다. 본체가 떠났으면 실제 현재 위치에서 재회한다. 개인별 동행 복제·강제 대기 없음.

후발자: MAIN 미소유 때도 가능하며 인사 안 했으면 본인 인사부터 한다. 뒤늦은 사람의 대체 경로지만 사적 MAIN·옛 불씨 발견·소유자 호칭을 승계하지 않는다. 필요한 후속 확인은 실제 접촉이 가능할 때 남은 부분만 수행한다.

예상: 3–6분; 전체 마감 없음.
