# 탑과 여우신과 루브라스의 플레이 장면 상세안

2026년 10월 7일 개정

이 문서는 선택 탑 T01–T04, 여우신 첫 만남과 개인 MAIN M01–M05 및 별도 SIDE, 루브라스 연결 장면 네 개를 게임에 옮기기 위한 콘텐츠 명세다. 기준은 [메인 스토리 개정안](../01_메인_스토리_개정안.md)의 선택 사건과 선행 표이며, 기존 카드의 행동·선택·지식·복구를 유지한다. 기존 기믹 상세안은 상층 안전과 전투 관찰의 참고 자료로만 사용한다.

아래 세부 동선, 대사, 작은 기록 내용, 수량과 보상은 실행 제안이다. 구현 코드, 등록된 좌표·아이템·NPC ID, 완성 페르소나를 뜻하지 않는다. 실제 서버 적용과 LLM 대화 시험은 하지 않았다. 작가용 정보가 있으므로 이 문서 전체를 플레이어 안내문으로 공개하지 않는다.

탑·FOX·LUB은 C 사건과 엔딩의 추가 필수 조건이 아니다. 높은 등급만으로 일반 조우를 C15나 C21까지 금지하지 않는다. 실제 위치·접근로·본인 의사·봉인과 현재 세계 수용 조건을 충족한 인물은 초반에도 후보가 되며, 세계 진행에 따라 낮은 등급 초반·높은 등급 후반의 상대적 후보 확률을 우대할 수 있다. 만남의 가능성과 강한 권능 행사·가호 수용·MAIN 수행 준비는 별도로 확인한다. 희박한 일반 조우와 완전 봉인의 접근 불가는 같은 확률 문제가 아니다. 탑의 C 조건, FOX 신호 조사, LUB의 후기 봉인 자료는 구체 사건·접근 이유가 있으므로 유지한다. LUB01·02의 초반 로컬 경로에는 C12·C17을 일반 조우 잠금으로 적용하지 않는다. LUB02 이후 장면에 필요한 현장 위치와 당사자 접촉을 확인하되 LUB01 완료 배지를 새 열쇠로 요구하지 않는다. 먼저 간 사람이 남긴 공개 자료로 현재 현장을 찾을 수 있다. 탑의 선행은 세계 진행으로 확인하고 후발자의 전 단계 개인 훈련을 강제하지 않는다.

일반 공유 분기는 제시한 해당 결과 범위에서 첫 유효 확정이 적용된다. 질문·농담·침묵은 확정이 아니다. 비용과 영향을 설명하고 명시적 선택을 확인한 뒤 실제 행동이 성공해야 결과를 기록한다. 한 분기를 확정해도 다른 독립 조사·생활 작업을 잠그지 않는다. NPC 동의와 개인 물자 제공은 각각 당사자가 정한다. C27의 지정 참여자 전원 동의를 이 선택 사건들에 추가하지 않는다.

완료한 공유 사건은 후발자를 위해 원상복구하지 않는다. 후발자는 현재 구조, 공개된 기록, 자기 행동을 통해 따라잡는다. 공용 기록에 놓였다는 것과 실제 읽었다는 것을 구분한다. 과거 참가·개인 찬성·사적 고백을 소급 지급하지 않는다. 최초 선택자가 없어도 다른 사람이 공유 일을 이어 갈 수 있으나 여우신 MAIN 소유자는 부재만으로 바뀌지 않는다.

### 제작 지명과 안전한 대체

다음 이름은 현재 Minecraft 세계의 배치 담당자가 채울 슬롯이며 실제 등록명이나 API가 아니다. 탑과 숲·봉인 현장·최종 원정의 접근은 현재 세계와 이미 존재하는 네더·엔드 범위에서 지정한다. 신화 고향이나 꿈의 도시를 위한 새 플레이 차원을 제작하지 않는다. 신들의 출신·과거는 보존하며, 창구는 이 세계를 관측하거나 계시·가호·제한 현현·실제 개입을 허용하는 연결을 뜻한다. T03·T04의 침입도 현 탑의 연결을 이용하는 사건이다.

- 탑 하층 귀환점·중층 경비 구역·상층 안전층·마지막 통로: 기존 계획 탑 안에서 지정한다. 각 구역의 입구, 출구, 차원, 엄폐, 천장, 낙하 착지면과 청크 경계를 현장에서 확인한다. 탑 자체가 아직 제작되지 않았다면 기존 계획 탑의 제작 범위로 남기고 다른 건물로 완료를 위장하지 않는다. 구조가 준비될 때까지 선택 탑만 미배치 상태로 둔다.
- 여우신 쉼터·숲 옛길·강 건널목·공터: 기존 주점 마당, 실제 숲과 강둑, 이미 다닐 수 있는 낮은 공터를 사용한다. 특정 바이옴이나 새 사당은 필요 없다. 물 반사 연출을 지원하지 않으면 같은 강둑의 관측 기록으로 대체한다.
- 붉은 전장 흔적·봉인석 조사면·외곽 귀환 구간: 기존 동굴·폐허·원정 귀환로 중 실제 답사한 곳을 사용한다. 루브라스를 위한 별도 성채나 매 장면 새 전장을 건설하지 않는다.

보행·몹 전투·지형 엄폐·아이템 운반은 실제 게임 행동이다. 환영, 봉인 반응, 기록 대조, 통로 권한 변경은 작성·연동할 이야기 기능이다. 연출 미지원 시 읽을 수 있는 관측문과 확인 가능한 전후 상태를 사용한다. 위치 판정·단일 개체 상태·선택 결과 저장이 불가능하면 해당 변화 경로를 공개하지 않고 읽기·보류 경로를 제공한다. 지원되지 않는 기능을 대사만으로 실행했다고 판정하지 않는다.

기본 수량은 제작 시험용으로 명시한다. 소모품 보상은 공개한 현장 보급함의 실제 재고나 별도 승인한 보상표에서 한 번 지급한다. 공용 상자와 개인 인벤토리를 같은 재고로 취급하지 않는다. 사망은 일반 게임 규칙대로 처리하며 무적·자동 부활·장비 회수·아이템 복제를 약속하지 않는다. 이 파일의 선택 장면 때문에 오프라인 사망, 봉인 악화, 집 파괴, 실패 시한이 발생하지 않는다. 다른 문서의 디오니소스 포션 의뢰에만 있는 현실 48시간 예외를 탑·FOX·LUB 또는 후속 MAIN에 옮기지 않는다.

### 배우와 지식의 경계

여우신은 여성체 동물신 한 명이며 달기·타마모노마에·구미호는 지역별 이름이다. 천군 소속·출발 등급 최상급은 확정이고, 다른 신성의 흡수로 초월급에 도달할 수 있다. 이나리나 모든 여우 종족과 합치지 않는다. 한 사람의 실제 위치와 출현 조건을 사용한다. 일반 여우와 빛·음성 흔적은 그녀의 분신이나 추가 본체가 아니다.

멸룡 루브라스는 묵시록의 붉은 용을 이 게임에서 재해석한 인물로, 진짜 용 종족의 드래곤 로드이자 그 가운데 최강자이며 천군 군단장, 천마의 신뢰받는 오른팔이다. 강함을 존중하는 진짜 용들에게 큰 존경을 받지만 종족 전체가 자동 복종하지는 않는다. 진짜 용은 계약을 중시하고 거짓말쟁이를 싫어하며, 묵시록 원전의 모든 세부 행적을 이 인물에게 자동 부여하지 않는다. 본래 전투등급은 초월급이며 같은 초월급 안에서도 천마보다 약하다. 신격 여부는 별개로 미정이다. 완전 봉인 중에는 일반 조우가 없다. 초반 첫 1겹 작업 동의·안전 확인을 위한 봉인석 바로 곁의 제한 접촉만 가능하며, 한 겹 해제 뒤에도 잔여 봉인·세계 수용 범위·접촉자 수용 범위를 따로 확인한다. 진짜 용은 거짓말할 수 없지만 답변·계약·협력을 거절할 수 있다.

니알라토텝과 크툴루의 신격 여부를 이 문서에서 확정하지 않는다. T04는 니알라토텝 실제 단일 본체의 제압과 연결 봉인에 관한 사건이며 영구 살해를 선언하지 않는다. 크툴루는 기록 언급만 있다.

## T01 첫 계단은 실제 계단

### 시작과 장면의 역할

C02 완료 뒤 탑 하층 입구의 귀환 안내판과 실제 계단이 시작 증거다. 탑이 준비되어 있고 통행 가능한 것이 확인되어야 한다. 이번 목적은 높은 층 보상보다 돌아오는 길을 먼저 익히는 것이다. 첫 엔더드래곤 토벌 전에 선택 가능한 탐험·전투 연습으로 사용한다. 엄폐로 사선을 끊기, 함께 적을 나누기, 장비와 음식의 실제 사용, 살아서 복귀하는 경험을 얻되 첫 용의 패턴을 연습했다거나 같은 난도라고 기록하지 않는다. T01을 건너뛰어도 C04의 실제 준비와 C05 참가에는 별도 탑 인증이 필요 없다. 안내는 현장에 이미 있는 관리 주민에게 배정할 수 있으나 필수 고유 NPC를 추가하지 않는다. 관리 주민이 없으면 그가 남긴 공개 점검표만 사용한다. 기록은 플레이어 질문에 자율 응답하는 주민 복제체가 아니다.

후발자는 현행 안내판에 이전 조사 결과가 남아 있음을 보고, 현재 길 한 번 확인 또는 새 훈련을 선택한다. “아무도 이 탑을 오른 적 없다”는 첫 방문 대사를 반복하지 않는다.

### 실제 행동과 완료 증거

1. 입구에서 귀환점과 한 층 위 착지면을 직접 본다. 안내판의 “하층 동쪽 계단으로 돌아온다” 같은 문구는 실제 배치 방향에 맞춰 작성한다.
2. 첫 모서리까지 올라가 뒤를 돌아 입구가 보이는지 확인한다. 보이지 않으면 다음 모서리의 귀환 표식을 확인한다. 길 표시가 부족한 경우 사용 허락된 벽면에 횃불 2개 또는 표지 2개를 배치하는 안을 쓴다.
3. 계단 위의 엄폐 둘과 내려오는 길 하나를 지도에 표시한다. 지도는 작성된 조사 페이지로 대체할 수 있다. 클릭만으로 답사를 대신하지 않고 관찰 지점 도달과 표식 확인을 남긴다.
4. 다음 두 활동 중 하나를 수행한다. 전투 시험은 스켈레톤 1마리·좀비 2마리를 시험 기본안으로 두고 모서리 엄폐를 오가며 실제 제거한다. 지도 작성은 옆 복도를 돌아 합류점에 도달하고, 위에서 내려오는 사람에게도 읽히는 귀환 표식 두 곳을 확인한다. 전투와 지도 작업은 공간이 안전하게 분리되면 병행한다.
5. 실제 귀환점까지 내려와 자신이 확인한 길을 마감한다. 전투 선택자는 해당 시도의 적 정리를, 지도 선택자는 왕복 동선과 두 표식을 완료 증거로 남긴다.

|---|---|---|---|
| 전투 시험 | 현재 훈련 구역에 실제 적을 투입한다는 설명 후 참가자가 시작 수락 | 참전·생존 복귀 또는 실제 승리 이력 | 다른 사람 지도 작성까지 완료하지 않음 |
| 지도 작성 | 자신의 이동·허락된 표식 설치, 공용 전투 결과를 고르지 않음 | 공개 귀환도 한 벌, 작성자 기여 | 전투 승리 없음 |
| 돌아가기 | 개인 철수, 탑의 영구 폐쇄 아님 | 현재 기록 보존 | T01 개인 경험 보류 |

두 방식 중 하나가 실제 완료되면 T01 세계 안내가 성립한다. 완료를 전투 선호도나 특정 직업으로 제한하지 않는다.

관리 주민의 지식은 자신이 점검한 하층, 오래된 상층 출입 금지 표식까지다. 미래 침입자의 정체는 모른다. “왜 하필 나야?”에는 “네가 먼저 문을 열었을 뿐이야. 길은 다음 사람도 써야 하니까”라고 답한다. 위층 적을 일찍 추측하면 “그건 올라가 확인한 기록이 아직 없어”라고 한정한다. “위로만 달리면 되지?”에는 “그럼 내려올 때 같은 모서리를 찾을 수 있는지 보자”라고 실제 확인을 제안한다. 거절에는 길을 가리켜 주고 멈추며, 급한 사람에게 기존 지도 열람만으로 실제 답사 이력을 주지 않는다.

### 결과와 복구

공유 보상은 실제 확인한 귀환 지도와 하층 통행 정보다. 참가자는 처음 끝낸 활동에 한해 빵 2개·횃불 4개를 시험용 보급안으로 받으며 재고 부족 시 미지급 표시를 남긴다. 선택 전투 훈련은 후속 반복 가능하나 첫 탐사 완료와 보급을 반복 생성하지 않는다. 세계 T01이 이미 끝났다면 개인 지도 확인이나 훈련 결과만 추가한다.

사망·철수·접속 종료 때 기록된 관찰은 유지한다. 남은 훈련 적을 안전하게 정리했는지 확인하기 전에는 같은 구역에 새 시도를 겹치지 않는다. 다른 사람이 이어서 적을 정리하면 그 사람의 실제 기여이며 이탈자의 개인 승리가 되지 않는다. 사망 물품 회수는 정상 규칙을 따른다.

핵심 재미는 계단과 엄폐를 몸으로 익히기다. 한 번 왕복하고 선택 활동 하나를 확인하면 마친다. 추가 층 등반은 요구하지 않고 C06 이후 T02 안내가 생긴다는 공개 예고만 둔다.

### 제작과 인수 검사

- 필요 자산: 기존 탑 하층 배치도, 귀환 표식 2개, 엄폐 2곳, 훈련 적 구성, 현행 지도 문안, 보급 수령 기록.
- 감지할 사실: 실제 관찰점 도달, 귀환점 복귀, 해당 시도 적 제거 또는 두 표식 확인. 발언만으로 완료 불가.
- 대체: 자동 NPC 안내가 없으면 공개 점검표와 표지판. 적의 시도별 귀속·정리가 불명확하면 전투 시연을 열지 않고 지도 경로만 제공한다.
- 배포 전 확정: 실제 층 좌표·허용 건축면·적 생성 및 정리 방법·보급 지급 경로. 고정 최소 인원 없음.
- 검사: 지도만으로 T01 완료 가능 / 두 플레이어 병행 시 보급 중복 없음 / 로그아웃 후 타이머 피해 없음 / 상층 미완성이어도 C03–C28 진행 유지.

## T02 끝나지 않는 경비 근무

### 시작과 등장 방식

T01과 C06 완료 뒤 중층의 같은 경비 구역에서 시작한다. 첫 용 토벌 뒤 통행·구호가 달라져 현재 방문자와 오래된 거주 명부의 불일치를 다시 다루는 사건이다. C06는 이 점검의 이야기 조건이며 솔로몬·브리기드의 일반 첫 조우를 늦추는 조건이 아니다. “거주자만 통과”라는 낡은 명령판과 지금 주민이 없는 명부가 시작 증거다. 관리 주민이 이전 결과를 들었다면 T01의 작성자를 기억할 수 있지만 모르는 참가자를 작성자라 부르지 않는다.

경비체는 비신격 방어체다. 실제 사용 가능한 기존 방어체 자산 한 기를 우선 배정한다. 없으면 한 구역을 지키는 스켈레톤 기반 방어체 한 기를 별도 이름표·장비로 표현하는 제작 제안을 사용한다. 종족 원전을 추가하지 않는다. 솔로몬은 공개 판정 양식의 작성자, 브리기드는 수리 원칙의 작성자로 기록에만 등장한다. 두 본체 호출은 조건이 아니다.

### 실제 행동과 증거

1. 안전선 밖에서 경비체의 경고와 명령판을 읽는다. 현장 문안은 “명부에 없는 방문자는 침입자”로 잡는다. 이 규칙을 현재 전체 주민의 법으로 확대하지 않는다.
2. 같은 층의 비어 있는 거주 구역을 살피고, 마지막 이주가 적힌 명부와 현재 출입 명령의 날짜·대상을 비교한다. 빈 방만으로 전원 사망을 결론내리지 않는다.
3. 솔로몬의 공개 양식 중 “허가 대상과 실행 대상 분리”, 브리기드의 원칙 중 “사람을 보호할 장치를 사람 시험에 쓰지 않기” 두 항목을 찾아 해당 명령의 잘못된 대상을 표시한다.
4. 유지 또는 파괴의 공동 영향을 읽고 명시적으로 고른다. 유지안은 주민 공격 명령을 바로잡고 작동 확인을 한다. 파괴안은 자동 경비를 잃으며 전투가 시작된다. 지금 조사만 마치고 물러날 수도 있다.
5. 유지안은 안전선 밖의 확인 장소에서 “현재 방문객을 기본 공격하지 않음, 실제 적대 행동 때만 구역 방어, 구역 밖 추적 금지” 세 항목을 점검한다. 담당자가 실제 명령 변경을 적용한 뒤 플레이어가 경계를 왕복해 오작동이 멈췄는지 본다. 실제 주민을 미끼로 투입하지 않는다.
6. 파괴안은 기둥 엄폐를 사용해 방어체를 실제로 제압하고 남은 공격원·투사체가 없는지 확인한다. 플레이어가 부쉈다는 말만으로 파괴 이력을 만들지 않는다.
7. 선택 결과를 명령판 옆에 남기고 현재 중층 복귀로를 다시 지난다. 유지안은 수정된 규칙과 시험 통과, 파괴안은 방어체 소멸과 자동 경비 중지 확인이 완료 증거다.

### 분기와 정보

| 선택 | 명시 확인 내용 | 공유 결과와 비용 | 완료되지 않는 것 |
|---|---|---|---|
| 경비를 고쳐 남김 | 이 구역의 주민 공격 명령을 수정하고 자동 경비를 유지 | 잘못된 방문객 공격 제거, 제한 구역 방어 유지 | 탑 밖 모든 경비의 통제권 없음 |
| 경비체 파괴 | 이 한 기와 구역 자동 경비를 영구 포기하고 전투 | 파괴 흔적·자유 통행, 이후 직접 경계 필요 | 경비 복구·유지안 혜택 없음 |
| 조사 후 보류 | 개인 철수, 공동 결론 미확정 | 자료 공개와 안전선 유지 | T02 해결 미완료, 코어 메인은 계속 |

첫 유효 확정 뒤 반대 분기 시작을 같은 경비체에 겹치지 않는다. 파괴 완료 뒤 후발자가 고치기를 골라도 최초 사건을 다시 만들지 않는다. 유지 상태에 대한 나중의 별도 정책 논의는 T02 재보상 사건이 아니다.

관리 주민은 이주 명부와 지금의 공격을 안다. 명령 작성자의 숨은 의도를 알지 못한다. 경비체의 “명부 불일치”는 규칙 출력이지 전쟁 비밀 증언이 아니다. 공개 문헌의 저자는 현장 대화를 듣지 않는다. 플레이어가 “옛 명부가 문제네”라고 먼저 짚으면 두 기록을 실제 확인했을 때 인정한다. “다 부수면 편하지?”에는 “여기는 조용해져. 뒤의 침입도 누가 직접 봐야 하고”라고 비용을 말한다. “신 둘 다 불러서 고치자”에는 공개 원칙으로 시도할 수 있음을 안내하고, 실제로 연락하지 않은 신의 승인을 꾸미지 않는다.

### 결과와 복구

공유 보상은 중층 상태 해결과 T03에 사용할 현재 지도다. 실제 참여자에게 선택 지급하는 방패 1개 또는 화살 8개는 보상표 채택 시의 시험안이며 어느 분기가 도덕적으로 더 옳다는 점수로 쓰지 않는다. 첫 유지·파괴 성과는 한 번만 있다. 후발자는 현재 명령 확인이나 위험 표시 점검을 하며 자기 기여만 남긴다.

전투 사망·접속 종료 시 파괴를 선완료하지 않는다. 남은 사람이 실제 정리할 수 있다. 유지 명령을 바꾸다 중단되면 검증 전 상태로 통행을 제한하고 원래 공격 규칙을 안전 구역에 방치하지 않는다. 명령 변경 기능이 없다면 유지안은 제작 대기이며 파괴만 조용히 강요하지 않는다. 공개 자료 확인·보류가 가능하고 코어 진행에는 영향 없다.

재미는 적으로 보이던 장치의 대상 오류를 찾거나 그 방어를 포기하는 선택이다. 선택 결과가 실제 한 번 검증되면 충분하다. 수리 재료 100개 같은 반복 채집은 요구하지 않는다.

### 제작과 인수 검사

- 필요 자산: 명령판·이주 명부 각 1개, 공개 원칙 2개, 실제 경비체 1기, 유지 및 파괴 후 안내문.
- 감지할 사실: 규칙 세 항목 적용·왕복 시험 또는 해당 방어체 실제 파괴. 인물 호감도는 판정 근거가 아니다.
- 대체: 자동 중립 전환을 지원하지 않으면 공격체를 안전하게 퇴장시키고 별도 비전투 경비 표시를 쓰는 안을 검토하되, 같은 경비체의 상태 전환임을 검증한다. 이를 지원하지 않으면 유지 분기를 배포하지 않고 보류를 안내한다.
- 배포 전 확정: 경비체 실자산과 변경 가능 범위, 구역 밖 추적 방지, 단일 개체 유지 방식.
- 검사: 파괴 후 재접속·후발 방문에서 재생성 없음 / 기록 저자 본체가 없어도 진행 / 보류가 C15를 막지 않음 / 다른 플레이어 소유 장비 자동 소비 없음.

## T03 어제 없던 복도

### 시작과 목표

T02와 C15 완료 뒤 T01·T02의 실제 계단 기록과 다른 빛·발소리가 들리는 상층 경계에서 시작한다. T02에서 경비체를 파괴했다면 없는 경비가 경고했다는 대사를 쓰지 않고 플레이어의 관찰 또는 기존 점검판으로 안내한다. 유지했다면 경비의 감지는 자기 구역 가장자리까지다.

니알라토텝이 현재 탑의 연결 틈을 이용해 이 세계에 개입하려는 흔적을 조사한다. 새로운 신화 차원으로 들어가는 원정이나 문화권 전체의 개방 사건으로 바꾸지 않는다. 직접 본체 대면은 여기서 자동 발생하지 않는다. 크툴루는 오래된 관련 경계 기록의 이름 한 줄로만 등장한다. 발소리, 빛, 가면 무늬는 비대화형 흔적이며 새로운 NPC나 여러 본체가 아니다.

### 실제 행동과 관찰 답안

1. 상층 진입 전 천장, 착지면, 계단 귀환로를 확인한다. 부양 후 안전하게 내려올 수 없는 낭떠러지는 전장으로 쓰지 않는다. 기존 탑 안의 적합한 다른 층을 찾고 없으면 선택 전투 배치를 보류한다.
2. 아래 계단의 표식을 출발점으로 삼아 실제 두 계단 참을 오른다. 지도에 기록한 높이 순서와 현재 밟은 순서를 비교한다. “한 계단을 올랐는데 이전 높이로 향하는 빛”이 첫 불일치라는 실행안을 쓴다.
3. 두 번째 모서리에서 발소리가 난 벽과 실제 통로를 각각 확인한다. 벽은 벽으로 남고 소리가 난다고 통과 가능한 새 복도가 생기지 않는다.
4. 세 번째 지점에서 빛의 문양과 귀환 표식을 대조한다. 안전한 표식은 끊김 없는 아래방향 선, 유도 흔적은 같은 모양의 윗부분이 빠진 선으로 제안한다. 유도 흔적이 원래 기록에 허용된 문턱을 넘어 하층 안전선 쪽까지 이어지는 사실도 조사한다. 모양이 이상하다는 것과 허용 범위를 넘어선 흔적이 있다는 것을 따로 적는다. 색각과 음량에 의존하지 않게 관찰문에도 차이를 적는다.
5. 확인한 세 사실인 계단 순서·막힌 벽·귀환 문양을 공개 조사표에 정리한다. 필요한 자료는 안전선 쪽에서도 확인 가능하게 배치하여 비전투 조사·임시 봉쇄가 유효하게 성립하도록 한다.
6. 침입 구간 전투에 동의하면 셜커 1기와 엔더마이트 2마리를 시험 기본안으로 투입한다. 플레이어는 모서리 뒤에서 유도탄을 피하고 셜커가 노출될 때 공격한다. 부양된 사람은 천장 아래 안전 착지면으로 이동하고 동료는 엔더마이트를 처리할 수 있다. 추가 적 증원은 필수가 아니다.
7. 전투 승리자는 더 안쪽에서 열린 길과 연결 방향을 한 번 더 관찰해 T04의 접근 엄폐 후보를 남긴다. 비전투 선택자는 이미 확인한 세 사실을 가지고 안전선 아래로 돌아와 해당 상층 진입을 임시로 닫는다.
8. 귀환점에서 실제 침입 증거와 현재 접근 상태를 확인한다. 세 근거와 봉쇄 확인 또는 적 제거·현장 확인이 완료 증거다. 단순히 도망쳤으나 자료가 없다면 T03 조사 미완료다.

### 선택 범위와 지식

| 선택 | 확인 | 실행 결과 | 하지 않은 일 |
|---|---|---|---|
| 조사 후 침입체 제거 | 이 상층 시도에 전투 참가, 실제 위험 고지 | 적 제거, 제한된 상층 관찰과 추가 접근 근거 | 니알라토텝 제압 아님 |
| 세 근거 확보 후 임시 봉쇄 | 해당 통로만 잠정 닫음, 나중 재검토 가능 | T03 조사 완료와 안전선, T04 자료 확보 | 전투 승리·내부 전리품 없음 |
| 자료 없이 철수 | 개인 철수 | 생존 복귀·이미 관찰한 항목만 보존 | T03 완료 아님 |

충분한 조사와 임시 봉쇄도 T03 완료가 될 수 있다. 따라서 T04에서의 영구 절단이 본체 전투를 강제하지 않는다. 전투 추가 관찰은 실제 엄폐를 미리 아는 이점이며 코어 장비 열쇠가 아니다.

현재 조사자는 직접 본 세 불일치를 안다. 기록의 저자는 “크툴루 관련 기록”의 범위만 알려 주며 지금 그가 여기에 있다는 보증이 아니다. 현장 문안: “소리는 길을 보여 주지만 계단을 대신 놓아 주지는 않는다.” “여기 크툴루가 나온다는 뜻이지?”에는 “이름이 같은 자료가 있다는 것까지다. 실제 개체는 확인하지 않았다.”라고 답한다. “저 가면을 전부 죽여야 해?”에는 비전투 흔적임을 알려 준다. 서두르면 세 근거가 모인 현재 자료로 임시 봉쇄를 선택할 수 있다. 농담으로 문을 열겠다고 해도 실행하지 않는다.

### 결과와 회복

공유 보상은 T04 자료와 현재 상층 안전 상태다. 실제 전투 승리 참가자에게 이동·방어 측면 장비 후보를 열 수 있으나 미작성 장비를 존재한다고 약속하지 않는다. 기본 지급안은 실제 기여자당 익힌 음식 4개 또는 화살 8개 중 하나, 최초 1회다. 관찰·봉쇄 참가자는 조사 완료 이력과 같은 범위의 조사 보급을 받을 수 있지만 전투 칭호를 받지 않는다.

사망·로그아웃은 세계 침입 확산 시계가 아니다. 셜커의 실제 이동·추가 생성·잔존 개체를 확인한 뒤 같은 구역의 재시도를 허용한다. 정리가 불확실하면 그 상층 시도만 잠그고 하층·중층과 코어는 유지한다. 전투에 뒤늦게 온 사람은 현재 전투에 참여한 만큼만 기록하고 과거 관찰을 자동 읽지 않는다.

재미는 지형과 증거로 감각을 의심한 뒤 안전한 높이 싸움을 하는 것이다. 세 근거와 현재 통로 상태를 확정하면 마친다. 기록 방을 전부 돌거나 니알라토텝 개인 MAIN을 찾을 필요가 없다.

### 제작과 인수 검사

- 필요 자산: 세 관찰문·안전 표식·유도 표식, 기록 이름 한 줄, 셜커 및 엔더마이트, 적합한 천장과 착지면.
- 감지할 사실: 실제 세 관찰, 임시 봉쇄 적용 또는 해당 시도 적 정리, 현재 귀환로. 셜커와 엔더마이트 외의 다른 승인되지 않은 적으로 대체하지 않는다.
- 대체: 빛·발소리 연출이 없으면 물리 표식과 현장 관찰문을 읽으며 이동한다. 셜커 안전성 검증이 안 되면 조사·임시 봉쇄 경로로만 배치한다.
- 배포 전 확정: 상층 실제 형상, 셜커 순간이동·증식·청크 경계 정리, 접근 제한을 적용하는 범위.
- 검사: 승인 적 구성 일치 / 무음·색상 구별 없이도 세 근거 판독 / 임시 봉쇄 뒤 C20 및 T04 접근 유지 / 여러 가면을 본체로 세지 않음 / 크툴루 자동 생성 없음.

## T04 이름을 부르지 않는 퇴로

### 시작과 상대의 제안

T03와 C20 완료 뒤 마지막 통로의 외측 안전선에서 시작한다. T03 공개 기록은 후발자도 읽을 수 있다. 니알라토텝이 실제 단일 본체로 접촉할 수 있을 때만 직접 대면한다. 다른 곳에 있거나 출현 조건이 불충족이면 제안을 담은 이미 확인된 기록 또는 현재 통로의 남은 유도문을 조사한다. 그 기록이 오늘의 모든 사실에 새로 답하는 대화창이 되지 않는다.

제안 대사: “너희가 찾던 마지막 문이라면, 내가 열어 줄 수 있지. 돌아올 길까지 누가 맡아야 하는지는 따로 이야기하자.” 목적은 플레이어의 침입 허용을 얻는 것이다. 마지막 문 기술이 실제 독립된 안전 해법인지 T03 증거로 반박한다. 여신의 사적 고백을 전달받지 않았다면 이를 알고 유혹하는 대사를 쓰지 않는다.

### 실제 행동과 증거 대조

1. T03의 세 관찰과 현재 문 바깥의 계단·벽·표식을 대조한다. 이전 완료자도 지금 접근 범위가 바뀌지 않았는지 한 지점을 직접 확인한다.
2. 제안 중 “길은 이어져 있다”, “되돌아갈 수 있다”, “허락한 범위만 통과한다” 세 주장에 각각 관찰 근거를 연결한다. 첫째는 높이의 불일치, 둘째는 막힌 벽, 셋째는 잘린 귀환 문양을 따라 허용 문턱 밖까지 이어진 유도 흔적과 대응하는 실행안을 쓴다. 이로써 안전을 보증하지 못한다는 결론을 얻되 전지적 거짓말 탐지 능력을 주지 않는다.
3. 관리 봉쇄·영구 통로 절단·임시 철수를 비교한다. 관리 봉쇄는 실제 본체 대면과 제압이 가능할 때만 제시한다. 영구 절단은 상층 탐사·보상 일부를 포기하는 공유 비용을 설명하고 명시적으로 확정한다.
4. 관리 봉쇄를 택하면 실제 본체 한 명의 현장 상태와 전투 참가자를 확인한 뒤 싸운다. 기본 전투는 사용 가능한 본체 전투 자산의 실제 패턴을 사용한다. 추가 엔더마이트 최대 2마리를 한 차례 넣는 것은 시험안이다. 가짜 가면은 피해·말·전리품을 가진 별도 본체가 아니다.
5. 실제 제압 뒤 본체와 연결을 구분한다. 플레이어는 외측 계단에서 관측·통과·귀환의 세 제한을 순서대로 확인하고 이 탑에 침입이 닿는 해당 연결을 봉인한다. 현재 세계의 모든 신화 창구나 네더·엔드 통행을 일괄 봉쇄하지 않는다. 전투 중 체력 정지나 상호작용 안전창이 검증되지 않았다면 전투가 끝난 뒤 안전한 이야기 단계로 수행한다.
6. 영구 절단을 택하면 대면 전투 없이 외측에서 현장 통로의 세 연결점 표시를 찾고, 확인된 통로 차단 작업을 실행한 다음 안전선 밖으로 나온다. 이것은 실제 봉쇄 상태 적용과 왕복 불가 검증이 필요한 작업이며 “끊었다”고 말하는 것으로 완료되지 않는다.
7. 관리 봉쇄는 현재 연결의 제한과 허용된 상층 통행을, 절단은 해당 상층 진입 불가와 하층·중층 귀환 가능을 직접 확인한다. 문 밖의 결과 표지를 바꾸고 완료한다.

### 선택별 결과

| 결과 | 필요한 확인과 실행 | 실제 남는 성과 | 소유·보상과 금지되는 해석 |
|---|---|---|---|
| 관리 봉쇄 | 본체 대면 가능, 전투 수락, 실제 제압, 연결 봉인 검증 | 해당 연결 제한, 허용된 상층 일부 이용 | 실제 전투 참가자만 제압 이력·전투 보상. 본체 영구 사망이나 소유권 없음 |
| 영구 통로 절단 | 세 증거 확인, 상층 영구 폐쇄와 남은 탐사·보상 포기를 명시 수락, 실제 차단 | 해당 상층 통로 닫힘, 하층·중층 보존 | 차단 기여·조사 보급. 본체 패배·본체 봉인·이동 기록 및 보스 보상 없음 |
| 임시 철수 | 아직 최종 결과 미확정 | 기존 임시 안전선 유지, 나중 재개 가능 | 영구 절단 동의나 승리 없음 |

영구 절단은 이 사건의 재도전으로 되돌리지 않는다. 대면 불가를 이유로 가짜 본체를 생성하지 않는다. 관리 봉쇄 후도 같은 니알라토텝 첫 제압을 반복하지 않는다. 별도 훈련 시스템이 없는 상태에서 재현 레이드를 약속하지 않는다. 이 선택은 C25–C27 접근 권한을 바꾸지 않는다.

### 상대가 알 수 있는 말과 짧은 반응

니알라토텝은 자신이 낸 제안과 이 통로를 이용하려는 목적, 직접 본 대응을 안다. 플레이어 개인 지식 전체를 읽지 않는다. 불일치가 제시되면 “문은 열릴 수 있지. 네가 기대한 곳으로 열린다고 내가 약속했나?”처럼 책임을 비틀 수 있으나 자료를 사라지게 하지는 않는다. 플레이어가 이 논리를 일찍 알아채면 대조 단계를 줄여 확인하고 비용 선택으로 간다.

“당신에게 열쇠를 안 주면?”에는 “너희가 닫을 수 있는 길이 어디까지인지 보겠군”이라고 반응한다. “상층 월세가 너무 비싸”라는 농담에는 “돌아오는 값이 더 비쌀 수도 있지”라고 받아도 계약 체결로 판정하지 않는다. 급한 사람에게는 세 증거 요약과 절단의 영구 비용을 한 번 설명한다. 본체 없는 기록 경로에서는 이 새 질문에 니알라토텝이 답하지 않는다.

### 완료와 실패 복구

관리 봉쇄 완료 증거는 실제 제압 기록·단일 본체 상태의 검증·해당 연결 제한·상층 허용 범위다. 절단 완료 증거는 본체와 무관한 통로 차단·상층 폐쇄·하층 귀환 가능이다. 결과와 접근 상태가 서로 어긋나면 완료 보상 전에 정합을 확인한다. 전투 장비 보상은 최종 측면 교체 후보이며 본편 필수 스탯을 독점하지 않는다. 미확정 보상표 대신 기본안으로 승리 참가자당 음식 8개·화살 16개를 최초 한 번, 절단 작업자당 음식 4개·횃불 8개를 최초 한 번 제안한다.

제압 전 사망·철수는 실패로 남고 정상 사망 규칙을 따른다. 제압 뒤 연결 봉인 전에 끊기면 실제 제압과 아직 미봉인인 상태를 분리하고 다음 접속자가 남은 안전 작업을 이어 갈 수 있다. 제압을 다시 요구하거나 전리품을 다시 지급하지 않는다. 단일 본체 상태가 불명확하면 대면 시도만 중지한다. 최종 결과 전 임시 봉쇄에는 악화 시한이 없다.

후발자는 이미 닫힌 상층을 새로 열어 같은 승리를 얻지 않는다. 관리 봉쇄 상태라면 허용 구역을 살피고, 절단 상태라면 외측의 남은 계단과 결과 기록을 확인한다. 실제로 읽은 기록만 알며 최초 선택자의 개인 동의는 상속하지 않는다.

이번 재미는 유혹을 말싸움만으로 이기는 대신 돌아갈 권한의 비용을 선택하고 실제 확보하는 데 있다. 제압과 연결 봉인, 또는 상층 절단과 귀환 확인까지면 끝이다. 탑에 남아 선택을 설명하는 반복 면담은 필수가 아니다.

### 제작과 인수 검사

- 필요 자산: 실제 니알라토텝 단일 본체 또는 비대화형 제안 기록, 세 주장 대조문, 세 연결점, 두 최종 결과 표지.
- 감지할 사실: 실제 제압 여부, 해당 연결 봉인 여부, 상층 이용 범위, 절단 확정과 실행 여부. 대사 생성이 이 사실을 덮어쓰지 않는다.
- 대체: 전투 중 봉인 입력 미지원 시 제압 뒤 순차 점검. 본체 전투 자산 미지원 시 임시 철수 또는 본체와 독립된 영구 절단 경로. 실제 통로 차단도 미지원이면 보류만 허용한다.
- 배포 전 확정: 본체 실자산·현재 위치·출현 허용 조건, 전투 종료 처리, 영구 폐쇄의 실제 범위와 보존할 하층 동선. 신격·불멸을 새로 배정하지 않는다.
- 검사: 본체가 다른 장소에 있을 때 중복 0 / 기록이 자율 대화하지 않음 / 본체 부재 절단은 본체 상태를 바꾸지 않음 / 절단 뒤 재도전·상층 보상 반복 불가 / 로그아웃을 절단 동의로 처리하지 않음 / 모든 탑 상태에서 정식 코어 선행 충족 시 C25 진행 가능.

## FOX 첫 만남 불을 따라오셨나요

### 여우신의 확정 설정과 집필 경계

여우신은 지역에 따라 달기·타마모노마에·구미호로 불리는 하나의 신성이다. 여성체 동물신이며 천군 소속이고, 출발 등급은 최상급이다. 다른 신성을 사냥·흡수하며 더 강해질 수 있고 본인이 초월급에 도달할 수 있다. 실제로 행사하는 힘은 현재 봉인과 세계 수용 범위의 제약을 그대로 받는다.

흡수당한 신은 영구 사망하지 않고 특수 봉인에 들어가며, 특정 아이템으로 풀려날 때까지 등장할 수 없다. 봉인이 해제되어도 여우신이 얻은 성장은 유지된다. 해방된 신의 힘이 어떤 상태로 돌아오는지는 아직 정하지 않는다. 기존 인물에게 과거 흡수·봉인·해방을 소급 배정하거나 이름 있는 새 희생자를 정하지 않는다.

다른 플레이어와 실제 대화 이력이 있고 현재 그 플레이어를 적대하지 않는 신은 흡수 대상에서 제외한다. 이 조건을 만족하는 다른 플레이어가 한 명이라도 있으면 보호되며, 그 신이 또 다른 플레이어에게 적대적이어도 마찬가지다. 주시·가호·퀘스트·MAIN 소유는 필요 없다. 이는 집필과 제작에서 지킬 대상 제한이며, 여우신이 모든 사람의 관계를 아는 능력이나 새 우주 법칙을 얻었다는 설정으로 설명하지 않는다.

아래 M01–M05는 기존 과거 퀘스트로 이어 쓰며, 별도 흡수 사냥 연쇄를 새로 만들거나 초월급 도달을 그 시작 조건으로 요구하지 않는다. 이 성장 설정만으로 자동 악역·얀데레·동맹 배신을 부여하지 않는다. 성장량·대상 판별의 구현·해방 아이템 명칭과 ID·반복 제한은 제작팀의 미정 영역이다. 말투와 지식 경계는 [여우신 설정과 관계 변화](../05_여우신_설정과_관계변화.md)를 함께 따른다.

### 시작과 실제 만남

여우신 한 개체가 실제로 현재 생활권에서 접촉 가능한 때, 기존 주점 마당이나 숲 가장자리의 안전한 쉼터에서 시작한다. 일반 인사는 사용자 확정에 따라 첫 용 토벌 전부터 가능하며 C15를 요구하지 않는다. 최상급이라는 이유만으로 초반 후보에서 제외하지 않는다. 특정 밤을 기다릴 필요도 없다. 초반에는 현재의 호칭·일상·걷고 싶은 길을 이야기하고, 아직 발견하지 않은 귀환 신호나 실종 동료의 증거를 받았다고 하지 않는다.

기존 제목의 “불을 따라온” 장면은 C15 뒤 공개된 전쟁 조사 결과와 현장의 실제 불씨 접점을 확인한 경우에 진행한다. 초반에 이미 만났다면 첫 인사가 아닌 재회로 이어지며, 낮에는 그늘의 작은 불빛으로 같은 단서를 읽는다. 이 자료 조건은 M01의 추적 이유를 만들기 위한 것이며 일반 조우 제한이 아니다. 완전 봉인·다른 장소 체류·현재 세계 수용 범위 등으로 실제 조우가 불가능하면 이미 존재가 확인된 흔적만 관찰한다. 본체 부재를 메우려고 새 불씨나 응답을 생성하지 않으며 대화·첫 만남·MAIN 수락은 성립하지 않는다.

실제 배우는 여우신 한 명, 필요한 모델도 한 명이다. 일반 여우는 자연 동물로 남는다. 여우신이 다른 플레이어와 있으면 현재 장소로 가서 만나거나 기다리며 개인별 쉼터에 복제하지 않는다.

### 실제로 하는 일

1. 쉼터에서 실제 여우신에게 인사한다. 일반 첫 만남에서는 현재 숲 풍경만 볼 수 있다. C15 뒤 신호 자료 조건이 맞을 때에는 조금 떨어진 자리에서 실제 불씨가 깜빡이는 숲 방향도 관찰한다. 인사 없이 지나간 것을 만남 완료로 세지 않는다.
2. 이름과 소속을 물을 수 있다. “달기, 타마모노마에, 구미호. 곳마다 다르게 불렀지. 어느 이름이든 내가 돌아볼 거야.”라고 답하고 천군 소속임을 숨기지 않는다. 호칭 선택은 유일한 진짜 이름 맞히기가 아니다.
3. 그녀가 숲으로 몇 걸음 먼저 움직이다 멈추는 모습을 본다. 플레이어는 지금 다닐 수 있는 숲 입구까지 걷거나 쉼터에서 대화를 마친다. 일반 산책은 SIDE로 이어질 수 있다. C15 뒤 신호 장면에서만 불씨가 향하는 실제 옛길과 공개 전쟁 자료의 귀환 흔적을 대조하며, 자료가 없는 초반 인사에 그 추적 성과를 주지 않는다.
4. C15 뒤 전쟁 조사 결과와 실제 신호 접점을 확인했고, 현재 숲길 조사·왕복·방어 또는 탈출을 수행할 준비를 확인한 경우에만 그녀가 “나와 저 불빛을 함께 찾아볼래?”라고 명확히 제안한다. MAIN이 미소유이면 이때 첫 수락 여부를 묻는다. 일반 인사·먼저 만남·SIDE 참여는 선점권이 아니다. 준비가 모자라면 이미 다닐 수 있는 길에서 연습하거나 보류하고, 다른 소유자가 이미 있으면 오늘 산책 SIDE나 현재 대화를 한다. 고정 전투력 수치·가호·장비를 제안과 동시에 지급하지 않는다.

동시 수락은 유효한 첫 한 명만 확정되도록 실제 결과 저장을 검증한다. 이미 다른 사람이 수락한 상태라면 늦은 수락자에게 이를 알리고 선택을 다시 제시한다. 대화 지연이나 먼저 호칭을 부른 순서를 소유 근거로 쓰지 않는다.

### 결과와 회복과 제작

만남 완료 증거는 실제 같은 장소에서 인사한 사실과 들은 말이다. 보상은 이 접점 자체이며 고급 가호·유일 장비·MAIN 선점 보상을 주지 않는다. 재접속은 새로운 최초 만남이 아니고, 사망·이탈은 아직 수락하지 않은 MAIN을 자동 확정하지 않는다. 소유자 부재 중 다른 사람은 자기 만남·SIDE를 할 수 있다.

일반 만남의 재미는 이름과 오늘의 취향을 나누는 데 있고 인사만 마쳐도 충분하다. C15 뒤의 신호 장면에서는 불빛에 먼저 반응하는 사람을 보고, 유효한 추적 제안을 수락하거나 보류하는 데서 마친다.

- 필요 자산: 실제 여우신 모델·현재 위치, 이름과 소속 대사, 현재 산책길. C15 뒤 신호 장면에만 숲 입구 불씨 관찰점·전쟁 자료 출처·MAIN 제안과 소유 상태 안내를 추가한다.
- 감지할 사실: 실제 조우·명시 수락·첫 소유자 하나. 기록 조우와 실제 조우를 구별한다.
- 대체: 이동 연출이 없으면 현재 위치에서 숲 방향을 바라보는 짧은 관찰문을 제공한다. 실제 개체를 만날 수 없으면 이미 존재가 확인된 흔적만 조사하고, 그런 흔적도 없으면 현재 길만 확인하며 만남을 보류한다.
- 배포 전 확정: 단일 배우 이동·대화 청중·동시 수락 처리. 이들은 미확인 구현 항목이다.
- 검사: C15 전 실제 조건 충족 시 일반 인사·현재 SIDE 가능 / 초반 인사만으로 신호·실종 동료 증거·MAIN 없음 / C15 뒤 실제 자료·준비 충족 후 두 수락 중 소유자 1명 / 기존 조기 만남을 재회로 기억 / 달기·타마모노마에·구미호에 같은 소유 상태 적용 / 일반 여우에게 대화해 MAIN 수락 불가.

## FOX M01 발자국보다 먼저 가는 불

### 시작과 현장 배치

첫 유효 MAIN 소유자와 실제 여우신이 쉼터에서 숲 옛길 추적을 시작한다. C15 뒤 공개 전쟁 조사를 실제로 확인하고 이번 불씨 접점을 발견한 후의 개인 이야기다. 그녀에게 이미 있던 기다림의 기억과, 이제 추적 가능한 신호를 얻었다는 현재 증거를 구분한다. 초반에 인사한 플레이어도 실제로 듣지 않은 기다림의 사연을 알고 있던 것으로 처리하지 않는다. C15는 이 자료 연결의 조건이고 여우신 일반 조우의 조건이 아니며 T03 완료는 필요 없다. 실제 나무 세 그루, 낙엽 흔적 두 곳, 물가로 이어지는 발자국 한 줄을 가까운 기존 숲길에 배치하는 실행안이다. 사적인 첫 추적이 이미 끝난 세계에서는 다른 플레이어에게 동일 과거를 재연하지 않는다.

### 순서가 있는 행동

1. 소유자는 입구의 굽은 나무를 기준점으로 살피고 본인이 돌아올 방향을 표시한다. 개인 소유 나무를 베거나 집 앞에 표식을 강제 설치하지 않는다.
2. 앞의 불빛을 따라 첫 나무 뒤로 걸어간다. 다시 같은 굽은 나무가 보이는 실제 짧은 고리 동선으로 돌아옴을 확인한다. 이동을 순간이동시키거나 실제 무한 미로를 생성하지 않는다.
3. 반복된 나무 아래 낙엽 두 곳을 내려다보고 그을음이 물가 쪽으로 이어진다는 관찰문을 얻는다. 불씨의 화재 연출이 플레이어 건축물을 태우지 않는다.
4. 물가의 발자국 시작점과 마지막 점을 차례로 밟아 실제 방향을 잡는다. 맨손 조사로도 가능하며 추적 스탯·직업 판정은 없다.
5. 여우신이 반대편으로 움직인 뒤 불빛만 그녀를 따라가고 발자국은 움직이지 않는 것을 기준점에서 비교한다. 플레이어가 먼저 말하면 이미 확인한 근거를 인정한다.
6. 움직이지 않은 발자국을 따라 물가 끝 지점에 도달하고 빛의 리듬을 관찰한다. 짧게 둘·길게 하나라는 패턴은 이번 실행안이다. 소리 없이 관찰문에도 표기한다.
7. 소유자가 불빛의 이동과 발자국의 방향을 구분한 기록을 확인한다. 실제 도착·두 흔적 확인·리듬 관찰이 완료 증거이며 정답 문장만 외워 말해서 완료되지 않는다.

### 선택과 대화

주 동선은 같은 발견에 도달하지만 먼저 눈에 띈 단서를 고를 수 있다. 그을음을 먼저 보면 가까운 땅을 읽고, 둔덕에서 옛길 고리를 먼저 보면 동선을 비교한다. 둘 다 같은 물가로 이어져 이미 한 답사를 강제로 반복하지 않는다. 공유 분기 없이 개인 조사 순서만 달라진다. 지금 돌아가면 관찰 항목만 남고 M01은 현장 완료 지점 전까지 보류다.

여우신은 천군의 귀환 신호를 기억한다. 이번 불빛이 그 신호와 닮았다는 것은 믿음과 대조 결과이며 발신자·생존을 확정하는 사실이 아니다. 대사: “이 리듬은 기억나. 누가 지금까지 붙들고 있었는지는 아직 모르겠어.” 플레이어가 일찍 “빛이 당신을 따라와서 길이 꼬여”라고 말하면 “오래 살았다고 늘 먼저 보는 건 아니구나”라고 인정하고 불필요한 실패 순환을 생략한다. “그렇게 강한 신이 길치야?”에는 “오늘은 네 발자국이 더 믿음직하네”라고 답하되 실제 전투력 저하 설정으로 바꾸지 않는다. 누구를 기다리느냐는 질문에는 “돌아오기로 한 사람들이 있어. 지금 이름을 다 꺼내고 싶지는 않아”라고 공개 범위를 제한할 수 있다.

### 결과와 소유와 회복

개인 보상은 M02에 쓸 실제 옛길과 신호 패턴 기록이다. 귀환 신호를 고급 아이템으로 인벤토리에 지급하지 않는다. 외부 공개용 안전 지도에는 이동 가능한 길만 적고 사적 기다림 대사는 넣지 않는다. 소유자가 그 안전 지도 공유를 승인한 경우 친구도 이용할 수 있다. 이미 공개된 물리 길 자체를 소유자만 밟을 수 있게 막지 않는다.

도중 사망·이탈 때 발자국 조사와 현재 단계는 유지하고 정상 사망 규칙을 적용한다. 신호는 접속하지 않았다고 꺼지지 않는다. 다른 사람은 일반 적 정리·길 확인을 도울 수 있으나 소유자가 해야 할 현장 추적의 청중·완료 이력을 대신 얻지 못한다. 소유자가 없는 동안 여우신은 복제 대기 NPC가 되지 않고 자신의 현재 활동을 계속한다. 재개 시 실제 위치를 확인해 이어 간다.

재미는 빛을 쫓는 호기심이 발자국을 믿는 발견으로 바뀌는 것이다. 물가에서 리듬을 확인하면 마친다. 같은 숲 안에서 M02로 이어 갈 수 있고 보고만 하러 주점으로 돌아갈 필요가 없다.

## FOX M02 물에 비치지 않는 길

### 시작과 구도

M01 완료 뒤 같은 강가의 갈림길에서 시작한다. 이름 그대로 물에 비치지 않는 허공의 불빛과 물속에만 흔적이 남는 실제 안전 동선을 비교한다. 실제 반사 그래픽 자체가 퍼즐 정답을 자동 제공한다는 뜻은 아니다. “물에서 보이는 반사점”은 작성된 관측이며, 지원되지 않으면 강둑 표지의 관측문으로 똑같이 읽을 수 있다.

여우신 본체 한 명이 익숙한 발소리를 듣고 한 번 잘못된 쪽으로 향한다. 그 소리는 대화 가능한 동료·여우신 복제체가 아니다. M01 소유자의 개인 탐사와 친구의 일반 길 도움을 구분한다.

### 실제 탐사

1. 갈림길 입구에서 현재 건널목과 귀환 표식의 위치를 확인한다. 위험한 깊은 물에 먼저 빠져야 정보를 얻는 구조는 쓰지 않는다.
2. 낮은 강둑 경로를 택하면 물가의 반사점 두 곳을 순서대로 조사한다. 높은 둔덕 경로를 택하면 위에서 건널목 양끝과 음성이 향하는 막힌 수풀을 내려다본다. 두 경로는 같은 안전 건널목을 가리키며 한쪽만 조사해도 충분하다.
3. 발소리 쪽으로 움직이던 여우신에게 확인한 동선의 근거를 알린다. 아직 관찰하지 않은 소유자의 주장에는 먼저 살펴보자고 답한다. 실제 근거를 이미 찾았다면 그녀의 실수를 반복 연출하지 않는다.
4. 얕은 여울·기존 다리 중 실제 안전한 한 곳을 직접 건넌다. 필요한 경우 허가된 구간에 임시 발판 최대 3개를 놓는 시험안을 쓴다. 수영·특정 장비·공중 이동을 강제하지 않는다.
5. 맞은편 표식에서 뒤를 돌아 출발한 둔덕 또는 강둑이 보이는지 확인하고, 같은 안전 길로 귀환한다. 실제 왕복과 선택한 관측점 확인이 완료 증거다.
6. 돌아온 그녀의 “기다리던 소리 같아서 길을 잊었어”를 실제 청중만 듣는다. 기다리는 이를 묻거나 지금 묻지 않는 선택으로 대화를 마친다.

## FOX M03 불씨를 물고 달리는 밤

### 시작과 역할 분담

M02에서 확인한 안전 길 가까이의 기존 공터에서 신호가 모인다. 여우신은 불씨를 안정시키고 플레이어는 실제 적을 상대하거나 확인한 길로 빠져나간다. 강한 신이 약해져 구조를 기다리는 설정이 아니라 서로 다른 일을 맡는 장면이다. 실제 적 기본안은 스켈레톤 2마리·거미 2마리다. 적 수·공격력은 제작 시험값이며 최소 전투 인원을 강제하지 않는다.

불씨는 현재 한 신호 현상의 작성 상태다. 드롭 가능한 고유 아이템을 반드시 요구하지 않으며 커스텀 그릇·새 마법 도구를 이미 존재한다고 쓰지 않는다. 여우신이 붙잡고 있다는 관찰문과 한 표시 지점으로 표현할 수 있다.

### 실제 행동

1. 공터 가장자리에서 엄폐 두 곳과 M02 귀환길 입구를 실제로 확인한다. 전투를 시작하기 전에 전투·탈출 중 선택 비용과 방법을 보여 준다.
2. 전투안은 소유자가 여우신의 안정 작업 시작을 확인하고 엄폐 한 곳으로 이동해 적을 맞는다. 탈출안은 신호를 붙잡은 그녀와 함께 미리 확인한 귀환길로 움직이기 시작한다.
3. 전투안은 스켈레톤 사선을 나무·바위로 끊고 거미가 가까워질 때 실제로 처리한다. 도와주러 온 친구도 해당 일반 전투에 참전할 수 있다. 소유자가 모든 막타를 칠 필요는 없다.
4. 탈출안은 공터 출구·강 건널목·안전 둔덕의 세 실제 지점을 차례로 통과한다. 추격자를 피하거나 필요한 만큼만 맞서며 세 지점 사이 이동을 직접 수행한다. 탈출 판정은 마지막 구간에서 적의 실제 추적이 끝났는지 확인하거나 안전한 차단 상태를 적용한 뒤 한다.
5. 전투안은 해당 시도 적이 정리된 뒤 공터의 불씨 지점으로 돌아온다. 탈출안은 안전 둔덕에서 여우신과 현재 불씨 상태를 확인한다. 둘 다 흩어진 신호가 작은 불씨 하나로 안정되었다는 실제 이야기 적용을 확인한다.
6. 소유자가 현재 불씨를 살피고 여우신의 반응을 듣는다. “아직 따뜻해”라는 말은 신호 상태에 대한 말이며 발신자의 생존 증명은 아니다. 작은 불씨 안정과 해당 경로의 실행 증거가 완료 조건이다.

### 여우신의 말과 지식

그녀는 불씨를 잡는 현재 감각과 자신이 기억하는 신호를 안다. 적이 왜 이끌렸는지는 현장 반응으로 추정하며 천마의 현재 명령이라 단정하지 않는다. “그냥 네 힘으로 다 없애면?”에는 “여기서 이걸 놓으면 흩어져. 저쪽을 맡을지, 함께 나갈지 정해 줘”라고 자신이 맡은 일을 설명한다. “우리끼리 간식 먹고 있어도 돼?”라는 농담에는 “나무 뒤라면. 화살 오는 쪽은 피하고”라고 짧게 받되 조작을 잠그는 긴 대화를 시작하지 않는다. “따뜻하면 살아 있다는 뜻이지?”에는 신호와 사람을 구분해 답한다. 급한 사람에게는 세 탈출 지점만 명확히 안내한다.

### 완료와 사망과 부재

소유자의 MAIN 완료는 실제로 본인이 수행한 방어·탈출 또는 동행 참여와 불씨 확인을 필요로 한다. 친구가 소유자 부재 중 일반 몹을 정리한 것은 유효한 전투 도움이나 개인 MAIN을 대신 끝낸 것은 아니다. 소유자가 접속 종료하면 여우신의 현재 신호 안정은 안전하게 보존하고, 잔여 적은 검증된 시도 정리 절차로 처리한다. 적 정리가 미지원이면 안전한 귀환 후 해당 시도를 중지하고 새 적을 겹치지 않는다.

소유자가 정상 사망했으면 사망 자체를 없애지 않는다. 신호 안정이 이미 검증되었다면 그 성과를 되돌리지 않고 생존 복귀 뒤 확인을 마친다. 미검증 상태면 다음 시도에서 남은 경로를 수행한다. 공용 성과와 개인 보상은 별도로 저장해 복구 때 중복 지급하지 않는다.

보상 기본안은 실제 방어·탈출 기여자에게 음식 4개, 최초 한 번이다. 자연 드롭은 실제 처치 규칙을 따르고 대사로 복사하지 않는다. MAIN 소유자는 M04 접점을 얻는다. 친구는 현재 전투 기여만 얻고 사적 고백 권리를 자동 획득하지 않는다.

재미는 앞의 관찰을 실제 싸움과 탈출의 방향 선택에 쓰는 것이다. 적 정리 또는 실제 탈출 뒤 불씨가 하나 남으면 충분하다. 짧은 휴식을 같은 길의 마당·강둑에서 이어 간다.

### 제작과 인수 검사

- 필요 자산: 공터 엄폐 2곳, 실제 적, 탈출 지점 3곳, 작은 불씨 전후 표시, 단일 여우신의 안정 작업 표현.
- 감지할 사실: 해당 시도 적 정리 또는 실제 세 지점 이동·추적 종료, 작은 불씨 안정, 소유자와 도움 참가자 구분.
- 대체: 적 자동 추격 제어가 없으면 기존 시야 차단과 안전 구간으로 이동한 뒤 잔존 적 상태를 확인한다. 안정 연출 미지원 시 전후 관측문을 쓴다. 실제 탈출의 안전성을 확인하지 못하면 성공이라 쓰지 않는다.
- 배포 전 확정: 배우 이동 가능 여부, 시도별 적 정리·추적 종료 검사, 도움 기여 기록과 MAIN 단계 저장의 분리.
- 검사: 친구 막타가 MAIN 소유권을 바꾸지 않음 / 탈출은 말 한마디로 완료 불가 / 신호 보존이 오프라인 요구 없음 / 사망 아이템 자동 복제 없음 / 두 경로 모두 M04로 이어짐.

## FOX M04 이름을 부르지 않고 기다리기

### 시작과 준비

M03의 작은 불씨가 안정된 뒤 기존 마당 또는 강둑 쉼터로 이어진다. 같은 여우신과 MAIN 소유자의 조용한 개인 장면이다. 동행 친구가 주변에 있다고 사적 대화 청중에 자동 포함하지 않는다. 소유자와 여우신이 함께 듣는 사람을 확인한 경우에만 그 사람에게 말한 범위가 전달된다. 비공개 대화 채널을 지원하지 않으면 공개 장소에서 비밀 고백을 출력하지 않고 청중을 통제할 수 있는 실제 방법이 준비될 때까지 대화 부분을 미룬다.

### 실제 행동과 대화 순서

1. 소유자는 공터에서 쉼터까지 확인된 길을 걸어 여우신의 현재 위치에서 재회한다. 바로 인접한 경우 불필요한 장거리 왕복을 추가하지 않는다.
2. 불씨 관찰점 옆에서 현재 빛이 일정하게 남아 있는지 확인한다. 안정된 작은 불씨를 인벤토리로 가져가려면 별도 허용과 실제 운반 자산이 필요하며 기본안에서는 현장 상태로 둔다.
3. 여우신과 안전 우회로가 보이는 쪽, 잔향이 남은 숲 쪽을 각각 바라본다. 한쪽은 신호 보존 뒤에도 쓸 길, 다른 쪽은 불씨를 풀었을 때 조용해질 범위라는 현재 두 용도를 설명한다.
4. 기다리는 사람을 묻기, 함께 신호 듣기, 오늘의 평범한 이야기를 하기 중 원하는 대화를 한다. 무응답 시간을 수치로 채워야 완료하는 묵념 퀘스트로 만들지 않는다.
5. 두 쓰임의 차이를 실제 현장 관찰문에서 확인한다. 소유자가 “신호는 남지만 숲 잔향도 남는다”, “숲은 조용해지지만 이 불씨의 귀환 단서는 사라진다”는 내용을 이해하고 질문을 마치면 M05 선택이 열린다. 지금 결정할 필요는 없다.

### 그녀가 말하는 범위

이 장면의 제안 배경은 천군이 그녀에게 누군가 돌아오기로 했던 자리이기도 하다는 것이다. 대사: “명령을 기다린 건 아니야. 저 길에서 익숙한 발소리가 들릴 줄 알았지.” 달기·타마모노마에·구미호의 기억은 한 사람에게 이어진다. 승인되지 않은 원전의 잔혹 행적이나 새 전쟁 승패를 고백으로 만들어 넣지 않는다.

확인된 것은 그녀가 실제로 기다렸고 지금 불씨를 놓기 어렵다는 자신의 경험이다. 이 장면의 불씨만으로 천마·루브라스·이름 없는 동료들의 현재 생사를 확정하지 못한다. 다만 이전의 실제 접촉이나 적법하게 전달받은 근거로 확인한 사실은 그 범위대로 기억한다. 이름을 말하지 않겠다는 것은 숨김이지 모름을 가장하는 답이 아니다. “누구를 기다려?”에는 “내가 아직 이름을 다 꺼낼 수는 없어. 돌아오겠다고 했던 이들이야”라고 거절할 수 있다. 먼저 들은 사적 이야기라면 같은 범위에서 기억하고 C20을 이유로 초기화하지 않는다.

“그냥 둘 다 하면?”에는 “지금 남은 불씨로는 신호를 붙들면서 이 숲에 전부 풀 수 없어”라고 이번 딜레마의 범위를 말한다. 모든 세계의 마법이 영원히 양립 불가능하다고 확대하지 않는다. “나도 오늘 약속을 잊었는데”라는 농담에는 일상 이야기를 나눌 수 있으나 플레이어의 실제 약속을 새로 지어내지 않는다. 서두르면 과거 이야기를 생략하고 두 현장 효과만 확인한 뒤 M05로 간다.

### 선택과 정보 공개

대화 주제는 개인 선택이며 정답·친밀도·연애 확정 버튼이 아니다. 그녀가 말하기를 거절해도 두 불씨 용도를 확인했다면 M04를 마칠 수 있다. 사적 기다림의 회상을 나중에 공개하려면 매 전달마다 소유자가 “어느 문장을 누구에게 어떤 목적으로” 보낼지 승인해야 하고 여우신의 공개 의사도 확인한다. 한 번 M04를 들었다는 것, 공용 회의에 참석한다는 것, MAIN 완료는 전면 공개 동의가 아니다.

완료 증거는 소유자의 현재 불씨·두 용도 확인과 실제 청중 기록이다. 보상은 M05의 충분히 설명된 선택권이다. 별도 장비·고백 수집 점수를 주지 않는다. 사망·접속 종료·대화 중단 뒤 이미 확인한 두 용도는 남으며 같은 고백을 다시 요구하지 않는다. 불씨에 만료 시간은 없다.

핵심 재미는 적을 상대하던 긴장 뒤 평범한 현재와 오래된 기다림 사이에 머무는 것이다. 두 효과를 이해했으면 충분하며 고백을 끝까지 들어야 진행하는 구조를 피한다.

- 필요 자산: 쉼터와 불씨 관찰점, 두 용도 비교문, 선택 주제 세 개의 짧은 응답, 실제 청중·공개 허용 범위 기록.
- 감지할 사실: 현장 효과 설명을 실제 받은 사람, 어떤 말이 누구에게 전달됐는지. 비밀 열람을 월드 전체 지식으로 저장하지 않는다.
- 대체: 음성·빛 미지원 시 불씨 관찰문과 짧은 텍스트 대화. 사적 청중 제어 미지원 시 사적 회상을 출력하지 않고 공개 가능한 용도 설명만 진행한다.
- 배포 전 확정: 대화 청중 범위, 이후 전달 때 승인 확인 경로, 불씨를 안정 보관할 실제 표시 방식.
- 검사: 고백 질문 거절 뒤 M05 가능 / 세 이름이 별개의 과거 MAIN을 만들지 않음 / C21 자동 사적 증언 없음 / 로그아웃 뒤 불씨·대화 지식 유지.

## FOX M05 한 불빛을 남길 곳

### 시작과 선택의 소유자

M04에서 두 용도를 확인한 MAIN 소유자가 실제 여우신과 불씨 앞에서 선택한다. 여우신도 자신의 신호를 어디에 쓸지 동의해야 한다. 소유자의 결정이 다른 플레이어 개인 물품·관계·의사까지 대신하지 않는다. 숲에 생길 공유 효과의 범위는 M02에서 확인한 이 숲길과 물가 잔향으로 한정하며 전 세계 환영 제거로 확대하지 않는다.

### 실제 실행

1. 불씨가 현재 안정되어 있고 이미 어떤 용도로 쓰이지 않았는지 확인한다. 후발 친구가 가져온 유사한 불빛을 원본 신호로 판정하지 않는다.
2. 소유자는 보존·숲에 풀기·유예 중 고른다. 앞선 설명을 알고 대상과 결과를 분명히 요청했다면 같은 확인을 반복하지 않는다. 농담·침묵·소유자 부재에는 아무 결말도 실행하지 않는다.
3. 보존을 확정하면 여우신이 동의한 현재 쉼터의 신호 자리로 함께 걸어가 불씨를 고정하는 작업을 진행한다. 플레이어는 그 자리에서 M01 리듬이 계속 읽히는지 확인하고 M02 우회로 입구까지 걸어 잔향이 남은 구간을 표시한다.
4. 숲에 풀기를 확정하면 여우신과 숲 입구·물가의 두 분산 지점으로 이동한다. 첫 지점에서 불씨를 풀고 다음 지점에서 잔향 감소를 확인한다. 효과 적용을 확인하기 전에는 단서가 사라졌다고 완료하지 않는다. 이어 기존 건널목을 걸어 더 이상 잘못된 방향 유도가 발생하지 않는지 관찰한다.
5. 보존안은 남은 신호와 안전 우회로, 풀기안은 사라진 이 불씨의 신호와 조용해진 지정 구간을 함께 확인해 마친다. 유예안은 현재 상태가 안정됨을 확인하고 떠난다. 유예에는 매일 접속·재료 공급·재서명 의무가 없다.

### 분기와 결과

| 선택 | 명시 확인할 비용 | 실제 공유 변화와 개인 후일담 | 남는 미완료 |
|---|---|---|---|
| 귀환 신호로 보존 | 이 불씨의 추적 단서를 남기며 지정 숲의 일부 잔향 유지 | 신호 자리 유지, 우회로 사용, 함께 불빛을 바라보는 밤 | 동료 귀환·생존·봉인 해제는 미확인 |
| 숲길에 풀기 | 이 불씨의 귀환 단서를 소모, 같은 불씨로 되돌릴 수 없음 | 지정 길의 잔향 제거, 플레이어의 실제 발소리를 따라 조용히 걷는 후일담 | 다른 귀환 단서는 새로 찾아야 함 |
| 결정 유예 | 결말을 아직 고르지 않음 | 현재 작은 불씨 안전 보관, 다른 활동 계속 | M05 최종 분기 미확정 |

보존과 풀기는 이 불씨에 대한 한 번의 결말이다. 시간이 지났다고 반대 효과를 추가 지급하거나 두 효과를 동시에 지속시키지 않는다. 후속 이야기가 별도 채택되기 전에는 이미 소모한 신호를 다시 주워 양쪽 보상을 얻지 못한다. 유예는 실패도 제3의 무료 양립 결말도 아니다.

### 대화와 정보

보존 뒤 그녀는 “길이 남았으니 더 찾아보겠어. 오늘 네가 걸은 길도 기억할게”라고 말한다. 풀기 뒤에는 “조용하네. 조금 허전하고… 이제 네 발소리가 잘 들려”라고 말할 수 있다. 상실감은 천군 탈퇴·플레이어 자동 적대를 뜻하지 않는다. 이 M05 선택만으로 초월급 도달까지 충족됐다고 보지 않으며, 관계 보상은 아래 두 조건을 함께 따른다. 유예에는 “여기서 꺼지지는 않아. 오늘은 돌아가도 돼”라고 안전 상태를 확인한다.

“천마를 부를 수 있지?”에는 “이 신호가 그분에게 닿는다는 근거는 없어”라고 답한다. “루브라스의 열쇠로 쓰자”에는 용의 실제 봉인과 다른 현상임을 밝힌다. “그럼 기다린 사람은 죽었네”라는 추론에는 어떤 선택도 생사를 증명하지 않음을 분명히 한다. “둘 다 됐다고 해 주면 안 돼?”에는 “그렇게 말한다고 이 불씨가 둘이 되진 않아”라고 받아도 실행 결과를 바꾸지 않는다.

### 과거 퀘스트의 완료와 관계 보상

M01–M04를 거친 기존 MAIN 소유자가 두 효과를 이해하고, 여우신과 동의한 M05의 보존 또는 풀기 중 하나를 실제로 실행한 뒤 그 결과를 확인하면 이 과거 퀘스트는 완료된다. 두 결말은 같은 자격으로 인정하며, 실종자의 생사·귀환을 알아내거나 그녀의 모든 비밀을 들을 필요는 없다. 유예는 현재 성과를 보존하지만 과거 퀘스트 완료는 아니다.

과거 퀘스트 완료와 여우신 본인의 초월급 도달은 서로 독립된 조건이다. 어느 쪽이 먼저 이루어져도 되며, 플레이어가 초월급 힘에 도달해야 한다는 뜻이 아니다. 두 조건이 모두 성립하면 기존 MAIN 소유자에게 관계 보상이 성립하고, 여우신은 그 플레이어를 다음 실제 만남에서 ‘서방님’이라 부르며 매우 우호적인 상태가 된다. 오프라인 중 대사를 이미 나눴다고 쓰거나, 부재 중인 소유자를 대신해 친구에게 호칭을 주지 않는다. 만남은 이 보상을 실제로 표현하는 자리이며 새 성향 시험이나 추가 퀘스트를 요구하지 않는다.

그 친근함은 무조건 복종·모든 비밀 공개·영구 동행·천군 이탈을 뜻하지 않는다. 그녀는 자기 목적과 사생활을 지키고 개별 부탁을 거절할 수 있다. 오래 기다리던 이와 지금의 플레이어를 동일인이나 연인의 환생으로 확정하지 않는다.

그녀가 이미 초월급이라면 M05를 완료해 두 조건을 갖추고, 과거 퀘스트를 먼저 마쳤다면 그 결말을 다시 선택하지 않은 채 그녀의 실제 성장을 기다린다. 성장이나 관계 보상 때문에 불씨의 보존·소모 결과를 되돌리지 않는다. 기존 M01–M05의 소유권·순서·현재 진행을 유지하고, C 사건과 엔딩에 새 선행을 붙이지 않는다.

### 보상과 복구와 늦은 참가

소유자는 실제 선택의 개인 후일담과 현재 관계를 얻는다. 모든 참가자에게 고유 불씨를 복제 지급하지 않는다. 길 정비에 직접 참여한 친구는 현장 기여 기록을 얻으며 일반 장비 보상은 기본안에 없다. 세계가 얻는 이동 편의와 소유자의 사적인 의미를 구분한다.

소유자가 없어도 다른 플레이어는 현재 안전 우회로와 SIDE를 이용한다. 소유자를 대신해 불씨를 태우거나 MAIN 결말을 선택하지 않는다. 공유 코어는 정상 진행된다. 소유자가 실행 중 사망·접속 종료하면 이미 적용한 단계와 남은 확인을 분리한다. 풀기 효과가 실제 적용되었다면 반대 결말로 바꾸지 않고 복귀 뒤 관찰을 마친다. 아직 실행 전이라면 확정 여부·현장 상태를 확인한 뒤 이어 간다. 불확실한 중간 상태는 불씨 중복 생성으로 고치지 않는다.

C21에는 현재 공개 가능한 천군 의견만, C22에는 실제 확보·공유된 길만, C28에는 실제 보존·소모·유예 상태만 전달한다. 사적 회상 인용은 각 전달의 정확한 내용·청중에 대한 소유자 승인과 여우신 의사를 확인한다. 승인 없는 경우 “이 구간은 지금 안전하다”는 현장 사실과 공개 가능한 독립 의견만 사용한다.

핵심 재미는 앞선 추적·전투가 남긴 하나를 어디에 쓸지 직접 정하는 것이다. 선택 효과와 걸어서 돌아올 길까지 확인하면 충분하다. 유예한 사람에게 결론을 재촉하는 반복 알림은 넣지 않는다.

## FOX SIDE 오늘의 산책길

### 시작과 목적

실제 여우신을 만난 MAIN 비소유자에게 제안한다. C15 전이라도 현재 배우와 이 세계의 짧은 산책길이 실제로 접근 가능하고 그녀가 동행에 동의하면 할 수 있다. MAIN 소유자가 없어도 가능하며, 신호를 못 찾은 초반에는 오늘의 풍경과 현재 관계만 다룬다. 첫 만남을 하지 않았으면 인사와 이름·소속을 실제로 듣고 시작한다. 사적 MAIN 줄거리를 축약 복제하거나 첫 불씨 발견의 공동 주인으로 만드는 대체 이야기가 아니다.

### 현재의 행동

1. 여우신에게 오늘 실제로 걸을 수 있는 강둑과 숲길 가운데 한 곳을 제안한다. 그녀가 지금 동행할 수 없으면 현재 길 조사만 해 두고 나중에 만나며 허구 동행을 기록하지 않는다.
2. 선택한 길의 입구에서 지금 실제로 보이는 지형·표식을 살핀다. 불씨 미발견 상태에서는 일반 산책으로 이미 확인한 안전한 길만 쓰고 M01·M02의 신호·반사점·귀환 증거를 생성하지 않는다. 불씨 발견 뒤 M05 보존 또는 진행 중이면 실제 공개된 안전 우회로를, 숲에 풀기 완료면 실제 조용해진 길을 쓴다. MAIN 자료가 공개되지 않았으면 별도의 현재 산책길을 택한다. 어느 상태라도 MAIN 단계 재연은 없다.
3. 길을 따라 실제 관찰점 두 곳을 걷는다. 평범한 여우가 실제로 있으면 멀리서 관찰할 수 있고, 없으면 강의 흐름·낙엽·사람의 발자국을 보는 대체를 쓴다. 여우 스폰·포획·사냥을 완료 조건으로 삼지 않는다.
4. 돌아오는 갈림길에서 오늘 선택한 길을 표시하고 동행을 마친다. 실제 왕복·두 관찰점·만난 배우가 완료 증거다.

### 선택과 말과 결과

강둑은 물과 건널목을, 숲길은 나무와 현재 표식을 보는 취향 선택이다. 개인의 오늘 산책이며 타인의 MAIN 선택을 변경하지 않는다. 공유 지도에 새 위험이나 안전한 길을 적으려면 실제 관찰한 내용만 전달한다. 다른 사람 집·물건·사적 대화는 지도 재료가 아니다.

그녀는 오늘 걸은 사람을 오늘의 동행으로 기억한다. 실제 불씨 소식을 들은 뒤 “그 불씨 이야기 나한테도 처음부터 해 줘”라고 물으면 “오늘 네가 걸은 길부터 이야기하자. 다른 사람과 나눈 말도 있으니까”라고 답하고 공개 허락 없는 고백을 꺼내지 않는다. 불씨가 아직 발견되지 않은 초반에는 그 소식을 스스로 꺼내거나 미래의 MAIN 동행자를 이미 만난 것처럼 말하지 않는다. “저 여우도 당신이야?”에는 “저 아이는 저 아이야. 좀 떨어져서 보자”라고 분리한다. “빨리 한 바퀴만”에는 가까운 두 관찰점을 택한다. 거절하면 관계 페널티나 숨은 MAIN 자격 상실이 없다.

보상은 개인 산책 기록과 실제로 들은 공개 대화이며 고유 불씨·첫 발견 칭호·M05 결정권이 없다. 오늘의 친근한 동행은 유효하지만 과거 퀘스트 완료나 소유자 한 명의 ‘서방님’ 호칭 보상을 공유하는 것으로 쓰지 않는다. 반복 산책은 가능하지만 같은 최초 보상·과거 고백은 반복 지급하지 않는다. 소유자의 허락 없이 사적 MAIN을 들은 것으로 만들지 않는다.

사망·로그아웃 때 실제 걸은 부분은 남지만 완료 왕복은 남은 부분을 수행해야 한다. 여우신이 다른 일을 위해 떠났으면 현재 위치에서 재회한 뒤 이어 간다. 다른 플레이어의 다음 산책을 위해 본체를 복제하거나 강제로 묶어 두지 않는다.

이번 재미는 세계사의 증거 수집에서 벗어나 지금 함께 걷는 사람을 알아가는 데 있다. 두 관찰점과 복귀로면 충분하다.

- 필요 자산: 현재 상태에 맞는 짧은 기존 경로 2개, 관찰점 각 2개, MAIN과 분리된 개인 SIDE 이력.
- 감지할 사실: 현재 동행·실제 이동·본인에게 한 말. 친구의 MAIN 기여를 승계하지 않는다.
- 대체: 야생 여우가 없으면 환경 관찰, NPC 자동 동행 미지원 시 실제 이동 가능한 두 장소에서 같은 본체와 재회한다. 이동 여부 미검증 상태를 동행 성공으로 쓰지 않는다.
- 배포 전 확정: 단일 배우의 일정 충돌 처리, 반복 SIDE 보상 유무, M05 현행 길 상태 읽기.

## LUB01 봉인된 붉은 전장

### 시작과 나타나지 않는 본체

첫 용 토벌 전에는 현재 생활권의 동굴 탐사나 공개된 위치 안내를 통해 로컬 봉인 현장을 찾는다. 바깥층·안쪽층·귀환 안전선과 현장 점검 기록의 첫 층 작업 범위를 확인하는 초반 경로다. C12 이후 지하 탐사 또는 C15 주변에서는 같은 현장의 전쟁 기록을 더 조사한다. C12에서 이미 읽은 공개 조사로도 위치를 알 수 있으며 C15를 다시 완료할 필요가 없다. 초기 로컬 자료는 C12 심층 조사·C13 범행 증거·C17 네더 계약을 포함하지 않는다. 위치는 현재 Minecraft 세계의 기존 동굴 안전 옆길 또는 발견된 폐허 벽면으로 정한다. 흔적을 찾아 신화 전쟁의 고향 차원으로 넘어가지는 않는다. 유리 같은 광택은 지형 재질 또는 관찰문으로 표현하며 귀중한 새 광석·자동 채굴 보상으로 만들지 않는다.

기본 출연 방식은 흔적과 기록이다. 완전 봉인 상태의 루브라스 본체·축소 분신·자유 대화 아바타를 놓지 않는다. 초반 첫 1겹 작업의 설명·안전 확인·동의 또는 거절에 한해 봉인석 바로 곁에서 짧은 현장 응답을 받는 경로를 둔다. 이 응답은 한 실제 존재에게서 온 것이며 일반 조우·본체 이동·개인 MAIN 수락이 아니다.

### 실제 탐사와 완료 증거

1. 동굴 입구에서 기존 귀환 표식과 안전한 조사면을 확인한다. C12의 조각 회수 공간을 새 필수 전투장으로 바꾸지 않는다.
2. 평범한 암반과 유리처럼 변한 암반 두 지점을 차례로 살핀다. 후자에만 넓은 열의 방향과 겹친 구속 문양이 남았다는 관찰문을 얻는다.
3. 초반에는 현장 점검 기록에서 바깥층의 조작 범위·안쪽층 보존·귀환 안전선만 읽는다. C12 뒤에는 폐허의 전쟁 기록 한 면을 현장에서 더 읽는다. “천군 군단장 루브라스의 구속을 여러 층으로 분리했다”는 문구를 작성 제안으로 둔다. 기록은 전후 봉인 점검 담당자의 첫 점검 기록, 마지막 줄이 결락된 한 면으로 제안하며 작성 주체·시점·손상 범위를 함께 적는다. 이름 없는 기록 작성자를 새 필수 NPC로 만들지 않는다. 기록 작성자가 본 것을 넘는 천마의 전후 운명은 기재하지 않는다.
4. 구속 문양의 바깥 테두리와 안쪽 겹침을 서로 다른 지점에서 관찰한다. 문양 모양만으로 층 수 전체·해제 방법·현재 전력이 판명되지 않음을 확인한다.
5. 실제 근거리 접촉 조건이 맞으면 봉인석 바로 곁의 안전한 지점에서 인사한다. 초반에는 첫 층 작업 범위와 안전에 관한 질문 하나에 답 또는 거절을 받는다. 전쟁 정보에 관한 자유 면담은 하지 않는다. 멀리서 귓속말·전 세계 통신을 계속할 수 없다.
6. 현장 조사표에 흔적·기록 주장·실제 응답을 나눠 적고 귀환 표식까지 나온다. 두 암반 비교·겹친 문양 확인·기록 출처 확인이 기본 완료 증거다. 목소리를 들어야 완료하는 조건은 없다.

### 선택과 답변의 한계

| 선택 | 범위와 확인 | 결과 |
|---|---|---|
| 흔적만 조사 | 읽기·관찰, 봉인 변경 없음 | 다중 봉인 조사 근거, 실제 위치 |
| 제한 접촉 시도 | 근거리 작업 확인 범위를 안내하고 참가자가 동의 | 실제 응답 또는 침묵, 그 청중만의 지식 |
| 철수 | 조사 중단 | 확인한 자료 보존, 봉인 손상·적대 없음 |

루브라스가 제한 접촉으로 말할 수 있다면 “네가 본 것은 나를 묶은 흔적이다. 내 전부는 아니다”라고 한다. 자신의 이름·패배·봉인을 아는 것은 당사자 지식이다. 현장 밖 플레이어 행적은 전달받지 않으면 모른다. 천마의 패전 후 봉인은 작가 기준 확정 사실이지만 루브라스가 현재 위치·봉인 세부를 실제로 아는지는 별도 근거가 필요하다. 그와의 신뢰는 확정이지만 지금의 위치까지 알고 있다는 뜻은 아니다.

“누가 당신을 혼자 이겼지?”에는 확인한 전쟁 패배와 일대일 승패가 다르다는 범위에서 답하거나 “그 질문의 전제를 받아들이지 않겠다”라고 거절한다. “거짓말 못 하니 묻는 건 다 답해”에는 “거짓을 말하지 않는 것과 네게 모든 말을 주는 것은 다르다.”라고 답한다. “그러면 내가 제일 강하다고 해 봐”라는 농담에는 근거 없이 긍정하지 않는다. 급한 사람에게는 봉인 변경 없는 조사 완료만 안내한다.

기록만 있는 경로에서는 이 질문에 루브라스의 즉석 답을 제공하지 않는다. 관리 주민이 있다면 기록에서 확인한 것만 설명하고 당사자 지식을 대신 말하지 않는다. 목소리 출처가 실제로 검증되지 않았다면 ‘루브라스 응답 확정’이 아니라 아직 식별하지 못한 현장 반응으로 남긴다.

### 결과와 회복과 호흡

보상은 실제 조사 위치·다중 봉인 증거와 다음 선택 조사 접점이다. 조각 원본·해방권·드래곤 로드의 계약·MAIN 소유권을 주지 않는다. 공개 조사표를 읽은 후발자는 자료를 알 수 있고 개인 관찰을 더할 수 있지만 최초 응답 청중이 되지는 않는다. 접촉 내용을 다른 사람에게 전달하면 전달자가 실제 들은 범위와 출처를 적는다.

일반 사망·철수·로그아웃은 봉인을 약화시키지 않는다. 확인한 지점은 보존하고 남은 조사만 이어 간다. 이후 이미 한 겹 열린 세계에서 처음 온 사람에게 “완전 봉인 중 첫 목소리”를 재연하지 않고 현재 잔여 봉인과 공개된 변화 기록을 안내한다. 같은 흔적에 인원수만큼 루브라스 개체를 만들지 않는다.

재미는 거대한 존재를 싸움이나 본체 크기 과시보다 땅과 말의 제한으로 느끼는 것이다. 관찰 세 종류를 구분했으면 충분하다. 초반에도 원하면 같은 현장에서 LUB02의 첫 층 작업을 선택할 수 있다. C12·C17 후기 조사 안내는 별도로 남기며 강제 해방 퀘스트를 주지 않는다.

### 제작과 인수 검사

- 필요 자산: 기존 동굴 두 암반 지점, 겹친 문양 관찰면, 출처를 쓴 전쟁 기록 1면, 선택적 근거리 접촉점.
- 감지할 사실: 실제 봉인 상태·기록 출처·관찰자·응답 출처와 청중. 작가가 아는 진실을 관찰문만으로 모두 공개하지 않는다.
- 대체: 재질·열기 연출이 없으면 현장 조사문. 근거리 접촉을 구현하지 못하면 기록 조사만으로 완료할 수 있으나, 첫 층 해제와 일반 만남 경로까지 구현된 것으로 검수하지 않는다.
- 배포 전 확정: 현장 좌표와 채굴 손상 방지 범위, 초반 작업 확인용 제한 접촉의 거리·응답 가능한 사실. 구체 봉인 층 수는 이후 필요한 범위만 정한다.
- 검사: 완전 봉인 상태에서 일반 조우 없음 / 기록만으로 완료 가능 / 음성을 들었다고 본체·MAIN 생성 없음 / 작가가 아는 천마의 봉인 상태·현재 위치를 개인에게 자동 공개하지 않음 / 제우스와의 일대일 패배를 새로 확정하지 않음.

## LUB02 한 겹을 풀어도 남는 것

### 시작과 별개 장치

초반에는 현재 생활권의 로컬 봉인 위치·첫 외곽층과 잔여층·안전선을 실제로 확인하면 첫 1겹 작업을 선택할 수 있다. C02 등의 개인 완료 도장이나 첫 용 토벌·C12·C17 완료는 이 초기 경로의 선행이 아니다. 실제 접근로와 로컬 작업 근거·안전·당사자 동의를 확인한다. C17 이후에는 네더 구속 구조를 조사한 경험을 바탕으로 같은 봉인 위치를 다시 살핀다. 초반에 열지 않았다면 첫 층 작업을 이때 선택할 수 있고, 이미 열었다면 잔여 봉인 조사로 이어져 첫 해제와 보상을 반복하지 않는다. 심층 해제와 전쟁·네더 협력에 관한 정식 계약은 각각 필요한 실제 자료·봉인 상태·당사자 동의 조건을 유지하며, 첫 층 작업에 동의했다는 이유로 자동 성립하지 않는다. C17은 해당 통행 장치와 전쟁 자료를 다루는 캠페인 접점이며, 모든 개인적 약속·보은·주시·가호·SIDE의 개방 시점을 뜻하지 않는다. 정식 계약에 필요한 정보가 다른 유효한 경로로 이미 확보되었다면 실제 근거를 검토하고, 장 번호만으로 그 사실을 부정하지 않는다. 아직 확보하지 않은 심층 해제 수단이나 계약 동의는 추정하지 않는다. C17의 구속 장치 제거·제5조각 회수와 루브라스 해제는 별개다. LUB01을 하지 않았어도 현재 공개된 봉인 위치와 현장 기록을 보고 조사할 수 있다. 흔적을 먼저 확인하는 실제 과정은 필요하나 별도 완료 배지를 추가 선행으로 만들지 않는다.

이번 실행 제안에서 선택 해제 대상은 루브라스 봉인의 ‘외곽 이동 제한층’ 한 겹이다. 첫 1겹을 실제로 풀어 초반 일반 만남을 여는 방향은 확정이며, 이 명칭과 조작 구조는 실행 세부안이다. 안쪽 힘의 구속과 다른 층은 건드리지 않는다. 제작 시 해당 층의 실제 범위와 안전한 조작점을 확인하지 못하면 조사·유지·보류만 배치한다. 단순한 C17 버튼이나 조각을 대는 것으로 해제하지 않는다.

### 실제 조사와 해제 작업

1. 초반에는 로컬 점검 기록과 실제 문양을 대조해 첫 외곽층만 작업 대상임을 확인한다. C17 뒤에는 그때 얻은 기록으로 통행 장치와 이 봉인의 대상·연결을 비교하고, C17의 어느 결말도 이 층을 자동 변경하지 않았음을 확인한다. C17 자료를 초반 조사표에 미리 넣지 않는다.
2. 봉인석 외곽의 세 조사면을 돌며 바깥층·안쪽층·귀환 안전선의 역할을 읽는다. 실행안은 바깥층이 작은 이동 범위만 제한하고 안쪽층이 계속 남는 구조다. 바깥 표식을 채굴하면 전체 봉인이 부서지는 바닐라 법칙처럼 설명하지 않는다.
3. 현재 가능한 제한 접촉 또는 이미 한 층 열린 상태의 실제 조우를 통해 루브라스에게 조사 결과를 전한다. 접촉 자체가 없으면 그의 동의가 필요한 해제 작업은 지금 성립하지 않으며 조사로 마친다.
4. 해제 제안의 대상·허용 범위·남는 봉인·예상 위험·중단 조건을 설명하고 그의 동의를 구한다. 초반 작업 약속은 “이 층 작업 중 조사 안전선 밖으로 힘을 뻗지 않으며, 플레이어는 합의한 외곽층만 조작한다”로 제한한다. 이는 이 로컬 작업의 동의이며 C17의 전쟁·네더 관련 정식 계약이 아니다. 그의 천군 지휘권이나 모든 용의 행동을 담보로 요구하지 않는다.
5. 봉인 유지, 조사만, 한 겹 해제 중 해당 공유 분기를 명시 확정한다. 한 겹 해제는 루브라스의 실제 동의와 유효한 현장 실행 계획을 함께 필요로 한다. 동의가 없으면 거절의 사실을 남기고 조사·유지를 선택할 수 있다.
6. 해제안은 첫 조사면에서 대상층과 내부층이 분리된 상태를 확인하고, 둘째 조작점에서 검증된 연결 분리 작업을 수행하며, 셋째 지점에서 잔여층 반응을 확인한다. 실제 연결 분리 기능이 없다면 이 단계를 성공 대사로 대신하지 않는다.
7. 바깥층만 해제되었음을 확인한 뒤 루브라스의 가능한 이동·발현 범위를 다시 점검한다. 세계와 접촉자 수용 조건도 맞을 때만 조건부 일반 조우를 연다. 초반 경로는 이 조건을 검증한 봉인 근처 안전 범위에서 한 실제 본체와 인사·현재 상태·약속과 신뢰를 이야기하는 제한 일반대화로 이어진다. 첫 층 해제의 즉시 일괄 보상으로 강한 가호·첫 용 전력 지원·MAIN 소유권이나 우선권을 지급하지 않는다. 플레이어 대신 보스를 토벌하지 않는다. 이는 초반 전체의 관계 성장이나 후원을 금지하는 규칙이 아니다. 해제 이후 실제 은혜와 교류에 따라 주시·별도 의뢰·위기 지원·가호·장비의 개별 가능성을 판단하며, 현재 봉인·세계 창구·수혜자 수용 한계·루브라스의 의사와 각 획득 조건을 적용한다. MAIN이 미수주·미완료여도 허용된 관계는 이어질 수 있으나, 같은 인사 반복이나 시간 경과만으로 후원을 보장하지 않는다. 구체 효과와 보상은 자료 확인 전 확정하지 않는다. 실제 조우가 아직 불가능하면 ‘한 겹 해제, 일반 조우 아직 불가’로 남기고 미구현 항목을 수정하며, 초반 만남 경로 완성으로 검수하지 않는다.
8. 유지안은 해당층을 그대로 둔 안전 상태와 조사 경계를 확인하고, 조사만 선택은 관찰 자료를 남긴다. 어느 경로든 결과가 남은 세 지점 중 출구에서 현재 상태를 한 번 확인하고 마친다.

봉인 유지 결론을 내렸다고 모든 미래 해제 논의를 영구 금지하지 않는다. 나중에 여건이 달라지면 새 정보와 새 동의로 재검토할 수 있으나 최초 보상은 반복하지 않는다. 이미 열린 한 겹을 새 방문자마다 다시 여는 업적도 없다. 해제 직후 다른 한 겹을 연속 무료로 여는 선택은 제공하지 않는다.

계약은 약속한 행동·범위·당사자만 묶는다. 플레이어 다른 친구의 영혼·장비·생명, 천군 전원·모든 용·천마의 선택을 담보로 삼지 않는다. 타인의 약속을 최초 선택자가 대신 서명하지 않는다. 한 겹 해제와 향후 원정 참여 계약은 별개다. 오프라인 재료 납부·접속 의무·자동 처벌 기한을 넣지 않는다.

완전 봉인 중의 제한 접촉으로 진행한다면 조사와 조건 설명은 플레이어가 현장 기록으로 준비하고, 봉인석 바로 곁에서 그 한정 제안을 읽어 짧은 승인 또는 거절만 받는다. 긴 자유 면담을 이어 가거나 모든 질문을 소진할 때까지 통신하는 일반 조우로 바꾸지 않는다. 그 범위의 유효한 동의조차 받을 수 없으면 해제안을 보류한다.

### 루브라스의 정보와 반응

그는 자기 몸의 현재 제한과 자신이 동의한 약속을 안다. 모든 봉인 설계자의 비밀이나 플레이어가 가져오지 않은 C17 결과를 자동 알지 않는다. “한 겹이 열리면 무엇을 할 수 있나?”에는 현재 확인한 이동 범위와 남은 제한을 구체적으로 말하되 현장 시험 전의 예상은 예상이라고 구분한다.

“풀어 주면 평생 내 편이지?”에는 “너는 한 겹을 제안했다. 내 생 전체를 사겠다고 말하지 않았다.”라고 답한다. “천마가 더 강한데 왜 당신을 오른팔로 뒀어?”에는 “힘을 겨루는 것과 일을 맡기는 것은 같은 일이 아니다. 우리는 서로를 믿었다.”라고 확정 관계 범위에서 말할 수 있다. 현재 명령을 전달받았다는 뜻은 아니다. “작은 모습이면 생각보다 약하네”라는 농담에는 “지금 네가 보는 범위는 봉인이 허락한 범위다”라고 답한다. 해제를 거절하면 즉시 적대하거나 거짓 호의를 강요하지 않는다.

### 완료와 실패 복구

완료 증거는 조사면 3곳의 확인과 선택 결과다. 해제 경로에는 대상층 변경·잔여층 보존·루브라스 동의·현재 조우 조건 검증이 추가된다. 보상은 구체 조사 성과와 실제 관계이며 강력한 용 소환권을 지급하지 않는다. 첫 만남의 기본 대화는 자신이 겪은 봉인·현재 상태·직접 맺은 약속을 중심으로 한다. 만나기만 했다는 이유로 C13 범행 증거·천마의 현재 위치와 봉인 세부·후기 협력 확약을 자동 제공하지 않는다. 실제로 확인하거나 전달받은 사실과 출처가 있다면 장 번호가 이르다는 이유로 모르는 척하지 않는다. 알고 있는 사실, 받은 주장, 의심, 공개를 거절하는 내용을 구별하고 청중별 공개 자격을 지킨다. 증거를 전달받은 것만으로 그 모든 주장이 진실이 되거나 협력 계약을 수락한 것으로 처리하지 않는다. 기존 사건의 조각 원본·고유핵은 사용하거나 복제하지 않는다.

작업 전 접속 종료면 현 상태 유지다. 분리 작업 중 중단되면 검증된 안전 상태로 멈추고 마지막 확인된 지점부터 재개한다. 이미 실제 한 층이 열렸다면 사망·로그아웃으로 다시 닫거나 또 열어 보상을 만들지 않는다. 상태 불명확 시 새 해제 시도를 겹치지 않고 현장 검증만 한다. 정상 사망 손실은 그대로이며 봉인을 잘못 만졌다는 이유로 오프라인 다른 사람을 죽이지 않는다.

최초 선택자 부재 때 공유 조사와 안전 확인은 이어 갈 수 있다. 미체결 개인 계약을 상속하지 않으며 새로운 수행자는 자신의 수행 범위와 루브라스 동의를 확인한다. 후발자는 현재 남은 봉인과 공개된 작업 기록을 보고, 이미 일어난 해제에 동의했던 사람으로 기록되지 않는다.

재미는 강한 존재를 풀기만 하면 모든 문제가 해결된다는 기대를 정확한 한 겹·한 약속으로 좁히는 데 있다. 조사 결과와 현재 층 상태를 확인하면 충분하다. 더 깊은 해제는 이번 장면의 끝없는 추가 단계가 아니다.

## LUB03 용들의 존경과 서로 다른 선택

### 시작과 출연 조건

C21 전후에 루브라스의 현재 접촉이 가능하거나 실제로 확인된 의견 전달 경로가 있을 때 선택적으로 진행한다. C21 회의를 이미 마친 세계라면 보충 면담으로 두고 회의의 과거 찬반을 다시 쓰지 않는다. 모든 용의 회의장을 새로 짓지 않고 현재 봉인 근처 안전선 또는 이미 쓰는 회의 장소의 짧은 접점을 사용한다.

루브라스는 실제 가능한 본체 또는 허용된 근거리 제한 접촉으로만 말한다. 완전 봉인에 제한 접촉도 없으면 그에게서 새로운 의견을 얻을 수 없다. 실제로 받은 과거 의견이 있다면 내용·수신자·시점을 표시해 전달할 수 있으나 아직 발언하지 않은 것을 미리 기록으로 만들어 우회하지 않는다.

완전 봉인 중에 예외 접촉을 채택한 경우에는 봉인석 바로 곁에서 짧은 한정 응답만 받는다. 아래의 긴 면담과 여러 당사자의 대화는 실제 일반 조우가 가능한 상태에서만 진행하며, 한 번의 제한 반응을 자유로운 원격 회의로 늘리지 않는다.

그를 존경하면서 별도 선택을 하는 진짜 용 한 명은 기존 안에 남아 있는 **미승인 선택 배역 제안**이다. 이름·과거·개인 MAIN·새 주요 역할을 여기서 확정하지 않는다. 기본 실행은 루브라스와의 단독 면담만으로 완결한다. 별도 배역은 사용자 채택과 기존 명부의 실제 한 개체·접촉 가능성이 확인되기 전까지 아래 4번·그 용의 대사·제작 자산을 활성화하지 않는다. 루브라스의 반대편 의견을 내기 위해 강화 엔더드래곤·귀환룡·새 수호자를 진짜 용으로 대체하지 않는다.

### 실제 면담과 플레이어 행동

1. 플레이어는 현재 회의 문서 또는 준비안을 들고 실제 접촉 장소까지 간다. 전달할 범위는 원정 목적, 주민 통행, 원정 외곽의 한 구간에 필요한 도움으로 제한해 제시한다.
2. 여신의 은폐나 과거 저주 자료를 이야기하려면 실제로 전달 가능한 근거를 고른다. 공개된 문서를 가져와도 상대가 읽기 전에는 안다고 처리하지 않는다. 사적 고백·여우신 회상을 포함할 때는 필요한 당사자 허락과 각 전달 범위를 확인한다.
3. 루브라스가 읽거나 전달받은 항목을 확인한 뒤 그 범위에 대한 판단을 듣는다. 제공하지 않은 C20 개인 대화나 다른 신의 내면을 판결 근거로 넣지 않는다.
4. 선택 진짜 용의 실제 접견이 준비되었다면 같은 제안 중 당사자에게 관련된 항목만 전한다. 이 용은 “그분을 존경한다. 하지만 이번 원정 호위는 맡지 않겠다”라는 자기 선택을 할 수 있다. 이 답은 루브라스 모욕이나 종족 반란의 자동 증거가 아니다.
5. 제안된 실제 귀환 구간의 지도나 현장 조망을 함께 확인하고, 루브라스가 맡을 수 있는 범위·거절한 범위를 나눠 기록한다. 물리적으로 현장을 볼 수 없으면 지도를 받은 수준의 판단으로 남기고 현장 점검은 플레이어가 한다.
6. 공개 회의에 전할 정확한 의견 문구와 청중을 당사자에게 확인한 뒤, 플레이어가 해당 회의 또는 보충 기록에 실제 전달한다. 전달하지 않기로 해도 면담 자체는 완료 가능하며 공개 증언은 아직 없다.

루브라스는 천마에 대한 신뢰와 진짜 용 가운데 자기 위치를 안다. “당신이 제일 강하니 모든 용을 불러”에는 “존경을 명령으로 바꾸지 마라. 그들이 맡을 일은 그들도 정한다.”라고 답한다. “천마보다 당신이 낫지?”에는 강함의 확정 관계를 뒤집지 않는다. “그를 믿는 건 알겠어. 우리는 왜 믿어야 하지?”에는 자기가 제공할 수 있는 구체 약속을 제안하거나 답변을 보류할 수 있다. 천마의 현재 생존·연락 여부를 임의로 증명하지 않는다.

여신의 은폐 자료를 실제로 받았을 때 “말하지 않은 이유를 들을 수는 있다. 듣기 전부터 거짓이 없었다고 해 주지는 않겠다”라는 의견을 제안한다. 정당한 답변 거절과 거짓말을 동일시하지 않고 실제 표현·누락·결과를 검토한다. 플레이어가 사적으로 들은 자발적 인정도 유효하게 전달했다면 그 사실을 무시하지 않는다. 루브라스는 유일한 심판자·무오류 거짓 탐지기가 아니다.

선택 진짜 용은 자신의 존경·참가 의사·맡은 생활을 안다. 루브라스가 말한 적 없는 생각이나 모든 용의 입장을 대신하지 않는다. “용끼리 뜻 좀 맞춰 줘”라는 농담에는 “네 친구들이 늘 같은 길을 걷는가?”라고 물을 수 있으나 플레이어 관계를 임의 추측하지 않는다. 급한 사람에게는 요청 하나·응답 하나·전달 문구 하나로 면담을 마친다.

### 결과와 복구와 후발자

완료 증거는 실제 제공한 근거, 받은 의견, 전달 여부다. 공개 문서 자체가 읽히지 않았으면 ‘열람 가능’으로 두며 청중 지식에 넣지 않는다. 보상은 범위를 분명히 한 협력 후보와 자기 판단 자료다. 용 소환권·종족 지휘권·천마의 위임장을 지급하지 않는다.

거절해도 정식 선행을 충족한 C21 회의와 C22 계획 예행은 진행된다. 이 의견이나 예행으로 핵을 미리 획득하거나 새 수호자를 탄생시키지 않는다. 루브라스가 현재 접촉 불가이면 의견 공석으로 두고 다른 실제 의견과 공개 근거로 이어 간다. 기다림에 시한이나 오프라인 페널티가 없다. 사망·끊김 때 이미 전달한 자료와 당사자 응답은 보존하고 아직 공개하지 않은 문구를 자동 전송하지 않는다. 뒤늦은 사람은 공개 의견을 실제 읽고 현재 반응을 할 수 있으나 과거 회의의 표결 참가자로 세지 않는다.

재미는 힘의 서열이 곧 의견의 일치를 뜻하지 않는다는 점을 구체 요청과 거절에서 경험하는 것이다. 당사자의 현재 판단과 공개 범위를 알면 충분하며 모든 용 설득을 완료 조건으로 삼지 않는다.

### 제작과 인수 검사

- 대체: 동시 집합 없이 순차 접견과 출처 있는 승인문 전달. 둘 중 한 배우가 없으면 가능한 사람의 의견만 얻고 다른 자리는 공석으로 남긴다.

## LUB04 최종전 밖에서 지킬 약속

### 시작과 범위

C25·C26에서 현재 봉인 상태·실제 이동 또는 작용 가능 범위·세계 수용 범위·관계와 당사자 동의가 허용할 때 루브라스가 원정 바깥의 위험이나 귀환로 한 구간을 맡는 선택 출연이다. 실제로 필요한 봉인층이 아직 열리지 않았거나 현재 봉인·작용 범위 때문에 직접 지원할 수 없으면 이 지원은 없다. LUB02의 완료 표기 자체보다 검증된 현재 상태를 기준으로 하며, 다른 경위의 해제가 실제로 확인됐다면 그 범위만 반영한다. 최종 원정 자체는 공개 준비와 플레이어 수행으로 그대로 가능하다.

여기서 원정은 현재 Minecraft 세계와 기존 네더·엔드의 확인된 접근로를 통해 최종 경계 현장에 가는 C25·C26 여정이다. 새 신화 차원을 찾거나 루브라스의 고향으로 출정하는 이야기가 아니다. 정식 C25 선행인 C22의 한 계획·C23 준비·C24 방법을 유지하고, LUB 장면 완료를 추가 열쇠로 넣지 않는다. 원정 지도에서 외측 귀환 구간 하나를 골라 시작·끝·철수 지점을 표시한다. C25 내부 결속, C26 귀환룡 본체 전투, 핵 제압은 루브라스 업무에 포함하지 않는다. 소환 버튼으로 어디에서나 출현시키지 않고 실제 한 개체의 현재 가능한 역할만 제안한다.

### C25에서의 실제 준비

1. 플레이어가 원정 전 외측 귀환로의 시작점과 끝점을 직접 답사하고, 엄폐·낙하·귀환 가능 여부를 확인한다. 이미 C25에서 확인한 같은 구간이라면 중복 왕복을 요구하지 않는다.
2. 접촉 가능한 루브라스에게 지도·현재 위험·맡길 한 구간을 실제로 전달한다. 과거에 협력할 의향이 있었다고 오늘의 역할과 제한까지 자동 수락한 것으로 보지 않는다.
3. 그가 가능한 범위를 제안하면 “이 원정 시도에서 이 구간의 외부 위협을 막고, 실제 철수 또는 안정 보관 확인 시 임무를 마친다”는 제한된 약속을 확인한다. 시간당 유지비·영구 복종·최종 보스 대리 처치를 붙이지 않는다.
4. 지원을 맡기기로 확정한 뒤 그가 실제로 위치·능력 범위에 들어왔는지 확인한다. 단순 대답만으로 외곽 안전을 완료하지 않는다. 동시에 다른 곳에 같은 본체가 일하는 것으로 배정하지 않는다.
5. 지원이 없거나 거절되면 기존 공개 원정 준비에서 플레이어가 같은 구간의 위험을 우회하거나 엄폐를 확보한다. 사용 허가된 발판 최대 6개·횃불 8개·음식 4개는 대체 준비 시험안이며 루브라스 부재 벌금이 아니다. 지형상 이미 안전하면 새 설치를 강요하지 않는다.

### C26에서의 실행과 확인

6. 실제 원정이 시작되면 플레이어는 내부 결속과 귀환룡을 상대한다. 루브라스 지원은 해당 외곽 위험에 한정한다. 구체 레이드 개입 확률·쿨다운·피해량 체계는 이 명세에서 확정하지 않는다.
7. 원정 중 외곽 관측점 또는 실제 지원 기록으로 그가 맡은 일을 수행했는지 확인한다. 전투 연출을 지원하지 않으면 검증된 외곽 지원 상태와 후속 현장 관찰로 표현하되 검증 없는 승리를 대사로 만들지 않는다.
8. 플레이어가 실제 귀환룡을 제압하고 핵과 퇴로의 안정 보관을 확인한 뒤 귀환로를 걸어 나와 약속 종료 조건을 확인한다. C26의 안정은 최종 선택을 준비할 안전 상태이며, 남은 세계의 경계 문제까지 모두 해결했다는 뜻이 아니다. C27은 C26 결과·선택 계획·사전 지정 전체 참여자의 명시 동의를 별도로 확인한다. 실패·철수라면 그 시도의 실제 철수를 확인하고 현재 약속을 마친다. 다음 시도는 현재 위치·범위를 다시 확인하며 자동 무한 소환 계약으로 이어지지 않는다.

### C28에서의 후일담

9. C28에 실제 현재 위치에서 재회하거나 이미 허용된 제한 접촉으로 결과를 알린다. 현재 남은 봉인과 실제 열린 층을 다시 확인한다. 최종 승리가 루브라스의 완전 해방을 자동 실행하지 않는다.
10. 실제 약속을 지킨 구간과 플레이어의 내부 승리를 각각 돌아본다. “내가 맡은 길은 여기까지다. 그 안에서 이긴 것은 너희다”라는 대사를 제안한다. 전리품·부하·펫이 되는 장면은 없다.

루브라스는 자신이 맡은 구간, 실제 수행한 일, 플레이어가 전달한 전투 결과를 안다. 외곽에 있었다는 이유로 내부 모든 행동과 사적 결말 논의를 목격하지 않는다. 내부 제압은 공개 전투 기록·실제 보고를 전달받은 뒤 인정한다. 원정 참가자도 눈으로 보지 않은 외곽 세부는 출처 있는 보고로 안다.

“같은 용이니 귀환룡에게 멈추라고 해”에는 “저것은 우리 종족이 아니다. 내 이름으로 멈출 존재도 아니다”라고 답한다. 강화 엔더드래곤·귀환룡·새 수호자를 진짜 용으로 만들지 않는다. “이번에 이기면 천마도 돌아오겠지?”에는 그 결과를 알 수 없다고 명확히 한다. “승리 기념으로 우리 집 지켜 줘”라는 농담은 새 영구 계약이 아니며 “오늘 약속한 길부터 마치겠다”라고 선을 긋는다. 지원을 거절한 원정에도 플레이어가 실제 이긴 성취를 깎지 않는다.

보상은 실제 안전 귀환과 한정된 신뢰다. 루브라스 고유 전리품·용 지휘권·강제 소환 아이템은 없다. C26 보상은 그 사건의 실제 참여 규칙대로 지급하며 외곽 선택 장면이 중복 보상을 만들지 않는다. C28에서도 신격·추가 해제·천마 재회는 새로 확정하지 않는다. 본래 전투등급 초월급을 현재 전력 행사나 추가 해제로 해석하지 않는다. 새 수호자 결말이어도 독립 생명의 거절·휴식·이탈과 생존 유지의 권리를 루브라스 지원 계약에 넘기지 않는다. 장치에서 분리할 수 있어야 하며 새 희생물로 대체하지 않고 이동 편의 감소를 감수한다. 어떤 결말 장치도 모든 신이나 용의 복종을 만드는 권능이 아니다.

이번 재미는 오래 논의한 약속이 최종전 바깥의 구체적인 한 길로 드러나는 것이다. 원정 시도에서 맡은 구간과 임무 종료를 확인하면 지원 장면은 마치고, C28의 짧은 현행 상태 확인으로 관계를 잇는다. 후속 해방이나 다른 용 갈등은 별도 이야기 후보이며 이번 패키지에서 이미 일어난 사실이 아니다.

### 공통 인수 시나리오

1. 두 명이 동시에 탑의 같은 공유 분기를 확정하려 할 때 첫 유효 선택만 적용되고, 다른 층 조사나 코어 활동은 계속된다.
2. 탑을 하나도 완료하지 않고 정식 C 선행만 충족한 플레이어가 C25·C27에 도달한다. T04 절단 상태도 동일하다.
3. C15 전에도 실제 접근 가능한 여우신과 여러 플레이어가 일반 인사·현재 SIDE를 하되 신호·MAIN을 선취하지 않는다. C15 뒤 자료·준비 조건을 갖춘 인사자 여섯 명 중 MAIN 첫 유효 수락자는 한 명뿐이며, 나머지는 각자 SIDE·일반 전투 도움·공개 길 이용을 한다.
4. MAIN 소유자가 장기 부재여도 공유 코어·다른 사람 관계는 진행되고, 불씨 결말과 사적 대화는 대신 확정되지 않는다.
5. 공개 정보와 사적 정보의 청중을 바꾸어 대화한다. C20 이전 유효한 조기 인정은 기억하고, C20 이후에도 미전달 고백을 모르는 배우는 계속 모른다.
6. 완전 봉인 루브라스는 일반 조우가 불가능하며 첫 층 작업 확인용 짧은 접촉만 허용한다. 첫 용 미토벌 상태에서 실제 로컬 조사와 실제 첫 1겹 해제, 잔여 봉인·안전 범위 검증을 마치면 제한 일반대화가 열린다. C17 재방문에서 같은 층이 다시 열리거나 다음 층이 자동 해제되지 않는다.
7. C17 장치 철거, C21 회의 참가, C26 승리, C27 모든 결말 각각이 루브라스·천마의 자동 완전 해방이나 신격·등급 확정을 만들지 않는다.
8. 선택 실행 전, 실제 실행 직후, 결과 확인 직전에 각각 접속을 끊었다가 재개한다. 원본 불씨·본체·최초 보상·승리 이력이 복제되지 않고 실제 남은 작업만 이어진다.
9. 정상 사망 후 물자 회수를 정상 게임 규칙으로 처리하고 오프라인 시간으로 사망·저주·집 파괴·봉인 악화가 발생하지 않는다.
10. 색상·소리·입자 연출 없이도 기록과 실제 동선으로 관찰 퍼즐을 풀 수 있다. 연출은 행동 증거를 대신하지 않는다.
11. 첫 용 미토벌·C02 완료 상태에서 T01의 지도 또는 전투 경로를 이용할 수 있다. T02←T01+C06, T03←T02+C15, T04←T03+C20은 그대로이며, T01을 하지 않은 사람의 C05는 잠기지 않는다.
12. 탑·숲·봉인·외곽 지원의 동선이 현재 세계 또는 기존 네더·엔드의 실제 위치에 묶여 있다. 새 신화 차원·고향 포털 제작, 가이아의 문화권 일괄 해금, 낮은 후보확률을 이용한 완전 봉인 접촉 우회가 없다.

이 인수 항목들은 배포 전 시험 명세이며 통과했다는 결과 보고가 아니다. 실제 좌표·전투 수치·대화 청중 처리·배우 이동·층별 봉인·보상 지급은 구현 환경에서 확인하고, 검증되지 않은 선택 효과는 안내문만으로 완료 처리하지 않는다.
