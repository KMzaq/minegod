# 마인크래프트 신화 RPG C15부터 C22까지의 후반 장면 상세안

개정일 2026년 10월 7일

천군의 남은 통행 기록에서 네더의 강제 구속을 추적하고, 엔더 정거장의 기록으로 여신과 종말핵을 검증한 뒤, 마지막 원정에 쓸 세 방안의 실제 비용을 경험하는 여덟 사건의 제작용 상세 콘텐츠 명세다. 기준은 [메인 스토리 개정안](../01_메인_스토리_개정안.md)의 C15–C22와 세계·진행 원칙이며, 장면 단위의 작성 방식은 [C01–C06 상세안](../02_C01_C06_상세안.md)을 잇는다. 성장과 일반 조우·특수 조우의 운영 기준은 [성장과 특수조우 상세안](../03_성장과_특수조우_상세안.md)을 함께 확인한다. C17은 `rpg_gimmick_details_v0.6.md`의 지형 조사·구속 범위 구별·비신격 집행체 전투 의도를 가져오되, 최신 본문의 회수 후 결정 순서와 자유 접속 원칙을 우선했다.

본문의 대사, 작은 주민 배역, 물자 수량, 조사 지점과 연출은 **실행 제안**이다. 새 NPC 신격, 실제 좌표, 등록 ID, 서버 기능, 확정 밸런스를 선언하지 않는다. 작가용 진실이 포함되어 있으므로 전체를 플레이어에게 공개하는 안내문으로 쓰지 않는다. 실제 서버 적용, 게임 플레이와 LLM 대화 시험은 수행하지 않았다.

## 공통 적용 기준

### 기록과 실행의 단위

- 공용 진행은 실제 완료한 조사·귀환로·선택 결과다. 개인에게는 직접 수행한 행동, 읽은 자료, 들은 말만 남긴다. 공개 자료가 있다는 이유로 모든 NPC와 플레이어가 이미 읽었다고 처리하지 않는다.
- 각 카드의 장소 슬롯은 제작자가 실제 기존 부지를 골라 연결할 이름이다. 좌표나 엔진 필드가 아니다. 구조물 이름을 지도 생성 조건으로 강제하지 않으며 새 전용 건축은 요구하지 않는다. 이 문서의 원정은 현재 Minecraft 세계의 지상 생활권과 기존 네더·엔드를 오가는 일이다. 신화 고향·출신과 과거 왕래는 남기되 새 신화세계·신화 차원 지도를 필수로 제작하거나 방문하지 않는다.
- 말로 한 제안, 명시적 확정, 실제 실행, 결과 확인은 분리한다. 의미 있는 공동 선택은 범위와 비용을 제시한 뒤 첫 유효한 명시적 확정으로 그 분기만 정한다. 질문·농담·개인의 불참 의사는 공동 확정이 아니다.
- 같은 공용 재고나 한 NPC의 약속을 중복 배정하지 않는다. 제공 허락을 받은 물건만 사용한다. 다른 재고·사람·현장의 독립 작업은 동시에 계속할 수 있다. 확정자가 없어도 남은 사람이 미사용 자원과 당사자의 동의를 확인해 공용 작업을 잇는다.
- 신과 주요 인물은 세계에 실제 한 개체다. 기록은 기록이며 즉석에서 대답하는 복제가 아니다. 본체 참여는 실제 위치·남은 봉인·세계와 창구 수용 범위·당사자 의사가 허용할 때만 쓴다. 창구는 관측·계시·가호·제한 현현·개입의 통로도 포함하며 신화 고향 포털만 뜻하지 않는다. 힘을 받는 사람의 수용 범위는 별도로 확인한다.
- 등급만으로 C15·C21 이전의 첫 만남을 막지 않는다. 실제 봉인·접근·사건 근거를 만족한 고위 인물도 앞서 만날 수 있고, 세계 진행은 조건을 만족한 조우 후보의 확률을 초반 낮은 등급·후반 높은 등급 쪽으로 우대한다. 낮은 확률과 완전 봉인으로 접촉 불가능한 상태를 구분한다. 각 사건의 선행은 그 조사·해결의 조건이며 모든 인물의 첫 조우·MAIN 수행 준비를 함께 해금하는 단계가 아니다.
- 앞서 만난 인물에게는 실제 마지막 대화와 지원 약속을 이어 받는다. 처음 보는 청중만 소개를 받고, 과거 만남이 없는 다른 친구에게 개인 경험을 복사하지 않는다. 조우가 성립해도 즉시 고급 가호·장비·복종을 주지 않는다.
- 선택 개인 MAIN 소유, 천마나 루브라스의 해방, 여우신 이야기, 탑 완주, 여섯 명 동시 접속은 이 여덟 사건의 추가 선행이 아니다. 네더와 엔더의 바닐라 탐사·성장을 사건 번호로 새로 잠그지 않는다.

### 결과 확인과 물건의 권리

첫 발견자·회수자·전투 참가자·현재 보관자를 각각 적는다. 고유 원본은 하나뿐이며 물리 보관과 연구·원정 사용 허락을 구별한다. 이미 허락된 공용 보관과 사용은 허락 범위 안에서 부재 중에도 이어 갈 수 있다. 개인 인벤토리에만 있고 사용 허락도 없는 물건을 부재 때문에 몰수하거나 복제하지 않는다. 그런 경우 해당 실물 단계의 접근 문제만 남기고, 공개 자료 검토·길 조사·다른 사람의 준비는 계속한다. 개인 MAIN 자체를 다른 사람에게 넘기는 해결은 쓰지 않는다.

일반 게임 사망과 소지품 손실 규칙은 유지한다. 문서상의 조사 이력은 사망으로 지워지지 않지만 잃은 실물을 저절로 돌려주지 않는다. 유일 조각·휴면 핵은 배포 전에 기존 유일 물건 관리 방식과 회수 절차를 확인해야 한다. 유실 시 먼저 기존 원본의 위치와 존재를 확인하고, 복구가 필요한 경우에도 같은 원본을 복구하는 운영 처리만 허용한다. 새 원본 두 개를 지급하지 않는다. 지원 없는 무적 구조나 신의 자동 막타는 없다.

자동 조사·호위·서명 확인이 없다면 실제 현장과 물건을 진행자가 확인하고, 그 사실에 대응하는 조사문과 결과문을 제시하는 방식으로 제작할 수 있다. NPC 이동 기능이 없을 때는 플레이어가 실제 길을 확보한 뒤 당사자가 출발·중간·도착 지점으로 이동했다는 승인된 장면을 순차 배치한다. 단순히 대화에서 “구했다”고 말한 것만으로 완료하지 않는다. 이런 연출용 이동과 기본 게임 규칙을 배포 전에 구분해 안내한다.

### 중반에서 받는 상태

첫 엔더드래곤 토벌은 플레이어가 이미 이룬 큰 승리로 이어 받는다. 조사에서 숨은 기원을 알아도 첫 용이 봐주었다거나 훈련용이었다고 바꾸지 않는다. 토벌 뒤 지역 연결과 신들의 개입 가능 범위가 바뀌지만, 모든 문화권·봉인·귀환로가 한 번에 열리지는 않는다. 플레이어는 기존 성장·탐험·개인 모험을 통해 이후 더 강해질 수 있으며 C15–C22는 그 성장을 초기화하지 않는다. 뒤의 귀환룡은 별개의 최종보스다. 조사·준비의 성공을 귀환룡 약화나 자동 승리로 계산하지 않으며, 전투력 고정 수치·배율·보상용 COMBAT_POWER를 이 문서의 조우·입장·피해 공식으로 쓰지 않는다.

C13의 조사 결과는 공개·제한 보관 여부와 실제 전달받은 청중을 함께 받는다. C14의 민간 회랑은 C10의 보증 항로 또는 독립 항로, C11의 소형 지름길·대형 제한 회랑·독립 육로, 실제 민간 개방과 분리 운송 결과를 이어 받는다. 이미 끝난 선택을 후반에서 편의상 바꾸거나 다른 조건의 지원까지 소급하지 않는다.

## C15 천군이 남긴 문

### 목적과 시작 조건

**정확한 선행은 C13 그리고 C14다.** 천마의 해방 대신, 전후 구속이 네더의 통행 장치와 경계 전체로 이어짐을 현장 증거로 확인한다. 시작 증거는 C13의 실제 확보 자료와 C14의 실제 접근로다. 공용 성과는 네더 연결의 위치·성격 확인이며, 천마 접촉과 각자의 질문은 개인 청취 범위로 남는다.

이미 C15가 끝난 세계에서는 닫힌 문을 새로 발견시키지 않는다. 남은 조사 흔적과 통행 기록을 읽고 현재 사용할 수 있는 C16 접근로의 갈림목 하나를 직접 확인한다. 과거 천마 접촉 경험이나 첫 발견은 주지 않는다.

### 장소와 배역

| 제작 슬롯 | 실제 부지 선택 | 안전한 대안과 필요한 자산 |
|---|---|---|
| 천군 기록 자리 | C14 회랑에서 닿는 기존 깊은 동굴의 넓은 선반 또는 이미 발견한 폐허의 바깥 방 | 낙하 없이 들어가고 돌아갈 수 있는 일반 동굴 벽면. 기존 블록에 조사 지점 3곳과 통행 기록 2편을 연결한다 |
| 네더 연결 흔적 | 기록 자리와 같은 동선의 막다른 균열 또는 기존 포탈 방향이 보이는 출구 | 포탈 자체를 새로 만들게 하지 않고, 현존 포탈까지 잇는 지상 길의 실제 표지를 쓴다 |
| 선택 봉인석 접점 | 아래 제한 접촉 장면이 별도 채택됐을 때만 지정하는 기록 자리 인접 암반 | 유효 부지가 없거나 채택하지 않았으면 기록 경로만 제공한다. 비슷한 돌을 임의로 천마의 봉인으로 만들지 않는다 |

손오공은 실제 접촉 가능한 경우 현장 동행 또는 짧은 제한 전달로 참여한다. 부재하면 그가 새 말을 했다고 꾸미지 않고, 주민 탐사자가 발견 기록과 자기 의문을 전한다. 천군 기록의 발화 주체는 당시 작성자이며 천마의 현재 대리인이 아니다. 루브라스의 열기·전쟁 흔적은 별도 연결을 채택한 경우에만 선택 조사물로 둔다. 여우신은 실제 위치·봉인·접근 조건이 맞으면 C15 이전에도 만날 수 있다. C15 뒤에는 이번 기록과 귀환 신호를 놓고 나눌 선택 대화가 더해질 뿐, 첫 조우 자격이나 자동 출현 보상이 생기지 않는다. 이미 만난 청중에게는 앞서 받은 질문·답을 이어서 말한다.

### 천마 경로의 제작 선택

두 경로는 모두 원문에 맞는 대안이다. **천마의 운명은 플레이어가 메뉴를 눌러 정하는 사건 분기가 아니다.** 패전 후 봉인은 확정이다. 제작자가 구체 제한 접촉 장면을 배치하지 않은 버전은 기록 경로를 기본으로 낸다.

- **기록 경로:** 과거의 영입 제안과 전후 통행 기록만 제공한다. 이 기록만으로 NPC나 플레이어가 천마의 현재 위치·의사를 안다고 처리하지 않는다. 봉인되어 있다는 작가의 확정 사실도 실제 전달 없이 개인 지식으로 주지 않는다. 네더 연결의 핵심 증거는 모두 확보된다.
- **제한 접촉 장면 채택 경로:** 봉인된 천마의 구체 접촉 장소와 조건을 별도로 채택했다는 제작 전제 아래, 봉인석 바로 곁에서만 짧은 접촉을 제안한다. 완전 봉인 중 일반 대면·신체 출현·동행·MAIN 수락·장비 증여는 없다. 이 카드에서는 한 겹 해제를 실행하지 않는다. 추후 별도로 채택한 해제 사건이 있다면 그 실제 결과와 남은 조건을 받아 일반 조우를 검토한다.

### 순서대로 하는 일

1. **안팎의 통행 표식을 잇는다.** 입구의 피난 통행 기록, 안쪽의 군수 통행 기록, 마지막 출구 방향의 차단 흔적을 차례로 확인한다. 실행안은 조사 지점 3곳이다. 같은 무늬가 있다고 동맹으로 단정하지 않고 날짜와 대상이 달라진 부분을 표시한다.
2. **두 문장을 대조한다.** 당시의 “민간 귀환 제외” 조항과 후대의 “해당 길을 쓰는 모든 통행” 문구를 읽는다. 이 문구는 본문의 오분류를 보여 주기 위한 기록 소품 제안이다. 구속의 대상이 넓어졌다는 설명을 실제 세 지점의 막힘과 연결한다.
3. **네더 쪽 방향을 검증한다.** 마지막 흔적에서 표시된 방향을 따라 기존 포탈 접근로의 확인 가능한 갈림목까지 간다. 같은 기록 부호가 남은 표지와 돌아오는 길을 확인한다. 즉시 네더 심부 원정을 강제하지 않는다.
4. **선택 접촉을 한다.** 채택된 접촉 경로가 있고 당사자가 원하면, 접촉 범위와 한계를 들은 뒤 봉인석 곁에서 질문 하나를 보낸다. 응답이 실제 성립한 경우에만 그 청중에게 현재 발언을 남긴다. 무응답도 가능한 결과이며 조사 완료를 막지 않는다.
5. **연결 근거를 남긴다.** 세 현장 관찰과 원문 차이를 묶은 공개 기술 발췌를 보관한다. 공개 가능 범위와 열람 위치를 적고, 접촉에서 사적으로 들은 말은 별도로 둔다. C16으로 이어지는 것은 발췌와 실제 접근 방향이다.

|---|---|---|
| 기록 조사만 마친다 | 현장 3곳과 방향 확인을 수행한다. 접촉 거절은 개인 선택이다 | C15 공용 완료. 봉인 상태는 정사로 확정하되 현재 위치·의사에 관한 개인 지식과 접촉 경험은 자동 부여하지 않음 |
| 채택된 봉인석 접촉을 시도한다 | “이 자리의 제한 응답만 요청하고 봉인을 건드리지 않는다”는 범위로 신청한다 | 실제 응답 내용과 실제 청중만 추가. 일반 조우·해방·MAIN·C16 특별 독점권 없음 |
| 루브라스 흔적을 더 살핀다 | 별도 선택 연결이 있을 때 안전한 외곽 관찰만 한다 | 후속 조사 위치를 얻을 수 있으나 C15 완료와 독립. 열기만으로 신격·봉인자·전력을 확정하지 않음 |

### 지식과 짧은 반응

- **손오공:** 받은 자료의 문구 변화와 자기 관찰을 안다. 강자를 믿는 것과 결정권을 맡기는 일을 다르게 본다. 천마의 현재 상태를 목격하지 않았다면 모른다. 여신의 비공개 정체도 자동으로 알지 못한다. “문이 열리면 좋지. 그런데 그 열쇠를 또 한 사람 허리에만 달아 둘 거냐?”
- **천마의 과거 기록:** 옛 영입 제안과 당시 입장만 증명한다. “나를 따르라”는 과거 문장을 현재 명령처럼 재생하지 않는다.
- **천마의 실제 제한 응답이 있는 버전:** 봉인석 곁 현재 접촉에 답한 범위만 안다. 밖의 전황은 전달된 근거만 받는다. 제안 대사: “그 길을 확인해라. 내 뜻이라며 대신 말하는 자의 말과 내 말은 나누어라.” 구체 현상은 채택안과 맞춰 제작한다.
- **현장 탐사자:** 자기가 읽은 통행 기록과 걸어 본 출구만 안다. “이 표시는 군대 짐칸에만 있었는데, 뒤의 글은 사람까지 묶어 놨어요.”

“천마가 다 풀어 주면 되지?”에는 손오공이 “지금 할 수 있는 일부터 확인하자”고 답한다. “천마는 죽은 거야?”에는 기록 경로에서 “여기 기록으로 현재를 확정할 수 없다”고 한다. 근거 있는 생존 추론은 가설로 보존한다. “천군 왕좌부터 예약할까?”라는 농담은 충성·MAIN 수락이 아니다. 서두르면 방향 확인까지 하고 선택 흔적은 뒤에 보아도 된다고 안내한다.

### 완료와 회복

완료 증거는 **대상 확대를 보여 주는 기록 대조, 실제 네더 연결 방향, 열람 가능한 기술 발췌**다. 공용 보상은 C16 조사 접근과 T03의 기존 선행 중 C15 충족이다. 개인 보상은 실제 관찰·청취 이력이며 고급 가호나 해방권은 없다. 원본 기록은 현장에 보존하거나 실제 허락된 보관처로 옮기고, 발췌는 원본과 구별한다.

사망·접속 종료 때 끝낸 조사와 아직 못 걸은 구간을 남긴다. 부재 중 봉인이 닳거나 응답자가 죽지 않는다. 후발자는 공개 발췌와 현장 확인으로 현재 조사에 합류한다. 손오공의 개인 MAIN 소유자가 없어도 자료를 읽고 C16으로 갈 수 있다.

### 호흡과 제작 점검

핵심 재미는 다른 표식이 하나의 통행망으로 이어지는 발견이다. C14의 길 만들기 다음에 다시 긴 운송을 요구하지 않는다. 연결 방향이 지도와 현장에서 맞으면 멈출 수 있고, 선택 접촉과 루브라스 흔적만 더 남는다.

| 제작 항목 | 확인할 사실 | 효과가 없을 때의 대안과 출시 전 확인 |
|---|---|---|
| 통행 기록 2편·현장 조사문 3개·방향 발췌 | 실제 읽거나 확인한 지점과 C13·C14 결과 | 조사문·책과 진행자 현장 확인 사용. 실제 부지와 포탈 방향을 맞춰야 함 |
| 손오공 또는 주민 전달 배역 | 실제 출연/수신 상태 | 신의 현재 대답이 없으면 주민의 관찰만 쓴다 |
| 선택 천마 응답 | 채택된 경로, 접촉 위치, 실제 청중 | 미채택이면 삭제. 빛 효과가 없어도 한정된 응답문으로 표현 가능 |

수용 시험: 기록 경로만으로 C16에 갈 수 있는가, 접촉 거절로 불이익이 생기지 않는가, 천마 본체와 MAIN이 자동 생성되지 않는가, C15 완료만으로 여우신·루브라스가 출현하지 않는가를 확인한다. 조건을 먼저 만족해 만난 여우신에게 첫 소개를 강요하지 않는지, 완전 봉인의 실제 제한을 등급 해제와 혼동하지 않는지도 확인한다.

## C16 빚이 아닌 계약

### 목적과 시작 조건

**정확한 선행은 C15다.** 네더 차원 자체의 해금이 아니라, C17 구속 장치의 적용 대상을 현장에서 판별하고 접근법을 정하는 조사다. 공용으로 남기는 것은 원계약·현행 분류·실제 통행 피해의 대조와 한 개 이상의 검증된 접근로다. 아스모데우스와 맺은 재심 약속은 실제 수락자와 약속 범위를 별도로 남긴다.

이미 지나간 세계에서는 당시 계약을 다시 체결하지 않는다. 현행 C17 결과를 읽고 현재 민간 길을 직접 확인한다. 이때 새 개인 교류는 가능하지만 과거 재심 약속의 당사자가 되지는 않는다.

### 장소와 배역 모드

| 슬롯 | 부지와 소품 | 등장 방식 |
|---|---|---|
| 계약 대조 자리 | 기존 네더 거점의 안전한 방이나 포탈 근처의 고체 지형. 원계약·현행 명령·귀환자 진술 3편 | 솔로몬이 실제 현장에 있으면 설명. 없으면 출처가 명확한 해석문과 플레이어의 현장 대조 |
| 높은 정문 길 | 용암을 강제로 뛰어넘지 않고 돌아갈 수 있는 넓은 암반길 | C17 수비의 시야와 외곽 경계를 관찰한다 |
| 낮은 통로 | 실제로 연결된 낮은 동굴이나 폐허 외곽 우회로. 안전 출구 1곳 포함 | 아스모데우스의 유효한 정보 제공이 있을 때 그 지도를 쓴다. 없으면 독립 탐사로 발견 가능한 별도 길을 사용 |

솔로몬은 현행 명부의 비신격 영웅으로 다루며 신 전용 MAIN을 만들지 않는다. 아스모데우스와 미카엘의 게임상 신격·등급은 여기서 결정하지 않는다. 아스모데우스의 기본 자산은 **현재 실제 가능한 제한 접견 또는 범위가 확인된 전달 수단**이다. 몸이 나오려면 현재 봉인·위치 조건이 이를 허용해야 한다. 접촉 불가능한 상태라면 살아 있는 응답을 생성하지 않으며, 이미 실제 발급된 유효한 제안서가 없는 한 거래 선택도 제시하지 않는다. 공개 조사 경로는 그대로 열린다.

엔릴의 현행 명령은 출처가 확인된 문서로 제시한다. 미카엘의 “지나가는 주민은 계약 당사자가 아니다”라는 반대도 실제 발언·응답 또는 기존 공개 원칙으로 구분한다. 기록을 읽는 주민이 그 인물의 현재 감정까지 대신 말하지 않는다.

### 실제 조사와 접근

1. **세 자료를 펼친다.** 원계약의 당사자, 제한 대상, 종료 조건을 찾아 표시한다. 예시 소품 문구는 “무장 운송의 정지”, “전쟁 통행로”, “해당 연결의 집행 종료”다. 이는 C17의 두 해결안을 읽기 위한 제안이며 모든 악마를 계약 당사자로 적지 않는다.
2. **돌아가려는 사람을 만난다.** 기존 주민 1명을 귀환자 역할로 배정한다. 목적지 실행안은 네더 지름길 반대편의 기존 강가 마을이며, 그곳의 가족에게 씨앗을 가져가거나 광맥 작업장 동료에게 생활 도구를 돌려주려는 사정 중 실제 주민 설정과 맞는 것을 쓴다. 지도에서 현재 출구와 지상 목적지를 연결해 신화 고향 원정이 아님을 드러낸다. 자기 짐 목록 중 씨앗과 생활 도구를 보여 줄지 본인이 결정한다. 강제로 소지품을 수색하지 않는다. 동의를 받지 못하면 본인이 공개한 사유와 출구 조사로 피해를 확인한다.
3. **서로 다른 경계 두 곳을 본다.** 정문의 군수 표식과 민간 사람이 막힌 옆 출구를 직접 대조한다. 관측문은 둘이 같은 집행 연결에 걸렸다는 사실을 제공한다. 일반 네더 블록이 마법적 계약을 자동 증명한다고 설명하지 않는다.
4. **접근 제안을 비교한다.** 솔로몬의 정문 경로는 넓지만 수비에 드러난다. 아스모데우스의 유효한 제안이 있다면 낮은 통로의 출구를 재심 발언 기회와 교환한다. 독립 경로는 지도에 없는 바깥 암반을 걸어 복귀점을 확인해야 한다.
5. **선택한 길을 실제 답사한다.** 실행안은 입구·엄폐 가능한 중간 지점·돌아오는 출구 3점 확인이다. 같은 친구 여섯 명이 모두 답사할 필요는 없다. 길이 실제로 이어지지 않으면 계약을 받아도 접근 완료로 처리하지 않는다.
6. **C17용 대조표를 남긴다.** “누가 당사자인가 / 누가 잘못 묶였나 / 어느 연결을 바꾸나 / 누가 어떤 말을 약속했나” 네 칸을 채운다. 공개 기술 사항과 사적인 거래 내용을 분리한다.

### 거래와 거절

| 선택 | 확정할 범위와 실행 | C17 이후의 효과와 남는 한계 |
|---|---|---|
| 아스모데우스의 제안을 받는다 | “낮은 통로 정보를 받는 대신, 당신의 접견 범위 재심 의견을 실제 심의 자리나 전달 경로에 올린다. 해방과 결론은 약속하지 않는다”는 내용에 양쪽이 동의한다 | C17 수비를 피한 관찰 위치를 이용. 재심 발언 기회를 제공할 의무가 남으며 제한 유지 결론이어도 없애지 않음 |
| 거래 없이 독립 조사한다 | 거래를 받지 않는다고 말하고 외곽 실제 길 3점을 확인한다 | 같은 구속 사실·C17 접근을 얻지만 그가 제공한 지도·협력·관계 보상은 없음 |
| 아직 결정을 보류한다 | 원계약과 현장 조사만 수행한다 | 다른 사람이 다른 자원으로 공용 접근을 완성할 수 있음. 개인에게 빚이나 전원 불참을 기록하지 않음 |

재심 약속은 타인의 영혼·장비·MAIN·의사를 담보로 삼지 않는다. 수락자가 부재하면 공용 조사단이 허용된 공개 의견을 회의에 올려 공용 진행을 이어 갈 수 있다. 그러나 그 수락자 개인의 약속 이행 확인이나 친밀도 정산까지 대신 받은 것으로 쓰지 않는다. 유효한 제안서가 없다면 플레이어끼리 계약했다고 선언해 아스모데우스의 동의를 만들어 낼 수 없다.

### 지식과 대사

| 화자 | 아는 것과 입장 | 모르는 것과 말하지 않을 수 있는 것 |
|---|---|---|
| 솔로몬 | 자기가 읽은 계약 조항과 확인된 정문. 무장 통행의 최소 제한을 지지 | 모든 네더 봉인과 여신의 현재 마음을 알지 못함. 자신의 판단이 법칙이라는 주장은 검증 대상 |
| 아스모데우스 | 자기 구속과 실제 알고 있는 낮은 길. 경계 밖으로 직접 가고 싶어 함 | C17 이후 다른 당사자의 결정과 모든 봉인 해제를 보장하지 못함. 알려 주기로 한 길 외의 개인 사정은 거절 가능 |
| 미카엘 | 실제 전달받은 민간 피해와 자기 공개 원칙 | 계약 전체의 역사와 아스모데우스의 속마음을 자동으로 모름 |
| 엔릴 | 자신의 명령과 실제 전달받은 오분류 근거 | 독립 탐사에서 아직 전달되지 않은 출구·사적 거래를 모름 |
| 귀환자 | 막힌 자기 길과 자기 물건 | 전쟁 전체·여신의 정체를 모름 |

- 솔로몬: “당사자의 이름부터 보세. 이 길을 밟았다는 것과 서약했다는 것은 다르네.”
- 아스모데우스: “자유를 약속하라는 말이 아니야. 내 말이 기록에서 지워지지 않을 자리를 달라는 거지.” 질문이 “그럼 널 믿어도 돼?”라면 “길은 네 발로 확인해. 그다음 나를 어디까지 믿을지 정해.”
- 미카엘: “짐을 든 손이 계약서에 서명한 손은 아니지.”
- 엔릴의 실제 응답이 있다면: “민간인의 오분류는 고치겠다. 모든 무장 통행을 열겠다는 데에는 동의하지 않는다.”

“당신도 신이야?”라는 질문은 미정 분류를 즉석 확정하는 계기가 아니다. 공개된 정체와 맡은 일까지만 답한다. “사인하면 모두 탈옥이지?”라는 농담에는 재심과 해방의 차이를 바로 짚는다. 빠른 추리로 원계약의 문제를 맞혀도 실제 출구 답사를 생략한 완료는 주지 않는다. 급하면 독립 정문 조사로 C17의 이유를 확인하고 사적 거래는 나중에 이어 갈 수 있다.

### 완료와 회복

완료는 원계약 3항목, 현재 민간 오분류, 검증된 접근로가 모두 확인되었을 때다. 보상은 접근도와 공개 대조표이며 반복 화폐·고급 장비를 새로 만들지 않는다. 개인의 재심 약속은 실제 발급·수신·이행 상태를 남긴다. 이 약속을 듣지 않은 후발자를 채무자로 만들지 않는다.

도중 사망·접속 종료는 조사한 항목을 유지한다. 용암으로 물건을 잃었다면 실제 손실은 남으며 원문 열람 경로는 다시 제공한다. 거래가 있었지만 길이 안전하지 않으면 해당 구간만 재조사한다. 종이에 동의했다고 자동 호위·안전 면역이 붙지 않는다.

### 호흡과 제작 점검

기록 해독을 끝내고 실제 막힌 사람과 길을 맞춰 보는 장면이다. C15보다 판단 대상이 구체적이다. 3항목 대조와 접근로 하나가 끝점이며, 모든 제안자를 찾아 도장 받는 순회는 없다.

| 필요한 제작물 | 완료를 판별할 사실 | 대안과 미확정 연결 사항 |
|---|---|---|
| 원계약·현행 명령·귀환자 진술·C17 대조표 | 읽은 조항, 민간 출구 조사, 길 3점 | 자동 퍼즐 없이 책과 현장 확인. 원계약 문구와 실제 출구를 먼저 고정 |
| 아스모데우스 제안과 솔로몬·미카엘 응답 | 실제 제안 주체, 접촉 모드, 당사자의 수락 범위 | 유효 전달이 없으면 독립 조사만 사용. 신격·본체 조우를 추가하지 않음 |
| 정문·낮은 길·독립 우회 | 실제 왕복 가능 여부 | 안전 지형이 없으면 다른 기존 네더 부지 선택. 강제 용암 점프는 배제 |

수용 시험: 거래 거절·당사자 부재·개인 MAIN 소유자 부재에서도 C17 접근이 가능한가, 낮은 길 정보가 거짓 완료가 되지 않는가, 사적인 담보를 공용 채무로 확대하지 않는가를 확인한다.

## C17 녹지 않는 쇠사슬

### 목적과 시작 조건

**정확한 선행은 C16이다.** 제5조각 원본을 비신격 수비로부터 회수하고, 이 통행 장치의 민간 구속을 끝내되 무장 통행의 제한을 남길지 연결 자체를 끊을지 정한다. C16의 계약 대조표와 검증된 접근로가 시작 증거다. 조각 회수와 최종 연결 변경은 별개 확인 단계다.

세계가 이미 해결되었다면 옛 계약과 수비병을 부활시키지 않는다. 후발자는 제5조각 회수 기록과 현재 민간 출구를 확인하고, 현재 통행·방어 정비에 기여한다. 최초 조각과 첫 승리 보상은 다시 지급하지 않는다.

### 장소와 적

기존 네더 폐허의 넓은 외곽 또는 용암 호수에서 떨어진 고체 지형을 우선한다. 정문·엄폐가 있는 전투 자리·제5조각의 걸림 자리·민간 출구·귀환 지점 다섯 슬롯을 같은 현장 동선에 배치한다. 실제 구조물 ID는 부지 답사 뒤 정한다. 적을 용암에 밀어 넣는 것만이 유일 해법이거나 피격 시 곧바로 허공으로 떨어지는 부지는 제외한다.

전투 자산 제안은 위더 스켈레톤 기반의 비신격 계약 집행체 1체와 블레이즈 보조 수비 2체다. 수량은 이 실행안의 시작점이며 난도 확정이 아니다. 실제 사용 가능한 전투 배치 방식으로 검증한 뒤 조정한다. 신 본체·위더 소환 폭발·아스모데우스 처형전으로 바꾸지 않는다. 악마나 이주민이라는 출신만으로 현장 전체를 적대화하지 않는다. 숨은 능력치, 고정 직업, 최소 두 명, 전원 동시 접속을 새 자격 조건으로 넣지 않는다. 혼자 감당하기 어렵다면 안전하게 물러나 다른 친구와 다시 올 수 있다.

### 순서대로 하는 일

1. **변경 대상과 비용을 미리 본다.** C16의 원문에서 민간인 연결과 무장 통행 연결을 나누어 표시한다. 두 결론 모두 제5조각을 얻을 수 있음을 알린다. 이때 선호를 말해도 아직 실제 절단은 일어나지 않는다.
2. **귀환점과 엄폐를 확보한다.** 플레이어가 실제로 안전 발판에서 민간 출구까지 왕복하고 용암·불·낙하 위치를 확인한다. 화염 저항·우유·회복은 선택 준비이며 특정 소비품을 필수 정답으로 만들지 않는다. 네더에서 물 양동이로 해결하라고 요구하지 않는다.
3. **수비를 제거한다.** 근접 집행체를 암반 쪽에서 상대하고, 블레이즈가 보이면 기존 엄폐로 시야를 끊으며 처리한다. 추가몹의 고정 체력 비율 소환·확률·쿨다운은 이 명세에 넣지 않는다. 현장 적과 남은 위험을 실제 확인한다.
4. **제5조각 원본을 회수한다.** 수비가 제거되고 접근 가능한 걸림 자리에서 원본을 꺼낸다. 조사문은 조각이 사람을 붙잡는 동력의 일부로 걸려 있었음을 보여 준다. 회수 자체로 모든 봉인을 해제하지 않는다. 회수자와 승인된 보관처를 확인한다.
5. **해결안을 명시적으로 확정한다.** 아래 두 안의 지원·비용을 다시 보여 준다. 첫 유효 확정이 정하는 것은 이 장치의 한 개 연결 해결이다. 다른 사람의 사적 의견이나 후속 개인 MAIN은 정하지 않는다.
6. **선택한 연결을 실제 바꾼다.** 좁힌 제한안은 민간 예외 연결만 분리하고 무장 연결을 남긴다. 절단안은 이 장치의 분류·집행 연결을 끊고 실제 외곽 방어·퇴로를 인계한다. 기술 효과는 작성된 조사 대상과 연결된 실행으로 확인하며 아무 레버나 누르면 세계 계약이 바뀌는 것으로 쓰지 않는다.
7. **귀환자를 통과시키고 흐름을 읽는다.** 귀환자 1명의 자발적 이동을 확인하고, C16에서 밝힌 지상 마을·작업장으로 이어지는 현행 출구 표지를 함께 확인한다. 이번 장면이 실제 끝난 구간까지만 통행 성과로 남기며 목적지까지 자동 도착했다고 쓰지 않는다. 조각 자리에서 엔더 방향으로 빠진 흔적을 조사한다. 이동 거절자는 강제 운송하지 않으며, 다른 동의한 통행자 또는 플레이어의 민간 시험 통행으로 해당 장치의 적용 변화를 검증한다.

### 배타적 해결과 허용 지원

| 해결안 | 확정 전 알릴 비용 | 실제 결과 | 남는 문제 |
|---|---|---|---|
| 좁힌 구속을 남긴다 | 무장 통행의 제한은 남으며 아스모데우스·일부 귀환자의 비구속 요구를 전부 충족하지 못함 | 민간 연결 분리와 통행 검증. 솔로몬의 실제 점검, 엔릴 측이 현재 제안한 민간 보급만 허용 범위에서 받을 수 있음 | 자동 보급을 선언하지 않음. 재심 발언권과 무장 통행 논쟁은 남음 |
| 구속의 연결을 끊는다 | 이 구간의 자동 차단 이익과 엔릴 측 군사 보급을 잃고 외곽 위험을 직접 맡음 | 이 장치의 분류·집행 연결 종료. 입구 방어 지점과 퇴로 확인. 실제 의사가 맞으면 아스모데우스의 제한 정보·협력 가능 | C22에서 허용 공용 방어 물자와 주민·플레이어 호위가 필요. 다른 봉인 해제는 없음 |

확정 문맥 예: “민간 귀환은 두 안 모두 가능해. 이 장치의 무장 제한도 끊고, 대신 이 입구의 방어를 우리가 맡는 쪽으로 실행할까?” 긍정이 오면 그 범위만 확정한다. 명확한 대상·비용을 이미 알고 실행을 요청했다면 의례적인 재확인을 반복하지 않는다.

C16의 재심 약속이 있다면 실제 의견을 안전한 서면이나 접견 범위에서 받아 기록하고 C21의 의제로 넘긴다. 원하는 결론을 주는 약속은 아니다. 불리한 결론 때문에 이미 받은 정보나 실제 구조를 과거에서 지우지 않는다.

### 화자가 아는 것과 짧은 반응

- **솔로몬:** 원계약과 현재 실제 바뀐 조항을 안다. 최소한의 무장 제한을 선호한다. “민간인을 놓아 주는 일과 무장 통행을 허용하는 일은 따로 쓰겠네.” 연결 전체를 끊으면 불만은 남지만 거짓 성공 보고를 하지는 않는다.
- **아스모데우스:** 자신이 제공한 길과 전달받은 변경을 안다. “좁혀 둔 줄은 언젠가 다시 늘어날 수 있어. 내 반대도 남겨 둬.” 자기 다른 봉인이 자동 해제됐다고 반응하지 않는다. 제한안을 선택해도 약속한 발언 기회를 실제 받았다면 그 사실은 인정한다.
- **미카엘:** 실제 민간 구속 해제를 확인한 범위만 안다. “지나갈 사람부터 놓아 줘. 그다음 남을 경계를 다투자.” 과거의 모든 전쟁 서약을 취소할 권위는 없다.
- **엔릴의 실제 응답 또는 명령:** 민간 예외의 유효성·자기 보급 조건을 다룬다. 공개 절단을 실제 통보받지 않았다면 미리 분노하지 않는다.
- **귀환자:** 통과한 자기 길을 안다. “이제 내 짐에 군대 이름을 쓰지 않아도 되는 거죠?” 이후 위험을 설명받으면 호위·출발을 스스로 고른다.

“칼을 뽑았으니 루브라스도 자유지?”에는 “이 연결은 통행 장치다. 그의 남은 층은 별도”라고 답한다. “둘 다 장점만 남겨 줘”에는 실제 장치의 자동 차단과 완전 비구속을 동시에 갖지 못함을 보여 준다. “그냥 다 폭파하자”는 범위 확인 전 실행 명령으로 받지 않는다. 급하면 조각을 안전 보관하고 연결 선택을 보류할 수 있지만, 민간 통행 변화와 흐름 조사까지 끝나기 전 C17 전체 완료는 아니다.

### 완료와 보상

완료에는 **제5조각 원본의 실제 회수, 두 안 중 하나의 실제 적용, 민간 통행 검증, 엔더 방향 흐름 조사**가 필요하다. 제5조각의 기능 제안은 강제 맹약의 절단이며 회수 사건을 바꾸지 않는다. 원본 하나의 회수와 함께 C18의 선행 중 C17을 충족한다.

세계 보상은 선택한 통행 결과와 원본 하나다. 실제 참가자의 전투·구조 기록을 따로 남긴다. 개인 보급 보상은 허용된 현장 재고에서 이번 임무의 실제 참여자에게 1회 지급하는 식량 8개·화살 16개를 초기 제작안으로 둘 수 있다. 배포 시 재고 제공자와 정확한 품목을 정하고, 보상이 약속되지 않은 참가자에게 소급 지급하지 않는다. 기존 장비보다 강한 커스텀 장비가 이미 존재한다고 주장하거나 신격을 자동 지급하지 않는다.

### 실패와 후발자

전투 패배는 계약 선택을 자동 실행하지 않는다. 남은 적·불·떨어진 물건을 확인한 뒤 같은 미완료 전투를 이어 간다. 회수 후 접속 종료라면 원본 위치와 보관 권한을 확인하고, 회수 완료를 중복 지급하지 않는다. 연결 변경 중단은 마지막 실제 적용 지점에서 멈추며 확인되지 않은 출구는 미완료로 남긴다. 오프라인 주민 처형·봉인 악화·집 파괴 시한은 없다.

후발자는 현재 출구를 직접 걸어 보고 선택에 따른 방어·통행 일에 참여한다. 첫 승리와 아스모데우스의 거래 당사자 지위는 받지 않는다. 개인 MAIN 소유자가 없어도 공개 계약으로 조사와 공용 확인을 진행한다.

### 호흡과 제작 점검

C16의 말과 문서를 실제 전투·통행 변화로 바꾸는 사건이다. 전투의 끝은 조각 회수이고 사건의 끝은 사람이 지나가는 확인이다. 같은 수비를 반복해서 처치하게 하지 않는다. 추가 봉인 조사와 개인 재심 대화는 이후 선택 활동이다.

| 제작물 | 안정적으로 확인할 사실 | 대안과 출시 전 필수 확인 |
|---|---|---|
| 적 배치·귀환 지점·엄폐·조각 걸림 자리 | 수비 제거, 플레이어의 접근과 원본 회수 | 지원 전투 방식으로 배치. 실제 지형·화재/투사체 외부 피해·낙하 위험 시험 필요 |
| 민간/무장 연결 표시와 결과문 | 어느 연결을 실제 바꿨는지 | 마법 효과 미구현이면 정확한 현장 조사·진행자 실행으로 표현. 연출만 하고 세계 효과를 주장하지 않음 |
| 제5조각과 보관 기록 | 유일성, 회수자, 보관자, 사용 허락 | 기존 유일 물건 처리 연결을 출시 전 검증 |
| C18·C22 인계 | 엔더 흐름, 선택한 제한, 실제 지원자와 빈자리 | 통행 원문·현장 확인서를 재열람 가능하게 둠 |

수용 시험: 회수 후 선택 순서를 지키는가, 민간인이 양쪽 모두 통과하는가, C16 거래 거절로 조각이 잠기지 않는가, 연결 절단으로 아스모데우스·루브라스 봉인이 풀리지 않는가, 최초 회수·참전·현재 정비 기여를 구별하는가를 확인한다.

## C18 엔더 시티의 마지막 이주 명부

### 목적과 시작 조건

**정확한 선행은 C13 그리고 C17이다.** C13의 역사 조사와 C17에서 확인한 엔더 방향 흐름을 합쳐 정거장의 기원, 여신의 임시 결속과 미이행 해제 약속, 공동 보관한 알의 정체를 입증한다. 엔더 시티 방문 이력이 없는 척하지 않는다. 이전 겉날개·전리품·탐험 기록을 빼앗거나 다시 얻으라고 하지 않는다.

공용 완료는 실제 확보한 기원·기술 증거와 휴면 핵체 대조 결과다. 이것을 읽은 사람만 그 내용을 안다. 이미 완료된 세계의 후발자는 보존 자료와 현행 관측 지점을 살피며, 첫 발견·옛 이주자의 경험을 소급받지 않는다.

### 장소와 소품

| 슬롯 | 실제 장소 | 소품과 대체 부지 |
|---|---|---|
| 이주 명부 자리 | 이미 방문했거나 새로 발견한 엔더 시티의 안전하게 닿는 방 | 명부·운송 장부·남은 짐 3묶음. 구조물이 훼손되었으면 같은 유적 인접의 넓은 섬에 보존된 문서함을 두는 실행안 |
| 공사 기록 자리 | 같은 구조물 하부 또는 주변 고체 지형 | 전환망 설계 발췌·임시 결속 원문·해제 보류 기록. 모든 방 탐색을 요구하지 않음 |
| 현재 흐름 관측 자리 | 돌아올 지점과 이어진 외곽 섬 가장자리의 안전 구역 | C17 방향과 만나는 흐름 2곳의 조사문. 낙하 없는 엄폐와 복귀 표지 |
| 휴면 핵체 대조 자리 | C05 이후 실제 합의한 공동 보관처 | 원본 알과 보관 이력. 허락 없이 개인 보관물을 꺼내지 않으며, 현장 자료를 가져와 대조해도 됨 |

핵체를 시험장에 실어 나르거나 깨울 필요는 없다. 원본이 현장에 없으면 기록 확보와 난류 탐사를 먼저 마치고, 허락된 보관처에서 한 번의 대조로 끝낸다. 핵을 대신한 새 알이나 복제는 만들지 않는다.

### 기록의 실제 내용

제작할 읽기 자료는 다음 다섯 묶음이다. 짧은 원문과 기술 도식은 새 실행 제안이며, 최종 문구는 C12·C13 소품과 인물 표기를 맞춘다.

1. **이주 명부:** C12의 살아남은 연인을 가리키는 기존 식별 흔적이 전후 구호 담당자 기록에 이어진다. 같은 힘을 지닌 다른 사람이라는 설명을 검토할 수 있도록 날짜 순서·동행자·이동지가 연결되어 있다. 이동지는 기존 엔드 정거장과 현재 세계의 강가·해안 정착지를 잇는 구호 경로로 구체화한다. 출신란에 신화 고향이나 다른 세계 배경이 남아 있어도 그 고향의 신규 맵 방문을 기록 검증 조건으로 삼지 않는다.
2. **헤르메스의 운송 장부:** 같은 구호 담당자의 출발, 돌아온 운송과 마지막 피난 행렬의 도착을 잇는다. 운송 장부가 그녀의 생각까지 말하지 않는다.
3. **엔키·토트의 공사 기록:** 찢어진 창구의 과잉 흐름을 경계로 전환했고, 축적된 힘에서 첫 용이 생긴 뒤 그 흡수를 장기 장치에 연결했다는 순서를 보여 준다. 처음부터 완성된 용을 소환했다는 기록은 넣지 않는다.
4. **임시 결속과 해제 조항:** “마지막 피난 행렬의 통과 뒤 결속을 해제한다”는 당사자 동의와, 행렬 도착 이후에도 효용을 이유로 해제를 보류한 관리 기록을 짝지어 둔다. 자발적 임시 지원이 영구 감금 동의가 아니었음을 확인한다. 특정 신을 새 총책임자로 지정하지 않는다.
5. **휴면 구조 대조표:** 흡수 경로·전환망 접속·휴면 보존 상태를 구별한 기술 도식이다. C05 이후 보관한 동일 알의 현 상태를 이 도식과 대조하도록 한다. 알의 정체를 이름표 하나만 보고 확정하지 않는다.

### 플레이 순서와 우선순위

1. **현재 귀환점을 확인한다.** 기존 게이트웨이·다리·비행 접근 등 이미 쓰는 방법 중 실제 안전하게 돌아갈 수 있는 하나를 확인한다. 겉날개를 가진 사람에게 다리 재건을 강제하지 않지만, 동행자의 귀환법은 따로 확인한다.
2. **사람의 짐부터 또는 흐름부터 시작한다.** 짐을 먼저 고르면 이름표가 남은 짐 3묶음을 명부와 맞추고 원주인의 상태·돌려받을 의사를 확인할 수 있는 것만 분류한다. 흐름을 먼저 고르면 관측 지점 2곳을 조사하고 현재 누출 구간을 먼저 분리한다. 첫 선택은 이번 공용 조사 지원의 우선순위이며 다른 친구의 독립 정리를 금지하지 않는다.
3. **기술 원문은 어느 쪽에서도 확보한다.** 공사 기록, 마지막 행렬 도착, 해제 보류의 순서를 대조한다. 현재 누출을 먼저 멈추면 일부 현장 흐름은 사라져 기술 도식과 남은 다른 지점으로 보완한다. 원본 관측을 먼저 보존하려면 관측 자리 주변의 실제 적과 위험을 정리한다. 핵심 원문을 분기 보상으로 영구 파괴하지 않는다.
4. **공동 관측 제안을 판단한다.** 오딘 측이 실제로 제공한 현재 난류 자료가 있고, 허용 범위가 맞으면 이를 받아 별도 귀환점을 확인한다. 관측을 거부하면 두 현장 지점을 직접 답사해 같은 기원 사실을 확인한다. 추가 귀환점과 그의 외곽 관측망은 독립 경로의 공짜 보상이 아니다.
5. **알을 깨우지 않고 대조한다.** 실제 보관 원본의 외형·보관 연속성과, 전환망 도식에 대응하는 비활성 관측을 확인한다. 관측 연출안은 알을 접속하지 않은 상태에서 ‘휴면 흡수 경로’, ‘현재 전환망과의 대응’, ‘생성·부화 활동 없음’ 세 항목을 보여 주는 것이다. 이 관측은 제작된 조사 콘텐츠이며 바닐라 알 블록의 자동 능력이 아니다. 원본을 전환망에 연결하거나 알을 새 생명으로 부화시키지 않는다.
6. **결론을 분리해서 적는다.** 첫 용은 실제 죽었고 플레이어의 토벌은 큰 위협을 끝낸 유효한 승리다. 흡수 구조의 잔존이 그 죽음과 성취를 취소하지 않는다. 현재 알은 흡수 구조를 보존한 종말핵의 휴면 핵체다. 여신의 현재 감금은 첫 저주가 재발한 것이 아니라 전후 결속이다. 제6조각은 기록이 가리키는 끊어진 말단에 있다. 각 결론에 근거 자료와 실제 확인자를 붙인다.

### 선택의 결과

| 선택 범위 | 실제 실행과 이득 | 비용과 미완료 |
|---|---|---|
| 짐과 이름을 먼저 정리 | 명부와 짐 3묶음 대조, 반환 가능 상태 확인 | 현재 흐름 추적은 뒤에 수행. 망자의 물건을 개인 전리품으로 지급하지 않음 |
| 흐름을 먼저 추적 | 관측 지점 2곳과 누출 구간 확인 | 추모·짐 정리는 C28에 남길 수 있음. 기록 속 사람이 없던 것으로 바뀌지 않음 |
| 원본 현장을 먼저 보존 | 적·위험을 정리한 뒤 관측과 기록 보존 | 플레이어가 현장 안전을 실제 마련해야 함. 다른 생명을 희생시키는 시한 없음 |
| 현재 누출을 먼저 멈춤 | 정해진 국소 연결을 분리하고 남은 자료로 대조 | 일부 원위치 관측을 잃어 도식·남은 흔적 검토가 필요. 핵심 사실은 보존 |
| 제한된 공동 관측을 수락 | 공유 자료·관측 범위·보관 권한을 명시한 뒤 실제 자료를 받음 | 오딘의 감독권 전체나 핵 소유권을 승인한 것이 아님. 실제 제공한 자료만 지원으로 기록 |
| 독립 조사 유지 | 기존 귀환점과 현장 2곳을 직접 확인 | 그의 추가 관측망·호위 없음. 같은 기원 사실은 얻음 |

### 지식과 반응

- **엔키:** 자기가 만든 연결과 받은 누출 자료를 안다. 지금 위험을 멈추려 하며 과거의 임시 장치가 영구 구속이 되는 것을 막지 못한 책임을 회피하지 않는다. 여신의 사적 감정과 현재 모든 난류는 모른다. “이건 버티라고 만든 장치였어. 사람을 붙잡아 두는 이유가 되어선 안 됐지.”
- **토트:** 보존한 원문과 실제 대조 결과를 안다. 훼손되기 전 원본을 남기려 한다. “도착을 기록한 장부는 여기 있다. 해제했다는 기록은 없다. 보류했다는 기록은 있고.” 추측으로 빈 행을 채우지 않는다.
- **헤르메스:** 자기 운송 장부의 실제 행렬을 안다. 구호 담당자의 모든 내면이나 현재 정체는 독립 증거를 받기 전 모른다. “짐이 돌아온 날은 적혀 있어. 짐을 보낸 사람이 돌아온 날은 없네.”
- **오딘:** 자기 관측망의 현재 난류와 자신의 과거 범행을 안다. 플레이어가 확보한 명부와 알 대조 결과는 실제 전달받은 뒤 안다. “내 자료가 길 하나를 더 남길 수 있다. 그렇다고 이 핵을 제한 없이 열라는 뜻은 아니다.”
- **현장 기록 담당 주민:** 자신이 읽은 자료와 확인한 짐만 설명한다. 신의 죄책감·속마음을 대신 서술하지 않는다.

“알이 핵인 줄 알았어”에는 이전 추리가 이번 실제 대조에서 확인되었다고 답한다. C18 전의 핵 정체는 작가용 비밀이므로 당시 플레이어의 가설·질문은 그대로 남기되, NPC가 이미 정답을 보증한 별도 증거를 소급해서 만들지 않는다. 여신의 정체를 먼저 추리하거나 고백으로 안 경험과 알의 핵체 검증은 별개로 기록한다. “죽은 용이 다시 나오는 거지?”에는 첫 용의 실제 죽음과 핵의 흡수 구조를 분리해 설명한다. 이후 나타날 귀환룡은 첫 용의 부활이나 약해진 재대결이 아닌 별개의 최종 위협이며, 지금의 발견으로 승리가 보장되지 않는다. 장차 방어 생명이 생길 수 있다는 설계 경고는 가능하지만 C26의 모든 전투 동작을 예언하지 않는다. “그럼 알에게 사과부터?”라는 농담은 생명·의식·동의의 증거가 아니다. 급한 사람은 기술 기록과 핵체 대조를 마친 뒤 짐 정리를 C28에 남긴다.

### 완료와 회복

완료는 다섯 기록 묶음의 핵심 대조, 실제 현장 흐름 확인, **공동 보관 원본이 휴면 핵체라는 검증**과 제6조각 방향 확보다. 보상은 기원·외부 설계 자료 및 C19 접근 근거다. 알은 소모하지 않고 기존 승인 보관을 유지한다. 이전 전리품은 그대로 개인 소유다. 유족·주인 물건은 반환 권리를 확인하며 무주물이라고 임의 보상화하지 않는다.

사망·접속 종료 뒤 읽은 자료와 실제 회수한 사본은 남지만, 아직 관측하지 않은 핵은 확인 완료로 바꾸지 않는다. 핵이 부재 중 부화·도주·부패하지 않는다. 추모 미완료도 주민 사망 카운트다운이 아니다. 후발자는 공개된 기술 발췌를 실제 읽고 핵 보관 기록을 확인할 수 있다. 비공개 정체 고백은 그 경로에 자동 포함하지 않는다.

### 호흡과 제작 점검

C17의 전투 직후, 이미 익숙한 엔더 시티를 누군가의 짐과 미이행 약속이 남은 장소로 읽는 재미다. 자료를 전부 수집하는 도감 과제가 아니라 다섯 묶음의 인과를 맞추는 한 조사다. 기술 결론과 제6조각 방향이 나오면 멈출 수 있다.

| 제작물 | 확인 사실 | 대안과 출시 전 확인 |
|---|---|---|
| 명부·운송·설계·결속/보류·휴면 도식 | 연속성, 첫 용의 기원, 전후 감금, 동일 원본의 핵체 대조 | 책/조사문으로 제공. C12·C13의 인물 표기와 상대 연대 정합 필요 |
| 누출 2지점과 귀환점 | 실제 접근·국소 정리·독립 또는 공동 관측 | 광선 효과 없이 전후 조사문. 문서만 읽고 현장 완료를 주지 않음 |
| 핵체 비활성 관측 | 원본·보관 연속성·세 항목 확인 | 안전 보관처에서 진행자 관측 가능. 깨우는 작동과 혼동 없게 검증 |
| 짐 3묶음 | 이름 대조·반환 동의·미완료 추모 | 아이템 없이 승인된 조사 소품으로 가능. 유품 복제 보상 없음 |

수용 시험: 엔더 선행 방문자의 성취가 유지되는가, 오딘의 관측을 거부해도 핵심 사실을 얻는가, C18 전에 알을 자동으로 핵이라 부르지 않는가, C18 완료 뒤에도 실제 미열람자는 비밀을 모르는가, 여신의 정체를 이미 아는 청중에게 기억 초기화가 없는가를 확인한다.

## C19 엔드 외곽에 남은 여섯 번째

이번 목적지는 기존 엔드 외곽의 섬과 끊긴 경계이며 새로운 신화세계 지도가 아니다.

### 목적과 시작 조건

**정확한 선행은 C18이다.** 끊어진 엔더 경계의 실제 귀환로를 확보하고 제6조각 원본을 회수한다. 시작 증거는 C18의 말단 방향과 원본 조각의 기원 기록이다. 제6조각은 용사의 죽음 때 흩어진 원본이며 종말핵이 새로 생산한 물건이 아니다.

공용 결과는 제6조각의 회수와 외곽 말단 조사다. 각자의 전투·이동·축복 대조 경험은 별도로 남는다. 이미 완료되었다면 현행 귀환점 점검으로 합류하며 원본을 재생성하지 않는다.

### 장소와 배역

기존 엔드 외곽의 넓은 섬 두 곳과 사이를 잇는 검증된 길을 사용한다. 새 신화 차원으로 들어가는 장면이 아니라 이미 존재하는 엔드 안의 끊긴 말단을 살피는 탐사다. 슬롯은 출발 귀환점, 중간 피난 자리, 끊어진 말단, 조각 자리다. 이미 안전한 다리·게이트웨이·비행 경로를 확보했다면 재건 과제를 주지 않는다. 현행 장비로 가능한 귀환법이 없는 섬은 채택하지 않는다.

현장 적은 이름 없는 비신격 경계 방어체이며 셜커 기반 고정 수비 2체를 초기 실행안으로 제안한다. 기존 셜커가 있는 안전한 엔더 시티 가장자리도 사용할 수 있다. 새 주요 레이드 한 종으로 세지 않고 일반 탐사전으로 구성한다. 떠오름 때문에 즉시 공허 사망만 반복하는 자리는 피한다. 엔더맨 전체를 피난민의 변신이나 자동 적군으로 묶지 않는다.

여신은 가능한 제한 통신으로만 나온다. 몸은 여전히 원초 창구에 갇혀 있다. 핵은 기존 보관처에 둔 채 이미 확보된 관측 기록을 사용하며, 반응이 필요하면 원정 뒤 허락된 보관처에서 확인한다. 핵을 들고 뛰어넘는 배달을 필수로 하지 않는다.

### 실제 순서

1. **출발과 복귀 방법을 맞춘다.** 출발점에서 중간 피난 자리까지 실제 왕복한다. 비행자는 착지 가능한 부지를, 걷는 사람은 실제 이어진 발판을 확인한다. 고정 클래스나 특정 장비 지급을 열쇠로 쓰지 않는다.
2. **말단의 세 흔적을 읽는다.** C18 도식의 끝, C17에서 빠진 흐름, 오래된 칼날 흔적을 대조한다. 조사문은 새 흐름이 옛 원본을 감싼 것임을 보여 준다. 하나의 밝은 이펙트만으로 시간 순서를 단정하지 않는다.
3. **수비를 실제로 통과한다.** 셜커의 발사체를 엄폐로 끊고 접근해 전투한다. 다른 플레이어는 귀환 발판 확인을 병행할 수 있다. 신의 자동 개입으로 마지막 적을 지우지 않는다.
4. **원본을 꺼내 안전 자리로 돌아온다.** 회수자와 원본 위치를 기록하고, 현장에 남은 조각을 다른 사람에게 다시 지급하지 않는다. 귀환 확인이 되기 전 사망하면 원본의 실제 위치를 확인해 회수한다.
5. **축복과 남은 힘을 대조한다.** 동의한 플레이어 한 사람의 기존 축복 반응과 조각의 연결 흔적을 관찰한다. 모든 플레이어의 몸과 기억을 자동 검사하지 않는다. 이 대조는 동일 힘의 연속성을 더하지만 그 자체로 인물 동일성을 독립 확정하는 유일 증거가 아니다.
6. **여섯 원본의 현황을 확인한다.** 제1 C12, 제2 C10, 제3 C11, 제4 C09, 제5 C17, 제6 C19의 회수·보관·사용 허락을 목록으로 맞춘다. 이 장에서 한 칼로 붙이지 않는다. C20의 여섯 반응 검증을 준비한다.

### 선택과 반응

| 선택 범위 | 실제 실행 | 결과와 한계 |
|---|---|---|
| 기존 경로를 활용 | 이미 확인된 이동·귀환법으로 이번 조각 자리까지 연결 | 기초 제작을 반복하지 않음. 이번 미확인 구간은 직접 확인 |
| 다른 안전 접근을 연다 | 실제 옆 섬이나 고체 지형의 우회 확인 | 현재 탐사 선택이며 자동 새 포탈·순간이동은 없음 |
| 제한 통신에서 내부 지원 제안을 듣는다 | 실제 통신을 열고 청중과 제안을 기록 | C20에서 검토할 제안. 듣기만 해서 협력 확정·C25 내부 개방이 되지 않음 |
| 통신을 미루고 증거를 정리 | 여섯 원본 현황과 물리 대조를 완료 | C20 독립 검증 가능. 여신의 새 답변은 듣지 않은 상태 |

여신이 처음 정체 질문을 받으면 실제 확보 근거를 살피고 인정하거나 답변을 거절한 상태를 분명히 남긴다. 이미 유효한 고백을 들은 청중에게는 “내가 그 사람이라는 건 이제 알고 있지. 문제는 아직 이 안에 묶여 있다는 거야”처럼 이어 간다. “해제 약속이 끝났는데 왜 못 나왔어?”에는 자신이 아는 결속과 관리 지연을 설명하되 밖의 모든 결정을 목격한 것처럼 말하지 않는다. “내가 내부에서 틈을 열 수 있어. 네가 밖에서 할 일은 별도로 맞춰야 해”라는 제안은 원정 협력의 후보이며 실행 결과가 아니다.

“여섯 개면 자동 완성검이지?”에는 불가역 합일과 C24의 별도 선택을 안내한다. “이제 용사를 부를 수 있나?”에는 원본이 힘과 기억의 흔적이지 생명·인격 저장소가 아님을 말한다. “누가 주인공 할래?”라는 농담은 소유권 배정이나 엔딩 권한 합의가 아니다. 서두르면 조각 안전 회수와 현황 기록까지 마치고 통신을 뒤로 미룬다.

### 완료와 보상 및 회복

완료는 실제 말단 조사, 수비 통과, 제6조각 원본 회수와 현재 보관 확인이다. 제6조각의 역할 제안은 열린 경계의 버팀이다. 고유 원본은 세계에 한 개이며 개인 성장·전투 참여 기록은 실제 행동자에게만 남긴다. 개인 탐사 보급을 쓰려면 사전 제공된 재고 안에서 식량 8개 또는 화살 16개 한 묶음을 실제 참가자에게 1회 주는 실행안으로 둘 수 있다. 원본·새 신격·최종 접근권 독점은 개인 반복 보상이 아니다.

사망·접속 종료 시 실제 확보한 귀환점과 조사 결과는 유지한다. 미회수 조각은 그 자리에 있고, 회수된 조각은 실제 보관자·떨어진 위치를 추적한다. 접속자가 적다고 잃은 발판이 오프라인에 무너지거나 핵이 불안정해지지 않는다. 선택자가 없어도 허용된 공용 경로와 물건으로 나머지가 회수를 잇는다. 후발자는 현재 길을 확인하고 공개 조각 현황을 읽을 수 있지만 첫 회수·첫 전투를 받지 않는다.

### 호흡과 제작 점검

기록 중심 C18 뒤의 짧은 외곽 탐험과 실물 회수가 중심이다. 서로 다른 방법으로 돌아올 수 있게 길을 읽는 재미를 살린다. 핵 운반과 여섯 보관처 강제 순례는 넣지 않는다. 원본 회수와 안전 보관 확인이 끝점이다.

| 제작물 | 확인 사실 | 대안과 출시 전 확인 |
|---|---|---|
| 귀환 3자리·말단 조사 3개·수비 2체 제안 | 실제 왕복·전투·원본 접근 | 기존 엔더 지형으로 조정. 셜커 발사체·낙하·비행 접근 시험 |
| 제6조각 및 현황표 | 유일 원본과 고정 회수 사건 | 기존 고유 물건 관리와 승인 보관 연결 |
| 축복 대조·여신 제안 | 동의한 실제 관측자, 실제 청중, 기존 고백 여부 | 시청각 효과 없이 정확한 관측문. 불통이면 물리 조사만 진행 |

수용 시험: 원본을 핵이 생산했다고 설명하지 않는가, 여섯 개가 자동 합일되지 않는가, 여신의 조기 인정이 유지되는가, 핵을 들고 공허를 건너야만 완료되는 구조가 아닌가를 확인한다.

## C20 여신의 이름

### 목적과 시작 조건

**정확한 선행은 C13 그리고 C09·C10·C11·C12·C17·C19다.** 이름을 처음 맞히는 퀴즈가 아니다. 여신의 정체를 이미 알더라도, 현재 결속을 그녀의 설명에 종속되지 않고 판별하며 누구도 새 희생자로 삼지 않는 외부 접근 원리를 완성하는 사건이다.

시작 증거는 저주 조사 자료, 여섯 원본의 회수와 승인된 조사 접근, C18의 연속 기록이다. C18은 기존 진행상 이미 지난 사건이지만 새로운 별도 조건을 덧붙이지 않는다. 공용 완료는 독립 검증과 외부 접근 자료다. 여신과 협력할지, 사적 고백을 어디까지 공개할지는 다른 범위의 결정이다.

이미 완료된 세계에서는 “정체를 처음 듣는 모두의 회의”를 재연하지 않는다. 후발자는 공개 가능한 근거를 직접 읽고 현재 외부 경계 하나를 조사해 자기 이해를 확인한다. 비공개 이야기는 실제 전달받기 전 모른다.

### 장소와 등장 방식

기존 공용 보관처나 생활 거점의 안전한 작업 자리와, 가까운 기존 경계 흔적을 사용한다. 슬롯은 기록 대조 자리, 여섯 원본의 승인 관측 자리, 외부 연결 확인 자리, 선택 제한 통신 자리다. 새 의식실이나 여섯 명이 동시에 서는 발판을 만들지 않는다. 원본이 여러 허락된 보관처에 있으면 각 장소에서 순차 관측한 실제 결과를 공용 대조표로 잇는다. 원본을 한 사람이 몰수해 모을 필요가 없다.

여신은 유효한 제한 통신만 사용한다. 몸은 현재 Minecraft 세계의 기존 경계망에 결속된 원초 창구에 있고, 이 창구에 접근하려고 새 신화 고향 지도를 열지는 않는다. 제한 통신은 본체 이동과 다르다. 조각 기억 속 용사는 생전 자신이 겪은 장면의 흔적일 뿐 현재 질문에 답하는 유령이 아니다. 토트·엔키는 실제 접촉 가능한 작업 또는 출처 있는 기술 기록으로만 참여한다. 대조표를 읽는 주민이 이들의 지식 전체를 대변하지 않는다.

### 증거별로 증명하는 것

| 자료 | 실제 대조 행동 | 얻는 결론과 남기는 한계 |
|---|---|---|
| C12 생존 기록과 C18 명부·운송·결속 기록 | 같은 사람을 잇는 기존 식별 흔적·시간 순서·이동과 구호 행적을 줄로 잇는다 | 살아남은 연인이 전후 구호와 임시 결속까지 살았음. 이름 한 글자·같은 힘만으로 동일인을 단정하지 않음 |
| C12·C13의 용사가 겪은 기억 | 이름을 붙든 연인과 용사의 실제 전이 순간을 이미 확보한 흔적과 대조 | 생전 관계·구조 행위의 범위를 확인. 용사 사후의 신격 획득·관리 결정은 이 기억에서 나오지 않음 |
| 현재 축복과 현재 결속의 대응 | 동의한 축복 수혜자의 비활성 관측을 현재 결속 흔적과 연결 | 현재 꿈의 여신이 그 연속된 삶의 당사자라는 독립 근거를 완성. 다른 사람의 사적인 꿈 내용까지 열람하지 않음 |
| C13 저주 종결 흔적과 C18 전후 결속 | 서로 다른 시작·종료·적용 대상 표시를 실제 자료에 붙인다 | 옛 저주는 용사의 죽음과 함께 끝났고 현재 감금은 별개의 전후 결속. 반복 가능한 대속법이 아님 |
| 여섯 원본의 각기 다른 대응 | 각 원본을 승인 범위에서 조사해 경계 연결 하나씩을 기술 도식에 맞춘다 | 감금·흡수·지역 연결을 구분해 읽고 끊을 외부 경로. 모든 신의 본래 권능·봉인을 제어하는 열쇠가 아님 |

이 대조의 도식과 반응은 콘텐츠로 제작할 관측 결과다. 책을 상자에 넣거나 칼 여섯 개를 바닥에 놓는 것만으로 바닐라 게임이 신원을 증명한다고 주장하지 않는다.

### 플레이 순서

1. **청중의 출발점을 확인한다.** 실제 고백을 들은 사람, 다른 사람에게 보고만 받은 사람, 공개 증거를 처음 읽는 사람을 구별한다. 이미 아는 사람에게 거짓 부정이나 같은 반전을 강요하지 않는다. 아직 모르는 사람에게 남의 사적인 회상 전문을 자동 배포하지 않는다.
2. **삶의 연속성을 맞춘다.** 위 표의 첫 세 자료를 대조한다. 결론을 이미 아는 사람도 근거의 빈칸을 확인할 수 있고, 미열람자가 직접 판단할 자료가 남는다. 이름과 연대를 임의 암호 퍼즐로 숨기지 않는다.
3. **두 구속을 나눈다.** 저주 종결과 전후 결속의 시작을 다른 줄에 적고, 해제 조항이 이행되지 않은 연결을 표시한다. “새 사람을 고정점으로 바치면 된다”는 잘못된 해법은 자료상 조건을 보여 주며 배제한다.
4. **여섯 원본의 대응을 확인한다.** 제4조각으로 연결점을 식별하고, 제1조각으로 봉인 흔적을 읽으며, 나머지 원본의 역할을 도식에 맞춘다. 기능은 기존 제안 범위다. 제2조각은 침식의 버팀, 제3조각은 흐름 전환, 제5조각은 강제 맹약 대응, 제6조각은 열린 경계의 버팀이다. 소유자 여섯 명 동시 참석은 필요 없다.
5. **외부의 한 구간을 직접 확인한다.** C18 설계와 맞는 기존 경계 말단에 가서 감금 연결·흡수 연결·지역 연결의 서로 다른 관측을 확인한다. 여기서는 읽기와 접근 경로 확인만 한다. 휴면 핵을 가동하거나 원초 창구 전체를 분리하지 않는다.
6. **여신의 제안을 검토한다.** 통신이 가능하면 아래 조건을 실제로 주고받는다. 불통이면 독립 접근 자료를 완성하고 여신의 답변을 ‘미수신’으로 남긴다. 대답을 기다려야만 C21로 갈 수 있게 하지 않는다.
7. **외부 접근서와 공유 발췌를 완성한다.** 누가 외부 결속을 다루고, 핵 방어가 깨어날 위험을 어떻게 알리며, 어떤 결과가 C25·C26에 남는지 적는다. 공개 가능한 기술 근거와 사적인 기억의 열람 범위를 분리한다.

### 협력 선택

| 선택 | 명시적 확인과 실제 실행 | 얻는 것과 남는 부담 |
|---|---|---|
| 조건부 협력 | 내부 통제 접속과 여신 개인 의지를 분리하고, 원정 위험을 실제 참가자에게 알리며, 그녀에게 준비 과정의 발언권을 보장하되 최종 결정 독점은 주지 않는 조건을 제시한다. 여신의 실제 수락을 받는다 | C25 내부 안전 통로 지원 약속. 외부 결속 해제는 여전히 플레이어 몫. 지금 감금·방어가 해제된 것은 아님 |
| 독립 접근 | 외부 기술 기록으로 접근하고 그 물자·외곽 방어를 스스로 맡겠다고 범위를 정한다 | 여신의 해석·동의를 기다리지 않는 접근 자료. 내부 지원을 받은 것으로 계산하지 않음 |
| 조건 제안 뒤 답변 미수신 | 제안 전달 여부와 미응답을 남기고 외부 경로 준비를 진행한다 | C20의 독립 검증은 완료 가능. 실제 수락 전에는 조건부 협력 보상이 없음 |

이 선택은 공용 원정의 접근 방식을 정하며 누구의 신앙·개인 감정까지 통일하지 않는다. 해방 지원과 장치 미래의 권한을 분리한다. 여신의 반대 때문에 기존 축복·장비·신격을 회수하지 않는다. 실제 수락한 지원을 변경할 필요가 생기면 남은 제공 범위를 다시 확인하며, 최초 선택자의 부재를 협력 취소나 개인 MAIN 양도로 해석하지 않는다.

### 여신과 조력자의 지식

- **여신의 확인된 자기 지식:** 자신은 살아남은 연인이며 자신의 업으로 신격을 얻었다. 용사는 실제 죽었고 되살릴 의도가 없다. 임시 결속과 현재 자신의 접속을 안다. 밖의 모든 피해·현재 작전은 전해 들은 범위만 안다.
- **여신의 믿음과 요구:** 중앙 흡수가 남으면 또 생명을 붙잡을 수 있다고 두려워한다. 해방과 다음 희생의 중단을 원한다. 그 두려움이 모든 장치의 객관적 불가능성을 증명하지는 않는다.
- **여신이 거절할 수 있는 공개:** 개인의 회상 전문·아직 말할 준비가 없는 감정. 이미 인정한 사실을 “모른다”로 바꾸지는 않는다. 사실 거부와 공개 거절을 구분한다.
- **토트:** 읽은 기록의 연속성과 서명·보존 상태를 안다. 현재 통신의 청중이 아니면 여신의 새 답변을 모른다.
- **엔키:** 확인된 외부 설계와 실제 관측한 연결을 안다. 기록 속 구호 담당자를 알더라도 꿈의 여신과 동일한 현재 존재라는 검증은 실제 근거를 받은 범위에서 갱신한다.
- **조각 기억:** 용사의 생전 경험만 보여 준다. 스스로 모르던 가해자의 마음이나 사후 역사를 답하지 않는다.

짧은 대사 제안:

- 처음 확인된 청중에게 여신: “그가 남긴 힘을 받은 사람은 나야. 그 뒤에 사람들을 데려오며 쌓은 삶도 내 것이었고.”
- 이미 아는 청중에게 여신: “이름은 이미 말했지. 이제 내가 무엇을 숨겼고, 너희가 무엇을 맡을지 이야기하자.”
- 보호 기능을 실제 숨겼던 경로: “문이 막힌 이유는 말했고, 그 문이 막아 주던 위험은 먼저 말하지 않았어. 그 선택은 내 책임이야.”
- 일찍 위험을 밝혔던 경로: “그 위험은 전에 함께 확인했어. 오늘 새로 정할 건 내 접속과 너희 접근을 어떻게 나눌지야.”
- 독립 접근을 고르면: “내 도움이 없어도 나갈 길을 찾겠다는 거구나. 내 말을 들을 자리는 남겨 줬으면 해.” 상대가 그 발언권까지 거절했다고 지어내지 않는다.
- 토트: “답을 안다는 것과 다른 사람도 확인할 근거를 갖는 것은 다른 일이네.”

“우리도 당신처럼 희생하면 돼?”에는 대속 재연이 필요 없고 C20에서 찾은 외부 분리가 그 대안임을 답한다. “내가 용사 환생?”은 부정하며 혈통 조건을 만들지 않는다. 농담으로 “그럼 이름표만 바꾸자”라고 해도 개인의 정체 공개 동의나 장치 통제가 성립하지 않는다. 급하면 기술 대조와 접근서만 먼저 마치고 사적인 이야기는 유효한 다음 통신으로 남긴다.

### 완료와 회복

완료 증거는 **삶의 연속성 대조, 저주와 전후 결속 분리, 여섯 원본 대응, 실제 외부 말단 확인, 외부 접근서**다. 통신 수락·사과·용서·사적 회상의 공개는 필수 완료 조건이 아니다. 공용 보상은 C21의 판단 근거와 C25 외부 접근의 준비 지식, T04의 기존 C20 선행 충족이다. 최종전 승리·신들 지휘권·모든 지역 안정은 주지 않는다.

접속 종료 시 원본의 위치와 검증한 항목을 보존하고, 허락 없는 개인 물건의 이동은 중단한다. 고백 도중 일부만 들었다면 실제 받은 범위만 남긴다. 후발자는 공개 기술 자료와 현재 관측으로 이해를 얻으며 조기 고백의 청중인 척하지 않는다. 완료를 반복해 조각·핵·개인 MAIN을 추가로 얻지 않는다.

### 호흡과 제작 점검

C19의 실물 회수 뒤, 여섯 조각이 왜 필요한지 직접 확인하고 여신에게 조건을 제시하는 전환점이다. 장문의 고백을 끝까지 들어야 조작이 풀리는 장면은 쓰지 않는다. 기술 대조와 한 외부 말단 확인이 끝점이다.

| 제작물 | 안정적으로 확인할 사실 | 대안과 출시 전 확인 |
|---|---|---|
| 연속성·두 구속·여섯 대응 도식 | 실제 읽은 근거, 원본 조사, 외부 말단 | 책과 현장 조사문으로 가능. C12·C13·C18 증거 문구 교차 검토 |
| 제한 통신의 청중별 첫말 | 조기 고백·보고·독립 검증의 구분 | 불통이면 기술 검증 지속. 본체·사적 기억 자동 전파 금지 |
| 협력 조건과 외부 접근서 | 실제 여신 수락 여부, 맡은 일, 미완료 실행 | 서면 확인 가능. C25는 약속이 아니라 실제 분리·접근을 다시 검증 |

수용 시험: 정체를 이미 아는 사람에게도 새 접근 성과가 있는가, 직접 답변 없이도 증거 검증이 되는가, 사적 고백이 C21 공개본에 자동 들어가지 않는가, 합일·핵 가동·여신 해방이 여기서 미리 완료되지 않는가를 확인한다.

## C21 신들도 대답해야 하는 회의

### 목적과 시작 조건

**정확한 선행은 C20이다.** 독립 근거를 바탕으로 과거 책임과 현재 도움의 조건을 나누고, C22에서 시험할 방안에 필요한 실제 협력·불참·빈자리를 남긴다. 전 신화가 한 방에 모여 고개를 숙이는 장면이 아니다.

공용 결과는 심의 순서, 실제 공개한 증거, 실제 받은 입장, 한정 지원과 미완료 책임 의제다. 개인의 사적 증언·지지·용서는 별도로 남긴다. 이미 회의가 끝난 세계에서는 새 참가자를 과거 투표자로 적지 않는다. 공개 회의록을 읽고, 아직 답이 없는 질문을 자기 이름으로 제시하거나 현재 준비에 참여할 수 있다.

### 회의 자리와 전달 방식

기존 강가 거점이나 주점의 공용 자리를 사용한다. 슬롯은 공개 기술 자료, 응답 보관, 지원 배정표, 현장 연결 지도다. 실제 접견 가능한 NPC만 그 자리에 온다. 다른 곳에서 자기 일을 하는 존재는 유효한 제한 전달·서명 응답·현재 공개 자료로 참여할 수 있다. 아무 접촉도 없는 존재는 “미수신/불참”으로 적는다. 신이 불참했다고 모두 참석할 때까지 세계 진행을 멈추지 않는다. 기존에 자료를 받은 사람이 답변을 거절하면 그 거절만 남긴다. 전달 기록이 없는 발언을 채워 넣지 않는다.

발언을 전하는 주민은 받은 문구와 출처까지만 읽는다. 모든 신의 인격을 재현하는 대리 화자를 만들지 않는다. 천군 강경파의 의견은 그 발언자들의 의견이며 천마의 현재 명령이 아니다. 루브라스·여우신·가이아·닉스는 실제 위치·봉인·접근·전달 조건이 맞을 때만 추가한다. C21은 이 인물들의 등급별 첫 조우 해금이 아니며, 일찍 만났다면 기존 관계와 실제 받은 자료를 이어 간다. 아직 충족하지 못한 봉인·접근 조건은 회의 초대만으로 생략하지 않는다. 이들의 부재를 완료 결격으로 두지 않는다.

### 최소로 진행할 의제

1. **자료의 공개 범위를 정한다.** C13의 실제 공개/제한 보관, C18의 원문, C20 기술 근거를 확인한다. 이미 공개 가능한 독립 기술·범행 증거를 회의 자료로 묶는다. 사적인 고백·회상은 당사자의 공개 허락 없이는 넣지 않는다. 허락을 받지 못해도 독립 근거로 책임을 물을 수 있다.
2. **심의 우선순위를 고른다.** 아래 두 선택의 차이를 알리고 현재 제공 가능한 공용 회의 자리의 순서를 확정한다. 이것이 다른 플레이어의 질문과 독립 조사를 금지하는 명령은 아니다.
3. **근거와 답변을 실제 연결한다.** 조사한 사람이 원문 한 부분과 현장 사실 하나를 제시한다. 유효한 수신 경로에만 보낸다. 받은 답은 직접 인정·부인·정당화·응답 거절로 구분하고, 답이 없으면 그대로 남긴다. 상대의 사과를 완료 열쇠로 요구하지 않는다.
4. **현재 도움의 조건을 검토한다.** 실제 제안된 항로·관측·민간 보급·외곽 호위 중 사용할 것을 범위별로 고른다. 인물·구간·제공 물자·중단 조건을 한 줄씩 적는다. 감독 요구를 거부했다면 그 감독에 딸린 미제공 지원은 배정하지 않는다.
5. **C16 재심 약속을 처리한다.** 유효하게 받은 아스모데우스의 의견을 실제 심의 당사자에게 전달하거나 공개 가능 범위에서 기록하고 검토 자리를 제공한다. 결과가 그의 뜻과 달라도 발언 자체를 삭제하지 않는다. 당사자 부재로 추가 답변을 받지 못하면 질문을 남기며 다른 의제를 계속한다.
6. **C22의 실제 빈자리를 정한다.** 해상 보증이 없으면 독립 항로, 엔릴 보급이 없으면 허용 공용 물자와 자발적 호위, 내부 지원이 없으면 외부 접근 준비를 사용할 것이라고 적는다. 이미 없는 지원을 말로 되살리지 않는다.
7. **열린 쟁점을 남기고 마친다.** 책임 심의가 끝나지 않았다면 C28에 이어질 질문과 피해 회복 요구를 기록한다. 이 문서는 면죄·항복·천마 해방 승인서가 아니다.

### 심의 우선순위의 선택

| 선택과 영향 범위 | 명시적 확정과 실행 | 공용 결과와 남은 의제 |
|---|---|---|
| 저주 책임을 먼저 공개 심의 | “공개 가능한 범행 증거를 먼저 다루고, 응답하지 않은 당사자도 그대로 적는다”는 순서를 확정. 실제 자료 공개와 수신 확인 | 공개 조사와 피해자의 발언을 우선. 지원자가 조건을 철회했다면 해당 지원만 빠지고 독립 준비로 보완. 불참·부인은 남음 |
| 원정과 민간 보호의 한정 협력 먼저 | “안전한 통행과 제공할 지원만 먼저 합의하고 책임 문제는 면제하지 않는다”는 범위를 확정. 실제 조건을 검토하고 받은 지원만 배정 | 당장 사용할 수 있는 도움을 확인. 미완료 책임과 ‘협력이 면죄가 아님’을 회의록에 명시하고 C28에 계속 |
| 공개를 확대하지 않고 확인을 보류 | 자기 사적 자료의 공개를 거절하거나 개인 질문을 미룬다 | 타인의 공개 가능한 독립 근거 심의를 막지 않음. 사적 기억은 유지되고 공용 준비는 진행 가능 |

“책임부터 묻자”는 말만으로 부재한 세 신이 자동 적대하거나 모든 지원이 박탈되지는 않는다. 변화는 실제 증거를 수신한 당사자의 유효한 답과 이미 알려진 조건으로 정한다. 반대로 도움을 받았다는 이유로 과거 강제를 정당한 계약으로 바꾸지 않는다.

### 실제 응답을 작성할 기준

다음은 해당 인물에게 자료가 실제 도착했고 응답 가능한 경우의 짧은 기본 응답안이다. 부재한 인물의 가상 출석 대본이 아니다.

| 화자 | 알고 있는 것과 자기 판단 | 짧은 응답과 수락하지 않는 범위 |
|---|---|---|
| 오딘 | 자기 범행, 자기 관측망, 실제 받은 핵·조각 자료. 미래 위험 판단은 믿음과 예측 | “내가 막은 균열은 아직 남아 있다. 네가 내놓은 근거와 내가 두려워한 파국을 함께 보겠다. 무제한 개방에는 동의하지 않는다.” 인정·정당화·답변 거절은 실제 응답대로 남기며 사과를 보장하지 않음. 감독권 요구를 거부해도 자기 관측까지 플레이어 소유가 되지 않음 |
| 바루나 | 과거 강제 가담, 자기가 구한 배, 실제 받은 항로·위험 화물 정보 | “지금의 보증도 지켜야 한다. 과거의 강제를 같은 약속이라 부를 수 있느냐는 질문은 피하지 않겠다.” 보증 의무 삭제·미참여 항로 보호는 거절 |
| 엔릴 | 자기 명령·범행, 실제 받은 민간 피해와 변경 | “민간 통행과 무장 회랑은 나누어 말하라. 내 지원도 그 선을 넘지 않는다.” 기록의 권위를 다툴 수 있고 무제한 군수 개방에 동의하지 않음 |
| 제우스 | 자기 세력의 현재 행동과 실제 받은 위험·피난 자료 | “열리는 문 너머의 충돌은 누가 막지?” 실제 민간 보호·무기 운송 제한에 합의하면 외곽 분담 협의 가능. 연합 전체의 사죄와 자신의 무조건 복종은 거절 |
| 엔키 | 자신이 만든 연결과 현재 수리·관측 | “사람을 바꾸어 끼우는 수리는 내놓지 않겠다.” 실제 설계 제공과 안전 조사에 참여할 수 있으나 최종전 승리를 보장하지 않음 |
| 토트 | 실제 보존한 원문과 전달받은 대조 | “내 이름도 기록에서 지우지 않겠다. 없는 동의도 더하지 않겠다.” 공개할 원본과 사적 기록의 권리를 구별 |
| 여신 | 자기 경험·의도·전달받은 외부 근거 | “누구든 붙잡아 두는 방식이 다시 남는 건 원하지 않아.” 회의에서 자기 해방을 주장할 수 있으나 다른 사람의 미래를 독점하지 않음 |
| 아서 | 실제 지킨 피난로·받은 계획, 자기 약속 | “그 안으로 들어간 사람들이 돌아올 자리는 어디지?” 여성 비신격 인간의 의견. 다른 피난 약속·수용 한계가 있으면 원정 호위를 거절할 수 있음 |

| 천군의 발언자 | 자신의 경험과 자료 | “그 장치를 남기고 누가 안전하다고 말할 수 있나?” 천마·천군 전원 명의의 명령으로 기록하지 않음 |

선택 화자의 경우 여우신은 공개 가능한 천군 의견과 현재 귀환 신호 범위만, 루브라스는 직접 겪고 실제 전달받은 사실만 말한다. 루브라스는 거짓말할 수 없으나 계약상 공개 거절·침묵·모름을 구별할 수 있다. 가이아는 실제 땅의 훼손, 닉스는 실제 피난자의 감시·은폐 범위를 따진다. 가이아의 응답을 한 문화권 전체의 조우·진입 허가로 쓰지 않는다. 전쟁 전체나 여신의 비공개 고백을 자동으로 알지 않는다.

“모두 유죄에 손 들어”라는 말로 신의 권능을 빼앗지 않는다. “사과 안 하면 통과 못 해”에는 공개 근거와 민간 통행을 사과 요구와 분리한다. 앞서 신들이 인정한 사실을 다시 모르는 척하지 않으며, 플레이어가 추측만 한 내용은 근거를 묻는다. 농담으로 신들을 ‘호위 알바’라 불러도 계약은 생기지 않는다. 급하면 실제 자료 1묶음, 현재 답변·미수신 상태, 지원 배정과 책임 잔여 의제를 확정하고 선택 접견은 나중에 이어 간다.

### 완료와 보상 및 회복

완료는 **공개 범위, 심의 우선순위, 실제 근거 제시/전달, 수신 답 또는 불참 기록, 허락된 지원표와 독립 대안**을 갖춘 때다. 모든 신의 출석·사과·굴복·개인 MAIN 소유는 필요 없다. 공용 보상은 C22 시험 준비의 정당한 근거와 실제 협력 범위다. 신격·민심·NPC 복종을 자동 보상으로 지급하지 않는다.

접속 종료 중 확정하지 않은 제안은 미확정이다. 확정된 해당 지원만 보존하고 소유자의 동의 없는 새 재고는 사용하지 않는다. 실제 서명한 NPC가 다른 당사자와 맺은 약속까지 무효로 만들지 않는다. 부재 중 책임 심의가 실패하거나 주민이 처벌받지 않는다. 후발자는 공개본을 읽고 현행 의제에 합류하며, 첫 선택자의 개인 MAIN을 대신 소유하지 않는다.

### 호흡과 제작 점검

정답을 말한 뒤 박수를 받는 장면이 아니라 다른 목적을 가진 존재의 실제 제안을 비교하는 장면이다. 필수 동선은 공용 자리 하나와 이미 유효한 전달 경로다. 선택 출연자 전원을 찾아다니는 외교 수집 과제를 만들지 않는다. C22에서 쓸 현재 조건과 빈자리를 알면 충분하다.

| 제작물 | 확인 사실 | 대안과 출시 전 확인 |
|---|---|---|
| 증거 묶음·공개 범위·회의록 | 실제 공개 자료와 청중·수신자 | 책·서면으로 가능. 사적 기억이 섞이지 않는지 검토 |
| 실제 응답과 지원표 | 접촉 모드, 불참/거절, 구간·물자·허용 권한 | 불통은 미수신으로 기록하고 주민 독립 준비로 진행 |
| C22 세 지역 지도 | C10·C11·C14·C17 선택과 현재 허락 | 미참여 신의 보호를 지도로 지어내지 않음 |

수용 시험: 세 신 모두 불참해도 공용 준비를 마칠 수 있는가, 도움과 면죄가 구분되는가, 공개 자료가 모든 인물에게 자동 학습되지 않는가, 회의 선택이 정신 지배·추가 봉인 해방·엔딩 투표로 바뀌지 않는가를 확인한다.

## C22 세 지역에 먼저 적용하다

### 목적과 시작 조건

**정확한 선행은 C21이다.** 세 결말의 차이를 같은 귀환과 탐험의 실제 결과로 경험하고, 마지막 원정에 사용할 준비안을 남긴다. 휴면 핵은 깨우지 않고, 아직 태어나지 않은 수호자의 동의·성격·평생 협조를 시험하지 않는다. 여기서 다루는 것은 기존 지역 분기 장치의 소규모 대리 시험이다. 큰 전환망에 최종 방식을 설치하고 능동 핵 방어를 제압하는 일은 C25·C26에 남는다.

**준비안은 각각 별도 결과다.** 열린 협약·새 수호자·주인 없는 경계 중 한 안을 실제로 마치면 C23·C24로 갈 수 있다. 다른 안은 원하는 때 추가 준비한다. C27에서 고를 수 있는 것은 그때 실제 준비가 끝난 해당 안이며, 한 안 완료를 세 안 완료로 바꾸지 않는다. C22의 준비는 최종 엔딩 선택이나 전원 동의가 아니다.

### 한 번의 귀환 동선과 재사용

새 실행안은 **강가에서 모여 기존 해안길과 네더 귀환 출구의 현재 상태를 잇고, 돌아온 사람을 같은 세계의 강가 생활권에서 맞이하는 한 묶음의 활동**이다. 회복할 연결은 출신 문화권으로 나뉜 신규 차원이 아니라 가족의 마을, 동료의 작업장, 선원의 항구처럼 이미 지도에 있는 생활 목적지다. 플레이어가 모든 구간을 한 번에 전부 걸어야 하는 호위 행렬은 아니다. 이미 C10·C11·C14·C17에서 확인한 현재 유효 경로는 그대로 재사용하고, 현행 통행과 충돌하는 새 지점만 확인한다. 친구들이 서로 다른 시간에 맡은 구간도 실제 결과로 합칠 수 있다.

각 준비안은 아래의 공통 경로 확인과 **그 안의 차이를 보여 주는 실제 시험 구간 1곳 이상**을 갖추면 된다. 이 명세의 권장 배치는 협약안은 강가의 합류와 해안 화물 조정, 수호안은 해안의 크기 제한·철수 확인, 무주안은 네더 출구와 연결된 작은 옆길이다. 실제 지형상 해안 대신 강가, 네더 대신 이미 확보한 지상 회랑에서 같은 제한을 입증해도 되며, 시험하지 않은 지역까지 같은 보호를 얻었다고 쓰지 않는다. 세 지역을 세 방식으로 아홉 번 순회하는 것은 완료 조건이 아니다.

추가 안을 준비할 때는 이미 확인된 귀환점·당사자·짐·이동 구간을 다시 수집하지 않는다. 다른 결과를 보기 위해 이미 도착한 사람을 같은 위험에 다시 집어넣지 않으며, 동의한 새 짧은 이동이나 빈 시험 구간의 실제 전환으로 그 안의 고유 관측만 보충한다.

| 슬롯 | 기존 부지 | 실제 하는 일과 대체 |
|---|---|---|

| 해안 분기점 | C10에서 쓴 항로의 출발·복귀 지점 | 현재 보증 조건 또는 독립 암초길, 큰 통행과 작은 통행을 구별. 실제 큰 선박 모델이 없으면 통행 규모를 적은 현장 화물 표지와 실제 작은 보트·육로를 대조 |
| 네더 귀환 출구 | C17에서 민간 구속을 끝낸 출구와 안전한 외곽 | 제한 유지/연결 절단 결과를 그대로 사용. C17 수비를 재생성하지 않고 현행 출구와 실제 남은 위협만 확인 |
| 지역 대리 시험점 | 위 세 구간 중 이미 존재하는 분기 장치의 접근 가능한 외곽 | 전환망 전체와 분리된 해당 시험 구간만 유입·잔류 완충·분리 상태를 바꾼다. 실제 장치가 아직 없으면 조사 소품과 승인된 장면 상태로 제작하되 구현 완료라고 말하지 않음 |
| 퇴로와 낮은 통행점 | 기존 좁은 물길·육로·낮은 선반 중 안전 왕복 가능한 구간 | 모든 안에서 실제 돌아올 장소. 낙하나 용암 점프를 피할 수 없는 부지는 제외 |

강가의 맞이하는 주민, C10의 선원, C16·C17의 귀환자는 기존 주민에게 배정하는 작은 역할이다. 귀환·짐 제공·호위는 당사자의 의사를 확인한다. 싫다는 사람을 운송 목표물로 잡지 않는다. 이름 없는 주민을 새 고유 신격이나 개인 MAIN으로 만들지 않는다.

### 공통 경로 확인

1. **당사자와 실제 목적을 고른다.** 실행안은 서로 다른 생활권의 귀환자 2명과 남아서 맞을 주민 1명이다. 한 사람은 강가 가족에게 씨앗을, 다른 사람은 기존 광맥 작업장의 동료에게 도구를 보내려는 식으로 C16부터 받은 사정과 실제 지도 목적지를 잇는다. 가족·동료는 기존 주민 관계 안에서 표현하며 새로운 필수 주요 인물을 만들지 않는다. 수량은 장면 제안이며 동시 접속 인원 요구가 아니다. 본인이 원하면 짐만 보내거나 현재 거처에 남을 수 있고, 그 선택을 실패로 쓰지 않는다.
2. **허락된 물자만 표시한다.** 예시 화물은 밀 8개 한 묶음, 씨앗 8개 한 묶음, 돌 도구 2개 한 묶음이다. 실제 품목·주인·목적지를 표시한다. 공용 안전 몫의 시작안은 식량 16개, 횃불 16개, 길 보수용 일반 고체 블록 32개다. 이미 사용 가능한 안전길이면 블록을 억지로 소모하지 않는다. 수량은 밸런스 확정이 아니라 무엇을 남기고 쓸지 보여 줄 소품·보급안이다.
3. **현재 경로 조건을 대조한다.** 아래 표에서 이미 확인한 사항을 재사용하고 변화한 지점만 조사한다. 개인 소유의 물건과 사적인 항로 정보는 기존 허락 범위 이상으로 공개하지 않는다. 지역 대리 장치 역시 C21에서 시험 사용을 허락받은 현장 또는 주민·플레이어가 정당하게 관리하는 구간만 쓴다. 다른 소유자의 장치를 허락 없이 분리하지 않는다. 허락이 없는 부지는 독립 관리 가능한 기존 구간으로 바꾼다.
4. **이번 공용 지원의 사용을 확정한다.** 첫 유효 선택은 이번 행렬의 실제 제공된 보급·NPC 지원을 어떤 시험에 쓸지만 정한다. 다른 플레이어가 다른 재고와 자발적 당사자로 다른 준비안을 병행하는 것은 막지 않는다.
5. **선택한 아래 카드의 실제 행동을 마친다.** 말로 비용을 이해했다고만 답해서 완료하지 않는다. 귀환·전환·철수·방어 중 그 안의 차이가 현장에서 확인되어야 한다.
6. **안별 결과를 인계한다.** 실제 구간, 행동, 비용, 지원자/불참자, 사용·남은 물자, 확인자, 해당 안에서 남는 한계를 남긴다. 한 안 이상 끝나면 다음 장으로 안내한다.

### 화자별 지식과 태도

- **헤르메스:** 자신의 장부·실제 걸린 운송·받은 지도만 안다. 세 길을 한 지도로 잇고 싶어 빠른 운송을 제안하지만 모든 짐을 실을 수 없다는 현재 조건을 숨기지 않는다. “한 줄로 그리면 빠르겠지. 그런데 이 짐까지 그 선에 들어가는지는 봐야겠어.” 부재하면 이미 실제 제출한 운송안만 읽는다.
- **선원:** 자기 배와 항로·C10의 실제 약속을 안다. 큰 배로 돌아가고 싶다. “작은 배로 나누면 갈 수는 있겠죠. 그래도 내 배가 못 가는 건 못 가는 거예요.” 무한 항해 지식과 다른 바다의 보증은 없다.
- **네더 귀환자:** 직접 막혔던 길과 현행 출구를 안다. 짐 검사보다 집으로 가는 첫 굽이를 보고 싶다. “오늘은 누가 날 분류하는지보다, 저 굽이가 어디로 가는지 먼저 보고 싶어요.” 검증되지 않은 모든 옆길을 안전하다 부르지 않는다.
- **맞이하는 주민:** 실제 남을 자리·손님 수·공용 재고만 안다. “떠나는 사람은 정했나요? 여기 남을 식량도 같이 세어 봐요.” 없는 재고를 신의 선물로 채우지 않는다.
- **단군:** 실제 전달받은 주민의 정착·맞이할 사정을 바탕으로 말한다. “돌아오는 길 끝에도 누군가는 있어야 하네.” 직접 접촉이 없다면 주민의 일 자체로 같은 준비를 한다.
- **헬리오스:** C07에서 직접 보거나 출처를 확인해 받은 일조·작물 관측과 이번에 실제 받은 수확·운송 보고만 안다. “내가 본 빛의 범위와 지금 실을 수확은 구분해 적자. 이 짐을 보낼지는 기른 사람이 정해야지.” 관측하지 않은 밭의 회복이나 전 구간 안전을 보증하지 않고, 씨앗 제공·운송 허락을 주민 대신 정하지 않는다.
- **케찰코아틀:** 실제 확인한 바람·가벼운 경로와 받은 계획을 말한다. “덜 싣는 일이 더 멀리 가는 길일 때도 있지.” 만능 비행·무제한 수송을 주지 않는다.
- **아서·롤랑:** 실제 답사와 자기 약속 범위에서 돌아올 길을 제안한다. 아서: “지킬 곳을 줄인다면, 남은 사람이 갈 곳도 먼저 정해 둬.” 롤랑: “앞에서 길을 찾는 일과 뒤에서 사람을 기다리는 일, 둘 다 필요하군.” 플레이어의 전투를 대신 마치지 않는다.
- **백호·주작:** 이미 확인한 통행 약속과 실제 접촉에서 받은 현재 계획만 안다. 백호: “옛 약속으로 오늘 없는 다리를 만들 수는 없지.” 주작: “돌아올 자리를 먼저 보자.” 실제 지원이 없으면 옛 기록이 현재 호위를 보장하지 않는다.
- **선택 출연하는 여우신·루브라스·가이아·닉스:** 이전 만남이나 앞 사건에서 실제 확립한 현재 접촉·지원 범위만 사용한다. 불씨·용의 계약·땅의 회복·피난 은폐는 선택 도움이며 추가 준비안 열쇠가 아니다. 사적 회상과 천마의 의사를 대신 공개하지 않는다.

같은 지도를 본 인물이 여신의 사적 정체나 모든 원정 대화를 함께 아는 것은 아니다. C22의 생활·물자 정보만 전달받은 인물에게는 그 범위의 말만 준다.

### C22 열린 협약 준비 카드

#### 시작과 핵심 행동

공통 경로 확인과 C21의 실제 지원 조건이 시작 자료다. 강가 합류점과 해안 화물 분기점에서 **서로 다른 출신의 사람을 한 귀환에 함께 받아들이면서 비상 여유를 남기는 것**이 핵심이다. 현재 도착한 사람들이 출신별로 다시 격리되지 않는 모습을 완료 목격으로 삼는다.

1. 헤르메스의 실제 운송안 또는 선원의 독립 운송안에 화물 3묶음과 동의한 귀환자들을 올려 본다. 장면상의 운송 한도를 명시해 모두의 큰 짐과 무기 화물을 한 번에 넣을 수 없다는 문제를 보여 준다. 이 한도는 실제 보트 인벤토리 규칙을 바꾼다는 뜻이 아니다.
2. 다음 두 실행 중 하나를 고른다. **허락받은 무기 화물 일부를 이번 운송에서 제외하고 비상 여유를 남기거나**, 해당 운송에 독점 후원이 실제 걸려 있다면 **그 후원을 쓰지 않고 얕은 물길과 육로로 나누어 간다**. 남의 무기를 몰수하지 않는다. 화물 주인이 제외에 동의하지 않으면 그 물건은 별도 보관·별도 운송하고 동의한 사람들로 행렬을 진행한다. 독점 후원이 처음부터 없으면 존재하지 않는 혜택을 포기했다고 기록하지 않는다.
3. 플레이어가 선택한 실제 선행 구간을 답사하고 돌아올 일행을 호위한다. 보증 항로는 C10의 검사 조건을 지키고, 독립 항로는 직접 마련한 물자와 길을 쓴다. 네더에서 이미 확보된 민간 통행은 C17 결과 그대로 이용한다.
4. 강가에 도착한 각 주인이 자기 짐을 내려놓는다. 실행안의 밀·씨앗·도구를 원래 받기로 한 사람에게 실제 인계하고, 허락된 비상 몫은 사용하지 않고 남은 상태를 확인한다.
5. 실제 참여 당사자에게 **공용 비축의 용도, 통행 조건, 이의 제기와 탈퇴 가능 범위**를 읽어 준다. 예시 약속은 “비상 귀환용 물자는 일반 군수 수송에 돌리지 않는다”, “새 부담을 지우기 전 당사자에게 묻는다”, “탈퇴해도 이미 통과 중인 사람의 귀환은 마친다”다. 각 당사자의 실제 동의만 기록한다. 협약 밖 신과 지역의 보증을 붙이지 않는다.

#### 선택과 결과

| 실행 | 실제 확인 | 얻는 것과 잃는 것 |
|---|---|---|
| 허락된 화물을 줄여 같은 행렬 유지 | 제외한 물건의 주인·보관처, 남은 비상 여유, 실제 공동 귀환 | 서로 다른 주민이 같은 길에서 보호. 이번 최대 운송량과 해당 무기 운송의 편의를 포기 |
| 독점 후원 없이 분리 운송 | 포기한 실제 후원, 얕은 물길·육로의 실제 답사와 도착 | 독점 조건을 피하고 독립 경로 사용. 해당 후원의 빠른 운송·호위는 없음 |

확정 질문은 “이번 공용 비상 몫을 남기고, 허락된 이 화물만 내려서 이 행렬을 보낼까?”처럼 실제 대상에 한정한다. 개인이 참여하지 않아도 이미 동의한 다른 사람이 갈 수 있다. 최종 열린 협약 엔딩의 전원 동의로 읽지 않는다.

선원의 불만은 남겨 둔다. “다 같이 갔으니 최대 화물도 다음부터 무료지?”에는 비상 여유 때문에 그 편의를 포기했다고 답한다. “내 깃발도 꽂자”는 농담은 소유권·대표권이 아니다. 급하면 자기 짐 인계와 안전 몫 확인까지 하고 추가 인사를 생략할 수 있다.

#### 완료와 보상 및 복구

**완료 증거는 실제 공동 귀환, 명시한 화물/후원 비용, 남긴 비상 몫, 실제 참여자의 한정 약속**이다. 결과는 ‘열린 협약 준비 완료’이며 이 시험 구간과 참여 당사자에 한정된다. 도착한 물건은 원래 주인·수취인 소유, 공용 비축은 허락된 용도에만 쓴다. 독점 장비나 핵은 지급하지 않는다.

호위 실패·사망·접속 종료 때는 도착한 사람과 짐을 유지하고 미도착 구간만 보완한다. 실제 잃은 소지품은 정상 규칙을 따른다. 이미 도착한 사람을 다시 납치하거나 비상 몫을 초기화하지 않는다. 오프라인을 이유로 식량이 부패하거나 주민이 죽지 않는다. 후발자는 회의록·인계 현장을 읽고 현재 공용 비축 확인이나 새 자발적 귀환에 참여한다. 과거 협약 당사자·첫 호위 참가자를 소급하지 않는다.

핵심 호흡은 화물 조정 한 번과 공동 도착 한 번이다. 불필요한 세 항구 왕복·정기 납품은 없다. 배포 수용 시험은 다른 출신의 실제 당사자가 같은 길을 썼는지, 줄인 용량·포기한 실제 혜택이 남는지, 불참 지역의 자동 보증이 없는지다.

### C22 새 수호자 준비 카드

#### 시작과 핵심 행동

공통 경로 확인과 지역 대리 시험점이 시작 자료다. **유입을 제한하면 방어가 쉬워지지만 큰 통행을 포기하며, 추가 조절이 사라져도 안전하게 더 좁힐 수 있다**는 사실을 확인한다. 여기에는 살아 있는 조절자가 없다. 작은 지역 장치의 추가 완충을 붙였다 떼는 것으로 기능과 철수를 시험할 뿐, 미출생 수호자에게 일을 시키지 않는다.

1. 선원이 원하는 큰 통행을 현장 표지에 적는다. 예시는 큰 배 한 척과 무거운 화물의 직행이다. 시험의 제한 유입에서는 그 연결을 열지 않는다는 설명과 실제 닫힌 대리 구간을 확인한다.
2. 실제 작은 보트와 기존 육로로 화물 3묶음을 나누어 옮긴다. 같은 사람이 세 번 달리는 반복 과제 대신 동의한 운송자·플레이어가 나눠 맡거나 한 귀환 동선에서 필요한 작은 이동만 수행한다. 큰 배는 원래 소유자가 허락한 자리에 남고 몰수하지 않는다.
3. 낮아진 유입에서 지킬 구간이 줄어든 것을 관찰한다. 실행안은 두 방향의 접근 중 큰 통행 방향이 닫히고 좁은 귀환 구간 하나만 남는 구성이다. 이미 제거한 적을 부활시키지 않고 실제 현재 위협과 접근 가능 방향을 확인한다. 낮은 유입이 모든 적의 공격을 무효화하는 힘은 아니다.
4. **안전 감축 시험의 조건을 별도로 알린다.** 추가 완충이 사라졌다는 상황을 가정해, 현재 통과 중인 소규모 행렬만 한정된 잔류 완충과 퇴로로 마치고 새 큰 유입을 받지 않게 한다. 당사자의 짧은 시험 이동과 철수 참여를 확인한다. 거절한 사람 대신 동의한 플레이어가 시험 이동을 해도 된다.
5. **지역의 추가 완충을 실제 시험 범위에서 분리한다.** 신규 진입을 먼저 멈추고, 이미 통과 중인 사람이 확보된 퇴로로 이동하는 동안만 잔류 여유가 쓰임을 보여 준다. 시험 전에 정한 한 차례의 철수를 마치면 잔류 여유는 소진으로 기록한다. 수치 시간을 맞히거나 사람을 위험한 곳에서 기다리게 하는 타이머 퍼즐이 아니다.
6. **철수 후의 작은 길을 확인한다.** 잔류 여유가 없는 상태에서 추가 유입이 차단되고 고정된 낮은 유입·좁은 생활 통로만 남는 관측을 받는다. 기존 제한 유입에서 쓸 수 있던 중간 규모 직행도 지금은 닫힌다. 작은 생활 통로와 지상·해상 우회만 실제로 확인한다. 누군가 대신 흡수하거나 물자를 반복 주입하지 않는다.
7. 시험 결과에 “독립된 새 생명이 도움을 거절·중단·휴식·이탈해도 같은 안전 감축을 사용한다”는 미래 설계 조건을 적는다. 생존 유지와 장치 참여를 분리해, 접속을 끊는 선택이 그 존재의 굶주림·소멸·강제 귀환으로 이어지지 않아야 한다. 이는 작동 제한을 확인한 조건이며 그 생명의 동의를 미리 얻은 약속이 아니다. 도움을 얻지 못한 비용은 더 작은 통행과 실제 우회로 감당하고 다른 생명을 대신 고정점에 묶지 않는다.

#### 두 운용 수준을 구별하는 관측

| 이번 지역 시험의 수준 | 현장에서 확인할 사실 | 남는 비용 |
|---|---|---|
| 추가 조절을 가정한 제한 유입 | 큰 연결은 닫혀 있고 작은 운송이 통과하며 지킬 접근 구간이 줄어듦 | 큰 배·대규모 직행·무제한 원군 통행을 포기 |
| 추가 조절이 빠진 안전 감축 | 새 진입 중단, 실제 진행 중 이동의 유한 철수, 잔류 여유 소진, 더 낮은 유입만 유지 | 앞 수준의 일부 중간 규모 직행도 멈춤. 생활 통로와 실제 우회를 사용 |

시험 선택의 확인은 “이번 지역 구간의 추가 완충을 떼고, 이 통과 중인 일행만 준비한 퇴로로 마친 뒤 더 작은 길을 확인할까?”다. 수호 생명을 만들거나 평생 부릴 동의를 요구하지 않는다. 시험이 불가능한 부지는 새 생명을 투입해 해결하지 않고 다른 안전한 기존 분기점으로 바꾼다.

선원은 작은 배로 도착한 기쁨과 자기 큰 배가 남은 아쉬움을 함께 말한다. “그 아이가 싫다고 하면 다시 투표해?”에는 선원이 “그때는 작은 배를 쓰면 되죠. 그 아이를 다시 붙잡자는 표는 받을 일이 아니고요”라고 답하는 실행안을 둔다. 제작상 C27에서는 거절·휴식·이탈과 통행 감축을 포함한 안에 사전 지정 참여자 전원이 한 번 명시 동의하며, 출생 뒤 그 존재가 내리는 실제 선택은 그와 별개로 존중한다. “그럼 네가 대신 영원히 버텨”라는 요청에는 어떤 NPC도 새 고정점으로 잡지 않는다. 농담으로 알에게 명령해도 알의 응답·동의를 만들어 내지 않는다.

#### 완료와 보상 및 복구

**완료 증거는 작은 경로를 통한 실제 귀환, 큰 통행 포기, 추가 완충 분리, 통과 중 이동의 유한 철수, 잔류 소진 뒤 신규 유입 차단과 저유입 생활 통로 확인**이다. 앞의 작은 귀환만 끝냈으면 준비안 전체는 미완료다. ‘새 수호자 준비 완료’는 이 설계와 감축 가능성을 갖췄다는 뜻이며 새 수호자가 태어나거나 봉사 계약을 맺은 결과가 아니다.

모든 물건은 원래 주인·수취인에게 남는다. 시험에 실제 사용된 일반 물자는 기록하되 매일 충전해야 하는 유지비로 바꾸지 않는다. 미사용 공용 물자의 다음 용도는 기존 허락 범위 안에서 확인한다. 시험을 반복해 무한 잔류량·보호 버프를 쌓지 않는다.

중단되면 추가 유입을 열지 않은 안전한 상태에서 멈추고, 다음 접속 때 미확인 철수·저유입 관측만 계속한다. 시험 참여자 부재를 가상의 실시간 잔류량 소진과 사망으로 계산하지 않는다. 일반 이동 중 실제 게임 사망은 별도로 처리한다. 후발자는 감축 결과를 읽고 현행 작은 길을 직접 확인할 수 있으며, 처음 시험한 사람·미출생 생명의 대리 동의자가 되지 않는다.

핵심 호흡은 작은 귀환 뒤 한 차례 감축을 보는 연속 장면이다. 세 지역을 같은 방식으로 다시 돌지 않는다. 배포 수용 시험은 잔류 여유가 유한한지, 철수 후 안전의 원인이 새 유입 차단인지, 추가 조절 수준과 더 낮은 대기 수준이 다른지, 생명의 동의·핵 가동·정기 충전이 없는지다.

### C22 주인 없는 경계 준비 카드

#### 시작과 핵심 행동

공통 경로 확인과 C17의 현행 민간 출구가 시작 자료다. **작은 옆길을 중앙의 별도 허가 없이 사용하되 공동 완충을 뺀 구간의 위험은 실제 현장 방어로 감당한다**는 차이를 경험한다. 권장 부지는 네더 귀환 출구와 이어지는 외곽 안전 선반이다. 공간이 맞지 않으면 C14의 기존 지상 절벽 옆길을 쓴다.

1. 귀환자가 실제 알고 있고 가고 싶다고 한 작은 옆길을 제시한다. 자기가 아는 범위 밖의 위험은 모른다고 말한다. 플레이어는 지도상의 시작·낭떠러지 옆 안전 발판·돌아올 출구 3점을 확인한다.
2. 이 시험 구간만 중앙 쪽 완충에서 분리할 범위를 밝힌다. C17 제한 유지라면 이미 풀린 민간 길에서 출발하고 남겨 둔 무장 제한을 몰래 해제하지 않는다. C17 연결 절단이라면 실제 비구속 출구에서 시작한다. 어느 경우에도 다른 봉인과 신 권능을 건드리지 않는다.
3. 이번 시험에 제공된 공용 방어 물자와 자발적 호위 인원을 확인한 뒤 분리를 실행한다. 중앙에 새 허가를 구하지 않아도 되는 범위는 이 실제 지역 분기와 통행이다. 남의 땅·개인 포탈·물건을 무단 사용해도 된다는 뜻이 아니다.
4. 플레이어가 실제 옆길을 먼저 건너고, 주민은 자기가 맡겠다고 한 지름길 표지나 짐 이동을 수행한다. 귀환 일행 뒤에서 접근하는 실제 적을 막는다. 네더 부지면 비신격 현장 수비의 새 소규모 접근, 지상 부지면 실제 사용 가능한 일반 적 접근을 장면에 맞춰 배치한다. 예시 수량은 2체이며 C17의 원계약 집행체 부활로 설명하지 않는다.
5. 적이 정리된 뒤 마지막 사람이 출구에 닿는 것을 확인한다. 필요해 실제 사용한 보수 블록·횃불·식량과 남은 것을 센다. 가져온 32블록을 무조건 제출하거나 모두 버리게 하지 않는다.
6. 현장 참여자들이 **누가 이 길을 쓸지, 큰 위험 때 어느 퇴로를 쓸지, 이번에 제공한 방어의 범위**를 자기 말로 정한다. 다음 모든 공격의 상시 군역이나 정기 납품 의무를 붙이지 않는다. 큰 위협에 추가 호위가 필요할 수 있다는 비용은 남긴다.

#### 선택과 결과

| 선택과 범위 | 실제 확인 | 얻는 것과 잃는 것 |
|---|---|---|
| 이번 지역 구간을 분리하고 직접 지킨다 | 해당 분기 분리·옆길 왕복·후방 방어·귀환 확인 | 작은 옆길의 독립 통행. 공동 완충이 없으므로 큰 위험의 방어·피난·호위는 지역이 마련해야 함 |
| 아직 분리하지 않고 조사만 한다 | 실제 지형과 퇴로 확인 | 다른 준비에도 쓸 경로 지식만 획득. 이 안의 실제 분리·방어는 미완료 |

확정 질문은 “이 지역 시험 구간만 공동 완충에서 떼고, 제공된 물자와 동의한 호위로 이번 귀환을 지킬까?”다. 동의 없는 NPC 배정과 개인 물건 사용은 불가능하다. 누가 먼저 말했다고 마을 전체의 영구 지휘관이 되지 않는다.

귀환자: “이번에는 저 굽이를 지나도 되는지 누구에게 먼저 물어야 하진 않네요.” 호위자: “대신 뒤를 볼 사람은 우리가 정해야지.” “이제 어디든 안전하지?”에는 실제 지킨 구간만 확인되었다고 답한다. “중앙이 없으니 법도 없네”라는 농담은 다른 사람의 권리를 없애지 않는다. 급하면 이번 한 귀환의 방어와 퇴로 확인까지 끝내고 다른 옆길 탐험을 생략한다.

#### 완료와 보상 및 복구

**완료 증거는 실제 해당 구간 분리, 독립 옆길 통과, 플레이어와 동의한 주민의 실제 방어·귀환, 사용 물자와 남은 퇴로**다. ‘주인 없는 경계 준비 완료’는 이 구간의 경험과 원정 준비다. 시험하지 않은 지역이 자동 안전해지거나 모든 중앙 연결이 이미 사라지지 않는다.

짐과 남은 물자는 소유·허락 범위를 유지한다. 세계 보상은 독립 통행의 실증이며 원본 조각·최종 핵 소유권이 아니다. 실제 참여자의 답사·전투·정비 기여만 기록한다. 실패하면 미완료 위험 구간만 보완하고 이미 구한 사람을 다시 잃지 않는다. 접속 종료를 방어 의무 위반이나 오프라인 공격·주거 파괴로 만들지 않는다. 이후 추가 위협 대응은 선택 모험이며 이 시험을 정기 반복하는 세금이 아니다.

후발자는 현행 옆길·방어 기록을 읽고 현재 선택한 정비나 새 탐험을 맡는다. 처음 선택자의 부재로 길의 공용 확인이 잠기지 않으며 개인 MAIN도 이동하지 않는다. 핵심 호흡은 작은 길 하나를 직접 걸어 지키는 일이다. 배포 수용 시험은 현장 분리 범위가 좁은지, C17의 무장 제한이 몰래 뒤집히지 않는지, 실제 물자와 호위 없이 자동 보호가 생기지 않는지다.

### C22 전체 완료와 최종편 인계

아래 항목을 준비안마다 따로 남긴다. 완료 표시는 구현된 서버 변수명이 아니라 결과를 기록할 내용이다.

| 인계 항목 | 기록할 실제 내용 |
|---|---|
| 준비한 안 | 열린 협약 / 새 수호자 / 주인 없는 경계. 미완료·조사만 완료도 구별 |
| 시험 구간 | 강가·해안·네더 중 실제 적용한 구간과 기존 경로. 시험하지 않은 영역도 명시 |
| 완료 행동 | 위 카드의 실제 귀환·비축·분리·방어·철수 관측과 확인자 |
| 제공 권한 | 물자 주인, 공용 사용 허락, 사용·남은 수량, 보관처 |
| 협력과 빈자리 | 실제 동의한 주민·NPC와 지원 범위, 거절·불참·미수신자, 독립 대안 |
| 유지되는 비용 | 줄인 운송량·포기한 실제 후원·보증 의무·공동 완충 부재·방어 부담 |
| 수호안의 추가 증거 | 추가 완충 분리, 신규 진입 정지, 유한 잔류로 철수 완료, 잔류 소진, 고정 저유입·생활 통로, 중간 규모 직행 중단 |
| 개인 경험 | 실제 참여·열람·청취·동의자. 부재자의 찬성과 과거 기여는 만들지 않음 |
| 다음 단계 | 한 안 이상 실제 완료이면 C23·C24 진행. C24는 별도로 여섯 원본 확인 필요. C27은 그때 선택한 해당 안 준비와 사전 지정 참여자 전원의 명시적 같은 선택 동의 필요 |

C26 뒤 결정을 미루는 안정 보관은 핵·퇴로의 안전을 확보한 상태이며, 끊긴 생활권·통행 부담·아직 해결하지 않은 지역 문제까지 전부 끝난 상태는 아니다. 이 세 안의 모든 혜택을 임시로 받는 상태도 아니다. C22 완료를 최종 네트워크 설치·여신의 해방·귀환룡 승리로 기록하지 않는다. 최종편에서는 위 결과를 실제 원정의 준비 근거로 쓰되 같은 시험을 반복하도록 요구하지 않는다.

### C22 제작과 통합 확인

| 필요한 데이터와 자산 | 확인할 안정된 사실 | 효과가 없을 때의 대안 | 배포 전에 연결할 사항 |
|---|---|---|---|
| 세 지역의 현재 경로 지도와 기존 분기 이력 | 현재 사용 가능 경로·조건·실제 미확인 구간 | 종이 지도·책·표지와 현장 답사 | C07·C10·C11·C14·C17·C21 결과가 같은 의미로 이어지는지 |
| 주민 3역과 실제 선택 지원자 | 당사자의 목적·참여·물자 제공 허락 | 기존 주민 배역과 승인된 단계별 이동 장면 | 호위 이동 또는 장면 이동 방식, 지형·동선 안전 |
| 화물·공용 비축·반환 기록 | 소유·제공·실제 사용·남은 물건 | 기존 일반 아이템과 상자 또는 조사 소품 | 소비되는 실제 재고와 연출 소품을 구별해 표시 |
| 지역 대리 장치의 상태별 조사문 | 제한 유입·분리·신규 유입 차단·유한 철수·낮은 통행 | 시각 효과 없이 현장 전후 조사와 진행자 확인 | 소규모 시험 범위가 실제 핵/전체 봉인 제어와 혼동되지 않도록 연결 |
| 무주안 현장 적과 방어 구간 | 실제 적 제거·마지막 귀환·퇴로 | 지원되는 일반 몹 전투, 위험 없는 기존 부지로 재배치 | 화재·낙하·외부 주거 피해, 온라인 진행과 중단 처리 |
| 준비안별 결과서 | 한 안 완료·다른 안 미완료·최종 선택 가능 범위 | 재열람 가능한 책/기록 | C23·C24·C27에서 해당 안을 정확히 참조하는지 |

공통 수용 시험은 다음과 같다.

- 한 안만 마친 세계가 C23·C24로 진행하고, C27의 다른 미준비 안은 실제 보완 전 선택 확정되지 않는다.
- 세 지역과 세 방식을 아홉 번 돌지 않고 기존 경로·기여를 재사용한다. 독립된 물자와 사람을 쓴 다른 안의 준비는 병행할 수 있다.
- C17 제한 유지·연결 절단의 권한과 C10·C11의 비용이 사라지지 않는다. 부재한 MAIN 소유자 없이도 공개 근거와 실제 현장 준비를 진행한다.
- 지역 대리 시험에 원본 핵을 연결하지 않는다. 새 수호자를 미리 만들거나 대신 동의하지 않는다.
- 수호안은 짧은 유한 철수 뒤 새 유입 차단과 저유입 안전을 확인한다. 생존과 장치 참여를 분리하고 실제 거절·휴식·이탈에도 생활 통로·우회를 유지한다. 무한 완충·대체 희생·반복 충전·두 번째 엔딩 만장일치를 요구하지 않는다.
- NPC는 자기 의사로 돕거나 거절한다. 실제 통행하지 않은 사람·시험하지 않은 지역·불참 신에게 성공·동의·보증을 자동 배포하지 않는다.
- 일반 사망은 유지하되 오프라인 실패·부패·강제 사망·주거 파괴 시한은 없다. 되풀이 가능한 현재 정비와 한 번뿐인 최초 성취를 구별한다.
