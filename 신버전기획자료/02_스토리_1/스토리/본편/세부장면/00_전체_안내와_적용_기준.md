# 신화 RPG 전체 장면 상세안 안내

2026년 10월 8일 개정. 창작자용 비밀과 결말을 포함한다.

이 묶음은 C01–C06 다음의 메인 사건과 병렬·선택 이야기를, 실제 플레이 목표와 확인 가능한 결과를 가진 장면으로 작성한 콘텐츠 명세다. 각 사건의 시작·완료 조건, 실제 행동, 선택의 대가, 발화자의 지식, 실패와 복귀, 필요한 자료와 연결 지점을 다룬다. 이번에 성장 경로를 확장한 C01–C06 상세안도 함께 두어 처음부터 끝까지 같은 기준으로 읽을 수 있게 했다.

새 대사·세부 동선·작업량은 실행안 제안이다. 원본에 확정된 인물 설정과 큰 줄거리, 선행 관계는 유지한다. 이 묶음을 작성했다는 사실이 서버 설치·공식 파서 로드·NPC 모델 배치·실제 플레이 테스트가 끝났다는 뜻은 아니다. 확인되지 않은 기능은 작동하는 것처럼 적지 않고, 각 장면에 필요한 연결과 대안을 명시한다.

운영자의 수동 판정이나 승인된 장면 배치는 시제품·리허설용 대안이며, 최종 자동 NPC 동작이 구현됐다는 뜻은 아니다. 실제 자동 운영으로 배포하려면 각 카드의 필수 감지·실행·복구 연결을 검증해야 한다.

## 이번 개정의 공통 해석

- 플레이 가능한 새 신화세계 차원은 만들지 않는다. 기존 Minecraft 생활권·지형·네더·엔드를 사용하고, 신화 고향과 과거의 관계는 배경으로 남긴다. 원정·귀환·명계라는 표현만으로 새 차원 제작 요구를 만들지 않는다.
- 등급만으로 일반 조우를 초기·중반·후기로 잠그지 않는다. 실제 봉인·접근·상태 조건을 확인한 후보 가운데 세계 진행도에 따라 확률을 다르게 둔다. 사건의 선행 자료·협력 조건은 첫 만남 조건과 별개다. [명계 관련 12명과 72악마의 무작위 조우 바이옴은 네더 지역](../00_개정_안내와_변경요약.md#네더-무작위-조우의-후속-반영)으로 적용하고, C08 통행·R사건·MAIN 조건과 기록·제한 응답의 구분은 유지한다.
- 첫 용 전에도 충분한 성장 활동이 있다. 기존 지역·탑은 선택 경로이며, 특정 신의 개인 MAIN이나 모든 지역 연쇄 완료를 공동 메인의 필수 열쇠로 만들지 않는다.
- 디오니소스 술 의뢰는 수락부터 현실 48시간이며 오프라인에도 경과하는 명시적 예외다. 이 기한을 다른 사건·후속 개인 MAIN·엔딩 대기에 적용하지 않는다.
- 구체적인 디오니소스·이집트 스핑크스의 보상과 실패 처리는 [성장과 특수 조우 상세안](../03_성장과_특수조우_상세안.md)을 따른다.
- 새 인물 편입이나 주요 배역 변경 제안의 승인 범위는 [등장인물 변경 검토 보고](../04_등장인물_변경_검토보고.md)에서 확인한다.

## 인게임 적용에 사용할 때

각 카드를 실제 구현할 때는 다음을 순서대로 대조한다. 문서에 적힌 장면용 표식·지점 이름은 제작자가 대상을 구분하는 이름이며 등록된 게임 ID가 아니다.

1. **장소를 고른다.** 실제 월드의 지형·구조물과 안전한 복귀 지점을 지정한다. 카드가 제시한 대체 부지를 사용할 수 있다. 이미 설치됐는지 모르는 희귀 구조물을 필수 조건으로 만들지 않는다.
2. **배역의 표현을 고른다.** 실제 본체, 허용된 원격 응답, 기록, 전달자, 배경 행동을 구분한다. 기록만 필요한 인물에게 전신 모델·신 전용 MAIN을 만들 필요는 없다. 같은 신의 대화용 복제체를 만들지 않는다.
3. **완료 근거를 연결한다.** 실제 방문·회수·제출·전투·당사자 응답 중 카드가 요구한 사실을 감지한다. 물건 제시와 소비, 제안과 수락, 수락과 실행 성공을 구분한다. 대화문만으로 완료를 만들지 않는다.
4. **영향을 고지하고 선택을 받는다.** 무엇이 누구에게 달라지는지 알린 뒤 유효한 의사를 확인한다. 모든 잡담에 확인창을 붙이지 않고, 이미 범위가 명확한 요청을 반복 확인하지 않는다.
5. **현재 상태를 복구 가능하게 남긴다.** 실제로 일어난 세계 변화, 개인의 기여, 청중별 받은 정보, 물건의 현재 소유·보관, 아직 미실행인 약속을 나눈다. 실패·재접속·후발 합류에서 이미 끝난 역사를 다시 만들지 않는다.
6. **작은 현장 시험을 한다.** 한 명의 조사, 두 명의 독립 작업, 같은 지원을 동시에 요청하는 경우, 선택자의 부재, 미열람자·후발자, 실행 실패를 각 카드의 검수 기준으로 확인한다. 레이드 난도와 보상 수치는 별도 실제 플레이 검증 대상이다.

## 모든 장면에 공통인 진행 경계

### 공동 선택과 병행

첫 유효 공동 선택이 확정하는 것은 제시된 분기 또는 허락된 한정 지원의 배정 범위다. 서버의 모든 활동 순서나 타인의 개인 참여를 소유하는 권리가 아니다. 다른 재고·다른 경로의 독립 작업은 병행할 수 있고, 같은 물자·같은 실제 NPC를 이중 배정하지 않는다. 뒤 요청자는 이미 배정된 범위를 안내받고 기다리거나 별도 자원과 자력 경로를 택할 수 있다.

공동 사건을 처음 선택한 사람이 중단하거나 오래 접속하지 않아도, 다른 사람은 실제 남은 공용 상태와 당사자의 의사에 맞춰 일을 이어 갈 수 있다. 개인 물건을 몰수하거나 개인 MAIN 소유권을 넘기지 않는다. 이미 소비한 물건은 자동으로 돌아오지 않으며 재시도에 보상을 중복 지급하지 않는다. 개인 MAIN을 기다리는 것과 공용 메인을 진행하는 것은 별개다.

### 지식과 대화

작성자가 아는 사건의 정답을 모든 NPC의 지식으로 쓰지 않는다. 각 인물의 직접 관측·받은 보고·믿음·비공개 사실과 이후 새로 배울 조건을 구분한다. 공개 자료가 놓였어도 읽거나 듣지 않은 사람은 아직 모를 수 있다. 신화상 인연이 있는 미등장 신을 자산이 없다는 이유로 모르는 사람으로 만들지도 않는다.

운영자가 장면을 고르기 위해 아는 세계 상태는 NPC가 말할 수 있는 사실과 다르다. 생성 입력에는 해당 화자가 실제로 알고 현재 청중에게 허용된 내용만 전달한다. 비밀의 자기 기억을 유지하면서 청중에게 공개하지 않는 기능은 제공된 프로필 양식만으로 검증되지 않았다. 원문 비밀을 입력에 넣고 말하지 말라는 지시만 붙이는 것을 안전한 비밀 관리의 구현으로 단정하지 않는다.

질문·농담·가정·개인 의향을 확정 약속으로 기록하지 않는다. 중요한 선택은 제안, 영향 범위, 실제 확인, 실행 결과를 나눈다. NPC의 의향과 게임의 실행 권한도 다르다. 자유 대화가 허용돼도 대사만으로 아이템·가호·통행·퀘스트 완료를 생성하지 않는다.

### 실제 역사와 순서 밖 진행

선행 표는 정상적인 콘텐츠 흐름을 정의한다. 이미 실제로 일어난 세계 사실을 맞추려고 과거 행동을 다시 강요하거나 미수행 개인의 관찰·참전·동의를 만들어 내지 않는다. 기록 누락과 실제 실행 부재를 구별해 필요한 부분만 복구한다. 다음 단계의 현재 참여가 허용돼도 과거의 개인 보상과 첫 경험이 자동 지급되는 것은 아니다.

세계가 변해도 나중에 온 친구는 현재 사람과 현장, 출처 있는 요약에서 상황을 알아보고 남은 행동으로 자기 성취를 만든다. 이미 재회한 인물을 다시 실종시키거나 파괴된 방어체를 최초 사건용으로 되살리지 않는다. 반복 가능한 활동이 필요하면 첫 사건과 보상·정체성을 구분해 별도로 설계한다.

### 강한 존재와 봉인

고유 강함, 남은 봉인, 세계와 창구의 수용 범위, 받는 사람의 수용 능력은 서로 다른 조건이다. 기록·꿈·약한 가호가 먼저 닿아도 본체 조우나 전력 지원이 자동 성립하지 않는다. 완전 봉인 중의 제한적 봉인석 접촉은 일반 조우·해제·MAIN 수락과 다르다. 일부를 풀었다고 완전 해방이 되지 않는다.

신들이 도울 이유가 있어도 플레이어의 승리를 대신하지 않는다. 이미 다른 일을 맡은 NPC는 거절할 수 있다. 비신격 인간이 강하다고 자동 불멸이 되지 않으며, 진짜 용과 용처럼 보이는 생명의 규칙을 혼동하지 않는다.
