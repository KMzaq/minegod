# 전체 장면 색인과 연결 점검표

이 색인은 유지·개정한 후속 67개 장면의 위치, 진입 조건과 다음에 넘길 결과를 찾는 제작용 길잡이다. 장면 이름을 누르면 해당 파일의 본문으로 이동한다. 이번에 확장한 C01–C06 여섯 사건은 별도로 표시하며 67개에 다시 세지 않는다.

진입 조건은 [메인 스토리 개정안](../01_메인_스토리_개정안.md)의 선행 표와 각 상세 카드에 따른다. C·T의 정식 선행, R의 지역 단계, 배우의 실제 조우 자격은 서로 구별한다. 아래 ‘인계’에 적힌 후속 연결은 새 선행을 추가하지 않는다. 개인 MAIN·탑·지역·여우신·루브라스 이야기를 코어의 필수 조건으로 바꾸지 않는다.

C·T·R·FOX·LUB 표기는 문서에서 장면을 찾는 편집용 참조다. 새 게임 ID, 등록 좌표나 구현된 함수 이름을 선언하지 않는다. 세부 제작 슬롯과 수량은 해당 카드의 실행 제안이며, 이 색인도 서버 적용 또는 실제 플레이·LLM 시험 완료를 뜻하지 않는다. 적용 경계는 [전체 안내](00_전체_안내와_적용_기준.md)를 함께 읽는다.

초반 선택 성장 활동과 디오니소스·스핑크스 절차는 [C01–C06 상세안](../02_C01_C06_상세안.md) 및 [성장과 특수 조우 상세안](../03_성장과_특수조우_상세안.md)을 함께 읽는다. 이들은 아래 67개 집계에 더해진 필수 메인 사건이 아니다. 일반 조우 가능성과 각 사건의 선행 조건은 구분한다.

본문 파일: 06_탑_여우신_루브라스_장면.md. 네 표기는 선택 장면 참조이며 01 → 02 → 03 → 04의 완료 배지를 강제하는 새 퀘스트 사슬이 아니다. 흔적 조사, 예외적인 봉인석 접촉, 한 겹 해제, 일반 조우와 실제 지원은 각각 확인한다. 완전 봉인 중 일반 조우는 열리지 않는다.

| 장면 | 진입 조건과 실제 상태 | 완료 뒤 인계할 것과 연결 |
|---|---|---|
| [LUB01 봉인된 붉은 전장](06_탑_여우신_루브라스_장면.md#lub01-봉인된-붉은-전장) | 초반 생활권에서 실제 접근 가능한 로컬 봉인 조사. C12 뒤 또는 C15 주변은 전쟁 자료 심층 조사 | 봉인 위치·흔적과 실제 열람 자료. 초반에는 첫 층 작업 확인용 짧은 응답만 가능하며 C12·C13 증거·일반 조우·MAIN을 선취하지 않는다. |
| [LUB02 한 겹을 풀어도 남는 것](06_탑_여우신_루브라스_장면.md#lub02-한-겹을-풀어도-남는-것) | 첫 용 전 실제 로컬 조사·첫 외곽층 작업 근거·안전·당사자 동의. C02·LUB01 완료 배지 비필수. C17 뒤 심층 조사·정식 계약 조건은 별도 유지 | 조사·유지/보류 또는 첫 1겹 실제 해제 뒤 제한 일반대화. 잔여 봉인·힘·개입 제한 유지, C17 재방문 시 같은 층 반복 해제·다음 층 자동 해제 없음. |
| [LUB03 용들의 존경과 서로 다른 선택](06_탑_여우신_루브라스_장면.md#lub03-용들의-존경과-서로-다른-선택) | C21 전후, 현재 가능한 접촉 또는 검증된 실제 의견 전달 경로 | 실제 받은 의견·거절·한정 지원 범위를 남긴다. 완전 봉인 예외는 봉인석 곁 짧은 응답뿐이고 긴 면담은 일반 조우 가능 시만. |
| [LUB04 최종전 밖에서 지킬 약속](06_탑_여우신_루브라스_장면.md#lub04-최종전-밖에서-지킬-약속) | C25·C26에서 검증된 현재 봉인·작용·세계 수용 범위·관계·본인 동의가 허용한 선택 지원 | 외곽 한 구간의 실제 지원과 C28 후일담. LUB02 배지 대신 현재 상태를 확인하며 다른 실제 해제 경위도 그 범위만 반영한다. |

루브라스의 초반 첫 1겹 실제 해제 뒤 일반 만남은 사용자 확정 범위다. 천마의 패전 후 봉인과 루브라스의 본래 초월급은 이미 확정이다. 추가 해방, 천마의 구체 접촉 경로, 루브라스의 신격 여부는 이 색인으로 확정하지 않는다. C17·C26·C27 완료가 모든 봉인 해방으로 이어지지 않으며 지원 부재도 공용 최종 원정을 막지 않는다.

## 적용 단계별 연결 점검

아래는 구현 담당자가 실제 환경에서 채우고 시험할 최소 확인표다. 원본 카드의 행동·선택·복구를 대체하는 요약이나 완료 보고가 아니다. 가능한 수동 시연도 실제 확인자가 행동과 결과를 대조해야 하며, 자동 운영에는 해당 감지와 저장 연결이 필요하다.

| 적용 단계 | 이번 묶음에서 먼저 대조할 대상 | 확인할 결과와 본문 위치 |
|---|---|---|
| 현재 세계와 배치 슬롯 | 실제 열린 길·구조물·차원·안전 복귀점·소유 허락 | 01 C10·C11·C14의 항로, 02 C22의 재사용 경로, 06 탑 실제 층. 없는 구조물은 카드의 대안 또는 해당 선택 장면 보류로 처리 |
| 배우와 출연 방식 | 한 인물의 현 위치·봉인·조우 가능성, 기록/전달자/본체 구분 | 04·05 공통 출연 경계, 06 FOX·LUB. 명계 관련 12명·72악마의 네더 무작위 조우, R01 동의 방문과 R06 야마의 실제 네더 접촉/기존 허용 응답을 구분. 같은 본체를 복제하지 않고 기록의 작성자·때·허용 청중을 연결 |
| 행동과 완료 증거 | 관찰·왕복·회수·제출·소비·실제 수신·적 제압 | 01 C09 원본 인계, 02 C17 회수 후 변경, 05 R10-01 기부 영수증, 03 C26 승리. 제안이나 말만으로 실행을 만들지 않음 |
| 선택 화면과 적용 범위 | 고를 안·당사자·비용·유예·실행 결과, 같은 분기의 동시 확정 | 03 C24 합일과 C27 최종 참여자, 06 FOX M05. 불가역 합일 동의와 최종 같은 안의 만장일치를 별개로 연결 |
| NPC가 실제 받은 사실 | 직접 관측·수신 자료·사적 청중·여전히 모르는 것 | 01 C13의 교차 반응, 02 C20의 조기 인정, 06 FOX M04. 운영자 세계 상태를 화자 전지식으로 공급하지 않음 |
| 원본과 1회 정산 | 고유 물건의 현존·보관·허락, 최초 성취·개인 지급/미지급 | 03 C24 원본, C26 핵, 06 불씨와 탑 보급. 누락 지급 복구와 새 보상 획득을 나누고 과거 참가를 복제하지 않음 |

최소 연결 시험은 01의 병렬 순서, 02의 한 준비안 완료, 03의 분산/합일과 세 결말별 결과, 04·05의 단계 대기와 무소비 경로, 06의 탑 미완료·MAIN 소유자 부재·완전 봉인을 각각 포함한다. 실제 서버와 대화 시험은 이 문서 작성과 별도로 수행해야 한다.


## 사신수와 사흉수의 선택 경로 참조

[사신수·사흉수 인정과 두 용의 길](../06_사신수_사흉수_인정과_용_연결.md)은 기존 67개 상세 장면을 대체하지 않는 후속 설정 부록이다. 백호·주작의 C11·C14·C22 역할과 실제 기여·수신·협력 조건은 유지한다. 각 갈래 네 명의 명시적인 개인 인정을 모아 해당 용을 찾아갈 길을 여는 단계와, 기존 사건 완료·일반 대화·지원·MAIN을 구별한다. 여덟 필수 MAIN이나 공통 레이드는 추가하지 않는다.
