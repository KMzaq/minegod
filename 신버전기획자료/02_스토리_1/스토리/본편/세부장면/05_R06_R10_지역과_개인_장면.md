# R06부터 R10 지역과 개인 장면 상세안

이 문서는 선택 지역 연쇄 다섯 개의 15사건을 실제 플레이 행동, 인물의 말, 선택 비용, 비동기 복구까지 풀어 쓴 콘텐츠 명세다. 사건명과 기존 선행 순서는 유지한다. 새 생활 배역·대사·소량의 물품 수량·선택 결과는 이번 실행 제안이며 승인된 과거 정사가 아니다. 서버 등록, 실제 시드 답사, LLM 대화 시험과 멀티플레이 실행 시험은 수행하지 않았다.

기준은 [메인 스토리 개정안](../01_메인_스토리_개정안.md)의 R06–R10과 정보·자유 접속 원칙, 기존 지역·개인 연쇄의 동명 15사건이다. 기존 카드의 동작·분기·대사·복구를 유지한다. 명부의 실제 장소·봉인·접근로는 지키며, 등급만을 이유로 정한 본체 첫 조우 단계는 일반 만남의 잠금으로 쓰지 않는다. 미승인 인원 제한이나 조각·핵 설정도 되살리지 않는다.

- 표는 지역 사건의 세계 단계다. 본체와의 실제 대화에는 해당 배우의 실제 접근 자격·단일 개체·현 위치·봉인과 세계 수용 상태를 별도로 지킨다. 등급만으로 정한 C06·C15·C21 첫 조우 잠금은 적용하지 않는다. 초반에도 실제 조건이 맞는 인물은 만나되, 단계가 열렸다고 자동 소환하지 않는다. 라파엘을 C06 전에 만날 수 있어도 R07-03의 용 토벌 뒤 작별 사정은 아직 발생하지 않는다. R07-02에는 C06나 라파엘 대면을 요구하지 않는다.
- 각 연쇄는 01→02→03이다. 앞 사건이 끝나도 다음 세계 단계 전이면 결과를 보존하고 쉬며, 미접속 벌금·굶주림·주거 파괴·NPC 사망 카운트다운을 만들지 않는다. 이 15사건은 어떤 C 사건의 추가 필수 조건도 아니다.
- 공동 결과는 공용 자료의 정정·허락받은 전달·현재 경로 확인이다. 개인 결과는 실제 관찰·청취·자기 선택·관계 확인이다. 한 명씩 다른 시간에 기여해도 되며 전원 접속이나 지정 직업이 필요 없다. 서로 독립된 조사와 개인 대화를 하나의 잠금으로 막지 않는다.
- 의미 있는 선택은 대상, 범위, 비용, 아직 못 얻는 것을 먼저 보여 주고 명시적으로 확정한다. **첫 유효 확정은 표에 적은 동일 배타 분기만** 잠근다. 채팅 속 농담·추측·“좋아 보인다”는 확정이 아니다. 남의 물품과 비공개 경험을 기부·공개할 권한까지 생기지 않는다.
- 신별 MAIN은 기존 첫 유효 소유자만 가진다. 공개 지역 사건을 완료했다고 MAIN을 새로 주거나 옮기지 않는다. 소유자 부재 중 공용 진행은 계속되고 그 사람만의 책임 대화는 유보한다. 실제 의뢰 주체의 유효한 확인 없이 개인 MAIN 정산을 대신하지 않는다.
- 바리공주·야마·강림·아나히타는 기존 신격 제안 분류를 유지한다. 이 파일은 신규 신격 채택이나 MAIN 등록을 승인하지 않는다. 라파엘·랜돌프 카터·아탈은 신격 미정이며 새 God 프로필·불멸·MAIN을 부여하지 않는다. 토비아·가레스·올리비에·오드·위글라프·로빈 후드·메이드 매리언은 비신격 인물로 쓴다.

### 사건을 기다리는 이유와 초반 선택

R06-02·03은 C08에서 현재 세계의 산 사람·망자 통행을 구별한 결과가 있어야 오인 명부를 바로잡고 안전한 귀환을 지원할 수 있다. R07-03과 R10-02·03은 C06 뒤 이어진 생활권의 작별·순찰·보급 상황을 다룬다. R08-03은 C20 이후 실제로 공개된 귀환 사례를 현재의 카터에게 전하는 결말이다. 이 사건 조건들은 유지하며, 그 인물들과의 첫 인사를 같은 단계에 묶지 않는다. 세계 진행에 따른 조우 확률은 초반 낮은 등급, 후반 높은 등급 후보를 상대적으로 우대할 수 있지만 전 문화권을 한꺼번에 잠그거나 해금하는 규칙은 아니다.

첫 용 토벌 전에도 C02 뒤 R06-01, R07-01·02, R08-01·02, R09 전체, R10-01을 선택해 실제 전달·수로·퇴로·동행·보급을 익힐 수 있다. 이때 얻은 유효한 현장 자료는 C04에서 재사용한다. R09-02의 전투는 실제 등록되어 현재 참가 가능한 경우만 열고, 없는 전투를 승리한 것으로 만들지 않는다. 이 활동들의 전부 완료, 신과의 친분, 개인 MAIN, 기부 횟수를 C05 추가 진입 조건으로 요구하지 않는다. 실제 장비·보급과 현재 전투 준비의 성장, 이야기의 관계 성과를 구분한다.

### 본체와 지식

실제 배우는 현재 그 한 명뿐이다. 현신이나 제한 응답은 이미 열린 층·허용된 창구·수신 조건이 있는 때만 사용하며, 완전 봉인된 존재에게 보통 대화를 열지 않는다. 부재 시의 공개 기록은 작성자·작성 때·공개 허용 범위가 있는 **고정 텍스트**다. 기록이 새 질문에 실시간으로 답하거나 플레이어를 따라다니는 대역이 되지 않는다. 전달자는 자신이 받은 부탁만 말한다.

이 파일의 직접 대사는 실제 대면 또는 유효한 제한 응답에서 쓰는 예시다. 해당 모드가 불가능하면 같은 문장을 새 발언으로 재생하지 않는다. 공개 도움은 현장 주민과 이미 남긴 공개 요청으로 수행할 수 있지만, 특정 인물을 만남·고백 청취·MAIN 확인한 것으로 기록하지 않는다. 현재 유효한 공개 요청조차 없다면 그 인물의 관계 장면은 보류하고 현재 경로 조사만 한다. 그 보류가 C 사건을 막지는 않는다.

NPC는 본인이 본 것, 전달받은 것과 추측을 구별한다. 세계에 공개 기록이 있다는 이유만으로 읽었다고 간주하지 않는다. 여신의 정체·저주·핵의 기원을 여기의 모든 인물에게 자동 주입하지 않는다. 플레이어가 실제 기록이나 이미 들은 유효한 인정 내용을 적법하게 전달하면 그 청중은 앞당겨 알 수 있으며 C20 전이라는 이유로 잊지 않는다. 운영자에게 보이는 진행 값은 인물의 지식이 아니다.

### 증거와 복구

아래 슬롯 이름은 **현재 Minecraft 세계의 부지 선정용 편집 표지**이며 실제 레지스트리나 API 이름이 아니다. 숲·사막·나루·집·탑은 현재 세계의 실제 장소이고, 명계 통행은 C08에서 확인한 이곳의 경계 접점을 사용한다. 다른 신화 세계의 도시나 신화 고향 포털을 새 제작 대상으로 요구하지 않는다. 출신과 오래된 인연은 보존하며, 기존 네더·엔드 탐사는 그대로 가능하다. 신의 창구는 관측·계시·가호·제한 현현·개입의 범위이며 새 이동 차원을 뜻하지 않는다. 배포 전 각 슬롯에 실제 차원·좌표·도달 동선·기존 소유자 허락·안전 발판·복귀점을 묶어야 한다. 구조물이 없으면 명시된 자연 부지를 쓴다. 본체의 기존 풀을 다른 지역으로 옮겨 오는 대체는 허용하지 않는다.

행동 증거에는 수행자·실제 대상·장소·행동·성공 여부·해당 시도와 중복 정산 구분이 필요하다. 자유 발언만으로 아이템 소비, 구조, 이동, 승리나 완료를 생성하지 않는다. 자동 감지 연동이 없으면 운영자가 실제 행동을 관찰하고 확인하는 수동 판정을 대체안으로 쓸 수 있다. 그 확인도 못 하면 완료를 보류한다. “했다”는 채팅만으로 채우지 않는다.

아이템 **제시**는 비소비다. 실제 납부는 수량·소유자·받는 대상·철회 가능 시점을 보여 준 별도 확정 뒤 한 번만 소비한다. 거래 원장과 사건 원장이 불일치하면 재납부를 요구하지 않고 기존 영수증을 먼저 대조한다. 바닥 드롭을 전달 완료로 삼지 않는다. 일반 사망과 아이템 손실은 서버의 실제 규칙을 따르며 이 이야기가 취소하지 않는다. 추가 영구 손해를 얹지 않는다.

후발자는 현재 상태의 기록과 남은 행동으로 참여한다. 이미 해결된 사람을 다시 실종·오인 집행·위기에 넣지 않는다. 앞 사건 공용 결과를 읽고 현재 흔적을 확인한 것을 후속 진입의 맥락으로 삼되, 자기 과거 참여·동의·비밀 수령으로 소급하지 않는다. 최초 선택자가 나가도 승인된 공용 결과는 유효하고 남은 공용 작업은 다른 사람이 이어 할 수 있다.

## R06 부르지 않은 이름의 배

핵심은 마지막 말을 전달할 권리, 명부와 사람의 불일치, 돌아갈 사람과 남을 사람의 서로 다른 선택이다. 옛 용사의 죽음은 확정이며 이 연쇄에 부활 경로가 없다.

**생활 배역 제안:** ‘귀환 희망자’는 C08의 어긋난 경계에 잘못 묶여 현재 세계의 습지 대기점에서 귀가하지 못한 살아 있는 비신격 주민이다. 돌아갈 곳은 같은 세계의 기존 생활권 B이며, 다른 신화 차원에서 주민을 수입하는 장면이 아니다. ‘잔류자’는 이미 죽은 별개의 비신격 주민으로, 남아 있겠다는 본인 의사와 전달 허락이 기록되어 있다. 둘을 같은 이름으로 잘못 묶은 서류가 갈등의 원인이다. 죽은 이를 살아 있는 모델로 세워 증언시키지 않는다. 바리공주가 가진 당사자 발언의 출처·정확한 시점·공개 허락을 장면 자료로 작성한다. 이는 새로운 신화적 사망·부활 법칙이 아니다.

**부지와 배우:** R06_A는 기존 강나루 또는 강변의 마른 승하선 턱, R06_B는 기존 생활권 공용 쉼터, R06_C는 기존 습지 폐허 바깥의 마른 대기점이다. 구조물 미발견 시 강·평원·습지의 안전 지면을 쓴다. 바리공주는 기존 강변 풀, 강림은 기존 습지 풀에 있는 자기 본체로만 만난다. 야마의 무작위 조우 풀은 네더 지역으로 옮기며, 야마의 새 판단은 실제로 접근 가능한 네더의 한 본체와 접촉하거나 이미 허용된 제한 응답을 통해서만 받는다. 이 접촉은 R06_A/B/C의 지상 생활·전달 부지를 네더로 옮기거나 강변에 야마의 대체 본체를 만드는 근거가 아니다. C08에 쓰인 나루와 길을 재사용할 수 있으나 실제 현장이 같은 곳일 때만 동일 슬롯에 묶는다.

### R06-01 전하지 말라는 말

**목적과 진입:** C02 이후, 공개된 물가 요청을 살핀다. 열림 증거는 C02의 현재 세계 상태와 유효한 전달 요청이다. 완료 증인은 지정 수신자 또는 그 수신자가 승인한 접수 담당이다. 이 사건은 명계 통행 자체를 새로 열지 않는다. C08 전에는 살아 있는 쪽 A–B만 움직이고 이미 수신된 허락 문장만 전달한다. 이때 명계 통행·현재 망자 대면·루브라스 같은 다른 봉인의 해제를 새로 열지 않는다.

**배우와 장면:** 바리공주가 접근 가능하면 대면한다. 그렇지 않으면 그녀가 사전에 공개 허락받은 문장과 현장 전달자의 안내를 구분한다. 전달자는 잠긴 사적 문장을 모른다. 살아 있는 가족 배역은 기존 주민 한 명을 배정하고, 바리공주를 대신해 모든 사정을 설명시키지 않는다.

**행동 순서와 판정**
1. A에서 두 전달 항목을 비교한다. 제안 문구는 ‘기다리며 끼니를 거르지 말아 달라’와 ‘남기로 한 개인적 이유’다. 첫 항목은 지정 가족에게 전달 허락, 두 번째는 비공개로 표시한다. 이유 본문은 허락 없는 플레이어에게 처음부터 보여 주지 않는다.
2. A의 마른 발판과 B의 대기 장소를 확인하고 A→B→A를 답사한다. 왕복 1회가 실행 제안의 충분 조건이다. 플레이어마다 종이 아이템을 새로 만들 필요 없다.
3. B에서 지금 있는 수신자를 확인한다. 이름이 같아도 수신자 배역과 일치하는지 묻는다. 허락된 문장을 그대로 전하거나, 전달을 맡지 않고 접수 가능 위치만 보고한다.
4. A에서 전달 여부와 공개할 업무 정보만 정리한다. 사적인 이유를 알아냈다는 가설은 기록에 넣지 않는다.

| 선택과 확정 | 실제 비용과 실행 | 남는 결과와 아직 안 된 일 |
|---|---|---|
| 지정 수신자에게 공개 허락 문장만 전달 | “이 문장만 이 사람에게 전한다” 확인 후 전달 대화와 접수 확인. 아이템 소비 없음 | 공용에는 전달 완료와 수신 대상만 남는다. 숨긴 이유의 공개·부활 약속은 없음 |
| 말은 맡지 않고 왕복 길만 확인 | 무소비. 실제 답사와 전달 보류 보고 | 길 조사는 완료된다. 메시지는 미전달 상태로 다른 유효 전달자를 기다린다. 개인은 여기서 마쳐도 된다 |
| 허락 범위를 넘겨 설명하려 함 | 실행 전 “공개 동의가 없는 내용”을 표시하고 중단 | 관계상 경고만 가능하다. 비공개 텍스트를 자동 노출하거나 선의라는 이유로 공개하지 않는다 |

메시지 전송은 지정 수신자에 대한 한 번의 공용 배타 작업이다. 이미 다른 사람이 전달했으면 현재 수신 확인과 길 조사로 참여하고 원문을 재전송하지 않는다. 길 조사와 자기 관계 대화는 병렬로 가능하다.

**지식과 짧은 대사:** 바리공주는 직접 맡은 허락 범위를 알고, 말을 맡긴 이의 삶 전체와 여신의 현재 비밀은 모른다. 가족은 전달받기 전에는 ‘기다리고 있다’는 자기 사정만 안다. “왜 안 돌아와?”에는 바리공주가 “그 이유까지 전해도 좋다는 말은 듣지 못했어. 네 기다림이 크다고 허락이 늘지는 않아.”라고 답한다. “그냥 좋은 말로 바꿀까?”에는 “위로는 네 말로 해. 그 사람의 말이었다고 하지는 말고.” 거절에는 “길만 알아 둬도 돼.” 성급한 정체 추리에 대해서는 “같은 이름이라는 것만으론 같은 사람인지 몰라.” 농담으로 ‘내가 전령왕’이라 하면 “왕이면 더 정확히 전해야겠네.”라고 받되 직책을 부여하지 않는다.

**결과·복구·후발:** 공용 보상은 안전한 전달 동선과 허락 범위, 개인 보상은 실제 수신 확인과 관계 반응이다. 고유 물품과 반복 지급 보상은 없다. 왕복 완료를 말만으로 주장하거나 잘못된 수신자를 찾으면 미완료 위치를 표시한다. 사망·이탈은 확인한 구간까지 보존하고 마지막 안전점에서 남은 구간을 확인한다. 전달 후 접속 종료는 재전송하지 않고 접수 기록으로 정산한다. 바리공주 MAIN 소유자가 없어도 공용 전달은 가능하며, 소유자만의 사적 답은 남에게 넘어가지 않는다.

**리듬과 연결:** 전투 대신 말의 경계를 직접 고르는 장면이다. B의 대사는 ‘아직 기다림’에서 ‘말은 받았으나 이유는 모름’으로 바뀐다. 전달 또는 길 조사 보고가 끝점이다. C08 전에는 R06-02를 보류하고, 이후 A와 C의 명부 비교로 이어진다. C13 공개 저주 자료는 이 편지의 숨긴 내용을 알아야 열리는 자료가 아니다.

**제작과 인수:** 전달 2항목, 수신자 연결, A/B 부지, 전달·답사 증거, 공개 범위 표시가 필요하다. 미연동 시 실제 왕복과 접수 대화를 운영자가 확인한다. 검수는 잘못된 수신자에게 완료되지 않는지, 비공개 본문이 공용 목록에 없는지, 전달 직후 재접속해도 2회 접수되지 않는지 확인한다.

### R06-02 배에 타지 않은 사람

**목적과 진입:** R06-01의 공용 결과와 C08 이후. C08에서 현재 세계의 경계 접점 통행을 정리한 공개 결과를 읽고 그 결과에 포함된 실제 A–C 접근이 가능한지 확인한다. 메시지 전달을 보류했어도 길 조사 결과로 앞 사건을 끝냈다면 진입 가능하다. 열림은 A의 명부와 C의 현재 대기자 진술의 불일치, 완료 증인은 강림의 유효한 재확인 또는 권한 있는 현장 접수자의 정정 기록이다. 공용 길의 이용 자격과 개인 MAIN은 별개다.

**행동 순서와 판정**
1. A에서 ‘같은 이름·북쪽 나루 출발’로 적힌 호출 기록을 읽는다. C의 살아 있는 사람은 ‘남쪽 둑에서 길이 어긋났고 배에는 타지 않았다’고 진술한다. 이름은 허구 생활 배역용으로 배포 때 하나를 정하되, 동명이인 두 배역의 식별값을 합치지 않는다.
2. A의 출발 위치와 C의 대기 위치를 직접 조사한다. 비교 항목은 출발 방향과 승선 여부 두 개다. 승선 여부는 실제 남아 있는 당시 출발 명부·현장 증언으로 확인하며 물리 발자국 생성 기능을 가정하지 않는다.
3. 비교판에 ‘이름 일치’, ‘출발지 불일치’, ‘승선 근거 없음’을 넣는다. 여기서 ‘죽은 사람을 찾아냄’까지 결론내리지 않는다.
4. 집행을 보류하고 추가 자료를 기다릴지, 현재 확보한 별개의 접수 기록까지 대조해 오인 대상을 정정할지 고른다. 선택 전에 영향 범위를 그 두 배역으로 한정해 보여 준다.

| 선택과 확정 | 실제 비용과 실행 | 결과와 남는 일 |
|---|---|---|
| 이 대상의 집행 보류 | “호명된 이 사람에 대한 집행만 보류한다” 확정. 비용은 처리 지연이며 아이템 없음 | 살아 있는 대기자는 안전한 C에서 쉰다. 모든 명계 규칙 폐지나 통행 중단은 아님. 정확한 배정은 R06-03에서 재확인 |
| 추가 대조 후 대상을 정정 | 기존 현장 담당이 가진 접수 1건을 읽고 방향·당사자 확인을 대조. 추가 원정은 없음 | 두 사람의 명부를 분리하고 각자 선택을 물을 수 있다. 본인의 귀환·잔류 결정은 아직 없음 |
| 이름만 보고 집행 주장 | 확인창에서 근거 부족을 보여 주고 집행 불가 | 살해·생사 시험을 실행하지 않는다. 비교를 고쳐 재시도 |

첫 확정은 **이 오인 집행 건의 상태**만 적용한다. 여러 사람이 다른 항목을 조사해 공용 증거를 더할 수 있다. 보류를 정정으로 바꾸는 것은 새 근거를 보여 준 후 이 건의 수정이며 다른 사건 선택을 덮지 않는다.

**배우와 지식:** 강림은 자신이 받은 호출과 본인이 실제 대조한 자료만 안다. 처음에는 명부가 맞을 것이라 믿지만 보이는 불일치를 부정하지 않는다. 살아 있는 대기자는 자기가 배를 타지 않은 사실을 알고 잔류자의 내밀한 이유는 모른다. 강림 본체를 못 만나면 권한 있는 접수자가 공용 보류·정정만 처리하고 강림이 반성하거나 개인 약속했다고 쓰지 않는다.

**대사:** 강림은 “이름은 맞았다. 그래서 나머지를 보지 않았군.”이라고 수정한다. “네 명령은 누가 검사해?”에는 “지금 네가 가져온 두 줄부터 다시 보겠다.” 부활 질문에는 “살아 있는 자를 잘못 데려가지 않는 일이다. 죽음을 없애는 명령이 아니다.” 조기 추리 ‘명부 전체가 가짜’에는 “이 한 건의 오류는 확인했다. 전부라는 근거는 아직 없다.” 거절에는 “대조한 항목은 남겨라. 다음 사람이 처음부터 틀리지 않게.” 급하면 두 불일치만 요약하되 확정 클릭은 대신하지 않는다.

**결과·복구·후발:** 잘못 묶인 명부의 보류 또는 정정이 한 번 남고 개인은 자신이 확인한 항목만 얻는다. 돈·고유 조각은 없다. A 한 지점만 본 것은 대조 완료가 아니며 같은 증언 복사본 두 개도 독립 근거 두 개로 세지 않는다. 사망·로그아웃은 검증된 항목과 집행 보류를 유지한다. NPC를 공격해도 생사 증거가 생기지 않고 실제 전투 결과를 일반 규칙대로 처리한다. 늦은 사람은 정정된 두 목록을 읽고 C의 현재 안부를 확인한다. 오인을 다시 발생시키지 않는다.

**리듬과 연결:** R06-01의 전달에서 문서와 현장을 맞추는 추리로 바뀐다. 선택 즉시 호출 표제의 ‘집행’이 ‘보류’ 또는 ‘대상 정정’으로 바뀐다. 그 한 건의 안전 상태가 충분한 끝점이다. R06-03은 선택을 듣는 단계다. C08과 상호 참조하되 C08 자체를 이 수사 때문에 다시 잠그지 않는다.

**제작과 인수:** 배역 두 개의 식별·명부 2종·진술 1종·A/C 연결·해당 집행 건의 변경 이력이 필요하다. 물리 호송은 필수 자산이 아니다. 확인해야 할 배포 사실은 담당자의 정정 권한과 두 기록의 출처다. 검수는 동명이인 합치기, 보류 뒤 오프라인 강제 사망, 선행 C08 이전 실제 명계 이동, 본체 복제의 네 오류를 막는다.

### R06-03 돌아온 뒤의 하루

**목적과 진입:** R06-02 이후이며 C08 이후. 열림은 안전하게 보류·정정된 두 대상과 각자의 독립된 의사 확인 가능 상태다. 끝은 살아 있는 귀환자의 현재 생활 확인과 잔류자의 선택 보존이다. 야마는 실제 접근 가능한 네더의 한 본체와의 접촉 또는 이미 허용된 제한 응답으로만 새 판단을 말한다. 제한 응답은 본체 대면·무작위 조우 완료로 세지 않으며, 새 통신 경로를 자동 생성하지 않는다.

**행동 순서와 판정**
1. 귀환 희망자에게 ‘오늘 B로 돌아가겠다’와 ‘지금은 C에서 쉬고 나중에 정하겠다’를 실제로 묻는다. 본인 답이 먼저다. 제안 기본 장면에서는 B로 가기를 원하되 플레이어의 일정에 종속시키지 않는다.
2. 잔류자의 동의 기록에서 ‘남는다’와 ‘이 답을 지정 가족에게 알린다’의 범위를 따로 읽는다. 살아 돌아오는 사람의 승낙으로 망자의 귀환을 승인하지 않는다.
3. 같은 세계의 가족·이웃이 기다리는 B의 현재 쉴 자리와 기존 A→B 귀환로를 확인한다. 망자는 이 보행의 호송 대상에 섞지 않는다. 이미 답사한 구간은 현재 막힘 여부만 본다. 빵 1개를 준비해 제시할 수 있으나 먹였다는 판정이나 자동 소비는 없다. 식량이 없으면 B의 기존 식사 가능 안내를 확인하는 무소비 경로가 동등하다.
4. 귀환자가 실제 도착한 경우 그 본체의 B 위치와 본인 도착 대화를 확인한다. 이동 연동이 없으면 동행 연출을 생략하고 정식 장소 갱신·현장 확인을 갖춘 도착 장면으로 잇는다. 위치 확인이 안 되면 ‘귀환 준비 완료’까지만 남긴다.
5. 실제 네더 접촉 또는 기존의 허용된 제한 응답이 가능한 야마, 아니면 권한 있는 현장 접수 담당에게 두 사람의 서로 다른 결과를 분리해 보고한다. 접수 담당의 확인을 야마의 새 판단·본체 만남·개인 MAIN 확인으로 바꾸지 않는다. 유족에게 전할 답도 허락된 범위에서만 정한다.

| 선택과 확정 | 비용과 실행 | 결과와 미완료 |
|---|---|---|
| 동의한 귀환자의 오늘 귀환을 돕고 잔류 답을 그대로 남긴다 | “살아 있는 이 사람의 이동만 돕는다” 확인. 길 확인·도착 증거. 필수 아이템 소비 없음 | 실제 도착했으면 귀환 완료. 잔류자는 남는다. 용사·죽은 가족의 소환이나 신격 부여 없음 |
| 귀환자는 쉬게 두고 필요한 곳만 준비한다 | 귀환자의 유보 동의를 확인. B의 현 상태와 접수 연락만 정리 | 준비 지원으로 지역 사건을 마칠 수 있다. 귀환 완료·실제 재회는 미부여. 다른 사람이 나중에 현재 요청을 이어받을 수 있음 |
| 잔류 답을 바꿔 “곧 돌아온다”고 위로하려 한다 | 사실과 다른 문장임을 먼저 표시. 그 문장을 당사자 발언으로 전달하는 경로는 허용하지 않음 | 자기 위로의 말과 사실 보고를 분리해 다시 선택. 잔류 선택은 그대로 |

귀환과 잔류는 두 당사자의 결정이지 플레이어 간 승자 분기가 아니다. 공동으로는 이번 지원안을 확정하며 누구든 다음 날 새로운 요청에 답할 수 있다. 야마·바리공주의 기존 MAIN이 정식 채택되어 있고 소유자가 현장에 있다면 ‘돌아온 뒤의 돌봄을 어디까지 약속할 것인가’라는 개인 책임 대사를 덧붙인다. 약속은 철회 가능한 방문 범위이며 부재 중 납부 의무가 아니다.

**지식과 대사:** 야마가 아는 것은 제출받은 의사와 정정 자료다. 저주의 전말이나 여신의 감금은 이 보고서에서 배우지 않는다. “살아 있는 이의 발걸음과 죽은 이의 답은 같은 칸에 넣을 수 없다.” “용사도 데려오면?”에는 그 용사의 실제 죽음을 확인한 지식이 있을 때만 “그는 실제로 죽었다. 이 건은 그 죽음을 되돌리는 길이 아니다.”라고 답한다. 그 사실을 모르면 “그 사람의 일은 확인하지 못했다. 지금 살피는 것은 이 명부의 오류다.”라고 답하며 작가의 정답을 대신 인증하지 않는다. 바리공주는 “돌아온 다음 끼니가 필요하지, 너를 평생 은인이라 부를 의무는 없어.”라고 말한다. 귀환자는 “함께 와 줘서 고마워. 내일은 내가 길을 물어볼게.” 거절에는 돌봄 강제가 없고, ‘빵으로 생명 구매’ 농담은 거래로 처리하지 않는다.

**결과·복구·후발:** 공용에는 도착 또는 안전 유보, 잔류 존중, 전달 상태를 각각 남긴다. 개인 관계 확인은 실제 들은 사람만 가진다. 첫 귀환 연출은 1회며 새 방문자의 재회 대사는 반복 가능해도 보상 지급을 반복하지 않는다. 죽음·이탈로 호송을 중단하면 이미 도착한 NPC를 다시 C로 되돌리지 않는다. 미완료 이동은 안전점에서 재개한다. 선수의 부재나 MAIN 소유자 부재로 식사·귀환 지원을 막지 않는다. C28에는 현재 B에 사는 사람 또는 계속 쉬는 사람의 하루를 보여 준다.

**리듬·제작·인수:** 판정과 명부에서 생활의 안부로 규모를 줄인다. 쉴 자리를 보고 두 결과를 확실히 분리하면 끝이다. 필요한 자산은 본인 의사 2종, 잔류 기록, 준비/도착을 구별한 결과문, B 현장과 실제 위치 확인이다. 식사 애니메이션은 선택이고 확인 문장으로 대체한다. 인수 시험은 준비만 하고 귀환 성공이 뜨지 않는지, 두 명 중 한 명의 동의를 다른 사람에게 복사하지 않는지, C13 공개 증거가 바리공주 MAIN 없이도 남는지 확인한다.

## R07 물을 구한 사람이 주인은 아니다

토비아의 여행과 가족, 아나히타의 물길, 라파엘의 도움을 같은 소유 관계로 묶지 않는다. 토비아가 돌아가려는 곳은 현재 세계에서 통행이 끊겼던 가족의 생활권이다. C02 뒤에는 지금 오갈 수 있는 물길을 준비하고, C06 뒤에는 다시 확인된 귀환 동선을 두고 다음 여정을 고른다. 신화 고향으로 갈 새 차원을 만들지 않는다. 치유의 이야기와 실제 게임 회복 효과를 분리한다.

**부지와 배우:** R07_A는 기존 강변 취수 지점의 마른 가장자리, R07_B는 현재 토비아가 머무는 기존 사막 생활권의 쉼터, R07_C는 라파엘의 기존 숲 풀에 있는 안전한 접점이다. 강변 폐허·사막 주점·숲 감시 지점이 실제로 있으면 사용하고 없으면 강·사막·숲의 안전 지면을 쓴다. 아나히타는 강, 토비아는 사막, 라파엘은 숲의 현재 본체를 유지한다. 세 장소가 가깝다고 가정하지 말고 기존 귀환 동선을 재사용한다.

### R07-01 먼 길의 물 한 통

**목적과 진입:** C02 이후. 열림 증거는 여행자의 유효한 현재 물길 문의다. 공용 수원 소유권을 얻는 퀘스트가 아니라 자기 힘으로 돌아올 길을 고르는 일이다. 토비아가 직접 만날 수 없으면 그가 남긴 공개 문의와 현장 길 안내를 사용하고 개인 동행 약속은 미정으로 둔다.

**행동 순서와 판정**
1. B에서 토비아의 지도 또는 본인 설명으로 두 경로를 본다. 실행안은 ‘짧지만 물을 건너는 길’과 ‘길어도 마른 둑으로 돌아오는 길’이다. 둘 다 실제로 답사 가능한 경우에만 선택지로 활성화한다.
2. A의 물 블록과 마른 복귀 발판을 한 곳씩 확인한다. 물 양동이 1개를 이미 소지했다면 제시하고, 없다면 수원을 관찰하는 무소비 경로를 쓴다. 꼭 물을 퍼 가거나 설치할 필요는 없다.
3. 고른 길에서 A→안전 복귀점→A를 확인하고 선택 이유로 ‘왕복 가능’ 또는 ‘수상 이동 장비 준비’를 고른다. 실제 장비가 없는 수로를 안전하다고 인정하지 않는다.
4. 토비아에게 확인한 구간과 아직 못 본 구간을 나눠 보고한다. 아나히타의 접근 조건이 맞으면 수원을 물건처럼 독점하지 말라는 짧은 반응을 듣는다.

| 선택과 확정 | 비용과 행동 | 결과와 한계 |
|---|---|---|
| 마른 둑길 이용 | 더 걷는 비용. 발판·복귀 조사 후 자기 계획 확정 | 도보 귀환 정보. 수질 인증·물 소유권·다른 주민 통행 제한 없음 |
| 실제 준비된 수로 이용 | 자기 보트 등 이미 준비된 수단만 사용. 사용에 따른 일반 위험·내구 규칙 | 수로 왕복 증거. 다른 사람에게 장비를 강제 납부시키지 않음 |
| 조사만 하고 동행은 보류 | 수원과 안전 발판 확인, 본인 계획 보류 | 공개 길 정보는 남고 토비아의 실제 이동은 미완료. 다음 사건의 도움 범위 논의는 가능 |

자기 이동 계획은 개인 선택이다. 공용 추천 경로 표시는 검증된 공개 자료 중 첫 승인 제안을 기본으로 쓰되 다른 안전한 대안의 조사·표시를 막지 않는다.

**지식과 대사:** 토비아는 자신의 목적지와 지도 출처를 알고 실제 답사하지 않은 둑의 현재 상태는 모른다. “물을 챙겼으니 길도 안다고 생각했어. 돌아오는 발판은 보지 않았네.” 아나히타는 전달받은 조사만 확인하고 “길을 찾아 준 건 고맙다. 그 물을 네 것이라고 부를 이유는 생기지 않았어.”라고 말한다. ‘치료되는 물이냐’에는 “지금 확인한 건 물이 있는 곳과 돌아올 자리야.” 거절에는 토비아가 “지도를 돌려줘도 돼. 네가 확인한 데까지만 적어 줘.” ‘벌써 회랑을 다 뚫었다’는 추리는 현재 확인 구간만 인정한다. 농담으로 통행세를 청구하면 실제 거래를 만들지 않는다.

**결과·복구·후발:** 수원과 귀환 동선의 공용 정보, 개인의 실제 답사 기록이 보상이다. 양동이 무료 복제와 수질 수치는 없다. 물을 바라만 본 것을 왕복 완료로 세지 않는다. 익사·일반 사망은 정상 적용하고 검증된 관찰은 보존한다. 로그아웃은 토비아의 갈증 사망 타이머를 시작하지 않는다. 이미 길을 정한 뒤 합류하면 지금도 이용 가능한지 확인해 새 기여를 남긴다. 아나히타 MAIN 선점과 무관하다.

**리듬·연결:** 경로 고르기와 이동 감각이 중심이다. 바로 보이는 변화는 지도에 ‘확인됨/미확인’이 구분되는 것이다. 돌아올 지점 하나와 보고가 충분한 끝점이다. R07-02의 도움 범위를 정할 때 이 경로를 그대로 쓰고, C14의 공용 회랑 개방은 별도 진행한다.

**제작과 인수:** A/B 실측 동선, 수로 사용 가능 여부, 비소비 제시와 왕복 증거, 지도 2안이 필요하다. 지도 UI가 없으면 기존 기록문에 두 경로를 번호로 적는다. 시험은 양동이 미소지자의 관찰 대안, 실제 없는 수로 선택 비활성, 물 관찰의 자동 치유 오판정을 확인한다.

### R07-02 도움을 받는 조건

**목적과 진입:** R07-01 이후. C06이나 라파엘 대면을 추가 전제로 삼지 않는다. 아나히타의 공개 구호 요청에는 ‘이번 길의 준비를 돕는다’는 범위와 ‘숭배·영구 동행·수원 양도 없음’을 명시한다. 완료 증인은 실제 보급 수령자 또는 경로 보고 접수자다.

**행동 순서와 판정**
1. 토비아와 공개 요청을 읽고 이번에 필요한 것이 ‘한 번의 이동 준비’인지 ‘동행’인지 나눈다. 둘을 동시에 필수로 묶지 않는다.
2. 자기 빵 1개 또는 방패 1개를 준비해 제시한다. 이미 가진 것을 인정한다. 기존 상점에서 산다면 실제 재고·가격을 보여 준 구매 영수증만 사용한다. 새 상점이나 임의 골드 가격을 전제하지 않는다.
3. 돈과 장비가 없는 경우 R07-01의 길에서 아직 확인하지 않은 쉬는 지점 1곳을 살피거나 변한 구간을 점검한다. 무소비 기여다. 같은 왕복을 이유 없이 다시 강제하지 않는다.
4. 수령자가 원할 때 자기 빵 1개를 주는 선택을 별도로 제시할 수 있다. 납부 연결이 검증되지 않았으면 소비 선택을 끄고 준비·경로 기여만 쓴다. 방패 제시는 증여가 아니다.
5. ‘어디까지 도와주는가’를 상대와 확인하고 실행한 항목을 보고한다. 믿음의 고백은 판정 항목이 아니다.

| 선택과 확정 | 비용과 실행 | 결과와 남는 일 |
|---|---|---|
| 내 준비로 이번 이동에 동행한다 | 자기 장비 준비 확인, 허락된 현재 구간 A→B 이동. 필수 물품 납부 없음 | 해당 구간 동행 도움. 장기 호위·숭배·영구 안전은 미약속 |
| 동행 대신 필요한 길 정보만 나눈다 | 쉬는 지점 1곳 또는 변경 구간 조사와 보고 | 구호 정보 기여 완료. 물자 제공·호위 실적으로 기록하지 않음 |
| 자기 빵 1개를 이번 수령자에게 추가 제공 | 받는 이와 수량 확인 후 실제 1회 납부. 완료 후 먹은 빵 반환은 약속하지 않음 | 그 1개만 보급 기여. 관계 무한 상승·물 권리·MAIN 선점 없음 |

공동 구호안의 첫 유효 확정은 그 요청의 기본 실행안에만 적용한다. 이후 자발적 독립 기여는 가능하지만 타인의 재산·후원 관계를 일괄 약속하지 않는다. 아나히타가 후원을 제안하더라도 별도 개인 동의이며 이 사건 완료 조건이 아니다.

**지식과 대사:** 아나히타는 자신이 허용한 도움의 범위를 알고, 토비아가 속으로 무엇을 믿는지는 모른다. “감사를 받고 싶을 수는 있어. 그 감사로 네 다음 발걸음을 사지는 않겠어.” 토비아는 “고맙다고 말하고도 다른 길로 갈 수 있지?”라고 묻는다. 플레이어가 숭배를 제안하면 “그 말 없이도 이 도움은 유효해.”라는 답을 들을 수 있다. 거절에는 “그러면 어느 구간이 안전한지만 나누자.” ‘라파엘이 다 낫게 할 것’이라는 추리에는 현재 확인한 약속이 없다고 답한다. 농담으로 ‘방패 보증인’이라 해도 장비 소유권을 넘기지 않는다.

**결과·복구·후발:** 공개 요청의 도움 범위와 실제 기여 종류를 남긴다. 개인 감사 대사와 기존 방패 상품 정보가 보상이며 방패 자동 지급·공격력 강화는 없다. 물품을 들었다고 납부되거나 동행했다고 부재자의 관계가 오르지 않는다. 구매 후 중단해도 영수증을 재구매 요구로 바꾸지 않는다. 사망한 플레이어의 물품은 일반 규칙을 따르고 기부 여부가 불확실하면 기존 기록을 대조한다. MAIN 소유자가 없어도 지역 구호는 정산한다.

**리듬·연결·제작:** 길 찾기 다음에는 제안의 조건을 고르고 직접 작은 도움을 준다. 실행한 한 도움의 감사와 ‘여기까지’라는 합의가 끝점이다. R07-03에서 작별을 고를 수 있는 근거가 되고 C06·C22 구호에는 범위 제한의 사례로 연결한다. 요청문, 실제 상점 항목 확인, 제시/납부 분리, 받는 이의 동의와 도착 확인이 필요하다. 시험은 무소비 경로 완결, 한 번 납부 뒤 재접속 중복 차감 방지, 숭배 거절 후 진행 보존을 포함한다.

### R07-03 작별해도 남는 길

**목적과 진입:** R07-02 이후이며 C06 이후. 용 토벌 뒤 구호가 정리되어 가족 생활권으로 향할 현재 동선을 다시 논의할 수 있을 때 시작한다. 라파엘의 일반 첫 만남은 C06에 고정하지 않으며 실제 접근 자격과 현재 숲 위치를 따로 확인한다. 이전에 만났다면 그 도움과 대화의 실제 범위를 기억한다. 열림 증거는 앞 도움의 실제 결과와 토비아의 다음 행선지 문의다. 라파엘을 못 만났다면 공개 도움 기록과 토비아의 현재 선택으로 지역 결말을 내고 라파엘 개인 대화는 남긴다.

**행동 순서와 판정**
1. C에서 실제 라파엘을 만나면 ‘추가 도움이 가능한지’를 묻는다. 제안 기본 답은 ‘이번 작별 준비는 돕되 다음 여정의 상시 동행은 약속하지 않는다’다. 그는 거절할 수도 있다. 무응답은 동의가 아니다.
2. 토비아에게 계속 조사하고 싶은 일과 가족에게 돌아갈 이유를 묻는다. 제안 기본 상태는 가족 귀환을 원함이며, 플레이어의 동행 제안이 있어도 그의 현재 답을 따로 받는다.
3. 출발점과 실제 목적지의 공개된 접수 지점을 확인한다. 가족의 사적 집 내부에 임의 진입시키지 않는다. 이전 경로를 활용하고 변한 마지막 구간만 다시 확인한다.
4. 선택에 따라 현재 한 구간을 동행하거나 보내 주고, 실제 도착 또는 출발 준비만 확인됐는지 구별한다. 단일 토비아의 논리 장소와 실제 위치가 맞기 전에는 ‘가족 재회 완료’라고 쓰지 않는다.

| 제안과 확정 | 비용과 NPC 선택 | 결과와 포기하는 것 |
|---|---|---|
| 가족에게 돌아가도록 돕는다 | 토비아의 귀환 동의 후 현재 동선 확인. 라파엘 도움 거절 시 플레이어와 현장 안내로 진행 | 실제 도착하면 귀환, 그 전이면 준비. 더 긴 동행 장면은 이번에 하지 않음 |
| 함께 한 구간만 더 조사한다 | 토비아가 자발적으로 수락할 때만 활성. 범위는 공개된 가까운 미확인 지점 1곳, 실제 이동 | 이번 동행 관계. 가족 귀환은 지연되지만 장기 인질·자동 가족 피해 없음 |
| 작별 인사만 하고 각자 간다 | 무소비. 토비아의 계획을 들었다는 것만 확인 | 존중한 작별로 완결. 플레이어의 호송·라파엘 지원 실적은 없음 |

토비아의 한 몸을 동시에 두 곳으로 보낼 수 없다. 첫 유효 확정은 **당사자가 받아들인 이번 일정**에만 적용한다. 다른 플레이어는 현재 행선지 정보를 받아 합류하거나 훗날 재회하고, 그 선택을 했던 사람의 사적 대화를 소급 수령하지 않는다.

**지식과 대사:** 라파엘은 자기 도움과 실제 보고를 알고, 토비아의 모든 속마음이나 여신의 계획을 알지 않는다. “이번에 손을 빌려줬다는 이유로 네 다음 길을 고르지는 않겠다.” 토비아는 “다시 길을 묻고 싶을 거야. 오늘은 집으로 가고 싶어.”라고 말한다. ‘거절하면 은혜를 모르는 것’이라는 말에는 “감사는 남겨도 발걸음은 내가 정할게.” 도움을 더 못 준다는 답은 신격 박탈이나 적대 선언이 아니다. 급하게 작별을 고르면 간단히 범위만 확인한다. 조기 추리 ‘천사니까 내 여정도 끝까지 맡아 주겠지’에는 라파엘이 “오늘 내가 할 수 있는 일부터 말하겠다”고 답한다. 제작 판정에서는 천사라는 호칭만으로 신격·MAIN·상시 동행을 부여하지 않는다.

**결과·복구·후발:** 재회 가능한 관계, 현재 목적지, 확인된 귀환길을 남긴다. 첫 작별 장면은 1회이며 이후 현재 여행 소식은 반복 대화다. 전원에게 첫 호송 보상을 복제하지 않는다. NPC 경로 이동 실패는 안전한 접점에 머무르는 상태로 복구하고 실제 위치를 확인한다. 플레이어 사망은 되돌리지 않으며 부재 중 NPC를 벌로 죽이지 않는다. 라파엘·토비아의 부재나 후원자 접속 여부와 C14 공개 회랑은 무관하다.

**리듬·제작·인수:** 도움의 조건에서 사람을 보내 주는 감정으로 바뀐다. 행선지와 다음 만남 가능 지점이 보이면 끝이다. 라파엘 응답·토비아 의사·실제 출발/도착을 별개 자료로 만들고, 이동 연출 불가 시 검증된 현 위치의 짧은 도착 대사로 잇는다. 시험은 NPC 거절 후 무소비 결말, 두 플레이어의 동시 상반 일정 충돌, 라파엘 미대면의 만남 업적 오지급을 확인한다.

## R08 그리운 집의 문턱

카터의 꿈과 실제 길의 차이를 발견하고, 기억 속 집을 찾는 마음과 지금 함께 걷는 사람의 선택을 함께 다룬다. 꿈의 고향은 그의 과거와 바람으로 남기며 새 플레이 차원으로 확정하지 않는다. 오늘 플레이어가 돌아올 집은 현재 세계의 생활 거점 H다. 카터와 아탈은 문학 인물이라는 이유로 악역·토벌 대상·신격자로 자동 분류하지 않는다.

**부지와 배우:** R08_A는 기존 주점이나 공용 쉼터의 조용한 자리, R08_B는 같은 생활권에서 실제 왕복할 수 있는 숲길의 갈림점, R08_T는 기존 탑의 공개된 바깥 입구, R08_H는 현재 돌아올 생활 거점이다. A와 H는 같은 장소여도 된다. 새 꿈 도시·차원·건물·표식 블록을 만들지 않는다. 카터와 아탈의 본체는 기존 생활권 풀에 한 명씩 있으며, 탑 입구에 함께 서는 연출이 현재 배치와 맞지 않으면 입구 조사는 플레이어가 하고 두 인물에게 그 결과를 전한다.

### R08-01 돌아오는 표식 없이

**목적과 진입:** C02 이후. 열림은 카터가 공개 허락한 꿈의 길 설명과 A의 현재 지형이다. 완료 증인은 실제 A 귀환과 본인의 비교 기록이며, 카터와의 관계 확인은 그가 유효하게 응답했을 때 따로 남긴다. 꿈 기록을 읽은 사람은 꿈속을 직접 다녀온 사람이 아니다.

**행동 순서와 판정**
1. A에서 카터의 꿈 설명 세 줄을 듣거나 허락된 고정 기록을 읽는다. 제안은 ‘갈림길이 한 번 나온다’, ‘집으로 돌아가는 쪽에는 물소리가 들린다’, ‘돌아올 때도 같은 갈림길이다’다. 실제 지도와 다른 항목은 현장 선정 뒤 하나만 구체적으로 정한다. 기억이 틀렸다는 사실이 거짓말의 증거는 아니다.
2. A→B→A를 실제로 걸으며 A와 B의 고체 발판, 돌아오는 방향을 확인한다. 처음부터 안전하게 왕복 가능한 길을 선정한다. 손에 든 지도·블록 배치 없이도 눈에 보이는 나무·물가·능선으로 길을 설명할 수 있어야 한다.
3. 귀환 뒤 꿈과 실제의 차이를 하나 고른다. 예를 들어 실제 B에서는 물소리가 있는 물가 쪽이 귀환길과 반대임을 현장 물 위치·지형으로 확인한다. 소리 연출이 없으면 카터가 말한 ‘물 있는 쪽’과 실제 물 위치를 비교한다.
4. ‘기억을 실제 길에 맞춰 고친다’ 또는 ‘꿈의 지도는 꿈의 기록으로 따로 둔다’를 선택한다. 어느 쪽도 현실 길을 꿈대로 바꾸지 않는다.

| 선택과 확정 | 비용과 실행 | 결과와 남는 일 |
|---|---|---|
| 현재 귀환길 주석을 꿈 지도에 붙인다 | 무소비. 실제 차이 1개와 A 귀환 확인 후 주석 범위 확정 | 공용 사본에 현실 주석을 남길 수 있음. 원본 꿈의 기억은 지우지 않음 |
| 꿈 기록과 실제 답사를 따로 보관한다 | 무소비. 두 자료의 출처를 구분해 확정 | 실제 길 정보와 개인 해석이 분리됨. 꿈의 집 실재 여부는 미확인 |
| 돌아가고 비교는 나중에 한다 | 실제 귀환까지만 확인 | 귀환 기록은 보존. 비교가 미완료여서 이 카드 결말은 보류, 벌칙 없음 |

카터의 원본 기록을 수정하는 선택은 당사자가 동의한 사본의 주석에 한정한다. 공용 사본의 최초 표시 방식만 첫 유효 확정으로 정하고 각자의 개인 해석은 동시에 남길 수 있다.

**지식과 대사:** 카터는 자기 꿈과 그리움, 실제 이번 답사 결과를 안다. 꿈의 집이 현재 세계의 어느 좌표인지, 여신의 감금과 연결되는지는 모른다. “분명 저쪽에서 물소리를 들었어. 그런데 오늘 집으로 돌아오는 길은 이쪽이군.” 아탈이 보고를 받으면 “틀린 기억도 네 기억이지. 발 디딜 곳까지 그 기억에 맡기진 마라.”라고 말한다. ‘꿈이 함정이냐’는 조기 추리에는 카터가 “차이는 찾았어. 누가 만들었는지는 아직 모르지.” 거절에는 “돌아오는 데까지만 함께 하자.” ‘내 집은 침대 하나’라는 농담에는 “그 침대로 돌아가는 길부터 맞혀 보자.” 급하면 비교 1개만 제시하고 추가 꿈 이야기는 선택으로 둔다.

**결과·복구·후발:** 공용 보상은 현재 귀환 동선, 개인 보상은 자신이 짚은 차이와 실제 들은 꿈 이야기다. 꿈 지도를 전능한 탐지 아이템으로 지급하지 않는다. A에만 머물며 왕복했다고 말하면 미완료다. B에서 죽거나 나가면 도착 증거는 남지만 귀환 완료는 실제 돌아왔을 때만 붙인다. 이미 주석이 정해진 뒤 온 사람은 현재 차이를 직접 확인하고 최초 발견 업적을 복제하지 않는다. 신격 미정인 두 인물에게 God MAIN을 만들지 않는다.

**리듬·연결·제작:** 낯익은 길의 차이를 찾는 가벼운 탐험이다. A에 돌아오면 꿈 기록 옆에 이번 관찰 한 줄이 남는 것이 즉시 변화다. 비교 1개로 끝내도 충분하며 아탈의 R08-02 경고로 이어진다. A/B 실제 배치, 꿈 기록 3줄, 차이 항목 1개, 왕복 감지 또는 관찰 판정이 필요하다. 인수는 꿈 회상에 새 NPC 본체·별도 차원이 생기지 않는지, 주석이 없는 최초 상태와 후발의 현재 상태가 다른지 확인한다.

### R08-02 경고를 들은 다음

**목적과 진입:** R08-01 이후. T01·T03·T04 완료를 요구하지 않는다. 탑의 실제 현 개방 범위와 철수 지점을 보여 주는 것이 열림 증거다. 탑 입구가 아직 바인딩되지 않았다면 A에서 현재 공개된 접근 기록을 읽고 ‘오늘은 도전하지 않음’ 경로를 완료할 수 있다. 없는 입구로 강제 이동시키지 않는다.

**행동 순서와 판정**
1. 아탈에게 카터의 꿈 비교 결과 중 공개할 부분만 보여 준다. 실제 아탈이 부재하면 이미 공개한 탑 주의 기록을 읽고 개인 상담은 보류한다. 기록에는 답사할 수 있는 현재 층과 돌아올 지점이 있어야 한다.
2. 이번 탐사 범위를 ‘열린 입구까지만’ 또는 ‘현재 유효한 T 사건의 공개 구간’으로 정한다. 아직 닫힌 층을 번호만 고른다고 여는 선택은 없다.
3. R08_T가 실제 이용 가능하면 그 바깥 안전점에 가서 양손을 비우고 중단/도전 선택을 확인한다. 슬롯 조건은 짧은 준비 표현일 뿐 무장 해제 상태로 위험 구간에 들어가라는 뜻이 아니다. 탑 앞에 갈 수 없는 경우 A의 안전한 자리에서 공개 접근 기록과 양손 상태를 확인하는 보류 결말을 쓴다.
4. 철수 조건을 ‘공개 귀환점 밖으로는 안 감’, ‘위험 구간 진입 전에 다시 확인’ 중 이번 범위에 맞게 정한다. 자기가 정한 조건을 친구의 동의로 대신하지 않는다.
5. 철수하면 안전한 A/H로 돌아온 사실을, 도전이면 해당 T 사건으로 인계한 사실만 확인한다. T 전투 성공을 이 선택 한 번으로 지급하지 않는다.

| 선택과 확정 | 비용과 실제 실행 | 결과와 남는 일 |
|---|---|---|
| 경고를 받아들이고 오늘 철수 | 무소비. 실제 돌아오거나 미출발 상태를 분명히 남김 | R08-02 완료. T 사건은 그대로 열림/보류 상태, 보상은 미획득 |
| 현재 열린 범위만 도전 | 이번 범위·철수점 확인 후 T 사건의 기존 입장으로 넘김 | R08-02의 결정은 완료, 탐사/전투 성과는 해당 T 사건이 별도 판정 |
| 아직 결정하지 않는다 | 준비·경고 청취만 보존 | 결말은 미완료. 불참 벌금·침입 자동 확대 없음 |

이 선택은 해당 플레이어의 출발 범위다. 탑 공용 문을 잠그거나 다른 친구의 탐사를 취소할 권한이 아니다. T04의 이미 확정된 상층 차단은 이 카드에서 다시 열지 않는다.

**지식과 대사:** 아탈은 자신이 확인하거나 전달받은 탑 위험과 귀환 사례를 안다. 아직 일어나지 않은 T03 침입, 니알라토텝의 현재 의도 전체는 모른다. “돌아올 조건을 정하고 올라가라. 올라간 뒤엔 더 올라갈 이유만 잘 보인다.” 카터는 ‘여기서 물러나면 집을 영영 잃느냐’는 질문에 “모르겠어. 하지만 너를 붙잡아 두면 지금의 길부터 잃겠지.”라고 답한다. ‘이미 상층의 정체를 안다’면 가져온 실제 증거를 보고 아탈이 알려진 범위를 갱신하며 정답을 말한 것만으로 T03을 끝내지 않는다. 거절에는 “문밖까지 왔어도 돌아갈 수 있다.” 장난으로 ‘맨손 정복’이라 하면 무장 준비는 자유라고 안내한다.

**결과·복구·후발:** 이번 철수 기준과 현재 귀환을 기록한다. 관계 보상은 경고를 들었다는 개인 맥락뿐, 탑 최초 승리·개인 MAIN·새 경지는 없다. 양손 검사 뒤 로그아웃하면 자동 도전으로 처리하지 않는다. T 사건에서 죽으면 그 사건의 정상 사망·복구 규칙을 따르고 R08 결정 기록은 남는다. 부재한 친구는 자기가 경고를 들었다고 간주되지 않는다. 탑이 이미 닫힌 후 온 사람은 현재 봉쇄 표지와 귀환길로 철수 결말을 택한다.

**리듬·연결·제작:** R08-01의 ‘무엇이 다른가’에서 ‘어디까지 갈까’로 선택의 재미가 바뀐다. 현재 층·철수점이 눈에 보이면 충분하다. R08-03은 C20까지 기다리고 그 사이 어떤 T 사건도 추가 필수가 아니다. 필요한 것은 현 탑 상태 읽기, 안전 입구 또는 공개 기록 대안, 양손 확인, T 인계와 성과를 구별한 문구다. 인수는 T04 미완료·상층 차단·탑 미바인딩 세 경우에도 철수 결말이 있고 C 진행이 막히지 않는지 확인한다.

### R08-03 문을 닫고도 기억하기

**목적과 진입:** R08-02 이후이며 C20 이후. 열림 증거는 C20의 공용 진행과 현재 세계에서 집으로 돌아온 사람의 실제 수신 가능한 소식이다. C20 완료만으로 그 소식이나 여신의 고백을 자동 생성하지 않으며, 실제 전달되지 않았다면 공개 가능한 현재 생활 보고를 먼저 받는다. 카터가 C20 정체 증명을 자동 읽은 상태는 아니다. 이 사건에는 ‘누군가는 돌아왔고 누군가는 다른 선택을 했다’는 공개 허락된 생활 사실만으로 충분하다.

**행동 순서와 판정**
1. 카터는 실제 공유받은 귀환 사례를 보며 “그들이 돌아왔으니 내 집도 찾을 수 있지 않을까”라고 희망한다. 플레이어는 그 사례의 출처를 보여 주고 ‘한 사람의 귀환’과 ‘카터의 집이 실재함’을 분리한다. C20 자료를 공유하지 않으면 여신의 정체를 끌어오지 않는다.
2. 현재 동행하려는 사람에게 의사를 묻는다. 접속하지 않은 친구에게 동의 창을 대신 눌러 주지 않는다. 혼자 온 플레이어는 카터에게 자기 출발/귀환 의사를 말하면 충분하다.
3. 지금은 헤어질지, 서로 원하는 현재 공개 지점 1곳만 더 살필지 제안한다. 카터도 제안을 거절할 수 있다. 더 탐사하면 R08_B의 아직 확인하지 않은 가지나 현재 열린 탑 바깥만 쓰며 닫힌 T04 상층은 사용하지 않는다.
4. 실제 현재 생활권 H로 돌아온 뒤 아탈에게 돌아왔음을 알린다. 아탈 부재 시 H의 현재 귀환 확인을 공용 접수에 남기고 그의 개인 반응은 실제 재회 때 받는다.
5. 카터의 기억을 버릴 필요가 없다는 말과 오늘의 동행이 끝났다는 사실을 함께 남긴다. 플레이어가 그의 마음이 완전히 치유됐다고 판정하지 않는다.

| 선택과 확정 | 비용과 실행 | 결과와 포기하는 것 |
|---|---|---|
| 지금의 동료를 보내고 오늘 탐사를 마친다 | 자기 귀환 의사와 NPC의 수락 확인. H로 실제 복귀 | 오늘의 일정 종료, 그리운 집의 수색은 열린 삶의 관심으로 남음. 집 발견 보상 없음 |
| 서로 동의한 한 지점을 더 살핀 뒤 돌아간다 | 현재 동행자만의 동의, 지점 1곳 관찰 후 H 복귀 | 새 현재 관찰 1건과 동행. 꿈의 집·새 차원·T04 성공은 미확정 |
| 카터는 남고 나는 먼저 돌아간다 | 카터가 자기 일정으로 남는 것을 수락한 경우만. 플레이어 복귀 | 동행 관계는 유지되나 상시 호송 계약 없음. 카터를 강제 끌고 오지 않음 |

당일 공동 동선의 첫 확정은 실제 동의한 동행자에게만 적용한다. 카터의 한 몸은 한 일정만 유지하고 새 합류자는 그 현재 일정에 자발적으로 합류한다. 친구 전원의 삶을 ‘함께 더 조사’로 고정하지 않는다.

**지식과 대사:** 카터는 “네가 돌아온 건 네가 찾은 길 덕분이지. 내 문을 찾았다는 증거로 삼아 버렸군.”이라고 선을 긋는다. 아탈은 실제 귀환 보고 뒤 “무엇을 찾았느냐보다 오늘 돌아왔다는 말을 먼저 듣고 싶었다.”라고 답한다. ‘여신도 사랑 때문에 그랬지’는 그가 실제 그 고백을 알 때만 비교한다. 모르면 “그 이야기는 듣지 못했다. 오늘 네가 떠나고 싶다는 건 들었어.” 거절에는 카터가 “기억까지 두고 가라는 말은 안 할게.” 농담으로 ‘집에 가서 다시 꿈꾸자’에는 “그건 나도 하고 싶군.” 급하면 H 귀환과 작별 두 확인만 남긴다.

**결과·복구·후발:** 꿈의 지리를 해석한 관계, 오늘의 동행/작별, 현재 H 귀환이 보상이다. 최초 사건을 끝낸 뒤 재회와 새 공개 길의 답사는 반복할 수 있지만 고정 보상을 재지급하지 않는다. 탐사 중 죽거나 이탈하면 실제 확인 구간만 보존하고 H 귀환은 별도 확인한다. 무응답인 친구의 동의는 미수령으로 남긴다. C28 이후 처음 시작하면 기존 귀환 공개 기록과 지금의 카터를 만나고 C20을 재연하지 않는다.

**리듬·제작·인수:** 마지막은 답을 맞히기보다 집으로 돌아오는 선택이다. H에서 카터가 동행자에게 시간을 더 달라고 붙잡지 않는 반응이 즉시 변화다. 새 관찰은 선택이며 작별과 현재 귀환이면 충분하다. 본인 의사, 실제 동행 범위, H 귀환, 실제 전달받은 C20 지식의 유무가 필요하다. 시험은 T04 포기 상태의 완결, 부재 친구 동의 미복사, 카터의 꿈을 사실/퀘스트 좌표로 자동 확정하지 않는지를 확인한다.

## R09 살아 돌아오라는 명예

혈통을 밝히는 시험 대신 작은 역할을 맡고, 보이는 퇴로를 확인하며, 결과를 기다리는 사람에게 위험까지 전한다. 가레스·올리비에·오드는 모두 비신격 인물이며 이 사건에서 God MAIN이나 신의 불멸을 얻지 않는다. 가레스와 같은 전승의 인물이라는 이유로 아서의 미정 정치 소속을 확정하지 않는다.

**부지와 배우:** R09_A는 기존 생활권 주점의 공용 자리, R09_B는 실제 보급 경로의 도착점, R09_H는 기존 감시탑의 안전한 외곽 또는 초원의 낮은 능선 전망점, R09_L은 바로 연결되는 낮은 귀환점이다. 가레스·오드는 기존 생활권 풀, 올리비에는 기존 산지 풀의 현 위치를 지킨다. 절벽 낙하나 성채 신축 없이도 H와 L을 대비할 수 있어야 한다.

### R09-01 이름을 묻기 전에

**목적과 진입:** C02 이후. 열림은 가레스의 이번 보급길 도움 제안과 실제 경로 A–B다. 완료 증인은 경로 도착의 실제 확인과 정한 역할에 대한 접수다. 가문·신격·전투력 공개를 수행 자격으로 요구하지 않는다.

**행동 순서와 판정**
1. 가레스에게 이번에 부족한 일을 묻는다. 제안은 ‘먼저 길을 보고 돌아와 안내’와 ‘준비한 물품을 가지고 옆에서 함께 걷기’ 두 가지다. 실제 주민을 추가 위험에 넣는 역할극은 만들지 않는다.
2. 자기 방패 또는 빵을 제시한다. 제안 수량은 각각 1개이며 비소비다. 아무것도 없다면 위험 구간에 들어가지 않는 경로 조사로 기여할 수 있다. 빵을 들었다고 호위가 완료되는 것은 아니다.
3. A→B를 실제로 걷고 갈림점 1곳에서 B로 이어지는 방향을 확인한다. 가레스의 물리 동행이 없으면 해당 지점에서 사전에 정한 작업 내용을 현장 기록으로 확인하고, 나중에 실제 본체에게 결과를 전한다. ‘옆에서 싸웠다’고 꾸미지 않는다.
4. B의 실제 수령 위치 또는 안전한 대기점을 확인해 이번 역할 완료를 보고한다. 이름을 묻는 대화는 선택이며 대답하지 않아도 보고를 접수한다.

| 선택과 확정 | 비용과 실행 | 결과와 남는 일 |
|---|---|---|
| 길을 먼저 확인한다 | 무소비. A→B와 갈림점 조사 | 안내 기여 완료. 전투 호위·물품 기부 실적 없음 |
| 준비한 장비로 한 구간 함께 간다 | 자기 장비의 일반 사용 비용. 실제 현재 동행 또는 범위가 명시된 호위 확인 | 그 구간 도움. 가레스의 가문·충성 서약·영구 수행원 자격은 없음 |
| 준비만 하고 오늘은 맡지 않는다 | 제시만 기록, 무소비 | 사건 실행은 미완료. 다른 사람의 조사와 공용 진행은 계속 |

자기 역할 선택은 개인 범위다. 공동 보급 실행안을 최초 확정해도 다른 친구에게 물품과 호위 의무를 나눠 줄 권한은 없다. 가레스가 동행을 거절하면 무소비 조사로 바꾸거나 보류한다.

**지식과 대사:** 가레스는 자기 과거를 알지만 모두에게 먼저 밝힐 의무가 없다. 다른 플레이어의 신격·가문과 C13 비밀은 제공받지 않았다면 모른다. “누구의 아들인지보다, 저 갈림길에서 무엇을 할 건지 먼저 물어 줘.” 신분 추리에는 “네 짐작이 맞는지 말하기 전에, 맡은 길부터 보자. 나중에 이야기할지는 내가 정하겠어.” 실제 과거 인정이 이미 있었다면 같은 청중에게 모르는 척하지 않는다. 거절에는 “그럼 길을 본 데까지만 알려 줘.” ‘주방일도 호위냐’는 농담에는 “돌아온 사람들이 먹을 게 없다면 자랑도 길게 못 하겠지.” 급하면 갈림점 한 곳만 확인하게 한다.

**결과·복구·후발:** 공용 경로와 개인의 맡은 일, 가레스의 실제 재회 약속이 보상이다. 왕실 훈장·God MAIN·첫 승리를 지급하지 않는다. 지도만 읽은 사람과 실제 걸은 사람을 구분한다. 사망·중단은 확인한 지점까지 저장하며 NPC를 다시 위험에 세우지 않는다. 후발은 지금 보급길의 막힘을 점검한다. 가레스 본체 부재 시 공용 길 보고는 완료해도 개인 동행·대면 보상은 보류한다.

**리듬·연결·제작:** 이름 맞히기 대신 역할을 고르는 첫 협업이다. 보고 후 가레스가 그 역할을 이름보다 먼저 기억하는 반응이 변화다. B 확인과 보고가 끝점이며 장거리 추가 배달은 선택이다. R09-02는 같은 길을 내려다볼 전망과 퇴로로 잇고 C04 준비에 이 경로 정보를 사용할 수 있다. 첫 용 토벌 전에도 이 연쇄는 완결할 수 있으며, 퇴로 선택·장비 제시·실제 등록 전투의 경험을 가져간다. 가레스·올리비에·오드의 칭찬이나 연쇄 완료는 C05 참가 자격이 아니다. 실제 길·갈림점·제시/동행 증거·가레스 응답이 필요하다. 인수는 무장 미보유자의 조사 완결, 가문 응답 거절 후 진행, NPC 동행 미구현 때 가짜 호위 업적 방지를 확인한다.

### R09-02 보이는 퇴로

**목적과 진입:** R09-01 이후. 공용 전투나 레이드 참가를 추가 전제로 삼지 않는다. 열림은 올리비에의 공개 퇴로 확인 요청과 실제 H–L 동선이다. 완료 증거는 전망 발판·낮은 귀환점·실제 하산이며 올리비에가 실제 전달받으면 개인 반응을 갱신한다.

**행동 순서와 판정**
1. H의 고체 발판에서 B와 L이 어느 방향인지 확인한다. 미끄러운 절벽 끝이나 전투 중인 지점을 필수 조사점으로 고르지 않는다.
2. 올리비에의 경고 ‘높은 곳에서 이겨도 짐을 들고 내려올 길이 있어야 한다’를 듣거나 출처 있는 공개 기록을 읽는다. 현재 막힌 길과 안전한 우회로를 하나씩 구분한다.
3. H→L을 직접 이동하고 뒤를 돌아 H의 접근 방향을 확인한다. 같은 기록을 읽는 것만으로 개인 하산 증거를 주지 않는다. 이미 공개된 동선을 동료와 나눠 확인했다면 공용 안전 정보에 기여할 수 있다.
4. 현재 실제 등록된 반복 비신격 전투가 있고 참가 조건이 맞으면 퇴로를 확인한 뒤 선택 참가한다. 대상 이름·범위·입장 조건·실패 비용은 해당 기존 전투의 실제 정의를 보여 준다. 미등록이면 전투 선택을 숨기고 답사만으로 끝낸다.
5. 보고에 ‘답사 완료’, ‘전투 참가 후 귀환’, ‘전투 중단’, ‘승리 확인’ 중 실제 증거가 있는 결과만 붙인다.

| 선택과 확정 | 비용과 실행 | 결과와 남는 일 |
|---|---|---|
| 퇴로 확인으로 마친다 | 무소비. H/L 조사와 실제 하산 | 지역 사건 완료. 전투 승리·레이드 보상 없음 |
| 기존 반복 전투에 참가한다 | 기존 전투가 고지한 비용과 현재 참가 의사 확인. 실제 입장·귀환 | 전투 영수증에 따른 결과만 추가. 지역 사건이 새로운 보스나 최초 승리를 만들지 않음 |
| 위험을 보고 이번 참가를 중단한다 | 중단 위치·이유와 실제 귀환 확인 | 중단 판단을 결과로 남겨 완료. 이탈자를 겁쟁이 점수로 처벌하지 않음 |

R 사건의 역할 선택이 기존 레이드의 다른 참가자를 자동 모집·강제 입장시키지 않는다. 이미 열린 전투의 규칙은 존중하되 참여자가 없으면 답사 결말을 쓴다. 일반 첫 유효 선택은 이번 공용 안전 권고에만 적용하고 개인의 참가/철수 결정을 빼앗지 않는다.

**지식과 대사:** 올리비에는 자신이 본 위험과 보고된 전투 결과만 안다. 오드가 모든 전황을 들었는지, 다른 전승 인물의 운명이 무엇인지는 모른다. “돌아오라는 말을 싸우지 말라는 말로 바꾸지 마. 싸우고도 돌아오게 준비하자는 거야.” ‘명예를 버렸냐’에는 “보이는 길을 못 본 척하는 게 명예라면, 그 말부터 고치자.” 숨은 적 추리에는 관찰 근거를 요구하고 새 적을 생성하지 않는다. 거절에는 “그럼 네가 확인한 낮은 길을 다음 사람에게 남겨.” ‘정상 인증샷만 찍자’는 농담에는 낮은 귀환점까지 확인하자고 받는다.

**결과·복구·후발:** 공용 퇴로 지도와 정확한 참가·철수 구분이 보상이다. 실제 레이드 보상은 기존 영수증으로만 정산하며 지역 카드에서 재지급하지 않는다. H 조사만 하고 L로 떨어져 죽은 것은 안전 하산 완료가 아니다. 일반 사망 이후 재개해 마지막 귀환을 확인할 수 있다. 로그아웃은 전투 승리·명예 상실로 해석하지 않는다. 이미 전투가 끝났으면 현재 퇴로를 조사하며 그 승리를 자신의 것으로 받지 않는다.

**리듬·연결·제작:** 가레스와 걷던 길을 이번에는 높은 곳에서 읽고 안전하게 내려오는 공간적 재미다. 실제 내려온 뒤 보고서에 중단도 쓸 수 있는 것이 변화다. 답사만으로 끝내도 R09-03에 전할 충분한 이야기가 생긴다. C22 대비에 퇴로를 참고할 수 있지만 필수 지역 인증은 아니다. H/L 실측, 전투 정의 존재 확인, 판정 분류문과 실제 이동 확인이 필요하다. 인수는 전투 없는 월드 완결, 실패 후 승리 오지급 방지, 로그아웃자의 명예 감점 부재를 확인한다.

### R09-03 오드에게 말할 것

**목적과 진입:** R09-02 이후. 열림은 실제 답사·전투·중단 결과 중 하나와 소식을 듣겠다는 오드의 현재 의사다. 오드의 대면이 유보되어 있으면 그녀가 허용한 접수에 사실 보고를 남기고 관계 화해는 별도 미완료로 둔다. 선물이나 돈으로 대면 거절을 해제하지 않는다.

**행동 순서와 판정**
1. A에서 이번에 확인한 보고 항목을 읽는다. 필수 칸은 ‘한 일’, ‘확인한 위험’, ‘돌아왔는지’ 세 개다. 전투가 없었다면 ‘퇴로 답사’라고 쓰고 승리를 꾸미지 않는다.
2. 오드에게 보고할 문장을 고른다. 실제 성공한 일만 전하며 다시 출정을 권하는 안과, 성공·중단 판단·위험을 함께 전하는 안을 제시한다. 성공이 없으면 ‘이번에 확인한 성과만’이라는 정확한 표현으로 바꾼다.
3. 의미 있는 누락 선택에는 “확인한 위험을 이번 보고에서 빼며 오드가 충분한 판단을 못 할 수 있다”는 결과를 먼저 보이고 확정한다. 누락된 사실이 세계 기록에서 지워지지는 않는다.
4. 오드는 받은 내용과 자신이 이미 가진 보고를 비교한다. 위험을 모르는 상태에서 즉시 거짓말을 알아채지 않는다. 알고 있던 위험이 빠졌으면 왜 뺐는지 묻고 만남 또는 후원 요청을 유보할 수 있다.
5. 정정하려면 빠진 위험과 중단 이유를 명시해 수정본을 전달한다. 오드가 당장 화해하지 않아도 사실 정정은 완료할 수 있다.

| 선택과 확정 | 비용과 실행 | 관계 결과와 남는 일 |
|---|---|---|
| 성과와 위험을 함께 보고 | 무소비. 3항목의 사실과 모르는 부분을 그대로 전달 | 충분한 판단 자료가 남음. 오드는 추가 출정에 찬성하거나 반대할 자유가 있음 |
| 성과만 강조해 다음 출정을 권한다 | 무소비. 누락 범위를 확인하고 실제 한 일만 전달 | 검토 자료가 불완전함을 개인 보고에 남김. 오드가 나중에 별도 보고를 받으면 설명 요구·만남 유보 가능. 위험 사실은 삭제되지 않음 |
| 지금은 말을 아끼고 기록만 맡긴다 | 오드가 허용한 접수 범위 확인. 출처 있는 사실 기록 제출 | 공용/지정 수신 보고는 완료 가능, 개인 대면·재회 약속은 미완료 |

각 플레이어의 보고는 그 사람의 책임이며 최초 한 보고가 다른 사람의 증언을 금지하지 않는다. 오드의 한 번의 반응과 일정은 현재 상태를 유지한다. 공동 공개 요약은 허락된 자료의 첫 유효 확정으로 남기되 이후 출처 있는 정정본을 덧붙일 수 있다. 다른 사람의 사적 사연을 ‘완전한 보고’ 명목으로 공개하지 않는다.

**지식과 대사:** 오드는 자기 관계와 실제 받은 소식을 안다. 배우 원전의 비극이 이 세계에서 이미 일어났다고 자동 가정하지 않는다. “돌아왔다니 다행이야. 그런데 돌아오지 못할 뻔한 이유는 왜 빼놓았지?”는 그 이유를 실제로 알고 있을 때만 쓴다. 처음 듣는다면 “어디까지 확인한 말인지 먼저 알려 줘.”라고 한다. ‘좋은 말만 해야 힘이 나지’에는 “힘을 내는 것과 또 보내도 되는지는 다른 판단이야.” 거절에는 “지금 만나지 않아도 기록은 사실대로 남겨 줘.” 농담으로 ‘훈장으로 사과’하면 “내가 기다린 건 물건이 아니야.” 급하면 세 칸만 확인한다.

**결과·복구·후발:** 실제 사실 보고와 관계의 현재 상태, 자발적인 재회 약속이 보상이다. 기존 수리용 소모품이나 방패 판매 정보가 있으면 안내할 수 있으나 무료 고정 물품은 이 카드에서 새로 지급하지 않는다. 누락 정정은 반복 가능해도 우호 수치를 무한 구매하지 않는다. 보고 제출 전 사망·이탈은 초안만 남고 수신으로 계산하지 않는다. 수신 뒤 이탈은 같은 보고를 두 번 보내지 않는다. 늦게 온 사람은 자기 현재 답사와 기존 보고의 차이를 전하고 과거 전투 참가자로 쓰지 않는다.

**리듬·연결·제작:** 행동의 결과를 누구에게 어떻게 말할지 고르는 대화의 결말이다. 보고가 ‘잘했다’ 한 줄에서 실제 성과·위험·귀환을 구분하는 형태로 보이면 끝이다. 오드의 용서를 받아야 C22나 C28에 갈 수 있는 것은 아니다. 보고 항목, 청중별 수신 이력, 실제 정정문, 오드의 응답 유보가 필요하다. 인수는 위험을 몰랐던 오드의 초능력 거짓말 탐지 방지, 선물로 유보 해제 불가, 정정 후 최초 전투 보상 재지급 방지를 확인한다.

## R10 남은 사람의 몫

식량을 어디서 가져왔는지, 찾으러 나선 사람이 무엇을 원했는지, 익숙한 영웅이 없어도 누가 오늘의 일을 이어 가는지를 다룬다. ‘영웅 부재’는 현재 일정상 곁에 없는 상태도 포함한다. 베오울프나 다른 현존 인물을 이 카드 때문에 죽였다고 새로 쓰지 않는다. 실제로 죽은 옛 용사와 첫 용을 재소환하지 않는다.

**부지와 배우:** R10_A는 기존 숲길의 안전한 분기점, R10_B는 기존 생활권 주점 또는 공용 쉼터, R10_C는 숲의 현재 순찰 확인점, R10_R은 B로 이어지는 안전한 귀환점이다. 발견된 숲 폐허를 쓸 수 있으나 없으면 숲·평원의 마른 기존 동선으로 대체한다. 로빈 후드와 메이드 매리언은 숲 풀, 위글라프는 생활권 풀의 각 단일 본체를 유지한다. C02의 실종 안내인은 이미 구출됐다면 다시 실종시키지 않는다. 이곳의 확인은 현재 순찰과 보급이다.

### R10-01 누구의 식량인가

**목적과 진입:** C02 이후. 열림은 현재 주민들이 요청한 소량 보급 또는 운반길 확인이며, 로빈의 명성이나 통행세가 아니다. 완료 증인은 실제로 물품을 받은 현재 수령자 또는 답사 보고 접수자다. 주민 상자를 열거나 동료 인벤토리를 자동 징수하지 않는다.

**행동 순서와 판정**
1. A에서 요청을 읽는다. 실행 제안은 ‘이번 대기자에게 빵 4개를 나누거나, B까지 보급품을 가져올 수 있는 길을 확인’이다. 4개는 이 카드의 소량 납부 제안이며 서버 경제 측정값이 아니다. 수령 배역과 실제 요청이 없으면 자의로 누구에게 빵을 넣지 않는다.
2. 빵을 가지고 있다면 자기 소유 4개를 제시해 출처를 확인한다. 공동 상자의 물건은 사전 분배 허락을 실제 확인한 때만 별도로 사용할 수 있고, 이번 기본 경로는 자기 빵만 사용한다.
3. 기부를 고르면 받는 사람·4개 소비·납부 뒤 반환 불가를 확인하고 실제 제출한다. 제출 연동이 없거나 결과가 불명확하면 소비하지 않고 답사 경로로 이어 간다. 제시만으로는 식량 기여가 아니다.
4. 답사를 고르면 A→B→A를 실제 확인해 보급 짐을 놓을 수 있는 허락된 안전 위치 1곳을 보고한다. 물품을 실제로 옮기지 않았다면 운반 실적은 부여하지 않는다.
5. 로빈이나 현장 담당에게 ‘무엇을 누구의 허락으로 썼는가’를 짧게 확인하고 공용 결과에 수량 또는 동선만 남긴다. 개인 재산 목록 전체를 공개하지 않는다.

| 선택과 확정 | 실제 비용과 실행 | 결과와 남는 일 |
|---|---|---|
| 자기 빵 4개 기부 | 지정 수령자에게 실제 1회 납부. 확인 전 취소 가능, 납부 후 소비분 반환 없음 | 이번 식량 4개 기여. 토지·주민·배식 지휘권을 얻지 않음 |
| 물품 대신 왕복 길 확인 | 무소비. A–B 왕복과 허락된 안전 적재 위치 확인 | 현재 보급 정보 기여로 완료. 식량 4개를 제공한 것으로 계산하지 않음 |
| 주민의 상자를 쓰자고 제안 | 타인 재산 사용 허락이 없으면 실행 중단 | 그 물품으로 완료하지 않음. 자기 물품/답사 대안은 유지 |

첫 유효 확정은 **이번 요청의 기본 지원 방식**만 정한다. 남의 개인 기부 결정을 빼앗지 않는다. 이미 충족된 4개 요청에 추가 빵을 받으면서 같은 사건의 관계 보상을 반복 지급하지 않는다. 추가 수령이 실제 필요하면 별개의 새 요청과 수령 동의를 제시한다.

**지식과 대사:** 로빈은 받은 요청과 제출 출처를 알고, 플레이어의 모든 상자와 소지품 이력은 모른다. “누구 걸 가져왔는지부터 묻자. 나눠 줬다는 말만으로 빵이 네 것이 되진 않으니까.” ‘부자 상자는 괜찮지’에는 “그 상자의 권한을 여기서 내가 대신 주진 않아.” 거절에는 “그럼 돌아올 길을 봐 줘. 빈손으로도 할 일이 있지.” ‘로빈 이름으로 기부’라는 농담에는 “빵에 내 이름까지 새기면 먹기 불편하겠네. 낸 사람을 적어.” 조기 추리로 군수 위조 명령을 언급하면 실제 C09 기록을 제시받은 범위만 반응하고 이 기부로 C09 조각을 생성하지 않는다.

**결과·복구·후발:** 공용에는 실제 기부 수량 또는 확인한 길, 개인에는 자기 기여와 감사만 남긴다. 최초 지급 고유 물품은 없으며 반복 기부로 MAIN·친밀도 단계·우두머리 권리를 사지 않는다. 4개를 들었다가 먹은 뒤 제출한다고 말하면 현재 수량과 영수증을 대조해 미완료를 알린다. 소비 직후 접속 종료는 재납부시키지 않고 실제 영수증으로 복구한다. 길에서 죽으면 일반 손실을 따르며 제출하지 않은 빵까지 기부 처리하지 않는다. 늦은 플레이어는 충족된 요청을 보고 현재 길 점검이나 새 유효 요청에 참여한다.

**리듬·연결·제작:** 작고 분명한 재산 선택과 가벼운 보급이 중심이다. 담당자의 요청 표시가 ‘물품 받음’ 또는 ‘길 확인됨’으로 달라지면 끝이다. C06 전에는 안전하게 기다리며 R10-02의 현재 순찰로 이어진다. C02·C09의 주민 물자 문제와 서로 참조하되 약탈로 새 필수 전투를 만들지 않는다. 납부·소유권 확인·적재점 허락·중복 정산이 필요하다. 인수는 제시/소비 구별, 동료 상자 자동 징수 금지, 기부와 답사 두 경로의 동등한 지역 완료를 확인한다.

### R10-02 찾으러 간 사람

**목적과 진입:** R10-01 이후이며 C06 이후. 용 토벌 뒤 다시 이어진 숲길과 생활권의 현재 보급·순찰 보고가 생긴 뒤 시작한다. 열림은 매리언이 정한 현재 순찰 확인 요청과 자신의 공개 범위다. 로빈·매리언·위글라프의 일반 조우를 C06 뒤로 미루는 조건은 아니다. 매리언을 수동적인 구조 대상에 가두지 않는다. 그녀가 찾으러 나선 동료와 플레이어가 찾는 매리언의 위치는 서로 다른 사실이다.

**행동 순서와 판정**
1. 실제 매리언 또는 출처 있는 현 요청에서 ‘오늘 C를 확인한 뒤 B의 보고와 맞춘다’는 범위를 읽는다. 공개 기본 이름은 그녀가 동의한 현장 호칭을 쓴다. 이 문서의 배역명이 게임 내 모든 NPC가 아는 이름이라는 뜻은 아니다.
2. A/C의 실제 관찰 두 항목을 확인한다. 실행 제안은 ‘통행 흔적이 이어지는 방향’과 ‘현재 쓰지 않는 우회길’이다. 흔적은 기존 길·밟힌 구간·당사자 보고와 연결된 관찰문으로 쓰고 자동 발자국 추적 엔진을 가정하지 않는다.
3. B에 있는 로빈 측의 공개 순찰 보고와 맞춘다. 한쪽은 ‘동료가 B로 향했다’, 다른 쪽은 ‘B의 접수에서 동료를 확인했다’로 연결한다. 접수 증거가 없으면 행선지 추정으로 남기고 구조 완료라고 선언하지 않는다.
4. 매리언에게 실제 보고를 전한다. 공개 이름을 숨긴 채 경로 정보만 공유할지, 그녀가 특정 수신자에게 신분 공개를 허락했을 때 그 범위까지 포함할지 고른다.
5. 매리언 본체의 현재 위치·이번 일정과 보고를 일치시킨다. 숲과 생활권에 동시에 세우지 않는다. 이동 구현이 없으면 위치는 원래대로 두고 플레이어가 보고를 가져간다.

| 선택과 확정 | 비용과 실행 | 결과와 남는 일 |
|---|---|---|
| 현장 호칭으로 길 정보만 공유 | 무소비. 경로·수신자·호칭을 확인하고 보고 | 순찰 정보는 공용에 남음. 신분 공개·개인 사정은 미공유 |
| 당사자가 허락한 신분까지 지정 수신자에게 공유 | 현재 동의의 대상·정보 범위를 보여 준 뒤 전송 확정 | 그 청중에게만 이름과 관계 정보가 알려짐. 서버 전체 공개나 향후 무제한 공유 권한 없음 |
| 신분을 밝히라고 요구하며 길 보고도 보류 | 매리언은 요구를 거절하거나 개인 동행에서 이탈 가능 | 공용 경로 조사 자료는 유효. 사적 관계는 유보되고 확인 가능한 다른 공개 보고 경로는 남음 |

같은 보고의 배타 공개 방식은 첫 유효 확정으로 정하지만 그 선택은 매리언의 실제 동의를 넘지 못한다. 이미 공개된 정보는 비공개로 완전히 되돌렸다고 쓰지 않는다. 이후 범위 축소는 새 공개를 중단하는 조치다. 플레이어의 자기 경험 공유와 타인 신분 공유를 구분한다.

**지식과 대사:** 매리언은 자기가 찾으러 나섰다는 목적과 허락한 공개 범위를 안다. 로빈이 아직 보내지 않은 보고와 부재 플레이어의 의도는 모른다. “나를 찾으러 왔어? 나는 다른 사람을 찾는 중이었어. 네가 본 쪽부터 말해 봐.” ‘로빈이 다 알아도 되지’에는 “어떤 말인지 먼저 묻고 전해. 가까운 사람이라고 모든 말의 수신자는 아니야.” 구조 거절에는 “데려갈 사람을 정하기 전에 어디로 가려는지 물어 줘.” 조기 추리로 동료 생사를 단정하면 접수 증거의 유무를 짚는다. 농담으로 ‘구조된 영웅 역할’이라 하면 “오늘은 수색 보고를 쓰는 역할이 더 급해.”라고 받는다.

**결과·복구·후발:** 공용 순찰의 빈칸이 채워지고 본인 허락 범위에 맞는 관계 반응이 남는다. 매리언을 구조한 고유 업적·God MAIN·영구 호위권은 없다. A의 방향만 본 것을 B 도착 확인으로 세지 않는다. 사망·로그아웃은 확인 항목과 유효 공개 동의를 보존하되, 시간 민감한 새 요청의 전송 직전에는 동의 철회 여부를 다시 확인한다. 부재했다고 그녀를 다시 실종시키지 않는다. 후발자는 현재 순찰 자료를 맞추며 자신이 듣지 않은 신분 정보는 자동 수령하지 않는다.

**리듬·연결·제작:** 식량 양을 고르던 장면에서 서로 다른 시야의 순찰 퍼즐로 바뀐다. 두 보고가 맞아 동료의 현재 행선지가 분명해지는 것이 즉시 변화다. 확인 가능한 행선지와 공유 범위가 정해지면 끝이다. R10-03에는 누가 이번 일을 맡을 수 있는지에 관한 현재 정보만 넘긴다. C06 구호·C22 대비의 다른 주민을 다시 구조 대상화하지 않는다. 실제 A/C/B 연결, 보고 2종, 공개 호칭과 실명 청중, 단일 배우 일정이 필요하다. 인수는 신분 거절 뒤 공용 조사 유지, 동일 배우 이중 배치 방지, 접수 없는 도착 성공 방지를 확인한다.

### R10-03 영웅이 빠진 자리

**목적과 진입:** R10-02 이후이며 C06 이후. 열림은 이번에 필요한 보급·귀환 지원과 현재 맡을 의사가 있는 사람들의 확인이다. 공통 주인공 중 한 사람을 영구 지휘관으로 정하는 선거가 아니다. 위글라프를 실제로 못 만나면 공개 요청과 현장 주민의 동의로 지역 일 분담을 완료하고 그의 개인 평가만 남긴다.

**행동 순서와 판정**
1. B에서 오늘의 일 두 가지를 보여 준다. 제안은 ‘남아서 현재 물자와 대기자를 확인’과 ‘밖에서 돌아올 길을 확인’이다. 실제 주민 배역이 자기 몫을 맡을 수 있고 플레이어 1명만 있어도 하나를 수행해 기여할 수 있다.
2. 지금 참여한 각 당사자에게 맡을지·쉬거나 돌아갈지 묻는다. 플레이어가 없는 친구를 명단에 자동 배정하지 않는다. NPC도 전투와 잔류를 거절할 수 있다. 동의가 없는 자리는 ‘미배정’으로 보인다.
3. 돌아올 길을 맡으면 C→R→B의 현 안전 상태를 답사한다. 남는 일을 맡으면 B의 허락된 공용 물자 위치와 연락 가능 접수 1곳을 확인한다. 식량 납부와 별도 송금은 필수가 아니다.
4. 현재 실제 등록된 반복 비신격 전투가 있을 때만 선택 참가를 제안한다. 실제 적·범위·요건·귀환점을 기존 정의에서 보여 준다. 없거나 참여할 사람이 없으면 답사와 생활 지원으로 완결한다. 보물무덤의 용·첫 엔더드래곤·귀환룡을 반복 전투용으로 복제하지 않는다.
5. 돌아온 사람과 쉬기로 한 사람의 상태를 각자 확인한다. 이번 분담의 종료를 선언해 역할을 해제한다. 다음 요청에는 새로 묻는다.

| 선택과 확정 | 비용과 실제 실행 | 결과와 감수한 한계 |
|---|---|---|
| 전투 없이 귀환길·생활 지원을 맡는다 | 무소비. 선택한 현장 확인 1종과 결과 접수 | 공동체의 현재 준비가 남고 사건 완료. 전투 승리·전리품 없음 |
| 실제 반복 전투를 돕고 돌아온다 | 기존 전투 비용과 참가 의사 확인, 실제 참가·귀환 증거 | 해당 전투 결과만 기록. 누군가 남아 돌보는 일은 그 당사자의 별도 동의와 실행이 있어야 함 |
| 나는 돌아가고 맡겠다는 사람에게 정보만 남긴다 | 자기 확인 자료와 현 상태 전달. 상대 수락이 있을 때만 인계 완료 | 철수와 정직한 인계로 완결. 미배정 역할은 숨기지 않고 보류하지만 오프라인 자동 피해 없음 |

첫 유효 확정은 **이번 요청의 공용 지원안**에 적용하며 각자의 실제 참가 동의는 별개다. 전원의 같은 선택이나 만장일치는 요구하지 않는다. 일반 사건 합의로 C27의 최종 엔딩 동의를 대신하지 않는다. 역할은 그 일의 종료와 함께 끝나며 지휘권·주민 징발권·동료 통제권으로 이어지지 않는다.

**지식과 대사:** 위글라프는 자기가 겪은 전승의 기억과 이번에 확인한 사람들의 결정을 안다. 다른 인물이 지금 이 세계에서 죽었는지는 별도 증거 없이 단정하지 않는다. “남겠다는 말은 내가 할 수 있어. 네가 남으라는 맹세는 내가 대신 못 해.” ‘영웅 한 명이면 충분하지’에는 “그 한 명이 없는 오늘도 누군가는 물을 긷고 길을 알아야 하니까.” 로빈은 실제 자기에게 알려진 분배를 두고 “내 이름은 빼도 좋아. 오늘 누가 먹고 돌아왔는지는 남겨.”라고 말한다. 매리언은 “다음 순찰은 다음에 묻자. 오늘의 수락을 평생으로 늘리지 말고.”라고 덧붙인다. 거절에는 인계·현재 자료만 요청하고 죄책감 벌점을 주지 않는다. ‘그럼 내가 왕’이라는 농담은 “오늘 맡은 일이 끝나면 왕도 퇴근해.”로 받으며 직책을 만들지 않는다.

**결과·복구·후발:** 현재 지원·귀환 정보·자발적 분담의 기록이 보상이다. 기존 반복 전투의 보상은 그 전투에서만 정산하며 최초 세계 전투나 원본 조각 보상을 지급하지 않는다. 남을 사람 이름만 적고 떠난 것은 그 사람의 실행이 아니다. 사망·실패는 실제 결과와 미배정 역할을 드러내고 이미 한 조사·제공 물품을 지우지 않는다. 오프라인인 사람 때문에 굶주림·보복·주택 파괴를 예약하지 않는다. 최초 선택자가 나가도 허락받은 공용 지원은 다른 사람이 현재 의사로 이어 할 수 있다. 후발자는 새 요청 또는 현재 남은 일을 하고 과거의 기부·전투·맹세를 소급받지 않는다.

**리듬·연결:** 마지막은 누가 영웅인지 가리는 전투보다, 돌아온 뒤 각자의 일을 내려놓는 생활 장면이다. B에서 ‘이번 일 종료’와 실제 돌아온 사람/남은 사람이 구분되면 충분하다. 더 싸우기와 추가 보급은 선택이다. C22에는 이 지역이 동의한 현재 지원 범위를 제시하고, C28에는 어느 엔딩이든 숲과 집이 계속 쓰이는 모습을 보여 준다. 이 결과가 없는 세계도 공개 길 조사로 C22·C28을 진행한다.

**제작과 인수:** 이번 요청·당사자별 동의·기간이 짧은 역할·실제 행동 증거·종료 표시가 필요하다. 영웅의 빈 의자 같은 시각 소품은 선택이며 기존 공용 자리의 대사만으로도 충분하다. 배포 전 반복 전투가 정말 존재하는지만 확인하고 없으면 탐사·인계 경로를 쓴다. 인수는 1명 접속의 비전투 완결, 없는 친구 자동 동의 금지, 전투 후 영구 지휘관 미생성, 종료 뒤 새 요청의 재동의, C28 이후 첫 고정 보상 반복 방지를 확인한다.

## 서로 돌아오는 장면 연결

아래는 추가 선행 퀘스트가 아닌 짧은 반응 연결이다. 해당 사실을 실제 들은 배우만 반응하고, 해당 인물이 부재하면 허락된 공개 생활 기록을 읽는다. 한 지역의 비밀이나 MAIN 대사를 다른 지역의 보상으로 넘기지 않는다.

| 현재 장면에서 얻은 사실 | 다음 방문에서 쓰는 구체 반응 | 역방향으로 돌아볼 곳 |
|---|---|---|
| R06에서 전달 허락과 당사자의 잔류를 분리함 | C13 기록 조사자가 공개 저주 자료와 사적인 마지막 말이 서로 다른 자료임을 짚는다 | C28에서 실제 귀환자의 하루와 잔류 답의 보존 상태를 확인한다 |
| R07에서 도움을 한 구간으로 한정함 | C14·C22의 현재 이동 계획에 도움의 범위·철회 가능 구간을 적는다 | 회랑이 열린 뒤 토비아의 현재 길과 라파엘의 실제 도움 가능 여부를 다시 묻는다 |
| R08에서 안전 귀환과 기억을 구별함 | 현재 T 사건의 귀환 기록에 꿈 해석을 사실 좌표로 적지 않는다 | C20 이후 실제 공유받은 귀환 소식을 카터가 자기 집의 증명으로 과장하지 않는 장면을 본다 |
| R09에서 중단 이유까지 보고함 | C22 준비에서 실제 확인한 퇴로와 아직 못 본 위험을 구분한다 | C28에 오드가 실제 받은 보고를 바탕으로 재회 여부를 고른다 |
| R10에서 이번 일만 자발적으로 분담함 | C22에 지역이 동의한 인력·물품·범위만 제시한다 | C28에서 다음 순찰과 식사는 새 요청으로 이어지고 옛 맹세를 자동 갱신하지 않는다 |

## 배포 직전 공통 인수 기준

1. **사건 수와 순서:** 위 15개 이름·01→02→03 연결, 실제 통행·생활 변화·귀환 보고에 근거한 C08/C06/C20 대기, R07-02의 불필요한 C06 잠금 부재를 확인한다. C02 뒤 용 미토벌 상태에서 지정된 앞 장면들이 열려야 하고, 일반 조우에는 등급만을 근거로 한 C06/C15/C21 잠금이 없어야 한다. 어떤 지역 미완료도 C 사건의 추가 잠금이 아니다.
2. **장소:** 모든 A/B/C/H/L/R/T 슬롯은 실제 부지·소유자 허락·복귀점에 묶는다. 구조물 미발견에서는 명시된 자연 지형 경로로 교체한다. 실제 좌표가 없는 슬롯을 가짜 좌표나 추정 구조물 ID로 실행하지 않는다.
3. **한 인물 한 몸:** 두 사람이 같은 NPC에게 동시에 접근해도 본체·일정은 하나다. 개인 대화와 공개 결과를 분리하고 봉인된 본체의 기록이 실시간 화자로 바뀌지 않는다.
4. **행동과 말:** “전달했다/죽였다/돌아왔다/기부했다”는 자유 발언만 넣어도 성공하지 않아야 한다. 관찰·실행·수신·도착·소비 증거 중 카드가 요구하는 것이 빠지면 정확한 미완료 항목을 보여 준다.
5. **동시 선택:** 상반된 동일 공용 분기 두 확정이 오면 먼저 유효한 것만 적용하고 두 번째에는 현재 결과를 알린다. 다른 카드·개인 조사·독립 지원은 계속된다. 사적 공개·납부·NPC 동의를 이 규칙으로 우회하지 않는다.
6. **사망과 재접속:** 제출 전후, 수신 전후, 왕복 중간, 실제 도착 전후를 각각 끊어 본다. 완료된 공용 결과는 보존하고 미완료 행동만 재개한다. 정상 사망은 그대로 적용하며 추가 오프라인 벌칙과 원본 고유 보상 복제는 없어야 한다.
7. **후발과 부재:** 모든 최초 선택자와 MAIN 소유자가 오프라인이어도 공개 자료와 현재 행동으로 지역 공용 결과를 읽고 C 진행을 이어 간다. 개인 MAIN은 재배정하지 않으며 후발에게 첫 승리·첫 만남·과거 사적 발언을 소급하지 않는다.
8. **지식 경계:** 운영자 화면의 C20 완료가 모든 NPC의 여신 정체 지식이 되지 않는다. 실제로 앞서 인정받거나 근거를 전달받은 청중은 그 사실을 기억한다. 기록이 공개되어 있다는 것과 읽었다는 것을 분리한다.
9. **선택의 비용:** 기부는 실제 자기 물품만, 답사는 실제 이동만, 전투는 기존 정의만, 작별은 현재 동의한 일정만 남긴다. 여유가 없는 플레이어도 무소비 탐사·보고 경로로 지역 결말에 도달할 수 있다.
10. **내용 검토와 실행 검증 구별:** 이 파일은 콘텐츠 설계다. 실제 관찰·납부·수신·배우 이동·보상 연동의 구현과 라이브 서버·LLM 시험은 별도 확인 대상이며, 필요한 기능이 없으면 명시된 수동 확인 또는 비소비 경로를 사용한다. 그 대체조차 확인할 수 없으면 해당 효과만 미완료로 남긴다.
