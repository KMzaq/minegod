# 성격 참고 채택과 기존 이야기 연결 — 적용 안내 (본문의 과거 집계·작성 범위는 해당 시점 이력이며 최신 인원·등급·제작 분류는 현행 통합 명부를 따른다.)

이 자료는 당시 757명 저술 마스터 위에 추가한 성격·소설적 작은 설정·관계 연결 설계층이다. 754명은 설정과 AI 자유 대화 페르소나 제작 대상이며, 3명은 설정만 필요하다. 제작 대상 분류와 집필 완성은 다르다. 개별 AI 페르소나 전체, 실제 대사 분기, 퀘스트 코드와 서버 상태 전이는 이번에 구현하지 않았다.

## 기존 작업 흐름에서 읽는 순서

1. 현행 `rpg_authoring_master_current.json`의 정체·접근·지식·동의 제약을 먼저 읽는다.
2. 기존 `스토리/01_메인_스토리_개정안.md`와 C01–C28, T01–T04, R01–R10 세부 장면을 읽는다. 기존 본문은 그대로 보존했다.
3. 새 성격 채택 문서에서 해당 인물의 차용한 성향과 차용하지 않은 설정, 현재 게임에 맞춘 판단을 확인한다.
4. 관계 그래프와 경로·장 연결 문서에서 기존 관계와 이번 연결 제안을 구별한다. 장 연결은 첫 등장 확정이나 공개된 지식의 자동 취득이 아니다.
5. 전체 인물 색인에서 현재 역할, 장, 지역·개인 경로, 첫 도입 재료가 실제로 있는지 확인한다. 원안 역할 씨앗, 조우 후 대화 예, 완성된 첫 도입 장면을 같은 것으로 세지 않는다.
6. 실제 구현에 들어가기 전 인물별 접근·의사·출처·전달 대상·선택 결과를 장면과 데이터로 작성하고 검증한다.

## 출처 우선순위

최신 승인된 게임 설정 및 명시적 제한 → 현행 마스터의 현재 필드와 기존 승인 이야기 → 이번 적용 가능한 성격·작은 설정 채택 → 외부 작품 참고 자료 순이다. 서로 충돌하면 위 순위를 따르고, 확인되지 않은 중요한 변경은 논의 항목으로 남긴다. 외부 작품의 인물 전체를 수입하는 크로스오버가 아니다. 원전·외부 작품 설명은 캐릭터가 현재 세계에서 아는 사실과 별개다. 원래 참고 카탈로그는 읽기 전용 참고 자료로 보존하고, 채택 판단은 별도 파일에서 연결한다.

## 고정된 경계와 최신 논의 반영

- 이 설계층 작성 당시 명부는 757명이고 등급 분포는 최하급 33·하급 128·중급 156·상급 198·최상급 188·초월급 54였다. 이후 승인된 인원·등급 변경은 최신 통합 명부를 따른다. 인원이나 등급을 다시 바꾸려면 먼저 사용자와 논의한다.
- 신의 등급·강함에 따른 퀘스트 진행 전투력 최소컷을 마련하되, 일부 이집트·그리스로마·북유럽 신의 초반 퀘스트 구간은 그 최소컷 없이 진행할 수 있다는 최신 방향을 반영한다. 가호를 받고 주시받는 정도는 예시이며 인물에 따라 다르다. 20%는 진행도 설명용 예시였으므로 고정 비율·전투력 배율·새 해금 임계값으로 구현하지 않는다. 초반 예외의 대상과 범위는 인물별 작성 대상이다. 신이 약해졌다는 새 설정으로 해석하지 않는다.
- 캠페인의 무대는 기존 Minecraft 세계·네더·엔드다. 별도 신화 차원을 추가하지 않는다. 엔더드래곤 토벌은 첫 큰 절정, 귀환룡은 최종 대립이다. 두 용의 설정 전용 제작 범위를 AI 자유 대화 제작으로 바꾸지 않는다.
- 옛 용사는 실제로 죽었다. 검·기억·힘의 흔적을 생존 인격이나 부활 장치로 바꾸지 않는다.
- 달기(여우신)의 기존 관계·성장 제한과 여우신 이야기를 지킨다. 달기 자신이 신성 흡수로 초월급 수준까지 성장하고, 해당 MAIN 소유자가 달기의 과거 퀘스트를 완료한 두 조건을 함께 만족한 뒤 다음 실제 만남에서 ‘서방님’ 호칭과 매우 우호적인 태도를 적용한다. 단순 호감으로 앞당기거나 마지막 불씨의 특정 답을 새 필수조건으로 더하지 않는다. 흡수·특수 봉인·해방 후 성장 유지의 기존 조건도 보존한다.
- 아서는 인간 여성, 초월급이라는 현행 설정을 지킨다. 정식 전쟁 소속은 미정인 채 유지한다. ‘제3세력’으로 자동 확정하지 않는다.
- 루브라스의 천군 관련 위상, 거짓말을 못 한다는 제약, 천마가 더 강하다는 관계를 유지한다. 천마가 패배하여 봉인되었다는 승인 설정과 AI 자유 대화 페르소나 제작 의도를 유지한다. 실제 접촉 방식·봉인 해제 단계·현재 장면은 별도 미정이다. 옛 문서의 ‘현재 상태 미정’ 표현으로 봉인 설정이나 페르소나 제작 의도를 취소하지 않는다.
- 업은 단순한 선악 점수가 아니다. 누군가의 기억에 남는 것이라는 설명을 따른다. 누군가를 죽이는 일이 강렬한 죽음·마지막 기억을 남겨 업을 쌓기 쉬운 방식이라는 세계관 설명도 포함한다. 이를 자동 부활·수치 환산·반복 살해 보상 규칙으로 바꾸지 않는다.

## 축복과 가호의 구분 — 사용자 확인 완료

축복과 가호는 서로 다르다. 메인 도입의 여신 축복은 그대로 유지하며, 가호 없이 진행하는 인간 경로와 충돌한다고 보지 않는다. 인간 경로에서 제한하는 것은 가호이고, 축복만 받았다는 이유로 이 경로를 막지 않는다. 초기 축복을 삭제하거나 꿈·접촉만으로 바꾸는 방안은 채택하지 않는다. 이번 구분만으로 축복의 수치 효과·수락 절차·추가 해금 조건을 새로 만들지 않는다. 사용자 확인: `Sentinel_c6384a9e4f108191b349914ec666ce28`.

## 별도로 남기는 후속 논의

다음 사항은 이번 연결안의 나머지 적용을 막지 않는다. 이미 받은 가호를 포기하고 인간 길로 바꿀 수 있는지, 천마의 현재 접촉 방식, 아서의 정식 정치 소속, 사신수·사흉수의 개별 인정 과제와 황룡·흑룡 발견 단서는 아직 확정하지 않는다. 세부 상태는 `discussion_points.json`을 따른다. 새 소개 경로 역시 실제로 완료된 과거 인연으로 소급하지 않는다.

## 구현 요청 목록

아래는 구현된 기능이 아니라 다음 개발·집필 요청이다.

- 채택된 성격을 인물별 말투·금기·반응·관계 상태별 대사로 작성
- 조우 후보의 실제 위치·봉인·의사와 접촉 방식 검증
- 장면별 지식 출처·전달 대상·전달 시점 작성 및 스포일러 검사
- 관계 변화의 원인, 거절 가능성, 후속 대화, 증거 보유 여부 작성
- 선택 경로와 메인 진행의 상태 분리, 늦게 합류한 플레이어의 전달 절차 검증
- 기존 제외 인물은 기억·과거·무대 밖 인연으로만 참조하고 필수 NPC로 재생성하지 않음
- 위 작성이 끝난 뒤에만 서버 데이터·코드·테스트로 전환
