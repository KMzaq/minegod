2026-09-20 / **문서 단계 완료, M1 코드 구현은 미착수**

## 다시 확인한 현재 상태

- 기준 인수인계는47절까지의 구현 기록이다. 개발 게임1.0.11/AI0.1.12, 서버 게임1.0.2/AI0.1.3/콘텐츠0.1.0이다. 게임 행동 원장·관찰·소문 회복의 **개발 구현 존재**와 **현재 서버 미배포**를 구분한다.
- 기존 개인 회상·소문/평판 검토·회복 후 대화 연결이 이미 있으므로 신규 소유권/중복 엔진을 만들지 않는다. 실제 전서구/정책 콘텐츠 및 인게임 통합 수용은 여전히 별도다.
- 신 입력의 이벤트 취소는 정상 라우팅일 수 있고, 신 대사 HUD는 수신자·페이지마다 복제된다. 수집은 이벤트1개=발화1개로 단순화하지 않고 논리 발언과 실제 수신을 분리한다.
- 설치된 FTB Teams 팀 채팅은 별도 packet/전송 경로이며 바닐라 팀 채팅과 다르다. 공개 채팅만 수집해서 전체 대화 완료라고 하지 않는다.
- 소문 SavedData에는 worldId도 있다. 구 test 기억 제외는 파일 삭제·세계 identity 재발급이 아니라 신규 dataset/cursor 경계로 처리한다.
- 100GB는 합산 상한이다. 기존 원장 index·주시·소문/평판 항목 안전 한도는 따로 존재하며, 조기 한도 도달은 상태/누락으로 보고한다. 신규 RAW에는 기존12,000건·신별2,000건 한도를 상속하지 않는다.

| 조건 | 결과 |

| 최신 문서·소스·서버 버전 분리 | 확인. 개발 JAR은47절 기록과 대조, 배포본은 변경하지 않음 |
| source owner/ID/revision/current 검증 지점 | 대응표 확정. v1에 없는 신 청중/발전 과제 투영을 있다고 가정하지 않음 |
| 수집 채널/중복 후처리 | 호출 지도와 채널 fixture 정의. hook 구현·실제 수집은 M2 |
|100GB 파일 목록·test 경계 | registry 및 별도 원본 보존 기준 확정. quota 실제 강제는 M1 |
| JDBC 선정·확보·라이선스 |3.53.4.0 기본 JAR/게임 단일 패키징 선정. 미다운로드·native/NeoForge 미실행 |
| 새 핵심 사용자 선택 | 현재 없음. 후속 실행 권한과 미작성 콘텐츠를 미리 확정하지 않음 |

검증 PASS: 설계 폴더 Markdown15개, 로컬 링크55개, JSON 예시1개, 펜스/공백/충돌 마커 검사 및 보호 파일45개 SHA-256 불변을 확인했다. `git diff --check` 통과, 인수인계의 기존47절까지 내용은 보존하고48절만 추가했다. 전체 월드 파일을 전수 검증/백업했다는 뜻은 아니다.

이전47절의11,782 assertion이나43절의 실제 모델 실측을 이번에 재실행한 결과로 표시하지 않는다. 실제 게임/LLM 호출·빌드·서버 실행·배포·world 변경·test 삭제는 하지 않았다.
