# 필요 시 행동 참고 — 과장과 생성 잘림 후속 검증

2026-10-20 · `behaivior` · 게임1.0.35 / AI0.1.49 / 콘텐츠0.1.3 · `gemma4:12b` 유지. 운영 미배포.

## 확인한 원인

이전 실행의 실패 두 턴에는 원문 wire가 없어 당시 HTTP 응답을 사후 확정할 수 없다. 대신 저장된 **동일 생성 입력**을 기존 클라이언트로 재생했다([화제 전환](diagnostic-before/turn-12.json), [추천](diagnostic-before/turn-13.json)).

- 화제 전환: 첫 응답 `done_reason=length`, `eval_count=260`, JSON 도중 잘림. 같은260토큰 재시도는244토큰에 완료했다. 모델 검토는 통과했지만 이전 NPC 추측을 다시 인용해 평온함/돌봄을 전제하는 의미 오류가 있었다.
- 개인화 추천: 두 응답 모두 `length`,260토큰. 두 번째는 `currentEmotion` 문자열에서 잘려 `Unterminated string` 파싱 실패. 같은 한도로 다시 생성하는 정책이 이 실패를 복구하지 못했다.
- 위 재현은 두 입력 모두 한도에 도달할 수 있음을 입증한다. **과거 두 실패의 wire까지 확보했다고 주장하지 않는다.**

## 수정

- 정상 첫 요청은260토큰 그대로. `length` 종료는 JSON이 우연히 완성되어도 미완료로 거절한다. 이 경우에 한해서만 한 번 재시도 예산을 `max(512, 2×기존)`(최대1024)로 늘린다. 다른 오류의 재시도 예산은 유지한다. 모델·운영 설정 변경 없음. 잘린 JSON을 임의로 붙여서 발행하지 않는다.
- 행동 프롬프트에서 넓은 `category` 꼬리표를 빼고 실제 사건 코드·대상·결과 및 좁은 `literalMeaning`을 전달한다. 같은 선택 사건의 `observedActionBoundary`는 확인된 행동/행위자/관찰자와 미확인인 준비·감정·취향을 구분한다. 별도 DB·추론·권한·저장 스키마 추가 없음.
- 일반 대화 검토는 기존 계약을 유지한다. 관찰 자료가 제공된 경우만 행동 범위 검토를 덧붙인다. 신 자신의 감상과 플레이어의 감정/성실함 주장을 구분하며, 정상적인 수확 회상은 추가 인증 없이 인정한다.
- 관찰 수정은 실패 초안에 끌려가는 부분 편집 대신 원래 자료에서 재작성한다(`ObservedSupportRepair`). 일반 턴의 기존 제한 편집은 유지한다. 모델 출력은 본문만 받고 화자/청중/제안/메타데이터는 코드가 보존한다. 재작성 후에도 원래 자료로 전체 검토한다. 이전 NPC 칭찬/추측을 새 행동 근거로 쓰지 않는다.
- 격리 LIVE fixture는 전송 요청·응답·종료 사유를 수집한다. 일반 운영 호출에 원문 보관을 새로 켠 것은 아니다.

## 중간 실패도 보존

- 첫 AI build는 새 검토 지침이 일반 대화의 동결 계약까지 바꿔 `roomPlayerClaimTransportTest`에서 실패했다. 관찰 시에만 지침을 적용하도록 좁힌 뒤1433검사 PASS. 시험 기대값을 바꿔 통과시키지 않았다.
- `audit-v1`: 이전 원문 장면으로 과장/정상7개 대조. 최초 판정6/7, 수정 후 정상 수확 과잉거절과 과장 잔존이 있어 실패. 자동 PASS인 실제 과거 대사 수정문에도 '가꾸고 돌보는 일에 마음을 쏟음'과 목적 추정이 남았다. 합격으로 취급하지 않는다.
- `audit-v2`: 같은 사건을 새 의미 표현으로 렌더링. 최초7/7 판정 일치, 정상 수확 과잉거절 해결. 짧은 과장2개는 수확 사실로 수정했지만 긴 실제 실패 초안은 다른 추측으로 바뀌어 재검토에서 차단됨.
- `audit-v3`: 근거 없는 부분 생략을 허용하는 부분 수정 실험도 같은 긴 초안에서 실패. 이 실험 코드는 최종 경로에 남기지 않았다.
- `audit-v4`: 초안을 빼고 재작성. 기존 생성 지침과 새 지침을 겹쳐 넣은 첫 형태는1건512토큰까지 반복해 잘림. 최종 형태는 별도 간결한 지침과 고정된 원래 자료를 사용한다.
- `audit-v5`: 자동7/7 및 수정3/3 PASS. 직접 읽은 수정1개에서 '어떤 마음으로 밭을 일구고 있는지 알 수 없다'라는 미확인 행동 전제가 남았다. 자동 결과만으로 합격 선언하지 않았다.
- `audit-v6`: 그 전제 대조를 추가, 최초8/8 판정 일치. 같은 즐거움/성실함 과장을 검토기가 `CONTEXT_CONTRADICTION`으로 부르는 바람에 예전 부분 편집을 타서 수정1건 실패. 이후 관찰 자료가 있는 턴인지로 분기를 고정했다.
- `audit-v7`: 최초8/8, 수정4/4 자동 PASS. 직접 확인한 긴 과장 원문의 수정은 '밀을 수확하는 모습을 보았다 / 그것만으로 좋아하는지·이유는 알 수 없다'로 개선. 그러나 `unsupported-care` 수정에는 다시 '어떤 마음으로 땅을 일구는지'라는 전제가 남아 **수동 의미 gate는 미통과**. 제한형 사실 응답을 수정 시에만 허용할지 사용자에게 질문했으며, 임의로 적용하지 않았다.
