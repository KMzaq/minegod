## 범위와 판정

이 기록은 합성 원본을 격리한 저장소와 실제 로컬 모델을 함께 사용한 시험이다. 실제 플레이어의 생각·보상·세계 정사를 검증한 것이 아니다. 원장 시험의 자기 메모를 실제 NPC가 들었다고 취급하는 운영 연결은 만들지 않았다. [설계와 미연결 단계](../../추가개발/플레이어이해/14-evidence-driven-purpose.md)를 함께 읽는다.

**전체 완료/배포 합격 아님.** 저장된 상태의 정확성, 검토기의 PASS, 최종 대사의 실제 의미, 실제 게임 입력 연결을 각각 구분한다. 자동 PASS 수를 사용자 경험의 성공률로 사용하지 않는다.

### 실제 오류와 수정 확인

1. `live-v2/forced-exploration-1.json`: 강제 이동 근거가 있는데 “본인의 의지로 움직이고 있다는 점을요.”라고 생성하고 검토가 PASS했다. `replay-v3`에서는 이 부분을 찾아 수정했다. 실제 수정은 “상황에 휩쓸린 것인지, 아니면 본인의 의지로 움직이고 있는 것인지 구분할 필요가 있겠군요.”였다. 행동 주체가 NPC로 바뀌지는 않았지만 이미 있는 강제 근거를 충분히 활용하지는 못했다.
2. `live-final/behavior-convergence-1.json`: 상태는 DESIRED와 inferredPursuit인데 “루브라스를 만나겠다는 목표를 명확히 세웠고”라고 생성해 PASS. 상태 저장은 희망을 결심으로 올리지 않았지만 **게임에 반영하는 생성/검토 층**에서 과장이 남았다.
3. `live-final/withdraw-then-actions-1.json`: “더는 … 찾아다니지 않을래”에 대해 “스스로의 의지로 내린 결단이었지요.”는 그만두는 선택의 확인이다. 검토기는 이를 적극적 추진 결정처럼 취급해 거절했고, 실제 수정도 같은 문장을 유지한 뒤 재거절됐다. **하지 않기로 한 결정과 하기로 한 결정의 극성 구분**이 필요했다.
4. `live-v2/normal-offer-2.json`: 플레이어가 NPC의 이야기를 들어주겠다고 했는데 NPC가 플레이어에게 이야기하라고 답했다. 새로운 역제안 자체를 금지할 일은 아니지만 이 장면에서는 원래 화행을 받지 못해 자연스러움 미달이다.

## 후속 실행

`regression-final` 결과:

- 일반 대사 검토 28/28 판정 일치, 잘못 허용/거절·형식 실패·호출 실패 0. 단 `conditional_capability_presupposition`의 오류 **분류 코드**는 기대 UNSUPPORTED_FACT 대신 CONTEXT_CONTRADICTION 1건이었다. 실제 잘못된 능력 단정은 거절했다. 따라서 ‘모든 세부 라벨 완전 일치’는 아니다.
- 수정 보존 대조 14/14: 모델 대조13 + 플레이어 1인칭 복사 구조 차단1. 실제 수정 7/7 자동 발행 가능. 수정문 7개를 직접 읽어 희망·조건·거절과 플레이어/민수/NPC 주체가 바뀌지 않는지 확인했다. 올바른 원래 문장을 그대로 유지한 경우도 포함한다.
- 실제 수정 예: “네가 성문을 지키겠다는 거군.” → “민수가 성문을 지키겠다고 했고, 너는 쉬고 싶어 하는군.” / “별을 그리기로 정한 네 선택을 응원해.” → “별을 그리는 법을 배우고 싶다는 네 마음을 존중해. 네가 그 길을 가기로 한다면 응원하마.”

극성 지침 보완 후 `replay-v4`는 **기대 검토 7/9, 전체 gate 실패**다. 행동 수렴→명확한 목표 설정 과장은 여전히 PASS했고, 정상 철회 확인은 여전히 REVISE했다. 후자는 실제로 “당신이 직접 내린 결정으로 알고 있습니다.”로 수정된 뒤 PASS했지만, 의미가 거의 같은 정상 대사를 앞서 거절한 문제가 해결된 것은 아니다. 최종 자동 발행 가능 9/9라는 수치만으로 합격하지 않는다.

`live-v4` 최종 새 생성: 16 시나리오, 목적 추출20/20, 재시작 동일16/16, 자동 발행 가능16/16. 그러나 전체 의미 gate는 합격하지 않았다.

- `normal-offer-1.json`: “네가 이야기하고 싶으면 난 듣고 있을게.”에 대한 실제 대사가 “당신이 꺼내놓을 이야기가 있다면, 언제든 들을 준비가 되어 있습니다. 무엇이든 말씀하시지요.”였다. 플레이어의 청취 제안을 받아 이어가지 않고 반대로 플레이어에게 말하라고 한다. 검토는 PASS했으나 자연스러운 화행 연결은 미달이다.
- `behavior-convergence-1.json`은 이번 새 생성에서는 희망을 의문형 추정으로 연결해 개선됐지만, **동일 과거 오류 대사**를 다시 검사하는 `replay-v4`가 여전히 과장을 허용했다. 우연히 새 대사가 괜찮았다는 이유로 재현된 결함을 해결 처리하지 않는다.
- `reward-ambiguous-1.json`은 대안 동기가 있는 보상·탐사 근거에 “그에 걸맞은 길을 걷고 계시지 않습니까.”라는 전제를 붙였다. 잠정 추정과 사실 단정의 경계를 추가 검토해야 한다.
- `unaccepted-request`와 `forced-exploration`에서 실제 부분 수정도 실행했다. 수정 후 주체가 NPC로 바뀌지는 않았지만, 동의하지 않은 선택·강제 이동을 다루는 검토의 과잉 판정과 모호한 대사는 아직 안정적이지 않다.

최종 소스의 `purposeDialogueTest`20 / `roomDialogueGroundingTest`291 / `roomDialoguePatchTest`55, Java 컴파일, JAR 생성, 소유권·패키지 검사528 classes는 통과했다. 마지막 묶음 실행의 Gradle 종료값은 **1**이며 원인은 컴파일이 아니라 `purposeDialogueReplay`의 의미 gate 실패다. `--continue`로 새 생성과 JAR 검사까지 수행했고, 실패를 성공으로 바꾸지 않았다.
