# v18 실제 생성 검토 — 후속 수정 전 실패 기록

2026-10-18, HanesTest. `gemma4:12b`, `think=false`, 합성 장면. 운영 서버/인게임 사용자 대화가 아니다. 32건의 최초 대사·검사·수정본·최종 후보를 직접 읽었다. 이 기록은 **v19 이후의 합격 증거가 아니다.**

## 결론

자동 발행 후보는 **29/32**였으나 품질 gate는 실패했다. 기본 관계 wish/decision, 친밀 관계 undecided가 생성된 화자·수신자 ID 때문에 구조 검사에서 차단됐다. 기존 게임 권한 검사는 정상적으로 이 출력을 막았다. 모델은 프롬프트의 빈 수신자 계약과 달리 ID를 생성했고, 당시 범용 생성 스키마가 이를 허용했다. 이후 v19에서 생성 스키마를 기존 게임 계약에 맞추었다. 실패한 출력의 ID를 사후 삭제해서 통과시키지는 않았다.

희망 강화·타인 귀속을 실제로 잡아 수정한 사례와 별개로, 정상 철회 인정 대사도 과잉거절했다. 자동 후보가 있다고 의미 품질 합격으로 계산하지 않는다.
