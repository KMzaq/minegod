# AI 장기기억·다중 신 대화 통합 설계

2026-09-21 / 설계 v1 + M0 대화방 변경 반영 / **M0 완료·기존 방 연결 보완 JAR 배포·M1 미착수·서버 부팅 미검증**

## 결론

플레이어 행동은 기존 게임 원장을 원본으로 유지한다. 대화는 월드별 공용 원문 저장소에 한 번 기록한다. 신의 기억에는 실제로 들은 대화, 실제 주시한 행동의 참조, 전달받은 소문과 그 해석을 연결한다. 조회 시에는 **알고 있는가**와 **현재 청중에게 공개 가능한가**를 각각 검증한다.

이미 구현된 원장·주시·개인 회상·소문/회복·다인 대화를 폐기하는 신규 엔진이 아니다. 현 기능을 보존하면서 저장, 근거 추적, 검색, 신별 발언 조정을 단계적으로 통합한다.

## 확정 방향

- 기존 게임 행동 기록을 재사용하고 신별로 행동 원본을 복제하지 않는다.
- 기록이 허용된 지원 채널의 전체 대화 원문을 수집한다. 새 방의 명시적 기록 `off`는 예외이며 수집과 NPC 열람 권한은 별개다.
- 보관 일수 제한을 두지 않는다. 월드별 기록·기억 합산 상한은 **100,000,000,000 bytes(100GB)**다.
- 오래된 시험용 `memories.json`과 대화 로그는 새 기억의 입력에서 제외한다. 파일 삭제나 월드 초기화는 하지 않는다.
- 신규 Primary/Secondary 순차 생성은 우선 플레이어 1명·신 최대 2명으로 검증한다. 이미 개발된 방당 최대 64플레이어·16신 참가와 병행 대화방 기능을 축소하지 않는다. 현재 응답은 한 턴 한 신이다.
- RisuAI, 천계어·악마어·요괴어·고대어의 습득/해독 시스템은 넣지 않는다.

## 추천 구현 흐름

**M0 기준 고정 → M1 저장·용량 → M2 전체 대화 수집 → M3 행동/소문 참조·공개 → M4 파생 기억 → M5 검색 전환 → M6 다중 신 조정 → M7 통합 수용**.

M0의 기준·계약 문서 확정을 마쳤으며 다음 요청은 M1이다. 새 단계가 끝날 때마다 다음 단계에 필요한 계약·미완료를 보고하고, 서버 실행·실제 모델 호출·배포는 별도 승인으로 남긴다. 자세한 요청문은 [구현 계획](08_단계별_구현계획.md)을 사용한다.

## 현재 상태와 문서 우선순위

최신 연결 기준은 [PROJECT_HANDOFF 51~53절](../../인수인계/PROJECT_HANDOFF.md), 개발·서버 배포본은 게임 1.0.13 / AI 0.1.14, 콘텐츠 배포본은 기존 0.1.0이다. 48절과 M0의 기존 CSV는 2026-09-20 당시 기준으로 보존한다. [JAR 배포](../../docs/ROOM_RECORDING_RELEASE_20260921.md)는 완료했지만 서버 부팅/실제 플레이 검증과 M1 구현은 별개다.

기존 정책·계약 전체를 여기 복제하지 않는다. 현재 동작은 최신 소스와 후속 기록, 기존 행동/주시 정책은 해당 원문을 따른다. **이번 사용자 결정인 전체 대화·무기한 보관·100GB와 이 문서의 후속 설계는 구현 전 목표**다. 이전 문서의 작은 한도나 기간 제한을 이미 수정했다고 간주하지 않는다.

최초 설계와 2026-09-20 M0는 문서 작업이었다. 2026-09-21에는 변경된 채팅에 맞춰 게임 발화 통지→기존 TXT 기록과 방 이동 후 기억 근거 검증을 보완하고 후속 요청으로 JAR을 배포했다. 신규 SQLite·100GB·전체 채널 RAW는 여전히 후속 M1~M2이며, 원본 기획서·콘텐츠·서버 설정·월드는 바꾸지 않았다.
