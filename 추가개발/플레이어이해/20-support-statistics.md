# 누적 플레이 통계와 진행 지원

2026-10-20 · `behaivior` · 사용자 재확정에 따른 구현 기준. 이전 대사 교정 실험과 구분한다. 운영 미배포.

## 목적

플레이어가 원활하게 진행하도록 **통계 → 근거 있는 잠정 성향 → 필요할 때 선택 가능한 도움**을 제공한다. 행동 한 건을 NPC가 정확히 복창하는 것이 핵심 기능은 아니다. 모델은 `gemma4:12b`를 유지한다.

## 네 영역

| 영역 | 누적 근거 | 해석·지원 |
|---|---|---|
| 평소 플레이 | 농사·제작·건축·채집·낚시·탐사·퀘스트의 실제 수행 | 내실/탐험 등 복수 경향. 활동량과 활동 구간을 분리하고 추천 후보만 제시 |
| 레이드 | 실제 참가 run 안에서 공격·방어 사용, 작성형 기믹/지원 선택 | 공격 활용/신중한 방어/동료 지원. 장비·기믹·역할 영향을 인정하고 실력·인격·부정 성향으로 해석하지 않음 |
| AI 대화 | 실제 플레이어 발화의 정보 요청·도움 요청·친목/농담 등 | 대화 방식별 반복 경향. AI/NPC 발언을 플레이어 성향의 근거로 사용하지 않음 |
| 등장인물 목표 | 실제 ID가 확인된 정보 탐색·명시한 의향·대상 선택 | 관심/희망/검토/본인이 밝힌 결심과 행동 진행을 분리. 타인의 계획·인용은 본인 목표에서 제외 |

## 집계와 변경

- 게임 원장이 원본이다. 같은 원장 writer에서 재구축 가능한 누적 집계를 유지하며 최근 400개 진단 표시가 전체 통계를 대체하지 않는다.
- 원본의 월드·플레이어·분석 시작 경계를 지킨다. 중복 원문/재시도는 한 번만 반영한다. 정식 분석에 시험 자료를 섞지 않는다.
- 단순 행동 수와 독립 구간(run 또는 게임 시간 10분 구간)을 따로 센다. 한 자리 반복이나 한 번의 대화가 성향을 확정하지 않는다. 최근 활동 구간도 따로 유지해 새로운 플레이 방식이 나타날 수 있게 한다.
- AFK·오프라인·활동 부재는 표본이나 감점 분모가 아니다. 시간 경과만으로 관심이 식거나 목적을 포기한 것으로 처리하지 않는다.
- 추정은 복수로 공존한다. 본인 이의 제기·목적 철회가 우선한다. 통계 누락/한도는 숨기지 않는다.

## 활용 경계

- 평상시 대화에는 전체 프로필·목표를 넣지 않는다. 대화 기억 조회는 유지한다.
- 본인이 통계/도움을 열거나 개인화 지원을 요청한 경우에만 참고한다. 선택지를 제시하고 현재 명시적 요청을 우선한다.
- 자기 화면의 통계는 NPC의 지식이 아니다. NPC 입력은 실제 청취/목격/공개 권한을 통과한 자료에서만 만든다. 비공개 프로필을 요청 분류 하나로 자동 공개하지 않는다.
- `/mythprofile`의 **NPC 진행 도움용 공유**는 기본 차단이다. 직접 허용한 경우에도 본인 한 명과 NPC 한 명의 비밀방에서 자기 평가/개인화 도움을 요청한 턴에만 영역별 지원 후보 최대 2개(총 6개)·목표 최대 2개의 요약을 보낸다. 원문·좌표·타인 기록은 보내지 않는다. 공유 철회는 진행 중 응답도 무효화하며, 철회 저장 실패 시에도 현재 서버에서는 차단을 유지한다.
- NPC에 성향표를 해설시키지 않는다. 누적 경향에서 **게임이 고른 작은 지원 후보**(`supportOptions`)를 전달하고 NPC는 그중 현재 요청에 맞는 것을 제안한다. 본인 화면에는 통계·경향·근거를 그대로 제공한다. 인물 목표에는 게임 등록 이름과 원래 의향/진행 단계를 함께 전달해 대상 활용을 돕되 만남·실행을 확정하지 않는다.
- 목격 행동 회상과 개인화 지원은 별도 경로다. “무엇을 하는 것을 봤어?”에만 소량의 목격 기록을 조회한다. 자기 평가/진행 도움에는 누적 통계 기반 지원 후보를 사용하며, 공유가 차단되었거나 근거가 부족하다고 최근 수확 몇 건으로 대체 평가하지 않는다. 기존 대화 기억은 두 경우 모두 유지한다.
- 보상·가격·난이도·관계·게임 진행을 불리하게 바꾸지 않는다. 자동 수락·아이템 소비·보상 지급·등장인물 스폰도 하지 않는다.
- 충분한 근거가 있으면 “최근 탐험 쪽 활동이 잦다”는 가설을 사용할 수 있다. 모든 답변에 “모른다”를 강요하거나 NPC 성격을 지우는 정형 답변으로 바꾸지 않는다.

## 구현·검증 순서

1. 기존 누적/최근 집계와 본인 화면을 보완하고, 반복·다인 격리·AFK·재시작·정정을 검사한다.
2. 실제 레이드와 대화 생산자·등장인물 대상 연결을 보완한다. 실제로 수집하지 못하는 전술/콘텐츠 선택은 미지원으로 표시한다.
3. 요청형 지원과 NPC 허용 입력을 연결한다. 평상시 입력 비포함, 개인정보 격리, 명시적 선택 우선, 작은 영향 상한을 검사한다.
4. 전체 빌드/회귀와 동일 모델의 실제 입력·출력을 검사한다. 일반 문체 문제와 통계·목적 오귀속/권한 오류는 구분해 기록한다. **검증 전 서버 배포 금지.**

구현 결과·남은 항목은 후속 검증 보고서와 브랜치 인수인계에 기록한다. 이 설계 자체는 네 영역의 구현 완료 선언이 아니다.

## 이번 개발 구현의 구체적 범위

- 게임 `1.0.36` / AI `0.1.50`. 기존 원장의 동일 writer에서 누적 통계를 재구축한다. 활동 횟수와 독립 구간 수를 분리하고, 평소 플레이/레이드/대화의 최근 32개 구간을 별도로 유지한다. 한 영역의 플레이가 다른 영역의 경향을 밀어내지 않는다. 3개 이상 독립 구간의 반복부터 잠정 경향으로 표시한다.
- 실제 레이드 참가자·활성 run·대상 보스를 확인한 공격 적중과 방패 방어 자세 전환을 수집한다. 방패 유지/재접속을 반복 선택으로 세지 않는다. 이 지표만으로 “공격적인 사람”, “소극적”, 실력, 위험 회피 성공률을 단정하지 않는다.
- 실제 플레이어 발화에 기존 의도 분류 결과를 연결해 정보 요청/진행 도움/친목·잡담을 기록한다. 추가 LLM 호출은 만들지 않는다. 등장인물 이름이 명시된 경우에만 선택적 목표 분류 필드를 추가한다. 게임이 현재 발화에 실제 존재하는 이름 후보를 제공하고 ID·화자·원문·턴·분석 시작 경계를 검증한다.
- 자동 목표 기록은 등록된 신의 `MEET`/`LEARN_ABOUT`에 대한 관심·희망·검토·부정·철회·보류다. `DECIDE`/완료/실행으로 자동 승격하지 않는다. 같은 턴은 한 번만 반영하고, 반복 희망도 희망으로 남는다. 분류 실패는 목표 기록을 생략할 뿐 정상 대화를 막지 않는다.
- “전에 누구에 대해 뭐라고 했지?” 같은 기억 재조회는 새 인물 관심 근거가 아니다. 기존 기억 조회 판정을 재사용해 양성 목표 갱신에서 제외한다. 현재 발화의 명시적 부정·철회·보류는 과거 목표를 함께 언급해도 우선 반영한다.
- 이름은 게임 정의의 literal/서버 표시 이름과 번들 공식 한국어 번역에서만 가져온다. 예컨대 `Demeter`와 `데메테르`는 같은 게임 ID다. AI 별명 목록이나 별도 신 identity DB를 만들지 않는다. 원문 발행 이후 정의 generation이나 기록 runtime이 바뀌면 이전 분류 결과를 받지 않는다. 기본 작업본에 등록되지 않은 디오니소스·아폴론 의미 테스트를 실제 운영 대상 연결 완료로 해석하지 않는다.
- 본인 화면에 누적 통계/최근 경향/근거와 “진행 도움” 전환을 추가했다. NPC 공유와 화면 도움은 독립적이다. 기존 대화 기억 조회는 유지하고, 평상시 입력에는 새 통계 요약을 주입하지 않는다.
- 최신 카드 프로토콜은 `understanding-2`이며 서버/클라이언트 게임 모드 버전 일치가 필요하다. 새 원장 이벤트 두 종류가 추가되어 구버전 바이너리의 무조건적인 롤백을 보장하지 않는다. 배포·마이그레이션은 이번 작업에서 하지 않았다.

## 아직 단정하지 않는 것

- 레이드 위치 선정·회피·힐/지원 기술·장비/역할별 기회 보정은 아직 계측하지 않는다. 작성형 기믹/동료 지원 선택 계약은 기존 기능이며 정식 콘텐츠가 연결한 부분만 근거가 된다.
- 인물 관련 보상 선택·특정 지역 탐사·퀘스트가 어느 목표의 준비/추진인지 연결하는 **콘텐츠별 매핑은 아직 없다**. 일반 농사·이동·선물 등을 임의로 특정 인물의 목표로 연결하지 않는다. 목적 상태 리듀서의 준비/추진 지원과 실제 콘텐츠 생산자의 연결 완료는 다르다.
- 대명사만 사용한 대상, 등록 이름과 다른 별칭, 일반 스토리 NPC 전체, 한 턴의 다중 목표 추출은 지원 완료가 아니다. 한 건을 놓쳤을 때 속마음을 지어내는 대신 다음 근거를 기다린다.
- 누적 행동 수와 최근 구간은 지속 유지하지만 독립 구간 중복 제거 집합은 키별 8,192개 상한이며 초과 시 “이상”으로 표시한다. 목적 조회는 기존 4,096근거/64목표 한도를 유지한다. AFK나 오래 접속하지 않은 시간 때문에 감점하지 않는다.
