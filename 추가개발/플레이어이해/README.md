## 현재 구현

최신 개발 게임1.0.36 / AI0.1.50은 [20](20-support-statistics.md)을 따른다. 레이드·평소 플레이·대화 누적 경향, 현재 발화의 선택적 등장인물 목표 기록, 본인 화면·명시적 공유 후 요청형 NPC 도움을 구현한다. 단일 관찰 복창이나 인격 평가가 핵심이 아니다. [이번 검증](../../검토결과/support-statistics-20261020/REVIEW.md)의 미완료/제한을 함께 확인한다. 운영 미배포.

선행 AI0.1.48~49는 [19](19-need-only-dialogue-support.md)를 따른다. 기록과 대화 기억은 유지하고 관찰 기반 지원은 현재 요청에 필요한 경우에만 조회한다. 아래0.1.47의 매 턴 관찰/관심 가설 입력은 선행 이력이다.

2026-10-20 게임1.0.35 / AI0.1.47 후속은 [18](18-native-dialogue-support.md)을 따른다. 명시적 NEW 경로에 게임 권한이 붙은 대화 원문 조회와 단일 신 비밀방의 관찰 기반 잠정 가설을 연결했다. 본인 프로필 전체 공개·목적 자동 추출·운영 활성화는 하지 않았다. 실제 LLM/그래픽 및 전체 회귀의 실행별 판정은 [검증 보고서](../../검토결과/native-dialogue-support-20261020/REVIEW.md)에 별도로 남긴다. 아래 버전들은 선행 이력이다.

최신 활동 후속은 게임1.0.33의 [17](17-minecraft-support-activities.md)이다. Minecraft 활동 수집과 본인 카드 확장, AFK·미참여로 인한 직접/조회창 불이익 차단을 구현했다. 실제 목적 대상·관찰자·추천 보정 연결까지 완료된 것은 아니며 서버 미배포다. 아래 게임1.0.32/AI0.1.44~45 결과는 선행 목적/대화 실험 이력이다.

후속 AI0.1.45는 [15](15-purpose-reply-contract.md)의 핵심 구절 보호·제한된 후속 표현과 별도 의미 검토 후보를 구현했다. 실제 비교 결과와 한계는 [대사 계약 검증](../../검토결과/purpose-reply-20261019/REVIEW.md)을 따른다. 기본 게임 대화 경로에는 활성화하지 않았으며 전체 의미/자연스러움 gate 미완료·미배포다.

개발 게임1.0.32 / AI0.1.44. [14](14-evidence-driven-purpose.md)의 네 축 목적 상태, 게임 원본 기반 근거 누적·영속 주석, 본인 화면·철회를 구현했다. 새 NPC 문맥 입력과 실제 Gemma 생성·검토·수정을 격리 평가했지만 **전체 의미 gate는 실패**했다. 실제 방 대화/Native 기억의 자동 추출, 관찰자별 운영 연결과 콘텐츠 대상 매핑도 미완료이며 자동 목적 추출은 비활성이다. [현재 검증 기록](../../검토결과/purpose-state-20261019/REVIEW.md)과 [브랜치 기록](../../인수인계/브랜치실험/behaivior/PROJECT_HANDOFF.md)을 우선한다.

## 범위

행동 기록을 재작성하거나 별도 호감도·게임 사실 DB를 만들지 않는다. 사실, 행동 경향, 현재 목적, 인물의 평가를 분리한다. 추론은 게임 실행 권한이 아니다. 테스트 기록은 정식 분석에서 제외한다. 원문 보관에 일수 제한을 추가하지 않으며 기존 월드 기록 용량 정책(기본 100GB)을 유지한다.

첫 수직 구현은 출처 추적 가능한 행동 분석과 본인 확인·정정 화면이다. 상세 레이드 선택 계측과 의미 기반 목적 추출은 각각 실제 입력 생산자 및 평가를 연결한 뒤 완료 처리한다. 미연결 항목은 UI에서도 근거 부족으로 표시한다.

## 이전 HanesTest 개발 결과 (0.1.43 당시 기록, 현재 상태 아님)

**현재:** 개발 게임1.0.31 / AI0.1.43, 같은 Gemma 유지·**전체 의미 gate 실패/미배포**. [13](13-independent-semantic-frames.md)의 독립 원문/초안 해석 후보는 일반 회귀20/28로 악화돼 평가 전용으로 격리했다. 기본 개발 경로는 이전 일반V7/관계V6를 유지하고 수정문이 플레이어의 1인칭을 NPC 관점으로 그대로 복사하는 경우를 차단한다. 기본 경로 일반27/28, 보존 대조14/14(모델13+구조차단1), 실제 수정6/7이며 새 생성에서도 정상 대사의 과잉거절과 화행 변화가 남는다. [실제 대사·최종 검증 기록](../../검토결과/player-understanding-20261019/claim-v29-v36-manual-review.md)을 우선한다. 이전0.1.42 결과는 [12](12-relational-audit-and-local-repair.md)의 당시 기록이다. **해결 완료/운영 추천/배포 준비 완료가 아니며 자동 목적 추출도 비활성이다.** 목적 영속화·장기 누적·관찰자 통합·콘텐츠 추천과 실제 클라이언트 확인은 미완료다.
