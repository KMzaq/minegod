# 검증과 단계별 도입

## 단계

1. 출처·가설·정정 계약과 원장 읽기: 오래된 테스트 제외, bounded/비동기, 재시작.
2. 일반 행동 분석과 본인 화면: 실제 기록으로부터 근거 표시, 정정 저장, 오류/빈 상태.
3. 레이드 선택 계측: 실제 결정 기회 생산자와 연결, 역할/성공/시도 분리.
4. 허용된 대화·주시 근거 기반 목적/관찰자 해석: 청중별 격리, 정정·목적 변경.
5. 자연스러운 대화 연결: 실제 전달·반복 억제·문맥 적합성, 단독/다중 신.
6. 작성된 적격 콘텐츠 제안: 기존 실행 검증/확인/결과 환류. 임의 보상·난이도·관계 변경 없음.

각 단계는 코드 존재, 결정적 테스트, 실제 모델 평가, 인게임 확인, 배포를 별도로 기록한다.

## 필수 불변식

다른 플레이어/월드/세션 섞임 없음. 숨겨진 근거를 바꿔도 허용 관찰자 입력은 동일. 테스트/분석 시작 전 기록 제외. 승패의 대표 기록자를 모든 행동 주체로 사용하지 않음. 동일 원본 재생 중복 없음. 기록 부족을 부정 성향으로 해석하지 않음. 서버 결과 없는 성공 주장 없음. 정정 실패/중복/늦은 완료/재접속에서 허위 성공 없음. 새 기능 때문에 기록 OFF를 우회하지 않음. 원장 용량 실패로 레이드/보상을 중단하지 않음.

## 플레이 경험 사례

| 사례 | 좋은 경험 | 실패 |
|---|---|---|
| 레이드 실패 직후 | 전투 맥락을 이해하고 적절할 때 반응 | 죽음 횟수로 비겁/무능 판정 |
| 지원할 기회가 없음 | 모름/근거 부족 | 비협조적이라 평가 |
| 특정 신을 찾음 | 아는 인물이 적절한 순간 질문/단서 | 모든 NPC가 속마음을 앎 |
| "그 뜻 아니야" | 설명을 받아 다음 턴 판단 조정 | 사과만 하고 같은 단정 반복 |
| 관심사가 바뀜 | 현재 목적을 우선하고 옛 목적은 과거로 취급 | 오래된 추천 강요 |
| 신이 여럿임 | 각자의 정보와 가치관에 따른 반응/침묵 | 같은 기억을 연속 낭독 |
| 무관한 질문 | 현재 질문에 답함 | 모든 답을 성향·퀘스트로 연결 |
| 플레이어 화면 | 근거와 불확실성을 이해하고 이의 제기 | 가짜 확률/정체성 낙인/비밀 유출 |
| 연결 지연 | 기다림·실패를 정직하게 표시 | 늦은 결과가 다른 화면/턴 덮어씀 |

## 의미 품질 평가

동일 입력의 기존/변경 비교 + 여러 턴의 독립 대화 이력 비교를 둘 다 사용한다. 각 상황은 표현·관계·성격·정보 공개 조건을 바꾼다. 정해진 모범 문장과 문자열 일치만 검사하지 않는다. 3회 이상 반복은 초기 재현성 점검이며 만족도 통계 증명이 아니다.

평가 축: 현재 발화 적합성, 사실/추정 구분, 인물 일관성, 기억의 유용성, 반복·간섭, 정정 후 회복, 선택권, 응답 지연. 치명적 권한/비밀/실행 오류는 평균 점수로 상쇄하지 않는다. 침묵·답변 차단만 늘려 안전 점수를 얻은 것은 자연스러움 개선이 아니다.

실제 플레이 평가는 UI 열람 → 근거 확인 → 정정 → 후속 대화 → 다음 접속의 연속 경험을 확인한다. 모델/자동 판정만으로 플레이어 만족을 확정하지 않는다. 실제 확인하지 않은 항목을 통과로 기록하지 않는다.
