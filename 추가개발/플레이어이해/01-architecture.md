# 구조와 정보 경계

## 데이터 흐름

게임 원본 사건 → 출처를 가진 상황별 지표 → 수정 가능한 가설 → 본인 확인 화면 또는 관찰자별 허용 투영 → 대화/기존 콘텐츠 제안 → 게임 검증.

본인 화면의 분석을 NPC에게 그대로 전달하지 않는다. NPC 투영은 직접 청취·허용 주시·실제 전달받은 소문으로 입력을 제한한 뒤 계산한다. 비밀을 포함해 계산하고 출처만 삭제하는 방식도 금지한다. 현재 청중에게 공개 가능한 범위는 보유 지식과 별도로 검사한다.

## 의미 계약

- 사실: 원본 occurrence/source revision, 실제 행위자/대상, 월드, 시각, episode/run, 수집 범위.
- 지표: 활동 종류와 독립 구간 수. 행동 횟수·선택 기회·성공률은 서로 다른 값.
- 성향: domain/context별 최근·누적 방향, 지지·반대 근거, 관측 범위, 규칙 버전. 고정 인격/도덕/실력 판정이 아니다.
- 목적: 종류·정확한 게임 대상 ID, 본인 의향·관측 진행·근거 강도·생명주기를 분리한다. 반복된 희망은 결심이 아니고 행동 추론은 본인의 발언이 아니다. 대상이 모호하면 미확정이며 대사는 달성을 증명하지 않는다. [근거 누적형 목적 계약](14-evidence-driven-purpose.md)을 따른다.
- 정정: 원본 삭제가 아니라 가설에 대한 이의 제기. 새 원본과 정정 모두 보존한다. 당사자 설명은 발언 사실이지 객관적 세계 사실의 수정 권한이 아니다.
- 인물의 평가: 신의 가치관·관계·감정에 따른 해석. 플레이어 화면은 비공개 NPC 평가·숨겨진 인물·비밀 퀘스트를 노출하지 않는다.

## 일반 활동

탐험/정착, 채집/농사/제작/건축/전투 활동, 도전/안정, 준비/즉흥, 독립/협력, 공동 기여, 인물·서사 관심, 실험/반복을 구분한다. 초기 수집으로 확인할 수 없는 축은 UNKNOWN이다. 강제 퀘스트·자원 부족·동료 부재·기록 비활성화를 선호로 오해하지 않는다. 전체 행동 비율을 모르는 상태에서 일부 기록의 비중을 플레이 시간 비율로 표시하지 않는다.

## 레이드

기존 승패/명단은 참가와 결과 근거다. 대표 기록자는 파티 전체의 행동 주체가 아니다. 승패·DPS·사망만으로 기믹 성향이나 실력을 판정하지 않는다.

선택 계측 계약에는 run/phase/mechanic/version, 실제 참가자, 역할(미확정 가능), 유효 기회 수, 선택 수, 강제/행동 불가/정보 부족 여부, test 구분이 필요하다. 기믹 시도와 성공, 지원 시도와 유효 회복량, 위험 선택과 피해 결과를 분리한다. 위치 매 tick 저장 대신 실제 결정 구간에서 제한된 요약을 만든다. 서버 취소·재시작·연결 장애는 의지나 성격 근거가 아니다.

## 갱신/보관

독립 구간별 중복 상한, 반대 근거, 최근 변화, 역할/장비/콘텐츠 버전 차이를 고려한다. confidence는 LLM 자기평가 확률이 아니다. 반복 조회·NPC가 재서술한 내용·추천을 반복 수락한 결과는 독립 근거로 증식하지 않는다.

기존 원장 위의 파생 분석을 우선하며 새로운 원문 저장소를 만들지 않는다. 비동기 bounded read, 출처/권한/revision 재검증, OFF/용량 부족/기록 누락 표시가 필수다. 분석 실패로 게임 진행을 막지 않는다. 새 feature의 분석 시작 경계 이후만 사용하며 과거 테스트 자료를 자동 소급하지 않는다.

## 게임 반영

초기에는 대화와 기존 적격 콘텐츠의 제안까지만 허용한다. 보상·호감도·가격·난이도·출현·스토리 정사를 추론으로 변경하지 않는다. 욕구는 수주·소비·모집 시작 동의가 아니다. 기존 Gateway의 확인과 검증을 유지한다. 일반 NPC 연결은 기존 게임 identity와 지식 provider를 확장하며 신 ID를 복제하지 않는다.
