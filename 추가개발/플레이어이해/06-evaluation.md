# 실제 모델 평가와 보류 이유

이 문서는 1차 프롬프트 비교 이력이다. 이후 별도 출처 검증 추출 단계를 추가한 결과는 [07 후속 평가](07-followup.md)를 따른다. 두 방식 모두 아직 기본 비활성이다.

2026-10-18. 현재 로컬 Ollama `gemma4:12b`에 **합성 장면만** 입력했다. 실제 플레이어 기록·운영 월드·신 프로필은 변경하지 않았다. 분류/검색/최종 근거 검토/수리/게임 실행을 모두 통과한 통합 대화가 아니라, 실제 생성 프롬프트와 로컬 클라이언트의 초안 비교다.

## 실험 구성

동일 장면에 기존 프롬프트(새 지침 제외)와 새 지침을 각각 적용하고 호출 순서를 교대했다. 동일 사례 3회 반복이며 사용자 만족도 통계나 모델 일반 정확도 추정은 아니다. 인물은 ‘직설적·신중함, 선택의 자유를 중시’하는 합성 시험 프로필 한 종류다. 이 가치관이 추상적 자율성 발언에 영향을 주었을 가능성이 있으나, 품질을 좋게 보이게 하려고 프로필을 바꾸지 않았다. 다른 성격/관계·다중 신 평가는 추가로 필요하다.

| 버전 | 생성 호출 | 호출 실패 | 기존 구조 검사 실패 | 의미 평가 |
|---|---:|---:|---:|---|
| [v1](../../검토결과/player-understanding-20261018/live-v1) | 36 | 0 | 0 | 추상적인 자율성 설명·안전한 회피가 많음 |
| [v2](../../검토결과/player-understanding-20261018/live-v2) | 60 | 0 | 0 | 지침 축약 후에도 구체적 목적 추측을 회피 |
| [v3](../../검토결과/player-understanding-20261018/live-v3) | 60 | 0 | 4 | 추측 일부 개선, 근거 없는 동기/상황 덧붙임·훈계 잔존 |

v1은 6사례×3회×2군. v2/v3는 7사례×3회×2군 + 3턴 독립 대화×3회×2군. 합계 156회. 4개 구조 실패는 v3 대조군 2개/변경군 2개의 `Unauthorized speech audience`이며 실제 운영에서 허용된 전달로 해석하지 않는다. HTTP 성공과 JSON 초안 생성은 유효한 게임 대사 성공이 아니다.

## 관측 결과

- 명시적 욕구: 대체로 질문을 이어 갔지만 일부 발화 주체 표현은 모호했다.
- 목적 정정: 옛 OOO 만남 목적을 다시 단정하지 않는 사례는 확인했다. 다만 친구 부탁 한마디로 관계가 깊다고 덧붙이거나 농사 능력을 근거 없이 칭찬한 사례가 있었다.
- 주제 전환/추천 거절: 별 이야기·휴식·농장 이름 대화로 이동했고 레이드 추천 반복은 보이지 않았다. 실제 장기 기록의 억제 기능을 증명한 것은 아니다.
- 목적 추측 요청: v2는 근거가 있는데도 ‘본인만 안다’며 회피했다. v3는 소식을 찾고 있다는 말을 연결하기 시작했지만, ‘그가 가진 무언가/진실’이나 인근에 단서가 있다는 식의 근거 없는 사정을 보탰다.
- 레이드 실패: 사망 횟수로 직접 비겁/무능 판정을 하지는 않았으나, 구체적인 전투 상황을 묻기보다 긴 가치관 설명으로 피하는 경우가 남았다.
- 3턴 독립 대화: 정정→농장 이름으로 화제를 옮길 수는 있었다. 없는 정보 조회를 하겠다는 약속, 정보 부재를 과거 접촉 부재로 확장하는 문제가 남았다.

따라서 **자연스러움·안전한 목적 해석 모두 최종 합격 처리하지 않았다.** 침묵/회피만으로 안전해진 것을 좋은 플레이 경험으로 평가하지 않는다. 특정 문장의 고정 답변을 추가하지 않았다.

## 적용 결정

`PlayerUnderstandingPrompt.productionPolicy()`는 빈 문자열을 반환한다. 새 지침을 기본 주/보조 생성 경로에서 사용하지 않으며, 자기 화면의 개인 메모를 AI에게 넘기지 않는다. 후보 텍스트와 비교 도구는 후속 개선용으로 보존했다. 기존 다른 작업의 지침·근거 검토·기억 검색은 그대로 유지한다.

후속 실험은 [목적 후보 계약](05-next-stage-contracts.md)의 출처 검증을 먼저 붙이고, 같은 미세 표현의 반복 수정보다 정보 선택→해석→응답의 어느 단계가 실패했는지 분리해 평가한다. 적어도 다음 게이트가 필요하다.

1. 청중·화자·근거 ID·게임 실행 권한 결정적 검사가 모두 통과할 것.
2. 목적 있음/모름/대리 질문/정정/변경/가정/인용을 서로 구별할 것.
3. 관련 없는 질문을 목적 추론으로 가로채지 않고, 알 수 있는 경우까지 회피하지 않을 것.
4. 성격/관계/청중을 바꾼 비교와 독립된 연속 대화에서도 같은 오류가 재현되지 않을 것.
5. 실제 클라이언트에서 근거 확인→정정→후속 대화의 경험을 사람이 확인할 것.

이 게이트는 이번에 통과했다는 뜻이 아니다. 운영 활성화와 보상 등 게임 상태 영향은 별도다.

## 재현 도구 주의

`playerUnderstandingLiveEvaluation`은 출력 폴더 속성을 명시했을 때만 로컬 모델을 호출한다. 출력 JSON은 CREATE_NEW로 저장하므로 새 폴더를 사용한다. 최종 소스는 기본 경로 비활성화 후 실험 지침을 시험 하네스에서만 추가하도록 변경했다. 따라서 위 v1~v3 원본 JSON의 메시지가 당시 실험의 정확한 입력 증거다.

최종 하네스는 구조 검사를 통과하지 못한 NPC 초안을 다음 턴의 ‘전달된 발화’로 이어 붙이지 않도록 보완했다. v3에서 해당 문제가 생긴 연속 대화는 마지막 턴이어서 후속 턴 오염은 없었지만, 기존 결과를 사후 수정하거나 재평가 성공으로 바꾸지 않았다. 최종 하네스 변경 뒤 새 모델 비교는 실행하지 않았다.
