# 1차 장비·스킬 구현 후 시험 계획

2026-10-22. 이 문서는 실제 구현·플레이 시험의 결과가 아니라 사용자가 구현한 뒤 수행할 시험 명세다. 모든 피해량은 체력 포인트 기준이며 2포인트=하트 1칸이다.

## 목적과 범위

- 무기 스킬 없는 장비, 공격 스킬 무기, 대응형 무기 모두 선택할 이유가 있는지 비교한다.
- 무기 스킬과 별도 습득 스킬을 혼동하지 않는다. 현재 일반 스킬은 무기 우클릭과 선택한 습득 스킬 J 입력을 따른다. 다중 슬롯·직업 제한을 새로 확정하지 않는다.
- 장비 7등급은 일반/고급/희귀/영웅/전설/신화/근원이며 이번 시험은 같은 등급의 역할 차이를 먼저 검증한다.
- 이 시제품은 정식 인물 보상 배정이나 신규 스토리를 확정하지 않는다. 인물별 보상은 기존 이야기와 획득 난도를 맞춰 후속 연결한다.

## 구현 순서

1. 실제 장비 속성 및 임시 정의 ID 등록. 테스트용 정의와 정식 제작 관리키를 별도로 관리한다.
2. 마나·쿨타임·시전 식별자·서버 대상 판정·시전 시작 장신구 기록을 기존 기반에 연결한다.
3. 검기, 패링, 대쉬 등 신규 동작은 기존 파서에 없는 필드를 억지로 추가하지 않고 독립된 확장 명세에 따라 구현한다.
4. 허수아비 또는 고정 표적에서 피해·충돌·자원 및 실패 처리를 검증한다.
5. 단일 보스의 명확한 예고 공격과 회피 가능한 범위 공격으로 대응형 스킬을 비교한다.
6. 최종적으로 5인 동시 사용을 시험한다. 허수아비 수치만으로 실제 레이드 밸런스 완료를 선언하지 않는다.

## 비교 조건

각 결과에 장비, 활성 가호 단계, 장신구 조합, 기본 체력, 스킬, 보스 방어, 참가 인원, 서버 TPS를 기록한다. 무기만 바꾼 시험에서는 나머지 조건을 고정한다. 가호 없음과 동일한 고정 가호 세트를 나눠 시험하며 서로 다른 가호 상태의 점수를 직접 비교하지 않는다.

- 짧은 구간: 10초간 순간 피해와 자원 소비를 측정한다.
- 긴 구간: 180초간 실제 피해·회복·스킬 횟수·고갈 시점을 측정한다.
- 대응 구간: 같은 예고 공격을 반복하여 회피 성공, 패링 성공/실패, 이동 손실 시간을 기록한다.
- 실제 레이드 구간: 5명 구성에서 처치 시간·사망·구조·기믹 수행·보스 무력화 시간을 기록한다. 목표 처치 시간은 보스 패턴 설계와 함께 후속 확정한다.

## 필수 회귀 시험

| 시험 | 기대 결과 |
|---|---|
| 마나 부족·기절·사용 권한 없음 | 시전 전 실패, 비용과 쿨타임 무소모 |
| 정상 시전 후 공격 빗나감 | 마나와 쿨타임 소모, 환급 장신구가 있으면 정해진 조건만 적용 |
| 무기 교체·스킬 재선택·재접속 | 진행 중인 쿨타임 초기화 금지 |
| 광역이 여러 대상 적중 | 같은 시전의 연계 발동은 정해진 한 번, 대상별 중복 시전 생성 금지 |
| 같은 권리 장신구 복제 | 두 번째 합법 획득권리로 인정하지 않음 |
| 별도 획득한 같은 장신구 2개 | 기존 허용 규칙대로 효과 중첩 |
| 최대 마나 장신구 교체 | 상한 증가만으로 즉시 마나 충전 없음, 감소 시 새 상한으로 제한 |
| 시전 중 장신구 교체 | 시전 시작 기록을 사용, 나중 착용 효과 소급 적용 금지 |
| 벽·문·낮은 천장으로 이동 | 충돌 판정에 맞춰 정지, 벽 통과·끼임·비인가 구역 침입 금지 |
| 월드 경계·미로딩 청크 접근 | 안전한 이동 종료, 새 지역 강제 로딩을 전제로 하지 않음 |
| 패링과 무적이 동시에 가능한 순간 | 방어 결과와 반격 횟수를 한 피해 사건 기준으로 중복 처리하지 않음 |
| 기믹성 강제 피해·공허 | 일반 패링·짧은 무적으로 임의 무효화하지 않음 |
| 5인 동시 투사체·다단 적중 | 시전별 적중 기록 유지, 중복 피해·서버 부하 확인 |
| 아군·중립 생명체·상자·블록 | 명시적으로 허용한 대상만 영향, 기본은 아군 피해와 지형 파괴 없음 |

## 자원 계산의 기준

기본 최대 마나는 200, 자연 회복은 초당 최대치의 1%다. 살아서 접속 중이며 회복을 버리지 않는 구간을 가정하면 180초간 기본 자연 회복 상한은 360, 시작 마나 200을 합친 이론상 총량은 560이다. 실제로는 최대치에서 버려지는 회복, 사망, 조작 및 시전 간격 때문에 사용할 수 있는 양이 다를 수 있다.

최대 마나 증가량이 +100인 장신구가 한 개면 최대 300·초당 3, 두 개면 최대 400·초당 4가 된다. 이는 계산 예시이며 해당 장신구의 확정 수치가 아니다. 마나 장신구는 저장량뿐 아니라 장기 회복량도 올리므로 지속 화력에 미치는 영향을 반드시 같이 평가한다.

## 조정 원칙

- 스킬 없는 무기의 공격 주기와 일반 타격이 장점이 되는지 먼저 확인한다. 한 번도 쓸 이유가 없다면 단순 외형 선택지로 방치하지 않는다.
- 패링은 숙련 보상이지만 실패해도 항상 유리한 상시 방어 버튼이 되어서는 안 된다. 반대로 보스의 모든 공격이 패링 불가라면 레이드용 선택지로 성립하지 않는다.
- 대쉬 무적은 위험에서 빠져나오는 짧은 기회다. 지연 환경을 고려하되 무한 연결·판정 소급 확대·기믹 무시를 기본으로 제공하지 않는다.
- 같은 역할의 인접 등급은 지속 화력 또는 생존성 약 10~15% 개선을 시험 출발점으로 삼는다. 모든 능력을 동시에 올리는 고정 배율이 아니며 실제 검증 후 조정한다.
- 실제 피해·방어·마나 효율을 먼저 정하고 전투력 고유 점수를 보정한다. 전투력 환산값을 올리는 것으로 실제 아이템 능력이 변경되지는 않는다.
- 전투력 권장값은 관측 결과에 기반해 작성한다. 최소 전투력 수주 제한이나 신규 보스 입장 제한을 이번 문서만으로 추가하지 않는다.

## 완료 기준

1. 정해진 수치·범위·비용·실패 처리가 실제 서버에서 재현된다.
2. 시전·재접속·복제·교체로 비용이나 쿨타임을 우회하지 않는다.
3. 스킬 없는 무기와 공격형·대응형 무기에 각각 유효한 선택 상황이 있다.
4. 단독/5인, 가호 없음/보유, 장신구 없음/단일/중복 조합 시험 결과가 기록된다.
5. 현재 구현된 동작과 추가 구현이 필요한 동작의 목록이 실제 코드와 일치한다.

위 기준은 후속 구현의 완료 조건이다. 이번 기획 문서 전달 시점에는 충족 여부를 시험하지 않았다.
