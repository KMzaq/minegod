# 5인 레이드 1차 전투 시제품 명세

작성일 2026년 10월 22일

## 1 목적과 결정 범위

Minecraft Java 1.21.1 / NeoForge 21.1.248의 약 5인 레이드에서, **평타를 강화한 무스킬 무기와 검기·패링 무기의 선택이 실제로 성립하는지** 먼저 비교한다. 시제품은 무기 3개, 방어구 조합 2개, 습득 스킬 1개, 장신구 2종으로 한정한다. 모든 피해·시간·점수는 **미검증 초기안**이며 실제 구현·서버 배포·게임 내 검증을 완료한 명세가 아니다.

- 장비 7등급 명칭은 일반 → 고급 → 희귀 → 영웅 → 전설 → 신화 → 근원을 채택한다. 이번 비교 장비는 전부 희귀다. 등급별 배율·저장 enum·새 JSON 필드는 확정하지 않는다.
- NPC 6등급은 장비 7등급과 별개다. 하급 이상은 방어구·습득 스킬, 중급 이상은 무기, 상급 이상은 장신구 제공 자격을 가진다. 등급 충족은 지급 조건 통과를 뜻하지 않는다.
- 기존 영구 가호, 인간 루트 제한, 레이드 직접 가호 예외를 변경하지 않는다. 장비·스킬·장신구 습득을 가호 획득으로 기록하지 않는다.
- 아래 proto_cbt:*는 이 문서의 **프로토타입 임시명**이다. 정식 인물 ID나 전체 인물 ID 정책을 신설·확정하지 않는다. 지급 인물은 미배정이다.
- 772명 전체 보상 제작, 신별 특수스킬, 운영 레이드 입장 전투력, 외부 모드 도입은 범위 밖이다. 전달서와 원본 코드는 수정하지 않았다.

## 3 공통 전투 계약

### 3.1 단위와 조작

피해와 체력은 체력 포인트 단위다. 체력 2가 하트 1칸이다. 거리 1은 1블록, 시간 20 tick은 서버 20 TPS에서 1초다. 서버 지연 시 실제 벽시계 시간이 길어질 수 있다. 클라이언트 애니메이션보다 서버 판정을 우선한다.

기본 공격은 좌클릭이며 기존 Minecraft 충전·사거리·치명타·휘두르기·방패·인챈트 처리를 유지한다. 스킬에 이 보정을 자동 복제하지 않는다. 세 무기는 검 계열로 동일한 일반 공격 사거리와 공격속도를 사용한다. 비교 시험에서는 추가 사거리·치명타·쓸어내리기 인챈트를 제외한다.

주 손의 등록 무기 우클릭은 무기 스킬 1개만 사용한다. Shift+우클릭은 기존 일반 상호작용이다. 상자·문·주민 등 상호작용 가능한 대상을 직접 지정했으면 해당 상호작용을 우선하고 스킬을 시전하지 않는 것을 **시제품 입력 확장 계약**으로 한다. 공중·비상호작용 블록을 향한 우클릭만 스킬 후보가 된다. 동일 클릭으로 주 손 스킬과 보조 손 음식·방패가 동시에 발동하지 않도록 소비 여부를 서버와 맞춘다. 무스킬 무기는 rightClickSkill을 생략하고 바닐라 우클릭 동작을 유지한다.

### 3.2 자원과 상태

시간표는 승인 tick을 t=0으로 한다. 검기는 [0,4) 선딜, t=4 발사, [4,10) 후딜이다. 패링은 [0,2) 선딜, [2,6) 판정, [6,14) 후딜이다. 대시는 [0,1) 선딜, [1,5) 이동, [1,4) 회피, [5,8) 후딜이다. 구간 끝 tick은 포함하지 않으며 각 종료 tick부터 다음 입력을 허용한다. 이동·발사 이벤트는 해당 tick의 피해 이벤트 이전에 갱신하는 서버 처리 계약을 사용한다.

- 기본 최대 마나 200, 장신구 증가량을 더한 현재 최대 마나의 1%를 초당 회복한다. 살아서 접속 중일 때만 회복하며 사용 후 회복 대기는 없다.
- 정상 시전 승인 tick에 비용 차감과 쿨타임 시작을 함께 확정한다. 선딜 중 취소·헛침·벽 충돌·목표 무적에도 반환하지 않는다. 조건 검사 이전 실패는 무소모다.
- 사망·관전·기절·메뉴 전용 상태·다른 스킬 선후딜 잠금·마나 부족·쿨타임·무권한은 승인 전 실패다. 여기서 기절과 메뉴 상태의 정확한 연결은 E4에서 기존 상태 시스템과 대조한다.
- 일반 스킬 쿨타임은 서버 가동 시간을 따른다. 교체·선택 변경·재접속·동일 보상의 재지급으로 초기화하지 않는다. 서버 종료 시간은 포함하지 않는다.
- 시전마다 플레이어 UUID, 시도 ID, 스킬 ID, 시작 tick, 무기 변형, 착용 장신구 권리, 연계 대상, 소비 마나를 기록한다. 클라이언트의 피해·거리·마나 주장을 신뢰하지 않는다.

### 3.3 공통 잠금과 교체 악용 차단 후보 E4

승인부터 표의 후딜 종료까지 다른 스킬 시전, 기본 공격, 음식·방패 사용을 잠근다. 이동·시점 회전은 개별 규칙을 따른다. 핫바 교체·인벤토리 이동 자체는 허용하되 잠금과 쿨타임은 남는다. 무기 스킬 승인 후 주 손 변형이 달라지면 아직 발사하지 않은 검기 또는 진행 중 패링을 취소한다. 발사된 검기는 원래 시전 기록으로 계속 진행한다. 취소로 남은 후딜을 삭제하지 않는다. 무기 내구 파괴도 같은 취소 조건이다.

습득 대시는 주 손에 의존하지 않아 무기 교체로 취소하지 않는다. 같은 tick에 무기 스킬과 J 입력이 오면 서버가 먼저 승인한 하나만 실행하고 다른 입력은 무소모 거절한다. 무기 교체로 바닐라 공격 충전이 완료되는 편법이 생기지 않도록 기존 충전 리셋을 유지하고 시험한다. 이 잠금은 현재 구현 완료 사항이 아니라 추가 요청이다.

### 3.4 대상과 기믹 안전선

이번 테스트 배포는 통제된 레이드 또는 등록 시험장에만 한정한다. ACTIVE 레이드 참가자는 같은 도전의 등록된 살아 있는 적을, 시험장 참가자는 시험에 등록된 고정 표적을 대상으로 시험한다. 정식 일반 무기 스킬·습득 스킬에 레이드 전용 규칙을 신설하는 것은 아니다. PvP·중립 생물·마을 주민·길들인 동물·아군은 공격 대상에서 제외한다. 승인된 레이드·시험장 밖에서는 이번 시제품 시전을 무소모 거절한다. 정식 콘텐츠의 사용 범위는 후속 결정한다. 일반 좌클릭은 기존 서버 PvP·보호 구역 정책을 그대로 따른다.

보스의 강제 처형, 공허, 낙하, 익사·질식, 용암·화염 환경 피해, 낙인 부여, 위치·발판·인원 수 검사, 방 파괴는 패링·대시로 해제하거나 회피하지 않는다. 적이 발생시킨 모든 피해를 무조건 회피 가능으로 취급하지 않는다. E2/E3에 사용하는 회피·패링 가능 피해는 보스별 명시 허용 목록으로 관리하고 미분류 공격은 기본적으로 불가다. 기존 무적 우회 피해는 이 명세보다 우선한다. 피해를 막아도 낙인·퍼즐·페이즈 전환은 진행된다.

패링·대시는 E4 잠금으로 같은 플레이어가 동시에 시전할 수 없다. 다른 기존 방어 효과와 겹치는 경우 피해 사건 처리 순서는 우회 여부 확인 → 기존 무적/취소 여부 → 대시 회피 → 패링 → 일반 피해 계산이다. 앞 단계에서 피해가 이미 취소되면 패링 성공·패링 창 소비·장신구 적중을 생성하지 않는다. 기존 가호의 의미를 바꾸지 않도록 연결 순서를 검토하며, 순서 충돌이 해소되지 않으면 해당 조합은 시제품에서 비활성화한다. 하나의 피해 사건을 두 번 취소하거나 두 번 적중으로 기록하지 않는다.

## 4 동일 조건 비교 무기 3개

### 4.1 실제 장비값과 전투력 입력

모두 희귀 등급, 다이아몬드 검 기반 표시, 내구도 1561, 수리 규칙은 기존 서버 정책을 따른다. 실제 공격속도 목표값은 세 무기 모두 1.6회/초다. 이는 플레이어 기본값 4를 전제로 주 손 공격속도 기여 -2.4를 적용한 목표다. 공격력·공격속도 modifier를 구성할 때 아이템 기본 modifier와 중복 가산하지 않는다. 배포 담당자는 완성 스택의 실제 attribute를 확인해야 한다.

| 임시명과 이름 | 실제 무기 공격 기여 | 기본값 1 포함 공격력 | 실제 공격속도 | 정책 W | E | 무기 스킬 K |
|---|---:|---:|---:|---:|---:|---:|
| proto_cbt:steady_blade 단련의 검 | +8 | 9 | 1.6 | 8 | 10 | 0 |
| proto_cbt:wave_blade 파문검 | +6 | 7 | 1.6 | 6 | 10 | 20 |
| proto_cbt:guard_blade 응수검 | +6 | 7 | 1.6 | 6 | 10 | 20 |

날카로움은 모두 0, 보호 0이다. 별도 인챈트 없는 조건에서 무기만 보유한 전투력은 세 가지 모두 120이다. 이는 플레이 스타일의 가치가 같다는 검증 결과가 아니라 비교를 시작하기 위한 의도적 동일 점수다.

단련의 검에는 숨은 패시브·우클릭 기술을 붙이지 않는다. 높은 평타, 마나 전량의 회피 활용, 시전 실패 위험 없음이 장점이다. 파문검은 근접하기 어려운 구간의 딜 유지, 응수검은 지정 공격의 숙련 방어가 장점이다. 응수검이 탱커 어그로·상시 방패를 자동 부여하지는 않는다.

### 4.2 단련의 검 운용

좌클릭 일반 공격만 사용한다. 별도 마나·쿨타임·선후딜·추가 충돌 판정이 없다. 기본 공격 충전 및 기존 타격 후 처리만 적용한다. 막힌 벽 너머를 타격하지 않고 기본 사거리도 늘어나지 않는다. 우클릭은 스킬 미지정이므로 보조 손 방패 등 기존 행동을 사용한다. 다른 두 무기는 일반 우클릭을 무기 스킬이 소비하므로 같은 입력으로 보조 손 방패를 함께 사용하지 못한다. Shift+우클릭의 일반 상호작용은 기존 입력 조건을 따르되, 방패 사용 가능 여부·상호작용 대상 우선순위를 구현 시 확인한다. 확인 전에는 스킬 무기의 상시 방패 사용을 보장하지 않는다.

평타 실패는 마나 소모 없이 기존 충전 규칙을 따른다. 보스의 무적·방어·일반 근접 판정을 무시하지 않는다. 레이드 기믹 해제·아군 공격 변경·지형 파괴 효과가 없다. 무기 교체로 공격 충전·스킬 쿨타임을 회복시키지 않는다.

### 4.3 파문검의 일선 검기 E1

무기 스킬 임시 ID는 proto_cbt:blade_wave다. 중급 이상 제공자가 이 검을 지급하는 획득 경로를 사용하며 learn_skill 보상은 사용하지 않는다. 정식 제공자와 선행 퀘스트는 미정이다.

| 항목 | 시제품 값 |
|---|---|
| 입력 | 공통 우클릭, 1회 입력당 1회 시전 |
| 마나와 쿨타임 | 24 / 160 tick 8초, 승인 시 시작 |
| 선딜과 후딜 | 선딜 4 tick, 발사 후 후딜 6 tick, 총 입력 잠금 10 tick |
| 방향 | 승인 때 눈 위치·시선 벡터 고정, 선딜 중 회전해도 발사 방향 변경 없음 |
| 형상 | 반지름 0.25블록의 작은 검기, 미관상 큰 궤적은 판정 확대 아님 |
| 이동 | 매 tick 1블록, 최대 10블록 또는 발사 후 10 tick에서 종료 |
| 피해 | 첫 유효 적 8, 둘째 4, 셋째 4, 최대 3개 서로 다른 적에게 각 1회 |
| 피해 분류 | 플레이어 귀속 검기 전용 물리 스킬 피해 확장, 아래 E1 태그 계약 사용, 힘·날카로움·치명타·충전 보정 없음 |
| 밀침과 CC | 없음, 보스 경직·넉백·스턴 없음 |
| 연출 | 짧은 밝은 검선과 낮은 절삭음, 적중·벽 소멸 구분 |

매 tick 이전 위치부터 다음 위치까지 연속 충돌 검사를 한다. Minecraft 블록 충돌 형상을 사용하며 벽·유리·닫힌 문·담장·반블록 등 실제 충돌면에서 즉시 소멸한다. 통과 가능한 풀·물은 파괴·변형하지 않는다. 첫 발사 위치가 고체 안이면 발사 즉시 소멸하고 비용은 유지한다. 블록과 적 충돌이 겹치면 가장 이른 충돌만 우선하고 동거리면 블록을 우선한다. 벽 뒤 적에게 피해를 주지 않는다.

아군은 피해도 충돌 소모도 없이 통과한다. 최대 3개 적의 순서는 거리순이며 같은 거리면 안정적 엔티티 ID 순서다. 보스 다중 히트박스는 하나의 전투 대상 ID로 묶어 시전당 한 번만 계산한다. 적의 무적 등으로 최종 체력 피해가 0이면 연계용 유효 적중은 아니다. 해당 적과의 충돌은 관통 대상 수를 소비하되 다음 적으로 진행한다. 문서상 유효 적중 정의와 현행 damage 반환값이 다르면 연결 구현을 조정하고 시험한다.

일반 피격 무적 시간과 기존 피해 처리 흐름을 우회하거나 초기화하지 않는다. 보스 장벽·방패·피해 감소·페이즈 무적을 존중한다. E1 피해 유형은 기존 마법 행동을 재해석하지 않고 검기 전용 물리 스킬 피해 확장으로 정한다. 일반 피격 무적·보스 페이즈 무적·전용 장벽 차단을 먼저 존중하고, 허용된 피해에는 갑옷 방어력·강인함 → 기존 저항·보호 처리 → 기존 최종 피해 보정 순서의 서버 피해 파이프라인을 적용한다. 해당 표적에 기존 보호 곡선 적용 조건이 충족되면 그 곡선을 사용하고 일반 보호를 이중 적용하지 않는다. 갑옷·저항·보호·무적을 우회하는 태그는 주지 않는다. 이 의미에 맞는 정확한 damage type ID와 연결은 구현 시 결정·검증한다. 현행 AIMED_DAMAGE가 같은 물리 피해라고 주장하지 않는다. 힘·날카로움의 평타 추가 보정은 적용하지 않는다. 실제 최종 체력 피해는 전투력 환산과 무관하다.

승인 전 권한·상태 실패는 무소모다. 승인 뒤 사망·도전 종료 시 검기를 제거하며 환불하지 않는다. 선딜 중 무기 교체는 취소, 발사 뒤 교체는 기존 검기 유지다. 명중 0회라도 쿨타임은 유지한다. 장신구 판정에는 발사 전 승인 때의 스냅샷을 사용한다.

### 4.4 응수검의 순간 패링 E2

무기 스킬 임시 ID는 proto_cbt:timed_parry다. 무기 지급 방식과 제공자 자격은 파문검과 같다. 반격 피해를 자동 생성하지 않으므로 광역 딜·무기 적중 연계의 우회 수단으로 쓰지 않는다.

| 항목 | 시제품 값 |
|---|---|
| 입력 | 공통 우클릭 |
| 마나와 쿨타임 | 20 / 120 tick 6초, 승인 시 시작 |
| 시간창 | 선딜 2 tick → 패링 가능 4 tick → 후딜 8 tick, 총 잠금 14 tick |
| 방향 | 승인 때 수평 시선 고정, 전방 좌우 각 60도 이내 |

각 판정 tick에서 공격 원점과 플레이어 현재 위치의 수평 각도를 계산한다. 원점이 없거나 수평 벡터가 0이면 패링 불가다. 피해 이벤트에서 생존 피해 적용 전에 적격 여부를 검사하고, 동일 tick 다중 공격도 서버 순서상 처음 적격 1건만 막는다. 다음 공격은 정상 피격된다. 비적격 피해가 들어와도 남은 패링 창은 소비하지 않으며 사망·기절하면 취소된다.

투사체, 장판, 후방 공격, 지속 피해, 환경 피해, 강제 기믹은 막지 않는다. 패링이 성공해도 적의 공격 애니메이션·다른 참가자 피해·연계 패턴은 중지되지 않는다. 낙인·상태 부여를 차단하려면 해당 보스 공격 계약이 별도로 허용해야 하며 기본은 부가 기믹 유지다. 아군 공격은 패링 성공으로 보지 않는다. 지형은 변하지 않는다.

시도는 성공 여부와 관계없이 마나와 쿨타임을 소모한다. 성공해도 적에게 피해를 주지 않으므로 연계의 매듭은 발동하지 않는다. 무기 교체·로그아웃·사망으로 패링 창은 사라지고 쿨타임은 남는다. 두 패링 무기를 번갈아 들어도 동일 스킬 ID 쿨타임을 공유한다. 장기 서버 지연 보상으로 판정창을 임의로 넓히지 않는다.

## 5 방어구 조합 2개

두 조합은 모든 부위가 희귀 표시다. 새로운 세트 보너스·직업 제한·이동 감속은 넣지 않아 바닐라 방어력·강인함과 보호 인챈트의 차이를 먼저 본다. 부위별 실제 장비 컴포넌트와 등록 보호 단계는 일치시켜야 한다.

| 조합 | 머리 | 가슴 | 다리 | 발 | 실제 방어 합 | 강인함 합 | 보호 합 P | E 합 |

철제는 각 부위 보호 II, 금강은 인챈트 없음이다. 표의 부위 숫자는 실제 방어력이다. 금강은 부위별 강인함 2, 철제는 0이다. 내구도는 각각 해당 바닐라 아이템 기본값을 유지한다. 임시 식별자는 proto_cbt:iron_guard_head/chest/legs/feet 및 proto_cbt:diamond_guard_head/chest/legs/feet다. 실제 레지스트리가 아니라 문서용 명칭이며 실물은 itemId+components로 구분한다.

- 방어구를 혼합 착용할 수 있다. 세트 4개 강제 착용이나 세트 효과는 없다. 전투력은 보유 이력의 슬롯별 최고 후보를 고르므로 착용 조합과 표시 점수가 일치할 필요는 없다.
- 방어구 제공 인물은 하급 이상, 실제 배정 미정이다. 기믹 무시·추가 아군 효과·지형 변화·마나 소비는 없다. 교체는 기존 장착 규칙을 따르며 획득 이력 점수나 스킬 쿨타임을 초기화하지 않는다.

## 6 습득 스킬 짧은 회피 E3

임시 ID proto_cbt:short_dodge. 이름은 짧은 회피다. 하급 이상 인물이 제공하는 연습 퀘스트 보상 후보이며 실제 인물·퀘스트 ID는 미정이다. learn_skill 보상 연결을 사용하고 무기와 독립적으로 영구 보유한다. K로 선택, J 또는 /mythskills use로 사용한다. intrinsicPower 초기안은 15다.

| 항목 | 시제품 값 |
|---|---|
| 마나와 쿨타임 | 30 / 200 tick 10초, 승인 시 시작 |
| 전체 시간 | 선딜 1 tick → 이동 4 tick → 후딜 3 tick, 총 잠금 8 tick |
| 이동 방향 | 승인 때 수평 시선, 수직 방향 무시, 전방 대시만 제공 |
| 거리 | 최대 3블록, 4 tick에 나누어 이동, 매 tick 최대 0.75블록 |
| 짧은 무적 | 이동 시작부터 3 tick, 보스 목록에서 dodge 허용한 직접 근접·투사체·일회성 범위 공격의 체력 피해·해당 넉백만 무효 |
| 이동 외 기능 | 피해 없음, 정화 없음, 넉백 공격 없음, 점프 없음, 스턴 없음 |
| 사용 가능 상태 | 지면 위 일반 보행, 살아 있는 ACTIVE 레이드 참가자 또는 승인된 시험장 참가자 |
| 사용 불가 상태 | 공중·수영·비행·활공·탑승·수면·기절 및 공통 금지 상태 |
| 연출 | 출발 먼지·짧은 잔상, 무적 종료를 구분할 수 있는 작은 섬광 |

각 tick 플레이어 실제 AABB를 이동 경로로 쓸어 검사하며 벽·문·담장·반블록·엔티티 충돌·월드 경계 앞의 마지막 안전 위치에서 멈춘다. 순간이동으로 벽을 뚫지 않는다. 미로딩 청크·도전 경계로 들어가지 않으며 청크 강제 로드도 하지 않는다. 블록을 부수거나 높이를 자동 보정해 벽을 올라가지 않는다.

발밑 지지가 끊기는 다음 이동은 중단하고 마지막 안전 위치를 유지한다. 경사·계단에서 다음 위치를 현재 높이로 통과할 수 없으면 정지한다. 첫 안전 이동이 0.25블록 미만으로 사전 확인되면 시전 전 실패로 무소모 처리한다. 시전 승인 뒤 이동 가능한 공간이 막히면 정상 비용을 유지하고 남은 이동·무적을 즉시 종료하며 후딜 예정 종료 시각은 유지한다. 안전 착지 범위 판정은 서버 충돌 조회로 구현해야 하며 클라이언트 예측만으로 처리하지 않는다.

레이드 기믹 경계가 충돌 블록으로 표현되지 않은 경우 별도 이동 금지 판정이 필요하다. 그 연결이 없으면 해당 보스에서 대시를 비활성화한다. 아군을 밀거나 아군을 통해 좁은 통로를 통과시키지 않는다. 피해가 0이 된 공격도 보스 패턴·낙인·발판 판정까지 제거하지 않는다. 일반 화염 상태나 독을 정화하지 않으며 미분류 지속 피해도 회피하지 않는다.

짧은 무적은 불사 능력이 아니다. 낙하·환경·공허·처형을 막지 않고 기존 피격 무적 타이머를 연장하지 않는다. 같은 시전에 대해 별도 버프 ID를 남겨 전투력 활성 효과 평가를 오류로 만들지 않도록 전용 런타임 상태로 관리하는 안을 우선한다. 정식 저장 필드·action type은 E3 구현 검토 후 결정한다.

무기·장신구 교체로 이동 거리·남은 무적·쿨타임을 늘리지 않는다. 사망·로그아웃·도전 이탈 시 상태는 즉시 끝나고 쿨타임은 남는다. 시전 중 마나 최대치가 낮아져도 이미 차감한 비용을 돌려주지 않는다.

## 7 장신구 2종

### 7.1 맑은 마나석

임시 정의 ID proto_cbt:clear_mana_stone. 상급 이상 제공 자격, 실제 제공자·획득 퀘스트 미정. 표시 아이템 후보는 minecraft:lapis_lazuli지만 실제 지급되는 권리 아이템은 기존 bound_accessory 흐름을 따른다.

- 효과: 기존 MAX_MANA +40.
- fixedPower: 12. 효과를 추가로 자동 점수화하지 않는다.
- 하나 장착: 최대 240, 초당 2.4 회복. 별도 획득권 두 개 장착: 최대 280, 초당 2.8 회복.
- 장착 즉시 현재 마나는 늘지 않는다. 탈착 시 현재 마나를 새 상한까지만 줄인다. 빈 마나로 반복 탈착해도 회복이 생기지 않는다.
- 별도 조작·사거리·선후딜·피해·충돌·기믹 무시·아군·지형 효과 없음. 실제 착용 중에만 최대치와 회복률에 반영한다.

### 7.2 검흔의 매듭

임시 정의 ID proto_cbt:blade_knot. 상급 이상 제공 자격, 실제 배정 미정. 표시 아이템 후보 minecraft:amethyst_shard. 실제 보유와 장착은 영수증 권리 UUID를 사용한다.

- 효과: 기존 ‘연계의 매듭’ 효과. JSON의 정확한 enum은 구현 가이드를 확인해 작성하며 이 문서가 새 enum을 만들지 않는다.
- fixedPower: 12. 지정 연계 대상은 시제품의 짧은 회피.
- 무기 우클릭 스킬이 유효 적중하면 대상 습득 스킬의 **기본 쿨타임 10%**, 즉 20 tick을 남은 시간에서 뺀다. 남은 시간이 없으면 감소하지 않는다.
- 서로 다른 권리의 매듭 2개는 40 tick 감소. 여러 적·보스 히트박스·다단 적중도 한 시전에서 한 번만 감소한다. 남은 시간 0 아래로 내려가지 않는다.
- 검기에만 유효 적중이 있으므로 단련의 검 평타, 패링 성공, 대시에는 발동하지 않는다. 패링을 가짜 적중으로 처리하지 않는다.
- 승인 때 착용과 연계 대상을 고정한다. 검기 발사 후 매듭 장착으로 추가 발동하지 않는다. 발사 때 착용했다면 이후 해제해도 그 검기의 기록은 유지한다.
- 별도 조작·마나·독립 쿨타임·피해·지형 영향 없음. 기믹 면역 적의 피해 0 충돌은 발동시키지 않는다.

### 7.3 두 슬롯 선택과 악용 처리

추천 기본 비교는 ‘마나석 1 + 매듭 1’이다. 보조 비교는 ‘마나석 2’와 ‘매듭 2’이며 각각 합법적인 별도 획득권을 준비한다. 단일 권리 UUID 복사·분실 재지급으로 슬롯을 두 개 채우지 못한다. 교체는 전투 중에도 가능하며 새로운 전투 중 교체 금지를 신설하지 않는다.

합법 보유권이 두 개 이상이면 세 구성의 장신구 점수는 모두 24일 수 있다. 실제 마나와 연계는 착용 두 칸만 따른다. 보유 점수와 착용 성능을 혼동해 버그로 판정하지 않는다. 같은 이름의 아이템을 일반 인벤토리에 넣거나 갑옷칸에 넣은 것은 장착이 아니다.

## 8 전투력 계산과 실전 성능을 분리한 비교

### 8.1 통제된 전투력 예시

H₀=20, A₀=1, 활성 효과 없음, 영구 가호 점수 O=0, 날카로움 0, 기타 점수 0, 짧은 회피 보유 K=15, 장신구 권리 두 개 J=24를 가정한다. 이 O=0은 시험용 원장 조건일 뿐 기존 유저 가호 삭제를 뜻하지 않는다.

전투력 = 10×(1+W) + 20×sqrt(1+P/40) + 장비 E + 무기 스킬 점수 + 습득 15 + 장신구 24.

| 보유 장비 집합 | 무기 | 공격 항 | 생존 항 | 장비 E | 무기 K | 습득과 장신구 | 총점 |
|---|---|---:|---:|---:|---:|---:|---:|
| 해당 무기와 철제 4부위만 | 단련 | 90 | 21.908902 | 26 | 0 | 39 | 176.908902 |
| 해당 무기와 철제 4부위만 | 파문 | 70 | 21.908902 | 26 | 20 | 39 | 176.908902 |
| 해당 무기와 철제 4부위만 | 응수 | 70 | 21.908902 | 26 | 20 | 39 | 176.908902 |
| 해당 무기와 금강 4부위만 | 단련 | 90 | 20 | 38 | 0 | 39 | 187 |
| 해당 무기와 금강 4부위만 | 파문 | 70 | 20 | 38 | 20 | 39 | 187 |
| 해당 무기와 금강 4부위만 | 응수 | 70 | 20 | 38 | 20 | 39 | 187 |

표는 자료 수식에 대입한 산술값이며 서버 출력 검증이 아니다. 반올림은 표시용으로만 했다. 여러 무기·두 방어구 조합을 모두 지급하면 슬롯별 최고 후보 선택과 동일 스킬 ID 최대값 규칙을 적용한다. 모든 획득 장비 E와 무기 K를 합산하지 않는다. 이 사례에서는 금강 부위가 각각 높은 후보 점수이므로 철제로 갈아입어도 표시 점수가 금강 기준으로 남을 수 있다.

실제 가호 활성 효과가 있으면 해당 단계와 고유 O를 분리해 재계산한다. 성급함 평가 배율을 실제 스킬 쿨타임 감소로 바꾸지 않는다. 장신구 마나·연계 성능을 이 수식에 임의로 다시 더하지 않는다. 전투력 176.9나 187을 레이드 입장 최소값으로 확정하지 않는다.

### 8.2 평타 수치와 자원 압박의 읽는 법

공격력×공격속도만 단순 곱한 이상적 평타 입력량은 단련 14.4, 나머지 11.2다. 이것은 실제 DPS가 아니다. 충전 샘플링, 적 방어, 치명타, 피격 무적, 이동, 선후딜로 달라진다. 검기 8피해/8초도 그대로 실제 DPS +1로 합산하면 안 된다. 스킬 잠금 동안 평타가 막히기 때문이다.

기본 마나에서는 검기 반복 비용이 평균 3/초로 회복 2/초보다 높고, 대시를 매 10초 사용하면 추가 3/초가 든다. 따라서 공격 기술을 무제한 유지하는 설계가 아니다. 마나석 하나를 착용해도 회복은 2.4/초이며 무기 스킬과 대시의 동시 무제한 반복을 보장하지 않는다. 매듭은 대시 마나를 환급하지 않아 쿨타임 감소가 생존을 자동 보장하지 않는다.

## 9 구현 담당자에게 넘길 최소 계약

1. 정확한 itemId+components 변형을 지급 RewardEntry와 전투력 items에 동일하게 작성한다. custom_model_data 후보 번호는 구현 담당자가 기존 값 충돌을 확인해 예약한다. 이름·인챈트·attribute modifier까지 포함한 변형 차이를 관리한다.
2. 무스킬 무기의 skills는 빈 맵, rightClickSkill은 생략한다. 파문·응수는 skills에 임시 스킬 ID와 점수 20, rightClickSkill에 동일 ID를 연결한다. weapon_skills의 무기 스킬 정의에는 현행 intrinsicPower 필드가 없으므로 추가하지 않는다. 실제 장비의 전투력 등록 intrinsicPower는 E=10으로 유지한다.
3. 방어구는 head/chest/legs/feet 슬롯, 무기 weapon으로 일관되게 등록한다. W는 무기 기여만 쓰고 플레이어 기본 1을 중복 입력하지 않는다.
4. E1~E4는 **확장 요구사항**으로 구현한다. action 이름·schemaVersion·저장 형식은 본 문서에서 운영 형식으로 확정하지 않는다. 기존 AIMED_DAMAGE 예시를 검기 구현 완료물로 표시하지 않는다.
5. E1은 시전 ID별 적중 집계·장신구 연계를 연결한다. E2는 피해 1회 차단과 보스 허용 분류를, E3는 서버 이동 충돌·짧은 회피 상태를, E4는 입력 중복·잠금·교체를 담당한다.
6. 새 런타임 상태가 전투력에서 미등록 활성 효과로 인식되는지 확인한다. 전용 상태를 사용한다면 가호·포션 평가 경로와 독립시킨다.
7. 장신구는 기존 정의·권리·2칸 시스템을 재사용한다. 맑은 마나석 MAX_MANA 40, 검흔의 매듭 기존 연계 효과, fixedPower 각각 12. 재지급은 신규 보유권 생성이 아니다.
8. 지급 인물은 6등급 제공 자격을 확인하고 기존 정식 ID를 나중에 배정한다. 테스트 계정에 지급하더라도 지급 이력 누락을 방치하지 않는다. 정책은 유효한 하나로 통합하며 프로토타입 정책을 여러 개 동시에 활성화하지 않는다.

## 10 검증 계획과 통과 기준

아래는 해야 할 시험이며 수행 결과가 아니다. 먼저 빈 시험 계정의 보유 원장을 분리해 점수 비교를 하고, 다음 기존 가호가 있는 계정으로 회귀 시험한다. 유저의 영구 가호나 지급 이력을 초기화하지 않는다. 허수아비도 시험 도전의 등록 적으로 만들거나 별도 개발 시험 호출을 사용하며, 시험 범위 제한을 정식 일반 스킬의 레이드 전용 규칙으로 확대하지 않는다. 첫 수치 비교는 보조 손 비움으로 통제하고, 다음 방패 착용 비교를 별도로 한다.

| 시험 | 기대 결과 |
|---|---|
| 실제 attributes | 세 무기 속도 1.6, 공격력 9/7/7, armor 15/20, toughness 0/8 확인 |
| 수식 비교 | 독립 보유 집합에서 표의 176.908902 또는 187과 표시 오차 범위 일치 |
| 슬롯별 이력 | 장비를 벗어도 보유 점수 유지, 실제 방어는 착용에 따라 변경 |
| 검기 얇은 벽 | 빠른 이동 중에도 유리·담장·닫힌 문 뒤 적 피해 0 |
| 검기 관통 | 4마리 직선 배치에서 첫 3마리만 8/4/4 입력, 같은 보스 다중 부위 중복 없음 |
| 검기 아군 | 5인 중 앞에 선 아군에게 피해·연계 없음, 적에게는 정상 진행 |
| 패링 경계 tick | 선딜·창 이전/이후에는 정상 피격, 창 안 적격 1건만 차단 |
| 패링 동시 공격 | 같은 tick 두 적격 공격 중 첫 1건만 차단 |
| 패링 기믹 | 장판·처형·낙인·미분류 공격을 막지 않음 |
| 대시 충돌 | 벽·모서리·천장·경계·빈 청크·발밑 낭떠러지 통과 없음 |
| 대시 무적 | 허용 공격만 지정 3 tick 회피, 환경·기믹은 유지 |
| 승인 전 실패 | 무권한·마나 부족·기절·막힌 대시 모두 무소모 |
| 승인 뒤 실패 | 헛침·선딜 취소·발사 후 장애물에 비용과 쿨타임 유지 |
| 교체와 재접속 | 무기·스킬 선택·장신구·재지급·재접속으로 쿨타임 초기화 없음 |
| 매듭 | 검기 다중 적중에도 1회, 패링·평타·대시에는 0회, 교체 후 소급 적용 없음 |
| 마나석 | 200/240/280 및 2/2.4/2.8 회복, 반복 탈착 즉시 회복 없음 |
| 가호 회귀 | 기존 영구 가호·힘 레이드 보정·보호 곡선·활성 효과 계산 유지 |
| 부하와 지연 | 5명 동시 검기·대시·패링에서 판정 중복·마나 음수·서버 오류 없음 |

실전 비교는 5명이 무기를 교대로 사용해 동일 장비·가호·보스 조건으로 기록한다. 근접 유지 보스, 이동 강요 보스, 예고 근접 공격 보스의 세 상황을 사용하고 각 플레이어의 장비 순서를 바꿔 숙련 편차를 줄인다. 02_구현후_밸런스시험계획.md의 10초·180초 시험을 적용하되 긴 시험을 60초씩 나누어 실제 총 피해, 평타·스킬 기여, 피격·사망, 마나 고갈 시간, 패링 성공/시도, 대시 실패 원인, 보스 기믹 성공률을 기록한다.

초기 판정 목표는 ‘단련이 근접 유지에서 경쟁력 있음’, ‘파문이 이동 구간에서 장점 있음’, ‘응수가 적격 공격의 생존에 장점 있지만 필수 장비는 아님’이다. 총 피해 ±10%는 조사 시작점일 뿐 합격을 보장하는 기준이 아니다. 한 선택이 모든 상황에서 우월하면 먼저 피해·비용·시간창 한 축만 조정하고 재시험한다. 특히 패링·대시가 기믹을 무시하거나 지형을 통과하면 수치 밸런스 이전에 배포를 중단한다.
