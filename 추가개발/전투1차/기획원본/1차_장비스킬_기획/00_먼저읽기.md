## 확정된 작업 분담

현재 준비된 것은 시스템 기반이며 실제 정식 콘텐츠는 아직 없다. 기획은 dot이 작성하고 사용자가 구현한다. 기존 God ID 목록은 모두 폐기 예정인 테스트 자료로 취급하며 운영 인물 대응표로 다시 선택하게 하지 않는다. 정식 인물 ID는 앞서 합의된 작성 양식을 따른다. 이번 시제품은 특정 신의 보상으로 자동 배정하지 않는다.

장비 등급: 일반 → 고급 → 희귀 → 영웅 → 전설 → 신화 → 근원.
저장값 후보: common / uncommon / rare / heroic / legendary / mythic / primordial.
이 값은 새 등급 저장 체계를 구현할 때 연결하며, 현행 파서에 지원되지 않는 필드를 임의로 넣지 않는다.

인물 6등급의 보상 제공 자격, 장비 7등급, 개별 보상표의 tier는 서로 별개다. 모든 무기에 스킬이 붙지 않으며 별도 습득 스킬과 무기 우클릭 스킬도 구분한다. 최상급의 레이드 NPC 지원 특수스킬 및 친밀 관계에 따른 확률 도움은 이 시제품에 포함하지 않는다.

## 기존 기능에만 묶이지 않는 기획

검기·패링·대쉬·짧은 무적은 신규 확장을 포함할 수 있다. 현재 공통 실행 행동으로 지원되는 범위와 추가 구현이 필요한 부분을 구분한다. 일시 변신·스턴·기타 투사체·소환 등도 후속 기획 후보이며 이번 첫 시제품에 전부 포함한 것은 아니다.

이번 패키지는 외부 모드 코드나 리소스를 포함하지 않으며 특정 모드의 호환성 검증을 수행하지 않았다. 향후 외부 모드 활용 시 필요한 사용 허락은 사용자 담당이며 기획에서는 대상 기능과 자체 구현 대안을 구분한다.
