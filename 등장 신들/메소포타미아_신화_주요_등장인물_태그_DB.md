# 메소포타미아 신화 주요 신격·영웅·왕·괴물 태그 DB

> 게임 세계관용 선별 DB입니다. 수메르·아카드·바빌로니아·아시리아 전승을 넓은 의미의 **메소포타미아 신화권**으로 묶어 정리했습니다.
> 같은 신격이 언어에 따라 다른 이름을 갖는 경우(예: 인안나/이슈타르, 우투/샤마시, 엔키/에아)는 한 캐릭터로 통합했습니다.
> 이름만 신 목록이나 왕명록에 잠깐 나오는 인물은 제외하고, 독립적인 신앙·신화·문학·역사적 업적 또는 현대 인지도가 충분한 존재를 우선했습니다.

# 전체 수

**총 100명/존재**

- 원초·창세 신격: **15**
- 주요 신격: **35**
- 괴물·신수·집단 신격: **18**
- 영웅·전설 인물: **14**
- 역사·유명 왕·신격화 인물: **18**

# 태그 운용 기준

- 신격: `[메소포타미아 신화] [신]`을 기본으로 세부 문화권과 권능을 추가
- 수메르/아카드 이름이 사실상 같은 신격으로 이어지는 경우 하나의 항목으로 통합
- 신수·악마·괴물·집단 신격은 각각 `[신수] [악마] [괴수] [집단]` 등으로 구분
- 인간·왕은 실제 업적 또는 유명 문학 전승이 충분한 인물만 포함
- 실제로 생전 또는 사후 신격화가 명확한 왕·영웅은 `[인간에서 신이 됨] [신격획득]` 사용
- 유명하지만 실제 신격화가 확정적이지 않은 인간은 게임용 `[승천후보]` 사용
- Fate 정보는 원전 정보와 섞지 않고 `Fate 참고` 항목에서 별도 표기

# 주요 신격

## 16. 인안나 / 이슈타르 — Inanna / Ishtar

**분류:** 주요 신격  
**성별:** 여성  
**태그:** `[메소포타미아 신화] [수메르 신화] [아카드 신화] [신] [대신] [사랑] [욕망] [전쟁] [금성] [왕권] [풍요]`

**핵심 전승/업적:** 수메르의 인안나와 아카드의 이슈타르로 이어지는 메소포타미아의 대표 여신. 사랑·성·전쟁·왕권·금성과 관련되며 명계 하강 신화와 길가메시 서사에서도 핵심 역할을 한다.

**게임용 성격·해석:** 감정과 욕망이 매우 크고 자존심이 강한 여왕형 전투신. 사랑과 파괴가 한 인물 안에서 극단적으로 오가는 매력적인 위험인물로 만들기 좋다.

**Fate 참고:** Fate/Grand Order의 이슈타르는 **여성**이며 린 토오사카를 그릇으로 삼은 의사 서번트다. 공식 애니메이션 소개에서는 자유분방하고 보석과 아름다운 것을 좋아하며 길가메시에게 강한 악감정을 가진 여신으로 묘사된다. 게임용 성격에는 **자존심, 즉흥성, 허영, 전투적 기질과 의외의 인간적인 정**을 섞으면 Fate의 인상을 살릴 수 있다.

## 100. 세미라미스 — Semiramis

**분류:** 역사·유명 왕·신격화 인물  
**성별:** 여성  
**태그:** `[아시리아 전설] [전설적 인물] [여왕] [여성] [왕권] [전쟁] [건축] [책략] [독] [승천후보]`

# 인간 → 신 승천 시스템에 특히 중요한 인물

## 실제 신격화 사례

### 나람신

`인간 → 정복왕 → 제국의 절대 군주 → 생전 신격화`

메소포타미아 왕권사에서 **인간 왕이 실제 신적 표기와 신성한 왕의 도상을 적극 사용한 대표 사례**입니다. 게임에서 최초의 '군사 업적형 승천' 사례로 쓰기 좋습니다.

### 슐기

`인간 → 왕 → 문무·행정 업적 → 왕실 숭배 → 신격`

자신을 신적으로 표기하고 왕실 찬가를 통해 초인적 능력을 강조한 대표적 신왕입니다. 단순한 전투 업적이 아니라 **통치·학문·체력·제의의 총합**으로 신이 된 모델로 쓰기 좋습니다.

### 루갈반다

`전설적 인간 영웅 → 왕 → 영웅 서사 축적 → 후대 신격화`

길가메시 이전 세대의 영웅왕이 신이 된 형태이므로, 네 세계관에서 **영웅 서사가 신앙으로 굳어 신격을 형성한다**는 규칙을 설명하기 좋습니다.

### 지우수드라 / 우트나피쉬팀

`인간 → 세계적 재앙 생존 → 신의 특별 보상 → 불멸`

업적을 쌓아 스스로 신이 되는 것과는 다르지만, 신이 인간에게 불사성과 초월적 지위를 부여하는 **외부 승인형 승천** 사례로 활용할 수 있습니다.

# DB 설정 메모

## 동일 신격의 문화권별 이름

메소포타미아는 시대와 언어가 바뀌면서 같은 신격의 이름이 달라지는 경우가 많습니다.

- 인안나 = 이슈타르
- 우투 = 샤마시
- 난나 = 수엔/신
- 엔키 = 에아
- 이슈쿠르 = 아다드
- 두무지 = 탐무즈

게임에서는 이들을 별도 캐릭터로 중복 등록하기보다 **하나의 신격이 시대·지역에 따라 다른 이름과 폼을 가진다**고 처리하는 것을 권장합니다.

예:

`[수메르 폼: 인안나] → [아카드/바빌로니아 폼: 이슈타르]`

이렇게 하면 동일 신을 중복 캐릭터로 늘리지 않으면서 문화권의 차이는 살릴 수 있습니다.

## 왕의 신격화

모든 메소포타미아 왕이 신이었던 것은 아닙니다.

따라서 역사적 인간은 기본적으로 `[승천후보]`로 두고, 나람신·슐기처럼 신적 표기와 숭배가 명확한 사례에만 `[인간에서 신이 됨] [신격획득]`을 붙이는 것을 권장합니다.
