# 중국 신화 주요 등장인물 태그 DB

> 중국의 창세신화·도교·민간신앙·사신/용신·팔선·『서유기』·『봉신연의』와, 신격화 또는 신격화 후보로 사용하기 좋은 매우 유명한 역사·전설 인물을 한 게임용 DB로 정리했습니다.
> 이름만 족보나 지방 제사에 잠깐 등장하는 신·요괴·인간은 제외했습니다. 역사 인물도 중국 문화권에서 인지도가 높거나 후대 전설성이 매우 강한 경우만 포함했습니다.

# 기본 분류 원칙

- 실제 신격·신선·영물은 `[신] [신선] [신수] [용] [요괴]` 등을 사용합니다.
- 역사·전설 속 인간은 `[인간] [역사적 인물] [전설적 인물]`을 사용하고 게임상 신격화 가능성이 높으면 `[승천후보]`를 추가합니다.
- 실제로 인간에서 신격화되어 폭넓은 숭배를 받은 관우·마조 등은 `[인간에서 신이 됨] [신격획득]`을 사용합니다.
- 『서유기』·『봉신연의』처럼 역사 인물과 신화가 섞인 작품은 작품판 캐릭터를 독립된 전설적 존재로 취급합니다.
- Fate판에서 성별이나 존재종이 변경된 경우 원전/역사 성별과 Fate판 설정을 반드시 분리해 기록합니다.

# 인간 → 신 승천 시스템에 특히 좋은 중국 사례

## 실제 신격화 모델

### 관우 → 관제
`인간 장수 → 충의·무용의 전설화 → 사당과 국가적 숭배 → 무신·수호신`

역사상의 인간이 수백 년에 걸쳐 점점 더 높은 신격을 얻는 **명성·신앙 누적형 승천**의 대표 사례입니다.

### 마조
`실존 여성 임묵 전승 → 해난 구조·기적 전승 → 지역 수호령 → 해상 여신 → 천후급 신격`

지역 신앙이 광범위한 문화권 신앙으로 성장하면서 신격도 상승하는 **신앙 확장형 승천**에 매우 적합합니다.

### 황비호
`인간 장군 → 전쟁 중 사망 → 봉신 → 산악·명계 계열 신장`

『봉신연의』의 세계관처럼 대업에 참여해 죽은 인간을 공식적으로 신으로 임명하는 **제도형 승천**의 좋은 예시입니다.

## 게임에서 승천시키기 좋은 인간

- **후예** — 태양 아홉 개를 격추한 세계구급 위업
- **황제 헌원** — 문명 통합과 치우 격퇴
- **강자아** — 왕조 교체와 봉신 체계 완성
- **현장삼장** — 대장정·불경 전래·세계적 종교문화 영향
- **진시황** — 중국 통일과 황제 체제 확립
- **항우** — 인간 최강급 무용과 패왕 전설
- **제갈량** — 역사적 업적 + 거의 신선급으로 확대된 후대 전승
- **무측천** — 유일한 여성 황제로서의 정치적 업적
- **형가** — 실패했지만 수천 년간 기억된 영웅적 암살 시도
- **화목란** — 효와 군사 영웅성
- **악비** — 충절과 국토 수호, 실제 사후 숭배
- **포증** — 공정한 인간 판관에서 명계의 심판자로 전설화하기 쉬움

# 게임 DB 운용 메모

- **양전과 이랑진군**, **강자아와 태공망**처럼 역사·민간전승·소설판이 합쳐진 인물은 별도 캐릭터로 중복 등록하기보다 하나의 인물이 여러 `폼/전승`을 가진다고 처리하는 것이 좋습니다.
- **관우**는 인간 시절과 `관제` 신격을 별도 성장 단계로 나누면 승천 시스템을 가장 명확하게 보여줄 수 있습니다.
- **서유기 손오공**은 신에게 임명되어 천계 직책을 얻기도 하고 불교적 깨달음으로 투전승불에 오르는 결말도 있어, `반역 → 수행 → 깨달음 → 신격 상승`이라는 독특한 성장 루트로 만들기 좋습니다.
- **나타**는 인간 출신 신격이라기보다 신성한 영주·연꽃 육체·선술이 결합된 존재이므로 `[인공생명] [신]` 계열을 추가해도 좋습니다.
- Fate 성격은 원전 성격을 대체하지 않고, 게임 캐릭터화를 위한 참고 레이어로만 사용했습니다.
