# 일본 신화·전승 주요 등장인물 태그 DB

> 게임 세계관용 캐릭터 선별 목록입니다. 『고사기』·『일본서기』의 카미, 일본 민간신앙과 신불습합, 오니·요괴·원령, 고대 영웅, 헤이안·겐페이 전승, 그리고 후대에 강하게 전설화되거나 신격화된 유명 역사 인물을 함께 정리했습니다.
> 단순히 족보에 이름만 남은 신이나 거의 알려지지 않은 역사 인물은 제외했습니다. 인간 출신 인물은 대중적 인지도, 전설성, 업적, 실제 신격화 여부를 기준으로 선별했습니다.

# 총 정리 수

**총 110명/존재**

- 창세·천손·자연신: **28**
- 민간·신불습합 주요 신격: **14**
- 신수·요괴·오니·원령: **18**
- 고대·설화 영웅: **12**
- 헤이안·겐페이 전승: **16**
- 유명 역사·전설 인물: **22**

# DB 운용 기준

- 신화 원전의 카미: `[일본 신화] [신]`을 기본으로 권능·성별·영역을 추가합니다.
- 요괴·오니·원령: `[요괴] [오니] [원령] [영물] [용]` 등을 존재종으로 사용합니다.
- 인간·역사 인물: `[역사적 인물] [인간]`을 기본으로 게임 세계관에서 승천할 만한 경우 `[승천후보]`를 붙입니다.
- 실제 인간이 사후 신으로 널리 숭배된 경우 `[인간에서 신이 됨] [신격획득]`을 사용합니다.
- 일본의 신화·민간전승은 신토와 불교가 오랫동안 습합되어 왔으므로 칠복신·염라·관음 같은 신불습합적 존재는 별도 분류했습니다.
- Fate의 성별·종족·성격 재해석은 원전과 혼동하지 않도록 `Fate 참고`에서 따로 적었습니다.

**게임용 성격·해석:** 실수를 통해 죽음과 오염을 경험한 뒤 정화의 질서를 확립한 창조자. 정화·봉인·생명 회복 계열의 최고위 신격으로 적합하다.

# 인간 → 신 승천 시스템에 특히 좋은 일본 사례

## 1. 스가와라노 미치자네 → 텐진

`인간 학자·정치가 → 억울한 죽음 → 원령화 → 공포와 제사 → 신격화 → 학문의 신`

단순히 업적이 큰 인간이 신이 되는 것을 넘어, **사후의 사회적 기억과 신앙이 신격의 성격까지 변화시키는 사례**로 쓰기 좋습니다.

## 2. 도쿠가와 이에야스 → 도쇼다이곤겐

`인간 다이묘 → 천하 통일 체제 완성 → 쇼군 → 사망 → 국가적 제향 → 수호신`

정치·통치 업적과 국가적 제례가 결합되는 **제도형 승천**의 대표 사례입니다.

## 3. 관념상 하치만 / 오진천황

`전설적 천황 → 왕권의 신성화 → 무사 계층의 숭배 → 국가 수호 무신`

한 역사·전설적 군주의 기억이 시대가 지나며 전쟁신·국가신으로 확대되는 구조를 만들 수 있습니다.

## 4. 영웅 업적형 승천 후보

- **후예가 아니라 일본 쪽에서는 야마토타케루** — 전국 원정과 구사나기 전승
- **사카타 킨토키** — 인간의 괴력과 오니 토벌
- **와타나베노 츠나** — 이바라키도지의 팔을 벤 오니 사냥 업적
- **미나모토노 라이코** — 슈텐도지·츠치구모 토벌
- **후지와라노 히데사토** — 거대 지네 퇴치와 마사카도 토벌
- **사카노우에노 다무라마로** — 역사적 정복 + 오타케마루 전설
- **미나모토노 요시츠네** — 겐페이 전쟁의 천재적 군공과 비극적 전설
- **미야모토 무사시 / 사사키 고지로** — 인간의 무예가 신역에 도달하는 기술형 승천

# 운용상 주의점

- 일본 신화에서는 동일 신이 지역·신사·시대에 따라 다른 이름이나 성격으로 결합되는 경우가 많습니다. 모든 대응 관계를 '완전히 같은 인물'로 고정하지 않는 편이 좋습니다.
- `오쿠니누시 ↔ 다이코쿠텐`, `고토시로누시/히루코 ↔ 에비스`처럼 신불습합·후대 동일시가 있는 존재는 **기본 신격과 후대 폼**으로 나누는 방식이 게임 DB에 적합합니다.
- 신토 전통에는 역사적 인간이 카미로 숭배되는 경우가 있으므로, 이 세계관의 인간 승천 규칙과 특히 궁합이 좋습니다.
- Fate 설정은 원전의 대체물이 아니라 캐릭터 성격·성별 재해석을 위한 별도 참고 레이어로 기록했습니다.
