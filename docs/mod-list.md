# 서버 모드 목록

> **이력 안내:** 아래 표는 초기 모드 계획 목록이며 현재 `server/mods`의 설치 목록이 아니다. 실제 서버·클라이언트 파일은 [작업 시작 안내](../인수인계/START_HERE.md)와 [서버 안내](../server/README.md)를 통해 확인한다.

| 파일 | 버전 | 설치 범위 | 출처 | 의존성 | 배포 가능 | 상태/비고 |

| `mythictrpg-1.0.0.jar` | 개발 중 | 서버+클라이언트 | 자체 제작 | NeoForge | 예 | upstream 통합 전 |
| `mythaiaicontent-0.1.0.jar` | 0.1.0 | 통합 중 | 자체 제작 | NeoForge | 예 | 정적 AI 콘텐츠 |
