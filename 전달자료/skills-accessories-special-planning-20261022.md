# 스킬·장신구·특수스킬 기획 전달서

2026-10-22. `behaivior` 개발 작업 기준. 개별 등장인물·스킬·장신구의 정식 목록과 수치는 기획자가 작성한다. 이 문서의 이름과 예시 수치는 실제 인물 배정이 아니다. 구현 계약은 [시스템 작성 가이드](../mythictrpg-main/docs/SKILLS_ACCESSORIES_SPECIAL.md), 실제 검증·배포 상태는 [작업 기록](../인수인계/브랜치실험/behaivior/SKILLS_ACCESSORIES_SPECIAL_20261022.md)을 따른다.

## 1. 등급별 보상 범위

상위 등급은 아래 등급의 보상 종류를 누적해서 제공할 수 있다. 등급만으로 보상을 자동 지급하지 않으며 인물별 실제 보상 목록·관계·퀘스트 조건을 따로 정한다.

| 인물 등급 | 새로 허용되는 종류 | 누적 허용 |
|---|---|---|
| 최하급 | 가호 | 가호 |
| 하급 | 방어구·습득 스킬 | 가호·방어구·습득 스킬 |
| 중급 | 무기 | 위 보상 + 무기 |
| 상급 | 장신구 | 위 보상 + 장신구 |
| 최상급 | 특수스킬 | 위 보상 + 특수스킬 |
| 초월급 | 독자 종류 미정 | 위 보상 전체 |

이 표는 인물의 제공 가능 범위다. 실제 인물의 6등급 배정은 별도 기획을 따른다. 가호의 특성 효과도 인물별 허용 목록을 유지한다. 일반 재료·화폐·제작 도구를 이 표만으로 금지하지 않는다.

습득 스킬·장신구·특수스킬을 받았다는 사실을 자동으로 ‘신의 가호 보유’로 기록하지 않는다. 인간 루트의 가호 제한과 레이드 직접 가호 예외는 [이전 보상 기획](blessing-reward-planning-20261021.md)을 유지한다.

## 2. 일반 스킬

스킬은 두 경로로 사용한다.

- **무기 스킬:** 지정된 일부 보상 무기를 주 손에 들고 우클릭. 모든 무기에 스킬을 붙이지 않는다. Shift+우클릭은 일반 상호작용이다.
- **습득 스킬:** 퀘스트·탐사·이벤트 등의 보상으로 습득하여 개인이 계속 보유한다. 초기 조작은 K로 목록, 한 스킬을 선택한 뒤 J로 사용한다. 보유 수를 직업이나 루트로 제한하지 않는다. 선택과 연계 대상은 따로 설정할 수 있다.

### 공통 자원·비용

- 기본 마나200. 최대 마나는 `200 + 장착 장신구의 최대 마나 증가량 합계`다.
- 초당 **현재 최대 마나의 1%** 회복, 사용 후 대기시간 없음. 접속 중 살아 있을 때 회복한다.
- 장착으로 최대치가 늘어도 현재 마나를 즉시 채우지 않는다. 최대치가 줄면 현재 마나를 새 상한까지만 줄인다.
- 스킬마다 마나와 쿨타임을 따로 정한다. 일반 스킬 쿨타임은 서버 가동 중 흐르고, 서버 종료 시간은 포함하지 않는다.
- 정상 발동한 공격 스킬은 빗맞혀도 마나·쿨타임을 소모한다. 사용 권한·마나 부족·기절·잘못된 상태 등 **시전 전 조건 실패는 무소모**다.
- 무기 교체·스킬 선택 변경·재접속으로 쿨타임이 초기화되지 않는다.

### 스킬마다 제출할 항목

`ID / 이름 / 설명 / 획득 경로 / 지급 인물 / 마나 / 기본 쿨타임 / 대상·범위 / 피해·회복·버프 수치 / 지속·반복 횟수 / 고유 전투력 / 연출`.

초기 실행 행동은 조준 마법 피해, 본인 중심 범위 마법 피해, 동일 대상 반복 피해, 자가 회복, 임시 유익 버프다. 새로운 돌진·투사체·소환 행동이 필요하면 효과 설명과 함께 별도 요청한다. 단계·범위·값이 정해지지 않은 스킬을 운영 콘텐츠에 자동 배정하지 않는다.

## 3. 장신구

### 확정 공통 규칙

- 기본 장비칸과 별개로 **자유 슬롯2칸**. 반지·목걸이 같은 부위 제한 없음.
- 전투 중 교체 허용. 수치 효과 중첩 허용.
- 별도로 획득한 동일 장신구2개는 함께 착용할 수 있다. 하나의 획득 보상을 재지급한 복사본은 두 번째 획득으로 세지 않는다.
- 획득 권한은 영구 저장하고 분실 시 재지급한다. 교체·재지급·재접속·부활로 사용 기록과 쿨타임을 초기화하지 않는다.
- 장신구마다 **고정 전투력**을 작성한다. 기존 장비의 획득 기록 평가 방식을 유지하여 보유 중인 합법적인 장신구 중 고정 점수가 높은2개의 합을 장신구 점수로 사용한다. 실제 효과는 착용한2개만 활성화한다. 효과 수치를 전투력으로 다시 자동 환산하지 않는다.
- 장신구 이름과 효과 이름은 별개다. `OOO의 반지`에 `연계의 매듭` 효과를 붙이는 형태로 작성할 수 있다.

### 효과 목록과 작성할 값

| 가칭·효과 | 동작 | 기획자가 작성할 값 |
|---|---|---|
| 최대 마나 증가 | 장착 중 최대 마나 증가. 1% 회복량도 증가 | 증가 마나 |
| 연계의 매듭 | 무기 우클릭 스킬 적중 시 지정한 습득 스킬의 **기본 쿨타임10%**만큼 남은 시간 감소 | 실제 장신구 이름·고정 점수 |
| 정화의 부적 | 일반 CC1회 해제. 기믹 제외. 기본 쿨타임5분 | 적용할 CC의 정화 가능 분류 |
| 응급의 목걸이 | 적 공격 후 생존하고 체력이25% 경계를 아래로 통과하면 최대 체력의 일부를 서서히 회복. 기본 쿨타임24시간 | 총 회복 비율·회복 시간 |
| 재정비의 반지 | 공격 시전 전체가 빗나가면 지불한 마나 일부 환급 | 환급 비율 |
| 행운의 반지 | 보상 희귀도·수량 및 개인 확률 사건의 행운 입력 증가 | 증가 행운 |
| 공격의 반지 | 일반 공격·플레이어 귀속 공격의 최종 피해에 고정값 추가 | 추가 피해 |
| 속도의 반지 | 이동속도 속성에 고정값 추가 | 증가 속성값 |
| 점프의 반지 | 공중 추가 점프 제공 | 추가 점프 횟수 |
| 강인의 반지 | 받는 최종 피해에서 고정값 감소 | 감소 피해 |
| 재생의 반지 | 초당 체력 회복 | 초당 회복 체력 |
| 골드 추가 획득 | 확정되는 보상 골드에 추가 비율 적용 | 추가 비율. 예:5% |

행운은 기존 밸런스 상한17을 유지한 초기 구현이다. 버프 단계와 장신구 행운을 합산하여17까지만 반영한다. 이 상한을 바꾸려면 행운 보상 계수와 함께 후속 기획한다. 골드 추가는 퀘스트·레이드·스토리 등의 보상 영수증으로 확정되는 골드에 적용하며, 환불·송금·상점 정산 같은 모든 잔액 증가에 붙이지 않는다. 보너스는 소수점 버림하고 한 번 확정한다.

### 연계·환급의 정확한 판정

- 광역으로10명을 맞혀도 한 시전이다. 다단·지속 피해도 같은 시전으로 묶는다.
- 연계는 성공적으로 감소시킨 시전에서 한 번만 발동한다. 지정 습득 스킬이 쿨타임 중일 때만 적용하며0초 아래로 줄이지 않는다.
- 기본20초 스킬은 매듭1개로2초, 같은 효과2개로4초 감소한다. 남은 시간이1초면1초만 줄인다.
- 장신구와 특수스킬의 사용 제한은 연계 대상이 아니다.
- 환급은 시전 종료까지 유효 적중이0일 때 한 번만 한다. 두 장신구의 환급률을 합산하되 지불 마나100%가 상한이다. 쿨타임은 환급하지 않는다.
- 시전 시작 때 착용 장신구와 연계 대상을 기록한다. 발동 후 교체로 이미 시작한 공격의 효과를 뒤늦게 바꾸지 않는다.

### 중첩·교체에 대한 초기 처리

다음은 이번 구현에서 사용한 공통 처리이며 개별 인물의 정사나 고정 보상 수치가 아니다.

- 수치 증가량·감소량·재생량·골드 비율은 합산한다.
- 점프 효과는 추가 점프 횟수를 합산한다. 각각1회면 두 개로 공중 추가2회다. 착지해야 충전되며 공중 교체·재접속으로 새 점프가 생기지 않는다.
- 정화2개는 일반 CC가 걸릴 때 준비된 장신구 하나씩 사용한다. 이미 일반 CC에 걸렸을 때 준비된 부적을 새로 장착해도 해제한다. 같은 CC에 두 개를 동시에 낭비하지 않는다. 쿨타임은 각 획득 장신구에 남는다.
- 응급 회복2개가 모두 준비되어 있으면 같은 조건에서 각각 발동하고 회복량이 합산된다. 발동한 회복은 장신구를 벗어도 진행하지만 사망하면 종료된다. 쿨타임은 유지된다.
- 응급 회복은 낙하·환경 피해나 장신구 교체로 체력 비율이 바뀐 것만으로 발동하지 않는다. 적에게 귀속된 지속 피해는 적 공격 판정에 포함된다.
- 피해 증가·감소는 방어 계산 뒤 체력 피해 단계에 적용하고 피해0을 허용한다. 강제 처형·공허 등 무적 우회 피해에는 적용하지 않는다. 따라서 작은 반복 피해를 막는 성격도 있다.

## 4. 특수스킬 — 기획자가 사용 제한 선택

최상급 이상 인물에게서 얻는 레이드 지원 기술이다. **레이드에서만 사용하며 인물이 등장해 정해진 행동 한 번을 하고 퇴장**한다. 개별 신의 기술은 이후 기획서를 받아 작성한다. 제우스·케라우노스는 구상 예시이며 현재 자동 배정하지 않았다.

### 선택 가능한 사용 제한

| 선택 항목 | 기획자가 입력할 값 | 동작 |
|---|---|---|
| 레이드당 횟수 | 보통1회, 필요하면 별도 횟수 | 플레이어·스킬·해당 도전별 횟수 제한 |
| 현실 쿨타임 | 시간. 24시간이면86,400초 | 사용한 시점부터 현실 시간이 흐름. 서버 종료·로그아웃 중에도 진행 |
| 소모 아이템 | 정확한 아이템 종류·변형·수량. 복수 재료 가능 | 정상 시전마다 해당 재료를 소비 |
| 추가 마나 비용 |0이면 없음, 필요하면 수치 | 위 제한과 별도로 공통 마나에서 소비 |

**사용 제한은 최소 하나 선택한다. 여러 개를 선택하면 전부 만족해야 한다.** 선택하지 않은 제한은 자동으로 붙지 않는다. 마나 비용만으로 사용 제한 선택을 대신하지 않는다.

| 예시 유형 | 레이드당 횟수 | 현실 쿨타임 | 아이템 |
|---|---:|---:|---|
| A |1회|없음|없음|
| B |없음|24시간|없음|
| C |없음|없음|소환석1개|
| D |1회|없음|소환석1개|
| E |없음|24시간|소환석1개|
| F |1회|24시간|없음|
| G |1회|24시간|소환석1개|

아이템만 요구하는 유형은 아이템이 충분하면 다음 정상 사용도 가능하다. 임의로 레이드당1회나24시간 제한을 추가하지 않는다. 레이드당 횟수는 같은 도전의 부활·재접속·재입장으로 초기화되지 않는다. 새 도전을 만들면 그 도전의 횟수는 새로 계산한다. 현실 쿨타임은 도전이 바뀌어도 남는다.

### 발동과 실패

`습득·제공 인물·현재 참가 자격·추가 조건·자원 확인 → 사용 기록·비용 확정 → 등장·대사·기술1회 → 퇴장`.

사용 전 조건 실패는 무소모다. 정상 시전이 시작되면 기술이 빗맞거나 적이 피해를 막아도 횟수·쿨타임·재료를 소비한다. 재정비 환급과 연계 감소는 특수스킬에 적용하지 않는 초기 구현이다. 기존 레이드 참여 제한과 인물 관계 조건을 우회하지 않는다. 특별한 관계 제한이 필요하면 해당 기술에 조건을 작성한다.

현재 초기 행동은 전격 연출+범위 마법 피해, 범위 마법 피해, 근처 레이드 참가자 회복이다. 공격에는 짧은 일반 스턴을 붙일 수 있다. 보스별 일반 스턴 면역은 따로 작성하며 기믹을 스턴으로 건너뛰지 않는다. 추가 행동은 구체적인 기술 기획과 함께 확장한다.

## 5. 남은 기획

신별 등급·보상 배정, 일반 스킬 목록, 장신구 효과 수치와 고정 점수, 특수스킬별 선택 제한·행동을 작성한다. 기존 기능에 없는 행동은 구현 필요 항목으로 표시한다. 이번 공통 시스템이 신별 목록과 정식 수치를 대신 확정하지 않는다.
