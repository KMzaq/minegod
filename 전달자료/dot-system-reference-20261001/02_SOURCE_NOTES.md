# 원문 읽기 주의사항과 현재 상태

2026-10-01 스냅샷. 아래는 기존 문서를 수정한 결과가 아니라 **이 전달 묶음의 해석 안내**다. 원문은 `reference/`에 그대로 보존했다. 이 요약은 전체 코드를 재감사하거나 실행 검증한 보고서가 아니다.

## 우선순위

사용자의 현재 확정 요구 → 실제 코드와 현재 빌드 입력 → 최신 HanesTest 기록 → 해당 분야의 후속 상세 가이드 → 과거 누적 기록 순으로 대조한다. 충돌이 해결되지 않으면 질문하고, 문서의 ‘최신/완료’라는 단어만으로 선택하지 않는다. 미래에 원본이 갱신되면 이 ZIP도 과거 스냅샷이 된다.

## 혼동하기 쉬운 항목

| 원문에 남아 있는 설명 | 이번 기획에서 사용할 해석 |
|---|---|
| `QUEST_PARTICIPATION_GUIDE`의 ‘물리 NPC 없음’, 옛 `/mythtalk`·HUD 일시정지 설명 | 당시 대화 진입 경로의 설명이다. 현재 물리 NPC와 새 대화방이 있다. 참여형 퀘스트의 목표·동의·정산 계약과 옛 대화 명령을 분리해서 읽는다. 현재 명령은 `AI_DIALOGUE_TEST_COMMAND`/`CONVERSATION_ROOMS`를 참고한다. |
| 보상/FTB/참여 문서 중간의 ‘watch 타입 미구현’ | 후속 구현과 보상 가이드 첫 배너, 실제 RewardEntryCodec/RewardExecutionService에서는 `watch`를 지원한다. 메인 접근 권한과 주시 획득은 별개다. |
| 관계/AI 행동 문서의 초기 ‘1플레이어·2신에서만 Secondary’ | 9/23 후속 전체 방 통합에서 다른 참가 신의 순차 반응 범위를 확장했다. 임의의 모든 게임 행동을 Secondary에게 허용했다는 뜻은 아니다. |
| 사회맥락 문서의 ‘감정 연결 없음/전투력 공급자 없음’ | 대화 감정과 보상 증거 기반 전투력 공급자는 후속 추가됐다. 다만 자율 활동의 공용 감정, 신↔플레이어 전투 우위/보호 계약은 이 공급자와 다르며 미확인 정보를 추측하지 않는다. |
| 옛 가이드의 protocol 7/8/9 | 최신 개발 게임은 1.0.23/protocol 10이다. 과거 UI 도입 당시 번호를 현재 배포 버전으로 사용하지 않는다. |
| `docs/README`나 오래된 사회맥락의 `mine` 빌드 의존 설명 | HanesTest 최신 AI는 `src/main/java` + `src/engine/java`를 직접 컴파일한다. `mine`/`mine2`는 새 개발 기준이 아니다. |
| `NPC_VISIT_PLAYER` 완료 모드 존재 | 완료 준비 조회 계약과 실제 방문 자동 시작은 별개다. 현재 `readyForNpcVisit` 조회를 물리 방문 시작으로 연결하는 후속 작업이 남았다. |
| 신규 기록/검색의 상세 문서가 많음 | 새 체계 전체가 실제 대화에 기본 적용된 것은 아니다. 최신 작업표의 미완료·후순위와 운영 OFF/시험 제한을 따른다. 기존 대화/기억 기능 자체가 없는 뜻도 아니다. |
| 예시 `mythictrpg:demeter`, `mythictrpg:fortuna` | 기존 시험 데이터의 실제 ID다. 신규 인물은 제공된 ID/최신 작성 규칙을 따르며 이 두 예시를 새 명명 규칙으로 일반화하거나 기존 ID를 무단 변경하지 않는다. |
| 문서의 테스트 개수·BUILD SUCCESS·JAR 생성 | 실제 클라이언트/모델의 자연스러움, 운영 설치·부팅, 완성된 콘텐츠의 증거가 아니다. |

## 이번 포장 작업에서 확인한 근거

- `git branch --show-current`: HanesTest. 기존 미커밋 변경을 포함한 문서 스냅샷이며 커밋/병합하지 않았다.
- 세 모듈 `gradle.properties`: Minecraft 1.21.1 / NeoForge 21.1.248, 개발 버전 게임 1.0.23·AI 0.1.26·콘텐츠 0.1.3.
- `server/mods` 파일 목록: 게임 1.0.16·AI 0.1.19·콘텐츠 0.1.2. 설치 파일 확인이지 서버 부팅 확인이 아니다.
- 최신 브랜치 인수인계·작업표·NPC 활동 기록의 구현/검증/미배포 구분.
- 공용 진행·퀘스트·관계·상점·보상·레이드·전투력의 관련 원문 및 핵심 코드 조회.
- 문서 복사 해시와 핵심 안내 링크 확인은 `bundle-validation.json`에 기록한다. ZIP 생성 후에는 압축 항목을 다시 읽어 묶음 파일과 해시를 비교하며, 그 결과는 ZIP 옆의 `.validation.json`에 남긴다. 원문 문서가 가리키는 미포함 소스/로그 링크 전체를 검증한 것은 아니다.

## 별도 제공해야 할 것

- 등장 신화/신 후보 원본과 필수 등장 인물.
- 확정된 배경·진행 스토리, 수정 가능한 초안, 확정 여부 표시.
- 목표 플레이 인원/기간/분위기와 최종 성장 수준 등 아직 결정하지 않은 콘텐츠 조건.
- 실제 맵·리소스팩·보스 자산이 필요하면 후속 작업에서 선별 전달.

이 포장은 해당 자료를 임의로 찾아 합치거나 새로운 기획을 확정하지 않는다. 서버/소스/월드/운영 데이터는 변경하지 않았으며 새 빌드나 모델 호출도 하지 않았다.
