# 공용 인수인계 절별 색인

이 색인은 [공용 인수인계](PROJECT_HANDOFF.md)의 §1–58을 빠르게 찾기 위한 것이다. 각 절과 제목의 버전·`최신` 표현은 **작성 당시의 기록**이다. 현재 작업은 [작업 시작 안내](START_HERE.md)에서 브랜치·실제 파일·로그를 먼저 대조한다. `HanesTest` 실험 결과는 [별도 브랜치 인수인계](브랜치실험/HanesTest/PROJECT_HANDOFF.md)에 남기며 공용 §58 이후의 완료 이력으로 취급하지 않는다.

이 파일은 길찾기 전용이다. 새 공용 절을 추가한다면 `PROJECT_HANDOFF.md`에 `handoff-59`처럼 중복 없는 앵커를 붙이고 여기에 한 줄을 추가한다. 기존 절의 시점별 검증·배포 문구는 사후에 현재형으로 고치지 않는다.
