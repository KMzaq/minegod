# 퀘스트와 분기 작성 양식

참여형 SOLO는 동일 퀘스트를 여러 사람이 각각 복제 수주하는 유형이 아닙니다. GROUP은 확정 참가자 각자의 목표 달성·제출을 확인합니다.
참여 설정이 없는 기존 고정 퀘스트는 전역 최초 완료 경로이며 다른 수주자에게 영향이 있습니다. 즉석 사이드는 현재 개인형입니다.

## 5. 완료 확인과 정산

기본은 목표 달성 → 의뢰한 신의 실제 확인 → 정산입니다. 달성만으로 신이 자동 방문하지 않습니다.
원격 확인은 해당 신이 현재 그 플레이어를 유효하게 주시하고 응답 가능한 때에만 가능합니다. 주시 획득권만으로는 부족합니다.
독서·산책 등 활동 중에는 원격 확인이 제한됩니다. 비주시 플레이어는 수주·지정 장소의 실제 대면 또는 실제 재조우가 필요합니다.
