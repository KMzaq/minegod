# FTB Quests 작업본 진입 지침

작업 전 [상위 AGENTS.md](../AGENTS.md)를 읽는다. 인수인계는 [PROJECT_HANDOFF.md](../인수인계/PROJECT_HANDOFF.md), 게임 연동 계약은 [FTB_QUESTS_INTEGRATION_GUIDE.md](../mythictrpg-main/docs/FTB_QUESTS_INTEGRATION_GUIDE.md)다.

기부 Task 등이 수정된 작업본이므로 일반 배포판으로 덮어쓰지 않는다. FTB 팀 목표와 MythicTRPG의 개인 수주/서버 전역 완료를 구분하고 보상을 중복 지급하지 않는다. 상위 작업공간이 없는 복사본이면 외부 계약을 먼저 확인한다.
